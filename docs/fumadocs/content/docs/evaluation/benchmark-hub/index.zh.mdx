## 怎么选

先明确要验证的主张，再打开对应配方——不要先安装独立环境。

- **终身 / 知识迁移操作**：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（Franka 桌面上的四个套件）。厨房相关看 [RoboCasa](/zh/docs/evaluation/benchmark-hub/robocasa)。
- **GPU 并行技能族**：[ManiSkill](/zh/docs/evaluation/benchmark-hub/maniskill)（SAPIEN）。WorldFoundry 导入 rollout，不替代模拟器。
- **长时程语言链**：[CALVIN](/zh/docs/evaluation/benchmark-hub/calvin)（A/B/C → D，链长度 1–5 的成功率）。
- **真机到仿真的策略排序**：[SimplerEnv](/zh/docs/evaluation/benchmark-hub/simpler-env)（按真机标定的 Google Robot 与 WidowX/Bridge）。
- **带逻辑目标的家务活动**：[BEHAVIOR-1K](/zh/docs/evaluation/benchmark-hub/behavior1k)（OmniGibson 中 1000 项 BDDL 活动）。
- **视频模型能否续写真实物理**：[Physics-IQ](/zh/docs/evaluation/benchmark-hub/physics-iq)（5 秒续写；仓内打分器）。只有当你要的就是那套协议时，才选择 [Physics-IQ Verified](/zh/docs/evaluation/benchmark-hub/physics-iq-verified)——媒体不可互换。
- **开源文生视频片段质量 / 组合**：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)、[T2V-CompBench](/zh/docs/evaluation/benchmark-hub/t2v-compbench)、[FETV](/zh/docs/evaluation/benchmark-hub/fetv)。

安装 benchmark 专用依赖前先看[运行环境矩阵](/zh/docs/evaluation/benchmark-hub/runtime-environments)。它区分统一环境、仓库管理的独立环境、托管 judge，以及按维度划分的 native/checkpoint 栈。

## 如何运行一个 benchmark

先打开配方。Prompt 文件、生成产物布局、checkpoint 名称、judge 模型和官方结果格式都因 benchmark 而异。

### 导入官方结果文件

当配方说明 WorldFoundry **归一化**上游导出、不运行模拟器时，使用此命令。

```bash
wf zoo benchmark-run \
  --benchmark-id <benchmark-id> \
  --mode official-validation \
  --official-results-path <official-result-file-or-dir> \
  --generated-artifact-dir <generated-artifact-dir> \
  --output-dir tmp/<benchmark-id>/official-validation \
  --json
```

### 在仓内给生成产物打分

只有配方明确说仓内 runtime 能从生成产物重算分数，并且所需媒体或 checkpoint 已就位时，才用 `official-run`。常见例子是 Physics-IQ。

```bash
wf zoo benchmark-run \
  --benchmark-id <benchmark-id> \
  --mode official-run \
  --generated-artifact-dir <generated-artifact-dir> \
  --output-dir tmp/<benchmark-id>/official-run \
  --json
```

需要先用已注册模型生成产物时：

```bash
wf run \
  --benchmark <benchmark-id> \
  --model <model-id> \
  --mode official-run \
  --output-dir tmp/<benchmark-id>/<model-id> \
  --json
```
