LIBERO-Para (EMNLP 2026 Main) is **not** another Spatial / Object / Goal / 100 suite. Soongsil and Chung-Ang freeze the **LIBERO-Goal** initial state so the instruction is the only task cue, then rewrite that instruction. The paper reports **4,092** held-out paraphrases of **10** Goal instructions across **43** types: 3 object-only, 10 action-only, and 30 compositional (object × action). Action types cover lexical, structural, and pragmatic forms (questions, hints). Object types are lexical substitutions. Everything else — scene, physics, objects — stays fixed.

Official scoring uses episode **success rate** plus **PRIDE** (Paraphrase Robustness Index in Robotic Instructional DEviation): a Paraphrase Distance from keyword similarity `S_K` and syntactic similarity `S_T`, then difficulty-weighted success. Published VLA configs drop **22.8–51.9** points versus the original Goal wording; most failures are planning-level trajectory divergence, not motor noise.

Paper: [LIBERO-Para](https://arxiv.org/abs/2603.28301). Project: [cau-hai-lab.github.io/LIBERO-Para](https://cau-hai-lab.github.io/LIBERO-Para/). Code: [cau-hai-lab/LIBERO-Para](https://github.com/cau-hai-lab/LIBERO-Para) (MIT). Dataset: `HAI-Lab/LIBERO-Para`.

WorldFoundry is **official-results only**. The Hugging Face snapshot is a staged asset. You run the upstream eval (`metrics/analyze_results.py` or equivalent), then `official-validation` normalizes the export. WorldFoundry does **not** recompute PRIDE and does **not** run robosuite. [Base LIBERO](/docs/evaluation/benchmark-hub/libero) can wire closed-loop execution; this page cannot.

## How to run

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id libero-para \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/libero-para/official-validation \
  --json
```

Optional `WORLDFOUNDRY_LIBERO_PARA_ROOT` / `WORLDFOUNDRY_LIBERO_PARA_DATASET_ROOT` point at the toolkit and `HAI-Lab/LIBERO-Para`. Default import path: `WORLDFOUNDRY_LIBERO_PARA_RESULTS_PATH`. Shared stacks: `libero_para_source_assets`, `libero_para_dataset_assets`. Manifest: `worldfoundry/data/benchmarks/tasks/external/libero-para.yaml`.

In-tree pointers:

```text
cache/worldfoundry/data/hfd_datasets/HAI-Lab__LIBERO-Para
cache/worldfoundry/repos/cau-hai-lab--LIBERO-Para
```

Outputs: `scorecard.json` (primary `success_rate`), `benchmark_contract.json`, `raw_metric_table.jsonl`, and `raw_results.jsonl`.
