LIBERO-Para（EMNLP 2026 Main）**不是**又一个 Spatial / Object / Goal / 100 套件。崇实大学与中央大学把 **LIBERO-Goal** 的初始状态冻住，使指令成为唯一任务线索，再改写这条指令。论文报告对 **10** 条 Goal 指令的 **4,092** 条仅评测改写，共 **43** 类：3 类仅物体、10 类仅动作、30 类组合（物体 × 动作）。动作类型覆盖词汇、结构与语用（疑问、暗示）；物体类型是词汇替换。场景、物理与物体保持不变。

官方计分用 episode **成功率** 加 **PRIDE**（Paraphrase Robustness Index in Robotic Instructional DEviation）：由关键词相似度 `S_K` 与句法相似度 `S_T` 得到改写距离，再按难度加权成功。已发表的 VLA 配置相对原始 Goal 措辞下降 **22.8–51.9** 个百分点；多数失败是规划级轨迹偏离，不是电机噪声。

论文：[LIBERO-Para](https://arxiv.org/abs/2603.28301)。项目：[cau-hai-lab.github.io/LIBERO-Para](https://cau-hai-lab.github.io/LIBERO-Para/)。代码：[cau-hai-lab/LIBERO-Para](https://github.com/cau-hai-lab/LIBERO-Para)（MIT）。数据集：`HAI-Lab/LIBERO-Para`。

WorldFoundry **只导入官方结果**。Hugging Face 快照作为就位资产。你在上游跑评测（`metrics/analyze_results.py` 或等价脚本），再经 `official-validation` 归一化导出。WorldFoundry **不**重算 PRIDE，也 **不**跑 robosuite。[基础 LIBERO](/zh/docs/evaluation/benchmark-hub/libero) 可以接线闭环；本页不行。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id libero-para \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/libero-para/official-validation \
  --json
```

可选 `WORLDFOUNDRY_LIBERO_PARA_ROOT` / `WORLDFOUNDRY_LIBERO_PARA_DATASET_ROOT` 指向工具包与 `HAI-Lab/LIBERO-Para`。默认导入路径：`WORLDFOUNDRY_LIBERO_PARA_RESULTS_PATH`。共享栈：`libero_para_source_assets`、`libero_para_dataset_assets`。清单：`worldfoundry/data/benchmarks/tasks/external/libero-para.yaml`。

仓内指针：

```text
cache/worldfoundry/data/hfd_datasets/HAI-Lab__LIBERO-Para
cache/worldfoundry/repos/cau-hai-lab--LIBERO-Para
```

输出：`scorecard.json`（主键 `success_rate`）、`benchmark_contract.json`、`raw_metric_table.jsonl`、`raw_results.jsonl`。
