LIBERO（NeurIPS 2023 Datasets & Benchmarks）是德州大学奥斯汀分校的终身操作评测，联合清华与 Sony AI。Franka 在 **robosuite / MuJoCo** 桌面上，必须跨任务迁移**陈述性**与**程序性**知识。四个官方套件把「迁了什么」拆开：

- **LIBERO-Spatial** — 物体相同，空间关系 / 布局不同。
- **LIBERO-Object** — 技能相同，物体身份不同。
- **LIBERO-Goal** — 场景相同，目标语言不同。
- **LIBERO-100** — LIBERO-10 短任务加 LIBERO-90 更长时程的混合。

它几乎已成为 VLA 的默认评测标准。论文是 [LIBERO: Benchmarking Knowledge Transfer for Lifelong Robot Learning](https://arxiv.org/abs/2306.03310)。项目：[libero-project.github.io](https://libero-project.github.io/)。代码：[Lifelong-Robot-Learning/LIBERO](https://github.com/Lifelong-Robot-Learning/LIBERO)（MIT）。

WorldFoundry 支持**两条**路径。官方 `eval_result` 树（或结构化导出）走 `worldfoundry.evals.tasks.embodied.normalizer`。闭环执行通过 `wf embodied run` 进行，需要上游模拟器、套件资产，以及官方脚本期望的策略。数据集快照：`yifengzhu-hf/LIBERO-datasets`（官方演示）与 `lerobot/libero`（LeRobot 转换版）。[Being-H0.5](/zh/docs/guides/supported-models/being-h05) 等模型提供 LIBERO 专家 checkpoint。

## 如何运行

导入官方结果树（不跑模拟器）：

```bash
wf zoo benchmark-run \
  --benchmark-id libero \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/libero/official-validation \
  --json
```

闭环执行需要 `WORLDFOUNDRY_LIBERO_ROOT`（可选，覆盖 runtime/仓库根）、套件资产和匹配的策略。省略 `--official-results-path` 时，默认导入路径是 `WORLDFOUNDRY_LIBERO_RESULTS_PATH`。共享资产栈：`libero_source_assets`、`libero_dataset_assets`。

仓内指针：

```text
worldfoundry/data/benchmarks/tasks/external/libero.yaml
cache/worldfoundry/data/hfd_datasets/yifengzhu-hf__LIBERO-datasets
cache/worldfoundry/data/hfd_datasets/lerobot__libero
cache/vla_va_wam/repos/Lifelong-Robot-Learning--LIBERO
```

`--output-dir` 下包括 `scorecard.json`（主键 `success_rate`）、`run_manifest.json`、`results.jsonl`、`metrics/summary.json`。
