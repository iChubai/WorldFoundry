RoboTwin 2.0 (The University of Hong Kong and Shanghai AI Laboratory, with AgileX) is a **bimanual** SAPIEN benchmark, not a video-generation suite. The paper instantiates **50** dual-arm tasks on **RoboTwin-OD** (**731** objects, **147** categories) across **five** embodiments: Aloha-AgileX, ARX-X5, Piper, Franka Panda, and UR5-WSG. Domain randomization is five axes — clutter, lighting, background, tabletop height, language — and **clean** vs **randomized** success are reported separately. The companion dump is **100k+** expert trajectories (`TianxingChen/RoboTwin2.0`).

Paper: [RoboTwin 2.0](https://arxiv.org/abs/2506.18088). Project: [robotwin-platform.github.io](https://robotwin-platform.github.io/). Docs: [usage / configurations](https://robotwin-platform.github.io/doc/). Code: [RoboTwin-Platform/RoboTwin](https://github.com/RoboTwin-Platform/RoboTwin). Official board: [leaderboard](https://robotwin-platform.github.io/leaderboard).

WorldFoundry **imports** official `eval_result/_result.txt` (layout `eval_result/{task}/{policy}/{config}/{ckpt}/{timestamp}/_result.txt`) or structured JSON/CSV. Offline normalization needs no simulator. Producing new results needs the upstream **SAPIEN / Curobo** stack and the official `policy/*/eval.sh` scripts. Rendering through `script/test_render.py` has not been validated in WorldFoundry. Shared stack: `robotwin_dataset_assets`.

## How to run

```bash
wf zoo benchmark-run \
  --benchmark-id robotwin \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/robotwin/official-validation \
  --json
```

`--official-results-path` may point at a `_result.txt` tree or a JSON/CSV export. Optional `WORLDFOUNDRY_ROBOTWIN_ROOT` overrides the runtime/repo root. Default import path: `WORLDFOUNDRY_ROBOTWIN_RESULTS_PATH`. Manifest: `worldfoundry/data/benchmarks/tasks/external/robotwin.yaml`.

Default local paths for the dataset dumps and upstream checkout:

```text
cache/worldfoundry/data/hfd_datasets/TianxingChen__RoboTwin2.0
cache/worldfoundry/data/hfd_datasets/lerobot__robotwin_unified
cache/vla_va_wam/repos/RoboTwin-Platform--RoboTwin
```

Outputs: `scorecard.json` (primary `success_rate`), `benchmark_contract.json`, `task_manifest.json`, `official_command_manifest.json`, `simulator_validation.json`, `raw_metric_table.jsonl`, and `evaluation/per_sample_metrics.jsonl`.
