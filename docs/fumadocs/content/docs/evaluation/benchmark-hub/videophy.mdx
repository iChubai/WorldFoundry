VideoPhy (UCLA and Google Research) tests whether text-to-video models obey **physical commonsense** in material interactions (solid-solid, solid-fluid, fluid-fluid). Each prompt describes a physical interaction. The official judge is **VideoCon-Physics**, a fine-tuned video-language model. Three scores:

- **Semantic Adherence** — does the clip match the prompt?
- **Physical Commonsense** — does the motion obey physics?
- **Joint Score** — both together.

`videophy_average` is the WorldFoundry mean over available families. A full 688-prompt reproduction has not been validated in WorldFoundry.

Paper: [VideoPhy](https://arxiv.org/abs/2406.03520). Project: [videophy.github.io](https://videophy.github.io/). Code: [Hritikbansal/videophy](https://github.com/Hritikbansal/videophy).

WorldFoundry **bundles the prompt list** and can run the in-tree VideoCon-Physics AutoEvaluator (`--videocon-checkpoint`, `--sa-threshold` / `--pc-threshold`) or import official JSON. The checkpoint is caller-supplied, not vendored.

## How to run

```bash
wf zoo benchmark-run \
  --benchmark-id videophy \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir tmp/videophy/official-validation \
  --json
```

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evals/tasks/execution/runners/videophy/run_videophy_official_runner.py \
  --run-official \
  --generated-artifact-dir "${WORLDFOUNDRY_GENERATED_ARTIFACT_DIR}" \
  --videocon-checkpoint /path/to/videocon_physics \
  --output-dir tmp/videophy/official \
  --json
```

Env: `WORLDFOUNDRY_VIDEOPHY_RESULTS_PATH`, `WORLDFOUNDRY_VIDEOPHY_JUDGE_BACKEND`. Prompt list: `worldfoundry/data/benchmarks/assets/videophy/prompts.json`.

Manifest and runner: `worldfoundry/data/benchmarks/tasks/external/videophy.yaml`, `worldfoundry/evals/tasks/execution/runners/videophy`.

Outputs include `scorecard.json` (primary `videophy_average`).
