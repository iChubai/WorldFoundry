VideoScience-Bench (Hao AI Lab, UC San Diego) asks whether video generators **understand science**. Prompts describe real experiments and phenomena. A VLM judge scores five dimensions on a **1–4 rubric**; the official weighted overall normalizes to the unit interval as `videoscience_average`:

- **Prompt consistency**
- **Phenomenon congruency** — does the depicted outcome match the true science?
- **Correct dynamism**
- **Immutability** — do invariant properties stay invariant?
- **Spatio-temporal coherence**

Paper: [VideoScience-Bench](https://arxiv.org/abs/2512.02942). Space: [lmgame/videoscience-bench](https://huggingface.co/spaces/lmgame/videoscience-bench/blob/main/README.md). Code: [hao-ai-lab/VideoScience](https://github.com/hao-ai-lab/VideoScience). No Hugging Face dataset is required.

WorldFoundry **normalizes official result files** and can drive judge runs over an experiments CSV when a provider / model / credential is configured.

## How to run

```bash
wf zoo benchmark-run \
  --benchmark-id videoscience-bench \
  --mode official-validation \
  --official-results-path <official_results.json> \
  --generated-artifact-dir <generated_videos> \
  --output-dir tmp/videoscience-bench/official-validation \
  --json
```

Runtime CLI takes `--experiments-csv`, `--evaluation-results-dir`, optional `--reference-videos-dir`, and judge flags (`--judge-provider`, `--judge-model`, `--judge-max-runs`, `--max-frames`, `--judge-fps`). `--ready-only` scores only complete artifacts. Default import: `WORLDFOUNDRY_VIDEOSCIENCE_BENCH_RESULTS_PATH`.

Manifest: `worldfoundry/data/benchmarks/tasks/external/videoscience-bench.yaml`.

Outputs include `scorecard.json` (primary `videoscience_average`).
