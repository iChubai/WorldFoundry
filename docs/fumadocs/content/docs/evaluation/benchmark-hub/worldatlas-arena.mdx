WorldAtlas Arena (OpenEnvision; catalog id **`worldatlas-arena`**) evaluates generated world-model rollouts across image / video static and dynamic suites plus a memory loop. It keeps the official **six-axis result vector** and **does not define a benchmark-wide scalar**. This is **not** Tsinghua FIB Lab [WorldArena](/docs/evaluation/benchmark-hub/worldarena).

- **Long sequence** — long-horizon persistence and closed-loop memory
- **Action control** — prompt, camera, motion, keystroke
- **3D / 4D consistency** — geometry, depth, flow, reconstruction
- **Physics** — physical plausibility and motion dynamics
- **Quality** — perceptual quality, fidelity, temporal artifacts
- **Real time** — throughput, response latency, physical-time behavior

Code: [OpenEnvision/WorldArena](https://github.com/OpenEnvision/WorldArena).

WorldFoundry can `--run-official` from a caller manifest, or normalize official report directories / summary JSON. Existing summaries normalize on CPU; full metric execution may need CUDA, checkpoints, media, and third-party runtimes. The checked-in fixture validates **normalization only**.

## How to run

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/worldatlas_arena/run_worldatlas_arena_official_runner.py \
  --run-official \
  --manifest /data/worldarena/manifest.jsonl \
  --generated-artifact-dir /data/worldarena/predictions \
  --output-dir tmp/worldatlas-arena/official-run \
  --json
```

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id worldatlas-arena \
  --mode official-validation \
  --official-results-path /path/to/worldarena/report \
  --output-dir tmp/worldatlas-arena/imported \
  --json
```

Outputs include `scorecard.json`, `raw_metric_table.jsonl`, `per_sample_scores.jsonl`, and `benchmark_contract.json`. There is no official combined leaderboard scalar to ingest.
