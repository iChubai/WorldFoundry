WorldAtlas Arena（OpenEnvision；目录 id **`worldatlas-arena`**）评生成式世界模型 rollout，覆盖图像 / 视频的静态与动态套件，外加记忆环。它保留官方 **六轴结果向量**，**不定义全基准标量**。这 **不是** 清华 FIB Lab 的 [WorldArena](/zh/docs/evaluation/benchmark-hub/worldarena)。

- **长序列** — 长程持续与闭环记忆
- **动作控制** — prompt、相机、运动、按键
- **3D / 4D 一致性** — 几何、深度、光流、重建
- **物理** — 物理合理性与运动动力学
- **质量** — 感知质量、保真、时间伪影
- **实时** — 吞吐、响应延迟、物理时间行为

代码：[OpenEnvision/WorldArena](https://github.com/OpenEnvision/WorldArena)。

WorldFoundry 可从调用方清单 `--run-official`，或归一化官方报告目录 / 摘要 JSON。已有摘要可在 CPU 上归一化；完整指标执行可能需要 CUDA、权重、媒体与第三方 runtime。仓内 fixture 只验证 **归一化**。

## 如何运行

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/worldatlas_arena/run_worldatlas_arena_official_runner.py \
  --run-official \
  --manifest /data/worldarena/manifest.jsonl \
  --generated-artifact-dir /data/worldarena/predictions \
  --output-dir tmp/worldatlas-arena/official-run \
  --json
```

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id worldatlas-arena \
  --mode official-validation \
  --official-results-path /path/to/worldarena/report \
  --output-dir tmp/worldatlas-arena/imported \
  --json
```

产物包括 `scorecard.json`、`raw_metric_table.jsonl`、`per_sample_scores.jsonl`、`benchmark_contract.json`。没有可收录的官方合并榜单标量。
