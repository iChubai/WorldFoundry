WorldOlympiad（阿里达摩院）是长视频世界模型的 **三项赛**。主键 `combined_score` 在单位区间上平均三条赛道：

- **物理** — Qwen3-VL 置信加权物理问答，覆盖力学、热学、材料
- **交互** — 逐 chunk 指令跟随、过渡平滑、全局一致性（原生 0–5，再归一化）
- **几何** — Depth Anything 3 重建（高斯溅射、元视角、相机轨迹对齐；原生 0–3）

论文：[WorldOlympiad](https://arxiv.org/abs/2606.11129)。项目：[alibaba-damo-academy.github.io/WorldOlympiad](https://alibaba-damo-academy.github.io/WorldOlympiad)。代码：[alibaba-damo-academy/WorldOlympiad](https://github.com/alibaba-damo-academy/WorldOlympiad)。数据：[`ziplab/WorldOlympiad`](https://huggingface.co/datasets/ziplab/WorldOlympiad)。钉选修订 **没有 LICENSE**。

WorldFoundry **检入官方批量评测器**——不需要外部 checkout。计分运行需要 `--da3-src`、`--weights-dir`（DA3 / SAM3 / QwenVL / CLIP），以及正在运行的 QwenVL、SAM3、DA3 reward 服务。**`--run-official --dry-run` 与裁判输出归一化已验证；不声称已做计分三项赛。**

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id worldolympiad \
  --mode official-validation \
  --official-results-path <case_root_or_judge_json> \
  --output-dir tmp/worldolympiad/official-validation \
  --json
```

`--official-results-path` 接受案例根、单个裁判 JSON、`summary.jsonl` 或汇总 JSON。用 `--skip-physical`、`--skip-interaction`、`--skip-3d` 跳过赛道。环境变量：`WORLDFOUNDRY_WORLDOLYMPIAD_RESULTS_PATH`、`WORLDFOUNDRY_WORLDOLYMPIAD_WEIGHTS_DIR`、`WORLDFOUNDRY_WORLDOLYMPIAD_DA3_SRC`。runner 拒绝把输出 / 权重路径放进已检入 runtime。

仓内指针：`worldfoundry/data/benchmarks/tasks/external/worldolympiad.yaml`，`worldfoundry/evaluation/tasks/execution/runners/worldolympiad`。

产物包括 `scorecard.json`（主键 `combined_score`）与 `per_case_metrics.jsonl`。
