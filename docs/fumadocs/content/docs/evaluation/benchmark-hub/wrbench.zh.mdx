WRBench（“Current World Models Lack a Persistent State Core”；中科大与 X-Humanoid / 北京人形机器人创新中心）把相机运动当成 **可观测性干预**：事件开始，相机转开，回来时问目标是 **推进到终点还是冻在离开时的状态**。**Natural-25** 交叉 25 个场景族与四级事件设计（空间变化 × 状态变化）。标准相机轨把 **100 个语义变体 × 五种相机控制** 展开成 **500 条请求**。

分层 **D1–D6**：

- **D1** — 请求相机精度 / prompt-相机对齐
- **D2** — 视觉完整性
- **D3 / D4** — 可见时的空间 / 状态一致性
- **D5 / D6** — 再观察时的空间 / 状态一致性（**只**在可判定的隐藏-返回证据上聚合）

`wrbench_average` 汇总 D1–D6。论文：[WRBench](https://arxiv.org/abs/2606.20545)。项目：[jinplu.github.io/WRBench](https://jinplu.github.io/WRBench/)。代码：[JinPLu/WRBench](https://github.com/JinPLu/WRBench)。数据：[`WRBench/wrbench-natural25`](https://huggingface.co/datasets/WRBench/wrbench-natural25)。

WorldFoundry **检入完整包装与 Natural-25 资产**。Natural-25 请求物化与结果归一化可用；**完整 D1–D6 执行未验证**。打分器：VGGT-Omega、DINOv2、Qwen3.5、Qwen3-VL。

## 如何运行

```bash
worldfoundry-eval zoo benchmark-run \
  --benchmark-id wrbench \
  --mode official-validation \
  --official-results-path <official_results.json_or_csv> \
  --generated-artifact-dir <generated_videos> \
  --output-dir tmp/wrbench/official-validation \
  --json
```

`--run-official` 对照 Natural-25 给生成视频加相机 sidecar 打分（`--scorer-profile`、`--sidecar-profile-gate`）。没有再观察支持的行从 D5/D6 **排除**，不记失败。环境变量：`WORLDFOUNDRY_WRBENCH_RESULTS_PATH`、`WORLDFOUNDRY_WRBENCH_ROOT`。共享栈：`vggt_omega`、`dinov2`、`qwen3_5_vl`、`qwen3_vl`。

仓内指针：`worldfoundry/data/benchmarks/tasks/external/wrbench.yaml`，`worldfoundry/data/benchmarks/assets/wrbench`，`worldfoundry/evaluation/tasks/execution/runners/wrbench/runtime/wrbench`。

产物包括 `scorecard.json`（主键 `wrbench_average`，榜单键 `Avg`）与 `generation_requests.jsonl`。
