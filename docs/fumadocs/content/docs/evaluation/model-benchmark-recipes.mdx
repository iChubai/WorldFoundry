Ten **inference → score** cells that exist in the model and benchmark catalogs. Each cell is half a screen: prepare, generate, one documented eval command, the **real** `scorecard.json` key, and pending vs verified. A process exit is not a leaderboard. WorldFoundry does not invent ranks.

Start from [Evaluation](/docs/evaluation) (welcome step 5) or the [Benchmark Hub](/docs/evaluation/benchmark-hub). Model launch details stay on each model page.

**Output dirs.** Write clips or traces under `tmp/<benchmark-id>/<model-id>/gen`. Write the scorecard under `tmp/<benchmark-id>/<model-id>/eval/scorecard.json`.

**Status words.** **Verified** means this repository recorded GPU / runner / component evidence for that slice. **Pending** means the route is wired but parity, judge, or the full suite is not recorded. **Import only** means the normalizer reads official-shaped files; it does not replay the simulator.

## Wan2.1 → VBench

Catalog: `wan2.1` recommends `vbench`. Use **`wan2.1-t2v-1.3b`** (verified 832×480, 81 frames). 14B and I2V are integrated, not this cell.

**Prepare.** `worldfoundry-unified-cu128`. Stage Wan-AI 1.3B T2V locally.

**Generate.** Artifact `wan2.1-t2v-1.3b-832x480-81f.mp4`.

```bash
worldfoundry-eval run wan2.1-t2v-1.3b --pipeline.task-profile text-to-video \
  --output-dir tmp/vbench/wan2.1/gen
```

**Score.** Hub-recorded bounded path: `custom_input` / `aesthetic_quality` (the only VBench GPU dimension this repo verified).

```bash
${WORLDFOUNDRY_UNIFIED_PYTHON} \
  worldfoundry/evaluation/tasks/execution/runners/vbench/run_vbench_official_runner.py run \
  --mode custom_input --dimension aesthetic_quality \
  --videos-path tmp/vbench/wan2.1/gen \
  --output-dir tmp/vbench/wan2.1/eval --json
```

**Scorecard.** `aesthetic_quality`. `official_benchmark_verified=false`.

## Being-H0.5 → LIBERO

Catalog: `being-h05` recommends `libero`. Use **`being-h05-2b-libero`**. Paper percents on that card are upstream, not a WorldFoundry scorecard.

**Prepare.** `worldfoundry-being-h05`. Stage `BeingBeyond/Being-H05-2B_libero` (no download at runtime).

**Generate.** Artifact `being_h05_action_trace.json`. That is a `get_action` trace, not a closed-loop suite score.

```bash
worldfoundry-eval run being-h05-2b-libero --pipeline.task-profile vla.policy_rollout \
  --output-dir tmp/libero/being-h05/gen
```

**Score.** LIBERO verification is **normalizer-only**. Import an official `eval_result` tree:

```bash
worldfoundry-eval zoo benchmark-run --benchmark-id libero --mode official-validation \
  --official-results-path <official_results.json> \
  --output-dir tmp/libero/being-h05/eval --json
```

**Scorecard.** `success_rate`. Closed-loop (`worldfoundry-eval embodied run`) is wired; this repo has not recorded a Being-H0.5 leaderboard run.

## Causal-Forcing → VBench

Catalog: `causal-forcing` recommends `vbench`. Studio default is chunk-wise T2V. Official demo parity is **pending**.

**Prepare.** `worldfoundry-unified-cu128`. Stage the chunk-wise student **and** a local Wan2.1 layout (`$WORLDFOUNDRY_WAN_MODELS_ROOT` or `$WORLDFOUNDRY_CKPT_DIR`). Profile notes point prompt lists at `worldfoundry/data/test_cases/forcing/prompts/` (override `$WORLDFOUNDRY_FORCING_PROMPTS_ROOT`). If that tree is missing, `custom_input` still scores clips you already wrote.

**Generate.** Artifact `causal-forcing.mp4`.

```bash
worldfoundry-eval run causal-forcing --pipeline.task-profile text-to-video \
  --output-dir tmp/vbench/causal-forcing/gen
```

**Score.** Same bounded VBench command as Wan2.1; point `--videos-path` at `tmp/vbench/causal-forcing/gen` and `--output-dir` at `tmp/vbench/causal-forcing/eval`.

**Scorecard.** `aesthetic_quality`. Model: `official_demo_parity_pending`. Bench: bounded.

## ZeroScope → FETV

Catalog: `zeroscope` recommends `fetv`. The 576w Diffusers route is **runner-verified**. Review CC-BY-NC-4.0 before automated scoring.

**Prepare.** `worldfoundry-unified-cu128`. Stage `cerspense/zeroscope_v2_576w` under `$WORLDFOUNDRY_HFD_ROOT`.

**Generate.** Artifact `zeroscope.mp4` (8 frames, 576×320). FETV-EVAL expects a 16-frame layout when it joins the official prompt index.

```bash
worldfoundry-eval run zeroscope --output-dir tmp/fetv/zeroscope/gen
```

**Score.** FETV-EVAL CLIPScore is the bounded official component (`verification_status: bounded_official_clipscore_verified`).

```bash
worldfoundry-eval zoo benchmark-run --benchmark-id fetv --mode official-validation \
  --official-results-path <official_results.csv-or-FETV-EVAL-dir> \
  --generated-artifact-dir tmp/fetv/zeroscope/gen \
  --fetv-metrics clip_score \
  --output-dir tmp/fetv/zeroscope/eval --json
```

**Scorecard.** `clip_score`. `fetv_average` only when every declared component is present. Human ratings cannot be recomputed.

## Cosmos Predict 2.5 → WorldModelBench

Catalog: `cosmos-predict-2.5` recommends `worldmodelbench` (and `physics-iq`; this cell is the world suite). Use **`cosmos-predict-2.5-2b`**. Checkpoints are gated.

**Prepare.** `worldfoundry-unified-cu128`. Stage `nvidia/Cosmos-Predict2.5-2B`. Download the 350-instance set when you will score.

**Generate.** Artifact `cosmos-predict2.5-2b.mp4`. 14B GPU output is still pending.

```bash
worldfoundry-eval run cosmos-predict-2.5-2b --pipeline.task-profile text-to-world-validation \
  --output-dir tmp/worldmodelbench/cosmos-predict-2.5/gen
```

**Score.** Import is the recorded first path. `official-run` needs `WORLDFOUNDRY_WORLDMODELBENCH_JUDGE`; **full judge execution is not verified**.

```bash
worldfoundry-eval zoo benchmark-run --benchmark-id worldmodelbench --mode official-validation \
  --official-results-path <official_results.json> \
  --benchmark-data-root <worldmodelbench_data_root> \
  --generated-artifact-dir tmp/worldmodelbench/cosmos-predict-2.5/gen \
  --output-dir tmp/worldmodelbench/cosmos-predict-2.5/eval --json
```

**Scorecard.** `world_model_average`. Leaderboard answers are withheld upstream.
