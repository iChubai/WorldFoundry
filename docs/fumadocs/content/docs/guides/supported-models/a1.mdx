A1 (AffordVLA) is an affordance-guided vision-language-action policy: it grounds manipulation in visual affordances before predicting robot actions. WorldFoundry runs AffordVLA in-tree (Molmo and CLIP ViT encoders, L1/DiT/flow action heads, and preprocessing) with two checkpoints: `spatialtemporal-ai/a1-libero` for LIBERO tasks and `spatialtemporal-ai/a1-pretrain` as the pretrained policy.

WorldFoundry pins upstream revision `2fcb07da`. Two Hugging Face checkpoints are available: task `spatialtemporal-ai/a1-libero` and pretrained `spatialtemporal-ai/a1-pretrain`. No license is published for these weights.

Validated with the released **LIBERO-Spatial** checkpoint on an **A100**: inference returns a finite **10×7** action chunk. Closed-loop LIBERO success rates have not been measured.

## What it is for

`a1` maps camera observations and an instruction to an action trajectory.

The stack couples Molmo (VLM) and CLIP ViT visual encoding with selectable action heads (L1 regression, DiT, or flow). The runtime derives action dimensions from checkpoint tensors and validates every action-token boundary, so mismatched checkpoints fail fast.

Tasks: VLA, VLA policy rollout, and robot policy. Aliases: `affordvla-a1`, `spatialtemporal-ai/a1-libero`, and `spatialtemporal-ai/a1-pretrain`.

Suggested benchmarks: [LIBERO](/docs/evaluation/benchmark-hub/libero) (The a1-libero checkpoint targets LIBERO manipulation tasks).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `action_trace` and `a1_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `A1Pipeline`.

Family status: **Runner parity pending**.

Stage tokenizer and checkpoint assets locally before running. Assets are local-only and checkpoint-provided Python is never executed; runtime loading uses strict key matching.

Output is an action_trace artifact, not video.

## Running in WorldFoundry

Run the policy with `wf run a1 --pipeline.task-profile default`.

It runs in the dedicated environment `worldfoundry-vla-a1` (Python 3.11, CUDA 12.8, torch>=2.8).

Weights: `spatialtemporal-ai/a1-libero` and `Qwen/Qwen2-7B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh a1`. Add `--download` to fetch missing public checkpoints.
