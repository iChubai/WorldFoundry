A1（AffordVLA）是可供性（affordance）引导的视觉-语言-动作策略：先将操作任务锚定到视觉可供性，再预测机器人动作。WorldFoundry 在树内运行 AffordVLA（Molmo 与 CLIP ViT 编码器、L1/DiT/flow 动作头与预处理），支持两个 checkpoint：LIBERO 任务用 `spatialtemporal-ai/a1-libero`，预训练策略用 `spatialtemporal-ai/a1-pretrain`。

论文：[arXiv 2604.05672](https://arxiv.org/abs/2604.05672)。

WorldFoundry 固定上游 revision `2fcb07da`。可用的两个 Hugging Face checkpoint：任务 checkpoint `spatialtemporal-ai/a1-libero`，预训练 checkpoint `spatialtemporal-ai/a1-pretrain`。这些权重未公布许可证。

已用发布的 **LIBERO-Spatial** checkpoint 在 **A100** 上验证：推理返回有限的 **10×7** 动作块。闭环 LIBERO 成功率尚未测量。

## 用来做什么

`a1` 把相机观测和指令映射为动作轨迹。

该栈将 Molmo（VLM）与 CLIP ViT 视觉编码同可选动作头（L1 回归、DiT 或 flow）耦合。运行时从 checkpoint 张量推导动作维度并校验每个动作 token 边界，不匹配的 checkpoint 会快速失败。

任务：视觉-语言-动作（VLA）、VLA 策略执行、机器人策略。别名：`affordvla-a1`、`spatialtemporal-ai/a1-libero`、`spatialtemporal-ai/a1-pretrain`。

推荐评测：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（a1-libero checkpoint 面向 LIBERO 操作任务）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`a1_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `A1Pipeline`。

系列状态：**Runner 一致性待确认**。

运行前需在本地就位 tokenizer 与 checkpoint 资产。资产仅从本地加载，绝不执行 checkpoint 携带的 Python；运行时加载采用严格键匹配。

AffordVLA、Molmo、CLIP ViT、L1/DiT/flow 动作头、预处理与安全的本地 checkpoint 加载均在树内运行。

## 在 WorldFoundry 中运行

用 `wf run a1 --pipeline.task-profile default` 运行策略。

运行环境：独立环境 `worldfoundry-vla-a1`（Python 3.11，CUDA 12.8，torch>=2.8）。

权重仓库：`spatialtemporal-ai/a1-libero`、`Qwen/Qwen2-7B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh a1`；下载缺失的公开权重时加 `--download`。
