ABot-M0 from Amap's CV Lab is a bimanual manipulation VLA built on Qwen3-VL with an AML flow action expert and optional VGGT geometric fusion. Three task weights are released — ABot-M0-LIBERO, ABot-M0-Robocasa, and ABot-M0-RoboTwin2 — plus a ModelScope pretraining checkpoint, all under Apache-2.0.

## What it is for

`abot-m0` is a vision-language-action policy: an instruction and observations in, actions out.

Qwen3-VL provides the vision-language backbone; the AML flow action expert decodes actions; optional VGGT fusion injects 3D geometry. The runtime loads the released config.yaml, dataset_statistics.json, and steps_*_pytorch_model.pt layout directly. It is published by Amap CV Lab (Alibaba Group).

Tasks: VLA, robot policy, policy rollout, and bimanual manipulation. Aliases: `abot_m0`.

Suggested benchmarks: [LIBERO](/docs/evaluation/benchmark-hub/libero) (Dedicated ABot-M0-LIBERO task weight), [RoboCasa](/docs/evaluation/benchmark-hub/robocasa) (Dedicated ABot-M0-Robocasa task weight), [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (Dedicated ABot-M0-RoboTwin2 task weight).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `action_trace` and `abot_m0_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `ABotM0Pipeline`.

Family status: **Static load only**.

Pick the task weight matching your benchmark (LIBERO, RoboCasa, or RoboTwin2). Only inference is supported; datasets, training, deployment services, and robot SDK code are not included.

## Running in WorldFoundry

Run the policy with `wf run abot-m0 --pipeline.task-profile default`.

It runs in the dedicated environment `worldfoundry-vla-abot-m0` (Python 3.10, Cu128 Recommended, torch>=2.7,\<2.8).

Weights: `acvlab/ABot-M0-LIBERO`, `acvlab/ABot-M0-Robocasa`, and `acvlab/ABot-M0-RoboTwin2` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh abot-m0`. Add `--download` to fetch missing public checkpoints.
