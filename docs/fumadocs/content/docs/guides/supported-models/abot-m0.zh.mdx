高德 CV 实验室的 ABot-M0 是基于 Qwen3-VL 的双臂操作 VLA，搭配 AML flow 动作专家与可选的 VGGT 几何融合。官方发布三个任务权重——ABot-M0-LIBERO、ABot-M0-Robocasa、ABot-M0-RoboTwin2——另有 ModelScope 预训练 checkpoint，全部采用 Apache-2.0 许可。

## 用来做什么

`abot-m0` 是视觉-语言-动作（VLA）策略：输入指令和观测，输出动作。

Qwen3-VL 提供视觉-语言骨干；AML flow 动作专家解码动作；可选 VGGT 融合注入 3D 几何。运行时直接加载发布的 config.yaml、dataset_statistics.json 与 steps_*_pytorch_model.pt 布局。该模型由高德地图 CV 实验室（阿里巴巴集团）发布。

任务：视觉-语言-动作（VLA）、机器人策略、策略执行、bimanual_manipulation。别名：`abot_m0`。

推荐评测：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（有专门的 ABot-M0-LIBERO 任务权重）、[RoboCasa](/zh/docs/evaluation/benchmark-hub/robocasa)（有专门的 ABot-M0-Robocasa 任务权重）、[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（有专门的 ABot-M0-RoboTwin2 任务权重）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`abot_m0_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `ABotM0Pipeline`。

系列状态：**仅静态加载**。

按基准选择任务权重（LIBERO、RoboCasa 或 RoboTwin2）。仅支持推理；不包含数据集、训练、部署服务与机器人 SDK 代码。

Qwen3-VL、AML flow 动作专家、可选 VGGT 融合、官方预处理与动作反归一化均已集成在树内。

## 在 WorldFoundry 中运行

用 `wf run abot-m0 --pipeline.task-profile default` 运行策略。

运行环境：独立环境 `worldfoundry-vla-abot-m0`（Python 3.10，Cu128 Recommended，torch>=2.7,\<2.8）。

权重仓库：`acvlab/ABot-M0-LIBERO`、`acvlab/ABot-M0-Robocasa`、`acvlab/ABot-M0-RoboTwin2` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh abot-m0`；下载缺失的公开权重时加 `--download`。
