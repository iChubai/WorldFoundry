ABot-World-0-5B-LF is Amap's interactive world model: give it an image plus actions and it rolls out world video block by block, keeping causal KV state resident between action blocks. Validated with the public 0.5B-LF checkpoint on an A100: one action block at the official 1280×704 resolution produces a decodable nine-frame H.264 clip.

## What it is for

`abot-world-0-5b-lf` is an action-conditioned world model: actions and a starting frame in, a rollout out.

The causal student uses Wan attention, a T5 text encoder, the Wan2.2 VAE, and its scheduler, with optional FP8. WorldFoundry supports causal inference and resident interactive rollout; training and the Gradio demo are not included. The checkpoint is acvlab/ABot-World-0-5B-LF (causal student). It is published by Alibaba (Amap).

Tasks: image-to-world-video, action-conditioned video, and interactive world model. Aliases: `abot-world` and `abot`. Modalities: image in, world state and video out.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (General world-model rollout quality evaluation).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `frames`, `fps`, `seed`, and `num-blocks`; artifacts `generated_world_video` and `abot-world.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `ABotWorldPipeline`.

Family status: **Verified**.

Stage the checkpoint in a local directory before running; the runtime works offline. The resident API keeps causal KV state between action blocks; the first block returns 9 RGB frames and subsequent blocks return 12 — plan client-side buffering accordingly.

## Running in WorldFoundry

Run `wf run abot-world-0-5b-lf --pipeline.task-profile interactive-video` to roll out the world model.

It runs in the dedicated environment `abot-world` (Python 3.12, CUDA 12.9, torch==2.8.0).

Weights: `acvlab/ABot-World-0-5B-LF`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh abot-world-0-5b-lf`. Add `--download` to fetch missing public checkpoints.
