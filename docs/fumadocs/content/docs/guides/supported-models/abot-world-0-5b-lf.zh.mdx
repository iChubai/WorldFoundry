ABot-World-0-5B-LF 是高德的交互式世界模型：输入一张图加动作序列，它逐块滚动生成世界视频，并在动作块之间保持因果 KV 状态常驻。已在 A100 上用公开的 0.5B-LF checkpoint 验证：在官方 1280×704 分辨率下，一个动作块生成可正常解码的九帧 H.264 视频。

## 用来做什么

`abot-world-0-5b-lf` 是动作条件世界模型：输入动作和起始帧，输出推演结果。

该因果学生模型使用 Wan 注意力、T5 文本编码器、Wan2.2 VAE 及其调度器，支持可选 FP8。WorldFoundry 支持因果推理与常驻交互滚动；不包含训练与 Gradio demo。checkpoint 为 acvlab/ABot-World-0-5B-LF（causal student）。该模型由阿里巴巴（高德地图 AMAP-CVLab）发布。

任务：image-to-world-video、动作条件视频、交互式世界模型。别名：`abot-world`、`abot`。模态上，它接受图像，输出世界状态、视频。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（世界模型滚动生成质量的通用评测）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`seed`、`num-blocks`；产物 `generated_world_video`、`abot-world.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `ABotWorldPipeline`。

系列状态：**已验证**。

运行前需把 checkpoint 放到本地目录；运行时离线工作。常驻 API 在动作块之间保持因果 KV 状态；首个块返回 9 帧 RGB，后续块返回 12 帧——客户端缓冲请按此规划。

## 在 WorldFoundry 中运行

运行 `wf run abot-world-0-5b-lf --pipeline.task-profile interactive-video` 推演世界模型。

运行环境：独立环境 `abot-world`（Python 3.12，CUDA 12.9，torch==2.8.0）。

权重仓库：`acvlab/ABot-World-0-5B-LF`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh abot-world-0-5b-lf`；下载缺失的公开权重时加 `--download`。
