AC3D 是 Snap Research 为 CogVideoX 提供的 **ControlNet 风格**相机插件：输入文本、源视频和 **19 列**相机位姿行，输出沿相机轨迹生成的视频片段。WorldFoundry 以 `AC3DPipeline` 运行官方推理代码。别名 `ac3d-cogvideox`、`ac3d-2b`、`ac3d-5b` 解析到这里。

<ModelPaperFigures modelId="ac3d" locale="zh" />

官方论文是 [AC3D: Analyzing and Improving 3D Camera Control in Video Diffusion Transformers](https://arxiv.org/abs/2411.18673)（CVPR 2025，arXiv 2411.18673）。项目页：[snap-research.github.io/ac3d](https://snap-research.github.io/ac3d/)。代码：[snap-research/ac3d](https://github.com/snap-research/ac3d)。许可证：**Snap 非商用研究许可**。

适配器沿用官方 `inference/cli_demo_camera.py` 的相机控制路径；即使同时准备了 5B ControlNet，仍保持官方 **2B ControlNet 形状**设置。

## 用来做什么

沿指定 3D 路径重绘一段视频。优先走 RealEstate10K 风格的 2B ControlNet demo。

启动 `wf run ac3d`。

评测入口：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（直接衡量生成视频中的相机控制精度）。

## 运行时契约

必填 `prompt`、`video`；可选 `image`；`actions`：camera_index、camera_index_range、camera_pose_rows；产物 `ac3d.mp4`。

基座权重：`THUDM/CogVideoX-2b` 与 `THUDM/CogVideoX-5b`。ControlNet 位于 `$WORLDFOUNDRY_CKPT_DIR/ac3d` 下的 `2B/checkpoint-10000.pt` 与 `5B/checkpoint-10000.pt`。其它位姿格式先转成 19 列约定。

## 在 WorldFoundry 中运行

独立环境 `ac3d`（Python 3.10，CUDA 12.4，torch 2.4），与 `worldfoundry-unified-cu128` ABI 不兼容。在本地准备好 CogVideoX 基座和对应的 ControlNet，然后在该环境执行 `wf run ac3d`。许可证：Snap 非商用研究。
