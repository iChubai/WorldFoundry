AC3D 分析并改进视频扩散中的相机控制：它是 ControlNet 风格的插件，为 CogVideoX 提供精确的 3D 相机控制。本 catalog 中 runner 已验证——RealEstate10K 相机控制 demo 通过 Workspace 推理路径运行，使用本地 CogVideoX-2B 与 AC3D ControlNet 权重，并保留官方 inference/cli_demo_camera.py 生成路径。

## 架构

按论文（arXiv 2411.18673），AC3D 发现相机运动信息集中在低频、早期时间步分量，因此仅对部分层做条件注入，同时提升控制精度与画质。catalog 记录 2B 与 5B 两个 ControlNet checkpoint；适配器保留官方 2B ControlNet 形状设置。

## 使用要点

AC3D 保留在专属环境中，因为官方 torch 2.4/CUDA 12.4 栈与统一环境的 ABI 不兼容。输入接受 RealEstate10K 风格的数据根目录，或「源视频 + 19 列相机位姿行」的直接输入。
