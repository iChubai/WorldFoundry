## What it is for

`adaworld` is an action-conditioned world model: actions and a starting frame in, a rollout out.

Per the upstream project, a latent action autoencoder extracts transferable action representations that condition an autoregressive world model. WorldFoundry runs the official FDM inference path in-tree. It is published by The Hong Kong University of Science and Technology / MIT.

Tasks: latent action world model, action-conditioned video, and multi domain world model. Modalities: action in, video out.

## Runtime contract

Required `video`; options `start-index`, `video-len`, `resolution`, `context-frame`, `num-steps`, `cfg-scale`, and 3 more; artifact `adaworld.mp4`.

CLI task profile: `latent-action-world-model`. WorldFoundry binds `AdaWorldPipeline`. Family status: **Verified**. Defaults for `latent-action-world-model`: fps=5, seed=32.

Supply the released adaworld.safetensors checkpoint and a readable source video. The main checkpoint includes the active CLIP and LAM encoder weights; a separate lam.ckpt is not needed for this inference path.

Validation covers a short rollout only (four frames, two sampling steps, synthetic source video); task behavior and long-horizon consistency are not measured.

## Running in WorldFoundry

Step the world with `wf run adaworld --pipeline.task-profile latent-action-world-model`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Little-Podi/AdaWorld`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh adaworld`. Add `--download` to fetch missing public checkpoints.
