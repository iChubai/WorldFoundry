## 用来做什么

`adaworld` 是动作条件世界模型：输入动作和起始帧，输出推演结果。

按上游项目，潜在动作自编码器提取可迁移的动作表示，用于条件化自回归世界模型。WorldFoundry 在仓内运行官方 FDM 推理路径。该模型由香港科技大学 / 麻省理工学院发布。

任务：潜动作世界模型、动作条件视频、多域世界模型。模态上，它接受动作，输出视频。

## 运行时契约

必填 `video`；参数 `start-index`、`video-len`、`resolution`、`context-frame`、`num-steps`、`cfg-scale` 等 9 项；产物 `adaworld.mp4`。

CLI task profile：`latent-action-world-model`。绑定的 pipeline 类是 `AdaWorldPipeline`。系列状态：**已验证**。`latent-action-world-model` 的默认值：fps=5, seed=32。

提供发布的 adaworld.safetensors 权重和可读取的源视频。主权重已包含推理所需的 CLIP 与 LAM 编码器参数，此推理路径不需要单独的 lam.ckpt。

验证只覆盖短时推理（合成源视频、生成 4 帧、采样 2 步）；任务效果和长时一致性尚未测量。

## 在 WorldFoundry 中运行

用 `wf run adaworld --pipeline.task-profile latent-action-world-model` 推进世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`Little-Podi/AdaWorld`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh adaworld`；下载缺失的公开权重时加 `--download`。
