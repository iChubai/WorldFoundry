AHA-WAM 是面向操作的**世界-动作模型**：视频专家和动作专家共享 **mixture cache**，让策略在推理时用上预测式世界建模。WorldFoundry 在进程内跑精确的视频/动作专家、mixture-cache 编辑器、**六帧**历史、两阶段块推理、Wan VAE 和 UMT5 编码器，不包含训练器、模拟器和部署服务。Pipeline：`AHAWAMPipeline`。别名 `aha-wam`、`aha-wam-robotwin` 解析到这里。

官方论文见 [arXiv 2606.09811](https://arxiv.org/abs/2606.09811)。项目页：[serene-sivy.github.io/aha-wam](https://serene-sivy.github.io/aha-wam/)。代码：[Serene-SIVY/AHA-WAM](https://github.com/Serene-SIVY/AHA-WAM)。许可证：**MIT**。策略 checkpoint：`SereneC/AHA-WAM-RoboTwin2.0`（`robotwin_ahawam.pt`）。VAE 与 UMT5 来自 `DiffSynth-Studio/Wan-Series-Converted-Safetensors`。

已在 **A100** 上用发布的 RoboTwin 2.0 checkpoint 验证：输入三个 ALOHA 视角加 **14 维**状态，pipeline 返回有限的 **16×14** 开环动作块。这是开环检查，不是闭环仿真分数。

## 用来做什么

用三个 ALOHA 视角加状态跑 AHA-WAM 的 RoboTwin 动作块。

启动 `wf run ahawam`。

评测入口：[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（发布的 checkpoint 面向 RoboTwin 2.0 训练）。

## 运行时契约

必填 `image`、`prompt`；可选 `model_id`、`state`、`preferred_cameras`、`image_size`、`configured_action_horizon`、`action_chunk_size`、`default_chunks_per_video_prefill`；产物 `action_trace`、`ahawam_action_trace.json`。

| 旋钮 | 记录值 |
| --- | --- |
| 图像尺寸 | **384×320** |
| 动作时域 | **64** |
| 块大小 | **16** |
| 视频 prefill 块数 | **2**（随后刷新 KV；最多保留六条更早的 prefill） |

VAE 与 UMT5 编码器可以放在策略 GPU、CPU 或另一张 GPU 上；自动放置按显存阈值决定。

## 在 WorldFoundry 中运行

统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。先把 `SereneC/AHA-WAM-RoboTwin2.0`、`DiffSynth-Studio/Wan-Series-Converted-Safetensors`、`Wan-AI/Wan2.1-T2V-1.3B` 就位到本地；所有资产从本地加载，严格键匹配。在该环境执行 `wf run ahawam`。
