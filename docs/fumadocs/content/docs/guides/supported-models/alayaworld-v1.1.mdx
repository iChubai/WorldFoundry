## What it is for

`alayaworld-v1.1` conditions video generation on camera poses.

In-tree inference-only rollout methods from the pinned upstream use WorldFoundry checkpoint/LoRA loaders, the LTX VAE, Gemma text encoding and the Alaya history encoder. The Alaya LTX-2.3 transformer is a variant of the canonical LTX stack; ViGeo uses the shared WorldFoundry implementation. It is published by AlayaLab.

Tasks: image-to-video, camera-controlled video, and interactive world model. Aliases: `alayaworld-v11` and `alaya-world-v1.1`. Modalities: image in, video out.

## Runtime contract

Required `input-path`, `load.base-checkpoint`, `load.gemma-path`, and `load.vigeo-checkpoint`; inputs `prompt` and `load.checkpoint-dir` (bundled samples are used when omitted); options `rounds`, `seed`, `execute`, and `timeout-seconds`; artifacts `generated_world` and `alayaworld-v1.1.mp4`.

CLI task profiles: `image-to-video`. WorldFoundry binds `AlayaWorldV11Pipeline`.

Family status: **Runner parity pending**.

Defaults for `image-to-video`: seed=42.

Select variant=ar (30 steps) or dmd (4 steps). Stage2b transformer/history weights, the LTX-2.3 base, Gemma and ViGeo1.1 are required; DMD additionally needs the stage3 LoRA. Gemma is gated and requires accepting its license. This route does not use the merged DA3 checkpoint of the original AlayaWorld.

## Running in WorldFoundry

Run `wf run alayaworld-v1.1 --pipeline.task-profile image-to-video --pipeline.input-path VALUE --pipeline.load.base-checkpoint VALUE --pipeline.load.gemma-path VALUE --pipeline.load.vigeo-checkpoint VALUE` to follow the camera path.

It runs in the dedicated environment `alayaworld-v1.1` (Python 3.11, CUDA 12.8, torch>=2.6).

Weights: `AlayaLab/AlayaWorld-v1.1-stage2b`, `AlayaLab/AlayaWorld-v1.1-stage3`, and `Lightricks/LTX-2.3` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh alayaworld-v1.1`. Add `--download` to fetch missing public checkpoints.

Gated weights: `google/gemma-3-12b-it-qat-q4_0-unquantized` (accept the upstream terms before downloading).
