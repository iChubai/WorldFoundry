AlayaWorld is a camera-controlled interactive world model for long video: from an image it rolls out world video autoregressively with action control and DA3-backed spatial memory. Validated with the released 33.6 GB merged checkpoint: the pipeline generates the official case1 first chunk (32 H.264 frames at 544×960, 24 fps) on an A100 with spatial memory enabled.

## What it is for

Use `alayaworld` when the viewpoint must follow a given camera path.

AlayaWorld extends WorldFoundry's in-tree LTX-2.3 model and reuses its Transformer, VAE, Gemma connector, RoPE, patchifier, attention dispatcher, and distributed helpers; the Alaya-specific weights add action AdaLN and a temporal-history encoder. Spatial memory uses the in-tree Depth Anything 3 model. It is published by AlayaLab.

Tasks: image-to-video, camera-controlled video, interactive world model, and long video generation. Aliases: `alaya-world` and `alaya_world`. Modalities: image in, video out.

Suggested benchmarks: [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-control quality of interactive rollouts), [MemoBench](/docs/evaluation/benchmark-hub/memobench) (Long-horizon spatial-memory consistency evaluation).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `fps`, `height`, `width`, `steps`, and `rounds`; artifacts `generated_world_video` and `alayaworld.mp4`.

CLI task profiles: `default`. WorldFoundry binds `AlayaWorldPipeline`.

Family status: **Verified**.

Attention dispatch is capability-based. Multi-GPU runs use Ulysses context parallelism over WorldFoundry core collectives.

## Running in WorldFoundry

Generate a camera-controlled clip with `wf run alayaworld --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch>=2.6).

Weights: `AlayaLab/AlayaWorld`, `google/gemma-3-12b-it-qat-q4_0-unquantized`, and `depth-anything/DA3NESTED-GIANT-LARGE-1.1`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh alayaworld`. Add `--download` to fetch missing public checkpoints.

Gated weights: `google/gemma-3-12b-it-qat-q4_0-unquantized` (accept the upstream terms before downloading).
