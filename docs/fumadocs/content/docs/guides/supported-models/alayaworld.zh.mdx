AlayaWorld 是面向长视频的相机可控交互式世界模型：以一张图像为起点，结合动作控制与 DA3 空间记忆，自回归滚动生成世界视频。已使用发布的 33.6 GB 合并 checkpoint 验证：pipeline 在 A100 上开启空间记忆，生成官方 case1 的首个 chunk（32 帧 H.264，544×960，24 fps）。

## 用来做什么

视角需要沿指定相机路径运动时，用 `alayaworld`。

AlayaWorld 基于 WorldFoundry 树内的 LTX-2.3 模型扩展，复用其 Transformer、VAE、Gemma 连接器、RoPE、patchifier、注意力分发器与分布式辅助；Alaya 专属权重新增动作 AdaLN 与时间历史编码器。空间记忆使用树内 Depth Anything 3 模型。该模型由 AlayaLab 发布。

任务：图生视频、相机可控视频、交互式世界模型、长视频生成。别名：`alaya-world`、`alaya_world`。模态上，它接受图像，输出视频。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（交互滚动生成的相机控制质量）、[MemoBench](/zh/docs/evaluation/benchmark-hub/memobench)（长时程空间记忆一致性评测）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `fps`、`height`、`width`、`steps`、`rounds`；产物 `generated_world_video`、`alayaworld.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `AlayaWorldPipeline`。

系列状态：**已验证**。

注意力分发按硬件能力选择。多卡运行使用基于 WorldFoundry 核心集合通信的 Ulysses 上下文并行。

## 在 WorldFoundry 中运行

用 `wf run alayaworld --pipeline.task-profile default` 生成相机可控视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch>=2.6）。

权重仓库：`AlayaLab/AlayaWorld`、`google/gemma-3-12b-it-qat-q4_0-unquantized`、`depth-anything/DA3NESTED-GIANT-LARGE-1.1`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh alayaworld`；下载缺失的公开权重时加 `--download`。

gated 权重：`google/gemma-3-12b-it-qat-q4_0-unquantized`（下载前需在上游接受条款）。
