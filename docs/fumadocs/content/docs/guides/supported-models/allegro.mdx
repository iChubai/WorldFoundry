Allegro is an open text-to-video and image-to-video generation model. WorldFoundry runs it through the TI2V (text+image to video) route: a prompt, optionally anchored by a start image, produces a video. The aliases allegro_ti2v and allegro-ti2v resolve to the same model.

## What it is for

Use `allegro` for both text-to-video and image-to-video generation.

Allegro is a diffusion-transformer video generator released by Rhymes AI. The TI2V route conditions generation on a prompt and an optional start image; see the upstream release for architecture details. It is published by Rhymes AI.

Tasks: text-to-video and image-to-video. Aliases: `allegro_ti2v` and `allegro-ti2v`. Modalities: text and image in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Multi-dimension video generation quality suite that fits Allegro's T2V/I2V output).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `fps`; artifacts `allegro-ti2v.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `AllegroTi2VPipeline`.

Family status: **Runner parity pending**.

Stage the Allegro checkpoints locally before launching. The default run generates 88 frames at 1280x720 and 15 fps.

## Running in WorldFoundry

Generate a clip with `wf run allegro --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `rhymes-ai/Allegro` and `rhymes-ai/Allegro-TI2V`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh allegro`. Add `--download` to fetch missing public checkpoints.
