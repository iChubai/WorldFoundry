Allegro 是开源的文生视频/图生视频模型。WorldFoundry 通过其 TI2V（文本+图像生成视频）路径运行它：一条提示词（可选配一张起始图）生成一段视频。别名 allegro_ti2v 与 allegro-ti2v 指向同一模型。

## 用来做什么

用 `allegro` 同时完成文生视频和图生视频。

Allegro 是 Rhymes AI 发布的扩散 Transformer 视频生成模型。TI2V 路径以提示词和可选的起始图为条件生成视频；架构细节请查阅上游发布说明。该模型由Rhymes AI发布。

任务：文生视频、图生视频。别名：`allegro_ti2v`、`allegro-ti2v`。模态上，它接受文本、图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（多维视频生成质量评测，适配 Allegro 的文生/图生视频输出）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `fps`；产物 `allegro-ti2v.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `AllegroTi2VPipeline`。

系列状态：**Runner 一致性待确认**。

启动前请先在本地就位 Allegro checkpoint。默认生成 88 帧、1280x720、15 fps 的视频。

## 在 WorldFoundry 中运行

用 `wf run allegro --pipeline.task-profile interactive-video` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`rhymes-ai/Allegro`、`rhymes-ai/Allegro-TI2V`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh allegro`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
