text → video

AnimateDiff is the classic motion-module approach to text-to-video: it animates existing Stable Diffusion image models by inserting a trained temporal module, rather than training a video model from scratch. In this catalog it is a fully verified route — WorldFoundry's output matched the official RealisticVision scripts.animate demo exactly, down to file SHA256 and decoded pixel SHA256. The entry also answers to the aliases animate-diff and animate_diff.

## Architecture

A legacy U-Net latent diffusion backbone (Stable Diffusion v1.5) plus AnimateDiff's temporal motion module; the recorded checkpoints are guoyww/animatediff, the T2I backup repo, stable-diffusion-v1-5, and the CLIP ViT-L/14 text encoder. The catalog task list labels it explicitly as legacy-unet-diffusion to distinguish it from the newer DiT-based families.

## Usage notes

Runner parity is verified, so this is one of the safest video routes to start with. The Studio/API route runs in the unified environment after the recorded diffusers/transformers checkpoint-key compatibility fixes; per-run validation evidence is tracked outside the model catalog.
