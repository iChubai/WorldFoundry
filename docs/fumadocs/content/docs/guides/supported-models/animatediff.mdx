AnimateDiff is the classic motion-module approach to text-to-video: a temporal module plugs into an existing Stable Diffusion 1.5 U-Net instead of training a video backbone from scratch. WorldFoundry's output matches the official RealisticVision `scripts.animate` demo exactly. Aliases `animate-diff` and `animate_diff` also work.

<ModelPaperFigures modelId="animatediff" locale="en" />

The paper is [AnimateDiff: Animate Your Personalized Text-to-Image Diffusion Models without Specific Tuning](https://arxiv.org/abs/2307.04725). Project page: [animatediff.github.io](https://animatediff.github.io/). Code: [guoyww/AnimateDiff](https://github.com/guoyww/AnimateDiff).

## What it is for

Prompt-only T2V through `AnimateDiffPipeline`: required `prompt`; the output is written as **MP4**. Passing `image` or `video` raises — this integration is not I2V or V2V. The upstream SparseCtrl configs are not supported.

Swap the T2I backbone (Realistic Vision is the verified demo) while keeping the motion module. Compare clip quality and temporal consistency on [VBench](/docs/evaluation/benchmark-hub/vbench).

## Inference

Sampler is **DDIM** (`DDIMScheduler` from `inference-v2.yaml`). WorldFoundry `generate_video` defaults:

| Knob | Default | Notes |
| --- | --- | --- |
| Size | **256×256** | height/width must be divisible by 8 |
| Frames | **16** | `video_length` / `num_frames` |
| Steps | **25** | `infer_steps` |
| Guidance | **7.5** | `cfg_scale` |
| FPS | **8** | written MP4 |
| Seed | **1234** | |

The official RealisticVision prompt YAML uses the same **25** steps but **guidance 8**, and either `mm_sd_v15_v2.ckpt` + `inference-v2.yaml` or `v3_sd15_mm.ckpt` + `inference-v3.yaml`. Default motion module path is `$WORLDFOUNDRY_HFD_ROOT/guoyww--animatediff/mm_sd_v15_v2.ckpt`; Realistic Vision weights come from `guoyww/animatediff_t2i_backups`.

## Running in WorldFoundry

`wf run animatediff` in `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Official modules call `.cuda()` — CPU is rejected. Stage `guoyww/animatediff`, `guoyww/animatediff_t2i_backups`, `stable-diffusion-v1-5/stable-diffusion-v1-5`, and `openai/clip-vit-large-patch14`. The motion module is licensed **Apache-2.0**. Studio/API uses the same unified environment.
