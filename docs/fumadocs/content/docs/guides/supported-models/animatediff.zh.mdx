AnimateDiff 是经典的运动模块式文生视频模型：在现成的 Stable Diffusion 1.5 U-Net 上插入时序模块，而不是从头训练视频骨干。WorldFoundry 的输出与官方 RealisticVision `scripts.animate` demo 完全一致。也可使用别名 `animate-diff`、`animate_diff`。

论文是 [AnimateDiff: Animate Your Personalized Text-to-Image Diffusion Models without Specific Tuning](https://arxiv.org/abs/2307.04725)。项目页：[animatediff.github.io](https://animatediff.github.io/)。代码：[guoyww/AnimateDiff](https://github.com/guoyww/AnimateDiff)。

## 用来做什么

这是只接受 prompt 的文生视频路径，使用 `AnimateDiffPipeline`：必填 `prompt`；输出为 **MP4**。传入 `image` 或 `video` 会报错——本集成不是图生视频，也不是视频到视频。不支持上游的 SparseCtrl 配置。

可以换 T2I 基座（已验证 demo 用的是 Realistic Vision），运动模块保持不变。画质与时序一致性可对照 [VBench](/zh/docs/evaluation/benchmark-hub/vbench)。

## 推理

采样器是 **DDIM**（`inference-v2.yaml` 里的 `DDIMScheduler`）。WorldFoundry `generate_video` 默认值：

| 旋钮 | 默认 | 说明 |
| --- | --- | --- |
| 分辨率 | **256×256** | 高宽须能被 8 整除 |
| 帧数 | **16** | `video_length` / `num_frames` |
| 步数 | **25** | `infer_steps` |
| Guidance | **7.5** | `cfg_scale` |
| FPS | **8** | 写出的 MP4 |
| Seed | **1234** | |

官方 RealisticVision prompt YAML 同样是 **25** 步，但 **guidance 8**，并在 `mm_sd_v15_v2.ckpt` + `inference-v2.yaml` 或 `v3_sd15_mm.ckpt` + `inference-v3.yaml` 之间二选一。默认运动模块路径是 `$WORLDFOUNDRY_HFD_ROOT/guoyww--animatediff/mm_sd_v15_v2.ckpt`；Realistic Vision 权重来自 `guoyww/animatediff_t2i_backups`。

## 在 WorldFoundry 中运行

在 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）中运行 `wf run animatediff`。官方模块会调用 `.cuda()`，因此不支持 CPU。请准备好 `guoyww/animatediff`、`guoyww/animatediff_t2i_backups`、`stable-diffusion-v1-5/stable-diffusion-v1-5` 和 `openai/clip-vit-large-patch14`。运动模块许可是 **Apache-2.0**。Studio/API 走同一套统一环境。
