AnimateDiff 是经典的「运动模块」式文生视频方法：通过在现成的 Stable Diffusion 图像模型中插入训练好的时序模块来让静态模型动起来，而不是从头训练视频模型。在本 catalog 中它是完整验证过的路径—— WorldFoundry 的输出与官方 RealisticVision scripts.animate demo 完全一致，文件 SHA256 与逐帧解码像素 SHA256 均精确匹配。条目同时响应别名 animate-diff、animate_diff。

## 架构

基座为旧式 U-Net 潜空间扩散模型（Stable Diffusion v1.5），叠加 AnimateDiff 的时序运动模块；记录的 checkpoint 包括 guoyww/animatediff、T2I 备份仓库、stable-diffusion-v1-5 与 CLIP ViT-L/14 文本编码器。 catalog 任务标签中特意标注 legacy-unet-diffusion，与较新的 DiT 系列相区分。

## 使用要点

Runner parity 已验证，是入门视频生成最稳妥的路径之一。Studio/API 路径在统一环境中运行（已包含记录在案的 diffusers/transformers checkpoint 键兼容性修复）；每次运行的验证证据在 catalog 之外单独跟踪。
