Astra is an **interactive world model** on a Wan2.1 backbone: one image plus camera actions roll out navigable world video. WorldFoundry exposes it as `AstraPipeline`. Studio defaults mirror the official Wan2.1-backed **Sekai** image rollout.

<ModelPaperFigures modelId="astra" locale="en" />

The official paper is [Astra: General Interactive World Model with Autoregressive Denoising](https://arxiv.org/abs/2512.08931) (ICLR 2026, arXiv 2512.08931). Project: [eternalevan.github.io/Astra-project](https://eternalevan.github.io/Astra-project/). Code: [EternalEvan/Astra](https://github.com/EternalEvan/Astra). Weights: `EvanEternal/Astra` (mirror `KwaiVGI/Astra`) plus `Wan-AI/Wan2.1-T2V-1.3B`. Recorded license on those bases: **apache-2.0**.

Validated with the released checkpoints: the official **garden_1** Sekai demo with `forward_left` camera control produces **97 frames at 832×480, 20 fps**.

## What it is for

Use Astra to explore a scene from a single image: camera actions steer a rollout of navigable world video.

Launch `wf run astra` with `--pipeline.task-profile official-sekai-image`.

Score on [CameraBench](/docs/evaluation/benchmark-hub/camerabench) — camera-following accuracy of interactive rollouts.

## Runtime contract

Required: `prompt` and `image`; optional: `video`; `actions`: camera_direction; artifacts: `astra.mp4`.

| Knob | Verified demo |

| Camera | `forward_left` on garden_1 |

## Running in WorldFoundry

Status: **Verified**.

Runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `EvanEternal/Astra` and `Wan-AI/Wan2.1-T2V-1.3B` locally, then run `wf run astra --pipeline.task-profile official-sekai-image`.
