[Astra: General Interactive World Model with Autoregressive Denoising](https://arxiv.org/abs/2512.08931) (ICLR 2026, 2025)

Astra 是基于 Wan2.1 基座、带相机控制的交互式世界模型：从单张图出发，跟随相机动作滚动生成可导航的世界视频。本 catalog 中它已验证——官方 garden_1 Sekai demo 通过树内 Studio/API 路径运行，使用 forward_left 相机控制，输出 832x480、20 fps 的 97 帧。
