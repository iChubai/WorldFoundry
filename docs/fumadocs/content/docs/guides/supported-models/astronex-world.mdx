## What it is for

`astronex-world` conditions video generation on camera poses.

Wan2.2 TI2V-5B with PRoPE camera conditioning, 64-dimensional actions and embodiment conditioning. WorldFoundry calls the official sampler from an external source checkout. It is published by Astronex-Robotics.

Tasks: text-to-video, image-to-video, camera-controlled video, and interactive world model. Aliases: `astronex`. Modalities: text and image in, video out.

## Runtime contract

Inputs `prompt`, `input-path`, and `load.checkpoint-dir` (bundled samples are used when omitted); options `fps`, `seed`, `execute`, and `timeout-seconds`; artifacts `generated_world` and `astronex-world.mp4`.

CLI task profiles: `interactive-world-model`. WorldFoundry binds `AstronexWorldPipeline`.

Family status: **Runner parity pending**.

Defaults for `interactive-world-model`: fps=24, seed=0.

Select mode=causal or bidirectional; supply source_root and checkpoint_dir. execute=True runs inference. latent_frames counts generated latent frames, not video frames; causal blocks require (latent_frames + reference_count) % 8 == 0.

## Running in WorldFoundry

Run `wf run astronex-world --pipeline.task-profile interactive-world-model` to follow the camera path.

Weights: `Astronex-Lab/Astronex-World`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh astronex-world`. Add `--download` to fetch missing public checkpoints.
