## 用来做什么

`astronex-world` 以相机位姿为条件生成视频。

基于 Wan2.2 TI2V-5B，加入 PRoPE 相机条件、64 维动作和 embodiment 条件。WorldFoundry 调用外部源码检出中的官方采样器。该模型由 Astronex-Robotics 发布。

任务：文生视频、图生视频、相机可控视频、交互式世界模型。别名：`astronex`。模态上，它接受文本、图像，输出视频。

## 运行时契约

输入 `prompt`、`input-path`、`load.checkpoint-dir`（不传时使用内置示例）；参数 `fps`、`seed`、`execute`、`timeout-seconds`；产物 `generated_world`、`astronex-world.mp4`。

CLI task profile：`interactive-world-model`。绑定的 pipeline 类是 `AstronexWorldPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-world-model` 的默认值：fps=24, seed=0。

选择 mode=causal 或 bidirectional，并提供 source_root 和 checkpoint_dir。execute=True 执行推理。latent_frames 为生成的潜帧数，而非视频帧数；因果模式要求 (latent_frames + reference_count) 能被 8 整除。

## 在 WorldFoundry 中运行

运行 `wf run astronex-world --pipeline.task-profile interactive-world-model` 沿相机路径生成视频。

运行环境：独立环境 `astronex-world`（Python 3.11，CUDA 12.8，torch>=2.6）。

权重仓库：`Astronex-Lab/Astronex-World`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh astronex-world`；下载缺失的公开权重时加 `--download`。
