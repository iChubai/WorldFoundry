ATI (Any Trajectory Instruction) turns trajectory drawing into video control: draw point trajectories over an input image and the Wan2.1-14B-based model animates objects, camera, or both along them. In this catalog only ATI's official inference delta is vendored — the unchanged Wan2.1 implementation is reused from worldfoundry/base_models.

## Architecture

Per the upstream release, ATI injects dense point-track conditioning into the Wan2.1 I2V backbone through a trajectory instruction module. Runtime checkpoint loading builds a read-only union of ATI weights (bytedance-research/ATI) and locally staged Wan2.1 I2V 480P base components.

## Usage notes

In-tree import and camera-track compilation are verified; full GPU artifact parity requires staged weights. No source checkout or runtime download is permitted — only locally staged checkpoints are resolved. Input schema is prompt, image, and dense point tracks.
