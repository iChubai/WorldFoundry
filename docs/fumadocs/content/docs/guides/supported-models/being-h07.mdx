Being-H0.7 is the successor in BeingBeyond's Being-H family: a latent world-action model (WAM) plus robot policy that maps an image, a prompt, and robot state to an action trace. WorldFoundry runs it through an in-tree port of the official policy runtime from the Being-H07 subdirectory of the official repository.

## What it is for

Start on `being-h07`. Launch `wf run being-h07 --pipeline.task-profile vla`. Need a GPU-validated BeingBeyond route? Use [Being-H0.5](/docs/guides/supported-models/being-h05) instead.

## Runtime contract

Required `image`, `prompt`, and `state`. Artifacts: `action_trace`, `being-h07_action_trace.json`.

## Running in WorldFoundry

Unified `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `BeingBeyond/Being-H07` when released; until then a run returns a runtime plan instead of actions. License terms are not documented; check the upstream repository before use.
