Being-H0.7 是 BeingBeyond Being-H 家族的后继模型：隐式世界-动作模型（WAM）加机器人策略，从图像、提示与机器人状态生成动作轨迹。WorldFoundry 通过树内移植的官方策略运行时运行它，源码来自官方仓库的 Being-H07 子目录。

## 用来做什么

从 `being-h07` 开始。启动 `wf run being-h07 --pipeline.task-profile vla`。如果需要经过 GPU 验证的 BeingBeyond 路径，请改用 [Being-H0.5](/zh/docs/guides/supported-models/being-h05)。

## 运行时契约

必填 `image`、`prompt`、`state`。产物：`action_trace`、`being-h07_action_trace.json`。

## 在 WorldFoundry 中运行

统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。待 `BeingBeyond/Being-H07` 权重发布后再准备；在此之前运行只返回运行时计划，不输出动作。许可证条款未注明，使用前请查看上游仓库。
