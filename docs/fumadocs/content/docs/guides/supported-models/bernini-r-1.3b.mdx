Bernini-R 1.3B is the small renderer-only member of ByteDance's Bernini family — a 1.3B rendering checkpoint fine-tuned from Wan2.1 1.3B, covering the same six task types as its larger siblings. It is the practical single-GPU way to try the Bernini task surface. WorldFoundry vendors the renderer inference in-tree and loads ByteDance/Bernini-R-1.3B-Diffusers.

## What it is for

`bernini-r-1.3b` covers both image and video generation and editing tasks.

A renderer-only 1.3B checkpoint fine-tuned from the Wan2.1 1.3B diffusion-transformer backbone; the 7B planner stage of the full Bernini design is not included.

Tasks: text-to-image, image-to-image, text-to-video, and video-to-video. Aliases: `bernini-r-1p3b` and `bernini-r-1.3b-diffusers`. Modalities: text, image, and video in, image and video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Quick quality yardstick for the small renderer).

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `task-type`, `num-frames`, `height`, `width`, `num-inference-steps`, `seed`, and 4 more; artifacts `generated_image`, `generated_video`, and `bernini-r-1.3b.mp4`.

CLI task profiles: `t2v`, `t2i`, `i2i`, `v2v`, `r2v`, and `rv2v`. WorldFoundry binds `BerniniWorldFoundryPipeline`.

Family status: **Runner parity pending**.

The small footprint makes this the recommended first stop in the Bernini family. Select tasks via task_type; the checkpoint is apache-2.0 and must be staged locally.

Official renderer inference is vendored in-tree; no external Bernini checkout is used.

## Running in WorldFoundry

Run `wf run bernini-r-1.3b --pipeline.task-profile t2v` for the default task. Switch tasks in the command builder above to change `--pipeline.task-profile`.

It runs in the dedicated environment `worldfoundry-bernini-cu124` (Python 3.11, CUDA 12.4, torch==2.5.1+cu124).

Weights: `ByteDance/Bernini-R-1.3B-Diffusers`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh bernini-r-1.3b`. Add `--download` to fetch missing public checkpoints.
