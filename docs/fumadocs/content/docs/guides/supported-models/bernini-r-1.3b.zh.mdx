Bernini-R 1.3B 是字节 Bernini 系列中的小型「仅渲染器」成员——由 Wan2.1 1.3B 微调而来的 1.3B 渲染 checkpoint，覆盖与大模型相同的六类任务。它是单卡体验 Bernini 任务面的实用选择。WorldFoundry 树内内置渲染器推理代码，加载 ByteDance/Bernini-R-1.3B-Diffusers。

<ModelPaperFigures modelId="bernini-r-1.3b" locale="zh" />

论文：[Bernini: Latent Semantic Planning for Video Diffusion](https://arxiv.org/abs/2605.22344)（2026）。

项目页：[bernini-ai.github.io](https://bernini-ai.github.io/)。代码：[bytedance/Bernini](https://github.com/bytedance/Bernini)。

完整规划+渲染流程请用 [Bernini](/zh/docs/guides/supported-models/bernini)；更大的渲染器请用 [Bernini-R 14B](/zh/docs/guides/supported-models/bernini-r-14b)。

权重：`ByteDance/Bernini-R-1.3B-Diffusers`（**apache-2.0**）。

## 用来做什么

`bernini-r-1.3b` 同时覆盖图像与视频的生成和编辑任务。

由 Wan2.1 1.3B 扩散 Transformer 基座微调而来的 1.3B 纯渲染 checkpoint；不包含完整 Bernini 设计中的 7B 规划阶段。

任务：文生图、图像编辑、文生视频、视频到视频。别名：`bernini-r-1p3b`、`bernini-r-1.3b-diffusers`。模态上，它接受文本、图像、视频，输出图像、视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（小渲染器的快速质量标尺）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `task-type`、`num-frames`、`height`、`width`、`num-inference-steps`、`seed` 等 10 项；产物 `generated_image`、`generated_video`、`bernini-r-1.3b.mp4`。

CLI task profile：`t2v`、`t2i`、`i2i`、`v2v`、`r2v`、`rv2v`。绑定的 pipeline 类是 `BerniniWorldFoundryPipeline`。

系列状态：**Runner 一致性待确认**。

小体量使它成为 Bernini 系列的推荐起点。通过 task_type 选择任务；checkpoint 为 apache-2.0，需在本地就位。

1.3B 容量使保真度低于 14B 渲染器与完整规划+渲染流程。

## 在 WorldFoundry 中运行

运行 `wf run bernini-r-1.3b --pipeline.task-profile t2v` 执行默认任务。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：独立环境 `worldfoundry-bernini-cu124`（Python 3.11，CUDA 12.4，torch==2.5.1+cu124）。

记录的权重仓库包括 `ByteDance/Bernini-R-1.3B-Diffusers`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh bernini-r-1.3b`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
