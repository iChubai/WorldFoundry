Bernini-R 14B is the renderer-only release of ByteDance's Bernini family: the 14B rendering model packaged without the 7B semantic planner. It keeps the same six-task surface (text-to-image, image editing, text/video/reference-to-video) but takes your inputs directly instead of planning first. WorldFoundry loads the ByteDance/Bernini-R-Diffusers checkpoint.

Project page: [bernini-ai.github.io](https://bernini-ai.github.io/). Code: [bytedance/Bernini](https://github.com/bytedance/Bernini).

This is **not** planner+renderer [Bernini](/docs/guides/supported-models/bernini) and **not** the single-GPU [Bernini-R 1.3B](/docs/guides/supported-models/bernini-r-1.3b).

Weights: `ByteDance/Bernini-R-Diffusers` (**apache-2.0**). Image recipes run on **one GPU**; video recipes can turn on explicit Ulysses sequence parallelism.

## What it is for

`bernini-r-14b` covers both image and video generation and editing tasks.

A single 14B rendering network from the Bernini two-stage design, run standalone. Image recipes fit on one GPU, while video recipes can use explicit Ulysses sequence parallelism for speed.

Tasks: text-to-image, image-to-image, text-to-video, and video-to-video. Aliases: `bernini-r` and `bernini-r-diffusers`. Modalities: text, image, and video in, image and video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Checks the renderer's raw T2V quality).

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `task-type`, `num-frames`, `height`, `width`, `num-inference-steps`, `seed`, and 4 more; artifacts `generated_image`, `generated_video`, and `bernini-r-14b.mp4`.

CLI task profiles: `t2v`, `t2i`, `i2i`, `v2v`, `r2v`, and `rv2v`. WorldFoundry binds `BerniniWorldFoundryPipeline`.

Family status: **Runner parity pending**.

Use task_type to select the task; stage the Bernini-R-Diffusers checkpoint (apache-2.0) locally first. For quick experiments prefer the 1.3B sibling; for the planner+renderer pipeline use the flagship bernini model.

## Running in WorldFoundry

Run the default task with `wf run bernini-r-14b --pipeline.task-profile t2v`. Switch tasks in the command builder above to change `--pipeline.task-profile`.

It runs in the dedicated environment `worldfoundry-bernini-cu124` (Python 3.11, CUDA 12.4, torch==2.5.1+cu124).

Recorded weight repository: `ByteDance/Bernini-R-Diffusers`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh bernini-r-14b`. Add `--download` to fetch missing public checkpoints.
