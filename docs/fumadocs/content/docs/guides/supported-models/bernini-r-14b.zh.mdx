Bernini-R 14B 是字节 Bernini 系列的「仅渲染器」发布：14B 渲染模型单独打包，不含 7B 语义规划器。它保留同样的六类任务（文生图、图像编辑、文/视频/参考生视频），但直接使用你的输入，不经过规划阶段。WorldFoundry 加载 ByteDance/Bernini-R-Diffusers checkpoint。

<ModelPaperFigures modelId="bernini-r-14b" locale="zh" />

论文：[Bernini: Latent Semantic Planning for Video Diffusion](https://arxiv.org/abs/2605.22344)（2026）。

项目页：[bernini-ai.github.io](https://bernini-ai.github.io/)。代码：[bytedance/Bernini](https://github.com/bytedance/Bernini)。

这不是规划+渲染的 [Bernini](/zh/docs/guides/supported-models/bernini)，也不是单卡的 [Bernini-R 1.3B](/zh/docs/guides/supported-models/bernini-r-1.3b)。

权重：`ByteDance/Bernini-R-Diffusers`（**Apache-2.0**）。图像配方**单卡**可跑；视频配方可以打开显式 Ulysses 序列并行。

## 用来做什么

`bernini-r-14b` 同时覆盖图像与视频的生成和编辑任务。

即 Bernini 两段式设计中的 14B 渲染网络，单独运行。图像配方可在单卡上运行，视频配方可显式启用 Ulysses 序列并行加速。

任务：文生图、图像编辑、文生视频、视频到视频。别名：`bernini-r`、`bernini-r-diffusers`。模态上，它接受文本、图像、视频，输出图像、视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（检验渲染器本身的文生视频质量）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `task-type`、`num-frames`、`height`、`width`、`num-inference-steps`、`seed` 等 10 项；产物 `generated_image`、`generated_video`、`bernini-r-14b.mp4`。

CLI task profile：`t2v`、`t2i`、`i2i`、`v2v`、`r2v`、`rv2v`。绑定的 pipeline 类是 `BerniniWorldFoundryPipeline`。

系列状态：**Runner 一致性待确认**。

通过 task_type 选择任务；先在本地准备好 Bernini-R-Diffusers checkpoint（apache-2.0）。快速实验建议使用 1.3B 版本；需要规划器与渲染器完整流程时，请使用旗舰 bernini 模型。

## 在 WorldFoundry 中运行

用 `wf run bernini-r-14b --pipeline.task-profile t2v` 运行默认任务。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：独立环境 `worldfoundry-bernini-cu124`（Python 3.11，CUDA 12.4，torch==2.5.1+cu124）。

记录的权重仓库：`ByteDance/Bernini-R-Diffusers`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh bernini-r-14b`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
