Bernini is ByteDance's unified any-to-any visual generation model: one checkpoint covers text-to-image, image editing, text-to-video, video-to-video, and reference-guided video. The full ByteDance/Bernini-Diffusers checkpoint pairs a 7B semantic planner with a 14B renderer. WorldFoundry ships the official inference source and loads the self-contained Diffusers checkpoint directly, so no external Bernini checkout is needed.

## What it is for

`bernini` is a multi-task model for image and video generation and editing.

Two-stage design: a 7B semantic planner produces an intermediate plan and a 14B renderer synthesizes the final pixels. Official recipes run single-request inference with 8-way Ulysses sequence parallelism (nproc_per_node=8, ulysses_size=8). The task_type input selects among the six task families at request time.

Tasks: text-to-image, image-to-image, text-to-video, and video-to-video. Aliases: `bernini-diffusers` and `bernini-7b-14b`. Modalities: text, image, and video in, image and video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Covers the T2V half of Bernini's unified task space), [T2V-CompBench](/docs/evaluation/benchmark-hub/t2v-compbench) (Compositional prompts stress the semantic-planner stage).

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `task-type`, `num-frames`, `height`, `width`, `num-inference-steps`, `seed`, and 4 more; artifacts `generated_image`, `generated_video`, and `bernini.mp4`.

CLI task profiles: `t2v`, `t2i`, `i2i`, `v2v`, `r2v`, and `rv2v`. WorldFoundry binds `BerniniWorldFoundryPipeline`.

Family status: **Runner parity pending**.

`t2i` defaults: num_frames=1, height=512, width=512, num_inference_steps=50, seed=42, fps=16. `i2i` defaults: num_frames=1, height=512, width=512, num_inference_steps=40, seed=42, fps=16.

The official dispatch needs one 8-GPU node with H100-class GPUs. If you do not have an 8-GPU node, use the renderer-only Bernini-R models instead — the 1.3B one runs on a single GPU.

## Running in WorldFoundry

Run `wf run bernini --pipeline.task-profile t2v` for the default task. Switch tasks in the command builder above to change `--pipeline.task-profile`.

It runs in the dedicated environment `worldfoundry-bernini-cu124` (Python 3.11, CUDA 12.4, torch==2.5.1+cu124).

The weight repository is `ByteDance/Bernini-Diffusers`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh bernini`. Add `--download` to fetch missing public checkpoints.
