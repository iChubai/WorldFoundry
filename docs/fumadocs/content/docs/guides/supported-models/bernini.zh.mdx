Bernini 是字节跳动的统一「任意到任意」视觉生成模型：一个 checkpoint 同时覆盖文生图、图像编辑、文生视频、视频到视频与参考引导视频。完整的 ByteDance/Bernini-Diffusers checkpoint 内含 7B 语义规划器与 14B 渲染器。WorldFoundry 自带官方推理源码，直接加载自包含的 Diffusers checkpoint，无需外部 Bernini 检出。

## 用来做什么

`bernini` 是面向图像与视频生成、编辑的多任务模型。

两段式设计：7B 语义规划器先产出中间规划，14B 渲染器再合成最终像素。官方配方使用单请求 8 路 Ulysses 序列并行推理（nproc_per_node=8、ulysses_size=8）。每次请求通过 task_type 输入选择六类任务之一。

任务：文生图、图像编辑、文生视频、视频到视频。别名：`bernini-diffusers`、`bernini-7b-14b`。模态上，它接受文本、图像、视频，输出图像、视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（覆盖 Bernini 统一任务空间中的文生视频部分）、[T2V-CompBench](/zh/docs/evaluation/benchmark-hub/t2v-compbench)（组合式提示词可检验语义规划阶段的能力）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `task-type`、`num-frames`、`height`、`width`、`num-inference-steps`、`seed` 等 10 项；产物 `generated_image`、`generated_video`、`bernini.mp4`。

CLI task profile：`t2v`、`t2i`、`i2i`、`v2v`、`r2v`、`rv2v`。绑定的 pipeline 类是 `BerniniWorldFoundryPipeline`。

系列状态：**Runner 一致性待确认**。

`t2i` 默认值：num_frames=1, height=512, width=512, num_inference_steps=50, seed=42, fps=16；`i2i` 默认值：num_frames=1, height=512, width=512, num_inference_steps=40, seed=42, fps=16。

官方调度需要一台 8 卡 H100 级 GPU 节点。如果没有 8 卡节点，请改用仅渲染器的 Bernini-R 模型——其中 1.3B 版单卡可跑。

## 在 WorldFoundry 中运行

运行 `wf run bernini --pipeline.task-profile t2v` 执行默认任务。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：独立环境 `worldfoundry-bernini-cu124`（Python 3.11，CUDA 12.4，torch==2.5.1+cu124）。

权重仓库为 `ByteDance/Bernini-Diffusers`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh bernini`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
