CameraCtrl 开创了文生视频扩散的即插即用相机控制：基于 Plücker 嵌入训练相机编码器，让轨迹无需重训基座即可操控生成。WorldFoundry 按官方轨迹文生视频 demo 在树内运行：输入文本提示词与相机轨迹文件，输出视频。

## 用来做什么

视角需要沿指定相机路径运动时，用 `cameractrl`。

按论文（arXiv 2404.02101），相机位姿编码为 Plücker 嵌入，通过可训练的相机编码器注入冻结的视频扩散基座（官方版基于 AnimateDiff）。该模型由香港中文大学 / 上海人工智能实验室发布。

任务：世界模型、video、相机控制。输出模态为视频。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机轨迹贴合度的标准评测）。

## 运行时契约

输入 `prompt`、`trajectory-file`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`guidance-scale` 等 9 项；产物 `cameractrl.mp4`。

CLI task profile：`trajectory-video`。绑定的 pipeline 类是 `CameraCtrlPipeline`。

系列状态：**已验证**。

`trajectory-video` 的默认值：frames=16, fps=8, height=256, width=384, guidance_scale=14.0, seed=42。

runner 遵循官方 demo 轨迹契约——提供相机轨迹文件与文本提示词即可。

## 在 WorldFoundry 中运行

用 `wf run cameractrl --pipeline.task-profile trajectory-video` 生成相机可控视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 11.3）。

权重仓库：`hehao13/CameraCtrl`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh cameractrl`；下载缺失的公开权重时加 `--download`。
