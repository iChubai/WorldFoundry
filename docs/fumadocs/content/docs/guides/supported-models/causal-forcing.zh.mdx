## 架构

按论文（arXiv 2602.02214），基于 Wan2.1 的教师被蒸馏为 chunk-wise 或 frame-wise 注意力的因果学生；++ variant 进一步压缩到 1-2 步采样。记录的 checkpoint 包括 chunk-wise，以及 zhuhz22/Causal-Forcing 下的 frame-wise 与两个 ++ 少步 variant。

## 使用要点

适配器执行内置的官方 inference.py 路径；完整一致性需要本地 Wan2.1 权重与所选 Causal-Forcing checkpoint/config 配对。benchmark 提示词列表需自行准备，并通过本地输入配置提供。
