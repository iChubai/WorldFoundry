In this catalog the official Apache-2.0 causal inference stack is vendored in-tree; execution waits on the public DiT, Wan2.1 VAE, and umT5 checkpoints being staged locally.

## Architecture

Per the paper (arXiv 2510.08431), rCM combines score-regularized consistency distillation for few-step sampling. The vendored stack drops the upstream imaginaire framework — WorldFoundry's own lazy_config, easy_io, and logging back it — and the block-causal mask predicates were lifted into worldfoundry/core/attention/block_pattern.py, verified against upstream across 702 mask and 162 chunk-schedule configurations.

## Usage notes

first_chunk_t and chunk_t select the schedule: c1-1 frame-wise gives the lowest streaming latency, c3-3 more throughput. Distilled 4-step sampling is the default; distilled=False samples the multi-step teacher with CFG. context_from_last_step=True saves one clean forward per chunk but requires a checkpoint trained for noisy context. The released entrypoint is prompt/image conditioned with no discrete action space.
