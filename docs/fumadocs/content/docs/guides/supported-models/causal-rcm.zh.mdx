## 架构

按论文（arXiv 2510.08431），rCM 结合分数正则化的一致性蒸馏实现少步采样。内置栈去掉了上游 imaginaire 框架——由 WorldFoundry 自有的 lazy_config、easy_io 与日志支撑——块因果掩码谓词提取到 worldfoundry/core/attention/block_pattern.py，并在 702 种掩码与 162 种 chunk 调度配置下对照上游验证。

## 使用要点

first_chunk_t 与 chunk_t 选择调度：c1-1 逐帧模式流式延迟最低，c3-3 吞吐更高。默认使用蒸馏的 4 步采样；distilled=False 则以 CFG 采样多步教师。context_from_last_step=True 每 chunk 省一次干净前向，但要求 checkpoint 针对带噪上下文训练。发布的入口为提示词/图像条件，无离散动作空间。
