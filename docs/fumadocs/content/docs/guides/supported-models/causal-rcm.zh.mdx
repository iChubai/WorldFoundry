Causal-rCM 把英伟达的 rCM 一致性蒸馏应用于因果视频生成：以潜帧 chunk 为单位进行自回归流式生成，结合蒸馏少步采样，可作为低延迟交互式世界模型的候选。WorldFoundry 运行官方 Apache-2.0 因果推理栈。

论文：[Large Scale Diffusion Distillation via Score-Regularized Continuous-Time Consistency](https://arxiv.org/abs/2510.08431)（ICLR 2026, 2025）。

项目页：[research.nvidia.com/labs/dir/rcm](https://research.nvidia.com/labs/dir/rcm)。代码：[NVlabs/rcm](https://github.com/NVlabs/rcm)。

因果后续论文：[arXiv 2606.25473](https://arxiv.org/abs/2606.25473)。社区 DiT：`worstcoder/rcm-Wan`（复现）。VAE / umT5：`worstcoder/Wan`。教师引用：`Wan-AI/Wan2.1-T2V-1.3B` 与 `14B`。Causal-rCM 与 Causal Forcing（`causal-forcing`）是不同的模型。

运行前请就位公开的 DiT、Wan2.1 VAE 和 umT5 checkpoint；缺少时 pipeline 返回阻塞诊断，不会写出 MP4。

## 用来做什么

用 `causal-rcm` 以动作推进世界并渲染出相应画面。

按论文（arXiv 2510.08431），rCM 在连续时间一致性蒸馏中加入分数正则化，实现少步采样。因果版本在块因果注意力掩码下逐 chunk 去噪潜帧；其掩码与 chunk 调度与上游一致。该模型由英伟达（NVIDIA）发布。

任务：autoregressive-video-generation、streaming-video-generation、交互式世界模型、文生视频。别名：`rcm`、`causal_rcm`、`rcm-causal`、`causal-rcm-wan2.1`。模态上，它接受文本、图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（流式文/图生视频的质量评测）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`steps`、`seed`、`plan-only`、`timeout-seconds`、`model-size` 等 12 项；产物 `generated_world`、`generated_video`、`causal-rcm.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `CausalRCMPipeline`。

系列状态：**Runner 一致性待确认**。

first_chunk_t 与 chunk_t 用于选择调度：c1-1 逐帧模式流式延迟最低，c3-3 吞吐更高。默认使用蒸馏的 4 步采样；distilled=False 则以 CFG 采样多步教师。context_from_last_step=True 每个 chunk 省去一次干净前向，但要求 checkpoint 针对带噪上下文训练。发布的入口以提示词或图像为条件，不提供离散动作空间。

## 在 WorldFoundry 中运行

用 `wf run causal-rcm --pipeline.task-profile default` 推进世界。

运行环境：独立环境 `causal-rcm`（Python 3.12，CUDA 12.6，torch==2.11.0）。

权重仓库：`worstcoder/rcm-Wan`、`worstcoder/Wan`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh causal-rcm`；下载缺失的公开权重时加 `--download`。
