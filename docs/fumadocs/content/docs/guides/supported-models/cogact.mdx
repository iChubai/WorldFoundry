CogACT from Microsoft is a componentized VLA: a Prismatic-style Llama-2 VLM handles cognition while a dedicated DiT action module handles control, released in Small/Base/Large variants under MIT. WorldFoundry runs CogACT in-tree with a strict local checkpoint mapper; checkpoint-backed inference is validated and needs no upstream checkout.

Paper: [arXiv 2411.19650](https://arxiv.org/abs/2411.19650).

Project page: [cogact.github.io/CogACT_paper.pdf](https://cogact.github.io/CogACT_paper.pdf). Code: [microsoft/CogACT](https://github.com/microsoft/CogACT).

Weights: `CogACT/CogACT-Small`, `CogACT/CogACT-Base`, `CogACT/CogACT-Large`. All VLM and DiT weights load from the CogACT checkpoint; only the Llama tokenizer can fall back to an installed OpenVLA copy.

## What it is for

Use `cogact-base` to predict robot actions from observations and a language instruction.

Cognition and action are separated: the VLM encodes image+instruction, then a DiT (diffusion transformer) action model predicts a 16x7 action chunk. The official demo contract is load_vla(...).predict_action(image, prompt, unnorm_key, cfg_scale, use_ddim, num_ddim_steps).

Tasks: VLA, VLA action prediction, and VLA policy rollout. Aliases: `cogact-base`, `cogact-small`, and `cogact-large`.

Suggested benchmarks: [SimplerEnv](/docs/evaluation/benchmark-hub/simpler-env) (Official normalization targets SimplerEnv setups).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `checkpoint-ref` and `official-policy-observation`; artifacts `action_trace` and `cogact_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `CogACTPipeline`.

Family status: **Runner parity pending**.

Default SimplerEnv setups use bridge_orig or fractal20220817_data normalization keys. The inference-only loader reuses an installed OpenVLA Llama tokenizer when a gated Llama 2 mirror is unavailable. FSDP training, RLDS loaders, the deployment server, and SimplerEnv adapters are not included.

Llama-2 tokenizer dependency may require a gated mirror or OpenVLA fallback.

## Running in WorldFoundry

Run `wf run cogact-base --pipeline.task-profile default` to predict actions.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch>=2.7.0).

Weights: `CogACT/CogACT-Base`, `meta-llama/Llama-2-7b-hf`, and `CogACT/CogACT-Small` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh cogact-base`. Add `--download` to fetch missing public checkpoints.

License: MIT; gated weights: `meta-llama/Llama-2-7b-hf` (accept the upstream terms before downloading).
