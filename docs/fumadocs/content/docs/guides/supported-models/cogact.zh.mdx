微软的 CogACT 是组件化 VLA：Prismatic 式 Llama-2 VLM 负责认知，专用 DiT 动作模块负责控制，按 Small/Base/Large 三档发布，MIT 许可。WorldFoundry 在树内运行 CogACT，并用严格的本地 checkpoint 映射器加载权重；checkpoint 驱动的推理已验证，无需上游 checkout。

论文：[arXiv 2411.19650](https://arxiv.org/abs/2411.19650)。

项目页：[cogact.github.io/CogACT_paper.pdf](https://cogact.github.io/CogACT_paper.pdf)。代码：[microsoft/CogACT](https://github.com/microsoft/CogACT)。

权重：`CogACT/CogACT-Small`、`CogACT/CogACT-Base`、`CogACT/CogACT-Large`。VLM 与 DiT 权重全部从 CogACT checkpoint 加载；只有 Llama tokenizer 可回退到已安装的 OpenVLA 版本。

## 用来做什么

用 `cogact-base` 根据观测和语言指令预测机器人动作。

认知与动作分离：VLM 编码图像+指令，DiT（扩散 transformer）动作模型预测 16x7 动作块。官方 demo 契约为 load_vla(...).predict_action(image, prompt, unnorm_key, cfg_scale, use_ddim, num_ddim_steps)。该模型由微软（Microsoft）发布。

任务：视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行。别名：`cogact-base`、`cogact-small`、`cogact-large`。

推荐评测：[SimplerEnv](/zh/docs/evaluation/benchmark-hub/simpler-env)（官方归一化面向 SimplerEnv 配置）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `checkpoint-ref`、`official-policy-observation`；产物 `action_trace`、`cogact_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `CogACTPipeline`。

系列状态：**Runner 一致性待确认**。

默认 SimplerEnv 配置使用 bridge_orig 或 fractal20220817_data 归一化键。当门控的 Llama 2 镜像不可用时，推理加载器复用已安装的 OpenVLA Llama tokenizer。不包含 FSDP 训练、RLDS 加载器、部署服务与 SimplerEnv 适配器。

Llama-2 tokenizer 依赖可能需要门控镜像或 OpenVLA 回退。

## 在 WorldFoundry 中运行

运行 `wf run cogact-base --pipeline.task-profile default` 预测动作。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch>=2.7.0）。

权重仓库：`CogACT/CogACT-Base`、`meta-llama/Llama-2-7b-hf`、`CogACT/CogACT-Small` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh cogact-base`；下载缺失的公开权重时加 `--download`。

许可证：MIT；gated 权重：`meta-llama/Llama-2-7b-hf`（下载前需在上游接受条款）。
