**发表机构:** 微软（Microsoft） · 企业

微软的 CogACT 是组件化 VLA：Prismatic 式 Llama-2 VLM 负责认知，专用 DiT 动作模块负责控制，按 Small/Base/Large 三档发布，MIT 许可。WorldFoundry 拥有独立的树内 synthesis 入口与严格本地 checkpoint 映射器；checkpoint 驱动的 Workspace 推理无需外部 checkout 即可通过。

## 架构

认知与动作分离：VLM 编码图像+指令，DiT（扩散 transformer）动作模型预测 16x7 动作块。官方 demo 契约为 load_vla(...).predict_action(image, prompt, unnorm_key, cfg_scale, use_ddim, num_ddim_steps)。

## 使用要点

默认 SimplerEnv 配置使用 bridge_orig 或 fractal20220817_data 归一化键。当门控的 Llama 2 镜像不可用时，推理加载器复用已安装的 OpenVLA Llama tokenizer。FSDP 训练、RLDS 加载器、部署服务与 SimplerEnv 适配器均被排除。
