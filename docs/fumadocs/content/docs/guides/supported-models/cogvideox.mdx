## Architecture

CogVideoX uses a diffusion transformer over a 3D causal VAE latent space with an expert transformer conditioning design (per the upstream publication). In this repository, the recorded contract exposes num_inference_steps, num_frames, height, width, and fps on T2V, plus guidance_scale on I2V.

## Usage notes

Pick the variant by size and task: 2B T2V for fast iterations, 5B T2V for quality, 5B I2V for animating an image. Runner parity is verified; per-run visual QA is tracked outside the catalog. Note the recorded license nuance: HF metadata reports Apache-2.0 for 2B but 'other' for several larger variants — review before commercial use.
