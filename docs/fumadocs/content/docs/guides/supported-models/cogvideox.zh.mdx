CogVideoX 是智谱 AI 的开源视频生成系列，也是使用最广的开源文生/图生视频基线之一。本条目提供三个可运行 variant——2B 文生视频、5B 文生视频、5B 图生视频——均通过树内运行时执行，且 runner parity 已验证。权重可从 Hugging Face 原生加载（THUDM/CogVideoX-5b），也可用 model_path 指向本地镜像。

## 架构

CogVideoX 采用 3D 因果 VAE 潜空间上的扩散 Transformer，并使用专家 Transformer 条件设计（见上游论文）。在本仓库中，记录的契约为：T2V 暴露 num_inference_steps、num_frames、height、width、fps， I2V 额外暴露 guidance_scale。

## 使用要点

按大小与任务选 variant：2B T2V 适合快速迭代，5B T2V 追求质量，5B I2V 用于让图片动起来。 runner parity 已验证；每次运行的视觉 QA 在 catalog 之外跟踪。注意记录在案的许可细节：HF 元数据中 2B 为 Apache-2.0，若干更大 variant 为“other”——商用前请先审阅。
