## Architecture

Predict 2.5 unifies text/image/video-to-world generation in one flow-based model with a Reason1 language conditioner and shared Wan VAE. Image/video conditioning and positive classifier-free guidance are expressed through shared runner contracts rather than a model-specific runtime.

## Usage notes

The public CosmosPredict2p5Pipeline invokes the native recipes directly. The 2B text-to-world route is verified at 1280x704 for 93 frames and 35 steps; the 14B route still requires end-to-end GPU output validation. NVIDIA checkpoint access remains gated.
