Cosmos Predict 2.5 是英伟达面向物理 AI 的世界基础模型：输入文本、图像或视频，输出世界视频，含 2B 与 14B 两个 variant。本 catalog 中它由 WorldFoundry 规范的去噪器、条件器、调度器、解码器与加载器角色原生组装、不依赖 Diffusers；官方 EMA transformer 结构 2B 匹配 569/569、14B 匹配 729/729 张量， Reason1 语言权重匹配 338/338，共享 Wan VAE 匹配 194/194。

## 架构

Predict 2.5 用单一流模型统一文/图/视频到世界生成，配 Reason1 语言条件器与共享 Wan VAE。图像/视频条件与正向 CFG 通过共享 runner 契约表达，而非模型专属运行时。

## 使用要点

公开的 CosmosPredict2p5Pipeline 直接调用原生配方。2B 文生世界路径已按 1280x704、93 帧、35 步完成验证；14B 路径仍需端到端 GPU 输出验证。NVIDIA checkpoint 访问仍受许可控制。
