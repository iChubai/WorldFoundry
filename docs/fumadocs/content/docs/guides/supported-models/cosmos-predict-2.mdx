Cosmos Predict 2 is NVIDIA's **previous-generation** world foundation model for **image/video-to-world**. Text plus a first frame or video prefix go in; a future world video comes out. Newer Cosmos releases are [Predict 2.5](/docs/guides/supported-models/cosmos-predict-2.5), [Transfer 2.5](/docs/guides/supported-models/cosmos-transfer-2.5), and [Cosmos 3](/docs/guides/supported-models/cosmos3).

WorldFoundry assembles it **natively** — framework-owned denoiser, **T5-11B** conditioner, Rectified Flow **AB2** scheduler, Wan codec, shared loader. **No Diffusers pipeline** and no NVIDIA runtime package. Recipe defaults are **1280×704, 93 frames, 16 fps, 35 steps**. Variants are only `cosmos-predict2-2b-video2world` and `cosmos-predict2-14b-video2world`. Aliases `cosmos-predict2` and `cosmos2` resolve here.

The official Predict 2 project is [research.nvidia.com/labs/dir/cosmos-predict2](https://research.nvidia.com/labs/dir/cosmos-predict2/). The linked paper is the 2025 [Cosmos World Foundation Model Platform](https://arxiv.org/abs/2501.03575) report, which describes the Predict 1-era platform that Predict 2 builds on.

Validated without weights: the native 2B and 14B architectures match the official checkpoint layouts, and conditioning masks and AB2 scheduler numerics are correct. Generated output has not been checked on GPU; the official Video2World weights are **gated** (`nvidia-open-model-license`).

## What it is for

Use this version only when you need the **T5-conditioned v2** recipe. New world-video work should start on [Predict 2.5](/docs/guides/supported-models/cosmos-predict-2.5): Reason1 conditioner, flow-UniPC, and a **verified 2B text-to-world** route at the same 1280×704 / 93-frame / 35-step geometry.

Launch `wf run cosmos-predict2-2b-video2world`. Required inputs: `prompt`, `image`, `video`. Artifact: `cosmos-predict2-2b-video2world.mp4` (14B writes `cosmos-predict2-14b-video2world.mp4`). For control-video / VACE conditioning use Transfer 2.5; for joint sound or a policy head use Cosmos 3.

Score predicted world video on [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) and [Physics-IQ](/docs/evaluation/benchmark-hub/physics-iq).

## Running in WorldFoundry

`CosmosPredict2Pipeline` runs in `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `nvidia/Cosmos-Predict2-2B-Video2World` or the 14B twin, plus `google-t5/t5-11b`, after accepting NVIDIA's gated terms.
