Cosmos Predict 2 is the previous generation of NVIDIA's world foundation model, covering image-to-video and video-to-world generation with 2B and 14B video2world variants. In this catalog it is assembled from the framework-owned denoiser, T5 conditioner, Rectified Flow AB2 scheduler, Wan codec, and standard runner — no NVIDIA runtime package or Diffusers pipeline is invoked.

## Architecture

Predict2 and Predict2.5 share one checkpoint-shaped transformer implementation in WorldFoundry; only version-specific architecture and sampling values live in recipes. The native 2B architecture contains 567 checkpoint-owned tensors with no synthetic cross-attention projection.

## Usage notes

Registry, component contracts, architecture construction, conditioning masks, and AB2 scheduler numerics are validated locally; gated checkpoint access and GPU parity are separate steps. Prefer cosmos-predict-2.5 for new work unless you need the T5-conditioned v2 recipe.
