Cosmos Predict 2 是英伟达世界基础模型的上一代，覆盖图生视频与视频到世界生成，含 2B 与 14B 两个 video2world variant。本 catalog 中它由框架自有的去噪器、T5 条件器、Rectified Flow AB2 调度器、 Wan 编解码器与标准 runner 组装——不调用英伟达运行时包或 Diffusers pipeline。

## 架构

在 WorldFoundry 中，Predict2 与 Predict2.5 共享同一按 checkpoint 形状实现的 transformer；只有版本差异的架构与采样值放在配方里。原生 2B 架构含 567 个 checkpoint 张量，无合成的交叉注意力投影。

## 使用要点

注册表、组件契约、架构构建、条件掩码与 AB2 调度器数值已本地验证；gated checkpoint 权限与 GPU 一致性是独立步骤。除非需要 T5 条件的 v2 配方，新工作建议优先使用 cosmos-predict-2.5。
