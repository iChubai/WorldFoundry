Cosmos Transfer 2.5 is the **sim-to-real / world-to-world** arm of the Cosmos 2.5 generation. A **control video** (raw RGB, edge map, or simulation render) plus a prompt go in; a photoreal world video that **follows that control** comes out. Transfer **translates** an already-structured control signal; to synthesize future world video from text, image, or video, use [Predict 2](/docs/guides/supported-models/cosmos-predict-2), [Predict 2.5](/docs/guides/supported-models/cosmos-predict-2.5), or [Cosmos 3](/docs/guides/supported-models/cosmos3).

<ModelPaperFigures modelId="cosmos-transfer-2.5" locale="en" />

It reuses Predict 2.5's **native** stack — Reason1 conditioner, flow-UniPC, shared Wan VAE, same loader — and adds only the checkpoint-shaped **VACE** control branch (four blocks at base layers 0/7/14/21, plus an 8-modality control embedder on the 28-layer base). Paper: [World Simulation with Video Foundation Models for Physical AI](https://arxiv.org/abs/2511.00062) (the same 2.5 write-up that covers Predict 2.5). Code: [nvidia-cosmos/cosmos-transfer2.5](https://github.com/nvidia-cosmos/cosmos-transfer2.5).

WorldFoundry provides one variant, **`cosmos-transfer-2.5-2b`**. Validated with the released 2B **edge** checkpoint: the pipeline generates a 93-frame **1280×704** controlled video in **35** denoising steps. The 14B Hugging Face checkpoint (`nvidia/Cosmos-Transfer2.5-14B`) is access-gated and has no WorldFoundry route. Weights use the gated `nvidia-open-model-license`.

## What it is for

Turn structured control into photoreal world video. Launch `wf run cosmos-transfer-2.5-2b`. Required inputs: `prompt`, `image`, `video`. The `actions` field is **`control_video`**. Artifact: `cosmos-transfer2.5-2b-controlled-video.mp4`.

Give the native route a **raw RGB** control clip and it extracts **Canny** edges itself. Set `control_is_preprocessed` only when the clip is already an edge map. This is not text-to-world (Predict 2.5) and not T5-conditioned video2world (Predict 2).

Score controlled world video on [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) and [Physics-IQ](/docs/evaluation/benchmark-hub/physics-iq).

## Running in WorldFoundry

`CosmosTransfer2p5Pipeline` runs in `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage the official 2B **edge** checkpoint `nvidia/Cosmos-Transfer2.5-2B` **and** the Predict 2.5 VAE plus Reason1 text encoder.
