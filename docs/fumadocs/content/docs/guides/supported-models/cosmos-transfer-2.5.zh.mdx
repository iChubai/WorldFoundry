Cosmos Transfer 2.5 是 Cosmos 2.5 世代的 **sim-to-real / 世界到世界** 分支。**控制视频**（原始 RGB、边缘图或仿真渲染）加上 prompt 进，生成**跟随该控制**的写实世界视频。Transfer 把已经结构化的控制信号**转译**为世界视频；要从文本、图像或视频合成未来世界视频，请用 [Predict 2](/zh/docs/guides/supported-models/cosmos-predict-2)、[Predict 2.5](/zh/docs/guides/supported-models/cosmos-predict-2.5) 或 [Cosmos 3](/zh/docs/guides/supported-models/cosmos3)。

<ModelPaperFigures modelId="cosmos-transfer-2.5" locale="zh" />

它复用 Predict 2.5 的**原生**栈——Reason1 条件器、flow-UniPC、共享 Wan VAE、同一加载器——只多了按 checkpoint 形状实现的 **VACE** 控制分支（基座第 0/7/14/21 层四块，外加 28 层基座上的 8 模态控制嵌入器）。论文：[World Simulation with Video Foundation Models for Physical AI](https://arxiv.org/abs/2511.00062)（与 Predict 2.5 同一篇 2.5 文）。代码：[nvidia-cosmos/cosmos-transfer2.5](https://github.com/nvidia-cosmos/cosmos-transfer2.5)。

WorldFoundry 提供一个 variant：**`cosmos-transfer-2.5-2b`**。已用发布的 2B **边缘** checkpoint 验证：pipeline 以 **35** 步去噪生成 93 帧、**1280×704** 的受控视频。Hugging Face 上的 14B checkpoint（`nvidia/Cosmos-Transfer2.5-14B`）需申请访问，WorldFoundry 未提供对应路径。权重采用 gated 的 `nvidia-open-model-license`。

## 用来做什么

把结构化控制译成照片级世界视频。启动 `wf run cosmos-transfer-2.5-2b`。必填输入：`prompt`、`image`、`video`。`actions` 字段是 **`control_video`**。产物：`cosmos-transfer2.5-2b-controlled-video.mp4`。

给原生路径一段**原始 RGB** 控制片段，它会自己抽 **Canny** 边缘。只有在片段已经是边缘图时才设 `control_is_preprocessed`。这不是文生世界（Predict 2.5），也不是 T5 条件的 video2world（Predict 2）。

受控世界视频可在 [WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench) 与 [Physics-IQ](/zh/docs/evaluation/benchmark-hub/physics-iq) 上评测。

## 在 WorldFoundry 中运行

`CosmosTransfer2p5Pipeline` 跑在 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。就位官方 2B **边缘** checkpoint `nvidia/Cosmos-Transfer2.5-2B`，以及 Predict 2.5 的 VAE 与 Reason1 文本编码器。
