Ctrl-World is a controllable generative world model for robot manipulation: conditioned on robot actions, it predicts future observation video so policies can be evaluated or improved inside the model. Validated with the released checkpoint: a five-frame synthetic-three-view run at the released 25-step sampler default keeps scene detail in all three views.

Code: [Robert-gyj/Ctrl-World](https://github.com/Robert-gyj/Ctrl-World).

Weights: `yjguo/Ctrl-World` plus `stabilityai/stable-video-diffusion-img2vid` and `openai/clip-vit-base-patch32`. Publisher: Tsinghua / Stanford. No license is specified.

The pipeline runs the released checkpoint with local SVD and CLIP components. Default inputs are synchronized **ALOHA** high / left-wrist / right-wrist demonstration images — the runtime does **not** synthesize cameras. Physically meaningful action conditioning needs checkpoint-matched **DROID** views and the initial seven-value DROID Cartesian pose.

## What it is for

`ctrl-world` generates future frames conditioned on actions.

Ctrl-World builds on a Stable Video Diffusion image-to-video backbone (stabilityai/stable-video-diffusion-img2vid) with CLIP conditioning (openai/clip-vit-base-patch32) and adds its own action-conditioning weights (yjguo/Ctrl-World). It is published by Tsinghua University / Stanford University.

Tasks: interactive world model, game world model, and action-conditioned video. Aliases: `ctrl_world` and `ctrlworld`.

Suggested benchmarks: [WorldArena](/docs/evaluation/benchmark-hub/worldarena) (Ctrl-World is listed on WorldArena for robot world-model evaluation).

## Runtime contract

Inputs `input-path`, `prompt`, `load.checkpoint-path`, `load.base-model-dir`, `load.clip-model-dir`, and `input-views` (bundled samples are used when omitted); options `input-mode`, `action-mode`, `action-direction`, `action-distance`, `action-scale`, `height`, and 10 more; artifacts `ctrl-world.mp4`.

CLI task profiles: `robot-action-video`. WorldFoundry binds `CtrlWorldPipeline`.

`robot-action-video` defaults: height=192, width=320, num_frames=5, num_inference_steps=4, guidance_scale=1.0, fps=4. The 4-step default is a smoke setting; use the released 25-step sampler (`--pipeline.num-inference-steps 25`) for quality runs.

Stage all three checkpoint sets before submitting jobs.

## Running in WorldFoundry

Step the world with `wf run ctrl-world --pipeline.task-profile robot-action-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `yjguo/Ctrl-World`, `stabilityai/stable-video-diffusion-img2vid`, and `openai/clip-vit-base-patch32`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh ctrl-world`. Add `--download` to fetch missing public checkpoints.
