**发表机构:** 清华大学 / 斯坦福大学 · 高校

Ctrl-World 是面向机器人操作的可控生成式世界模型：以机器人动作为条件预测未来观测视频，使策略可以在模型内被评估或改进。本 catalog 中其官方（WorldArena 收录的）源码已内置树内；执行待 Ctrl-World、Stable Video Diffusion 与 CLIP checkpoint 及任务资产就位。
