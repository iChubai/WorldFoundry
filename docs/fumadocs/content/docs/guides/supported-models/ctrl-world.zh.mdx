Ctrl-World 是面向机器人操作的可控生成式世界模型：以机器人动作为条件预测未来观测视频，使策略可以在模型内被评估或改进。已用发布权重验证：按官方默认 25 步采样的五帧合成三视角推理在三个视角中都保留了场景细节。

代码：[Robert-gyj/Ctrl-World](https://github.com/Robert-gyj/Ctrl-World)。

权重：`yjguo/Ctrl-World`，外加 `stabilityai/stable-video-diffusion-img2vid` 和 `openai/clip-vit-base-patch32`。发布方：清华 / 斯坦福。未标明许可证。

pipeline 使用本地 SVD 和 CLIP 组件运行发布的 checkpoint。默认输入是同步的 **ALOHA** 高位 / 左腕 / 右腕演示图像——运行时**不会**合成相机。要得到有物理意义的动作条件，需要与 checkpoint 匹配的 **DROID** 视角以及初始的七维 DROID 笛卡尔位姿。

## 用来做什么

`ctrl-world` 以动作为条件生成未来帧。

Ctrl-World 以 Stable Video Diffusion 图生视频模型（stabilityai/stable-video-diffusion-img2vid）为基座，使用 CLIP 条件（openai/clip-vit-base-patch32），并加入自有的动作条件权重（yjguo/Ctrl-World）。该模型由清华大学 / 斯坦福大学发布。

任务：交互式世界模型、游戏世界模型、动作条件视频。别名：`ctrl_world`、`ctrlworld`。

推荐评测：[WorldArena](/zh/docs/evaluation/benchmark-hub/worldarena)（Ctrl-World 已收录于 WorldArena 的机器人世界模型评测）。

## 运行时契约

输入 `input-path`、`prompt`、`load.checkpoint-path`、`load.base-model-dir`、`load.clip-model-dir`、`input-views`（不传时使用内置示例）；参数 `input-mode`、`action-mode`、`action-direction`、`action-distance`、`action-scale`、`height` 等 16 项；产物 `ctrl-world.mp4`。

CLI task profile：`robot-action-video`。绑定的 pipeline 类是 `CtrlWorldPipeline`。

`robot-action-video` 默认值：height=192, width=320, num_frames=5, num_inference_steps=25, guidance_scale=1.0, fps=4。

提交任务前请准备好全部三套 checkpoint。

## 在 WorldFoundry 中运行

用 `wf run ctrl-world --pipeline.task-profile robot-action-video` 推进世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`yjguo/Ctrl-World`、`stabilityai/stable-video-diffusion-img2vid`、`openai/clip-vit-base-patch32`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh ctrl-world`；下载缺失的公开权重时加 `--download`。
