CUT3R is a continuous 3D perception model with persistent state: it ingests a stream of images and continuously updates a metric-scale 3D reconstruction, without offline bundling. WorldFoundry provides an in-tree point-cloud export route and a two-stage 3DGS route, both available in Studio. CUT3R also serves as the geometry backbone for VMem.

## What it is for

`cut3r` estimates scene geometry from the input views.

A recurrent transformer maintains a persistent scene state; each new frame updates the state and outputs pointmaps and camera parameters online (per the upstream publication). WorldFoundry exposes raw point-cloud export and a two-stage 3DGS pipeline; weights are apache-2.0. It is published by UC Berkeley.

Tasks: 3D reconstruction, 3dgs, and point cloud. Output modalities: point cloud.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `size`, `vis-threshold`, and `revisit`.

CLI task profiles: `official-export` and `two-stage-3dgs`. WorldFoundry binds `CUT3RPipeline`.

Family status: **Runner parity pending**.

Defaults for `official-export`: size=512 Defaults for `two-stage-3dgs`: size=512, width=704, height=480.

Stage the `liguang0115/cut3r` weights locally or from Hugging Face before submitting Studio jobs.

## Running in WorldFoundry

Run `wf run cut3r --pipeline.task-profile official-export` to write the geometry. Switch tasks in the command builder above to change `--pipeline.task-profile`.

No runtime environment is recorded for this model.

Weights: `liguang0115/cut3r`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh cut3r`. Add `--download` to fetch missing public checkpoints.
