CUT3R 是带持久状态的连续 3D 感知模型：接收图像流并持续更新米制尺度的 3D 重建，无需离线捆绑优化。WorldFoundry 提供树内点云导出与两段式 3DGS 两条路径，均可在 Studio 中使用。CUT3R 同时是 VMem 的几何主干。

## 用来做什么

`cut3r` 根据输入视图估计场景几何。

循环 Transformer 维护持久场景状态；每帧新图像更新状态并在线输出点图与相机参数（见上游论文）。WorldFoundry 提供点云导出与两段式 3DGS pipeline；权重为 apache-2.0。该模型由加州大学伯克利分校（UC Berkeley）发布。

任务：3D 重建、3dgs、点云。输出模态为点云。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `size`、`vis-threshold`、`revisit`。

CLI task profile：`official-export`、`two-stage-3dgs`。绑定的 pipeline 类是 `CUT3RPipeline`。

系列状态：**Runner 一致性待确认**。

`official-export` 的默认值：size=512；`two-stage-3dgs` 的默认值：size=512, width=704, height=480。

提交 Studio 任务前，先在本地或从 Hugging Face 就位 `liguang0115/cut3r` 权重。

## 在 WorldFoundry 中运行

运行 `wf run cut3r --pipeline.task-profile official-export` 写出几何结果。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

该模型未记录运行环境。

权重仓库：`liguang0115/cut3r`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh cut3r`；下载缺失的公开权重时加 `--download`。
