Depth Any Panoramas (DAP) is Insta360's metric depth estimator for panoramic images — full 360° depth from a single equirectangular input. WorldFoundry runs it as a geometry prior with the Insta360-Research/DAP-weights checkpoint.

<ModelPaperFigures modelId="dap" locale="en" />

Paper: [arXiv 2512.16913](https://arxiv.org/abs/2512.16913).

Project page: [insta360-research-team.github.io/DAP_website](https://insta360-research-team.github.io/DAP_website/). Code: [Insta360-Research-Team/DAP](https://github.com/Insta360-Research-Team/DAP).

The backbone is **DINOv3-Large** with a DPT-style decoder. A dense metric depth head is paired with a plug-and-play **range-mask** head that marks pixels beyond a confident distance (the cards discuss thresholds such as 10 / 20 / 50 / 100 m). Zero-shot numbers in the paper are reported on Stanford2D3D, Matterport3D, and Deep360 — upstream, not a WorldFoundry scorecard.

## What it is for

`dap` estimates depth: images in, depth maps out.

A Depth-Anything-family model adapted to panoramic inputs and metric output: a DINOv3-Large backbone with a DPT-style decoder, a dense metric depth head, and a range-mask head for pixels beyond a confident distance. It is published by Insta360 (Research Team).

Tasks: panoramic depth estimation, metric depth estimation, and geometry prior. Aliases: `depth-any-panoramas` and `insta360-dap`. Modalities: image in, depth out.

Feed one equirectangular `image`, get `dap-depth.npz`. For ordinary pinhole photos use the Depth Anything V2/V3 priors instead.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `input-size`, `execute`, and `max-points`; artifacts `dap-depth.npz`.

CLI task profiles: `default`. WorldFoundry binds `DAPPipeline`.

Family status: **Verified**.

Feed one equirectangular image; the pipeline writes metric depth to dap-depth.npz. ViPE uses DAP as a shared geometry prior. Runner parity passed through the shared geometry-prior pipeline.

Panoramic-specific: for ordinary pinhole images use the Depth Anything V2/V3 priors instead.

## Running in WorldFoundry

Run `wf run dap --pipeline.task-profile default` to write the depth maps.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Insta360-Research/DAP-weights`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh dap`. Add `--download` to fetch missing public checkpoints.
