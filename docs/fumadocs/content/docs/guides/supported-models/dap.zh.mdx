Depth Any Panoramas（DAP）是影石 Insta360 面向全景图像的米制深度估计器，从单张等距柱状投影图得到完整 360° 深度。WorldFoundry 将它作为几何先验运行，使用 Insta360-Research/DAP-weights checkpoint。

<ModelPaperFigures modelId="dap" locale="zh" />

论文：[arXiv 2512.16913](https://arxiv.org/abs/2512.16913)。

项目页：[insta360-research-team.github.io/DAP_website](https://insta360-research-team.github.io/DAP_website/)。代码：[Insta360-Research-Team/DAP](https://github.com/Insta360-Research-Team/DAP)。

骨干是 **DINOv3-Large**，解码器是 DPT 风格。稠密米制深度头配一个即插即用的 **range-mask** 头，用来标出超出可信距离的像素（上游模型卡讨论 10 / 20 / 50 / 100 m 等阈值）。论文报告了在 Stanford2D3D、Matterport3D 与 Deep360 上的零样本结果；这些是上游数据，不是 WorldFoundry scorecard。

## 用来做什么

`dap` 估计深度：输入图像，输出深度图。

基于 Depth-Anything 系模型，适配全景输入与米制输出：DINOv3-Large 骨干配 DPT 风格解码器，带稠密米制深度头，以及标出超出可信距离像素的 range-mask 头。该模型由影石 Insta360（研究团队）发布。

任务：panoramic-depth-estimation、米制深度估计、几何先验。别名：`depth-any-panoramas`、`insta360-dap`。模态上，它接受图像，输出深度。

输入一张等距柱状投影 `image`，得到 `dap-depth.npz`。普通针孔照片请改用 Depth Anything V2/V3 先验。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `input-size`、`execute`、`max-points`；产物 `dap-depth.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `DAPPipeline`。

系列状态：**已验证**。

输入一张等距柱状投影图，pipeline 将米制深度写入 dap-depth.npz。ViPE 将 DAP 作为共享几何先验使用。已通过共享 geometry-prior pipeline 验证 runner parity。

专为全景设计：普通针孔图像请改用 Depth Anything V2/V3 先验。

## 在 WorldFoundry 中运行

运行 `wf run dap --pipeline.task-profile default` 写出深度图。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`Insta360-Research/DAP-weights`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh dap`；下载缺失的公开权重时加 `--download`。
