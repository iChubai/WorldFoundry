Depth Anything V1 is the foundation model for relative monocular depth that popularized large-scale unlabeled-data depth training. ## Architecture

A DINOv2 ViT backbone with a DPT-style depth head, trained on ~62M unlabeled images with a teacher-student scheme (per the publication). This entry serves relative depth; its metric siblings are the separate *-prior entries.

## Usage notes

A verified, dependable prior — good default for relative depth. For metric depth choose depth-anything-v2-prior or depth-anything-v3-prior instead.
