Depth Anything V1 is the foundation model for relative monocular depth that popularized large-scale unlabeled-data depth training. The in-tree pipeline exports relative depth and geometry artifacts; the Studio route is validated to produce a nonblank depth map.

## What it is for

`depth-anything-v1` estimates depth: images in, depth maps out.

It is published by TikTok / The University of Hong Kong.

Tasks: depth, geometry, and monocular depth estimation. Modalities: image in, depth out.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); artifacts `depth-anything-v1.png`.

CLI task profiles: `default`. WorldFoundry binds `DepthAnything1Pipeline`.

Family status: **Verified**.

A good default for relative depth. For metric depth choose depth-anything-v2-prior or depth-anything-v3-prior instead.

Relative depth only — no metric scale on this route.

## Running in WorldFoundry

Estimate depth with `wf run depth-anything-v1 --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `LiheYoung/depth-anything-large-hf`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh depth-anything-v1`. Add `--download` to fetch missing public checkpoints.
