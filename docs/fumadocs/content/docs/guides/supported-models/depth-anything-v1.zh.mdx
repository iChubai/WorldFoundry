Depth Anything V1 是让「大规模无标注数据训练深度」流行起来的相对单目深度基础模型。树内 pipeline 导出相对深度与几何产物；Studio 路径已验证可产出非空深度图。

## 用来做什么

`depth-anything-v1` 估计深度：输入图像，输出深度图。

DINOv2 ViT 主干加 DPT 式深度头，用约 6200 万张无标注图像以师生方案训练（见论文）。它输出相对深度；米制深度由独立的 *-prior 模型提供。该模型由 TikTok / 香港大学发布。

任务：深度估计、几何估计、单目深度估计。模态上，它接受图像，输出深度。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；产物 `depth-anything-v1.png`。

CLI task profile：`default`。绑定的 pipeline 类是 `DepthAnything1Pipeline`。

系列状态：**已验证**。

相对深度的默认选择。需要米制深度时请改用 depth-anything-v2-prior 或 depth-anything-v3-prior。

仅相对深度——该路径没有米制尺度。

## 在 WorldFoundry 中运行

用 `wf run depth-anything-v1 --pipeline.task-profile default` 估计深度。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`LiheYoung/depth-anything-large-hf`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh depth-anything-v1`；下载缺失的公开权重时加 `--download`。
