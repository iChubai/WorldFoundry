## What it is for

`depth-anything-v2-prior` is a depth estimation model.

Same DINOv2+DPT family as V1 but trained on precise synthetic labels with pseudo-labeled real images, improving edges and thin structures (per the publication). It is published by TikTok / The University of Hong Kong.

Tasks: monocular depth estimation, metric depth estimation, and geometry prior. Aliases: `dav2-prior` and `depth-anything-v2`. Modalities: image in, depth out.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `model`, `execute`, and `max-points`; artifacts `depth-anything-v2-prior.npz`.

CLI task profiles: `default`. WorldFoundry binds `DepthAnythingV2PriorPipeline`.

Family status: **Verified**.

Pass one image as input_path; the run writes the depth prediction to depth-anything-v2-prior.npz. Higher-level geometry pipelines such as ViPE use the same prior.

Metric accuracy varies by domain; indoor/outdoor calibration differs.

## Running in WorldFoundry

Estimate depth with `wf run depth-anything-v2-prior --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `depth-anything/Depth-Anything-V2-Large`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh depth-anything-v2-prior`. Add `--download` to fetch missing public checkpoints.
