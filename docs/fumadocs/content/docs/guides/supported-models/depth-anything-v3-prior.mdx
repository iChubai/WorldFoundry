Depth Anything 3 Metric Prior is the metric-depth head of ByteDance Seed's Depth Anything 3, packaged as a standalone geometry prior. It uses the depth-anything/DA3METRIC-LARGE checkpoint, and the Prior-Depth-Anything refiner is validated on its output.

## What it is for

`depth-anything-v3-prior` estimates depth: images in, depth maps out.

DA3 scales the Depth Anything recipe and adds metric and geometry heads. This prior runs only the metric-large checkpoint. It is published by ByteDance (Seed).

Tasks: monocular depth estimation, metric depth estimation, and geometry prior. Aliases: `dav3-prior` and `da3metric-large-prior`. Modalities: image in, depth out.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `focal-length`, `execute`, and `max-points`; artifacts `depth-anything-v3-prior.npz`.

CLI task profiles: `default`. WorldFoundry binds `DepthAnythingV3PriorPipeline`.

Family status: **Verified**.

Use it as a metric-depth prior for other pipelines, such as ViPE, through the shared geometry-prior interface. For the official SOH export route, use depth-anything-v3.

Depth prior only: full DA3 reconstruction is provided by depth-anything-v3.

## Running in WorldFoundry

Run `wf run depth-anything-v3-prior --pipeline.task-profile default` to write the depth maps.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `depth-anything/DA3METRIC-LARGE`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh depth-anything-v3-prior`. Add `--download` to fetch missing public checkpoints.
