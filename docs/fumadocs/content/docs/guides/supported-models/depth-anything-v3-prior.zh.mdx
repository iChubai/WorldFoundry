Depth Anything 3 Metric Prior 是字节 Seed 团队 Depth Anything 3 的米制深度头，以独立几何先验的形式提供。它使用 depth-anything/DA3METRIC-LARGE checkpoint，Prior-Depth-Anything 细化器即以它的输出为条件完成验证。

## 用来做什么

`depth-anything-v3-prior` 估计深度：输入图像，输出深度图。

DA3 扩展了 Depth Anything 的训练配方并增加米制与几何头。该先验只运行 metric-large checkpoint。该模型由字节跳动（Seed 团队）发布。

任务：单目深度估计、米制深度估计、几何先验。别名：`dav3-prior`、`da3metric-large-prior`。模态上，它接受图像，输出深度。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `focal-length`、`execute`、`max-points`；产物 `depth-anything-v3-prior.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `DepthAnythingV3PriorPipeline`。

系列状态：**已验证**。

将它作为米制深度先验，通过共享的几何先验接口供其他管线（如 ViPE）使用。官方 SOH 导出路径请使用 depth-anything-v3。

仅提供深度先验：完整的 DA3 重建请使用 depth-anything-v3。

## 在 WorldFoundry 中运行

运行 `wf run depth-anything-v3-prior --pipeline.task-profile default` 写出深度图。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`depth-anything/DA3METRIC-LARGE`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh depth-anything-v3-prior`；下载缺失的公开权重时加 `--download`。
