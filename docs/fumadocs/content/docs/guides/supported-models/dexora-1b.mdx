Dexora 1B is a dexterous bimanual manipulation VLA built on a 1B RDT policy backbone (paper: arXiv 2605.18722, MIT license). WorldFoundry includes the full inference stack — SigLIP/T5 encoders, strict checkpoint loader, diffusion sampler, and a 36-DoF action contract — but the authors publish data and training code without official policy weights, so you run it with your own trained checkpoint.

## What it is for

Use `dexora-1b` to predict robot actions from observations and a language instruction.

A 1B-parameter RDT (robotics diffusion transformer) policy with SigLIP vision and T5 language encoding, sampling 36-DoF bimanual dexterous actions through a diffusion sampler. The checkpoint format and inference contract match the official 1B configuration.

Tasks: VLA, dexterous manipulation, bimanual robot policy, and VLA policy rollout. Aliases: `dexora` and `dexora_vla`.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `action_trace` and `dexora_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `DexoraPipeline`.

Family status: **Static load only**.

Train your own Stage-1 or Stage-3 checkpoint with the official pipeline before running; WorldFoundry does not include training, datasets, teleoperation, ZMQ services, robot SDKs, or simulator code.

No official policy weights are released, so outputs cannot be compared numerically against an official checkpoint.

## Running in WorldFoundry

Run `wf run dexora-1b --pipeline.task-profile default` to predict actions.

It runs in the dedicated environment `worldfoundry-vla-dexora` (Python 3.10, CUDA 12.1 or newer, torch>=2.2).

Weights: `google/siglip-so400m-patch14-384` and `google/t5-v1_1-xxl`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh dexora-1b`. Add `--download` to fetch missing public checkpoints.
