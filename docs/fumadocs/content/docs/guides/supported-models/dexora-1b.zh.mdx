Dexora 1B 是灵巧双臂操作 VLA，基于 1B RDT 策略骨干（论文：arXiv 2605.18722，MIT 许可）。WorldFoundry 提供完整推理栈——SigLIP/T5 编码器、严格 checkpoint 加载器、扩散采样器与 36 自由度动作契约——但作者只发布了数据与训练代码，无官方策略权重，因此需要使用你自己训练的 checkpoint 运行。

## 用来做什么

用 `dexora-1b` 根据观测和语言指令预测机器人动作。

1B 参数的 RDT（机器人扩散 transformer）策略，SigLIP 视觉与 T5 语言编码，经扩散采样器输出 36 自由度双臂灵巧动作。checkpoint 格式与推理契约与官方 1B 配置一致。

任务：视觉-语言-动作（VLA）、dexterous_manipulation、bimanual_robot_policy、VLA 策略执行。别名：`dexora`、`dexora_vla`。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`dexora_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `DexoraPipeline`。

系列状态：**仅静态加载**。

运行前需先用官方流程训练自己的 Stage-1 或 Stage-3 checkpoint；WorldFoundry 不包含训练、数据集、遥操作、ZMQ 服务、机器人 SDK 与模拟器代码。

官方未发布策略权重，因此无法与官方 checkpoint 做数值对比。

## 在 WorldFoundry 中运行

运行 `wf run dexora-1b --pipeline.task-profile default` 预测动作。

运行环境：独立环境 `worldfoundry-vla-dexora`（Python 3.10，CUDA 12.1 或更新，torch>=2.2）。

权重仓库：`google/siglip-so400m-patch14-384`、`google/t5-v1_1-xxl`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh dexora-1b`；下载缺失的公开权重时加 `--download`。
