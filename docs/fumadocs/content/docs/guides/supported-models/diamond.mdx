DIAMOND (DIffusion As a Model Of eNvironment Dreams) trains reinforcement-learning agents entirely inside a diffusion world model, with released Atari agents and a playable CS:GO world model (NeurIPS 2024). WorldFoundry runs the official play and inference stack locally through the diamond-atari and diamond-csgo variants.

## What it is for

`diamond-atari` generates a 3D-consistent world rather than a single clip.

Per the publication, frame prediction uses an EDM-style diffusion model over recent frames and actions, keeping visual detail that latent world models lose. The upstream code is MIT-licensed. It is published by University of Geneva / University of Edinburgh / Microsoft Research.

Tasks: diffusion world model, reinforcement learning world model, and game world model. Aliases: `diamond-atari`. Other variants: `diamond-csgo`.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `interactions`, `frames`, `fps`, `seed`, `plan-only`, and `timeout-seconds`; artifact `diamond.mp4`.

CLI task profiles: `runtime-plan` and `default`. WorldFoundry binds `DIAMONDPipeline`. Defaults for `runtime-plan`: frames=16, fps=15, seed=42.

Start with `diamond-atari`. The family has 2 variants, selectable in the command builder above: `diamond-atari` (`atari-world-model`) — Runner parity pending; `diamond-csgo` (`game-world-model`) — Runner parity pending. Family status: **Verified**.

Use DIAMONDPipeline(pretrained=True, pretrained_game=...) for Atari or DIAMONDCsgoPipeline for CS:GO; then execute=True and headless_steps. Inputs come from real Atari initialization or the released CS:GO spawn. Prompt/image/video are not required.

Game-specific world models, not general text-to-video. Validation covers short rollouts. Long-horizon physics, reward accuracy and general game success remain unverified. CS:GO requires local checkpoint/config/spawn assets; runtime network downloads are disabled.

## Running in WorldFoundry

Generate a world with `wf run diamond-atari --pipeline.task-profile runtime-plan`. Switch tasks in the command builder above to change `--pipeline.task-profile`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `eloialonso/diamond`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh diamond-atari`. Add `--download` to fetch missing public checkpoints.
