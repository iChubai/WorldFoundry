DIAMOND（DIffusion As a Model Of eNvironment Dreams）让强化学习智能体完全在扩散世界模型内训练，官方发布了 Atari 智能体与可游玩的 CS:GO 世界模型（NeurIPS 2024）。WorldFoundry 通过 diamond-atari 与 diamond-csgo 两个 variant 在本地运行官方 play 与推理栈。

## 用来做什么

`diamond-atari` 生成 3D 一致的世界，而不只是一段视频。

按论文，帧预测使用基于近期帧与动作的 EDM 式扩散模型，保留了潜空间世界模型会丢失的视觉细节。上游代码采用 MIT 许可。该模型由日内瓦大学 / 爱丁堡大学 / 微软研究院发布。

任务：扩散世界模型、强化学习世界模型、游戏世界模型。别名：`diamond-atari`。同系列还有 `diamond-csgo`。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `interactions`、`frames`、`fps`、`seed`、`plan-only`、`timeout-seconds`；产物 `diamond.mp4`。

CLI task profile：`runtime-plan`、`default`。绑定的 pipeline 类是 `DIAMONDPipeline`。`runtime-plan` 的默认值：frames=16, fps=15, seed=42。

建议从 `diamond-atari` 开始。该系列共有 2 个 variant，可在上方命令构建器中切换：`diamond-atari`（`atari-world-model`）：Runner 一致性待确认、`diamond-csgo`（`game-world-model`）：Runner 一致性待确认。系列状态：**已验证**。

Atari 使用 DIAMONDPipeline(pretrained=True, pretrained_game=...)；CS:GO 使用 DIAMONDCsgoPipeline。调用时设置 execute=True 与 headless_steps。输入来自真实 Atari 初始化或官方 CS:GO spawn，无需 prompt/image/video。

游戏专用世界模型，不是通用文生视频模型。仅验证短程推理；长程物理、奖励准确率和通关效果尚未验证。CS:GO 需要本地 checkpoint/config/spawn，推理时禁用网络下载。

## 在 WorldFoundry 中运行

用 `wf run diamond-atari --pipeline.task-profile runtime-plan` 生成世界。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`eloialonso/diamond`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh diamond-atari`；下载缺失的公开权重时加 `--download`。
