**发表机构:** 斯坦福大学（REAL 实验室） · 高校

Diffusion Policy 是里程碑式的视觉运动策略：将动作生成建模为条件去噪扩散，相比回归策略大幅改进多模态动作分布。WorldFoundry 内置其低维 PushT 变体，从离线转换、完全解析的配置与纯张量 state dict 重建。

## 架构

在观测条件下对动作序列做去噪扩散。树内运行时为发布的低维 PushT 策略；转换后的 checkpoint 通过了 weights-only 重载、严格 model/EMA 恢复、CPU 加载与有限 GPU 动作探针。

## 使用要点

可执行的 dill workspace checkpoint 在运行时被拒绝，且无不安全反序列化回退——转换必须在可信离线环境中一次性完成。predict_action 路由输出配置的低维 PushT 动作 schema。
