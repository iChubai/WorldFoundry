DINO-WM builds world models on pre-trained DINOv2 visual features instead of pixels: it predicts future patch features and plans robot behavior by optimizing action sequences against a goal feature state — zero-shot planning without reconstruction. WorldFoundry includes the official planning/evaluation route together with the required environment simulators.

## What it is for

`dino-wm` is an action-conditioned world model: actions and a starting frame in, a rollout out.

Per the upstream project, a ViT predictor rolls DINOv2 patch features forward conditioned on actions; planning is model-predictive control in feature space. It is published by New York University (NYU).

Tasks: visual feature world model, predictive coding, and robot world model.

## Runtime contract

Inputs `load.ckpt-base-path` and `load.model-name` (bundled samples are used when omitted); options `plan-only` and `timeout-seconds`; artifact `dino-wm.mp4`.

CLI task profile: `wall-planning`. WorldFoundry binds `DinoWMPipeline`. Family status: **Verified**.

The wall_single planning route requires its released model_latest.pth, a DINOv2 encoder, and DATASET_DIR set to the parent directory containing the complete official wall_single trajectory dataset. These assets are not bundled with WorldFoundry; no external DINO-WM checkout is needed.

Only wall_single has been validated on GPU with released checkpoints; pusht and point_maze are untested. The wall validation runs do not establish planning quality or general task success. The model predicts in feature space; the MP4 is a simulator/planning visualization, not pixel generation.

## Running in WorldFoundry

Run `wf run dino-wm --pipeline.task-profile wall-planning` to roll out the world model.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

No public checkpoint is listed for this model; stage the weights as described in the usage notes. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh dino-wm`. Add `--download` to fetch missing public checkpoints.
