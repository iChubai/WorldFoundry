## 用来做什么

`dino-wm` 是动作条件世界模型：输入动作和起始帧，输出推演结果。

按上游项目，ViT 预测器在动作条件下向前滚动 DINOv2 patch 特征；规划是特征空间中的模型预测控制。该模型由纽约大学（NYU）发布。

任务：视觉特征世界模型、预测编码、机器人世界模型。

## 运行时契约

输入 `load.ckpt-base-path`、`load.model-name`（不传时使用内置示例）；参数 `plan-only`、`timeout-seconds`；产物 `dino-wm.mp4`。

CLI task profile：`wall-planning`。绑定的 pipeline 类是 `DinoWMPipeline`。系列状态：**已验证**。

wall_single 规划路径需要发布的 model_latest.pth、DINOv2 编码器，并将 DATASET_DIR 指向包含完整官方 wall_single 轨迹数据集的父目录。这些资源不随 WorldFoundry 分发；无需外部 DINO-WM 检出。

只有 wall_single 已用发布权重完成 GPU 验证；pusht 和 point_maze 尚未测试。wall 验证运行不能证明规划质量或一般任务成功率。模型在特征空间中预测；MP4 是仿真/规划可视化，并非像素生成。

## 在 WorldFoundry 中运行

运行 `wf run dino-wm --pipeline.task-profile wall-planning` 推演世界模型。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型没有登记公开 checkpoint；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh dino-wm`；下载缺失的公开权重时加 `--download`。
