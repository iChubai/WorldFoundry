DINO-WM 在动作条件下预测未来的 DINOv2 视觉特征，并在特征空间中进行目标导向规划。WorldFoundry 包含官方规划路径及 wall 任务仿真器代码。

参见[论文 arXiv 2411.04983](https://arxiv.org/abs/2411.04983)、[项目主页](https://dino-wm.github.io/)和[官方仓库](https://github.com/gaoyuezhou/dino_wm)。

## 验证

已用发布的 epoch-65 `wall_single` 权重、官方 wall 轨迹数据集和 DINOv2 ViT-S/14 编码器验证：GPU 规划运行生成可解码的 26 帧 MP4 及规划指标。

`pusht` 和 `point_maze` 的权重已发布，但它们的任务数据集与仿真依赖尚未在 WorldFoundry 中验证。

## 输入与输出

已验证的 wall 路径需要包含 `outputs/wall_single/hydra.yaml` 与 `outputs/wall_single/checkpoints/model_latest.pth` 的权重目录、DINOv2 编码器及完整官方 wall 轨迹。将 `DATASET_DIR` 指向含有 `wall_single/` 的父目录；wall 配置从 `${DATASET_DIR}/wall_single` 读取轨迹。公开 synthesis 路径接收 `ckpt_base_path`、`model_name="wall_single"` 和 `config`，输出 `dino-wm.mp4` 与规划指标。文本 prompt 或独立的图像/视频输入不属于已验证的 wall 规划运行契约。

MP4 展示仿真与规划过程。DINO-WM 在特征空间中预测，不是像素视频生成器。运行前应先检查解析后的计划：仅有模型权重还不足以提供所需轨迹。

## 局限

wall 验证运行使用很小的搜索预算，只确认执行链路；不能证明任务成功率、长时规划质量，也不代表其他发布任务的结果。
