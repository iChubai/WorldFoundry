DM0 is Dexmal's Dexbotic-family flow-matching VLA: a Qwen3 flow action expert with merged prefix/suffix attention and triple-view preprocessing. Two checkpoints are released, Dexmal/DM0-base and Dexmal/DM0-libero, under a CC license; the full inference loop — normalization plus Euler sampler — runs in process from local checkpoints.

## What it is for

`dm0` maps camera observations and an instruction to an action trajectory.

A Qwen3-based flow action expert decodes actions with an Euler sampler; the Perception Encoder and multimodal base are shared with DB-CogACT from the same Dexbotic family.

Tasks: VLA, VLA action prediction, and VLA policy rollout. Aliases: `dexbotic-dm0` and `dm0-base`.

Suggested benchmarks: [LIBERO](/docs/evaluation/benchmark-hub/libero) (Dedicated DM0-libero policy checkpoint).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `action_trace` and `dm0_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `DM0Pipeline`.

Family status: **Runner parity pending**.

Use DM0-libero for LIBERO evaluation and DM0-base for initialization. Training, datasets, servers, benchmark launchers, and the optional Triton realtime backend are not included.

Checkpoints carry a CC license — review terms before commercial deployment.

## Running in WorldFoundry

Run `wf run dm0 --pipeline.task-profile default` to predict actions.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch>=2.6.0).

Weights: `Dexmal/DM0-libero` and `Dexmal/DM0-base`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh dm0`. Add `--download` to fetch missing public checkpoints.
