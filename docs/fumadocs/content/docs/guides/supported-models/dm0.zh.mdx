DM0 是 Dexmal 的 Dexbotic 家族 flow-matching VLA：Qwen3 flow 动作专家，合并前后缀注意力与三视角预处理。官方发布 base 与 LIBERO 两个 checkpoint（Dexmal/DM0-base、Dexmal/DM0-libero，CC 许可）；完整推理环路——归一化加 Euler 采样器——在进程内从本地 checkpoint 运行。

## 用来做什么

`dm0` 把相机观测和指令映射为动作轨迹。

基于 Qwen3 的 flow 动作专家配 Euler 采样器解码动作；Perception Encoder 和多模态基座均与同属 Dexbotic 家族的 DB-CogACT 共用。

任务：视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行。别名：`dexbotic-dm0`、`dm0-base`。

推荐评测：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（有专门的 DM0-libero 策略 checkpoint）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`dm0_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `DM0Pipeline`。

系列状态：**Runner 一致性待确认**。

LIBERO 评测用 DM0-libero，初始化用 DM0-base。不包含训练、数据集、服务、基准启动器与可选的 Triton 实时后端。

checkpoint 为 CC 许可——商业部署前请审查条款。

## 在 WorldFoundry 中运行

运行 `wf run dm0 --pipeline.task-profile default` 预测动作。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch>=2.6.0）。

权重仓库：`Dexmal/DM0-libero`、`Dexmal/DM0-base`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh dm0`；下载缺失的公开权重时加 `--download`。
