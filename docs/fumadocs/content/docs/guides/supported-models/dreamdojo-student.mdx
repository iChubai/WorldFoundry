DreamDojo's self-forcing student predicts robot-view video with causal action conditioning and one to four TrigFlow sampling steps. WorldFoundry supports isolated offline rollouts and resident normalized-action streaming.

Source: [NVIDIA/DreamDojo](https://github.com/NVIDIA/DreamDojo/tree/02f119b759d5c7f84a399fdeea3c6e82e7ed6cff), including [the distillation workflow](https://github.com/NVIDIA/DreamDojo/blob/02f119b759d5c7f84a399fdeea3c6e82e7ed6cff/docs/DISTILL.md).

## What it is for

`dreamdojo-student` generates future frames conditioned on actions.

The causal student reuses the Cosmos action DiT, Reason1 encoder, and Wan codec. Clean prefill writes request-local three-frame KV history; noisy sampling only reads it. Window continuation retains nine RGB frames and eight aligned historical actions. It is published by NVIDIA.

Tasks: world, robot, and world model.

## Runtime contract

Required `input-path`, `action-file`, and `load.student-checkpoint-path`; input `prompt` (bundled samples are used when omitted); options `height`, `width`, `num-inference-steps`, `guidance-scale`, `fps`, and `seed`; artifact `dreamdojo_world.mp4`.

CLI task profile: `robot-world-generation`. WorldFoundry binds `DreamDojoStudentPipeline`. Family status: **Runner parity pending**. Defaults for `robot-world-generation`: height=480, width=640, num-inference-steps=4, guidance-scale=1.0, fps=10, seed=42.

Supply student_checkpoint_path, one initial image, normalized 384-D actions, and shared Cosmos tokenizer/Reason1 assets. First STEP consumes 12 actions and returns 13 frames; subsequent STEP consumes 4 actions and returns 4 new frames at a 10-fps playback clock. Reset retains weights.

The pinned DreamDojo Hub snapshot contains no distilled student checkpoint; explicit student assets are required. Student checkpoint-backed quality, official parity, closed-loop robot success, and 10-fps inference throughput are not yet validated. Dataset normalization and teleoperation mapping remain caller-owned; WASD controls are not robot actions.

## Running in WorldFoundry

Run `wf run dreamdojo-student --pipeline.task-profile robot-world-generation` to roll out the world model.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `nvidia/Cosmos-Predict2.5-2B` and `nvidia/Cosmos-Reason1-7B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh dreamdojo-student`. Add `--download` to fetch missing public checkpoints.
