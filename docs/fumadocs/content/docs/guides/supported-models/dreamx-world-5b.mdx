DreamX-World 5B AR is Amap's **causal autoregressive** world: latent, attention, cross-attention, and VAE caches stay **resident** while video rolls forward in **three-latent** blocks under camera actions. Decoded RGB is **output-only** — never fed back as conditioning. Distilled **four-step AR-Forcing**. Pipeline: `DreamXWorld5BARPipeline`. Alias `dreamx-world-5b-ar` resolves here.

Paper: [arXiv 2606.16993](https://arxiv.org/abs/2606.16993). Project: [amap-ml.github.io/DreamX_World](https://amap-ml.github.io/DreamX_World). Code: [AMAP-ML/DreamX-World](https://github.com/AMAP-ML/DreamX-World). License: **apache-2.0**.

Validated on a single A100: a **two-control** rollout from the official example image produces a finite, decodable **nine-frame 1280×704** block. Long-horizon quality has not been evaluated.

## What it is for

Roll a causal AR world forward block by block under camera actions.

Launch `wf run dreamx-world-5b`.

Score on [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) — general world-rollout quality.

## Runtime contract

Required: `image` and `prompt`; optional: `video`; `actions`: camera_navigation; artifacts: `generated_world` and `dreamx-world-5b.mp4`.

| Knob | Recorded |
| --- | --- |
| Validated block | **1280×704**, **9** frames, single A100 |
| Schedule | distilled **4-step** AR-Forcing |
| Block | **three** latents; KV / cross-attn / VAE caches stay resident |
| RGB | output-only — never fed back |
| Causal ckpt | `GD-ML/DreamX-World-5B` (`config.json`, `model.safetensors`) |
| Support | `Wan-AI/Wan2.2-TI2V-5B` (VAE, T5, tokenizer) |

## Running in WorldFoundry

Unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `GD-ML/DreamX-World-5B` and `Wan-AI/Wan2.2-TI2V-5B` locally, then run `wf run dreamx-world-5b`.
