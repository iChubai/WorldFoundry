## 架构

因果三潜块使用发布的 causal checkpoint 与蒸馏的四步 AR-Forcing 调度，且无 RGB 回灌：注意力 KV、交叉注意力、潜变量与因果 VAE 状态跨控制常驻，解码的 RGB 仅作输出——绝不回用为条件。
