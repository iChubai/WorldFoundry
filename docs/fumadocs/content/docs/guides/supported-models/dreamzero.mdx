NVIDIA DreamZero is a world-action model (WAM) that couples video prediction with robot control: DROID and AgiBot checkpoints are released under Apache-2.0 (GEAR-Dreams org). WorldFoundry serves the inference model through a distributed server and a WebSocket client that exchange data over a pickle-free NumPy msgpack protocol. Both checkpoints have been validated with GPU probes under CUDA 12.9.

## What it is for

`dreamzero-droid` is a world-action model: it predicts actions conditioned on world observations.

The 14B model builds on Wan2.1-I2V-14B-480P with the UMT5-XXL text encoder. The default 14B server uses two CUDA ranks while the Wan2.2 5B entrypoint can run on one. Checkpoint-controlled Hydra targets are rewritten to and allowlisted within in-tree inference modules, so checkpoint Python is never executed. It is published by NVIDIA (GEAR Lab).

Tasks: WAM, world action model, WAM world action modeling, and robot policy. Aliases: `dreamzero-droid`, `dreamzero-agibot`, and `DreamZero-DROID`. Other variants: `dreamzero-agibot`.

Suggested benchmarks: [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) (World-action modeling quality for embodied control).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `variant`, `dreamzero-server-port`, `plan-only`, `num-chunks`, and `use-zero-images`; artifacts `dreamzero_action_trace.json`.

CLI task profiles: `interactive-video`. WorldFoundry binds `DreamZeroPipeline`.

Start with `dreamzero-droid`. The family has 2 variants, selectable in the command builder above: `dreamzero-droid` (`wam.world_action_modeling`) — Runner parity pending; `dreamzero-agibot` (`wam.post_training_base`) — Runner parity pending. Family status: **Runner parity pending**.

Stage DreamZero-DROID or DreamZero-AgiBot under WORLDFOUNDRY_HFD_ROOT; a CUDA 12.9 runtime is required. Choose DROID for real-robot arm data distribution and AgiBot for the AgiBot embodiment.

Requires CUDA 12.9; the 14B default needs two GPU ranks.

## Running in WorldFoundry

Run `wf run dreamzero-droid --pipeline.task-profile interactive-video` to predict actions.

It runs in the dedicated environment `worldfoundry-dreamzero-cu129` (Python 3.11, CUDA 12.9, torch==2.8.0).

Weights: `GEAR-Dreams/DreamZero-DROID`, `GEAR-Dreams/DreamZero-AgiBot`, and `GEAR-Dreams/DreamZero-DROID` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh dreamzero-droid`. Add `--download` to fetch missing public checkpoints.
