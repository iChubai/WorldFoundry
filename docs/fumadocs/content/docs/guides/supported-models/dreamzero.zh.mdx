英伟达 DreamZero 是将视频预测与机器人控制耦合的世界-动作模型（WAM）：DROID 与 AgiBot checkpoint 以 Apache-2.0 发布（GEAR-Dreams 组织）。WorldFoundry 通过分布式服务与 WebSocket 客户端运行推理模型，两者之间使用无 pickle 的 NumPy msgpack 协议交换数据。两个 checkpoint 均已在 CUDA 12.9 下通过 GPU 探针验证。

## 用来做什么

`dreamzero-droid` 是世界-动作模型：以世界观测为条件预测动作。

14B 模型基于 Wan2.1-I2V-14B-480P，文本编码器为 UMT5-XXL。默认 14B 服务使用两个 CUDA rank，Wan2.2 5B 入口可单 rank 运行。系统会重写 checkpoint 控制的 Hydra target，并将其限定在树内推理模块白名单内，绝不执行 checkpoint Python。该模型由英伟达（GEAR 实验室）发布。

任务：wam、world_action_model、wam.world_action_modeling、机器人策略。别名：`dreamzero-droid`、`dreamzero-agibot`、`DreamZero-DROID`。同系列还有 `dreamzero-agibot`。

推荐评测：[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（具身控制的世界-动作建模质量）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `variant`、`dreamzero-server-port`、`plan-only`、`num-chunks`、`use-zero-images`；产物 `dreamzero_action_trace.json`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `DreamZeroPipeline`。

建议从 `dreamzero-droid` 开始。该系列共有 2 个 variant，可在上方命令构建器中切换：`dreamzero-droid`（`wam.world_action_modeling`）：Runner 一致性待确认、`dreamzero-agibot`（`wam.post_training_base`）：Runner 一致性待确认。系列状态：**Runner 一致性待确认**。

将 DreamZero-DROID 或 DreamZero-AgiBot 放置在 WORLDFOUNDRY_HFD_ROOT 下；需要 CUDA 12.9 运行时。DROID 面向真实机械臂数据分布，AgiBot 面向 AgiBot 本体。

需要 CUDA 12.9；14B 默认配置需两个 GPU rank。

官方 DROID / RoboArena 观测：**两路外相机**、腕部相机、关节、夹爪、提示词、`session_id`。默认 **14B** 服务器用 **两个 CUDA rank**；Wan2.2 **5B** 可单卡。checkpoint 里的 Python **从不执行**。

## 在 WorldFoundry 中运行

运行 `wf run dreamzero-droid --pipeline.task-profile interactive-video` 预测动作。

运行环境：独立环境 `worldfoundry-dreamzero-cu129`（Python 3.11，CUDA 12.9，torch==2.8.0）。

权重仓库：`GEAR-Dreams/DreamZero-DROID`、`GEAR-Dreams/DreamZero-AgiBot`、`GEAR-Dreams/DreamZero-DROID` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh dreamzero-droid`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
