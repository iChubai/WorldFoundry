DROID-W 是围绕 DROID 机器人操作数据生态的机器人世界模型：为 DROID 风格任务生成机器人视角视频用于评估。本 catalog 中官方源码路径已注册、源码固定在记录的 commit；checkpoint 与数据保持运行时限制。

## 用来做什么

`droid-w` 是记录的交互世界线。要用动作推进世界时从这里起步。

架构内部细节仓库未记录（上游：MoyangLi00/DROID-W，apache-2.0）。官方源码从 $\{WORLDFOUNDRY_MODEL_SOURCE_DIR\}/DROID-W 绑定，commit 为 c3414af6。

catalog 记录的任务包括 机器人世界模型、droid-evaluation、视频生成。输出模态为视频。

记录的评测入口包括[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（机器人视频预测的具身世界模型评测）。

DROID-W 机器人世界。权重未齐时预期是 runtime plan，不是视频。

## 运行时契约

必填 `image`、`prompt`、`video`；可选 `actions` (robot_action, droid_action)；产物 `generated_video`、`droid_w_runtime_plan.json`。

记录的任务 profile：`robot-world-model`、`droid-evaluation`、`video-generation`。绑定的 pipeline 类是 `DROIDWPipeline`。

系列状态：**Runner 一致性待确认**。

配置解析与 pipeline 导入预期可通过；在所需 checkpoint/资产就位前，真实生成会输出运行时计划。 缺失资产由计划报告，不视为 catalog 阻塞。

DROID-W official source route is registered; checkpoints/data are runtime-gated.

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run droid-w --pipeline.task-profile robot-world-model` 推进世界。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

本卡片未记录公开 checkpoint id；按使用说明就位权重。就位权重用 `bash scripts/inference/prepare_model_infer.sh droid-w`。

状态：**Runner 一致性待确认**。
