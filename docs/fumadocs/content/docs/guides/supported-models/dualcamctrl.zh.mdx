DualCamCtrl 用**相机轨迹加深度图**控制视频：RGB 和深度一起钉住几何，让相机运动落地。WorldFoundry 以 `DualCamCtrlPipeline` 运行它，输入与官方 RGB / 深度 / 相机 demo 一致。已用官方 seaside demo 验证：pipeline 以 50 步生成 320×480 的 61 帧视频。

## 用来做什么

相机可控的图生视频：提供起始图像、对应深度图与相机轨迹，生成沿相机路径运动的视频。

启动 `wf run dualcamctrl`。

评测入口：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（受控生成的相机轨迹贴合度）。

## 运行时契约

必填 `prompt`、`image`；可选 `video`；`actions`：camera_trajectory, depth_image；产物 `dualcamctrl.mp4`、`seaside.mp4`。

| 旋钮 | 官方 demo |
| --- | --- |
| 尺寸 | **320×480** |
| 帧数 | **61** |
| 步数 | **50** |
| 轨迹 | `.torch` 相机文件 |

## 在 WorldFoundry 中运行

统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。权重来自 `FayeHongfeiZhang/DualCamCtrl`、`alibaba-pai/Wan2.1-Fun-V1.1-1.3B-Control-Camera`、`Wan-AI/Wan2.1-T2V-1.3B` 与 `Wan-AI/Wan2.1-I2V-14B-480P`，默认通过 Hugging Face 缓存加载；已就位的本地资产可通过 `checkpoint_path`、`base_model_path` 或 `WORLDFOUNDRY_MODEL_DIR` 传入。在该环境执行 `wf run dualcamctrl`。
