## Architecture

A ViT encoder-decoder that regresses per-pixel 3D pointmaps in a shared frame for an image pair; global alignment merges pairs into scenes (per arXiv 2312.14132). WorldFoundry vendors it under base_models/three_dimensions/general_3d/dust3r, exposed via the geometry-prior contract.

## Usage notes

The runnable route is exposed through the shared geometry-prior contract (see dust3r-base-model). Mind the license: upstream is CC-BY-NC-SA-4.0 — recorded for provenance; respect non-commercial terms downstream.
