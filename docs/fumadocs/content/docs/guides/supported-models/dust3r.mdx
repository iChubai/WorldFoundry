DUSt3R made unconstrained two-view 3D easy: **two images**, no calibration, no poses — it regresses aligned **pointmaps**. WorldFoundry runs it as `DUSt3RPipeline` on the shared geometry-prior contract. The aliases `naver-dust3r` and `geometric-3d-vision-made-easy` select the same model.

Paper: [DUSt3R: Geometric 3D Vision Made Easy](https://arxiv.org/abs/2312.14132) (arXiv 2312.14132). Project: [dust3r.europe.naverlabs.com](https://dust3r.europe.naverlabs.com/). Publisher: NAVER Labs Europe. License: **CC-BY-NC-SA-4.0** (non-commercial downstream).

Validated with the released checkpoint: Studio inference produces a finite point cloud from the bundled multi-view test case.

## What it is for

Launch `wf run dust3r` with the feed-forward multi-view reconstruction profile. Required: `image`. Optional: `prompt`, `video`. `actions`: `multi_view_reconstruction`. Artifact: `dust3r_point_cloud.ply`. Large scenes still need global alignment, which gets expensive with many views. For streaming reconstruction with metric state, use [CUT3R](/docs/guides/supported-models/cut3r).

## Runtime contract

`DUSt3RPipeline` on the shared geometry-prior contract (`dust3r-base-model`). Required: `image` (an uncalibrated pair or multi-view set). Optional: `prompt`, `video`. `actions`: `multi_view_reconstruction`. Artifact: `dust3r_point_cloud.ply`.

| Knob | Value |
| --- | --- |
| Checkpoint | `naver/DUSt3R_ViTLarge_BaseDecoder_512_dpt` → `$WORLDFOUNDRY_CKPT_DIR/DUSt3R_ViTLarge_BaseDecoder_512_dpt.pth` |
| Encoder | ViT-Large + Base decoder, **512** DPT |
| Pair output | Per-pixel pointmaps in a shared frame (camera-1 coordinates) |
| Many views | Global alignment after pairwise inference |

Environment: `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). License: **CC-BY-NC-SA-4.0**.

## Running in WorldFoundry

Stage the NAVER `512_dpt` checkpoint at `$WORLDFOUNDRY_CKPT_DIR/DUSt3R_ViTLarge_BaseDecoder_512_dpt.pth`, then launch `wf run dust3r`.
