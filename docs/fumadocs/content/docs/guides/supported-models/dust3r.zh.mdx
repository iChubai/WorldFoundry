## 架构

ViT 编码-解码器为一对图像在共享坐标系中回归逐像素 3D 点图；全局对齐把多对合并为场景（见 arXiv 2312.14132）。WorldFoundry 将其内置于 base_models/three_dimensions/general_3d/dust3r，经 geometry-prior 契约暴露。
