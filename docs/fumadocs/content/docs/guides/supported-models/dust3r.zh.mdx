DUSt3R 简化了无约束双视图 3D 重建：仅需**两张图**，无需标定或位姿，即可直接回归对齐的**点图**。WorldFoundry 经共享几何先验契约以 `DUSt3RPipeline` 运行它。别名 `naver-dust3r`、`geometric-3d-vision-made-easy` 指向同一模型。

<ModelPaperFigures modelId="dust3r" locale="zh" />

论文：[DUSt3R: Geometric 3D Vision Made Easy](https://arxiv.org/abs/2312.14132)（arXiv 2312.14132）。项目页：[dust3r.europe.naverlabs.com](https://dust3r.europe.naverlabs.com/)。发布方：NAVER Labs Europe。许可证：**CC-BY-NC-SA-4.0**（下游非商用）。

已用发布的 checkpoint 验证：Studio 推理从捆绑多视图用例产出有限点云。

<ModelCommandBuilder modelId="dust3r" locale="zh" />

## 用来做什么

启动 `wf run dust3r`，走前馈多视图重建 profile。必填：`image`。可选：`prompt`、`video`。`actions`：`multi_view_reconstruction`。产物：`dust3r_point_cloud.ply`。大场景仍要全局对齐，视角增多时计算成本会上升。需要带米制状态的流式重建时，请使用 [CUT3R](/zh/docs/guides/supported-models/cut3r)。

## 运行时契约

`DUSt3RPipeline`，走共享几何先验契约（`dust3r-base-model`）。必填：`image`（未标定的一对或多视图）。可选：`prompt`、`video`。`actions`：`multi_view_reconstruction`。产物：`dust3r_point_cloud.ply`。

| 旋钮 | 取值 |
| --- | --- |
| Checkpoint | `naver/DUSt3R_ViTLarge_BaseDecoder_512_dpt` → `$WORLDFOUNDRY_CKPT_DIR/DUSt3R_ViTLarge_BaseDecoder_512_dpt.pth` |
| 编码器 | ViT-Large + Base 解码器，**512** DPT |
| 成对输出 | 共享坐标系下的逐像素点图（相机 1） |
| 多视图 | 成对推理后再做全局对齐 |

环境：`worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。许可证：**CC-BY-NC-SA-4.0**。

## 在 WorldFoundry 中运行

先把 NAVER `512_dpt` checkpoint 就位到 `$WORLDFOUNDRY_CKPT_DIR/DUSt3R_ViTLarge_BaseDecoder_512_dpt.pth`，再启动 `wf run dust3r`。
