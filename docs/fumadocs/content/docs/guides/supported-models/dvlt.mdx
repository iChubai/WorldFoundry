Déjà View Looping Transformer (DVLT) is an NVIDIA multi-view reconstruction model covering 3D reconstruction, camera pose estimation, and depth from image collections, exporting GLB scenes. The WorldFoundry wrapper is lazy: it runs the external DVLT GLB export path only when CUDA, dependencies, source, inputs, and weights are all staged locally.

## What it is for

Use `dvlt` for feed-forward 3D reconstruction from the input views.

DVLT uses a looping-transformer design for multi-view geometry (paper arXiv 2605.30215).

Tasks: 3D reconstruction, multi view reconstruction, camera pose estimation, and depth estimation. Aliases: `deja-view`, `dejaview`, `deja-view-looping-transformer`, and `nvidia/dvlt`. Modalities: image in, depth out.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `execute` and `max-points`; artifacts `dvlt_reconstruction.glb`.

CLI task profiles: `default`. WorldFoundry binds `DVLTPipeline`.

Family status: **Runner parity pending**.

Stage a local DVLT source checkout, its dependencies, and the `nvidia/dvlt` checkpoint before running; DVLTSynthesis fails fast when a prerequisite is missing. Check the NVIDIA non-commercial research/evaluation license terms before use.

Checkpoint license is NVIDIA non-commercial research/evaluation only.

## Running in WorldFoundry

Reconstruct the scene with `wf run dvlt --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `nvidia/dvlt`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh dvlt`. Add `--download` to fetch missing public checkpoints.

License: NVIDIA non-commercial research and evaluation license.
