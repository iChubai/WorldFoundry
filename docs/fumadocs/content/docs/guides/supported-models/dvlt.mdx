The WorldFoundry wrapper is lazy: it runs the external DVLT GLB export path only when CUDA, dependencies, source, inputs, and weights are all staged locally.

## Architecture

The catalog records a looping-transformer design for multi-view geometry (paper arXiv 2605.30215); the runtime source is externalized from the public release tree, so architecture internals beyond the recorded tasks are not stored here.

## Usage notes

Runner registration is wired; GPU parity is pending checkpoint and environment validation. The nvidia/dvlt checkpoint carries the NVIDIA non-commercial research/evaluation license — check terms before use. DVLTSynthesis fails fast on missing prerequisites.
