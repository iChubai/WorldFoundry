Déjà View Looping Transformer（DVLT）是英伟达的多视图重建模型，覆盖 3D 重建、相机位姿估计与深度估计，输出 GLB 场景。WorldFoundry 的封装采用惰性执行：仅当 CUDA、依赖、源码、输入与权重全部本地就位时，才运行外部 DVLT 的 GLB 导出路径。

## 用来做什么

用 `dvlt` 从输入视图做前馈 3D 重建。

DVLT 采用面向多视图几何的 looping-transformer 设计（论文 arXiv 2605.30215）。该模型由英伟达（NVIDIA）发布。

任务：3D 重建、multi-view-reconstruction、camera-pose-estimation、depth-estimation。别名：`deja-view`、`dejaview`、`deja-view-looping-transformer`、`nvidia/dvlt`。模态上，它接受图像，输出深度。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `execute`、`max-points`；产物 `dvlt_reconstruction.glb`。

CLI task profile：`default`。绑定的 pipeline 类是 `DVLTPipeline`。

系列状态：**Runner 一致性待确认**。

运行前先在本地就位 DVLT 源码 checkout、其依赖与 `nvidia/dvlt` checkpoint；缺少任一前置条件时 DVLTSynthesis 会快速失败。使用前请核对英伟达非商用研究/评估许可条款。

checkpoint 许可仅限英伟达非商用研究/评估用途。

## 在 WorldFoundry 中运行

用 `wf run dvlt --pipeline.task-profile default` 重建场景。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`nvidia/dvlt`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh dvlt`；下载缺失的公开权重时加 `--download`。

许可证：NVIDIA 非商用研究与评测许可。
