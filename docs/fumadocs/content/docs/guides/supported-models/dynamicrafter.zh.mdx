DynamiCrafter 借助视频扩散先验为开放域静态图片赋予动态——给它一张图（可附提示词），即可生成合理的运动视频。catalog 记录了两个不同分辨率的可运行 variant：dynamicrafter-512-i2v 与 dynamicrafter-1024-i2v，均封装为树内 WorldFoundry 运行时并配好了 checkpoint 环境。

## 架构

DynamiCrafter 属 U-Net 时代的潜空间视频扩散模型，采用双流图像条件设计（CLIP 图像特征加 VAE 编码的图像潜变量），见其论文。本仓库记录了两个分辨率 profile 与标准的 prompt/image/video/actions 输入 schema；更细的内部结构仓库未记录。

## 使用要点

两个 variant 均已接通，但官方长配置的一致性验证仍在等待。建议先用 512 版求快，再用 1024 版出成品。 manifest 要求在人工审阅上游许可前保持再分发受限——请相应对待产出。
