DynamiCrafter 为开放域静帧生成动画：输入图像和可选提示词，输出包含运动的视频。它采用基于 U-Net 的潜空间视频扩散架构和**双流**图像条件（CLIP 图像特征 + VAE 潜变量）。WorldFoundry 把两个分辨率 profile 封成树内运行时。默认 pipeline：`DynamiCrafter512I2VPipeline`。变体：`dynamicrafter-512-i2v`、`dynamicrafter-1024-i2v`。

追求速度时用 512，定稿时用 1024。模型会自行生成运动，**不**遵循相机路径或动作。

## 用来做什么

用 DynamiCrafter 根据静帧生成视频。

启动 `wf run dynamicrafter-512-i2v`。

评测入口：[AIGCBench](/zh/docs/evaluation/benchmark-hub/aigcbench)（与 DynamiCrafter 任务对齐的图生视频评测）。

## 运行时契约

必填 `prompt`、`image`；可选 `video`；产物 `dynamicrafter-512-i2v.mp4`。

| 变体 | 尺寸 | 帧数 | 帧步长 | 产物 |
| --- | --- | --- | --- | --- |
| `dynamicrafter-512-i2v` | **320×512** | **50** | **24** | `dynamicrafter-512-i2v.mp4` |
| `dynamicrafter-1024-i2v` | **576×1024** | **50** | **10** | `dynamicrafter-1024-i2v.mp4` |

## 在 WorldFoundry 中运行

统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。先把 `Doubiiu/DynamiCrafter`、`Doubiiu/DynamiCrafter_512`、`Doubiiu/DynamiCrafter_1024` 就位到本地，再在该环境执行 `wf run dynamicrafter-512-i2v`。
