EasyAnimate 是阿里 PAI 团队基于 DiT 的视频生成项目，覆盖文生视频、图生视频与视频到视频。 WorldFoundry 在树内封装了其 V5.1 图生视频运行时；WRBench 相机控制评测复用同一独立运行时，从不解析外部源码检出。别名 easyanimate_i2v、easyanimate-i2v 解析到本条目。

## 架构

记录的路径使用官方 V5.1 Flow 调度器、InP（图像条件补全式）checkpoint 系列，以及 height/width 到 sample_size 的映射。manifest 特别注明：`*-InP` checkpoint 对应 I2V demo，非 InP 的 EasyAnimateV5.1-7b-zh 才是文生视频模型。

## 使用要点

集成已完成；runner parity 为 pending，每次运行的视觉 QA 在 catalog 外跟踪。选择 checkpoint 时牢记上述 InP/非 InP 之分——选错系列是最常见的配置错误。官方代码在 aigc-apps/EasyAnimate，checkpoint 在 alibaba-pai 的 HF 组织下。

## 评测 Benchmark

- [CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench) — WRBench 相机控制复用该运行时，因此相机评测相关。
