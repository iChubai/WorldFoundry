Echo-Memory Context K=1 is **one model** in JD's Echo-Memory family: a Wan2.1-T2V-1.3B interactive world model that differs from its siblings **only** in memory. It is permanently bound to `context_k1/epoch-0.safetensors` — each new chunk conditions on **K=1** context frame. You do **not** pick a memory method at runtime. Pipeline: `EchoMemoryContextK1Pipeline`. Aliases `echo-context-k1` and `echo-memory` resolve here.

## What it is for

Use it as the minimal-context (K=1) baseline when comparing memory mechanisms in action-conditioned world models. For long text-to-video generation, use [Echo-Infinity](/docs/guides/supported-models/echo-infinity).

Launch `wf run echo-memory-context-k1`.

Score on [MemoBench](/docs/evaluation/benchmark-hub/memobench) — purpose-built for evaluating long-horizon memory in interactive world models.

## Runtime contract

Required: `prompt` and `image`; optional: `video`; `actions`: camera_trajectory; artifacts: `generated_world_video` and `echo-memory-context-k1.mp4`.

| Knob | Default |
| --- | --- |
| Size | **640×352** |
| Frames | **81** |
| FPS | **15** |
| Chunks | **2** |
| Context frames | **1** |
| Sample steps | **50** |
| Sample shift | **5.0** |
| Camera trajectory | `z*80` (stationary) |
| Camera translation step | **0.00125** per frame (`w*80` moves +Y 0.1 per chunk) |
| Camera rotation step | **0.5625°** per frame (`left*80` turns 45° per chunk) |
| Finetune | `Echo-Team/Echo-Memory` (`cc-by-4.0`) |
| Backbone | `Wan-AI/Wan2.1-T2V-1.3B` (`apache-2.0`) |

Pass `camera_trajectory="w*80"` to request the published forward action scale, or `"left*80"` for a 45° turn. A camera move mentioned only in the prompt does not replace the default stationary action. `camera_translation_step` and `camera_rotation_step_degrees` can override the per-frame distances.

## Running in WorldFoundry

Unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `Echo-Team/Echo-Memory` and `Wan-AI/Wan2.1-T2V-1.3B` locally, then run `wf run echo-memory-context-k1`. License: CC-BY-4.0 (finetune) and Apache-2.0 (backbone).

To add a new immutable recipe, see the [inference guide](/docs/guides/inference#echo-memory-context-k1). For checkpoint staging, see [local assets](/docs/guides/local-assets).
