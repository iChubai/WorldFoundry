Echo-Memory Context K=1 是京东 Echo-Memory 家族里的**一个模型**：Wan2.1-T2V-1.3B 交互式世界模型，和同族模型的差别**只有**记忆。它永久绑定 `context_k1/epoch-0.safetensors`——每个新块只条件于 **K=1** 帧上下文。运行时**不能**另选记忆方法。Pipeline：`EchoMemoryContextK1Pipeline`。别名 `echo-context-k1`、`echo-memory` 解析到这里。

画质是研究预览级（1.3B 主干）。

## 用来做什么

在动作条件世界模型中比较记忆机制时，把它用作最小上下文（K=1）基线。长文生视频请改用 [Echo-Infinity](/zh/docs/guides/supported-models/echo-infinity)。

启动 `wf run echo-memory-context-k1`。

评测入口：[MemoBench](/zh/docs/evaluation/benchmark-hub/memobench)（专为评估交互式世界模型的长时程记忆而设）。

## 运行时契约

必填 `prompt`、`image`；可选 `video`；`actions`：camera_trajectory；产物 `generated_world_video`、`echo-memory-context-k1.mp4`。

| 旋钮 | 默认 |
| --- | --- |
| 尺寸 | **640×352** |
| 帧数 | **81** |
| FPS | **15** |
| Chunk 数 | **2** |
| 上下文帧 | **1** |
| 采样步数 | **50** |
| Sample shift | **5.0** |
| 相机轨迹 | `z*80`（静止） |
| 相机每帧平移步长 | **0.00125**（`w*80` 每块沿 +Y 移动 0.1） |
| 相机每帧旋转步长 | **0.5625°**（`left*80` 每块转动 45°） |
| 微调 | `Echo-Team/Echo-Memory`（`cc-by-4.0`） |
| 主干 | `Wan-AI/Wan2.1-T2V-1.3B`（`apache-2.0`） |

要请求官方示例尺度的前进动作，请传入 `camera_trajectory="w*80"`；要转动 45°，请传入 `"left*80"`。仅在提示词中描述相机运动不会替换默认的静止动作。可用 `camera_translation_step` 和 `camera_rotation_step_degrees` 覆盖每帧幅度。

## 在 WorldFoundry 中运行

统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。先把 `Echo-Team/Echo-Memory` 和 `Wan-AI/Wan2.1-T2V-1.3B` 就位到本地，再在该环境执行 `wf run echo-memory-context-k1`。许可证：CC-BY-4.0（微调权重）、Apache-2.0（主干）。

如何加一条不可变 recipe 见[推理指南](/zh/docs/guides/inference#echo-memory-context-k1)。权重就位见[本地资产](/zh/docs/guides/local-assets)。
