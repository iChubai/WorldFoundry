## 架构

按 Echo-Memory 发布（arXiv 2606.09803），所有 variant 都是基于 Wan2.1-T2V-1.3B 的交互式世界模型，差异只在记忆机制。在 WorldFoundry 中，每个 variant 是绑定单一 checkpoint 的独立模型身份：配方由 NativeDiffusionPipeline 从共享 Wan 组件加框架自有的 frozen-context 策略组装——不使用外部后端。采样器采用「目标噪声+干净上下文后缀」、仅目标 CFG、每个求解步后重锁上下文、仅解码目标帧。

## 使用要点

checkpoint 从 Echo-Team/Echo-Memory（cc-by-4.0）下载，基座为 Wan2.1-T2V-1.3B（apache-2.0）。2026-07-20 的 A100 产物早于 NativeDiffusionPipeline 切换，仅作为历史证据保留——全新 CUDA 产物验证应视为 pending。运行时用户不选择记忆方法——每种方法都是独立的 catalog 身份。
