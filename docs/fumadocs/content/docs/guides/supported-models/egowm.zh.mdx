EgoWM 预测移动智能体**第一人称**会看到的视频：一张视角加导航动作。变体：`egowm-svd-3dof` 与 `egowm-svd-25dof`，基座是 **Stable Video Diffusion**（`anuragba/egowm`）。WorldFoundry 通过用户就位的源码检出绑定官方 25-DoF SVD 推理路径，对外是 `EgoWMPipeline`。变体之外的架构细节这里不存。未记录机构。

论文：[arXiv 2601.15284](https://arxiv.org/abs/2601.15284)。项目页：[egowm.github.io](https://egowm.github.io/)。代码：[miccooper9/egowm](https://github.com/miccooper9/egowm)。

配置导入应能过。**真正生成会先出 runtime plan**，直到 checkpoint 和资产就位。缺资产由 plan 报告，不是 catalog 阻塞项。Runner：`implemented`。

## 用来做什么

用 CMU fixture 跑第一人称导航世界模型。

启动 `worldfoundry-eval run egowm-svd-3dof --pipeline.task-profile navigation-video`。

## 运行时契约
