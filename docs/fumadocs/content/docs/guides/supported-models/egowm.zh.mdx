EgoWM 预测移动智能体**第一人称**会看到的视频：一张视角加导航动作。变体：`egowm-svd-3dof` 与 `egowm-svd-25dof`，基座是 **Stable Video Diffusion**（`anuragba/egowm`）。WorldFoundry 通过用户就位的源码检出绑定官方 25-DoF SVD 推理路径，对外是 `EgoWMPipeline`。变体之外的架构细节这里不存。未记录机构。

论文：[arXiv 2601.15284](https://arxiv.org/abs/2601.15284)。项目页：[egowm.github.io](https://egowm.github.io/)。代码：[miccooper9/egowm](https://github.com/miccooper9/egowm)。

配置导入应能过。**真正生成会先出 runtime plan**，直到 checkpoint 和资产就位。缺资产由 plan 报告，不是 catalog 阻塞项。Runner：`implemented`。

## 用来做什么

第一人称导航世界模型，包含动作条件 3-DoF 和状态加动作条件 25-DoF 变体。

默认 25-DoF 路径要求同一轨迹的首帧图像和物理状态／动作条件。

## 运行时契约

必填 `image`、`prompt`；可选 `video`；`actions`：navigation_action, egocentric_action；产物 `generated_video`、`egowm.mp4`。

| 旋钮 | 默认 |
| --- | --- |
| 尺寸 | **512×512** |
| 帧数 | **8** |
| 步数 | **25** |
| FPS | **7** |
| Seed | **42** |
| `motion_bucket_id` | **180** |
| 条件 | 配对的 `conditions_path` JSON（25-DoF 必填） |
| 学生 | `$WORLDFOUNDRY_CKPT_DIR/anuragba--egowm/svd_25dof_nav.pth` |
| SVD 基座 | `stabilityai/stable-video-diffusion-img2vid` |
| 源码 | `$WORLDFOUNDRY_MODEL_SOURCE_DIR/egowm` commit `4a24b6fb` |

默认 `variant=25dof` 需要显式提供首帧图像和 JSON 文件：`physical_initial_state` 是 25 个数，`physical_actions` 每生成一帧对应一行 25 个数。动作是源视频中相隔 6 帧的机器人状态之差；运行器按官方导航统计分别归一化状态和动作。图像必须与这条轨迹配对，默认不提供图像。`smoke_synthetic=true` 只用于检查模型加载和生成；零状态与合成动作不能验证机器人运动语义。使用 3-DoF 权重时，显式设 `variant=3dof`，不传条件文件，另用 `action_scale` 偏移量。

## 在 WorldFoundry 中运行

状态：**一条官方配对 25-DoF 导航样例已在 GPU 验证**。公共 pipeline 使用同一 EVE1x 验证样例的首帧、初始状态和 25D 动作生成输入帧加 8 个预测帧。单样例结果不能证明精确机器人位移或普遍导航质量。先将 `anuragba/egowm` 和 `stabilityai/stable-video-diffusion-img2vid` 就位到本地，缺文件加载失败；25-DoF 任务须提供配对图像与条件 JSON。catalog 未记录 VRAM。
