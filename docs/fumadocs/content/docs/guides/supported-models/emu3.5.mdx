## What it is for

Pick `emu3.5` when you want the catalog VLA policy: instruction and observation in, an action trace out. Use it to roll the recorded policy, not to train a new one.

The Emu series treats images and text as one token stream for next-token prediction — no separate diffusion decoder in the loop, per BAAI's public releases. This repository records the prompt+image input contract and the model_response artifact; parameter counts and internals of the 3.5 revision are not recorded here. It is published by Beijing Academy of Artificial Intelligence (BAAI).

Catalog tasks include multimodal-generation, image-generation, and vla reasoning. Catalog aliases include `emu3p5`, `emu3_5`, and `BAAI/Emu3.5`.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run emu3.5 --pipeline.task-profile multimodal-generation`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `BAAI/Emu3.5`. Stage assets with `bash scripts/inference/prepare_model_infer.sh emu3.5`.
