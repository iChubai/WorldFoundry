## 用来做什么

需要 catalog 上的 VLA 策略时选 `emu3.5`：指令与观测进、动作轨迹出。用来滚动已记录策略，不是用来训练新策略。

Emu 系列把图像与文本统一为一个 token 流做下一个 token 预测——按 BAAI 的公开发布，推理环节没有独立的扩散解码器。本仓库记录了 prompt+image 输入契约与 model_response 产物；3.5 版的参数规模与内部细节仓库未记录。该模型由北京智源人工智能研究院（BAAI）发布。

catalog 记录的任务包括 multimodal-generation、图像生成、VLA 推理。别名包括 `emu3p5`、`emu3_5`、`BAAI/Emu3.5`。

## 运行时契约

必填 `prompt`；可选 `image`；产物 `emu3.5.json`。

记录的任务 profile：`multimodal-generation`、`image-generation`、`vla.reasoning`。绑定的 pipeline 类是 `Emu35Pipeline`。

系列状态：**Runner 一致性待确认**。

先就位 BAAI/Emu3.5 权重；资产缺失时路径会给出明确报错。 预期输出是文本/图像响应，而不是视频。

Checkpoint 属于外部资产——权重缺失时会在运行时报告，而不会自动下载。
