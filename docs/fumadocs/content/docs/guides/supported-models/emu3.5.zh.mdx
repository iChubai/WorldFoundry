## 用来做什么

`emu3.5` 根据文本提示词生成图像。

Emu3.5 预测统一的图文 token 序列，并以离散扩散生成视觉 token，再通过独立的视觉 tokenizer 解码。该模型由北京智源人工智能研究院（BAAI）发布。

任务：multimodal-generation、图像生成。别名：`emu3p5`、`emu3_5`、`BAAI/Emu3.5`。

## 运行时契约

输入 `prompt`、`image`；产物 `emu3.5.pb`。

CLI task profile：`multimodal-generation`、`image-generation`。绑定的 pipeline 类是 `Emu35Pipeline`。

系列状态：**Runner 一致性待确认**。

就位 BAAI/Emu3.5 与 BAAI/Emu3.5-VisionTokenizer 权重。默认 story 和 howto 任务返回官方 protobuf 响应。

与官方 CLI 的逐字节一致性以及 384×384 以上的图像尺寸尚未验证。

## 在 WorldFoundry 中运行

运行 `wf run emu3.5 --pipeline.task-profile multimodal-generation` 写出图像。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`BAAI/Emu3.5`、`BAAI/Emu3.5-VisionTokenizer`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh emu3.5`；下载缺失的公开权重时加 `--download`。
