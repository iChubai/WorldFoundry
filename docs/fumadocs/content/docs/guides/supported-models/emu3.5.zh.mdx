Emu3.5 是北京智源（BAAI）面向交错文本与图像的原生多模态生成模型。WorldFoundry 已注册适配器，但已就位权重声明的 Emu3 架构无法被当前 Transformers 运行时识别。加载模型前即被阻塞，且不宣称视频输出。

## 架构

Emu 系列把图像与文本统一为一个 token 流做下一个 token 预测——按 BAAI 的公开发布，推理环节没有独立的扩散解码器。本仓库记录了 prompt+image 输入契约与 model_response 产物；3.5 版的参数规模与内部细节仓库未记录。

## 运行时契约

BAAI/Emu3.5 权重已就位，但 Transformers 4.57.6 无法识别 config.model_type Emu3。验证权重生成文本/图像响应前，需要经过检查的兼容加载器。
