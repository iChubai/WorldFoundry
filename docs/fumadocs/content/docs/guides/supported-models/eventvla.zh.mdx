InternRobotics 的 EventVLA 是长时程记忆 VLA：在 Qwen3-VL-4B 基座上增加事件头、时间锚点与原始关键帧图像记忆，使策略在长任务中记住已发生的事件。默认策略来自采用 Apache-2.0 许可的 ganlinyang/EventVLA checkpoint 集合，使用其中的 RoboTwin-MeM 子目录。

权重：`ganlinyang/EventVLA`，默认子目录 **RoboTwin-MeM**（另有 `RMBench` 子目录）。代码许可：**MIT**；权重集合为 **Apache-2.0**。已用发布的 RoboTwin-MeM checkpoint 在 A100 上验证：推理输出有限的 **50×14** 开环动作块。

## 用来做什么

`eventvla` 把相机观测和指令映射为动作轨迹。

Qwen3-VL 的编码结果送入动作 token 收集模块和兼容 checkpoint 的 MLP 动作头；事件头与时间锚点维护情节结构，关键帧图像构成记忆。全部组件在进程内运行。该模型由上海人工智能实验室（InternRobotics）发布。

任务：视觉-语言-动作（VLA）、VLA 动作预测、vla.long_horizon_memory。别名：`event-vla`、`eventvla-robotwin-mem`。

推荐评测：[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（RoboTwin-MeM checkpoint 面向 RoboTwin 记忆任务）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`eventvla_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `EventVLAPipeline`。

系列状态：**Runner 一致性待确认**。

在本地就位 EventVLA checkpoint（子目录 RoboTwin-MeM）与 Qwen3-VL-4B-Instruct 基座。训练、数据集、模拟器、基准启动器与 WebSocket 传输均被排除。

发布的策略面向 RoboTwin 记忆任务；其他套件需微调。

必填 `image`、`prompt`；可选 `model_id`、`state`、`temporal_anchors`、`action_dim`、`action_horizon`；产物 `action_trace`、`eventvla_action_trace.json`。

## 在 WorldFoundry 中运行

运行 `wf run eventvla --pipeline.task-profile default` 预测动作。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch>=2.6.0）。

权重仓库：`ganlinyang/EventVLA`、`Qwen/Qwen3-VL-4B-Instruct`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh eventvla`；下载缺失的公开权重时加 `--download`。
