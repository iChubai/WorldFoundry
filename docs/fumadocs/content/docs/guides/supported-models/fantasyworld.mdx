FantasyWorld does geometry-consistent world modeling by unifying video and 3D prediction: from an image it produces camera-controllable world video that stays geometrically coherent. Two variants are available: the default Wan2.1 pipeline and a Wan2.2 pipeline.

## What it is for

`fantasyworld-wan21` is a world generation model.

FantasyWorld augments a Wan video backbone with a unified 3D-prediction branch so that generated frames respect scene geometry (per arXiv 2509.21657). It is published by Alibaba (Amap, Fantasy-AMAP).

Tasks: geometry consistent world modeling. Aliases: `Geometry-Consistent World Modeling via Unified Video and 3D Prediction`. Other variants: `fantasyworld-wan22`.

Suggested benchmarks: [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Scores geometry-consistent generated worlds), [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-control quality evaluation).

## Runtime contract

Inputs `input-path`, `prompt`, and `camera-json-path` (bundled samples are used when omitted); options `fps`, `seed`, `using-scale`, `conf-threshold`, and `stride`; artifacts `generated_world` and `fantasyworld-wan21.mp4`.

CLI task profiles: `official-camera-world`. WorldFoundry binds `FantasyWorldPipeline`.

Start with `fantasyworld-wan21`. The family has 2 variants, selectable in the command builder above: `fantasyworld-wan21` (`image-to-world-video`) — Runner parity pending; `fantasyworld-wan22` (`camera-controlled-world-video`) — Runner parity pending. Family status: **Verified**.

`official-camera-world` defaults: fps=16, seed=1024.

Use the default fantasyworld-wan21 variant; it is the validated route.

## Running in WorldFoundry

Generate a world with `wf run fantasyworld-wan21 --pipeline.task-profile official-camera-world`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `acvlab/FantasyWorld-Wan2.1-I2V-14B-480P`, `Wan-AI/Wan2.1-I2V-14B-480P`, and `Ruicheng/moge-2-vitl-normal`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh fantasyworld-wan21`. Add `--download` to fetch missing public checkpoints.
