FantasyWorld 通过统一视频与 3D 预测实现几何一致的世界建模：从一张图生成相机可控、几何连贯的世界视频。提供两个 variant：默认的 Wan2.1 pipeline 与 Wan2.2 pipeline。

论文：[FantasyWorld: Geometry-Consistent World Modeling via Unified Video and 3D Prediction](https://arxiv.org/abs/2509.21657)（2025）。

项目页：[fantasy-amap.github.io/fantasy-world](https://fantasy-amap.github.io/fantasy-world/)。代码：[Fantasy-AMAP/fantasy-world](https://github.com/Fantasy-AMAP/fantasy-world)。

发布方：阿里高德（Fantasy-AMAP），作者含北邮。源码公开，但未附 LICENSE 文件。

运行时需要本地 FantasyWorld Wan2.1（`acvlab/FantasyWorld-Wan2.1-I2V-14B-480P`）、Wan2.1 I2V（`Wan-AI/Wan2.1-I2V-14B-480P`）、**MoGe**（`Ruicheng/moge-2-vitl-normal`）和 CUDA 资产。

## 用来做什么

`fantasyworld-wan21` 是世界生成模型。

FantasyWorld 在 Wan 视频基座上增加统一的 3D 预测分支，使生成帧遵守场景几何（见 arXiv 2509.21657）。该模型由阿里巴巴（高德 Fantasy-AMAP 团队）发布。

任务：geometry-consistent world modeling。别名：`Geometry-Consistent World Modeling via Unified Video and 3D Prediction`。同系列还有 `fantasyworld-wan22`。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（评估几何一致的生成世界）、[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机控制质量评测）。

## 运行时契约

输入 `input-path`、`prompt`、`camera-json-path`（不传时使用内置示例）；参数 `fps`、`seed`、`using-scale`、`conf-threshold`、`stride`；产物 `generated_world`、`fantasyworld-wan21.mp4`。

CLI task profile：`official-camera-world`。绑定的 pipeline 类是 `FantasyWorldPipeline`。

建议从 `fantasyworld-wan21` 开始。该系列共有 2 个 variant，可在上方命令构建器中切换：`fantasyworld-wan21`（`image-to-world-video`）：已验证、`fantasyworld-wan22`（`camera-controlled-world-video`）：Runner 一致性待确认。系列状态：**已验证**。

`official-camera-world` 默认值：fps=16，seed=1024。

请使用默认的 fantasyworld-wan21 variant，这是经过验证的路径。

## 在 WorldFoundry 中运行

用 `wf run fantasyworld-wan21 --pipeline.task-profile official-camera-world` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`acvlab/FantasyWorld-Wan2.1-I2V-14B-480P`、`Wan-AI/Wan2.1-I2V-14B-480P`、`Ruicheng/moge-2-vitl-normal`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh fantasyworld-wan21`；下载缺失的公开权重时加 `--download`。
