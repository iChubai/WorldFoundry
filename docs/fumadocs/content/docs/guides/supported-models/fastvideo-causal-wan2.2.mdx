FastVideo CausalWan2.2 is an **eight-step causal** Wan2.2 rollout: video comes out in **three-latent-frame** blocks while the stack routes between high- and low-noise experts. WorldFoundry keeps expert KV / cross-attention caches independent and owns deterministic **self-forcing re-noise** on a fixed shifted flow schedule. Native roles cover both Wan2.2 experts, T5, VAE, and cache traversal. Pipeline: `FastVideoCausalWanPipeline`. Alias `fastvideo-causal-wan` resolves here. Related HF id: `FastVideo/CausalWan2.2-I2V-A14B-Preview-Diffusers`.

## What it is for

Causal Wan2.2 fast video. Not the full Wan2.2 family card.

Launch `worldfoundry-eval run fastvideo-causal-wan2.2-i2v-14b` with `--pipeline.task-profile image-to-video` and an input image.
