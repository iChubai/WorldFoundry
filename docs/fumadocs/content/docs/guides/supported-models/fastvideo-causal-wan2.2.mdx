FastVideo CausalWan2.2 is an **eight-step causal** Wan2.2 rollout: video comes out in **three-latent-frame** blocks while the stack routes between high- and low-noise experts. WorldFoundry keeps expert KV / cross-attention caches independent and applies **self-forcing re-noise** on a fixed shifted flow schedule. Pipeline: `FastVideoCausalWanPipeline`. Alias `fastvideo-causal-wan` resolves here. Related HF id: `FastVideo/CausalWan2.2-I2V-A14B-Preview-Diffusers`.

## What it is for

Fast eight-step image-to-video with causal Wan2.2. This page covers the CausalWan2.2 I2V preview only, not the full Wan2.2 family.

Launch `wf run fastvideo-causal-wan2.2-i2v-14b` with an input image.

## Runtime contract

Required: `prompt` and `image`; artifacts: `fastvideo-causal-wan2.2-i2v-14b.mp4`.

| Knob | Default |
| --- | --- |
| Size | **832×480 area budget**; 16-pixel-aligned canvas follows the source aspect ratio (1280×704 → 848×464) |
| Frames | **81** from WorldFoundry; FastVideo's current official runner emits **73** for the same 81-frame request |
| Steps | **8** |
| Guidance | **1** |
| FPS | **16** |
| Block | **3** latent frames |

## Running in WorldFoundry

Run `wf run fastvideo-causal-wan2.2-i2v-14b` with an image. Validated with the preview checkpoint: 81-frame inference at 848×464 on an H100. The official FastVideo runner returns 73 frames for the same request because its denoiser drops the final two latent frames; the shared frames match in composition and forward motion, but pixel-level parity is not established because the implementations use different random generators and latent precision.
