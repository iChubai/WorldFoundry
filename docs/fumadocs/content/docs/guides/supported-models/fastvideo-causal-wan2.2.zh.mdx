FastVideo CausalWan2.2 是 **8 步因果** Wan2.2 滚动：视频按**三潜帧**块出来，栈在高噪/低噪专家之间切换。WorldFoundry 让专家 KV / 交叉注意力缓存彼此独立，并在固定的 shifted flow 日程上自己做确定性 **self-forcing 再加噪**。原生角色覆盖两个 Wan2.2 专家、T5、VAE 和缓存遍历。Pipeline：`FastVideoCausalWanPipeline`。别名 `fastvideo-causal-wan` 解析到这里。相关 HF id：`FastVideo/CausalWan2.2-I2V-A14B-Preview-Diffusers`。

## 用来做什么

因果 Wan2.2 快视频。不是完整 Wan2.2 家族卡。

启动 `worldfoundry-eval run fastvideo-causal-wan2.2-t2v-14b --pipeline.task-profile text-to-video`。

## 运行时契约

必填 `prompt`；可选 `image`、`video`；产物 `fastvideo-causal-wan2.2-t2v-14b.mp4`。

| 旋钮 | 默认 |
| --- | --- |
| 尺寸 | **832×480** |
| 帧数 | **717** |
| 步数 | **8** |
| Guidance | **1** |
| FPS | **16** |
| 块 | **3** 潜帧 |

## 在 WorldFoundry 中运行

状态：**Runner 一致性待验证**。统一环境 `worldfoundry-unified-cu128`（Python 3.11, CUDA 12.8）。先把 `FastVideo/CausalWan2.2-I2V-A14B-Preview-Diffusers` 就位到本地，缺文件加载失败，运行时不下载。在该环境执行 `worldfoundry-eval run fastvideo-causal-wan2.2-t2v-14b --pipeline.task-profile text-to-video`。许可证：Apache-2.0。catalog 未记录 VRAM。
