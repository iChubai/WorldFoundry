FastWAM is a world-action model built on the Wan video stack: a mixture-of-transformers (MoT) action-inference graph runs on Wan2.1-T2V-1.3B components (MIT license). Validated with the released checkpoints: the LIBERO and RoboTwin base checkpoints produce finite 32-step action chunks, and the separate LIBERO Optional IDM checkpoint produces finite 8-step chunks in both idm and first_frame modes.

## What it is for

`fastwam` maps camera observations and an instruction to an action trajectory.

The released MoT action-inference graph, Wan VAE, UMT5 encoder, scheduler, preprocessing, and normalization are all in-tree, so no FastWAM source checkout or remote checkpoint code is needed.

Tasks: WAM, robot policy, policy rollout, and embodied benchmark.

Suggested benchmarks: [LIBERO](/docs/evaluation/benchmark-hub/libero) (GPU-validated LIBERO checkpoint variant), [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (GPU-validated RoboTwin checkpoint variant).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `steps`, `seed`, `state`, `variant`, `head-camera`, `left-camera`, and 3 more; artifacts `action_trace` and `fastwam_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `FastWAMPipeline`.

Family status: **Verified**.

Select libero, libero_optional_idm, or robotwin in the runtime data configuration. Optional IDM supports idm (generated-future conditioning) and first_frame modes. Stage yuanty/fastwam plus the Wan-series converted safetensors and Wan2.1-T2V-1.3B tokenizer locally.

## Running in WorldFoundry

Run `wf run fastwam --pipeline.task-profile default` to predict actions.

It runs in the dedicated environment `worldfoundry-vla-fastwam` (Python 3.10, CUDA 12.1+, torch>=2.2).

Recorded weight repositories include `yuanty/fastwam`, `DiffSynth-Studio/Wan-Series-Converted-Safetensors`, and `Wan-AI/Wan2.1-T2V-1.3B` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh fastwam`. Add `--download` to fetch missing public checkpoints.
