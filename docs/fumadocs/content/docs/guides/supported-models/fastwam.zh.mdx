FastWAM 是基于 Wan 视频栈的世界-动作模型：mixture-of-transformers（MoT）动作推理图构建在 Wan2.1-T2V-1.3B 组件之上（MIT 许可）。已用发布权重验证：LIBERO 与 RoboTwin 基础权重输出有限的 32 步动作块，独立的 LIBERO Optional IDM 权重在 idm 与 first_frame 两种模式下输出有限的 8 步动作块。

## 用来做什么

`fastwam` 把相机观测和指令映射为动作轨迹。

发布的 MoT 动作推理图、Wan VAE、UMT5 编码器、调度器、预处理与归一化全部内置树内，无需 FastWAM 源码 checkout，也不执行远程 checkpoint 代码。

任务：wam、机器人策略、策略执行、具身评测。

推荐评测：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（GPU 已验证的 LIBERO checkpoint 变体）、[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（GPU 已验证的 RoboTwin checkpoint 变体）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `steps`、`seed`、`state`、`variant`、`head-camera`、`left-camera` 等 9 项；产物 `action_trace`、`fastwam_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `FastWAMPipeline`。

系列状态：**已验证**。

在运行时配置中选择 libero、libero_optional_idm 或 robotwin。Optional IDM 支持 idm（生成未来视频后预测动作）与 first_frame 模式。需在本地就位 yuanty/fastwam、Wan 系列转换 safetensors 与 Wan2.1-T2V-1.3B tokenizer。

## 在 WorldFoundry 中运行

运行 `wf run fastwam --pipeline.task-profile default` 预测动作。

运行环境：独立环境 `worldfoundry-vla-fastwam`（Python 3.10，CUDA 12.1+，torch>=2.2）。

权重仓库：`yuanty/fastwam`、`DiffSynth-Studio/Wan-Series-Converted-Safetensors`、`Wan-AI/Wan2.1-T2V-1.3B` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh fastwam`；下载缺失的公开权重时加 `--download`。
