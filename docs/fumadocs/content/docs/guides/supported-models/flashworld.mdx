FlashWorld generates 3D scenes in seconds: from one image (plus optional prompt) it produces a camera-navigable 3D scene rather than a flat clip. The image-conditioned camera-scene demo is validated with the released FlashWorld and Wan2.2 assets.

## What it is for

Use `flashworld` for feed-forward 3D reconstruction from the input views.

FlashWorld distills a Wan-based video generator into a fast 3D-scene generator with Gaussian-style scene representations (per arXiv 2510.13678). Execution requires FlashWorld, Wan2.2, diffusers/transformers, and CUDA assets. It is published by Xiamen University / Tencent.

Tasks: fast 3D scene generation from image or text.

Suggested benchmarks: [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Standard scoring for navigable generated scenes).

## Runtime contract

Inputs `input-path` and `prompt` (bundled samples are used when omitted); options `interactions`, `num-frames`, `fps`, `image-height`, `image-width`, and `return-video`; artifacts `generated_3d_asset`, `generated_video`, and `flashworld.ply`.

CLI task profiles: `official-camera-scene`. WorldFoundry binds `FlashWorldPipeline`.

Family status: **Verified**.

Recorded `official-camera-scene` defaults: num_frames=16, fps=15.

Stage imlixinyang/FlashWorld and Wan-AI/Wan2.2-TI2V-5B-Diffusers before running; execution needs a CUDA GPU.

## Running in WorldFoundry

Reconstruct the scene with `wf run flashworld --pipeline.task-profile official-camera-scene`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `imlixinyang/FlashWorld` and `Wan-AI/Wan2.2-TI2V-5B-Diffusers`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh flashworld`. Add `--download` to fetch missing public checkpoints.
