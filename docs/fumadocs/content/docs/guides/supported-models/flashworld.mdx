## Architecture

FlashWorld distills a Wan-based video generator into a fast 3D-scene generator with Gaussian-style scene representations (per arXiv 2510.13678). Execution requires FlashWorld, Wan2.2, diffusers/transformers, and CUDA assets; no empty runner shim is registered.

## Usage notes

Verified for the image-conditioned demo; per-run visual QA is tracked outside the catalog. Execution remains checkpoint/GPU/dependency gated — stage all recorded assets first.
