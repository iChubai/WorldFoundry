FlashWorld 数秒内生成 3D 场景：从一张图（可附提示词）产出可相机游走的 3D 场景，而非平面视频。图像条件的相机场景 demo 已用发布的 FlashWorld 与 Wan2.2 资产验证。

## 用来做什么

用 `flashworld` 从输入视图做前馈 3D 重建。

FlashWorld 将基于 Wan 的视频生成器蒸馏为快速 3D 场景生成器，使用高斯式场景表示（见 arXiv 2510.13678）。运行需要 FlashWorld、Wan2.2、diffusers/transformers 与 CUDA 资产。该模型由厦门大学 / 腾讯发布。

任务：fast 3D scene generation from image or text。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（可游走生成场景的标准评分）。

## 运行时契约

输入 `input-path`、`prompt`（不传时使用内置示例）；参数 `interactions`、`num-frames`、`fps`、`image-height`、`image-width`、`return-video`；产物 `generated_3d_asset`、`generated_video`、`flashworld.ply`。

CLI task profile：`official-camera-scene`。绑定的 pipeline 类是 `FlashWorldPipeline`。

系列状态：**已验证**。

`official-camera-scene` 记录默认值：num_frames=16, fps=15。

运行前请就位 imlixinyang/FlashWorld 与 Wan-AI/Wan2.2-TI2V-5B-Diffusers；执行需要 CUDA GPU。

必填 `prompt`、`image`；可选 `video`；`actions`：camera_path, camera_action_sequence；产物 `generated_3d_asset`、`generated_video`、`flashworld.ply`。

## 在 WorldFoundry 中运行

用 `wf run flashworld --pipeline.task-profile official-camera-scene` 重建场景。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`imlixinyang/FlashWorld`、`Wan-AI/Wan2.2-TI2V-5B-Diffusers`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh flashworld`；下载缺失的公开权重时加 `--download`。
