FramePack 是斯坦福的**恒定记忆**长图生视频模型（由 ControlNet 作者开发）：输入帧上下文被压缩到**定长**窗口，片段变长时生成成本大致不变，有限显存也能生成分钟级视频。WorldFoundry 通过 `FramePackPipeline` 运行最小化的仅推理运行时。

论文：[arXiv 2504.12626](https://arxiv.org/abs/2504.12626)。项目页：[lllyasviel.github.io/frame_pack_gitpage](https://lllyasviel.github.io/frame_pack_gitpage/)。代码：[lllyasviel/FramePack](https://github.com/lllyasviel/FramePack)。公开、非门控权重：`lllyasviel/FramePackI2V_HY` 和 `lllyasviel/FramePack_F1_I2V_HY_20250503`。其 Hugging Face 元数据**未公布许可证**，使用前请审阅上游条款。

## 用来做什么

从起始图像开始，按下一帧块生成长视频。

启动 `wf run framepack`。

评测入口：[ChronoMagic-Bench](/zh/docs/evaluation/benchmark-hub/chronomagic-bench)（长时程生成评测，契合 FramePack 的长视频定位）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `framepack.mp4`。

树内官方 runner 默认值，取自上游 UI 质量配方：

| 旋钮 | 默认 |
| --- | --- |
| 时长 | **5** 秒 |
| FPS | **30** |
| 步数 | 每个 FramePack 段 **25** |
| 潜窗口 | **9** |
| CFG / GS / RS | **1.0** / **10.0** / **0.0** |
| Seed | **31337** |
| TeaCache | **开** |

## 在 WorldFoundry 中运行

状态：**Runner 一致性待确认**。统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。先把 `lllyasviel/FramePackI2V_HY` 和 `lllyasviel/FramePack_F1_I2V_HY_20250503` 就位到本地，再执行 `wf run framepack`。未记录显存需求。
