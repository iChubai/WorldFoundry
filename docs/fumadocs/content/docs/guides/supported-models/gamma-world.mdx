Gamma-World is NVIDIA's multi-agent world model: given per-player start images and one action stream per player, it generates each player's view of a shared world. It runs as a native diffusion recipe with bidirectional, causal, and four-step causal variants; the four-step causal model is the default streaming choice.

Three variants share the same binding: **`gamma-world-causal-few-step`** (default **four-step** streaming), `gamma-world-causal`, and `gamma-world-bidirectional`. Aliases `gammaworld` and `gamma-world-causal` resolve here.

## What it is for

`gamma-world-causal-few-step` generates future frames conditioned on actions.

The model conditions on Reason1 (nvidia/Cosmos-Reason1-7B as text encoder) and decodes with the shared Wan VAE; WorldFoundry handles action normalization and windowed execution. The chijw/Gamma-World weights (apache-2.0) contain the bidirectional, causal, and distilled networks.

Tasks: multi agent world model, action-conditioned video, and image-to-video. Aliases: `gammaworld`, `gamma-world-causal`, and `gamma-world-causal-few-step`. Modalities: image in, video out. Other variants: `gamma-world-causal`, `gamma-world-bidirectional`.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (World-rollout quality under action conditioning).

## Runtime contract

Required `prompt` and start images. Causal and four-step causal inference also require one action track per view, supplied through `actions`/`action_paths` or action JSONs in `eval_dir`; these checkpoints cannot run without actions. Other options include `mode`, `n_players`, `num_frames`, `num_conditional_frames`, `guidance`, `num_steps`, and `seed`. The output is a generated video.

CLI task profiles: `interactive-video`. WorldFoundry binds `GammaWorldPipeline`.

Start with `gamma-world-causal-few-step`. The family has 3 variants, selectable in the command builder above: `gamma-world-causal-few-step` (`action-conditioned-video`) — Runner parity pending; `gamma-world-causal` (`action-conditioned-video`) — Runner parity pending; `gamma-world-bidirectional` (`action-conditioned-video`) — Runner parity pending. Family status: **Runner parity pending**.

Pass a sequence of per-player images plus one action JSON/mapping per player, or a compatible eval_dir. All released variants require `num_frames=189` per view (official `state_t=48`); shorter clips are outside the upstream inference contract. Stage the Gamma-World and Reason1 weights first.

## Running in WorldFoundry

Step the world with `wf run gamma-world-causal-few-step --pipeline.task-profile interactive-video`.

It runs in the dedicated environment `worldfoundry-gamma-world-cu128` (Python 3.10, CUDA 12.8, torch==2.7.0).

Recorded weight repositories include `chijw/Gamma-World`, `nvidia/Cosmos-Reason1-7B`, and `nvidia/Cosmos-Reason1-7B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh gamma-world-causal-few-step`. Add `--download` to fetch missing public checkpoints.
