Gamma-World is NVIDIA's multi-agent world model: given per-player start images and one action stream per player, it generates each player's view of a shared world. In this catalog it is a native diffusion recipe — no external checkout or model-owned runtime — with bidirectional, causal, and four-step causal variants; the four-step causal model is the default streaming choice.

## Architecture

Reason1 conditioning (nvidia/Cosmos-Reason1-7B as text encoder), the shared Wan VAE, checkpoint loading, scheduling, action normalization, and window execution all reuse WorldFoundry's base-model/core infrastructure; the recorded weights (chijw/Gamma-World, apache-2.0) cover bidirectional, causal, and distilled networks.

## Usage notes

Pass a sequence of per-player images plus one action JSON/mapping per player, or a compatible eval_dir. Runner status is checkpoint_environment_required — stage the Gamma-World and Reason1 weights first.
