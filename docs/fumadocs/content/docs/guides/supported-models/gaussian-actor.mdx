## What it is for

`gaussian-actor` is the recorded instruction-to-action line. Start here when you need a WorldFoundry VLA rollout rather than a video generator.

A Gaussian policy head for continuous control: the actor outputs mean and variance of an action distribution, following the LeRobot reference implementation. Further internals are not recorded in this repository. It is published by Hugging Face (LeRobot reference).

Catalog tasks include reinforcement learning, actor policy, and robot policy. Catalog aliases include `gaussian_actor` and `gaussian-policy-actor`.

## Runtime contract

Required `prompt`, `image`, and `state`; optional `model_id` (gaussian-actor), `policy_family`, and `action_representation`; artifacts `action_trace` and `gaussian-actor_action_trace.json`.

Recorded task profiles: `reinforcement_learning`, `actor_policy`, and `robot_policy`. WorldFoundry binds `GaussianActorPipeline`.

Family status: **Runner parity pending**.

Checkpoint absence is reported by runtime missing_assets and is not a catalog blocker; stage a trained actor checkpoint to run real predictions.

No separate official repository was identified; use the concrete LeRobot gaussian_actor policy as reference source.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run gaussian-actor --pipeline.task-profile reinforcement_learning`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `lerobot/gaussian_actor`. Stage assets with `bash scripts/inference/prepare_model_infer.sh gaussian-actor`.

Status: **Runner parity pending**.
