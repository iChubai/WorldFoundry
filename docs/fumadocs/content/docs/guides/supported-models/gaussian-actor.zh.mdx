## 用来做什么

`gaussian-actor` 是记录的指令到动作线。需要 WorldFoundry VLA rollout 而不是视频生成时从这里起步。

面向连续控制的高斯策略头：actor 输出动作分布的均值与方差，遵循 LeRobot 参考实现。更多内部细节仓库未记录。该模型由Hugging Face（LeRobot 参考实现）发布。

catalog 记录的任务包括 reinforcement_learning、actor_policy、机器人策略。别名包括 `gaussian_actor`、`gaussian-policy-actor`。

## 运行时契约

必填 `prompt`、`image`、`state`；可选 `model_id` (gaussian-actor)、`policy_family`、`action_representation`；产物 `action_trace`、`gaussian-actor_action_trace.json`。

记录的任务 profile：`reinforcement_learning`、`actor_policy`、`robot_policy`。绑定的 pipeline 类是 `GaussianActorPipeline`。

系列状态：**Runner 一致性待确认**。

checkpoint 缺失由运行时 missing_assets 报告，不视为 catalog 阻塞；就位训练好的 actor checkpoint 即可运行真实预测。

参考实现条目：无独立官方仓库或权重。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run gaussian-actor --pipeline.task-profile reinforcement_learning`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `lerobot/gaussian_actor`。就位权重用 `bash scripts/inference/prepare_model_infer.sh gaussian-actor`。

状态：**Runner 一致性待确认**。
