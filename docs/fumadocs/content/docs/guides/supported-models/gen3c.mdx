GEN3C generates camera-controlled video with an explicit 3D cache: it builds a rough 3D scene from the input image (via depth), warps it along the requested camera path, and lets the video model fill in the rest — precise camera control with 3D consistency (CVPR 2025). In this catalog it is assembled natively through the same denoiser/conditioner/scheduler contracts as the Cosmos Predict1 family.

## Architecture

Named camera trajectories, MoGe depth, and RGBD forward warping are native preprocessing inside the latent-initializer role; callers may also provide pre-rendered 3D-cache tensors. The stack uses the native T5 conditioner, Karras x0 AB2 scheduler, codec, and loader (license: nvidia-source-code).

## Usage notes

Transformer and T5 checkpoint structure, camera geometry, registry, and scheduler contracts pass local validation, but full-resolution native GPU output parity is pending — earlier official-runtime demo evidence does not carry over to the native path.
