GEN3C 用显式 **3D 缓存**生成**相机可控**视频：先从输入图（借助深度）搭出粗略 3D 场景，沿目标相机路径扭曲该缓存，再让视频模型补全其余部分。发表于 **CVPR 2025**。WorldFoundry 基于 Cosmos Predict1 家族同一套去噪器、T5 条件器、潜变量初始化、**Karras x0 AB2** 调度器、编解码器和加载器原生运行。Pipeline：`Gen3CPipeline`。不需要外部 GEN3C checkout。

<ModelPaperFigures modelId="gen3c" locale="zh" />

命名相机轨迹、**MoGe** 深度和 RGBD 前向扭曲均由潜变量初始化阶段处理。调用方也可以直接提供预渲染的 3D 缓存张量。

论文：[arXiv 2503.03751](https://arxiv.org/abs/2503.03751)。项目页：[research.nvidia.com/labs/toronto-ai/GEN3C](https://research.nvidia.com/labs/toronto-ai/GEN3C/)。代码：[nv-tlabs/GEN3C](https://github.com/nv-tlabs/GEN3C)（**nvidia-source-code**）。权重：`nvidia/GEN3C-Cosmos-7B` 加 `Ruicheng/moge-vitl`。

## 用来做什么

NVIDIA GEN3C 用于生成相机条件世界视频。权重有门控。

启动 `wf run gen3c --pipeline.task-profile official-single-image`。

评测入口：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（受控生成的相机轨迹贴合度）。

## 运行时契约

必填 `prompt`、`image`；可选 `video`；`actions`：camera_trajectory；产物 `gen3c.mp4`。

| 旋钮 | 默认 |
| --- | --- |
| 尺寸 | **1280×704** |
| 帧数 | **121** |
| FPS | **24** |
| 步数 | **35** |
| Guidance | **1.0** |
| 轨迹 | `left`、`center_facing`，距离 **0.3** |
| Seed | **1** |

## 在 WorldFoundry 中运行

统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。先把 `nvidia/GEN3C-Cosmos-7B`、`Ruicheng/moge-vitl` 放到本地，再在该环境执行 `wf run gen3c --pipeline.task-profile official-single-image`。
