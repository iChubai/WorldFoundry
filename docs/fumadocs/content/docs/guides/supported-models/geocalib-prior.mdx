GeoCalib estimates camera calibration and the gravity direction from a single image by combining geometric optimization with deep learning. WorldFoundry exposes it as a camera-calibration prior that higher-level pipelines, notably ViPE, consume through the shared geometry-prior contract.

## What it is for

Use `geocalib-prior` for feed-forward 3D reconstruction from the input views.

A neural network predicts geometric cues which a differentiable optimization layer turns into focal length and gravity estimates (per the upstream ECCV 2024 release). The official code is apache-2.0. It is published by ETH Zurich (CVG).

Tasks: camera calibration, gravity estimation, and geometry prior. Aliases: `geocalib` and `cvg-geocalib`.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `camera-model`, `execute`, and `max-points`; artifacts `geocalib-prior.json`.

CLI task profiles: `default`. WorldFoundry binds `GeoCalibPriorPipeline`.

Family status: **Verified**.

Stage the official geocalib-pinhole.tar weights from the v1.0 GitHub release. Run it directly through the geometry-prior pipeline, or let ViPE call it as its calibration prior.

Single-image estimation: degrades on images without clear geometric cues (e.g. pure sky or texture-less walls).

## Running in WorldFoundry

Run `wf run geocalib-prior --pipeline.task-profile default` to write the geometry.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

No public checkpoint is listed for this model; stage the weights as described in the usage notes. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh geocalib-prior`. Add `--download` to fetch missing public checkpoints.
