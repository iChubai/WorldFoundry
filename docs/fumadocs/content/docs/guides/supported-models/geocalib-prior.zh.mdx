GeoCalib 结合几何优化与深度学习，从单张图像估计相机标定与重力方向。WorldFoundry 将它作为相机标定先验提供，上层管线（尤其是 ViPE）通过共享 geometry-prior 契约调用。

## 用来做什么

用 `geocalib-prior` 从输入视图做前馈 3D 重建。

神经网络预测几何线索，可微优化层将其转化为焦距与重力估计（见上游 ECCV 2024 发布）。官方代码为 apache-2.0。该模型由苏黎世联邦理工学院（CVG 组）发布。

任务：camera-calibration、gravity-estimation、几何先验。别名：`geocalib`、`cvg-geocalib`。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `camera-model`、`execute`、`max-points`；产物 `geocalib-prior.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `GeoCalibPriorPipeline`。

系列状态：**已验证**。

请就位官方 GitHub v1.0 发布的 geocalib-pinhole.tar 权重。可直接通过 geometry-prior pipeline 运行，也可由 ViPE 作为标定先验调用。

单图估计：在缺乏几何线索的图像（如纯天空、无纹理墙面）上会退化。

## 在 WorldFoundry 中运行

运行 `wf run geocalib-prior --pipeline.task-profile default` 写出几何结果。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型未登记公开的 checkpoint；请按使用说明准备权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh geocalib-prior`；下载缺失的公开权重时加 `--download`。
