## What it is for

`geometry-prior` is the recorded reconstruction line. Start here to emit geometry from the documented views.

A contract, not a network: it defines how geometry priors are constructed, invoked, and how their artifacts are exported, so that higher-level pipelines can swap priors through configuration alone. It is published by WorldFoundry (this repository).

Catalog tasks include geometry, 3d-reconstruction, and geometry-prior.

Contract hub for geometry priors — do not launch this id. Pick [DUSt3R](/docs/guides/supported-models/dust3r), [Depth Anything 3 prior](/docs/guides/supported-models/depth-anything-v3-prior), [GeoCalib](/docs/guides/supported-models/geocalib-prior), or [DAP](/docs/guides/supported-models/dap).

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run geometry-prior --pipeline.task-profile geometry`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

The environment profile is not recorded.

Stage assets with `bash scripts/inference/prepare_model_infer.sh geometry-prior`.
