Geometry 不是上游模型——它是 WorldFoundry 的共享几何先验契约面。各个先验（DUSt3R、 Depth Anything、Metric3D、GeoCalib、UniDepth 等）以独立 catalog 条目注册并各自携带溯源，全部通过本条目所描述的 pipeline/operator 契约被调用。

## 用来做什么

`geometry-prior` 是记录的重建线。从记录的视图写出几何时从这里起步。

这是契约而非网络：定义几何先验如何构造、如何调用、产物如何导出，使上层管线仅靠配置即可更换先验。该模型由WorldFoundry（本仓库）发布。

catalog 记录的任务包括 几何估计、3D 重建、几何先验。

几何先验的契约总览——不要启动这个 id。请改用 [DUSt3R](/zh/docs/guides/supported-models/dust3r)、[Depth Anything 3 先验](/zh/docs/guides/supported-models/depth-anything-v3-prior)、[GeoCalib](/zh/docs/guides/supported-models/geocalib-prior) 或 [DAP](/zh/docs/guides/supported-models/dap)。

## 运行时契约

本卡片未记录输入、旋钮或产物。

记录的任务 profile：`geometry`、`3d-reconstruction`、`geometry-prior`。绑定的 pipeline 类是 `GeometryPriorPipeline`。

系列状态：**Runner 一致性待确认**。

不要直接运行本条目；请选择具体的先验条目。 每个先验的一致性证据都在其各自的 catalog 条目上。

仅为契约面——本身没有权重，也不直接产出产物。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run geometry-prior --pipeline.task-profile geometry`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境未记录。

就位权重用 `bash scripts/inference/prepare_model_infer.sh geometry-prior`。

状态：**Runner 一致性待确认**。
