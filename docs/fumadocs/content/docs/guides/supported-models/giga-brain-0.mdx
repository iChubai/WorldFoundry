GigaBrain-0 is GigaAI's 3.5B VLA foundation policy with subtask prediction, released as GigaBrain-0-3.5B-Base and the 0.1 refresh under Apache-2.0. Validated with the GigaBrain-0.1 checkpoint: the in-tree runtime produces a CUDA action_trace using converted LeRobot RoboTwin statistics.

Validated on the **0.1** variant: the public pipeline writes a checkpoint-backed CUDA `action_trace` on an 80 GB GPU using converted LeRobot RoboTwin statistics (about 20.8 GB allocated). The 3.5B-base checkpoint has passed a GPU tensor check only. Official task scores additionally need gated official task data and task-specific `norm_stats` / `delta_mask`.

## What it is for

`giga-brain-0-3.5b-base` maps camera observations and an instruction to an action trajectory.

A 3.5B policy on a PaliGemma tokenizer base using the FAST action tokenizer for discrete action encoding, plus subtask prediction heads.

Tasks: VLA, VLA action prediction, VLA policy rollout, and robot policy. Aliases: `giga_brain_0`, `gigabrain0`, `giga-brain-0.1`, and `GigaBrain-0-3.5B-Base` among others. Other variants: `giga-brain-0.1-3.5b-base`.

Suggested benchmarks: [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (CUDA action trace was produced with converted RoboTwin statistics).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `action_trace` and `giga_brain_0_action_trace.json`.

CLI task profiles: `interactive-video`. WorldFoundry binds `GigaBrain0Pipeline`.

Start with `giga-brain-0-3.5b-base`. The family has 2 variants, selectable in the command builder above: `giga-brain-0-3.5b-base` (`vla.action_prediction`) — Runner parity pending; `giga-brain-0.1-3.5b-base` (`vla.policy_rollout`) — Runner parity pending. Family status: **Verified**.

Stage the PaliGemma tokenizer model and the physical-intelligence FAST tokenizer. PaliGemma is gated (manual review) and requires Hugging Face auth.

Official task scores are not reproduced: they need the gated task-specific norm_stats/delta_mask assets.

## Running in WorldFoundry

Run the policy with `wf run giga-brain-0-3.5b-base --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `open-gigaai/GigaBrain-0-3.5B-Base`, `open-gigaai/GigaBrain-0.1-3.5B-Base`, and `google/paligemma-3b-pt-224` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh giga-brain-0-3.5b-base`. Add `--download` to fetch missing public checkpoints.
