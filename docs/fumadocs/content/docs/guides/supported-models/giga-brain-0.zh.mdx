GigaBrain-0 是极佳科技（GigaAI）的 3.5B VLA 基础策略，支持子任务预测，发布 GigaBrain-0-3.5B-Base 与 0.1 更新版，Apache-2.0 许可。已使用 GigaBrain-0.1 权重验证：树内运行时使用转换的 LeRobot RoboTwin 统计输出 CUDA action_trace。

已在 **0.1** 变体上验证：公开 pipeline 在 80 GB GPU 上用转换后的 LeRobot RoboTwin 统计写出 checkpoint 驱动的 CUDA `action_trace`（约占用 20.8 GB）。3.5B-base 权重仅通过 GPU 张量检查。官方任务分数还需要门控的官方任务数据和任务专用 `norm_stats` / `delta_mask`。

另外需要门控的 `google/paligemma-3b-pt-224`（Hugging Face 认证）和 `physical-intelligence/fast`。

## 用来做什么

`giga-brain-0-3.5b-base` 把相机观测和指令映射为动作轨迹。

3.5B 策略，PaliGemma tokenizer 基座，用 FAST 动作 tokenizer 做离散动作编码，另有子任务预测头。

任务：视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行、机器人策略。别名：`giga_brain_0`、`gigabrain0`、`giga-brain-0.1`、`GigaBrain-0-3.5B-Base` 等。同系列还有 `giga-brain-0.1-3.5b-base`。

推荐评测：[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（CUDA 动作轨迹以转换的 RoboTwin 统计产出）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`giga_brain_0_action_trace.json`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `GigaBrain0Pipeline`。

建议从 `giga-brain-0-3.5b-base` 开始。该系列共有 2 个 variant，可在上方命令构建器中切换：`giga-brain-0-3.5b-base`（`vla.action_prediction`）：Runner 一致性待确认、`giga-brain-0.1-3.5b-base`（`vla.policy_rollout`）：Runner 一致性待确认。系列状态：**已验证**。

需准备 PaliGemma tokenizer 模型与 physical-intelligence FAST tokenizer。PaliGemma 为门控模型（需人工审查），需要 Hugging Face 认证。

## 在 WorldFoundry 中运行

用 `wf run giga-brain-0-3.5b-base --pipeline.task-profile interactive-video` 运行策略。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`open-gigaai/GigaBrain-0-3.5B-Base`、`open-gigaai/GigaBrain-0.1-3.5B-Base`、`google/paligemma-3b-pt-224` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh giga-brain-0-3.5b-base`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
