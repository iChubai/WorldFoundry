GigaWorld-0 is GigaAI's open robotics world-model series: video-generation models for robot data generation, with pretrain and GR1-specialized 2B checkpoints. The WorldFoundry GR1 route generates video from an initial image and a text prompt; it does not consume structured robot actions.

The pipeline also needs `google-t5/t5-11b` and `Wan-AI/Wan2.1-T2V-1.3B-Diffusers`. The legacy T5-11B PyTorch pickle must be converted **once** with weights-only loading to an encoder-only safetensors directory (`scripts/inference/convert_t5_11b_encoder_to_safetensors.py` in an isolated Torch 2.6+ env). Normal inference only reads safetensors.

## What it is for

`giga-world-0` is an action-conditioned world model: actions and a starting frame in, a rollout out.

Two 2B video checkpoints are available under open-gigaai: GigaWorld-0-Video-Pretrain-2b and GigaWorld-0-Video-GR1-2b. The GR1 route also uses a T5-11B text encoder and the Wan VAE.

Tasks: robotics-world-model, video-generation, action-conditioned-generation, and robot-image-to-video. Aliases: `giga_world_0`, `gigaworld-0`, and `gigaworld0`. Output modalities: video.

Suggested benchmarks: [WorldArena](/docs/evaluation/benchmark-hub/worldarena) (WorldArena lists GigaWorld-0 for robot world-model evaluation), [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) (Embodied world-model video prediction quality).

For the policy model in the same family, see [GigaWorld-Policy-0.5](/docs/guides/supported-models/giga-world-policy-0.5).

## Runtime contract

Required `prompt` and `image`; optional `video` and `actions` (robot_action, world_action); artifacts `giga-world-0.mp4`.

Recorded task profiles: `robotics-world-model`, `video-generation`, `action-conditioned-generation`, and `robot-image-to-video`. WorldFoundry binds `GigaWorld0Pipeline`.

Family status: **Runner parity pending**.

Defaults for `robot-image-to-video`: height=480, width=640, num_frames=61, num_inference_steps=30, guidance_scale=1.0, fps=16.

Until the checkpoints and task assets are staged, the pipeline returns **blocked** diagnostics instead of a video.

## Running in WorldFoundry

Step the world with `wf run giga-world-0 --pipeline.task-profile robot-image-to-video`.

It runs in the unified environment `worldfoundry-unified-cu121` (Python 3.11, CUDA 12.1, torch==2.5.1).

Weights: `open-gigaai/GigaWorld-0-Video-Pretrain-2b`, `open-gigaai/GigaWorld-0-Video-GR1-2b`, and `google-t5/t5-11b` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh giga-world-0`. Add `--download` to fetch missing public checkpoints.
