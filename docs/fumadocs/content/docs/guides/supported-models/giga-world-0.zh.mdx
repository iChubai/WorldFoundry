GigaWorld-0 是极佳科技开源的机器人世界模型系列：面向机器人数据生成的视频生成模型，包含 pretrain 与 GR1 专用两个 2B checkpoint。WorldFoundry 的 GR1 入口根据首帧图像和文本提示生成视频，不消费结构化机器人动作。

pipeline 还需要 `google-t5/t5-11b` 和 `Wan-AI/Wan2.1-T2V-1.3B-Diffusers`。旧的 T5-11B PyTorch pickle 必须**转换一次**（仅加载权重），生成仅含编码器的 safetensors 目录（在隔离的 Torch 2.6+ 环境中运行 `scripts/inference/convert_t5_11b_encoder_to_safetensors.py`）。正常推理只读取 safetensors。

## 用来做什么

`giga-world-0` 是动作条件世界模型：输入动作和起始帧，输出推演结果。

open-gigaai 提供两个 2B 视频 checkpoint：GigaWorld-0-Video-Pretrain-2b 与 GigaWorld-0-Video-GR1-2b。GR1 入口还使用 T5-11B 文本编码器和 Wan VAE。该模型由极佳科技（GigaAI）发布。

任务：机器人世界模型、视频生成、action-conditioned-generation、robot-image-to-video。别名：`giga_world_0`、`gigaworld-0`、`gigaworld0`。输出模态为视频。

推荐评测：[WorldArena](/zh/docs/evaluation/benchmark-hub/worldarena)（WorldArena 收录 GigaWorld-0 用于机器人世界模型评测）、[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（具身世界模型视频预测质量）。

同系列的策略模型见 [GigaWorld-Policy-0.5](/zh/docs/guides/supported-models/giga-world-policy-0.5)。

## 运行时契约

必填 `prompt`、`image`；可选 `video`、`actions`（robot_action, world_action）；产物 `giga-world-0.mp4`。

记录的任务 profile：`robotics-world-model`、`video-generation`、`action-conditioned-generation`、`robot-image-to-video`。绑定的 pipeline 类是 `GigaWorld0Pipeline`。

系列状态：**Runner 一致性待确认**。

`robot-image-to-video` 的默认值：height=480, width=640, num_frames=61, num_inference_steps=30, guidance_scale=1.0, fps=16。

checkpoint 与任务资产就位前，pipeline 返回 **blocked** 诊断而不是视频。

## 在 WorldFoundry 中运行

用 `wf run giga-world-0 --pipeline.task-profile robot-image-to-video` 推进世界。

运行环境：统一环境 `worldfoundry-unified-cu121`（Python 3.11，CUDA 12.1，torch==2.5.1）。

权重仓库：`open-gigaai/GigaWorld-0-Video-Pretrain-2b`、`open-gigaai/GigaWorld-0-Video-GR1-2b`、`google-t5/t5-11b` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh giga-world-0`；下载缺失的公开权重时加 `--download`。
