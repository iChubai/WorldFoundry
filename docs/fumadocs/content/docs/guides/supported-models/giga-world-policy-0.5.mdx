GigaWorld-Policy-0.5 is GigaAI's world-action policy: an action-centered Mixture-of-Transformers released as a pretrained initialization (Apache-2.0), riding on Wan2.2-TI2V-5B components for VAE, text encoder, and tokenizer. WorldFoundry executes the exact released MoT and the official action-only diffusion loop in process.

The sharded-safetensors transformer (`open-gigaai/Giga-World-Policy-0.5`, revision `4b68e90c`) is **not** a task-ready policy. Deployment additionally needs a local `norm_stats_delta.json` and, when applicable, a task-finetuned transformer directory.

## What it is for

`giga-world-policy-0.5` maps camera observations and an instruction to an action trajectory.

Tasks: VLA, VLA action prediction, and VLA world action model. Aliases: `giga-world-policy`, `gigaworld-policy`, and `gwp-0.5`.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `action_trace` and `giga_world_policy_0_5_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `GigaWorldPolicyPipeline`.

Family status: **Runner parity pending**.

The released transformer is a pretrained initialization: task deployment additionally requires local post-training statistics (task-specific norm_stats_delta.json) and, when applicable, a task-finetuned transformer directory. All Hub assets must be staged locally; runtime network access is disabled.

Pretrained initialization only — task use requires your own post-training statistics/fine-tune.

## Running in WorldFoundry

Run the policy with `wf run giga-world-policy-0.5 --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch>=2.7.1).

Weights: `open-gigaai/Giga-World-Policy-0.5` and `Wan-AI/Wan2.2-TI2V-5B-Diffusers`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh giga-world-policy-0.5`. Add `--download` to fetch missing public checkpoints.
