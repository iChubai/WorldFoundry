**Publisher:** GigaAI · Company

GigaWorld-Policy-0.5 is GigaAI's world-action policy: an action-centered Mixture-of-Transformers released as a pretrained initialization (Apache-2.0), riding on Wan2.2-TI2V-5B components for VAE, text encoder, and tokenizer. WorldFoundry executes the exact released MoT and the official action-only diffusion loop in process.

## Architecture

An action-centered Mixture-of-Transformers over a Wan2.2-TI2V-5B base: the released sharded-safetensors transformer initializes the policy, and diffusion runs on the action stream only.

## Usage notes

The released transformer is a pretrained initialization: task deployment additionally requires local post-training statistics (task-specific norm_stats_delta.json) and, when applicable, a task-finetuned transformer directory. All Hub assets must be staged locally; runtime network access is disabled.
