GO-1 is the flagship policy of **AgiBot World** (AgiBot with OpenDriveLab): a generalist robot policy released as `agibot-world/GO-1`. WorldFoundry keeps InternVision, InternLM2, the **latent planner**, action expert, diffusion sampler, tokenizer, and preprocessing **in-tree** as `GO1Pipeline`. Runtime executes only staged safetensors and never imports checkpoint-provided Python. Dataset, training, deployment server, evaluator, and robot-control code are excluded.

The design is ViLLA-style: InternVision + InternLM2 form the VLM, a latent planner predicts intermediate latent actions, and a diffusion action expert decodes executable control. Parameter names preserve the official checkpoint contract. The released artifact is a **pretrained foundation**; upstream recommends downstream full fine-tuning. Any fine-tune must stay paired with the exact `dataset_stats.json` from that training run.

## What it is for

Launch `wf run go1`. Required: `image`, `prompt`, `state`, `control_frequency`. Cameras: `cam_high`, `cam_right_wrist`, `cam_left_wrist`. Policy family: `latent_planner_conditioned_diffusion`. Action representation: `checkpoint_defined_action_chunk`. Artifact: `go1_action_trace.json`. This is **not** [Genie Envisioner](/docs/guides/supported-models/genie-envisioner) (world video) and **not** [Galaxea G0Plus](/docs/guides/supported-models/galaxea-vla).

## Runtime contract

Default `agibot_pretrain` contract: **3** cameras, `control_frequency` **30**, action chunk **30**, dims `checkpoint_defined`. Example embodiments:

| Variant | Cameras | State / action | Freq | Chunk |
| --- | --- | --- | --- | --- |
| `agibot_pretrain` (default) | 3 | checkpoint-defined | 30 | 30 |
| `agilex_example` | 3 | 14 / 14 | 30 | 30 |
| `libero_example` | 2 | 8 / 7 | 10 | 10 |

Dedicated env: `worldfoundry-vla-go1` (Python 3.10, CUDA 12.4 or newer, torch 2.6.x, Transformers 4.46.3). Flash Attention 2 is used only on compatible Ampere / Ada / Hopper when installed locally; Turing and Blackwell use the portable shared SDPA path. No kernel or checkpoint is downloaded at runtime.

## Running in WorldFoundry

Stage `agibot-world/GO-1` and run `wf run go1` in `worldfoundry-vla-go1`. Confirm the non-commercial license. Pair any fine-tune with its own `dataset_stats.json`.

## Evaluation

No benchmark is recommended for GO-1. A run writes `go1_action_trace.json`; WorldFoundry does not produce a GO-1 benchmark `scorecard.json`. Do not pair this policy with EWMBench or LIBERO.
