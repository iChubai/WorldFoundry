Hailuo 2.3 is MiniMax's hosted video generation service for image-to-video and joint audio-video generation. You provide a start image (plus an optional prompt) and MiniMax renders the clip on its infrastructure; WorldFoundry submits the request and collects the returned video. The aliases minimax-i2v and minimax_i2v also resolve to this model. Use it to generate with MiniMax inside the Studio workflow without managing GPUs.

## What it is for

`hailuo-2p3` runs on the provider's hosted API; no local checkpoint is needed.

Tasks: audio video, image-to-video, and hosted api. Aliases: `minimax-i2v` and `minimax_i2v`. Modalities: image in, video out.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted).

CLI task profiles: `default`. WorldFoundry binds `Hailuo2p3Pipeline`.

Configure your own MiniMax platform API key and paid account before launching jobs. No weights are downloaded and no local GPU environment is needed; generation happens on the provider side, so cost, quota, and content policy follow your provider account.

MiniMax controls model versioning, so outputs can change over time.

No local weights and no offline mode; reproducibility is limited to the request parameters WorldFoundry stores.

## Running in WorldFoundry

No runtime environment is recorded for this model.
