Hailuo 2.3（海螺 2.3）是 MiniMax 的托管视频生成服务，支持图生视频与音视频联合生成。你提供一张起始图（可附文本提示词），MiniMax 在其基础设施上渲染成片；WorldFoundry 负责提交请求并回收返回的视频。别名 minimax-i2v、minimax_i2v 同样指向该模型。适合在不管理 GPU 的前提下，在 WorldFoundry 的 Studio 工作流中使用 MiniMax 生成。

## 用来做什么

`hailuo-2p3` 通过提供商的托管 API 运行，无需本地 checkpoint。

由服务方托管运行的模型：MiniMax 未公开其架构、参数规模或训练细节。WorldFoundry 提供一条向服务方端点提交请求并回收生成视频产物的 Studio pipeline。

任务：audio-video、图生视频、托管 API。别名：`minimax-i2v`、`minimax_i2v`。模态上，它接受图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（对比托管文/图生视频输出的标准多维质量评测）、[Physics-IQ Original](/zh/docs/evaluation/benchmark-hub/physics-iq)（检验服务方视频模型是否遵循基本物理合理性）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）。

CLI task profile：`default`。绑定的 pipeline 类是 `Hailuo2p3Pipeline`。

系列状态：**Runner 一致性待确认**。

启动任务前，请先配置你自己的 MiniMax 开放平台 API key 与付费账号。本地不下载权重，也不需要 GPU 环境；生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。

模型版本由服务方控制，输出可能随时间变化。

## 在 WorldFoundry 中运行

用 `wf run hailuo-2p3 --pipeline.task-profile default` 调用托管模型。

该模型未记录运行环境。

准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hailuo-2p3`；下载缺失的公开权重时加 `--download`。
