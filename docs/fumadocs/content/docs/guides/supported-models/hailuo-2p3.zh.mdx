Hailuo 2.3（海螺 2.3）是 MiniMax 的托管视频生成服务，本 catalog 将其记录为图生视频与音视频联合生成两类任务。你提供一张起始图（可附文本提示词），它在 MiniMax 的基础设施上渲染出成片—— WorldFoundry 本身不运行该模型。该条目还登记了 minimax-i2v、minimax_i2v 两个别名，旧配置可以继续解析。适合在不管理 GPU 的前提下，把 MiniMax 的生产级生成质量接入 WorldFoundry 的 Studio 工作流。

## 使用要点

Catalog 将该条目标记为 integrated：托管 API 的 Studio pipeline 已可用，但你必须自备服务方的 API key 与账号。本地不会下载任何权重、也不会创建 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。启动任务前，请先在 pipeline 中配置你的 MiniMax 开放平台 key。
