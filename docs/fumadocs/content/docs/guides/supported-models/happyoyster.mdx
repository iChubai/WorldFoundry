## What it is for

`happyoyster` generates a 3D-consistent world rather than a single clip.

HappyOyster is a hosted commercial product; the vendor has not published its architecture. It is published by HappyOyster (commercial product).

Tasks: world model, api product, and world generation.

## Runtime contract
