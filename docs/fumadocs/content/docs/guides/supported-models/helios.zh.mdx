Helios 是北大袁粒课题组的长视频生成系列，覆盖文生视频、图生视频、视频到视频与长视频生成，发布了三个 checkpoint：Helios-Distilled（默认、高效）、Helios-Mid、Helios-Base（最佳质量）。WorldFoundry 以固定 revision 在树内内置其推理实现，三个 checkpoint 均以 variant 形式暴露。常驻的 Distilled 会话保留原生 9 潜变量/33 帧历史，并允许在分段之间更换提示词。

## 架构

Helios 以 33 帧为块生成视频；树内 pipeline 会把请求帧数向上取整到兼容的块数。manifest 记录了 group offloading 与多卡上下文并行等运行时选项。注意已记录的 Base 冒烟测试：真实 A100 上以 384x640/33 帧、三步 [1,1,1] 金字塔完成加载与解码——它验证的是链路可跑与产物非空，而非官方 [20,20,20] 质量配方。

## 使用要点

默认用 Helios-Distilled；出成品换 Base（耗时显著增加）。runner 状态为 pending_visual_qa：轻量导入预检已有单测覆盖，但完整 240 请求帧的视觉一致性还需专用 Helios 环境与 GPU 执行。Helios 不提供键盘相机控制——唯一的交互是在块边界更新提示词。
