HelixWorld Preview v1 generates camera-controlled video and spatial audio together from one image and three scene descriptions.

```python
from worldfoundry.pipelines.helixworld import HelixWorldPipeline

pipeline = HelixWorldPipeline.from_pretrained(device="cuda")
result = pipeline(
    prompt="A forest path with rustling leaves as the camera walks forward.",
    audio_prompt="Footsteps on gravel, birds and wind in the trees.",
    av_prompt="The footsteps and sound field follow the camera movement.",
    images="first_frame.png",
    actions="W:5,right:5,stop:5",
    perspective="first_person",
    num_frames=121,
    seed=42,
    output_path="outputs/helixworld.mp4",
    return_dict=True,
)
```

The MP4 includes generated audio. `result` also exposes the waveform, sampling rate and video tensor. For existing assets, pass the checkpoint file as `model_path` and the Gemma directory as `text_encoder_path`.

Actions are `W`, `A`, `S`, `D`, `left`, `right`, `up`, `down` and `stop`. Combine keys with `+`, for example `W+right:5`. Durations count latent transitions: 121 frames require 15 transitions. The final segment may omit its duration to fill the remaining transitions. Both `first_person` and `third_person` perspectives are supported.

The default is 768×512 at 24 FPS. Frame counts are 121, 153, 185, …; inference uses four stochastic updates per four-latent-frame chunk. Each chunk rebuilds context from the initial chunk and the two most recent chunks. The sampling generator is separate from initialization, matching the released seed offset.

Validated with the full checkpoint on an H100 80 GB (BF16, default block offload): a 768×512, 121-frame run produces an MP4 with 48 kHz stereo audio in about 24 seconds after loading, peaking at 26.0 GiB allocated CUDA memory.

## What it is for

Use `helixworld` to step a world forward with actions and render the resulting frames.

LTX-2.3 joint audio/video transformer with action timestep embeddings, camera PRoPE, four-step stochastic sampling and bounded clean-context replay. It is published by Noiz AI.

Tasks: image-to-video, action-conditioned video, camera pose-controlled video, and audio video generation. Aliases: `helixworld-preview`, `helix-world`, and `NoizAI/HelixWorld-preview`. Modalities: image, action, and camera pose in, video and audio out.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `frames`, `fps`, `height`, `width`, `steps`, `guidance-scale`, and 1 more; artifact `helixworld.mp4`.

CLI task profile: `interactive-video`. WorldFoundry binds `HelixWorldPipeline`. Family status: **Runner parity pending**. Defaults for `interactive-video`: frames=121, fps=24, height=512, width=768, steps=4, guidance-scale=1.0.

Preview inference is released; full-model training code and the technical report are forthcoming.

## Running in WorldFoundry

Step the world with `wf run helixworld --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `NoizAI/HelixWorld-preview` and `google/gemma-3-12b-it-qat-q4_0-unquantized`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh helixworld`. Add `--download` to fetch missing public checkpoints.
