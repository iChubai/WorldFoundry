## What it is for

Use `hma-magvit-362m` to generate an explorable world.

Per the paper (arXiv 2502.04296), masked autoregression over video tokens handles heterogeneous action spaces through modality-specific heads; discrete (hma-base-disc) and continuous (hma-base-cont) checkpoints are published under liruiw (apache-2.0). It is published by Massachusetts Institute of Technology (MIT).

Tasks: robot world model, action-conditioned video, and video dynamics. Aliases: `hma-magvit-362m` and `hma-mar-1b`. Other variants: `hma-mar-1b`.

Suggested benchmarks: [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) (Embodied world-model video prediction quality).

## Runtime contract

Inputs `input-path`, `load.checkpoint-dir`, and `load.base-model-dir` (bundled samples are used when omitted); options `generated-frames`, `prompt-horizon`, `maskgit-steps`, `direction`, `action-scale`, `fps`, and 3 more; artifact `hma.mp4`.

Start with `hma-magvit-362m`. The family has 2 variants, selectable in the command builder above: `hma-magvit-362m` (`robot-action-video`) — Runner parity pending; `hma-mar-1b` (`robot-action-video`) — Runner parity pending. Family status: **Runner parity pending**.

Stage the official HMA source at the pinned commit and the HMA checkpoint. The continuous model also needs the Stable Video Diffusion temporal VAE; the discrete model needs the official MAGVIT2 tokenizer checkpoint. For a paired rollout, pass trajectory_path with prompt frames and raw LangTable delta actions.

The default route repeats one image and a constant action; it is a smoke configuration, so pass trajectory_path for a real paired rollout. Research-scale resolution: outputs target dynamics fidelity, not cinematic quality.

## Running in WorldFoundry

Generate a world with `wf run hma-magvit-362m --pipeline.task-profile robot-action-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `liruiw/hma-base-cont`, `liruiw/hma-base-disc`, and `stabilityai/stable-video-diffusion-img2vid`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh hma-magvit-362m`. Add `--download` to fetch missing public checkpoints.
