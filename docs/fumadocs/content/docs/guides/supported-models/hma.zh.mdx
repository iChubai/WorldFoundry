HMA（异构掩码自回归）跨异构机器人形态与数据集建模「动作-视频」动力学，速度足以支撑实时交互。variant 覆盖 MAGVIT 风格的 362M 离散模型与 1B MAR 连续模型。WorldFoundry 从本地就位的官方源码运行生成器；checkpoint 与机器人资产需在本地就位。

## 用来做什么

用 `hma-magvit-362m` 生成可探索的世界。

按论文（arXiv 2502.04296），对视频 token 的掩码自回归通过按模态划分的输出头处理异构动作空间；liruiw 发布了离散（hma-base-disc）与连续（hma-base-cont）checkpoint（apache-2.0）。该模型由麻省理工学院（MIT）发布。

任务：机器人世界模型、动作条件视频、视频动力学。别名：`hma-magvit-362m`、`hma-mar-1b`。同系列还有 `hma-mar-1b`。

推荐评测：[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（具身世界模型视频预测质量）。

## 运行时契约

输入 `input-path`、`load.checkpoint-dir`、`load.base-model-dir`（不传时使用内置示例）；参数 `generated-frames`、`prompt-horizon`、`maskgit-steps`、`direction`、`action-scale`、`fps` 等 9 项；产物 `hma.mp4`。

CLI task profile：`robot-action-video`。绑定的 pipeline 类是 `HMAPipeline`。`robot-action-video` 的默认值：fps=2, seed=42。

建议从 `hma-magvit-362m` 开始。该系列共有 2 个 variant，可在上方命令构建器中切换：`hma-magvit-362m`（`robot-action-video`）：Runner 一致性待确认、`hma-mar-1b`（`robot-action-video`）：Runner 一致性待确认。系列状态：**Runner 一致性待确认**。

就位固定 commit 的 HMA 官方源码与 HMA checkpoint。连续模型还需要 Stable Video Diffusion 时序 VAE；离散模型需要官方 MAGVIT2 tokenizer 权重。运行配对轨迹时，通过 trajectory_path 传入历史帧与原始 LangTable 增量动作。

默认路径重复同一张图并施加恒定动作，只是 smoke 配置；真实配对轨迹需传入 trajectory_path。研究规模分辨率：输出以动力学保真为先，而非影视级画质。

## 在 WorldFoundry 中运行

用 `wf run hma-magvit-362m --pipeline.task-profile robot-action-video` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`liruiw/hma-base-cont`、`liruiw/hma-base-disc`、`stabilityai/stable-video-diffusion-img2vid`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hma-magvit-362m`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
