## 架构

按论文（arXiv 2502.04296），对视频 token 的掩码自回归通过按模态划分的输出头处理异构动作空间；记录了 liruiw 下的离散（hma-base-disc）与连续（hma-base-cont）checkpoint（apache-2.0）。源码固定在记录的 commit。
