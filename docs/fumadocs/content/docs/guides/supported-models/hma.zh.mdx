## 用来做什么

`hma-magvit-362m` 是记录的交互世界线。要用动作推进世界时从这里起步。

按论文（arXiv 2502.04296），对视频 token 的掩码自回归通过按模态划分的输出头处理异构动作空间；记录了 liruiw 下的离散（hma-base-disc）与连续（hma-base-cont）checkpoint（apache-2.0）。源码固定在记录的 commit。该模型由麻省理工学院（MIT）发布。

catalog 记录的任务包括 机器人世界模型、动作条件视频、video-dynamics、robot-action-video。别名包括 `hma-magvit-362m`、`hma-mar-1b`。同系列还有 `hma-mar-1b`。

记录的评测入口包括[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（具身世界模型视频预测质量）。
