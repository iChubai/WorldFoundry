## Architecture

Per the upstream release, GameCraft builds on HunyuanVideo with unified continuous action-space injection and history-conditioned autoregressive extension. The infer-only runtime is retained in-tree and rejects external source roots; its Python 3.10 / torch 2.5.1 stack stays isolated in the documented HYGameCraft environment (license: tencent-hunyuan-community).

## Usage notes

Official inference uses the HYGameCraft conda profile and torchrun dispatch — plan for a multi-GPU host. Per-run visual QA is tracked outside the catalog.
