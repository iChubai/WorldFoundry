## What it is for

Use `hunyuan-game-craft` when the viewpoint must follow a given camera path.

HunyuanVideo transformer with a GameCraft camera network and history-conditioned autoregressive sampling. It is published by Tencent (Hunyuan).

Tasks: interactive world model, image-to-video, and camera control. Aliases: `hunyuan-gamecraft` and `gamecraft`. Modalities: image in, video out.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Action-following world-rollout quality).

## Runtime contract

Inputs `image` and `prompt` (bundled samples are used when omitted); options `interactions`, `frames`, `fps`, `height`, `width`, `steps`, and 1 more; artifacts `hunyuan-game-craft.mp4`.

CLI task profiles: `official-interactive-video`. WorldFoundry binds `HunyuanGameCraftPipeline`.

Family status: **Runner parity pending**.

Defaults for `official-interactive-video`: frames=129, fps=24, height=704, width=1216.

Provide local GameCraft checkpoints. Each action generates 33 frames; explicit num_frames must equal 33 times the action count. CPU offload and output_path export are supported. Validated on a single H100 with CPU offload: one forward action produces 33 frames at 1216x704 with 50 steps.

## Running in WorldFoundry

Generate a camera-controlled clip with `wf run hunyuan-game-craft --pipeline.task-profile official-interactive-video`.

It runs in the dedicated environment `HYGameCraft` (Python 3.10, CUDA 12.4, torch==2.5.1).

Weights: `tencent/Hunyuan-GameCraft-1.0`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh hunyuan-game-craft`. Add `--download` to fetch missing public checkpoints.
