## 用来做什么

视角需要沿指定相机路径运动时，用 `hunyuan-game-craft`。

HunyuanVideo Transformer 结合 GameCraft 相机网络与历史条件自回归采样。该模型由腾讯（混元）发布。

任务：交互式世界模型、图生视频、相机控制。别名：`hunyuan-gamecraft`、`gamecraft`。模态上，它接受图像，输出视频。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作跟随的世界滚动生成质量）。

## 运行时契约

输入 `image`、`prompt`（不传时使用内置示例）；参数 `interactions`、`frames`、`fps`、`height`、`width`、`steps` 等 7 项；产物 `hunyuan-game-craft.mp4`。

CLI task profile：`official-interactive-video`。绑定的 pipeline 类是 `HunyuanGameCraftPipeline`。

系列状态：**Runner 一致性待确认**。

`official-interactive-video` 的默认值：frames=129, fps=24, height=704, width=1216。

就位本地 GameCraft 权重。每个动作生成 33 帧；显式 num_frames 必须等于动作数量乘以 33。支持 CPU offload 与 output_path 导出。已在单张 H100 上以 CPU offload 验证：单个前进动作以 50 步生成 1216x704 的 33 帧。

## 在 WorldFoundry 中运行

用 `wf run hunyuan-game-craft --pipeline.task-profile official-interactive-video` 生成相机可控视频。

运行环境：独立环境 `HYGameCraft`（Python 3.10，CUDA 12.4，torch==2.5.1）。

权重仓库：`tencent/Hunyuan-GameCraft-1.0`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hunyuan-game-craft`；下载缺失的公开权重时加 `--download`。
