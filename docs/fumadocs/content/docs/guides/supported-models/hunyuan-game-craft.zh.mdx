## 用来做什么

`hunyuan-game-craft` 是记录的相机控制路由。按 catalog 相机路径推进时从这里起步。

按上游发布，GameCraft 基于 HunyuanVideo，采用统一连续动作空间注入与历史条件自回归扩展。仅推理运行时保留在树内并拒绝外部源码根；其 Python 3.10 / torch 2.5.1 栈隔离在文档化的 HYGameCraft 环境中（许可：tencent-hunyuan-community）。该模型由腾讯（混元）发布。

catalog 记录的任务包括 交互式世界模型、图生视频、相机控制、official-interactive-video。别名包括 `hunyuan-gamecraft`、`gamecraft`。模态上，它接受图像，输出视频。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作跟随的世界滚动生成质量）。

官方推理使用 HYGameCraft conda 档案与 torchrun 分发——请准备多卡主机。
