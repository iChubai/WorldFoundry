## 架构

按上游发布，GameCraft 基于 HunyuanVideo，采用统一连续动作空间注入与历史条件自回归扩展。仅推理运行时保留在树内并拒绝外部源码根；其 Python 3.10 / torch 2.5.1 栈隔离在文档化的 HYGameCraft 环境中（许可：tencent-hunyuan-community）。

## 使用要点

官方推理使用 HYGameCraft conda 档案与 torchrun 分发——请准备多卡主机。每次运行的视觉 QA 在 catalog 外跟踪。
