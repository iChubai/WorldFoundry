## Architecture

Same shared-native-runner design as the hunyuanvideo entry: HunyuanVideo 1.5 owns only model-specific network, codec, and conditioning behavior, while assembly, loading, and scheduling come from the shared diffusion infrastructure. generate.py is not retained as a second inference architecture.

## Usage notes

Registry resolution is verified; native checkpoint-backed CUDA parity is pending. Two gates to clear before running I2V: the main checkpoints carry 'other' HF license metadata, and FLUX.1-Redux-dev is gated with a non-commercial license that the manifest says needs review — accept its terms on Hugging Face first.
