HunyuanVideo 1.5 is the newer revision of Tencent's open video family, with separate text-to-video and image-to-video variants. Unlike the original, the I2V variant needs the gated FLUX.1-Redux-dev vision checkpoint staged as its own download.

## What it is for

Start on `hunyuanvideo-1.5-t2v`. Launch `wf run hunyuanvideo-1.5-t2v`. Use `hunyuanvideo-1.5-i2v` only after accepting the gated FLUX.1-Redux-dev terms.

[VBench](/docs/evaluation/benchmark-hub/vbench) is the listed T2V suite.

## Runtime contract

Required `prompt`; `actions` is seed. Default artifact `hunyuanvideo-1.5-t2v.mp4`. Variants: `hunyuanvideo-1.5-t2v`, `hunyuanvideo-1.5-i2v`. The I2V variant also needs the gated `black-forest-labs/FLUX.1-Redux-dev` vision checkpoint, staged separately.

## Running in WorldFoundry

Unified `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `tencent/HunyuanVideo-1.5`. Main weights carry `other` license metadata; review the terms before commercial use. Accept FLUX.1-Redux-dev terms on Hugging Face before I2V.
