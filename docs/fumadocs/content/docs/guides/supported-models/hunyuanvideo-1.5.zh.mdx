HunyuanVideo 1.5 是腾讯开源视频系列的较新版本，提供独立的文生视频与图生视频变体。与初代不同，I2V 变体需要单独就位 gated 的 FLUX.1-Redux-dev 视觉 checkpoint。

## 用来做什么

从 `hunyuanvideo-1.5-t2v` 开始。启动 `wf run hunyuanvideo-1.5-t2v`。只有接受 gated FLUX.1-Redux-dev 条款后才跑 `hunyuanvideo-1.5-i2v`。

列出的文生视频评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)。

## 运行时契约

必填 `prompt`；`actions` 是 seed。默认产物 `hunyuanvideo-1.5-t2v.mp4`。变体：`hunyuanvideo-1.5-t2v`、`hunyuanvideo-1.5-i2v`。图生视频变体还需要单独就位 gated 的 `black-forest-labs/FLUX.1-Redux-dev` 视觉 checkpoint。

## 在 WorldFoundry 中运行

统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。就位 `tencent/HunyuanVideo-1.5`。主权重 license 元数据为 `other`，商用前请审阅条款。跑 I2V 前先在 Hugging Face 接受 FLUX.1-Redux-dev 条款。
