## 架构

与 hunyuanvideo 条目相同的共享原生 runner 设计：HunyuanVideo 1.5 只拥有模型特有的网络、编解码与条件行为，装配、加载与调度均来自共享扩散基础设施。generate.py 没有被保留为第二套推理架构。

## 使用要点

注册表解析已验证；原生 checkpoint 加载的 CUDA 一致性仍在等待。运行 I2V 前有两道门槛：主 checkpoint 的 HF 许可元数据为“other”；FLUX.1-Redux-dev 为 gated 且许可为非商用（manifest 要求审阅）——请先在 Hugging Face 接受其条款。
