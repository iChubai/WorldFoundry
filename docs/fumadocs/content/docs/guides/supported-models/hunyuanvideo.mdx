HunyuanVideo is a novel open-source video foundation model that exhibits performance in video generation that is comparable to, if not superior to, leading closed-source models.

Training combines data curation, image-video joint model training, and an infrastructure built for large-scale training and inference. By scaling both the architecture and the dataset, the authors trained a video generative model with over 13 billion parameters. The design work targets visual quality, motion diversity, text-video alignment, and generation stability. In the official professional human study — 1,533 prompts, one inference pass each, more than 60 evaluators — HunyuanVideo ranks above Runway Gen-3, Luma 1.6, and three top-performing Chinese video models on the overall metric, especially motion quality. That comparison uses the high-quality version, which the authors distinguish from the released fast version.

The paper is [HunyuanVideo: A Systematic Framework For Large Video Generation Model](https://arxiv.org/abs/2412.03603) (arXiv, 2024).

The same foundation was later extended as HunyuanVideo-I2V. Image-to-video generation reconstructs the reference image with a token-replace method, concatenates MLLM semantic image tokens with video latents for full-attention multimodal generation, and ships LoRA training code for customizable special effects.

## Architecture

HunyuanVideo is trained in a spatial-temporally compressed latent space produced by a Causal 3D VAE. A large language model encodes the text prompt as the condition; the generator takes Gaussian noise plus that condition and outputs a latent, which the 3D VAE decoder turns into an image or a video.

The backbone is a Transformer with Full Attention and a Dual-stream to Single-stream layout: video and text tokens first pass through separate blocks so each modality can learn its own modulation, then they are concatenated and fused in later blocks.

### Text encoder

The text encoder is a pre-trained decoder-only multimodal LLM rather than CLIP or T5-XXL. After visual-instruction finetuning it aligns image and text more tightly than T5, describes detail and follows complex reasoning better than CLIP, and can attend to key phrases when a system instruction is prepended to the user prompt. Because the MLLM uses causal attention, an extra bidirectional token refiner is added to strengthen the text features.

### Causal 3D VAE

The CausalConv3D VAE compresses pixel-space video and images by 4× in time, 8× in space, and 16 channels, so the diffusion transformer can train at the original resolution and frame rate.

<figure className="wf-recipe-media is-diagram">
  <img src="/models/hunyuanvideo/3dvae.png" alt="CausalConv3D VAE — temporal 4×, spatial 8×, 16-channel latent" />
  <figcaption>CausalConv3D VAE — temporal 4×, spatial 8×, 16-channel latent</figcaption>
</figure>

User prompts vary in style and length, so a Hunyuan-Large rewrite model maps them into a form the generator prefers. Normal mode follows the user's intent more closely; Master mode adds composition, lighting, and camera movement, which can improve visual quality but sometimes drops semantic details.

### Image-to-video

HunyuanVideo-I2V keeps this stack and inserts the reference image by token replace: the MLLM emits semantic image tokens that are concatenated with the video latents for full-attention computation across both modalities.

## Inference

Official inference covers text-to-video and image-to-video at 540p and 720p (recommended), 129 frames, and 9:16, 16:9, 4:3, 3:4, and 1:1. At batch size 1 the peak memory is 60GB for 720×1280×129 and 45GB for 544×960×129; I2V at 720p is also listed at 60GB. The authors tested on a single 80GB GPU and recommend 80GB for quality. For I2V, `--i2v-stability` with flow-shift 7.0 gives more stable motion; turning stability off and using flow-shift 17.0 gives more dynamic motion. FP8 T2V weights save about 10GB of GPU memory.
