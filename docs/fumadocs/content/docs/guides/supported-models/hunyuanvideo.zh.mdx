HunyuanVideo 是一个全新的开源视频生成大模型，具有与领先的闭源模型相媲美甚至更优的视频生成表现。

训练上结合了数据整理、图像-视频联合训练，以及面向大规模训练与推理的基础设施。通过扩展模型结构与数据集，官方训练了超过 130 亿参数的视频生成模型。结构设计面向视觉质量、运动多样性、文本-视频对齐和生成稳定性。专业人工评测使用 1,533 条 prompt、每个 prompt 仅推理一次、60 多名评估人员；综合指标上优于 Runway Gen-3、Luma 1.6 和 3 个中文社区表现最好的视频生成模型，运动质量尤为突出。该对比基于高质量版本，与已发布的 fast 版本不同。

论文为 [HunyuanVideo: A Systematic Framework For Large Video Generation Model](https://arxiv.org/abs/2412.03603)（arXiv, 2024）。

## 架构

HunyuanVideo 在因果 3D VAE 压缩后的时空潜空间上训练。文本提示由大语言模型编码为条件；生成模型以高斯噪声和该条件为输入，输出隐变量，再由 3D VAE 解码器还原为图像或视频。

骨干是带 Full Attention 的 Transformer，采用「双流到单流」结构：视频与文本 token 先经独立 Block 学习各自的调制，再拼接后在后续 Block 中融合。

### 文本编码器

文本编码器是预训练的 Decoder-Only 多模态大语言模型，而不是 CLIP 或 T5-XXL。指令微调后，它的图文对齐强于 T5，细节描述与复杂推理强于 CLIP，并且可以跟随写在用户提示前的系统指令。由于 MLLM 使用因果注意力，官方额外加入双向 token 优化器以增强文本特征。

### 因果 3D VAE

CausalConv3D VAE 将像素空间视频与图像按时间 4 倍、空间 8 倍、通道 16 压缩，使后续扩散 Transformer 能在原始分辨率和帧率下训练。

<figure className="wf-recipe-media is-diagram">
  <img src="/models/hunyuanvideo/3dvae.png" alt="CausalConv3D VAE：时间 4 倍、空间 8 倍压缩，16 通道潜空间" />
  <figcaption>CausalConv3D VAE：时间 4 倍、空间 8 倍压缩，16 通道潜空间</figcaption>
</figure>

用户提示的风格和长度差异很大，因此用微调后的 Hunyuan-Large 做 Prompt 改写。正常模式更贴近用户意图；导演模式补充构图、光照和镜头运动，视觉质量更高，但有时会丢掉部分语义。

### 图生视频

HunyuanVideo-I2V 沿用上述结构，并用 token replace 写入参考图：MLLM 给出的语义图像 token 与视频潜变量拼接后，在图文两个模态上做全注意力计算。

## 推理

官方推理覆盖文生视频与图生视频，分辨率 540p 与 720p（推荐），129 帧，画幅 9:16、16:9、4:3、3:4 与 1:1。batch size 为 1 时，720×1280×129 峰值显存 60GB，544×960×129 为 45GB；I2V 720p 同样记为 60GB。官方在单张 80GB GPU 上测试，并建议用 80GB 以获得更好质量。I2V 若追求更稳，可打开 `--i2v-stability` 并将 flow-shift 设为 7.0；若追求更强动态，则关闭 stability、flow-shift 设为 17.0。FP8 T2V 权重大约节省 10GB 显存。
