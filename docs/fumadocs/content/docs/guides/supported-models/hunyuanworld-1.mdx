## What it is for

`hunyuanworld-1` generates a 3D-consistent world rather than a single clip.

Per the upstream release, generation goes panorama-first: a panoramic proxy is generated, semantically layered, and lifted to a 3D world representation. It is published by Tencent (Hunyuan).

Tasks: world model.

Suggested benchmarks: [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Standard scoring for generated explorable worlds).

## Runtime contract

Artifacts `generated_world` and `hunyuanworld_1_runtime_plan.json`.

CLI task profiles: `default`. WorldFoundry binds `HunyuanWorld1Pipeline`.

Family status: **Runner parity pending**.

Until the required checkpoints and assets are staged, a run returns a runtime plan that lists the missing assets instead of generating. For the newer stack, see hy-world-2.0.

Superseded by HY-World 2.0 for most world-generation use.

## Running in WorldFoundry

Generate a world with `wf run hunyuanworld-1 --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `tencent/HunyuanWorld-1`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh hunyuanworld-1`. Add `--download` to fetch missing public checkpoints.
