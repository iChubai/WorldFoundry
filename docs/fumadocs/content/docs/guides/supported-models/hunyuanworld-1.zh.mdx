## 用来做什么

`hunyuanworld-1` 生成 3D 一致的世界，而不只是一段视频。

按上游发布，生成以全景为先：先生成全景代理图，再做语义分层并提升为 3D 世界表示。该模型由腾讯（混元）发布。

任务：世界模型。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（生成可探索世界的标准评分）。

## 运行时契约

产物 `generated_world`、`hunyuanworld_1_runtime_plan.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `HunyuanWorld1Pipeline`。

系列状态：**Runner 一致性待确认**。

所需 checkpoint 与资产就位前，运行只输出列出缺失资产的运行时计划，不会生成内容。较新的栈请见 hy-world-2.0。

多数世界生成用途已被 HY-World 2.0 取代。

## 在 WorldFoundry 中运行

用 `wf run hunyuanworld-1 --pipeline.task-profile default` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`tencent/HunyuanWorld-1`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hunyuanworld-1`；下载缺失的公开权重时加 `--download`。
