HunyuanWorld-Mirror is Tencent's universal 3D reconstruction model: feed it images and it returns point clouds, Gaussian splats, depth, normals, and camera parameters in one pass. Validated with the tencent/HunyuanWorld-Mirror checkpoint: GPU inference produces point-cloud PLY, Gaussian-splat PLY, depth maps, normal maps, and a scene.rrd.

## What it is for

`hunyuanworld-mirror` recovers 3D geometry from images: views in, a reconstruction, camera trajectory, or point cloud out.

WorldFoundry runs the model through HunyuanMirrorPipeline with bundled inference code; the official repository is not needed at runtime. The environment needs onnxruntime, pycolmap, open3d, and gsplat. It is published by Tencent (Hunyuan).

Tasks: 3D reconstruction. Aliases: `hunyuan-mirror` and `hy-world-mirror`.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `confidence-percentile`, `edge-normal-threshold`, `edge-depth-threshold`, `apply-confidence-mask`, `apply-edge-mask`, `apply-sky-mask`, and 6 more; artifacts `hunyuan_mirror_outputs.zip`.

CLI task profiles: `default`. WorldFoundry binds `HunyuanMirrorPipeline`.

Family status: **Verified**.

HunyuanMirrorPipeline accepts image, input, images, or image_path payloads and writes reconstruction artifacts to the sample output directory. gsplat may need a CUDA/PyTorch-specific wheel that matches the local torch build.

Requires GPU-compatible torch/gsplat packages in the runtime environment.

Dependencies mirror the official HunyuanWorld-Mirror requirements. gsplat may need a CUDA/PyTorch-specific wheel matching the local torch build.

## Running in WorldFoundry

Reconstruct the scene with `wf run hunyuanworld-mirror --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `tencent/HunyuanWorld-Mirror`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh hunyuanworld-mirror`. Add `--download` to fetch missing public checkpoints.
