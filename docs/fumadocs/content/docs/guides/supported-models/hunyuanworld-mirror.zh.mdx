**发表机构:** 腾讯（混元） · 企业

HunyuanWorld-Mirror 是腾讯的通用 3D 重建模型：输入图像，一次前向返回点云、高斯泼溅、深度、法线与相机参数。本 catalog 中它已验证——使用本地 tencent/HunyuanWorld-Mirror 资产的 GPU 推理产出点云 PLY、高斯泼溅 PLY、深度图、法线图与 scene.rrd。

## 架构

WorldFoundry 通过树内 HunyuanMirrorPipeline 与内置的仅推理 WorldMirror 模型代码执行推理；官方仓库仅作一致性核对的溯源，不是运行时依赖。第三方包（onnxruntime、pycolmap、open3d、gsplat）是环境依赖，不是 catalog 阻塞。

## 使用要点

HunyuanMirrorPipeline 接受标准 pipeline runner 传入的 image、input、images 或 image_path 负载，并把重建产物写入样例输出目录。真实推理需要配置好的 Python 环境、本地 checkpoint 与 GPU 兼容的 torch/gsplat。
