## 用来做什么

`hunyuanworld-mirror` 从图像恢复 3D 几何：输入多视图，输出重建结果、相机轨迹或点云。

WorldFoundry 通过 HunyuanMirrorPipeline 和内置的推理代码运行该模型，运行时不需要官方仓库。运行环境需要 onnxruntime、pycolmap、open3d 与 gsplat。该模型由腾讯（混元）发布。

任务：3D 重建。别名：`hunyuan-mirror`、`hy-world-mirror`。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `confidence-percentile`、`edge-normal-threshold`、`edge-depth-threshold`、`apply-confidence-mask`、`apply-edge-mask`、`apply-sky-mask` 等 12 项；产物 `hunyuan_mirror_outputs.zip`。

CLI task profile：`default`。绑定的 pipeline 类是 `HunyuanMirrorPipeline`。

系列状态：**已验证**。

HunyuanMirrorPipeline 接受 image、input、images 或 image_path 负载，并把重建产物写入样例输出目录。gsplat 可能需要与本地 torch 构建匹配的 CUDA/PyTorch 专用 wheel。

运行环境需要 GPU 兼容的 torch/gsplat 包。

## 在 WorldFoundry 中运行

用 `wf run hunyuanworld-mirror --pipeline.task-profile default` 重建场景。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`tencent/HunyuanWorld-Mirror`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hunyuanworld-mirror`；下载缺失的公开权重时加 `--download`。
