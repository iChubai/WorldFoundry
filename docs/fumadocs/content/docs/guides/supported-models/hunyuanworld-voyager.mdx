HunyuanWorld-Voyager is designed to generate RGB-D video along a user-defined camera path from an input image. See the [official source](https://github.com/Tencent-Hunyuan/HunyuanWorld-Voyager) and [project page](https://3d-models.hunyuan.tencent.com/world/).

## WorldFoundry status

**Integration blocked.** The public `HunyuanWorldVoyagerPipeline.from_pretrained` path fails before loading a checkpoint: the in-tree `hunyuan_world_voyager/config.py` and `runtime.py` sources are missing, leaving only Python cache files. The pinned upstream `voyager/` package contains 37 Python files but does not contain WorldFoundry's `HunyuanWorldVoyagerRuntime` adapter. The model's pipeline binding is disabled until those sources are restored and the public route is tested.

The upstream case1 defaults (49 frames, 50 inference steps, flow shift 7.0) are recorded for reference only. No checkpoint-backed inference or visual quality is claimed.
