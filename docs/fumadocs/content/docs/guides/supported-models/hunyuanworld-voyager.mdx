## What it is for

Use `hunyuanworld-voyager` for catalog world-model inference. Choose it when you need action-conditioned future frames rather than a standalone clip generator.

Per the upstream release, Voyager combines a HunyuanVideo-based generator with joint RGB-D output and a world-cache mechanism for long-range consistency. The official case1 defaults are recorded in the runtime profile: num_frames=49, infer_steps=50, flow_shift=7.0, embedded_cfg_scale=6.0, i2v_stability=true. It is published by Tencent (Hunyuan).

Catalog tasks include world, video, and world model. Documented outputs include video.

Recorded evaluation entry points include [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Scoring for camera-navigable generated worlds), [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-path adherence evaluation).
