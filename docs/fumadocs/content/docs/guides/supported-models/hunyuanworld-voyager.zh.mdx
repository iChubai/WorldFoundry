## 用来做什么

`hunyuanworld-voyager` 是世界生成模型。

按上游发布，Voyager 将基于 HunyuanVideo 的生成器与 RGB-D 联合输出及世界缓存机制结合，实现长程一致性。官方 case1 默认值为：num_frames=49、infer_steps=50、flow_shift=7.0、embedded_cfg_scale=6.0、i2v_stability=true。该模型由腾讯（混元）发布。

任务：世界模型、视频生成。输出模态为视频。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（相机可游走生成世界的评分）、[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机路径贴合度评测）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `hunyuanworld-voyager.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `HunyuanWorldVoyagerOfficialPipeline`。系列状态：**已验证**。

需提供固定版本 6218ccd36df77d0254dcf24ad1fb77312f75b04a 的外部官方源码、权重、官方依赖环境及含 49 帧的已渲染条件目录，并设置 WORLDFOUNDRY_VOYAGER_SOURCE_ROOT 和 WORLDFOUNDRY_VOYAGER_PYTHON。腾讯社区许可证排除欧盟、英国、韩国境内使用，并限制再分发。

官方 case1 请求 49 帧，但 latent-concat I2V 流程丢弃 4 帧条件帧，最终视频为 45 帧；更长的游走需要迭代扩展。深度是生成式的、非传感器级——用于米制用途前请先验证。验证只覆盖官方 case1 示例；任意相机路径、长程扩展以及深度或相机精度的定量评估均未验证。

## 在 WorldFoundry 中运行

用 `wf run hunyuanworld-voyager --pipeline.task-profile default` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`tencent/HunyuanWorld-Voyager`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hunyuanworld-voyager`；下载缺失的公开权重时加 `--download`。
