HunyuanWorld-Voyager 旨在从输入图像出发，沿指定相机路径生成 RGB-D 视频。参见[官方源码](https://github.com/Tencent-Hunyuan/HunyuanWorld-Voyager)和[项目页](https://3d-models.hunyuan.tencent.com/world/)。

## 验证

`WorldFoundryPipelineRunner` 通过桥接器调用官方 Voyager 源码。使用官方 case1 权重及 49 帧条件，官方 CLI 与 WorldFoundry runner 在 8 步推理下均生成可完整解码的 RGB-D H.264 视频（768 × 1024、24 fps、45 帧）；WorldFoundry runner 也跑通了上游默认的 50 步配置。验证只覆盖 case1；任意相机路径、长程扩展以及深度或相机精度的定量评估均未验证。

运行时需另行准备固定在 `6218ccd36df77d0254dcf24ad1fb77312f75b04a` 的外部官方源码、官方权重、满足上游依赖的专用 Python 环境，以及预渲染的 49 帧条件目录；设置 `WORLDFOUNDRY_VOYAGER_SOURCE_ROOT` 和 `WORLDFOUNDRY_VOYAGER_PYTHON`。WorldFoundry 不分发官方源码和权重。腾讯社区许可证排除欧盟、英国、韩国境内使用，再分发上游材料时要求附带 `LICENSE` 和 `NOTICE`。
