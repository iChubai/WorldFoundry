HunyuanWorld-Voyager 旨在从输入图像出发，沿指定相机路径生成 RGB-D 视频。参见[官方源码](https://github.com/Tencent-Hunyuan/HunyuanWorld-Voyager)和[项目页](https://3d-models.hunyuan.tencent.com/world/)。

## WorldFoundry 状态

**集成受阻。** 公开的 `HunyuanWorldVoyagerPipeline.from_pretrained` 在加载权重前就会失败：树内 `hunyuan_world_voyager/config.py` 和 `runtime.py` 源码缺失，只剩 Python 缓存文件。固定版本的上游 `voyager/` 包有 37 个 Python 文件，但不包含 WorldFoundry 的 `HunyuanWorldVoyagerRuntime` 适配器。恢复源码并验证公开路径之前，pipeline binding 已禁用。

上游 case1 默认值（49 帧、50 步、flow shift 7.0）仅供参考；目前没有真实权重推理或视觉质量验证结果。
