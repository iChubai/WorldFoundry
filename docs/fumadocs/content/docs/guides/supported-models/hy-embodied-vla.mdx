Hy-Embodied-0.5-VLA is Tencent Hunyuan's bimanual manipulation VLA, released as two Apache-2.0 checkpoints on Hugging Face and ModelScope: RoboTwin and UMI. Validated on an A100: the RoboTwin checkpoint decodes a 20x20 action chunk from the official six-frame, three-camera input, and the UMI checkpoint decodes a 50x20 relative-action chunk in BF16.

## What it is for

`hy-embodied-vla-umi` maps camera observations and an instruction to an action trajectory.

An inference-only mixture-of-transformers (MoT) backbone with in-tree preprocessing and action decoding. The official input contract is six frames from three cameras; RoboTwin decodes absolute joint actions while UMI decodes relative actions.

Tasks: VLA, VLA policy rollout, robot policy, and bimanual manipulation. Aliases: `hy-vla`, `hy-embodied-0.5-vla`, and `Hy-Embodied-0.5-VLA`. Other variants: `hy-embodied-vla-robotwin`.

Suggested benchmarks: [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (GPU-validated RoboTwin policy checkpoint).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `state`, `variant`, `state-format`, `blend-mode`, `history-size`, `replicate-single-image`, and 2 more; artifacts `action_trace` and `hy_embodied_vla_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `HyEmbodiedVLAPipeline`.

Start with `hy-embodied-vla-umi`. The family has 2 variants, selectable in the command builder above: `hy-embodied-vla-umi` (`vla.policy_rollout`) — Verified; `hy-embodied-vla-robotwin` (`vla.policy_rollout`) — Verified. Family status: **Verified**.

Choose the RoboTwin checkpoint for simulator benchmark work and the UMI checkpoint for UMI-style relative-action deployments; both run through the same pipeline.

Validation covers action decoding only; full benchmark rollouts have not been validated.

## Running in WorldFoundry

Run `wf run hy-embodied-vla-umi --pipeline.task-profile default` to predict actions.

It runs in the dedicated environment `worldfoundry-hy-embodied-vla-cu128` (Python 3.12, CUDA 12.8, torch>=2.7,\<2.8).

Weights: `tencent/Hy-Embodied-0.5-VLA-UMI` and `tencent/Hy-Embodied-0.5-VLA-RoboTwin`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh hy-embodied-vla-umi`. Add `--download` to fetch missing public checkpoints.
