Hy-Embodied-0.5-VLA 是腾讯混元的双臂操作 VLA，在 Hugging Face 与 ModelScope 上发布了两个 Apache-2.0 checkpoint：RoboTwin 与 UMI。已在 A100 上验证：RoboTwin checkpoint 从官方六帧三相机输入解码出 20x20 动作块，UMI checkpoint 以 BF16 解码出 50x20 相对动作块。

## 用来做什么

`hy-embodied-vla-umi` 把相机观测和指令映射为动作轨迹。

推理专用的 mixture-of-transformers（MoT）骨干，预处理与动作解码内置树内。官方输入契约为三相机六帧；RoboTwin 解码绝对关节动作，UMI 解码相对动作。

任务：视觉-语言-动作（VLA）、VLA 策略执行、机器人策略、bimanual_manipulation。别名：`hy-vla`、`hy-embodied-0.5-vla`、`Hy-Embodied-0.5-VLA`。同系列还有 `hy-embodied-vla-robotwin`。

推荐评测：[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（GPU 已验证的 RoboTwin 策略 checkpoint）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `state`、`variant`、`state-format`、`blend-mode`、`history-size`、`replicate-single-image` 等 8 项；产物 `action_trace`、`hy_embodied_vla_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `HyEmbodiedVLAPipeline`。

建议从 `hy-embodied-vla-umi` 开始。该系列共有 2 个 variant，可在上方命令构建器中切换：`hy-embodied-vla-umi`（`vla.policy_rollout`）：已验证、`hy-embodied-vla-robotwin`（`vla.policy_rollout`）：已验证。系列状态：**已验证**。

模拟器基准工作选 RoboTwin checkpoint，UMI 式相对动作部署选 UMI checkpoint；两者共用同一 pipeline。

验证仅覆盖动作解码；完整基准 rollout 尚未验证。

## 在 WorldFoundry 中运行

运行 `wf run hy-embodied-vla-umi --pipeline.task-profile default` 预测动作。

运行环境：独立环境 `worldfoundry-hy-embodied-vla-cu128`（Python 3.12，CUDA 12.8，torch>=2.7,\<2.8）。

权重仓库：`tencent/Hy-Embodied-0.5-VLA-UMI`、`tencent/Hy-Embodied-0.5-VLA-RoboTwin`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hy-embodied-vla-umi`；下载缺失的公开权重时加 `--download`。
