## What it is for

Pick `hy-embodied` when you want the catalog VLA policy: instruction and observation in, an action trace out. Use it to roll the recorded policy, not to train a new one.

The runtime contract is a Transformers image-text interface over the HY-Embodied-0.5 checkpoint. Architecture internals beyond the official repository pointer (Tencent-Hunyuan/HY-Embodied, pinned head c9b3530e) are not recorded in this repository.

Catalog tasks include vla, robot policy, and embodied policy. Catalog aliases include `Hunyuan-Embodied`.

HY embodied world/video. VLA is a sibling.

## Runtime contract

Required `image` and `prompt`; optional `model_id` (hy-embodied), `policy_family`, and `action_representation`; artifacts `action_trace` and `hy-embodied_action_trace.json`.

Recorded task profiles: `vla`, `robot_policy`, and `embodied_policy`. WorldFoundry binds `HYEmbodiedPipeline`.

Family status: **Runner parity pending**.

Checkpoint absence is reported by runtime missing_assets and is not a catalog blocker; runs emit a runtime plan until weights are staged. For a GPU-validated Hunyuan policy, see the sibling hy-embodied-vla entry.

WorldFoundry routes HY-Embodied through an in-tree official Transformers image-text runtime adapter.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run hy-embodied --pipeline.task-profile vla`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `tencent/HY-Embodied-0.5`. Stage assets with `bash scripts/inference/prepare_model_infer.sh hy-embodied`.

Status: **Runner parity pending**.
