HY-Embodied 是腾讯混元的具身策略线，本条目对应已确认的 tencent/HY-Embodied-0.5 checkpoint。WorldFoundry 通过树内官方 Transformers 图文运行时适配器路由；权重尚未就位，运行输出运行时计划。

## 用来做什么

需要 catalog 上的 VLA 策略时选 `hy-embodied`：指令与观测进、动作轨迹出。用来滚动已记录策略，不是用来训练新策略。

运行时契约是基于 HY-Embodied-0.5 checkpoint 的 Transformers 图文接口。官方仓库指针（Tencent-Hunyuan/HY-Embodied，锁定 head c9b3530e）之外的架构内部细节仓库未记录。

catalog 记录的任务包括 视觉-语言-动作（VLA）、机器人策略、具身策略。别名包括 `Hunyuan-Embodied`。

## 运行时契约

必填 `image`、`prompt`；可选 `model_id` (hy-embodied)、`policy_family`、`action_representation`；产物 `action_trace`、`hy-embodied_action_trace.json`。

记录的任务 profile：`vla`、`robot_policy`、`embodied_policy`。绑定的 pipeline 类是 `HYEmbodiedPipeline`。

系列状态：**Runner 一致性待确认**。

checkpoint 缺失由运行时 missing_assets 报告，不视为 catalog 阻塞；权重就位前运行输出运行时计划。 如需 GPU 已验证的混元策略，请见同门条目 hy-embodied-vla。

许可为腾讯混元社区许可——商用前请审查。

必填 `image`、`prompt`；可选 `model_id`、`policy_family`、`action_representation`；产物 `action_trace`、`hy-embodied_action_trace.json`。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run hy-embodied --pipeline.task-profile vla`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `tencent/HY-Embodied-0.5`。就位权重用 `bash scripts/inference/prepare_model_infer.sh hy-embodied`。

状态：**Runner 一致性待确认**。
