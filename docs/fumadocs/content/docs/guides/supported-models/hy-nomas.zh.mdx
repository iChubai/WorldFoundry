## 用来做什么

`hy-nomas` 是文生视频模型：输入提示词，输出视频。

蒸馏 Hy-Nomas DiT 以 Qwen2.5-VL 文本基座为条件，用 Euler 调度和压缩 KV 历史自回归生成 latent 片段；PixelUMM 解码器将 latent 解码为视频帧。该模型由腾讯混元发布。

任务：文生视频、动作条件视频、交互式世界生成。别名：`hynomas`、`tencent/Hy-Nomas`。模态上，它接受文本、动作，输出视频。同系列还有 `hy-nomas-low-memory`。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`guidance-scale`；产物 `hy-nomas.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `HyNomasPipeline`。`interactive-video` 的默认值：frames=120, fps=24, height=720, width=1280, steps=8, guidance-scale=1.0。

建议从 `hy-nomas` 开始。该系列共有 2 个 variant，可在上方命令构建器中切换：`hy-nomas`（`text-to-video`）：Runner 一致性待确认、`hy-nomas-low-memory`（`text-to-video`）：Runner 一致性待确认。系列状态：**Runner 一致性待确认**。

有序 prompt 表示同一世界的连续片段。显式相机控制使用归一化 camera-to-world 矩阵。分别准备浮点 DiT、PixelUMM 与 Qwen2.5-VL-7B 权重。

尚未测量完整发布权重的生成效果、部署规模下的低显存量化与 Studio 性能。低显存推理在加载时对浮点 checkpoint 做 INT8/FP8 量化；不支持上游打包导出的 INT8/FP8 文件。

## 在 WorldFoundry 中运行

用 `wf run hy-nomas --pipeline.task-profile interactive-video` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu121`（Python 3.11，CUDA 12.1）。

权重仓库：`tencent/Hy-Nomas`、`Qwen/Qwen2.5-VL-7B-Instruct`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hy-nomas`；下载缺失的公开权重时加 `--download`。
