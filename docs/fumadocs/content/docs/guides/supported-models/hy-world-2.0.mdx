HY-World 2.0 is Tencent's second-generation world stack. WorldFoundry runs its WorldMirror 2.0 reconstruction component, verified through the Workspace infer path; it exports depth, normals, point cloud, Gaussian splat, cameras, COLMAP files, and RRD scene metadata.

## What it is for

`hy-world-2.0` generates a 3D-consistent world rather than a single clip.

WorldMirror 2.0 is a feed-forward reconstruction network that predicts depth, normals, cameras, point clouds and Gaussian splats from images or video. The upstream HY-Pano 2.0 panorama generator and five-stage world generation are not part of WorldFoundry. It is published by Tencent (Hunyuan).

Tasks: default. Aliases: `hyworld2.0`, `hyworld-2.0`, `hy-world2.0`, and `hy-world-2p0` among others.

Suggested benchmarks: [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Standard scoring for generated explorable worlds).

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `task`, `confidence-percentile`, `edge-normal-threshold`, `edge-depth-threshold`, `apply-confidence-mask`, `apply-edge-mask`, and 8 more; artifacts `hy-world-2.0.mp4`.

CLI task profiles: `default`. WorldFoundry binds `HYWorld2Pipeline`.

Family status: **Planned**.

Run task `worldrecon` for WorldMirror 2.0 reconstruction from an image directory or video. Only this component is available; panorama and world generation are not.

## Running in WorldFoundry

Run `wf run hy-world-2.0 --pipeline.task-profile default` to generate the world.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `tencent/HY-World-2.0`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh hy-world-2.0`. Add `--download` to fetch missing public checkpoints.
