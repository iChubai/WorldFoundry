HY-World 2.0 is Tencent's second-generation world stack with three components: HY-Pano 2.0 panorama generation, WorldMirror 2.0 reconstruction, and full text/image-to-3D-world generation. WorldFoundry runs the panorama and reconstruction components; full world generation runs upstream only. The validated WorldMirror 2.0 reconstruction path exports depth, normals, point cloud, Gaussian splat, cameras, COLMAP files, and RRD scene metadata.

## What it is for

`hy-world-2.0` generates a 3D-consistent world rather than a single clip.

The upstream five-stage world generation chains WorldNav trajectory generation, trajectory rendering, video generation, GS data preparation, and 3DGS composition (traj_generate.py through world_gs_trainer.py) plus a VLM endpoint. WorldFoundry runs HY-Pano 2.0 and WorldMirror 2.0; the other stages run upstream only. It is published by Tencent (Hunyuan).

Tasks: default. Aliases: `hyworld2.0`, `hyworld-2.0`, `hy-world2.0`, and `hy-world-2p0` among others.

Suggested benchmarks: [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Standard scoring for generated explorable worlds).

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `task`, `confidence-percentile`, `edge-normal-threshold`, `edge-depth-threshold`, `apply-confidence-mask`, `apply-edge-mask`, and 8 more; artifacts `hy-world-2.0.mp4`.

CLI task profiles: `default`. WorldFoundry binds `HYWorld2Pipeline`.

Family status: **Planned**.

Use the WorldMirror 2.0 reconstruction path for 3D outputs; run full world generation with the upstream code. The trajectory-render stage is available separately as hyworld-worldgen.

Full text/image-to-3D-world generation is not available in WorldFoundry; use the upstream code.

Full World Generation inference code ships upstream; WorldNav, WorldStereo 2.0, and World Composition are not available in WorldFoundry, so there is no full text/image-to-3D-world Studio path.

## Running in WorldFoundry

Run `wf run hy-world-2.0 --pipeline.task-profile default` to generate the world.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `tencent/HY-World-2.0`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh hy-world-2.0`. Add `--download` to fetch missing public checkpoints.
