## 用来做什么

需要动作条件世界步进时选 `hy-world-2.0`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

WorldMirror 2.0 是前馈式重建网络，从图像或视频预测深度、法线、相机、点云与高斯泼溅。上游的 HY-Pano 2.0 全景生成与五阶段世界生成不在 WorldFoundry 中。该模型由腾讯（混元）发布。

catalog 记录的任务包括 default。别名包括 `hyworld2.0`、`hyworld-2.0`、`hy-world2.0`、`hy-world-2p0` 等。

记录的评测入口包括[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（生成可探索世界的标准评分）。

## 运行时契约

可选 `input_path`、`task`、`confidence_percentile`、`edge_normal_threshold`、`edge_depth_threshold`；产物 `hy-world-2.0.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `HYWorld2Pipeline`。

系列状态：**计划中**。

使用 worldrecon 任务，从图像目录或视频运行 WorldMirror 2.0 重建。

仅提供 WorldMirror 2.0 重建组件；全景生成与世界生成不可用。

## 在 WorldFoundry 中运行

catalog 启动命令是 `wf run hy-world-2.0 --pipeline.task-profile default`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `wf run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `tencent/HY-World-2.0`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hy-world-2.0`；下载缺失的公开权重时加 `--download`。
