## What it is for

Pick `hy-worldplay` when you need an action-conditioned world stepper: recorded actions and a frame in, a rollout out. Use it for interactive world inference, not a text-to-video prompt dump.

The recorded checkpoint set tells the assembly: tencent/HY-WorldPlay action weights over tencent/HunyuanVideo-1.5 video-model support assets, with Qwen2.5-VL-7B-Instruct, byt5-small, and FLUX.1-Redux-dev as support components. The in-tree pipeline follows the official demo contract. It is published by Tencent (Hunyuan).

Catalog tasks include world, video, world model, and official-image-pose-video. Catalog aliases include `hunyuan-worldplay` and `hunyuanworldplay`. Documented outputs include video.

Recorded evaluation entry points include [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Interactive world-rollout quality), [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Pose/camera-following accuracy).

## Runtime contract

Required `prompt` and `image`; optional `video` and `actions`; artifacts `hy-worldplay.mp4`.

Recorded task profiles: `world`, `video`, `world_model`, and `official-image-pose-video`. WorldFoundry binds `HunyuanWorldPlayPipeline`.

Family status: **Verified**.

Recorded `official-image-pose-video` defaults: num_frames=125, fps=24, height=480, width=832, num_inference_steps=4, seed=1.

The official route uses 8 torchrun ranks — plan for a multi-GPU host and stage all five recorded checkpoint sets. Full benchmark scoring and longer interaction suites remain separate work.

## Running in WorldFoundry

Launch `worldfoundry-eval run hy-worldplay --pipeline.task-profile official-image-pose-video` to step the world. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `tencent/HY-WorldPlay`, `tencent/HunyuanVideo-1.5`, and `Qwen/Qwen2.5-VL-7B-Instruct` among others. Stage assets with `bash scripts/inference/prepare_model_infer.sh hy-worldplay`.
