HY-WorldPlay is Tencent's real-time interactive world video model: starting from an image, it follows pose/action input to roll the world forward — the interactive arm of the Hunyuan world stack. Validated on the official image-pose-video route with the official 8-GPU execution profile.

## What it is for

`hy-worldplay` generates a 3D-consistent world rather than a single clip.

tencent/HY-WorldPlay action weights run on tencent/HunyuanVideo-1.5 video-model assets, with Qwen2.5-VL-7B-Instruct, byt5-small, and FLUX.1-Redux-dev as support components. The in-tree pipeline follows the official demo contract. It is published by Tencent (Hunyuan).

Tasks: world, video, and world model. Aliases: `hunyuan-worldplay` and `hunyuanworldplay`. Output modalities: video.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Interactive world-rollout quality), [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Pose/camera-following accuracy).

## Runtime contract

Inputs `image`, `prompt`, and `interactions` (bundled samples are used when omitted); options `num-frames`, `fps`, `height`, `width`, `num-inference-steps`, `seed`, and 4 more; artifacts `hy-worldplay.mp4`.

CLI task profiles: `official-image-pose-video`. WorldFoundry binds `HunyuanWorldPlayPipeline`.

Family status: **Verified**.

Defaults for `official-image-pose-video`: fps=24, height=480, width=832, seed=1.

The official route launches 8 torchrun ranks; stage all five checkpoint sets before running.

## Running in WorldFoundry

Generate a world with `wf run hy-worldplay --pipeline.task-profile official-image-pose-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `tencent/HY-WorldPlay`, `tencent/HunyuanVideo-1.5`, and `Qwen/Qwen2.5-VL-7B-Instruct` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh hy-worldplay`. Add `--download` to fetch missing public checkpoints.
