HY-WorldPlay 是腾讯的实时交互世界视频模型：从一张图出发，跟随位姿/动作输入向前滚动世界——混元世界栈的交互分支。已按官方 image-pose-video 路径与官方 8 卡执行档案验证。

## 用来做什么

`hy-worldplay` 生成 3D 一致的世界，而不只是一段视频。

tencent/HY-WorldPlay 动作权重运行在 tencent/HunyuanVideo-1.5 视频模型资产之上，辅以 Qwen2.5-VL-7B-Instruct、byt5-small 与 FLUX.1-Redux-dev 支持组件。树内 pipeline 遵循官方 demo 契约。该模型由腾讯（混元）发布。

任务：世界模型、video。别名：`hunyuan-worldplay`、`hunyuanworldplay`。输出模态为视频。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（交互式世界滚动生成质量）、[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（位姿/相机跟随精度）。

HY-WorldPlay 交互回放。不是 HY-World 2.0。

## 运行时契约

输入 `image`、`prompt`、`interactions`（不传时使用内置示例）；参数 `num-frames`、`fps`、`height`、`width`、`num-inference-steps`、`seed` 等 10 项；产物 `hy-worldplay.mp4`。

CLI task profile：`official-image-pose-video`。绑定的 pipeline 类是 `HunyuanWorldPlayPipeline`。

系列状态：**已验证**。

`official-image-pose-video` 记录默认值：num_frames=125, fps=24, height=480, width=832, num_inference_steps=4, seed=1。

官方路径启动 8 个 torchrun rank；运行前请就位全部五套 checkpoint。

## 在 WorldFoundry 中运行

用 `wf run hy-worldplay --pipeline.task-profile official-image-pose-video` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`tencent/HY-WorldPlay`、`tencent/HunyuanVideo-1.5`、`Qwen/Qwen2.5-VL-7B-Instruct` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hy-worldplay`；下载缺失的公开权重时加 `--download`。
