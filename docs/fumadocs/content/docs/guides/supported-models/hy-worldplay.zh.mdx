## 架构

记录的 checkpoint 组合揭示其装配：tencent/HY-WorldPlay 动作权重叠加 tencent/HunyuanVideo-1.5 视频模型支持资产，辅以 Qwen2.5-VL-7B-Instruct、byt5-small 与 FLUX.1-Redux-dev 支持组件。树内 pipeline 遵循官方 demo 契约。

## 使用要点

官方路径使用 8 个 torchrun rank——请准备多卡主机并就位全部五套记录的 checkpoint。完整 benchmark 打分与更长交互套件是独立工作。
