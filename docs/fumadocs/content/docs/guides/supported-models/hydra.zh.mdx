## 用来做什么

用 `hydra` 做相机条件视频推理。配方绑定了已记录的相机控制 profile。

架构内部细节仓库未记录。固定的公开 revision 无 LICENSE 文件，下游使用前必须先做许可审查。

catalog 记录的任务包括 相机可控视频、视频到视频、世界模型。别名包括 `h-embodvis-hydra`。模态上，它接受视频，输出视频。

记录的评测入口包括[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（重渲染视频的相机行为贴合度）、[WRBench](/zh/docs/evaluation/benchmark-hub/wrbench)（该模型 manifest 的证据记录中提到了这一评测）。
