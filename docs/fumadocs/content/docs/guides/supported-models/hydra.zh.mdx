HyDRA 是相机可控的视频到视频世界模型：按 camera JSON 描述的新相机行为重新渲染输入视频。已在官方样例上验证：50 步推理生成了连贯的 77 帧 832x480 续写。

## 用来做什么

`hydra` 以相机位姿为条件生成视频。

HyDRA 将自有 checkpoint（H-EmbodVis/HyDRA）与 Wan2.1-T2V-1.3B 基座模型（Wan-AI/Wan2.1-T2V-1.3B）配合使用。

任务：相机可控视频、视频到视频、世界模型。别名：`h-embodvis-hydra`。模态上，它接受视频，输出视频。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（重渲染视频的相机行为贴合度）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`seed` 等 7 项；产物 `hydra.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `HydraPipeline`。

系列状态：**已验证**。

`default` 的默认值：frames=77, fps=15, height=480, width=832, seed=42。

必须使用内置源码——外部源码检出会被拒绝。输入为提示词、视频与 camera_json。

## 在 WorldFoundry 中运行

用 `wf run hydra --pipeline.task-profile default` 生成相机可控视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`H-EmbodVis/HyDRA`、`Wan-AI/Wan2.1-T2V-1.3B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hydra`；下载缺失的公开权重时加 `--download`。
