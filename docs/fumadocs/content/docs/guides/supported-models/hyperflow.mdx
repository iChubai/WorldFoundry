## What it is for

`hyperflow` covers text-to-video and image-to-video: a prompt and an optional still image in, a clip out.

It is published by Video Rebirth.

Tasks: text-to-video, image-to-video, reference-to-video, and audio video generation. Aliases: `hyperflow-h3` and `minimax-h3-hyperflow`. Modalities: text and image in, video out.

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `num-frames`, `seed`, and `memory-reserve-margin`; artifacts `generated_video` and `hyperflow.mp4`.

CLI task profiles: `t2va`, `fl2va`, and `ref2va`. WorldFoundry binds `HyperFlowPipeline`.

Family status: **Runner parity pending**.

Defaults for `t2va`: seed=42 Defaults for `fl2va`: seed=42.

Supply a complete local diffusers MiniMax-H3 snapshot, weights_path and the dedicated Python executable. The upstream loader supplies the fixed grid; num_inference_steps must be 8 and output fps must be 24. Validated on a single H100: T2VA, single-image FL2VA, and image-reference Ref2VA generate 124 frames at 640×384 in eight steps, with full video and stereo audio decoding.

## Running in WorldFoundry

Generate a clip with `wf run hyperflow --pipeline.task-profile t2va`. Switch tasks in the command builder above to change `--pipeline.task-profile`.

Weights: `videorebirth/hyperflow` and `MiniMaxAI/MiniMax-H3`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh hyperflow`. Add `--download` to fetch missing public checkpoints.
