## 用来做什么

`hyperflow` 同时支持文生视频与图生视频：输入提示词和可选的静态图，输出视频。

该模型由Video Rebirth发布。

任务：文生视频、图生视频、参考图生成视频、音视频联合生成。别名：`hyperflow-h3`、`minimax-h3-hyperflow`。模态上，它接受文本、图像，输出视频。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `num-frames`、`seed`、`memory-reserve-margin`；产物 `generated_video`、`hyperflow.mp4`。

CLI task profile：`t2va`、`fl2va`、`ref2va`。绑定的 pipeline 类是 `HyperFlowPipeline`。

系列状态：**Runner 一致性待确认**。

`t2va` 的默认值：seed=42；`fl2va` 的默认值：seed=42。

提供完整的本地 Diffusers 格式 MiniMax-H3 权重快照、weights_path 和专用 Python 可执行文件。上游加载器使用固定网格；num_inference_steps 必须为 8，输出帧率必须为 24 fps。已在单张 H100 上验证：T2VA、单图 FL2VA 和图像参考 Ref2VA 以 8 步生成 640×384、124 帧，包含完整视频与立体声音频解码。

## 在 WorldFoundry 中运行

用 `wf run hyperflow --pipeline.task-profile t2va` 生成视频。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：独立环境 `hyperflow`（Python 3.11，CUDA 12.8，torch==2.11.0+cu128）。

权重仓库：`videorebirth/hyperflow`、`MiniMaxAI/MiniMax-H3`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh hyperflow`；下载缺失的公开权重时加 `--download`。
