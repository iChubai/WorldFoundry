I2VGen-XL is Alibaba's cascaded image-to-video model, one of the earlier high-resolution open I2V releases. It turns a still image and a text prompt into a short video through a two-stage generate-then-refine cascade.

## What it is for

`i2vgen-xl` is an image-to-video model: a still image in, a video clip out.

I2VGen-XL has two latent diffusion stages. The base stage keeps the semantics and content of the input image coherent through two hierarchical encoders; the refinement stage adds detail guided by a brief text prompt and raises the resolution to 1280×720. It is published by Alibaba (Tongyi Lab).

Tasks: image-to-video. Modalities: image and text in, video out.

Suggested benchmarks: [AIGCBench](/docs/evaluation/benchmark-hub/aigcbench) (I2V-focused benchmark suite).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `negative-prompt`, `frames`, `height`, `width`, `steps`, `guidance-scale`, and 2 more; artifacts `i2vgen-xl.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `I2VGenXLPipeline`.

Family status: **Runner parity pending**.

Defaults for `interactive-video`: frames=16, height=704, width=1280, seed=8888.

WorldFoundry runs the Hugging Face diffusers I2VGenXLPipeline with the official ali-vilab weights in float16. The pipeline needs both an image and a prompt; `wf run` falls back to its bundled sample image and prompt when either is omitted.

## Running in WorldFoundry

Animate a still image with `wf run i2vgen-xl --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `ali-vilab/i2vgen-xl`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh i2vgen-xl`. Add `--download` to fetch missing public checkpoints.
