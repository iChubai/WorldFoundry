I2VGen-XL 是阿里巴巴的级联式图生视频模型，属较早的高分辨率开源 I2V 发布。它通过「先生成、再细化」的两级级联，把一张静态图和一段文本提示词生成为短视频。

## 用来做什么

`i2vgen-xl` 是图生视频模型：输入静态图，输出视频。

I2VGen-XL 由两级潜空间扩散模型组成：基础级通过两个层级编码器保持输入图像的语义与内容连贯；细化级在一段简短文本的引导下补充细节，并把分辨率提升到 1280×720。该模型由阿里巴巴（通义实验室）发布。

任务：图生视频。模态上，它接受图像、文本，输出视频。

推荐评测：[AIGCBench](/zh/docs/evaluation/benchmark-hub/aigcbench)（面向图生视频的评测集）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `negative-prompt`、`frames`、`height`、`width`、`steps`、`guidance-scale` 等 8 项；产物 `i2vgen-xl.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `I2VGenXLPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-video` 的默认值：frames=16, height=704, width=1280, seed=8888。

WorldFoundry 以 float16 加载 ali-vilab 官方权重，运行 Hugging Face diffusers 的 I2VGenXLPipeline。该 pipeline 同时需要图像和提示词；任一项未提供时，`wf run` 使用内置的示例图像和提示词。

## 在 WorldFoundry 中运行

用 `wf run i2vgen-xl --pipeline.task-profile interactive-video` 把静态图转化为视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`ali-vilab/i2vgen-xl`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh i2vgen-xl`；下载缺失的公开权重时加 `--download`。
