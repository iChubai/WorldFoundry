**Publisher:** Tsinghua University · University
[Streaming 4D Visual Geometry Transformer](https://arxiv.org/abs/2507.11539) (2025)

Infinite VGGT (StreamVGGT) turns the feed-forward VGGT reconstructor into a streaming model: it processes incoming frames causally with cached tokens, so reconstruction extends indefinitely instead of being bounded by a fixed window. The in-tree pipeline is registered for streaming 3D reconstruction.

## Architecture

Runner parity is pending: checkpoint-backed inference depends on staged StreamVGGT weights. Use the vggt entry for offline reconstruction and this one when frames arrive as a stream.
