Infinite VGGT（StreamVGGT）把前馈重建器 VGGT 改造成流式模型：利用缓存 token 按因果顺序处理输入帧，使重建可以无限延伸而不受固定窗口限制。

论文：[Streaming 4D Visual Geometry Transformer](https://arxiv.org/abs/2507.11539)（2025）。

项目页：[wzzheng.net/StreamVGGT](https://wzzheng.net/StreamVGGT/)。代码：[wzzheng/StreamVGGT](https://github.com/wzzheng/StreamVGGT)。

## 用来做什么

用 `infinite-vggt` 从输入视图做前馈 3D 重建。

该模型采用带缓存 token 的因果 Transformer，并从 VGGT 蒸馏而来（见 arXiv 2507.11539）。许可为 CC-BY-NC-4.0——非商用。该模型由清华大学发布。

任务：3D 重建、streaming-3d。别名：`stream-vggt`、`streamvggt`。

Infinite VGGT 做流式几何重建，与视频模型 Infinite-World 无关。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `output-format`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `InfiniteVGGTPipeline`。

系列状态：**Runner 一致性待确认**。

运行前需准备 StreamVGGT 权重。离线重建请用 VGGT；帧以流形式到达时用 Infinite VGGT。

CC-BY-NC-4.0：非商用许可。

## 在 WorldFoundry 中运行

运行 `wf run infinite-vggt --pipeline.task-profile interactive-video` 写出几何结果。

该模型未记录运行环境。

权重仓库：`lch01/StreamVGGT`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh infinite-vggt`；下载缺失的公开权重时加 `--download`。
