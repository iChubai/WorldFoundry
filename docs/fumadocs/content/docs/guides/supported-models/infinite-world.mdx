Infinite-World is MeiGen-AI's long-horizon world video model: from one image it navigates and extends a world over long durations. Validated on GPU with the official image-conditioned navigation demo settings: the pipeline produces a long-horizon world video with preview metadata.

## What it is for

`infinite-world` is a world generation model.

WorldFoundry runs Infinite-World in-tree from either a local or a Hugging Face checkpoint layout; inference does not need an external source checkout. It is published by Meituan (MeiGen-AI).

Tasks: world, video, and world model. Output modalities: video.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Long-horizon world-rollout quality), [MemoBench](/docs/evaluation/benchmark-hub/memobench) (Long-horizon consistency evaluation).

`infinite-vggt` is a separate streaming 3D reconstruction model, not an Infinite-World variant.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `frames`, `fps`, and `seed`; artifacts `generated_world` and `infinite-world.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `InfiniteWorldPipeline`.

Family status: **Verified**.

Stage the checkpoint in the official local/Hugging Face layout and start from the official image-conditioned navigation demo settings.

## Running in WorldFoundry

Run `wf run infinite-world --pipeline.task-profile interactive-video` to generate the world.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `thuml/InfiniteWorld`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh infinite-world`. Add `--download` to fetch missing public checkpoints.
