## 用来做什么

`infinite-world` 是世界生成模型。

WorldFoundry 在树内运行 Infinite-World，可使用本地或 Hugging Face checkpoint 布局；推理不需要外部源码检出。该模型由美团（MeiGen-AI）发布。

任务：世界模型、video。输出模态为视频。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（长时程世界滚动生成质量）、[MemoBench](/zh/docs/evaluation/benchmark-hub/memobench)（长时程一致性评测）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`seed`；产物 `generated_world`、`infinite-world.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `InfiniteWorldPipeline`。

系列状态：**已验证**。

`interactive-video` 的默认值：frames=81, fps=30, seed=42。

按官方本地/Hugging Face 布局就位 checkpoint，并从官方图像条件导航 demo 设置出发。

## 在 WorldFoundry 中运行

运行 `wf run infinite-world --pipeline.task-profile interactive-video` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`MeiGen-AI/Infinite-World`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh infinite-world`；下载缺失的公开权重时加 `--download`。
