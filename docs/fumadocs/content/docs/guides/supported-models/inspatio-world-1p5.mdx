InSpatio World 1.5 is a world model from inspatio for image-to-video, video-to-video, trajectory-conditioned video, and novel view synthesis.

Use model ID `inspatio-world-1p5`. The original `inspatio-world` entry keeps its existing checkpoint and video pipeline.

The model runs on a causal Wan2.1 backbone with the UMT5 encoder, Wan VAE, block sampler and DA3 depth model, and does not need a separately installed InSpatio checkout. The released inference geometry is **832×480**, BF16, three latent frames per block and four denoising calls. It produces completed videos; interactive streaming sessions are not available.

```python
from worldfoundry.pipelines.inspatio_world.pipeline_inspatio_world_v15 import InspatioWorldV15Pipeline

pipeline = InspatioWorldV15Pipeline.from_pretrained(
    model_path="/models/inspatio--world-1.5",
    wan_model_path="/models/Wan-AI--Wan2.1-T2V-1.3B",
    da3_model_path="/models/depth-anything--DA3NESTED-GIANT-LARGE-1.1",
    device="cuda:0",
)
result = pipeline(
    scene_dir="/data/prepared_scene",
    output_path="/outputs/pred.mp4",
    seed=0,
)
print(result["artifact_path"])
```

Prepared scenes use the official `scene.json` layout: RGB images or video, a prompt file (an empty prepared prompt is supported), uint16 depth with a shared min/max range, source intrinsics and poses, and a target trajectory. Camera matrices are OpenCV **world-to-camera** matrices: 16 row-major numbers per target frame. A four-image scene requires four views and complete groups of three latent frames. Valid output frames may exclude padded scene frames.

For direct inputs, replace `scene_dir` with `videos="/data/input.mp4"` or `images=["/data/view_00.png"]` (one or four images), and provide `prompt` and `traj_txt_path`. Videos are resized to 832×480; direct images must already have that resolution. The target trajectory must use the first-source-frame-normalized coordinate system and the same displacement scale as the source reconstruction. Use prepared scenes when supplying calibrated depth and cameras.

`return_frames=True` additionally loads decoded frames into host memory. The default returns artifact paths. `compile_dit=True` is an optional loading setting; compilation is not needed for standard inference.

Validated with the released weights: six short GPU cases (single-image, four-image and video prepared scenes, plus three direct RGB inputs; two causal blocks each) match the pinned upstream implementation exactly in BF16. Direct-input cases reuse the same DA3-estimated geometry on both sides, so DA3 reconstruction quality is not assessed separately.

To reproduce, check out upstream revision `dd3561f544053fe22d739b6b2f8461c9c97bf8cb` and stage the component weights locally. `tests/manual/inspatio_v15_regression.py` runs the same local checkpoints through WorldFoundry and the upstream implementation, then compares intermediate latents and decoded source, render, mask and prediction videos. Use a new output directory; the video example ships without depth, which `prepare-depth` computes with the shared DA3 model.

```bash
# Set INSPATIO_GPU_ID to an available GPU index or UUID from nvidia-smi.
INSPATIO_UPSTREAM=/path/to/inspatio-world-v1.5
INSPATIO_CHECKPOINTS=/models
INSPATIO_VALIDATION=/tmp/inspatio-v15-validation
for mode in prepare prepare-depth native upstream compare; do
  CUDA_VISIBLE_DEVICES="${INSPATIO_GPU_ID}" WAN_DISABLE_FA3=1 python tests/manual/inspatio_v15_regression.py "$mode" \
    --upstream "$INSPATIO_UPSTREAM" --checkpoints "$INSPATIO_CHECKPOINTS" \
    --output "$INSPATIO_VALIDATION"
done
```

Repeat `native`, `upstream` and `compare` with `--direct` to exercise RGB staging and DA3. `--cases` selects individual cases for parallel runs on separate GPUs. The standard replay matrix includes `inspatio-world-1p5-{image,multiview,video}-short`; set `WORLDFOUNDRY_REGRESSION_INSPATIO_SCENE_ROOT` to the validation directory's `fixtures` subdirectory. Comparisons refuse mismatched release weights.

## What it is for

`inspatio-world-1p5` estimates scene geometry from the input views.

Tasks: image-to-video, video-to-video, trajectory-conditioned video, and novel view synthesis. Aliases: `inspatio-world-v1.5` and `inspatio-world-1.5`. Modalities: image, video, and trajectory in, video out.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); option `seed`; artifact `inspatio-world-1p5.mp4`.

CLI task profile: `default`. WorldFoundry binds `InspatioWorldV15Pipeline`. Family status: **Verified**. Defaults for `default`: seed=0.

## Running in WorldFoundry

Run `wf run inspatio-world-1p5 --pipeline.task-profile default` to write the geometry.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `inspatio/world-1.5`, `Wan-AI/Wan2.1-T2V-1.3B`, and `depth-anything/DA3NESTED-GIANT-LARGE-1.1`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh inspatio-world-1p5`. Add `--download` to fetch missing public checkpoints.
