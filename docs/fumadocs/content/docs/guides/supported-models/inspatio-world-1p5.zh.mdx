InSpatio World 1.5 是来自 inspatio 的世界模型，支持图生视频、视频到视频、轨迹条件视频、新视角合成。

模型 ID 为 `inspatio-world-1p5`。原有 `inspatio-world` 继续使用旧版权重和视频推理入口。

模型基于因果 Wan2.1 骨干，配合 UMT5 编码器、Wan VAE、分块采样器和 DA3 深度模型运行，无需另行安装 InSpatio 仓库。已发布模型的推理规格为 **832×480、BF16、每块三个潜帧、四次去噪**。输出为完整视频文件，不提供交互式流式会话。

先准备本地 `inspatio/world-1.5` 和 `Wan-AI/Wan2.1-T2V-1.3B` 权重。直接输入图像或视频还需要 `depth-anything/DA3NESTED-GIANT-LARGE-1.1`；已准备深度和相机的场景不加载 DA3。

准备好的场景沿用官方 `scene.json` 格式，包括 RGB、prompt 文件（允许为空）、带统一 min/max 的 uint16 深度、源视角内参与位姿，以及目标轨迹。相机位姿为 OpenCV **world-to-camera** 4×4 矩阵，每个目标帧一行、16 个数字、按行展开。四图模式要求四个源视角，并覆盖完整的三个潜帧分组；输出会裁掉场景中的补齐帧。

直接输入时，用 `videos="/data/input.mp4"` 或 `images=["/data/view_00.png"]`（单图或四图）替换 `scene_dir`，并传入 `prompt` 和 `traj_txt_path`。视频会缩放到 832×480，直接输入的图像必须已具有这个分辨率。目标轨迹必须采用以第一个源相机为基准的坐标系，并与重建结果的位移尺度一致。有已标定深度和相机时，请使用准备好的场景。

默认返回视频路径；`return_frames=True` 会额外把帧载入主机内存。加载时可选 `compile_dit=True`，普通推理不要求编译。

已使用发布权重验证：六组短 GPU 用例（单图、四图和视频三类准备好的场景，以及三类直接 RGB 输入；每组两个因果块）在 BF16 下与固定版本的官方实现完全一致。直接输入用例两侧使用同一份 DA3 估计几何，因此不单独评估 DA3 的重建质量。

复现时，先将官方仓库切到 revision `dd3561f544053fe22d739b6b2f8461c9c97bf8cb`，并在本地准备组件权重。`tests/manual/inspatio_v15_regression.py` 使用同一套本地权重，分别运行 WorldFoundry 与官方实现，比较潜变量以及 source、render、mask、pred 的解码帧。请使用新的输出目录；官方视频样例没有附带深度，`prepare-depth` 会调用共享 DA3 补齐。

```bash
# 先根据 nvidia-smi 将 INSPATIO_GPU_ID 设为可用 GPU 的编号或 UUID。
INSPATIO_UPSTREAM=/path/to/inspatio-world-v1.5
INSPATIO_CHECKPOINTS=/models
INSPATIO_VALIDATION=/tmp/inspatio-v15-validation
for mode in prepare prepare-depth native upstream compare; do
  CUDA_VISIBLE_DEVICES="${INSPATIO_GPU_ID}" WAN_DISABLE_FA3=1 python tests/manual/inspatio_v15_regression.py "$mode" \
    --upstream "$INSPATIO_UPSTREAM" --checkpoints "$INSPATIO_CHECKPOINTS" \
    --output "$INSPATIO_VALIDATION"
done
```

再给 `native`、`upstream`、`compare` 加上 `--direct`，即可检查原始 RGB 输入和 DA3 路径。`--cases` 可选择单例并在不同 GPU 上并行运行。标准回归矩阵包含 `inspatio-world-1p5-{image,multiview,video}-short`；将 `WORLDFOUNDRY_REGRESSION_INSPATIO_SCENE_ROOT` 设为验证目录下的 `fixtures`。对照会拒绝不同版本的发布权重。

代码归属和 Apache-2.0 正文统一保留在根目录 `THIRD-PARTY-NOTICES`，各组件权重继续遵循上游条款。

## 用来做什么

`inspatio-world-1p5` 根据输入视图估计场景几何。

任务：图生视频、视频到视频、轨迹条件视频、新视角合成。别名：`inspatio-world-v1.5`、`inspatio-world-1.5`。模态上，它接受图像、视频、轨迹，输出视频。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `seed`；产物 `inspatio-world-1p5.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `InspatioWorldV15Pipeline`。系列状态：**已验证**。`default` 的默认值：seed=0。

## 在 WorldFoundry 中运行

运行 `wf run inspatio-world-1p5 --pipeline.task-profile default` 写出几何结果。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`inspatio/world-1.5`、`Wan-AI/Wan2.1-T2V-1.3B`、`depth-anything/DA3NESTED-GIANT-LARGE-1.1`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh inspatio-world-1p5`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
