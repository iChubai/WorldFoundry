InSpatio-World is a 1.3B video-conditioned world generator: given a video and a target trajectory it synthesizes trajectory-conditioned novel views of the same world. Validated with the released checkpoint: the pipeline generates a visually correct 297-frame video.

## What it is for

Use `inspatio-world` for feed-forward 3D reconstruction from the input views.

The checkpoint is inspatio/world (apache-2.0), used with the Wan2.1-T2V-1.3B base, Depth Anything 3 for geometry reconstruction, and Florence-2-large for video captioning. An optional use_tae path loads taew2_1.pth from the shared checkpoint root; the default Wan VAE path does not need it.

Tasks: video-conditioned world generation, trajectory-conditioned video, and novel view synthesis. Aliases: `inspatio-world-1.3b`.

Suggested benchmarks: [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Trajectory-following accuracy of generated views).

## Runtime contract

Required `input-path`; inputs `prompt` (bundled samples are used when omitted); options `skip-step1`, `skip-step2`, and `skip-step3`; artifacts `inspatio-world.mp4`.

CLI task profiles: `default`. WorldFoundry binds `InspatioWorldPipeline`.

Family status: **Verified**.

All default components load from local checkpoint storage only: stage inspatio/world, Wan-AI/Wan2.1-T2V-1.3B, depth-anything/DA3NESTED-GIANT-LARGE-1.1, and microsoft/Florence-2-large before running.

Video-conditioned by design: it needs an input video, not just an image or prompt.

## Running in WorldFoundry

Reconstruct the scene with `wf run inspatio-world --pipeline.task-profile default --pipeline.input-path VALUE`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `inspatio/world`, `Wan-AI/Wan2.1-T2V-1.3B`, and `depth-anything/DA3NESTED-GIANT-LARGE-1.1` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh inspatio-world`. Add `--download` to fetch missing public checkpoints.
