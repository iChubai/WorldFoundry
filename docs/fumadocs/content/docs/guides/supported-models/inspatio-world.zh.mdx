InSpatio-World 是 1.3B 的视频条件世界生成器：给定一段视频与目标轨迹，合成同一世界的轨迹条件新视角。已用发布的 checkpoint 验证：pipeline 生成的 297 帧视频通过了视觉检查。

## 用来做什么

用 `inspatio-world` 从输入视图做前馈 3D 重建。

checkpoint 为 inspatio/world（apache-2.0），配合 Wan2.1-T2V-1.3B 基座、用于几何重建的 Depth Anything 3 以及用于视频描述的 Florence-2-large 使用。可选的 use_tae 路径会从共享 checkpoint 根加载 taew2_1.pth；默认 Wan VAE 路径不需要它。

任务：video-conditioned-world-generation、trajectory-conditioned-video、新视角合成。别名：`inspatio-world-1.3b`。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（生成视角的轨迹跟随精度）。

## 运行时契约

必填 `input-path`；输入 `prompt`（不传时使用内置示例）；参数 `skip-step1`、`skip-step2`、`skip-step3`；产物 `inspatio-world.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `InspatioWorldPipeline`。

系列状态：**已验证**。

所有默认组件只从本地 checkpoint 存储加载：运行前请就位 inspatio/world、Wan-AI/Wan2.1-T2V-1.3B、depth-anything/DA3NESTED-GIANT-LARGE-1.1 与 microsoft/Florence-2-large。

设计上以视频为条件：需要输入视频，而不仅是图像或提示词。

## 在 WorldFoundry 中运行

用 `wf run inspatio-world --pipeline.task-profile default --pipeline.input-path VALUE` 重建场景。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`inspatio/world`、`Wan-AI/Wan2.1-T2V-1.3B`、`depth-anything/DA3NESTED-GIANT-LARGE-1.1` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh inspatio-world`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
