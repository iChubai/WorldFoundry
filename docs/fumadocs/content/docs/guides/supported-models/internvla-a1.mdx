InternVLA-A1-3B is the A1 generation of InternRobotics' InternVLA series: a 3B policy pairing a Qwen3-VL-2B backbone with an action expert and an NVIDIA Cosmos tokenizer wrapper. Base and RoboTwin checkpoints are confirmed (InternVLA-A1-3B, InternVLA-A1-3B-RoboTwin) under CC-BY-NC-SA-4.0, and the full graph runs in-tree with static verification complete.

## Architecture

The A1-3B graph couples Qwen3-VL-2B vision-language encoding with an expert action head, a Cosmos-Tokenizer-CI8x8 wrapper, flow sampling, and a normalization route — all in-tree, local-only, with no remote checkpoint code.

## Usage notes

Stage the A1-3B (or RoboTwin) checkpoint plus Qwen3-VL-2B-Instruct and the Cosmos tokenizer locally. Note the non-commercial license.
