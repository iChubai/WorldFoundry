## 用来做什么

`internvla-a1` 是视觉-语言-动作（VLA）策略：输入指令和观测，输出动作。

A1-3B 计算图将 Qwen3-VL-2B 视觉-语言编码与专家动作头、Cosmos-Tokenizer-CI8x8 封装、flow 采样与归一化路由耦合。全部在本地运行，不执行 checkpoint 附带的代码。该模型由上海人工智能实验室（InternRobotics）发布。

任务：视觉-语言-动作（VLA）、机器人策略、策略执行、具身评测。

推荐评测：[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（有专门的 InternVLA-A1-3B-RoboTwin checkpoint）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `official-policy-observation`；产物 `action_trace`、`internvla_a1_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `InternVLAA1Synthesis`。

系列状态：**仅静态加载**。

在本地就位 A1-3B（或 RoboTwin）checkpoint、Qwen3-VL-2B-Instruct 与 Cosmos tokenizer。注意非商用许可。

CC-BY-NC-SA-4.0：仅限非商用。

## 在 WorldFoundry 中运行

用 `wf run internvla-a1 --pipeline.task-profile default` 运行策略。

运行环境：独立环境 `worldfoundry-vla-internvla-a1`（Python 3.10，CUDA 12.8，torch>=2.7,\<2.8）。

权重仓库：`InternRobotics/InternVLA-A1-3B`、`InternRobotics/InternVLA-A1-3B-RoboTwin`、`Qwen/Qwen3-VL-2B-Instruct` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh internvla-a1`；下载缺失的公开权重时加 `--download`。
