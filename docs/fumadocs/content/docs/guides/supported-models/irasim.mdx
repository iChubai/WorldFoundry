## Architecture

Per the upstream release, a DiT video diffusion model conditions on per-frame action tokens for trajectory-accurate robot video. Training dataloaders, evaluation scripts, and interactive demos are pruned from the packaged runtime under synthesis/visual_generation/irasim/irasim_runtime.
