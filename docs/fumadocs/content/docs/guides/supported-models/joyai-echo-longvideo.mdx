## What it is for

`joyai-echo-longvideo` is an image-to-video model: a still image in, a video clip out.

The release builds on LTX-2.3 and adds few-step DMD generation plus a paired cross-modal memory bank. WorldFoundry packages the inference code from jd-opensource/JoyAI-Echo at 0b931fd4, reuses canonical LTX components, and runs its package-module CLI in the dedicated Python 3.11, PyTorch 2.8, CUDA 12.8 environment. It is published by JD.com (JoyAI / Echo Team).

Tasks: reference-to-video, audio video generation, and long video generation. Aliases: `joyai-echo`, `echo-longvideo`, and `joyai-echo-1.5`. Modalities: image in, video out.

Suggested benchmarks: [ChronoMagic-Bench](/docs/evaluation/benchmark-hub/chronomagic-bench) (Long-horizon temporal continuity across generated shots), [VBench](/docs/evaluation/benchmark-hub/vbench) (Baseline video quality and motion evaluation).
