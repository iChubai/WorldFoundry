JoyAI-Echo 1.5 是仅推理的长时程音视频生成模型。R2V 请求可组合提示词、可选首帧与最多七个有序图像/音频记忆槽，使角色身份、声音与故事上下文在可独立编辑的镜头间延续。

## 用来做什么

`joyai-echo-longvideo` 是图生视频模型：输入静态图，输出视频。

该版本基于 LTX-2.3，加入少步 DMD 生成与成对跨模态记忆库。WorldFoundry 在专用环境中通过上游 CLI 调用官方运行时（Python 3.11、PyTorch 2.8、CUDA 12.8）。该模型由京东（JoyAI / Echo 团队）发布。

任务：参考图生成视频、音视频联合生成、长视频生成。别名：`joyai-echo`、`echo-longvideo`、`joyai-echo-1.5`。

推荐评测：[ChronoMagic-Bench](/zh/docs/evaluation/benchmark-hub/chronomagic-bench)（评测生成镜头间的长时程时间连续性）、[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（基础视频质量与运动评测）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`seed`、`execute` 等 7 项；产物 `generated_video`、`joyai-echo-longvideo.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `JoyAIEchoLongVideoPipeline`。

系列状态：**Runner 一致性待确认**。

请检出固定 revision 的 JoyAI-Echo，准备专用环境，并传入 source_root、本地 Echo checkpoint 与受限访问的 Gemma checkpoint。生成必须显式设置 execute=True。FP4 还需 NVIDIA ModelOpt，生产级语音记忆提取需完成上游 MSST 设置。

## 在 WorldFoundry 中运行

用 `wf run joyai-echo-longvideo --pipeline.task-profile interactive-video` 把静态图生成为视频。

运行环境：独立环境 `joyai-echo-longvideo`（Python 3.11，CUDA 12.8，torch==2.8.0）。

权重仓库：`jdopensource/JoyAI-Echo`、`google/gemma-3-12b-it`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh joyai-echo-longvideo`；下载缺失的公开权重时加 `--download`。
