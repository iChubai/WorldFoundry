Echo-WM is an omnimodal world model that jointly evolves video, environmental sound, music, and speech under continuous navigation. Base generates about ten seconds; Flash Preview uses four denoising steps and bounded sink-plus-FIFO caches for autoregressive rollout.

## What it is for

Use `joyai-echo-wm` when the viewpoint must follow a given camera path.

Both public variants use an LTX-2.3 audio-visual backbone with UCPE camera conditioning. Base is bidirectional with separate video/audio CFG, while Flash distills guidance with DMD and maintains bounded video, audio, cross-modal, and camera-attention caches. It is published by JD.com (JoyAI / Echo Team).

Tasks: image-to-world-video, camera-controlled video, interactive world model, and audio video generation. Aliases: `echo-wm` and `joyai-echo-world-model`. Modalities: image in, world state and video out.

Suggested benchmarks: [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera and navigation action adherence), [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (General action-conditioned world-rollout quality), [WBench](/docs/evaluation/benchmark-hub/wbench) (The upstream Flash examples use WBench camera-control cases).

## Runtime contract

Required `input-path`; inputs `prompt`, `load.checkpoint-dir`, `load.gemma-path`, and `action-str` (bundled samples are used when omitted); options `num-frames`, `width`, `height`, `fps`, `seed`, `auto-fov`, and 4 more; artifacts `generated_world` and `joyai-echo-wm.mp4`.

Task profiles: `image-to-world-video`, `camera-controlled-video`, `interactive-world-model`, and `audio-video-generation`. WorldFoundry binds `JoyAIEchoWMPipeline`.

Family status: **Runner parity pending**.

Supply a first-frame image, prompt, and Action DSL such as w-60,a-60. Select variant=base or variant=flash at load time. The official source checkout, dedicated CUDA environment, Echo checkpoint, and gated unquantized Gemma encoder must be staged before execute=True.

## Running in WorldFoundry

Launch `wf run joyai-echo-wm`.

It runs in the dedicated environment `joyai-echo-wm` (Python 3.11, CUDA 12.8, torch==2.9.1).

Weights: `Echo-Team/Echo-WM` and `google/gemma-3-12b-it-qat-q4_0-unquantized`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh joyai-echo-wm`. Add `--download` to fetch missing public checkpoints.
