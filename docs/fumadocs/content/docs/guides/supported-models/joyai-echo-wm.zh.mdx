Echo-WM 是在连续导航控制下联合演化视频、环境音、音乐与语音的全模态世界模型。Base 生成约十秒内容；Flash Preview 使用四步去噪与有界 sink-plus-FIFO 缓存进行自回归滚动。

## 用来做什么

视角需要沿指定相机路径运动时，用 `joyai-echo-wm`。

两个公开变体均使用带 UCPE 相机条件的 LTX-2.3 音视频骨干。Base 为双向模型并分别使用视频/音频 CFG；Flash 以 DMD 蒸馏 guidance，并维护有界的视频、音频、跨模态及相机注意力缓存。WorldFoundry vendor 了官方推理代码（jd-opensource/JoyAI-Echo，a08f1274）。该模型由京东（JoyAI / Echo 团队）发布。

任务：image-to-world-video、相机可控视频、交互式世界模型、音视频联合生成。别名：`echo-wm`、`joyai-echo-world-model`。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机与导航动作遵循度）、[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（通用动作条件世界滚动生成质量）、[WBench](/zh/docs/evaluation/benchmark-hub/wbench)（上游 Flash 示例采用 WBench 相机控制案例）。

## 运行时契约

必填 `input-path`；输入 `prompt`、`load.checkpoint-dir`、`load.gemma-path`、`action-str`（不传时使用内置示例）；参数 `num-frames`、`width`、`height`、`fps`、`seed`、`auto-fov` 等 10 项；产物 `generated_world`、`joyai-echo-wm.mp4`。

CLI task profile：`image-to-video`。绑定的 pipeline 类是 `JoyAIEchoWMPipeline`。

系列状态：**Runner 一致性待确认**。

`image-to-video` 的默认值：width=1280, height=704, fps=24, seed=4。

需提供首帧图像、提示词与形如 w-60,a-60 的 Action DSL。加载时选择 variant=base 或 variant=flash。执行 execute=True 前必须准备专用 CUDA 环境、Echo checkpoint 与受限访问的未量化 Gemma 编码器。

## 在 WorldFoundry 中运行

运行 `wf run joyai-echo-wm --pipeline.task-profile image-to-video --pipeline.input-path VALUE` 沿相机路径生成视频。

运行环境：独立环境 `joyai-echo-wm`（Python 3.11，CUDA 12.8，torch==2.9.1）。

权重仓库：`Echo-Team/Echo-WM`、`google/gemma-3-12b-it-qat-q4_0-unquantized`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh joyai-echo-wm`；下载缺失的公开权重时加 `--download`。

gated 权重：`google/gemma-3-12b-it-qat-q4_0-unquantized`（下载前需在上游接受条款）。
