## 用来做什么

`kairos-sensenova` 是记录的交互世界线。要用动作推进世界时从这里起步。

默认可运行 variant 遵循官方 robot 4B 480P 蒸馏配方（kairos_4b_config_DMD.py）：81 帧、 480x640、cfg_scale 5、分块 VAE 解码、无 CFG 并行。记录的 checkpoint 覆盖 robot 480P 蒸馏、480P 预训练与 720P 三个 variant；配置布局要求 Kairos、Qwen 与 Wan2.1-T2V-14B 子目录。该模型由商汤科技（日日新 SenseNova）发布。

catalog 记录的任务包括 文生视频、图生视频、text-image-to-video、具身世界模型。别名包括 `Kairos`、`Kairos Sensenova`、`kairos-4b`、`kairos-sensenova-4b`。模态上，它接受文本、图像，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（文/图生视频输出的质量评测）、[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（具身世界模型预测质量）。

## 运行时契约

必填 `prompt`、`image`；可选 `video`、`actions` (seed)；产物 `kairos-sensenova.mp4`。

记录的任务 profile：`text-to-video`、`image-to-video`、`text-image-to-video`、`embodied-world-model`。绑定的 pipeline 类是 `KairosPipeline`。

系列状态：**已验证**。

将 WORLDFOUNDRY_KAIROS_MODELS_ROOT（或 models_root）指向符合官方配置布局的目录。 720P 与非蒸馏 variant 需要对应的 checkpoint 路径与配置覆盖。

已验证配方使用 8 个 torchrun rank——请准备多卡主机。
