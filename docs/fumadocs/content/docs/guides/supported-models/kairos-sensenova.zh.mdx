Kairos Sensenova 是商汤的具身世界模型视频生成器：4B 模型覆盖文生、图生与文+图生视频，并有面向机器人的蒸馏配方。本 catalog 中集成与 runner 均已验证——默认的 robot 4B 480P DMD 文生视频配方经树内 Apache-2.0 torchrun 运行时以 8 rank 运行。

## 架构

默认可运行 variant 遵循官方 robot 4B 480P 蒸馏配方（kairos_4b_config_DMD.py）：81 帧、 480x640、cfg_scale 5、分块 VAE 解码、无 CFG 并行。记录的 checkpoint 覆盖 robot 480P 蒸馏、480P 预训练与 720P 三个 variant；配置布局要求 Kairos、Qwen 与 Wan2.1-T2V-14B 子目录。

## 使用要点

将 WORLDFOUNDRY_KAIROS_MODELS_ROOT（或 models_root）指向符合官方配置布局的目录。720P 与非蒸馏 variant 需要对应的 checkpoint 路径与配置覆盖。
