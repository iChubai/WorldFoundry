## What it is for

`kandinsky6-pro-distill` covers text-to-video and image-to-video: a prompt and an optional still image in, a clip out.

Tasks: text-to-video, image-to-video, and audio video generation. Aliases: `kandinsky6` and `kandinsky-6`. Modalities: text and image in, video and audio out.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `generated_video` and `kandinsky6-pro-distill.mp4`.

CLI task profiles: `default`. WorldFoundry binds `Kandinsky6Pipeline`.

Family status: **Runner parity pending**.

Validated on one H100 80GB: text-to-video with SDPA attention and component offload generates 121 frames at 864x480 and 24 fps with muxed audio, taking about 140 seconds after an 85-second weight load.

Image-to-video has not been validated.

## Running in WorldFoundry

It runs in the dedicated environment `worldfoundry-kandinsky6-cu126` (Python 3.10, CUDA 12.6, torch==2.9.0+cu126).

Weights: `kandinskylab/Kandinsky-6.0-Pro-distill-5s-Diffusers`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh kandinsky6-pro-distill`. Add `--download` to fetch missing public checkpoints.
