## 用来做什么

`kandinsky6-pro-distill` 同时支持文生视频与图生视频：输入提示词和可选的静态图，输出视频。

任务：文生视频、图生视频、音视频联合生成。别名：`kandinsky6`、`kandinsky-6`。模态上，它接受文本、图像，输出视频、音频。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `generated_video`、`kandinsky6-pro-distill.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `Kandinsky6Pipeline`。

系列状态：**Runner 一致性待确认**。

已在单张 H100 80GB 上验证：文生视频使用 SDPA 注意力与 component offload，生成 121 帧、864x480、24 fps 的视频及同步音频；权重加载约 85 秒，生成约 140 秒。

图生视频尚未验证。

## 在 WorldFoundry 中运行

用 `wf run kandinsky6-pro-distill --pipeline.task-profile default` 生成视频。

运行环境：独立环境 `worldfoundry-kandinsky6-cu126`（Python 3.10，CUDA 12.6，torch==2.9.0+cu126）。

权重仓库：`kandinskylab/Kandinsky-6.0-Pro-distill-5s-Diffusers`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh kandinsky6-pro-distill`；下载缺失的公开权重时加 `--download`。
