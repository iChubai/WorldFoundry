## 用来做什么

`kandinsky6-pro-pretrain` 根据文本提示词生成视频，也可以额外用一张静态图做条件。

任务：文生视频、图生视频、音视频联合生成。模态上，它接受文本、图像，输出视频。

## 运行时契约

输入 `prompt`、`image`；产物 `generated_video`、`kandinsky6-pro-pretrain.mp4`。

CLI task profile：`text-to-video`、`image-to-video`、`audio-video-generation`、`video_generation`。绑定的 pipeline 类是 `Kandinsky6Pipeline`。

系列状态：**Runner 一致性待确认**。

## 在 WorldFoundry 中运行

用 `wf run kandinsky6-pro-pretrain --pipeline.task-profile text-to-video` 生成视频。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`kandinskylab/Kandinsky-6.0-Pro-pretrain-5s-Diffusers`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh kandinsky6-pro-pretrain`；下载缺失的公开权重时加 `--download`。
