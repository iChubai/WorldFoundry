Kling API is the hosted endpoint for Kuaishou's Kling video generation family, recorded here for text-to-video and image-to-video. Prompts or reference images are submitted to Kuaishou's service and the rendered clips come back as WorldFoundry artifacts. ## Architecture

This is a hosted, provider-operated model: the vendor has not published its architecture, parameter count, or training recipe, and this repository does not record them. What WorldFoundry records is the integration surface only — a Studio pipeline that submits requests to the provider endpoint and collects the returned video artifacts.

## Usage notes

The catalog marks this entry as integrated: the hosted-API Studio pipeline is available, but you must supply your own provider API key and account. No weights are downloaded and no GPU environment is provisioned locally — generation happens on the provider side, so cost, quota, and content policy follow your provider account. Credentials come from the Kling open platform (app.klingai.com).
