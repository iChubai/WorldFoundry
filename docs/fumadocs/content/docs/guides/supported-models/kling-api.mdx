Kling API is the hosted endpoint for Kuaishou's Kling video generation family, covering text-to-video and image-to-video. Prompts or reference images are submitted to Kuaishou's service and the rendered clips come back as WorldFoundry artifacts. Hosted Kling runs use the same Studio result format as locally run open models, so you can compare them side by side.

## What it is for

Use `kling-api` to call the hosted model through WorldFoundry.

Tasks: text-to-video, image-to-video, and hosted api. Modalities: text and image in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Standard multi-dimension quality suite for comparing hosted text/image-to-video outputs), [Physics-IQ Original](/docs/evaluation/benchmark-hub/physics-iq) (Probes whether provider-side video models respect basic physical plausibility).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted).

CLI task profiles: `default`. WorldFoundry binds `KlingApiPipeline`.

Family status: **Runner parity pending**.

The hosted-API Studio pipeline is available; supply your own provider API key and account. No weights are downloaded and no local GPU environment is needed — generation happens on the provider side, so cost, quota, and content policy follow your provider account. Credentials come from the Kling open platform (app.klingai.com).

Requires a paid provider account and API key; WorldFoundry does not ship credentials.

## Running in WorldFoundry

Call the hosted model with `wf run kling-api --pipeline.task-profile default`.

No runtime environment is recorded for this model.

Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh kling-api`. Add `--download` to fetch missing public checkpoints.
