Kling API 是快手「可灵」视频生成系列的托管接入点，覆盖文生视频与图生视频。提示词或参考图会提交到快手的服务端，渲染好的视频以 WorldFoundry 产物的形式返回。托管的可灵结果与本地运行的开源模型共用同一套 Studio 结果格式，方便直接对比。

## 用来做什么

用 `kling-api` 在 WorldFoundry 中调用托管模型。

这是由服务方托管运行的模型：厂商未公开其架构、参数规模或训练细节。WorldFoundry 提供一条 Studio pipeline，向服务方端点提交请求并回收生成的视频产物。该模型由快手（Kuaishou）发布。

任务：文生视频、图生视频、托管 API。模态上，它接受文本、图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（对比托管文/图生视频输出的标准多维质量评测）、[Physics-IQ Original](/zh/docs/evaluation/benchmark-hub/physics-iq)（检验服务方视频模型是否遵循基本物理合理性）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）。

CLI task profile：`default`。绑定的 pipeline 类是 `KlingApiPipeline`。

系列状态：**Runner 一致性待确认**。

托管 API 的 Studio pipeline 已可用，需自备服务方的 API key 与账号。本地不下载权重，也不需要 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。凭据需在可灵开放平台（app.klingai.com）申请。

需要付费的服务方账号与 API key；WorldFoundry 不提供任何凭据。

## 在 WorldFoundry 中运行

用 `wf run kling-api --pipeline.task-profile default` 调用托管模型。

该模型未记录运行环境。

准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh kling-api`；下载缺失的公开权重时加 `--download`。
