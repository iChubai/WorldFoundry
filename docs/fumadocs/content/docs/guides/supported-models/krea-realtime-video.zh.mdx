## 用来做什么

`krea-realtime-video` 是文生视频模型：输入提示词，输出视频。

上游将其描述为面向实时块式生成蒸馏的 14B 自回归/流式视频模型（权重在 krea/krea-realtime-video，apache-2.0）。生成按块进行，块数由 num_blocks 控制，输入为 prompt 与可选的 video。

任务：realtime-video-generation、文生视频、视频到视频、streaming-video。别名：`krea-rt-14b`。模态上，它接受文本、视频，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（流式文生视频输出的基础质量检查）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `fps`、`height`、`width`、`seed`、`num-blocks`；产物 `krea-realtime-video.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `KreaRealtimeVideoPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-video` 的默认值：fps=16, height=480, width=832, seed=42。

先把 krea/krea-realtime-video 放到本地。文生视频只需 prompt；视频到视频时再提供 video。

## 在 WorldFoundry 中运行

运行 `wf run krea-realtime-video --pipeline.task-profile interactive-video` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`krea/krea-realtime-video`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh krea-realtime-video`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
