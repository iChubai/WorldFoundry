## What it is for

`lagernvs` estimates scene geometry from the input views.

A novel-view / camera-path rendering model at 512 resolution. It is published by Meta AI (FAIR).

Tasks: novel view synthesis, 3D scene rendering, and camera path rendering. Aliases: `lager-nvs`, `facebook/lagernvs_general_512`, and `facebookresearch/lagernvs`.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `frames`, `fps`, `model-repo`, and `python-executable`; artifacts `generated_video` and `lagernvs.mp4`.
