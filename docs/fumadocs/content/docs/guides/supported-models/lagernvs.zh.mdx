## 用来做什么

`lagernvs` 根据输入视图估计场景几何。

512 分辨率的新视角/相机路径渲染模型。该模型由 Meta AI（FAIR）发布。

任务：新视角合成、3d-scene-rendering、camera-path-rendering。别名：`lager-nvs`、`facebook/lagernvs_general_512`、`facebookresearch/lagernvs`。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`model-repo`、`python-executable`；产物 `generated_video`、`lagernvs.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `LagrNVSPipeline`。

系列状态：**Runner 一致性待确认**。

`default` 的默认值：frames=16, fps=25。

运行需要 gated checkpoint 与 CUDA GPU。运行前请先在 Hugging Face 接受 gated 条款并设置 HF_TOKEN。

## 在 WorldFoundry 中运行

用 `wf run lagernvs --pipeline.task-profile default` 重建场景。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`facebook/lagernvs_general_512`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lagernvs`；下载缺失的公开权重时加 `--download`。

gated 权重：`facebook/lagernvs_general_512`（下载前需在上游接受条款）。
