LAPA (Latent Action Pretraining) learns actions without action labels: it pretrains a video-action model on unlabeled video by discovering latent actions, then transfers to real robot control. WorldFoundry runs latent-action inference with the MIT-licensed LAPA-7B-openx checkpoint.

## What it is for

`lapa-7b-openx` is a vision-language-action policy: an instruction and observations in, actions out.

A 7B video-action model trained on Open X-Embodiment scale data with latent action quantization.

Tasks: va, vam, latent action, and video action modeling. Aliases: `LAPA` and `LAPA-7B-openx`.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `seed`, `checkpoint-dir`, `dtype`, `image-size`, `mesh-dim`, and `tokens-per-delta`; artifacts `lapa_action_tokens.json`.

CLI task profiles: `interactive-video`. WorldFoundry binds `LAPAPipeline`.

Family status: **Runner parity pending**.

Defaults for `interactive-video`: seed=1234.

Run it in the dedicated JAX environment worldfoundry-lapa-jax-cu118. Plan-only execution works; full 7B inference needs a compatible JAX environment with tux installed.

## Running in WorldFoundry

Run the policy with `wf run lapa-7b-openx --pipeline.task-profile interactive-video`.

It runs in the dedicated environment `worldfoundry-lapa-jax-cu118` (Python 3.10, CUDA 11.8).

Weights: `latent-action-pretraining/LAPA-7B-openx`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lapa-7b-openx`. Add `--download` to fetch missing public checkpoints.
