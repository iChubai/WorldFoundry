LAPA（Latent Action Pretraining）无需动作标签学习动作：在无标注视频上通过发现隐式动作预训练视频-动作模型，再迁移到真实机器人控制。MIT 许可的 LAPA-7B-openx checkpoint 已确认并锁定 revision；WorldFoundry 将隐式动作推理运行时内置树内。

## 架构

7B 视频-动作模型，在 Open X-Embodiment 规模数据上以隐式动作量化训练。树内运行时通过了 py_compile、from_pretrained、仅计划执行与别名校验。

## 使用要点

真实 7B 推理目前受环境限制：prepare 环境缺少 tux，gpu-jax0325 环境的 JAX 不兼容。仅计划执行可用；完整推理需要兼容的 JAX 环境。
