## What it is for

`last-r1` maps camera observations and an instruction to an action trajectory.

LaST-R1 is a reinforcement-learning-refined VLA policy built on Qwen3-VL; WorldFoundry runs the official source (CHEN-H01/LaST-R1) and decodes actions through its latent/action tokens.

Tasks: VLA, reinforcement learning, and policy rollout.

Suggested benchmarks: [LIBERO](/docs/evaluation/benchmark-hub/libero) (Referenced in this model's manifest evidence notes).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `action_trace` and `last-r1_action_trace.json`.

CLI task profiles: `interactive-video`. WorldFoundry binds `LastR1Pipeline`.

Family status: **Runner parity pending**.

Install the pinned LaST-R1 source and set WORLDFOUNDRY_LAST_R1_SOURCE_DIR (or pass source_root to LastR1Pipeline.from_pretrained), and stage the libero_10 RL checkpoint from chenhao01/LaST-R1. The adapter returns eight seven-dimensional actions from one image and instruction.

Integration is scoped to offline action inference; closed-loop LIBERO rollout and task success rate are not validated.

## Running in WorldFoundry

Run the policy with `wf run last-r1 --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `chenhao01/LaST-R1`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh last-r1`. Add `--download` to fetch missing public checkpoints.
