## 用来做什么

`last-r1` 把相机观测和指令映射为动作轨迹。

LaST-R1 在 Qwen3-VL 上增加 latent 推理 token、由 56 个双向注意的动作 token 解码出的 8 步 7 维动作，以及价值头。WorldFoundry 已将官方模型代码（CHEN-H01/LaST-R1，ba4e9396）的推理路径纳入包内。

任务：视觉-语言-动作（VLA）、reinforcement_learning、策略执行。

推荐评测：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（该模型 manifest 的证据记录中提到了这一评测）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`last-r1_action_trace.json`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `LastR1Pipeline`。

系列状态：**Runner 一致性待确认**。

准备 chenhao01/LaST-R1 中的 libero_10 RL 权重。树内适配器从一幅图像与一条指令返回八步有限值的七维动作。

集成范围为离线动作推理；尚未验证闭环 LIBERO rollout 与任务成功率。

## 在 WorldFoundry 中运行

用 `wf run last-r1 --pipeline.task-profile interactive-video` 运行策略。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`chenhao01/LaST-R1`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh last-r1`；下载缺失的公开权重时加 `--download`。
