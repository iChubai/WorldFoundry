LDA-1B is a 1B-scale VLA policy combining Qwen3-VL language-vision assembly with a DINOv3-ViT compatibility model and an MMDiT action sampler, released for RoboCasa (Wayer2/LDA-robocasa, CC-BY-NC-4.0). WorldFoundry runs the full inference path in-tree.

## What it is for

`lda-1b` maps camera observations and an instruction to an action trajectory.

Qwen3-VL provides multimodal encoding, DINOv3-ViT adds visual features, and an MMDiT (multimodal diffusion transformer) samples actions, followed by state packing and action unnormalization. Module and parameter names follow the released checkpoint.

Tasks: VLA, robot policy, policy rollout, and embodied benchmark. Aliases: `lda1b` and `wayer2/lda-robocasa`.

Suggested benchmarks: [RoboCasa](/docs/evaluation/benchmark-hub/robocasa) (The released checkpoint targets RoboCasa).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `official-policy-observation`; artifacts `action_trace` and `lda_1b_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `LDA1BSynthesis`.

Family status: **Static load only**.

Stage the 14.4 GB Wayer2/LDA-robocasa checkpoint locally before running. The runtime loads it as a tensor state dict with weights_only=true and never executes checkpoint Python.

CC-BY-NC-4.0: non-commercial use only.

The source repository declares CC BY-NC 4.0 while the hosted checkpoint card declares Apache-2.0; WorldFoundry applies the stricter source license, so use the model for non-commercial purposes only.

## Running in WorldFoundry

Run `wf run lda-1b --pipeline.task-profile default` to predict actions.

It runs in the dedicated environment `worldfoundry-vla-lda-1b` (Python 3.10, CUDA 12.4+, torch==2.6.0).

Weights: `Wayer2/LDA-robocasa`, `Qwen/Qwen3-VL-4B-Instruct`, and `facebook/dinov3-vits16-pretrain-lvd1689m`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lda-1b`. Add `--download` to fetch missing public checkpoints.
