## 用来做什么

`lda-1b` 把相机观测和指令映射为动作轨迹。

Qwen3-VL 提供多模态编码，DINOv3-ViT 补充视觉特征，MMDiT（多模态扩散 transformer）采样动作，随后进行状态打包与动作反归一化。模块与参数名与发布的 checkpoint 一致。

任务：视觉-语言-动作（VLA）、机器人策略、策略执行、具身评测。别名：`lda1b`、`wayer2/lda-robocasa`。

推荐评测：[RoboCasa](/zh/docs/evaluation/benchmark-hub/robocasa)（发布的 checkpoint 面向 RoboCasa）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `official-policy-observation`；产物 `action_trace`、`lda_1b_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `LDA1BSynthesis`。

系列状态：**仅静态加载**。

运行前请在本地就位 14.4 GB 的 Wayer2/LDA-robocasa checkpoint。运行时以 weights_only=true 将其作为张量 state dict 加载，不执行 checkpoint 中的 Python 代码。

CC-BY-NC-4.0：仅限非商用。

## 在 WorldFoundry 中运行

运行 `wf run lda-1b --pipeline.task-profile default` 预测动作。

运行环境：独立环境 `worldfoundry-vla-lda-1b`（Python 3.10，CUDA 12.4+，torch==2.6.0）。

权重仓库：`Wayer2/LDA-robocasa`、`Qwen/Qwen3-VL-4B-Instruct`、`facebook/dinov3-vits16-pretrain-lvd1689m`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lda-1b`；下载缺失的公开权重时加 `--download`。
