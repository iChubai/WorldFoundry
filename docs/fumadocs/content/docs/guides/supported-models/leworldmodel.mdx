LeWorldModel (le-wm) studies latent world models: JEPA-style and pixel-space world models trained and evaluated on control tasks such as PushT. In this catalog an infer-only wrapper for the official eval route is registered; execution needs stable-worldmodel packages, task datasets, and policy checkpoints when the policy is not random.

## What it is for

Pick `leworldmodel` when you need an action-conditioned world stepper: recorded actions and a frame in, a rollout out. Use it for interactive world inference, not a text-to-video prompt dump.

The recorded structure spans latent (JEPA) and pixel world-model variants (checkpoints at eren23/lewm-models). Runtime eval configs live under data/models/runtime/configs/le_wm/config/eval; train configs are not required for inference. It is published by Mila – Quebec AI Institute / Université de Montréal.

Catalog tasks include latent-world-model, jepa-world-model, pixel-world-model, and pusht-eval.

## Runtime contract

Required `prompt`, `image`, and `video`; optional `actions` (world_action, robot_action); artifacts `generated_world` and `leworldmodel_result.json`.

Recorded task profiles: `latent-world-model`, `jepa-world-model`, `pixel-world-model`, and `pusht-eval`. WorldFoundry binds `LeWorldModelPipeline`.

Family status: **Runner parity pending**.

The route matches the official eval.py config flow and reports missing stable-worldmodel packages, task datasets, or non-random policy checkpoints before execution. Official PushT evaluation parity remains pending.

WorldFoundry exposes an infer-only wrapper for the official LeWorldModel eval route under synthesis/visual_generation/world_model/le_wm.

## Running in WorldFoundry

Launch `worldfoundry-eval run leworldmodel --pipeline.task-profile pusht-eval` to step the world. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `eren23/lewm-models`. Stage assets with `bash scripts/inference/prepare_model_infer.sh leworldmodel`.
