LeWorldModel (le-wm) studies latent world models: JEPA-style and pixel-space world models trained and evaluated on control tasks such as PushT. WorldFoundry runs the official evaluation route for inference only; execution needs stable-worldmodel packages, task datasets, and policy checkpoints when the policy is not random.

## What it is for

`leworldmodel` generates a 3D-consistent world rather than a single clip.

It covers latent (JEPA) and pixel world-model variants, with checkpoints at eren23/lewm-models. Inference uses the official eval configs; training configs are not required. It is published by Mila – Quebec AI Institute / Université de Montréal.

Tasks: latent world model, jepa world model, and pixel world model.

## Runtime contract

Options `plan-only` and `timeout-seconds`; artifacts `generated_world` and `leworldmodel_result.json`.

CLI task profiles: `pusht-eval`. WorldFoundry binds `LeWorldModelPipeline`.

Family status: **Runner parity pending**.

The route follows the official eval.py config flow and checks for stable-worldmodel packages, task datasets, and non-random policy checkpoints before execution.

Evaluation-oriented world model: it scores dynamics and does not render showcase video.

## Running in WorldFoundry

Generate a world with `wf run leworldmodel --pipeline.task-profile pusht-eval`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `eren23/lewm-models`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh leworldmodel`. Add `--download` to fetch missing public checkpoints.
