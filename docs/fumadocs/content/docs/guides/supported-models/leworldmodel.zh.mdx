LeWorldModel（le-wm）研究潜空间世界模型：在 PushT 等控制任务上训练与评估 JEPA 式及像素空间世界模型。WorldFoundry 以仅推理方式运行官方评估路径；执行需要 stable-worldmodel 包、任务数据集，以及策略非随机时的策略 checkpoint。

## 用来做什么

`leworldmodel` 生成 3D 一致的世界，而不只是一段视频。

覆盖潜空间（JEPA）与像素两类世界模型 variant，checkpoint 位于 eren23/lewm-models。推理使用官方 eval 配置，不需要训练配置。该模型由Mila 魁北克人工智能研究所 / 蒙特利尔大学发布。

任务：潜空间世界模型、JEPA 世界模型、pixel-world-model。

## 运行时契约

参数 `plan-only`、`timeout-seconds`；产物 `generated_world`、`leworldmodel_result.json`。

CLI task profile：`pusht-eval`。绑定的 pipeline 类是 `LeWorldModelPipeline`。

系列状态：**Runner 一致性待确认**。

该路径遵循官方 eval.py 配置流程，并在执行前检查 stable-worldmodel 包、任务数据集与非随机策略 checkpoint。

面向评估的世界模型：用于评价动力学，不渲染演示视频。

## 在 WorldFoundry 中运行

用 `wf run leworldmodel --pipeline.task-profile pusht-eval` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`eren23/lewm-models`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh leworldmodel`；下载缺失的公开权重时加 `--download`。
