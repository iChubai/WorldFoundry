LIBERO-Para is a **paraphrase-robustness evaluation recipe** around the LIBERO suite, not a new vision-language-action architecture. The paper is [LIBERO-Para: A Diagnostic Benchmark and Metrics for Paraphrase Robustness in VLA Models](https://arxiv.org/abs/2603.28301) (arXiv 2603.28301; also [hf.co/papers/2603.28301](https://huggingface.co/papers/2603.28301)). The project is [cau-hai-lab.github.io/LIBERO-Para](https://cau-hai-lab.github.io/LIBERO-Para/); code is [cau-hai-lab/LIBERO-Para](https://github.com/cau-hai-lab/LIBERO-Para) (**MIT**). The held-out instruction set is the confirmed Hugging Face dataset [HAI-Lab/LIBERO-Para](https://huggingface.co/HAI-Lab/LIBERO-Para).

WorldFoundry routes action evaluation through an in-tree official-policy adapter (`LiberoParaPipeline`). You supply a LIBERO-capable policy; this card records `lerobot/xvla-libero` as the weight pointer. Required inputs are RGB `image`, language `prompt`, and robot `state`. The artifact is `libero-para_action_trace.json`. This page is the **model / recipe** entry. The scorecard and official-results import live on the separate benchmark page [LIBERO-Para](/docs/evaluation/benchmark-hub/libero-para), built on parent [LIBERO](/docs/evaluation/benchmark-hub/libero).

## What it is for

Measure how a staged VLA behaves when the LIBERO-Goal instruction is reworded while the scene stays fixed. Official materials describe held-out paraphrases along **action** and **object** axes (thousands of instructions across ten LIBERO-Goal scenarios) and a difficulty-aware **PRIDE** metric. Use those as the upstream protocol — this catalog does not ingest a leaderboard.

Pair the recipe with a LIBERO-capable checkpoint. Missing weights are reported as runtime `missing_assets` and are not a catalog blocker; until they are staged the run stays in runtime-plan mode. Task profiles are `vla` (default), `policy_rollout`, and `embodied_benchmark`.

## Runtime contract

`policy_family` is recorded as `libero_para_policy_eval`; `action_representation` as `libero_para_action_trace`. Integration is **Runner parity pending**. Runner / demo status is **not recorded**, and no verified end-to-end GPU artifact sits on this card. This entry has **no policy checkpoint of its own**.

## Running in WorldFoundry

Launch `worldfoundry-eval run libero-para --pipeline.task-profile vla` in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `lerobot/xvla-libero` (or another LIBERO-capable policy) locally first. License on the official tree and dataset is **MIT**.
