LIBERO-Para is a paraphrase-robustness evaluation line around the LIBERO benchmark: it tests how VLA policies behave when task instructions are reworded (paper: hf.co/papers/2603.28301, MIT license). The HAI-Lab/LIBERO-Para dataset is confirmed on Hugging Face; WorldFoundry routes action evaluation through an in-tree official-policy runtime adapter.
