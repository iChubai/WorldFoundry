LIBERO-Para is a **paraphrase-robustness evaluation recipe** around the LIBERO suite, not a new vision-language-action architecture. The paper is [LIBERO-Para: A Diagnostic Benchmark and Metrics for Paraphrase Robustness in VLA Models](https://arxiv.org/abs/2603.28301) (arXiv 2603.28301; also [hf.co/papers/2603.28301](https://huggingface.co/papers/2603.28301)). The project is [cau-hai-lab.github.io/LIBERO-Para](https://cau-hai-lab.github.io/LIBERO-Para/); code is [cau-hai-lab/LIBERO-Para](https://github.com/cau-hai-lab/LIBERO-Para) (**MIT**). The held-out instruction set is the confirmed Hugging Face dataset [HAI-Lab/LIBERO-Para](https://huggingface.co/HAI-Lab/LIBERO-Para).

WorldFoundry registers an in-tree official-policy adapter (`LiberoParaPipeline`), but its configured external LeRobot source and policy target are rejected before planning. The `lerobot/xvla-libero` weights are only a staged pointer; no checkpoint-backed action trace has been verified. The intended inputs are RGB `image`, language `prompt`, and robot `state`, with `libero-para_action_trace.json` as the intended artifact. This page is the **model / recipe** entry. The scorecard and official-results import live on the separate benchmark page [LIBERO-Para](/docs/evaluation/benchmark-hub/libero-para), built on parent [LIBERO](/docs/evaluation/benchmark-hub/libero).

## What it is for

Measure how a staged VLA behaves when the LIBERO-Goal instruction is reworded while the scene stays fixed. Official materials describe held-out paraphrases along **action** and **object** axes (thousands of instructions across ten LIBERO-Goal scenarios) and a difficulty-aware **PRIDE** metric. Use those as the upstream protocol — this catalog does not ingest a leaderboard.

The registered task profiles are `vla` (default), `policy_rollout`, and `embodied_benchmark`. Staging a LIBERO-capable checkpoint alone does not unblock this pipeline; it needs a reviewed in-tree loader compatible with the LeRobot policy.

## Runtime contract

`policy_family` is recorded as `libero_para_policy_eval`; `action_representation` as `libero_para_action_trace`. Integration is **blocked** before planning. Runner / demo status is **not recorded**, and no verified end-to-end GPU artifact sits on this card. This entry has **no policy checkpoint of its own**.

## Running in WorldFoundry

Policy inference through `worldfoundry-eval run libero-para --pipeline.task-profile vla` is currently blocked by the external source and target configuration, even with `lerobot/xvla-libero` staged. The separate benchmark result-import path remains available. License on the official tree and dataset is **MIT**.
