LIBERO-Para 是围绕 LIBERO 基准的指令改写鲁棒性评测线：测试 VLA 策略在任务指令被改写时的表现（论文：hf.co/papers/2603.28301，MIT 许可）。HAI-Lab/LIBERO-Para 数据集已在 Hugging Face 确认； WorldFoundry 通过树内官方策略运行时适配器路由动作评测。

## 架构

这是以评测/数据集为中心的条目，而非新策略架构；记录的工件为指令改写数据集与评测路由。更多内部细节仓库未记录。

## 使用要点

checkpoint 缺失由运行时 missing_assets 报告，不视为 catalog 阻塞；权重就位前运行输出运行时计划。与支持 LIBERO 的策略搭配即可测量指令改写鲁棒性。
