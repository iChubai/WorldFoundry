LingBot-Map is Robbyant's streaming 3D reconstruction model: it consumes image streams and produces camera poses, depth, and point clouds through the GCTStream runtime, supporting both streaming and windowed reconstruction via LingBotMapPipeline. The official runtime is vendored in-tree; checkpoints stay external cache assets.

## Architecture

The vendored GCTStream runtime implements the streaming transformer described in the upstream release (paper arXiv 2604.14141); the wrapper defaults to SDPA attention so FlashInfer is not required for baseline execution (pass use_sdpa=false when FlashInfer is available).

## Usage notes

Runner status is implemented_pending_gpu_parity: import and dispatch are in-tree, and full GPU parity needs staged robbyant/lingbot-map checkpoints (apache-2.0). The pipeline accepts a checkpoint file or a local HF snapshot directory.
