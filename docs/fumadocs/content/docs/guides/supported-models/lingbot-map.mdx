LingBot-Map is Robbyant's streaming 3D reconstruction model: it consumes image streams and produces camera poses, depth, and point clouds through the GCTStream runtime, supporting both streaming and windowed reconstruction via LingBotMapPipeline.

## What it is for

Use `lingbot-map` for feed-forward 3D reconstruction from the input views.

The vendored GCTStream runtime implements the streaming transformer described in the upstream release (paper arXiv 2604.14141); the wrapper defaults to SDPA attention so FlashInfer is not required for baseline execution (pass use_sdpa=false when FlashInfer is available). It is published by Robbyant (Ant Group).

Tasks: 3D reconstruction, streaming 3D reconstruction, camera pose estimation, and depth estimation. Aliases: `lingbot_map` and `robbyant/lingbot-map`. Modalities: image in, depth out.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); artifacts `lingbot_map_predictions.npz`.

CLI task profiles: `default`. WorldFoundry binds `LingBotMapPipeline`.

Family status: **Runner parity pending**.

Stage the robbyant/lingbot-map checkpoint (apache-2.0). The pipeline accepts a checkpoint file or a local HF snapshot directory.

Streaming reconstruction drifts on long sequences without loop closure.

## Running in WorldFoundry

Reconstruct the scene with `wf run lingbot-map --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `robbyant/lingbot-map`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lingbot-map`. Add `--download` to fetch missing public checkpoints.
