LingBot-Map is Robbyant's streaming 3D reconstruction model: it consumes image streams and produces camera poses, depth, and point clouds through the GCTStream runtime, supporting both streaming and windowed reconstruction via LingBotMapPipeline. The official runtime is vendored in-tree; checkpoints stay external cache assets.

## What it is for

`lingbot-map` is the recorded reconstruction line. Start here to emit geometry from the documented views.

The vendored GCTStream runtime implements the streaming transformer described in the upstream release (paper arXiv 2604.14141); the wrapper defaults to SDPA attention so FlashInfer is not required for baseline execution (pass use_sdpa=false when FlashInfer is available). It is published by Robbyant (Ant Group).

Catalog tasks include 3d-reconstruction, streaming-3d-reconstruction, camera-pose-estimation, and depth-estimation. Catalog aliases include `lingbot_map` and `robbyant/lingbot-map`.

## Runtime contract

Required `image` and `video`; optional `actions` (streaming_reconstruction, windowed_reconstruction) and `prompt`; artifacts `lingbot_map_predictions.npz`.

Recorded task profiles: `3d-reconstruction`, `streaming-3d-reconstruction`, `camera-pose-estimation`, and `depth-estimation`. WorldFoundry binds `LingBotMapPipeline`.

## Running in WorldFoundry

Launch `worldfoundry-eval run lingbot-map --pipeline.task-profile 3d-reconstruction` to write geometry. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.10, CUDA 12.8).

Recorded weight repositories include `robbyant/lingbot-map`. Stage assets with `bash scripts/inference/prepare_model_infer.sh lingbot-map`.

Recorded licenses include apache-2.0; status: **Runner parity pending**.
