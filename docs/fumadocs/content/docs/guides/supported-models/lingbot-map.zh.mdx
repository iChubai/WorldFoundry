## 架构

内置的 GCTStream 运行时实现了上游发布所述的流式 Transformer（论文 arXiv 2604.14141）；封装默认使用 SDPA 注意力，基线运行不需要 FlashInfer（FlashInfer 可用时可传 use_sdpa=false）。

## 使用要点

runner 状态为 implemented_pending_gpu_parity：导入与调度已在树内，完整 GPU 一致性需要就位的 robbyant/lingbot-map checkpoint（apache-2.0）。pipeline 接受 checkpoint 文件或本地 HF snapshot 目录。
