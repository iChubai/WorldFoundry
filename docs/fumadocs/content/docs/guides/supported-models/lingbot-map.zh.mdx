LingBot-Map 是蚂蚁灵波的流式 3D 重建模型：通过 GCTStream 运行时处理图像流，产出相机位姿、深度与点云，LingBotMapPipeline 同时支持流式与窗口式重建。

论文：[Geometric Context Transformer for Streaming 3D Reconstruction](https://arxiv.org/abs/2604.14141)（2026）。

项目页：[technology.robbyant.com/lingbot-map](https://technology.robbyant.com/lingbot-map)。代码：[Robbyant/lingbot-map](https://github.com/Robbyant/lingbot-map)。

## 用来做什么

用 `lingbot-map` 从输入视图做前馈 3D 重建。

内置的 GCTStream 运行时实现了上游发布所述的流式 Transformer（论文 arXiv 2604.14141）；封装默认使用 SDPA 注意力，基线运行不需要 FlashInfer（FlashInfer 可用时，可传 use_sdpa=false）。该模型由蚂蚁灵波科技（Robbyant，蚂蚁集团）发布。

任务：3D 重建、streaming-3d-reconstruction、camera-pose-estimation、depth-estimation。别名：`lingbot_map`、`robbyant/lingbot-map`。模态上，它接受图像，输出深度。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；产物 `lingbot_map_predictions.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `LingBotMapPipeline`。

系列状态：**Runner 一致性待确认**。

请先就位 robbyant/lingbot-map checkpoint（apache-2.0）。pipeline 接受 checkpoint 文件或本地 HF snapshot 目录。

## 在 WorldFoundry 中运行

用 `wf run lingbot-map --pipeline.task-profile default` 重建场景。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`robbyant/lingbot-map`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lingbot-map`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
