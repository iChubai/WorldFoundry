LingBot-VA is Robbyant's video-action model, served through a vendored server/client runtime, with a base checkpoint plus RoboTwin and LIBERO-Long post-trained checkpoints (Apache-2.0). On an 80GB GPU the base transformer runs a CUDA forward pass and the LIBERO-Long server starts and listens on its websocket; end-to-end client rollout is not yet validated.

## What it is for

`lingbot-va-base` is a vision-language-action policy: an instruction and observations in, actions out.

A transformer video-action backbone. The provided configs set attn_mode=torch, and the vendored server is launched with --checkpoint-dir pointing at the chosen checkpoint. It is published by Robbyant (Ant Group).

Tasks: VLA, va, vam, and WAM. Aliases: `lingbot_va`, `lingbot-va-base`, `lingbot-va-posttrain-robotwin`, and `lingbot-va-posttrain-libero-long`. Other variants: `lingbot-va-posttrain-robotwin`, `lingbot-va-posttrain-libero-long`.

Suggested benchmarks: [LIBERO](/docs/evaluation/benchmark-hub/libero) (A LIBERO-Long post-trained checkpoint is available), [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (A RoboTwin post-trained checkpoint is available).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `lingbot_va_action_trace.json`.

CLI task profiles: `interactive-video`. WorldFoundry binds `LingBotVAPipeline`.

Start with `lingbot-va-base`. The family has 3 variants, selectable in the command builder above: `lingbot-va-base` (`vam.video_action_modeling`) — Runner parity pending; `lingbot-va-posttrain-robotwin` (`vla.policy_rollout`) — Runner parity pending; `lingbot-va-posttrain-libero-long` (`vla.policy_rollout`) — Runner parity pending. Family status: **Runner parity pending**.

Runs use a server/client split: the vendored server loads the checkpoint and the client drives the rollout.

Client rollout and action decoding are not yet validated end to end.

The inference path covers the model graph, distributed server, client, preprocessing, action diffusion, KV-cache updates, and action decoding.

## Running in WorldFoundry

Run `wf run lingbot-va-base --pipeline.task-profile interactive-video` to predict actions.

It runs in the dedicated environment `worldfoundry-lingbot-va-cu12` (Python 3.10, Cu126 Or Newer, torch==2.9.0).

Weights: `robbyant/lingbot-va-base`, `robbyant/lingbot-va-posttrain-robotwin`, and `robbyant/lingbot-va-posttrain-libero-long`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lingbot-va-base`. Add `--download` to fetch missing public checkpoints.
