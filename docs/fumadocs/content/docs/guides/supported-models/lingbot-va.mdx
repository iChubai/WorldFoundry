**Publisher:** Robbyant (Ant Group) · Company

LingBot-VA is Robbyant's video-action model served through a vendored server/client runtime: base plus RoboTwin and LIBERO-Long post-trained checkpoints are staged (Apache-2.0). On an 80GB CUDA GPU the base transformer passed CUDA forward, post-train checkpoints passed tensor probes, and libero-long server init reached websocket listen — full client rollout remains unverified.

## Architecture

A transformer video-action backbone; staged configs set attn_mode=torch and build_server_command passes --checkpoint-dir to the vendored server. Architecture internals beyond the official repository pointer are not recorded in this repository.

## Usage notes

Runs use a server/client split: server init is verified with staged checkpoints, but official demo parity is not claimed until client rollout and action decoding are validated.
