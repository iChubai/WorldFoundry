LingBot-VA 是蚂蚁灵波科技（Robbyant）的视频-动作模型，经内置的 server/client 运行时提供服务，提供 base 以及 RoboTwin、LIBERO-Long 后训练 checkpoint（Apache-2.0）。在 80GB GPU 上，base transformer 可完成 CUDA 前向，LIBERO-Long 服务可启动并监听 websocket；端到端客户端 rollout 尚未验证。

## 用来做什么

`lingbot-va-base` 是视觉-语言-动作（VLA）策略：输入指令和观测，输出动作。

transformer 视频-动作骨干。随附配置设 attn_mode=torch，内置服务启动时通过 --checkpoint-dir 指向所选 checkpoint。该模型由蚂蚁灵波科技（Robbyant，蚂蚁集团）发布。

任务：视觉-语言-动作（VLA）、va、vam、wam。别名：`lingbot_va`、`lingbot-va-base`、`lingbot-va-posttrain-robotwin`、`lingbot-va-posttrain-libero-long`。同系列还有 `lingbot-va-posttrain-robotwin`、`lingbot-va-posttrain-libero-long`。

推荐评测：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（提供 LIBERO-Long 后训练 checkpoint）、[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（提供 RoboTwin 后训练 checkpoint）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `lingbot_va_action_trace.json`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `LingBotVAPipeline`。

建议从 `lingbot-va-base` 开始。该系列共有 3 个 variant，可在上方命令构建器中切换：`lingbot-va-base`（`vam.video_action_modeling`）：Runner 一致性待确认、`lingbot-va-posttrain-robotwin`（`vla.policy_rollout`）：Runner 一致性待确认、`lingbot-va-posttrain-libero-long`（`vla.policy_rollout`）：Runner 一致性待确认。系列状态：**Runner 一致性待确认**。

运行采用 server/client 分离：内置服务加载 checkpoint，客户端驱动 rollout。

客户端 rollout 与动作解码尚未端到端验证。

## 在 WorldFoundry 中运行

运行 `wf run lingbot-va-base --pipeline.task-profile interactive-video` 预测动作。

运行环境：独立环境 `worldfoundry-lingbot-va-cu12`（Python 3.10，Cu126 Or Newer，torch==2.9.0）。

权重仓库：`robbyant/lingbot-va-base`、`robbyant/lingbot-va-posttrain-robotwin`、`robbyant/lingbot-va-posttrain-libero-long`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lingbot-va-base`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
