**发表机构:** 蚂蚁灵波科技（Robbyant，蚂蚁集团） · 企业

LingBot-VA 是蚂蚁灵波科技（Robbyant）的视频-动作模型，经内置的 server/client 运行时提供服务：base 加 RoboTwin 与 LIBERO-Long 后训练 checkpoint 均已就位（Apache-2.0）。在 80GB CUDA GPU 上，base transformer 通过 CUDA 前向，后训练 checkpoint 通过张量探针，libero-long 服务初始化可达 websocket 监听——完整客户端 rollout 尚未验证。
