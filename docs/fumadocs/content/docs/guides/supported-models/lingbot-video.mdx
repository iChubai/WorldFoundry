## What it is for

`lingbot-video` is a multi-task model for image and video generation and editing.

The dense 1.3B and MoE 30B-A3B (3B active) checkpoints share the inference surface; the MoE line adds a refiner stage. Supported execution paths include direct Diffusers, optional SGLang, FSDP, context-parallel, and CFG-parallel execution. The upstream-recommended stack pins a dedicated Transformers 5 / Diffusers 0.39 environment. It is published by Robbyant (Ant Group).

Tasks: text-to-image, text-to-video, text-image-to-video, and video refinement. Aliases: `lingbot-video-dense` and `lingbot-video-moe`. Modalities: text and image in, image and video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (General T2V quality suite for both checkpoint lines).

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `backend`, `mode`, `height`, `width`, `num-frames`, `num-inference-steps`, and 13 more; artifacts `generated_image`, `generated_video`, and `lingbot_video.mp4`.

CLI task profiles: `t2v`, `ti2v`, and `t2i`. WorldFoundry binds `LingBotVideoGenerationPipeline`.

Family status: **Runner parity pending**.

Defaults for `t2v`: height=480, width=832, seed=42, fps=24 Defaults for `ti2v`: height=480, width=832, seed=42, fps=24.

Validated with the released checkpoints: the dense 1.3B model generates a 121-frame 832x480 video, and a short MoE 30B-A3B T2V clip matches the pinned official runner visually but not pixel for pixel. T2I produces an image even though the default artifact type is the T2V video route. Dense and MoE weights (apache-2.0) are external and must be staged before running.

## Running in WorldFoundry

Run `wf run lingbot-video --pipeline.task-profile t2v` for the default task. Switch tasks in the command builder above to change `--pipeline.task-profile`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch==2.11.0+cu128).

Weights: `robbyant/lingbot-video-dense-1.3b` and `robbyant/lingbot-video-moe-30b-a3b`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lingbot-video`. Add `--download` to fetch missing public checkpoints.
