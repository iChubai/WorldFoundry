LingBot-Video 是蚂蚁灵波（Robbyant）的视频生成系列，支持文生图、文生视频、图文生视频与视频细化。它有两条 checkpoint 线：稠密 1.3B 模型与带细化器的 MoE 30B-A3B 模型。

## 用来做什么

`lingbot-video` 是面向图像与视频生成、编辑的多任务模型。

稠密 1.3B 与 MoE 30B-A3B（激活 3B）两个 checkpoint 共用同一套推理接口；MoE 线增加了细化阶段。支持的执行路径包括直连 Diffusers、可选 SGLang、FSDP、上下文并行与 CFG 并行。上游推荐栈要求专用的 Transformers 5 / Diffusers 0.39 环境。该模型由蚂蚁灵波科技（Robbyant，蚂蚁集团）发布。

任务：文生图、文生视频、text-image-to-video、video-refinement。别名：`lingbot-video-dense`、`lingbot-video-moe`。模态上，它接受文本、图像，输出图像、视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（两条 checkpoint 线通用的文生视频质量评测）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `backend`、`mode`、`height`、`width`、`num-frames`、`num-inference-steps` 等 19 项；产物 `generated_image`、`generated_video`、`lingbot_video.mp4`。

CLI task profile：`t2v`、`ti2v`、`t2i`。绑定的 pipeline 类是 `LingBotVideoGenerationPipeline`。

系列状态：**Runner 一致性待确认**。

`t2v` 默认值：height=480, width=832, num_frames=121, num_inference_steps=40, guidance_scale=3.0, seed=42；`ti2v` 默认值：height=480, width=832, num_frames=121, num_inference_steps=40, guidance_scale=3.0, seed=42。

结构化 `prompt_json` 若包含 `duration`，运行器会按 `duration × fps` 推导帧数并向上取到 `4n+1`。要使用该时长，请省略 `num_frames`，或将其设为相同的推导值；显式冲突会在加载权重前报错。Studio 预设含 `num_frames=121`，若提供不同时长的提示 JSON，需要删掉或改成对应帧数。

已使用公开发布的 checkpoint 验证：稠密 1.3B 模型可生成 121 帧、832x480 视频；MoE 30B-A3B 在官方 T2V 示例 1（时长缩短为 1 秒、40 步）上与固定版本的官方脚本生成的 25 帧 832x480 视频视觉一致，但并非逐像素相同。即使默认产物类型是 T2V 视频路径，T2I 也会产出图像。稠密与 MoE 权重（apache-2.0）为外部资产，运行前需先准备好。

## 在 WorldFoundry 中运行

运行 `wf run lingbot-video --pipeline.task-profile t2v` 执行默认任务。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch==2.11.0+cu128）。

权重仓库：`robbyant/lingbot-video-dense-1.3b`、`robbyant/lingbot-video-moe-30b-a3b`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lingbot-video`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
