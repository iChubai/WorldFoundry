## What it is for

`lingbot-vla-v2-6b` is a vision-language-action policy: an instruction and observations in, actions out.

A Qwen3-VL/MoE policy with a 55-dimensional internal representation, denoising action decoding, image_grid_thw handling, and optional torch.compile paths. Training-only perception teachers are excluded; inference consumes their distilled representations from the trained weights. It is published by Robbyant (Ant Group).

Tasks: VLA, VLA action prediction, VLA policy rollout, and robot policy. Aliases: `lingbot-vla2`, `lingbot-vla-v2-6b`, and `lingbotvla2`.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `action_trace` and `lingbot_vla_v2_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `LingBotVLAV2Pipeline`.

Family status: **Static load only**.

The public 6B checkpoint uses the bundled official-derived inference config; robot-specific downstream checkpoints may override it with their own lingbotvla_cli.yaml.

## Running in WorldFoundry

Run the policy with `wf run lingbot-vla-v2-6b --pipeline.task-profile default`.

It runs in the dedicated environment `worldfoundry-lingbot-vla-v2-cu128` (Python 3.11, CUDA 12.8, torch==2.8.0).

Weights: `robbyant/lingbot-vla-v2-6b` and `Qwen/Qwen3-VL-4B-Instruct`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lingbot-vla-v2-6b`. Add `--download` to fetch missing public checkpoints.
