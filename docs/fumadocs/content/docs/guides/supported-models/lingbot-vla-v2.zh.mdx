LingBot-VLA 2.0 是蚂蚁灵波科技（Robbyant）的 6B 第二代 VLA，基于 Qwen3-VL 专家混合策略，以 robbyant/lingbot-vla-v2-6b 发布，Apache-2.0 许可。WorldFoundry 运行官方策略推理，包括批处理、特征变换、机器人映射与归一化。

## 用来做什么

`lingbot-vla-v2-6b` 是视觉-语言-动作（VLA）策略：输入指令和观测，输出动作。

Qwen3-VL/MoE 策略，55 维内部表征、去噪动作解码、image_grid_thw 处理与可选 torch.compile 路径。仅训练用的感知教师被排除；推理消费其蒸馏进权重的表征。该模型由蚂蚁灵波科技（Robbyant，蚂蚁集团）发布。

任务：视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行、机器人策略。别名：`lingbot-vla2`、`lingbot-vla-v2-6b`、`lingbotvla2`。

LingBot-VLA 2.0 与第一代 LingBot-VLA（`lingbot-vla`）是不同的模型。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`lingbot_vla_v2_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `LingBotVLAV2Pipeline`。

系列状态：**仅静态加载**。

公开 6B checkpoint 使用捆绑的官方派生推理配置；机器人专用下游 checkpoint 可用自己的 lingbotvla_cli.yaml 覆盖。

## 在 WorldFoundry 中运行

用 `wf run lingbot-vla-v2-6b --pipeline.task-profile default` 运行策略。

运行环境：独立环境 `worldfoundry-lingbot-vla-v2-cu128`（Python 3.11，CUDA 12.8，torch==2.8.0）。

权重仓库：`robbyant/lingbot-vla-v2-6b`、`Qwen/Qwen3-VL-4B-Instruct`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lingbot-vla-v2-6b`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
