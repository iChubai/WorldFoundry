LingBot-VLA is Robbyant's 4B vision-language-action policy line: a pretrained base plus RoboTwin post-trained and depth-enhanced RoboTwin variants, all Apache-2.0 with pinned revisions on Hugging Face and ModelScope. WorldFoundry integrates the official policy, feature transforms, robot mapping, and normalization assets directly in-tree as an in-process runtime.

## What it is for

`lingbot-vla-4b` is a vision-language-action policy: an instruction and observations in, actions out.

A 4B policy backbone with feature transforms and per-robot mappings. It is published by Robbyant (Ant Group).

Tasks: VLA, VLA action prediction, VLA policy rollout, and robot policy. Aliases: `lingbot-vla-4b`, `lingbot-vla-4b-posttrain-robotwin`, and `lingbot-vla-4b-depth-posttrain-robotwin`. Other variants: `lingbot-vla-4b-posttrain-robotwin`, `lingbot-vla-4b-depth-posttrain-robotwin`.

Suggested benchmarks: [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (Dedicated RoboTwin post-trained checkpoints).

LingBot VLA policy rollout. The 6B successor is [LingBot-VLA v2](/docs/guides/supported-models/lingbot-vla-v2).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `action_trace` and `lingbot_vla_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `LingBotVLAPipeline`.

Start with `lingbot-vla-4b`. The family has 3 variants, selectable in the command builder above: `lingbot-vla-4b` (`vla.pretraining`) — Runner parity pending; `lingbot-vla-4b-posttrain-robotwin` (`vla.policy_rollout`) — Runner parity pending; `lingbot-vla-4b-depth-posttrain-robotwin` (`vla.policy_rollout`) — Runner parity pending. Family status: **Static load only**.

Use the RoboTwin post-train for simulator benchmarks (the depth variant adds depth input) and the base for fine-tuning. For the newer 6B generation see lingbot-vla-v2.

## Running in WorldFoundry

Run `wf run lingbot-vla-4b --pipeline.task-profile default` to predict actions.

It runs in the dedicated environment `worldfoundry-lingbot-vla-v1-cu128` (Python 3.11, CUDA 12.8, torch==2.8.0).

Weights: `robbyant/lingbot-vla-4b`, `robbyant/lingbot-vla-4b-posttrain-robotwin`, and `robbyant/lingbot-vla-4b-depth-posttrain-robotwin` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lingbot-vla-4b`. Add `--download` to fetch missing public checkpoints.
