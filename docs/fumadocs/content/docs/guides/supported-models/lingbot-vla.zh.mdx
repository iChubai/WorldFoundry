LingBot-VLA 是蚂蚁灵波科技（Robbyant）的 4B 视觉-语言-动作策略线：预训练 base，加 RoboTwin 后训练与深度增强 RoboTwin 变体，全部 Apache-2.0，并在 Hugging Face 与 ModelScope 锁定 revision。WorldFoundry 将官方策略、特征变换、机器人映射与归一化资产直接内置树内，作为进程内运行时。

## 用来做什么

`lingbot-vla-4b` 是视觉-语言-动作（VLA）策略：输入指令和观测，输出动作。

4B 策略骨干，配特征变换与按机器人映射。该模型由蚂蚁灵波科技（Robbyant，蚂蚁集团）发布。

任务：视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行、机器人策略。别名：`lingbot-vla-4b`、`lingbot-vla-4b-posttrain-robotwin`、`lingbot-vla-4b-depth-posttrain-robotwin`。同系列还有 `lingbot-vla-4b-posttrain-robotwin`、`lingbot-vla-4b-depth-posttrain-robotwin`。

推荐评测：[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（有专门的 RoboTwin 后训练 checkpoint）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`lingbot_vla_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `LingBotVLAPipeline`。

建议从 `lingbot-vla-4b` 开始。该系列共有 3 个 variant，可在上方命令构建器中切换：`lingbot-vla-4b`（`vla.pretraining`）：Runner 一致性待确认、`lingbot-vla-4b-posttrain-robotwin`（`vla.policy_rollout`）：Runner 一致性待确认、`lingbot-vla-4b-depth-posttrain-robotwin`（`vla.policy_rollout`）：Runner 一致性待确认。系列状态：**仅静态加载**。

模拟器基准用 RoboTwin 后训练版（depth 变体增加深度输入），微调用 base。更新的 6B 世代请见 lingbot-vla-v2。

## 在 WorldFoundry 中运行

运行 `wf run lingbot-vla-4b --pipeline.task-profile default` 预测动作。

运行环境：独立环境 `worldfoundry-lingbot-vla-v1-cu128`（Python 3.11，CUDA 12.8，torch==2.8.0）。

权重仓库：`robbyant/lingbot-vla-4b`、`robbyant/lingbot-vla-4b-posttrain-robotwin`、`robbyant/lingbot-vla-4b-depth-posttrain-robotwin` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lingbot-vla-4b`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
