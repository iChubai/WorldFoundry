## 用来做什么

需要 catalog 上的 VLA 策略时选 `lingbot-vla-4b`：指令与观测进、动作轨迹出。用来滚动已记录策略，不是用来训练新策略。

4B 策略骨干，配特征变换与按机器人映射；运行时使用共享的 WorldFoundry 核心设备选择、编译调度、Hugging Face 快照协调与流式 safetensors 加载。更多内部细节仓库未记录。该模型由蚂蚁灵波科技（Robbyant，蚂蚁集团）发布。

catalog 记录的任务包括 视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行、机器人策略。别名包括 `lingbot-vla-4b`、`lingbot-vla-4b-posttrain-robotwin`、`lingbot-vla-4b-depth-posttrain-robotwin`。同系列还有 `lingbot-vla-4b-posttrain-robotwin`、`lingbot-vla-4b-depth-posttrain-robotwin`。

记录的评测入口包括[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（有专门的 RoboTwin 后训练 checkpoint）。

## 运行时契约

必填 `prompt`、`image`、`state`；可选 `model_id` (lingbot-vla)、`state_dim` (14)、`camera_keys` (observation.images.cam_high, observation.images.cam_left_wrist, observation.images.cam_right_wrist)、`policy_family`、`action_representation`；产物 `action_trace`、`lingbot_vla_action_trace.json`。

记录的任务 profile：`vla`、`vla.action_prediction`、`vla.policy_rollout`、`robot_policy`、`vla.pretraining`。绑定的 pipeline 类是 `LingBotVLAPipeline`。

起步 variant 是 `lingbot-vla-4b`。catalog 登记了 3 个 variant（上方卡片）：`lingbot-vla-4b`（`vla.pretraining`）：仅静态加载、`lingbot-vla-4b-posttrain-robotwin`（`vla.policy_rollout`）：仅静态加载、`lingbot-vla-4b-depth-posttrain-robotwin`（`vla.policy_rollout`）：仅静态加载。系列状态：**仅静态加载**。

模拟器基准用 RoboTwin 后训练版（depth 变体增加深度输入），微调用 base。 更新的 6B 世代请见 lingbot-vla-v2。

此条目仓库未记录 GPU rollout 验证。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run lingbot-vla-4b --pipeline.task-profile vla.pretraining`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是独立 profile `worldfoundry-lingbot-vla-v1-cu128`（Python 3.11，CUDA 12.8，torch==2.8.0）。

记录的权重仓库包括 `robbyant/lingbot-vla-4b`、`robbyant/lingbot-vla-4b-posttrain-robotwin`、`robbyant/lingbot-vla-4b-depth-posttrain-robotwin` 等。就位权重用 `bash scripts/inference/prepare_model_infer.sh lingbot-vla-4b`。

记录 license 为 apache-2.0；状态：**仅静态加载**。
