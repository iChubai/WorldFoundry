LingBot-World Base Act is the action-conditioned sibling of LingBot-World: instead of camera poses it consumes an action matrix, making it the interactive-control profile of the family. It loads the official Base-Act preview checkpoint, not Base-Cam.

## What it is for

Use `lingbot-world-act` to step a world forward with actions and render the resulting frames.

The inference path reuses the in-tree LingBot runtime and central Wan base modules (apache-2.0). Inputs are prompt, image, pose, and action_matrix. It is published by Robbyant (Ant Group).

Tasks: interactive world model and action-conditioned video.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Action-conditioned world-rollout quality).

## Runtime contract

Inputs `prompt`, `image`, `pose`, and `action-matrix`; artifacts `lingbot-world-act.mp4`.

CLI task profiles: `interactive-world-model`, `action-conditioned-video`, and `world_model`. WorldFoundry binds `LingBotPipeline`.

Validated with the Base-Act preview checkpoint: the public runner generates a 17-frame, 8-step clip (544 × 720, 16 fps) from the official cat image and forward WASD actions in the dedicated LingBot environment. Action adherence has not been measured.

Only the 17-frame, 8-step configuration is validated; action adherence and the official 161-frame recipe are untested.

## Running in WorldFoundry

Run `wf run lingbot-world-act --pipeline.task-profile interactive-world-model` to roll out the world model. Switch tasks in the command builder above to change `--pipeline.task-profile`.

Use the dedicated `lingbot-world` environment (Python 3.10, CUDA 12.1). act2cam output in the unified environment is near-black.

Weights: `robbyant/lingbot-world-base-act-preview`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lingbot-world-act`. Add `--download` to fetch missing public checkpoints.

The official 161-frame recipe is untested.
