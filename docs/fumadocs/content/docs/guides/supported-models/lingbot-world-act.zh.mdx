LingBot-World Base Act 是 LingBot-World 的动作条件版本：它以动作矩阵而非相机位姿为输入，是该家族中用于交互控制的模型。它加载官方 Base-Act 预览 checkpoint，而不是 Base-Cam。

## 用来做什么

用 `lingbot-world-act` 以动作推进世界并渲染出相应画面。

推理路径复用树内 LingBot 运行时与中央 Wan 基座模块（apache-2.0）。输入为提示词、图像、位姿与 action_matrix。该模型由蚂蚁灵波科技（Robbyant，蚂蚁集团）发布。

任务：交互式世界模型、动作条件视频。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件世界滚动生成质量）。

## 运行时契约

输入 `prompt`、`image`、`pose`、`action-matrix`；产物 `lingbot-world-act.mp4`。

CLI task profile：`interactive-world-model`、`action-conditioned-video`、`world_model`。绑定的 pipeline 类是 `LingBotPipeline`。

已使用 Base-Act 预览权重验证：公开 runner 在专属 LingBot 环境中，使用官方猫图和前进 WASD 动作生成 17 帧、8 步片段（544 × 720，16 fps）。动作贴合度尚未测量。

官方完整长度配置下的画质与动作贴合度仍待评测。

## 在 WorldFoundry 中运行

运行 `wf run lingbot-world-act --pipeline.task-profile interactive-world-model` 执行世界模型推理。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

使用专属 `lingbot-world` 环境（Python 3.10、CUDA 12.1）；统一环境下 act2cam 输出近黑画面。

权重仓库：`robbyant/lingbot-world-base-act-preview`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lingbot-world-act`；下载缺失的公开权重时加 `--download`。

官方 161 帧配方尚未验证。
