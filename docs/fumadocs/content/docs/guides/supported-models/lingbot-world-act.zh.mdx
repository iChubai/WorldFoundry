LingBot-World Base Act 是 LingBot-World 的动作条件同门：它消费动作矩阵而非相机位姿，是该家族的交互控制档案。它独立记录，并解析官方 Base-Act 预览 checkpoint——绝不以 Base-Cam 顶替。

## 用来做什么

`lingbot-world-act` 是记录的交互世界线。要用动作推进世界时从这里起步。

推理路径复用树内 LingBot 运行时与中央 Wan 基座模块（apache-2.0）。输入为提示词、图像、位姿与 action_matrix。该模型由蚂蚁灵波科技（Robbyant，蚂蚁集团）发布。

catalog 记录的任务包括 交互式世界模型、动作条件视频。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件世界滚动生成质量）。

## 运行时契约

必填 `prompt`、`image`、`pose`、`action_matrix`；产物 `lingbot-world-act.mp4`。

记录的任务 profile：`interactive-world-model`、`action-conditioned-video`。绑定的 pipeline 类是 `LingBotPipeline`。

系列状态：**Runner 一致性待确认**。

完整 GPU 产物一致性待权重就位。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run lingbot-world-act --pipeline.task-profile interactive-world-model`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。
