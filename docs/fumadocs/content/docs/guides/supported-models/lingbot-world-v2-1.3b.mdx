LingBot-World-V2 1.3B is Robbyant's causal-fast camera-controlled world model, a smaller sibling of the 14B lingbot-world-v2 with its own checkpoint and defaults.

- Weights: [robbyant/lingbot-world-v2-1.3b-causal-fast](https://huggingface.co/robbyant/lingbot-world-v2-1.3b-causal-fast), revision `7e36a5f919f86cb4255cc9bfc30adb44963fbde1`.
- Source: [Robbyant/lingbot-world-v2](https://github.com/Robbyant/lingbot-world-v2), revision `94f43115de8d4a4f9f282126528c300a0b232c5f`.
- Load root-level indexed DiT shards separately; `shared_assets_path` supplies Wan2.1 UMT5, tokenizer, and VAE assets.
- Defaults: one GPU, 317 frames, chunk_size=4, shift=5, 16 FPS, no T5/DiT FSDP. The first chunk emits 13 frames and steady chunks emit 16.
- Camera conditions are reused within each chunk, reducing projections while preserving pixels.
- License: **CC-BY-NC-SA-4.0, non-commercial, attribution, share-alike**.

See [Causal Wan streaming inference](/docs/guides/causal-wan-streaming) for loading, shared acceleration effects, and the Studio sensor contract.

## What it is for

`lingbot-world-v2-1.3b` conditions video generation on camera poses.

30 transformer layers, hidden width 1536, FFN width 8960 and 12 attention heads; shared Wan2.1 VAE and UMT5 text encoding. It is published by Robbyant (Ant Group).

Tasks: image-to-world-video, camera-controlled video, and interactive world model. Aliases: `lingbot-v2-1.3b`. Modalities: image and camera pose in, world state and video out.

## Runtime contract

Inputs `image`, `prompt`, and `action-path` (bundled samples are used when omitted); options `size`, `frame-num`, `chunk-size`, `seed`, `sample-shift`, `local-attn-size`, and 6 more; artifact `lingbot-world-v2-1.3b.mp4`.

CLI task profile: `image-camera-video`. WorldFoundry binds `LingBotWorldV2SmallPipeline`. Family status: **Runner parity pending**. Defaults for `image-camera-video`: size=480*832, seed=42.

Offline-first. Supply shared_assets_path pointing to the Wan2.1 T5/tokenizer/VAE assets.

CC BY-NC-SA 4.0 non-commercial license. Scaled INT8/FP8 attention is an explicit approximate option, not the default.

## Running in WorldFoundry

Generate a camera-controlled clip with `wf run lingbot-world-v2-1.3b --pipeline.task-profile image-camera-video`.

It runs in the dedicated environment `lingbot-world-v2` (Python 3.10, CUDA 12.1, torch==2.5.1).

Weights: `robbyant/lingbot-world-v2-1.3b-causal-fast` and `Wan-AI/Wan2.1-T2V-1.3B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lingbot-world-v2-1.3b`. Add `--download` to fetch missing public checkpoints.
