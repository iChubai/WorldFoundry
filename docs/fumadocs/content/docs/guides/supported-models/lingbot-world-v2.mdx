LingBot-World-V2 (also aliased lingbot-world-infinity) is the second generation of Robbyant's world model: a 14B causal-fast model for image-to-world video with camera control. Validated with the released checkpoint: the causal-fast route generates a decodable 9-frame 848x464 video at 16 FPS on one 80 GB GPU.

## What it is for

Use `lingbot-world-v2` when the viewpoint must follow a given camera path.

Uses WorldFoundry's shared Wan, T5, VAE, scheduler, FSDP, and media components. Only the released causal-fast route is included; training and the unreleased causal-pretrain and bidirectional routes are not. The checkpoint is robbyant/lingbot-world-v2-14b-causal-fast. It is published by Robbyant (Ant Group).

Tasks: image-to-world-video, camera-controlled video, and interactive world model. Aliases: `lingbot-world-infinity` and `lingbot-v2`. Modalities: image in, world state and video out.

Suggested benchmarks: [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-control adherence of world rollouts), [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (General world-rollout quality).

## Runtime contract

Inputs `image`, `prompt`, and `action-path` (bundled samples are used when omitted); options `size`, `frame-num`, `chunk-size`, `seed`, `sample-shift`, `local-attn-size`, and 6 more; artifacts `generated_world_video` and `lingbot-world-v2.mp4`.

CLI task profiles: `image-camera-video`. WorldFoundry binds `LingBotWorldV2Pipeline`.

Family status: **Runner parity pending**.

Defaults for `image-camera-video`: size=480*832, seed=42.

The official causal-fast recipe uses eight GPUs; a four-GPU compact topology is also supported. When launched inside an existing torchrun process group, inference runs in that group without starting nested torchrun workers.

## Running in WorldFoundry

Run `wf run lingbot-world-v2 --pipeline.task-profile image-camera-video` to follow the camera path.

It runs in the dedicated environment `lingbot-world-v2` (Python 3.10, CUDA 12.1, torch==2.5.1).

Weights: `robbyant/lingbot-world-v2-14b-causal-fast`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lingbot-world-v2`. Add `--download` to fetch missing public checkpoints.
