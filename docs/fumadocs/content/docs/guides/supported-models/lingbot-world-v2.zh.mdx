LingBot-World-V2（别名 lingbot-world-infinity）是蚂蚁灵波世界模型的第二代：14B 的 causal-fast 模型，可根据图像生成带相机控制的世界视频。已使用公开发布的权重验证：causal-fast 路径可在单张 80 GB GPU 上生成可解码的 9 帧 848x464、16 FPS 视频。

## 用来做什么

视角需要沿指定相机路径运动时，用 `lingbot-world-v2`。

复用 WorldFoundry 共享的 Wan、T5、VAE、调度器、FSDP 与媒体组件。仅包含已发布的 causal-fast 路径；不包含训练与未发布的 causal-pretrain、双向路径。checkpoint 为 robbyant/lingbot-world-v2-14b-causal-fast。该模型由蚂蚁灵波科技（Robbyant，蚂蚁集团）发布。

任务：image-to-world-video、相机可控视频、交互式世界模型。别名：`lingbot-world-infinity`、`lingbot-v2`。模态上，它接受图像，输出世界状态、视频。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（世界滚动生成的相机控制贴合度）、[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（世界滚动生成的总体质量）。

## 运行时契约

输入 `image`、`prompt`、`action-path`（不传时使用内置示例）；参数 `size`、`frame-num`、`chunk-size`、`seed`、`sample-shift`、`local-attn-size` 等 12 项；产物 `generated_world_video`、`lingbot-world-v2.mp4`。

CLI task profile：`image-camera-video`。绑定的 pipeline 类是 `LingBotWorldV2Pipeline`。

系列状态：**Runner 一致性待确认**。

`image-camera-video` 的默认值：size=480*832, seed=42。

官方 causal-fast 配方为八卡，也支持四卡紧凑拓扑。在已有 torchrun 进程组内启动时，推理直接在该组内运行，不再嵌套启动 torchrun。

## 在 WorldFoundry 中运行

运行 `wf run lingbot-world-v2 --pipeline.task-profile image-camera-video` 沿相机路径生成视频。

运行环境：独立环境 `lingbot-world-v2`（Python 3.10，CUDA 12.1，torch==2.5.1）。

权重仓库：`robbyant/lingbot-world-v2-14b-causal-fast`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lingbot-world-v2`；下载缺失的公开权重时加 `--download`。

状态：**Runner 一致性待确认**。
