LingBot-World is Robbyant's camera-controlled world video model. Validated with the base-cam checkpoint on the official camera-control demo: the pipeline generates all 161 frames at 832x464 and 16 fps with 70 denoising steps, and a four-A100 compact topology completes the same full setting.

## What it is for

Use `lingbot-world` when the viewpoint must follow a given camera path.

The official base-cam recipe uses eight GPUs with DiT/T5 FSDP plus Ulysses sequence parallelism; WorldFoundry also supports a four-GPU compact topology (both 4 and 8 divide the model's 40 attention heads). A shared timestep embedding preserves floating precision for integer scheduler timesteps, preventing distributed sequence-parallel output corruption. It is published by Robbyant (Ant Group).

Tasks: world, camera control, and world model.

Suggested benchmarks: [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-control adherence of world rollouts), [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (General world-rollout quality).

## Runtime contract

Inputs `image` and `prompt` (bundled samples are used when omitted); options `action-path`, `frames`, `steps`, and `seed`; artifacts `lingbot-world.mp4`.

CLI task profiles: `image-navigation-video` and `image-action-video`. WorldFoundry binds `LingBotPipeline`.

Family status: **Verified**.

Defaults for `image-navigation-video`: frames=161, seed=42 Defaults for `image-action-video`: frames=21, seed=42.

The wrapper resolves only local HFD or explicit checkpoint directories — no runtime downloads. Base-cam runs in the dedicated `lingbot-world` environment; Base-Act has its own page, [LingBot-World Act](/docs/guides/supported-models/lingbot-world-act). The official Fast checkpoint uses Base-Cam's shared T5/VAE assets plus its own 16 shards. Validated on one H100: Fast generates a fully decodable 21-frame, 544 × 720, 16 fps clip. Select it with `runtime_variant=fast` and `fast_model_path`; Fast frame counts must be 9, 21, 33, … because its three-latent-frame chunks otherwise truncate the clip. Longer Fast rollouts and camera adherence remain unmeasured.

## Running in WorldFoundry

Generate a camera-controlled clip with `wf run lingbot-world --pipeline.task-profile image-navigation-video`. Switch tasks in the command builder above to change `--pipeline.task-profile`.

Recorded weight repositories include `robbyant/lingbot-world-base-cam`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lingbot-world`. Add `--download` to fetch missing public checkpoints.
