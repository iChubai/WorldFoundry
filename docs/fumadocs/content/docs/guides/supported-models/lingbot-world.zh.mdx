**发表机构:** 蚂蚁灵波科技（Robbyant，蚂蚁集团） · 企业

LingBot-World 是蚂蚁灵波的相机可控世界视频模型。本 catalog 中它已完整验证：base-cam checkpoint 于 2026-07-28 按官方 161 帧、70 步相机控制 demo 完成全质量产物验证——包括一个四张 A100 的紧凑拓扑，自适应调整 FSDP/Ulysses 设置并产出连贯产物。

## 架构

官方 base-cam 配方使用八卡，DiT/T5 FSDP 加 Ulysses 序列并行；Workspace 亦支持四卡紧凑拓扑（4 与 8 都能整除模型的 40 个注意力头）。共享的时间步嵌入为整数调度时间步保留浮点精度，避免分布式序列并行的输出损坏。

## 使用要点

封装仅解析本地 HFD 或显式 checkpoint 目录——无运行时下载。base-cam 在专属 lingbot-world conda 环境档案中运行；Base-Act 单独记录，目前仅 Fast checkpoint 不可得。
