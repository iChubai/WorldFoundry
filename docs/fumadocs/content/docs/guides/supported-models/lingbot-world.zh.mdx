LingBot-World 是蚂蚁灵波的相机可控世界视频模型。已使用 base-cam checkpoint 按官方相机控制 demo 验证：pipeline 以 70 步去噪生成全部 161 帧（832x464，16 fps），由四张 A100 组成的紧凑拓扑也能运行相同的完整配置。

## 用来做什么

视角需要沿指定相机路径运动时，用 `lingbot-world`。

官方 base-cam 配方使用八卡，DiT/T5 FSDP 加 Ulysses 序列并行；WorldFoundry 亦支持四卡紧凑拓扑（4 与 8 都能整除模型的 40 个注意力头）。共享的时间步嵌入为整数调度时间步保留浮点精度，避免分布式序列并行的输出损坏。该模型由蚂蚁灵波科技（Robbyant，蚂蚁集团）发布。

任务：世界模型、相机控制。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（世界滚动生成的相机控制贴合度）、[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（世界滚动生成的总体质量）。

## 运行时契约

输入 `image`、`prompt`（不传时使用内置示例）；参数 `action-path`、`frames`、`steps`、`seed`；产物 `lingbot-world.mp4`。

CLI task profile：`image-navigation-video`、`image-action-video`。绑定的 pipeline 类是 `LingBotPipeline`。

系列状态：**已验证**。

`image-navigation-video` 的默认值：frames=161, seed=42；`image-action-video` 的默认值：frames=21, seed=42。

封装仅解析本地 HFD 或显式 checkpoint 目录，不在运行时下载。Base-Cam 在专属 `lingbot-world` 环境中运行；Base-Act 另有独立页面 [LingBot-World Act](/zh/docs/guides/supported-models/lingbot-world-act)。官方 Fast 权重复用 Base-Cam 的 T5/VAE 组件，并使用独立的 16 个分片。已在单张 H100 上验证：Fast 生成可完整解码的 21 帧、544 × 720、16 fps 视频。选择 Fast 时传入 `runtime_variant=fast` 和 `fast_model_path`；由于上游按三个潜变量帧分块，帧数需取 9、21、33 等，否则会被截短。更长的 Fast 视频和相机贴合度尚未测量。

## 在 WorldFoundry 中运行

用 `wf run lingbot-world --pipeline.task-profile image-navigation-video` 生成相机可控视频。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：独立环境 `lingbot-world`（Python 3.10，CUDA 12.1，torch==2.5.1）。

权重仓库：`robbyant/lingbot-world-base-cam`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lingbot-world`；下载缺失的公开权重时加 `--download`。
