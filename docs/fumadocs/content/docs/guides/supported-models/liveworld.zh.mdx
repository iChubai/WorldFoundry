LiveWorld 是相机可控的视频到视频世界模型，采用以监控画面为中心的工作流：输入视频加几何 NPZ，在新的相机行为下重新渲染场景。WorldFoundry 以官方源码运行，并提供专用的几何 NPZ 输入路径。

## 用来做什么

`liveworld` 生成相机可控视频：输入相机轨迹，输出沿轨迹运动的视频。

LiveWorld 在 Wan2.1-T2V-14B 基座上叠加自有的 LoRA 与 state adapter（ZichengD/LiveWorld），并用 Qwen3-VL-8B-Instruct 做实体检测、SAM3 做分割、STream3R 做重建、DINOv3 做匹配。

任务：相机可控视频、视频到视频、世界模型。模态上，它接受视频，输出视频。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（重渲染视频的相机行为贴合度）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `liveworld.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `LiveWorldPipeline`。

系列状态：**Runner 一致性待确认**。

输入为提示词、视频与 geometry_npz。运行前需在本地就位全部六个 checkpoint snapshot：ZichengD/LiveWorld、Wan2.1-T2V-14B、Qwen3-VL-8B-Instruct、SAM3、STream3R 与 DINOv3。

除视频输入外还需要几何 NPZ。

## 在 WorldFoundry 中运行

用 `wf run liveworld --pipeline.task-profile default` 生成相机可控视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`ZichengD/LiveWorld`、`Wan-AI/Wan2.1-T2V-14B`、`Qwen/Qwen3-VL-8B-Instruct` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh liveworld`；下载缺失的公开权重时加 `--download`。
