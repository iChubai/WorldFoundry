LoGeR reconstructs 3D scenes, camera trajectories, and point clouds from input views. Validated with the Junyi42/LoGeR checkpoint: inference produces finite camera poses, depth, and a 601,570-vertex point cloud.

## What it is for

`loger` recovers 3D geometry from images: views in, a reconstruction, camera trajectory, or point cloud out.

A reconstruction-plus-trajectory model that exports binary PLY artifacts (upstream: Junyi42/LoGeR, apache-2.0).

Tasks: 3D reconstruction, trajectory, and point cloud. Output modalities: point cloud.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `interval`; artifacts `result.ply`.

CLI task profiles: `interactive-video`. WorldFoundry binds `LoGeRPipeline`.

Family status: **Verified**.

Runs in the shared worldfoundry-unified-cu128 environment; the exported point clouds can feed point-cloud navigation pipelines.

## Running in WorldFoundry

Run `wf run loger --pipeline.task-profile interactive-video` to write the geometry.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Junyi42/LoGeR`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh loger`. Add `--download` to fetch missing public checkpoints.
