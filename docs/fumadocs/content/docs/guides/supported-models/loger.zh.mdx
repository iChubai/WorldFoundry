## 用来做什么

`loger` 从图像恢复 3D 几何：输入多视图，输出重建结果、相机轨迹或点云。

「重建+轨迹」模型，导出二进制 PLY 产物（上游：Junyi42/LoGeR，apache-2.0）。

任务：3D 重建、轨迹、点云。输出模态为点云。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `interval`；产物 `result.ply`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `LoGeRPipeline`。

系列状态：**已验证**。

在共享的 worldfoundry-unified-cu128 环境中运行；导出的点云可接入点云导航管线。

## 在 WorldFoundry 中运行

运行 `wf run loger --pipeline.task-profile interactive-video` 写出几何结果。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`Junyi42/LoGeR`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh loger`；下载缺失的公开权重时加 `--download`。
