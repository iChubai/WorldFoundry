LongCat-Video is Meituan's open video generation model focused on long-video generation: text-to-video, image-to-video, and native video continuation in one model. The pipeline runs the official demo scripts and executes only when you pass execute=True. Weights are MIT-licensed at meituan-longcat/LongCat-Video.

## What it is for

Use `longcat-video` for both text-to-video and image-to-video generation.

Upstream positions LongCat-Video as a unified DiT-based generator where continuation is a first-class task, enabling minutes-long videos. It is published by Meituan (LongCat).

Tasks: text-to-video, image-to-video, video continuation, and long video generation. Modalities: text and image in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Baseline T2V quality suite), [ChronoMagic-Bench](/docs/evaluation/benchmark-hub/chronomagic-bench) (Long-horizon generation matches LongCat's continuation focus).

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `negative-prompt`, `task-type`, `num-frames`, `fps`, `height`, `width`, and 7 more; artifacts `generated_video` and `longcat_video.mp4`.

CLI task profiles: `official-t2v`. WorldFoundry binds `LongCatVideoPipeline`.

Family status: **Runner parity pending**.

`official-t2v` defaults: negative_prompt=Bright tones, overexposed, static, blurred details, subtitles, style, works, paintings, images, static, overall gray, worst quality, low quality, JPEG compression residue, ugly, incomplete, extra fingers, poorly drawn hands, poorly drawn faces, deformed, disfigured, misshapen limbs, fused fingers, still picture, messy background, three legs, many people in the background, walking backwards, num_frames=93, fps=15, height=480, width=832, num_inference_steps=50.

Remember the execute=True gate: default calls fail fast by design. Stage the LongCat checkpoints locally before running.

## Running in WorldFoundry

Generate a clip with `wf run longcat-video --pipeline.task-profile official-t2v`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

The four task entrypoints run as installed Python modules under `worldfoundry.synthesis.visual_generation.longcat_video.longcat_video_runtime`. More than one context-parallel worker runs under single-node torchrun; `enable_compile` compiles the DiT.

Weights: `meituan-longcat/LongCat-Video`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh longcat-video`. Add `--download` to fetch missing public checkpoints.
