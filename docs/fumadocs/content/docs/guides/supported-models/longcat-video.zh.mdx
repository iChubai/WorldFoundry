LongCat-Video 是美团开源的视频生成模型，主打长视频：文生视频、图生视频与原生视频续写集于一个模型。pipeline 运行官方 demo 脚本，只有显式传入 execute=True 才会执行。权重为 MIT 许可，位于 meituan-longcat/LongCat-Video。

## 用来做什么

用 `longcat-video` 同时完成文生视频和图生视频。

上游将 LongCat-Video 定位为统一的 DiT 系生成器，视频续写与其他任务同等受支持，可生成分钟级视频。该模型由美团（LongCat 团队）发布。

任务：文生视频、图生视频、video-continuation、长视频生成。模态上，它接受文本、图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（基础文生视频质量评测）、[ChronoMagic-Bench](/zh/docs/evaluation/benchmark-hub/chronomagic-bench)（长时程生成评测，契合其续写定位）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `negative-prompt`、`task-type`、`num-frames`、`fps`、`height`、`width` 等 13 项；产物 `generated_video`、`longcat_video.mp4`。

CLI task profile：`official-t2v`。绑定的 pipeline 类是 `LongCatVideoPipeline`。

系列状态：**Runner 一致性待确认**。

`official-t2v` 默认值：negative_prompt=Bright tones, overexposed, static, blurred details, subtitles, style, works, paintings, images, static, overall gray, worst quality, low quality, JPEG compression residue, ugly, incomplete, extra fingers, poorly drawn hands, poorly drawn faces, deformed, disfigured, misshapen limbs, fused fingers, still picture, messy background, three legs, many people in the background, walking backwards, num_frames=93, fps=15, height=480, width=832, num_inference_steps=50。

只有设置 execute=True 才会执行，默认调用会按设计快速失败。运行前请先在本地准备好 LongCat checkpoint。

## 在 WorldFoundry 中运行

用 `wf run longcat-video --pipeline.task-profile official-t2v` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`meituan-longcat/LongCat-Video`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh longcat-video`；下载缺失的公开权重时加 `--download`。
