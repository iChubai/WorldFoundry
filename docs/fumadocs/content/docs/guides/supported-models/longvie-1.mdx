LongVie is a controllable ultra-long video generation framework from the Vchitect team: it drives a Wan-based diffusion backbone with dense depth and sparse point/track control videos to keep minute-scale videos consistent. longvie-1 is the first-generation adapter; upstream has not published first-generation weights, and the public Vchitect/LongVie2 checkpoint is not interchangeable.

## What it is for

Use `longvie-1` to generate a video that starts from a reference image.

LongVie-1 runs a Wan model with its encoders, VAE, and VACE control roles on the shared staged runner. The native runner preserves the official 640x352 segment size and the history/noise continuation state, with optional USP ring/ulysses distributed controls. It is published by Shanghai AI Laboratory (Vchitect).

Tasks: image-to-video, long video generation, depth-controlled video, and trajectory-controlled video. Aliases: `longvie`, `longvie1`, and `longvie-v1`. Modalities: image in, video and depth out.

Suggested benchmarks: [ChronoMagic-Bench](/docs/evaluation/benchmark-hub/chronomagic-bench) (Long-horizon suite for minute-scale generation).

LongVie-1 generates long I2V clips with depth and point/track control. For the second generation with public weights, use [LongVie 2](/docs/guides/supported-models/longvie-2).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `frames`, `fps`, `height`, `width`, `steps`, `seed`, and 3 more; artifacts `generated_video` and `longvie-1.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `LongVie1Pipeline`.

Family status: **Runner parity pending**.

Default calls fail fast unless execute=True. Execution additionally requires an explicitly staged first-generation control checkpoint because no official LongVie-1 weights are published. For the public checkpoint-backed route, use longvie-2.

## Running in WorldFoundry

Animate a still image with `wf run longvie-1 --pipeline.task-profile interactive-video`.

It runs in the dedicated environment `worldfoundry-longvie-cu128` (Python 3.10, CUDA 12.8).

Weights: `Wan-AI/Wan2.1-I2V-14B-480P` and `Wan-AI/Wan2.1-T2V-1.3B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh longvie-1`. Add `--download` to fetch missing public checkpoints.
