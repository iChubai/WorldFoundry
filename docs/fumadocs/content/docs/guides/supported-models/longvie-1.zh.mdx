LongVie 是 Vchitect 团队的可控超长视频生成框架：用稠密深度与稀疏点/轨迹控制视频来驱动基于 Wan 的扩散基座，使分钟级视频保持一致。本条目保留第一代适配器，但上游尚未发布第一代权重；公开的 Vchitect/LongVie2 checkpoint 不能混用。

## 架构

LongVie-1 = 规范化 Wan 模型 + 编码器 + VAE + VACE/控制角色 + checkpoint 加载器 + 共享分段 runner。原生 runner 保留官方 640x352 分段尺寸与历史/噪声续写状态，并支持可选的 USP ring/ulysses 分布式控制。其 synthesis 包只是薄薄的产品装配层，不是独立引擎。

## 使用要点

默认调用在未传 execute=True 时快速失败。由于官方尚未发布 LongVie-1 权重，执行时还必须显式提供第一代 control checkpoint。需要公开 checkpoint 支持的路径时请使用 longvie-2。
