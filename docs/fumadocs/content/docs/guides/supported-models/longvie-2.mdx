LongVie 2 is the second-generation controllable long-video framework from the Vchitect team. It generates queued 81-frame control-video segments where each continuation reuses the prior final frame, an eight-frame history, and the noise state. Validated with the released checkpoints: the default four-GPU Studio route generates and decodes all 81 frames at 640x352.

## What it is for

`longvie-2` is an image-to-video model: a still image in, a video clip out.

Built on Wan2.1-I2V-14B-480P plus LongVie-specific weights: the adapter loads both control.safetensors and dit.safetensors, the latter being the LongVie 2 DiT attention override that distinguishes it from LongVie-1. Official USP ring/ulysses distributed inference is supported when execute=True. It is published by Shanghai AI Laboratory (Vchitect).

Tasks: image-to-video, long video generation, depth-controlled video, and trajectory-controlled video. Aliases: `longvie2` and `longvie-v2`. Modalities: image in, video and depth out.

Suggested benchmarks: [ChronoMagic-Bench](/docs/evaluation/benchmark-hub/chronomagic-bench) (Long-horizon generation suite), [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Control-driven generation benefits from camera-motion evaluation).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `frames`, `fps`, `height`, `width`, `steps`, `seed`, and 4 more; artifacts `generated_video` and `longvie-2.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `LongVie2Pipeline`.

Family status: **Verified**.

Each queued segment needs a non-empty prompt plus dense depth and sparse pointmap/track control videos; the first segment also needs an image. Quality defaults: 81 frames at 16 FPS, 50 steps. The Studio profile uses four-rank USP with the complete model resident on each 80GB GPU, and only rank zero writes the artifact.

## Running in WorldFoundry

Run `wf run longvie-2 --pipeline.task-profile interactive-video` to generate the video.

It runs in the dedicated environment `worldfoundry-longvie-cu128` (Python 3.10, CUDA 12.8).

Weight repositories include `Vchitect/LongVie2`, `Wan-AI/Wan2.1-I2V-14B-480P`, and `Wan-AI/Wan2.1-T2V-1.3B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh longvie-2`. Add `--download` to fetch missing public checkpoints.
