## 架构

构建在规范化 Wan 角色之上（基座：Wan2.1-I2V-14B-480P），叠加 LongVie 专属权重：适配器同时加载 control.safetensors 与 dit.safetensors——后者即区别于 LongVie-1 的 LongVie 2 DiT 注意力覆盖。 execute=True 时支持官方 USP ring/ulysses 分布式推理。

## 使用要点

每个排队分段都需要非空提示词加稠密深度与稀疏点图/轨迹控制视频；首段还需要一张图像。质量默认值： 81 帧、16 FPS、50 步。Studio profile 使用四 rank USP，只有 rank 0 落盘产物。这是排队式分段生成，不是键盘实时交互。
