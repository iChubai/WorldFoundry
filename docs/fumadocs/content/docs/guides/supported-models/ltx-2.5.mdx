## What it is for

Use `ltx-2.5` for both text-to-video and image-to-video generation.

The official distilled path encodes prompts with the bundled Gemma 4 12B text encoder, jointly denoises video and audio at half resolution, applies the LTX-2.5 latent spatial upscaler, performs the short second-stage refinement, and decodes through separate video and audio VAEs. WorldFoundry calls the official source directly because the LTX-2.3 monolithic loader is not compatible with LTX-2.5. It is published by Lightricks.

Tasks: text-to-video, image-to-video, and audio video generation. Aliases: `ltx2.5`, `ltx25`, and `ltx-2.5-distilled`. Modalities: text and image in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Baseline text/image-to-video quality and motion evaluation).

LTX-2.5 audio-video generation from a prompt. Sibling cards cover 2.x and LTX-Video.

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `frames`, `fps`, `height`, `width`, `seed`, `execute`, and 2 more; artifacts `generated_video` and `ltx-2.5.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `LTX25Pipeline`.

Family status: **Runner parity pending**.

Accept the Hugging Face model terms, download the five required split components while preserving their repository folders, clone the pinned source revision, install its ltx-core and ltx-pipelines dependencies in the dedicated environment, and pass execute=True. The optional duration head enables prompt-based automatic duration.

Validated without a GPU: WorldFoundry builds the official command and maps the split components correctly.

## Running in WorldFoundry

Generate a clip with `wf run ltx-2.5 --pipeline.task-profile interactive-video`.

It runs in the dedicated environment `ltx-2.5` (Python 3.11, CUDA 12.8, torch==2.11.0+cu128).

Weights: `Lightricks/LTX-2.5`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh ltx-2.5`. Add `--download` to fetch missing public checkpoints.
