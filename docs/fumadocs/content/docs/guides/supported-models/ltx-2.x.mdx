LTX-2.x is Lightricks' current-generation video model family. WorldFoundry runs the distilled LTX-2 and LTX-2.3 image-to-video paths natively, with the official spatial upscaler between two denoising stages, and runs the official IC-LoRA control-video (V2V) routes for both versions. Six variants exist (T2V/I2V/V2V for both 2 and 2.3): the I2V routes are validated, the V2V routes have run only on small synthetic control inputs, and the T2V variants are not yet validated.

## What it is for

Start with `ltx-2-i2v` or `ltx-2.3-i2v` for image-to-video; use `ltx-2-v2v` or `ltx-2.3-v2v` with a matching control video.

The I2V route is a two-stage denoise with the official Spatial Upscaler as the boundary, loaded automatically from spatial_upsampler_path (not a separate Studio refiner toggle). The native distilled schedule runs 8 first-stage plus 3 second-stage steps.

Tasks: text-to-video, image-to-video, video-to-video, and audio-video-generation. Modalities: text, image, and video in, video out. Other variants: `ltx-2-t2v`, `ltx-2-v2v`, `ltx-2.3-t2v`.

Suggested benchmarks: [AIGCBench](/docs/evaluation/benchmark-hub/aigcbench) (I2V-focused benchmark for the runnable routes).

LTX-2.5 and the original LTX-Video 0.9.x have their own pages: [LTX-2.5](/docs/guides/supported-models/ltx-2.5) and [LTX-Video](/docs/guides/supported-models/ltx-video).

## Runtime contract

Artifacts `ltx-2-t2v.mp4`.

CLI task profiles: `default`, `interactive-video`, and `control-video-to-video`. WorldFoundry binds `LTX23I2VPipeline`.

Start on `ltx-2-i2v`. The family registers 6 catalog variants (cards above): `ltx-2-t2v` (`text-to-video`) — Runner parity pending; `ltx-2-i2v` (`image-to-video`) — Verified; `ltx-2-v2v` (`video-to-video`) — Runner parity pending; `ltx-2.3-t2v` (`text-to-video`) — Runner parity pending; `ltx-2.3-i2v` (`image-to-video`) — Verified among others. Family status: **Verified**.

Validated: the LTX-2 and LTX-2.3 I2V routes generate non-blank demo videos. The V2V routes need the version-matched Pose-Control or Union-Control IC-LoRA plus a pose, Canny, or depth reference video; arbitrary RGB video does not work as a control input.

## Running in WorldFoundry

Run `wf run ltx-2-t2v --pipeline.task-profile default` to generate the video. Switch tasks in the command builder above to change `--pipeline.task-profile`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

The transformer is adapted from [Lightricks/LTX-2](https://github.com/Lightricks/LTX-2) at `d6053703e00195bc668cbd1d5eda9dc0b2e7b74a`. Checkpoints and adapted source remain under the upstream LTX license.

Weights: `Lightricks/LTX-2` and `Lightricks/LTX-2.3`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh ltx-2-t2v`. Add `--download` to fetch missing public checkpoints.

License: a custom license (see the model card).
