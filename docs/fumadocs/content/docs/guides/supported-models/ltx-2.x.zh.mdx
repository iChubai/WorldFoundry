LTX-2.x 是 Lightricks 当前一代视频模型系列。WorldFoundry 原生运行蒸馏版 LTX-2 与 LTX-2.3 的图生视频路径，在两段去噪之间使用官方空间上采样器；并为两个版本提供官方 IC-LoRA 控制视频（V2V）路径。共有六个 variant（2 与 2.3 各有 T2V/I2V/V2V）：I2V 路径已验证，V2V 仅在小尺寸合成控制输入上运行过，T2V variant 尚未验证。

## 用来做什么

图生视频从 `ltx-2-i2v` 或 `ltx-2.3-i2v` 开始；有匹配的控制视频时用 `ltx-2-v2v` 或 `ltx-2.3-v2v`。

I2V 路径为两段去噪，以官方 Spatial Upscaler 为分界，从 spatial_upsampler_path 自动加载（不是独立的 Studio 细化开关）。原生蒸馏调度为第一段 8 步加第二段 3 步。

catalog 记录的任务包括文生视频、图生视频、视频到视频、音视频联合生成。模态上，它接受文本、图像、视频，输出视频。同系列还有 `ltx-2-t2v`、`ltx-2-v2v`、`ltx-2.3-t2v`。

推荐评测：[AIGCBench](/zh/docs/evaluation/benchmark-hub/aigcbench)（针对可运行 I2V 路径的图生视频评测）。

LTX-2.5 与原版 LTX-Video 0.9.x 另有页面：[LTX-2.5](/zh/docs/guides/supported-models/ltx-2.5)、[LTX-Video](/zh/docs/guides/supported-models/ltx-video)。

## 运行时契约

产物 `ltx-2-t2v.mp4`。

CLI task profile：`default`、`interactive-video`、`control-video-to-video`。绑定的 pipeline 类是 `LTX23I2VPipeline`。

起步 variant 是 `ltx-2-i2v`。catalog 登记了 6 个 variant（上方卡片）：`ltx-2-t2v`（`text-to-video`）：Runner 一致性待确认、`ltx-2-i2v`（`image-to-video`）：已验证、`ltx-2-v2v`（`video-to-video`）：Runner 一致性待确认、`ltx-2.3-t2v`（`text-to-video`）：Runner 一致性待确认、`ltx-2.3-i2v`（`image-to-video`）：已验证等。系列状态：**已验证**。

已验证：LTX-2 与 LTX-2.3 的 I2V 路径均能生成非空 demo 视频。V2V 路径需要版本匹配的 Pose-Control 或 Union-Control IC-LoRA，以及姿态、Canny 或深度参考视频；任意 RGB 视频不能作为控制输入。

## 在 WorldFoundry 中运行

运行 `wf run ltx-2-t2v --pipeline.task-profile default` 生成视频。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

transformer 改编自 [Lightricks/LTX-2](https://github.com/Lightricks/LTX-2) 的 `d6053703e00195bc668cbd1d5eda9dc0b2e7b74a`。checkpoint 与改编源码仍受上游 LTX 许可约束。

记录的权重仓库包括 `Lightricks/LTX-2`、`Lightricks/LTX-2.3`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh ltx-2-t2v`；下载缺失的公开权重时加 `--download`。

许可证：自定义许可（见模型卡）。
