LTX-Video is Lightricks' earlier fast video generation model; this entry integrates the 0.9.8 distilled image-to-video route natively. Like LTX-2.x it runs a two-stage denoise with the official spatial upscaler in between. The single runnable variant is ltx-video-i2v; family-level T2V labels describe upstream capability, not a current local route.

## Architecture

Uses the same native transformer, VAE, scheduler, loader, and joint-state runner as LTX-2.x. The T5 text encoder is loaded as a Transformers architecture through NativeModuleLoader; Diffusers is not an inference backend. The spatial upscaler runs automatically between the two denoising stages.

## Usage notes

Runner parity is pending — the native I2V target is registered, but full checkpoint-backed parity with the upstream pipeline has not been recorded. The official HF cards report license 'other'; review before commercial use.
