Luma Ray2 是 Luma AI 的托管视频生成模型，支持文生视频与图生视频。WorldFoundry 的 Studio pipeline 封装了 Luma API：一条提示词或一帧起始图，最终以标准 WorldFoundry 结果目录中的可下载视频呈现。模型在 Luma 的服务器上运行，不在本地运行。

## 用来做什么

`luma-ray2` 通过提供商的托管 API 运行，无需本地 checkpoint。

Luma Ray2 是由服务方托管运行的模型；Luma 未公开其架构、参数规模或训练细节。Studio pipeline 向 Luma API 端点提交请求并回收生成的视频。

任务：文生视频、图生视频、托管 API。模态上，它接受文本、图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（对比托管文/图生视频输出的标准多维质量评测）、[Physics-IQ Original](/zh/docs/evaluation/benchmark-hub/physics-iq)（检验服务方视频模型是否遵循基本物理合理性）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）。

CLI task profile：`default`。绑定的 pipeline 类是 `LumaRay2Pipeline`。

需自备 Luma 账号与 API key，通过 LUMA_API_KEY（或 LUMALABS_API_KEY）提供；API key 通过 Luma 开发者平台（lumalabs.ai）签发。本地不会下载任何权重，也不需要 GPU——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。

需要付费的服务方账号与 API key；WorldFoundry 不提供任何凭据。

模型版本由服务方控制，输出可能随时间变化。

## 在 WorldFoundry 中运行

用 `wf run luma-ray2 --pipeline.task-profile default` 调用托管模型。

该模型未记录运行环境。

准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh luma-ray2`；下载缺失的公开权重时加 `--download`。
