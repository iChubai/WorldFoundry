Luma Ray2 是 Luma AI 的托管视频生成模型，catalog 记录其文生视频与图生视频能力。 WorldFoundry 的 Studio pipeline 封装了 Luma API：一条提示词或一帧起始图，最终以标准 WorldFoundry 结果目录中的可下载视频呈现。模型本身完全不在本地运行；该条目承担的是托管路径的记录与管道工作。

## 架构

这是由服务方托管运行的模型：厂商未公开其架构、参数规模或训练细节，本仓库也未记录这些信息。WorldFoundry 记录的只是集成层——一条向服务方端点提交请求并回收生成视频产物的 Studio pipeline。

## 使用要点

Catalog 将该条目标记为 integrated：托管 API 的 Studio pipeline 已可用，但你必须自备服务方的 API key 与账号。本地不会下载任何权重、也不会创建 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。API key 通过 Luma 开发者平台（lumalabs.ai）签发。
