Lyra is NVIDIA's generative world model family for exploration: from an image or video (Lyra-1) or from actions (Lyra-2) it produces an explorable world video. Validated with local assets: Lyra-1 runs the official static single-image SDG demo and Lyra-2 the official ZoomGS single-image forward-navigation demo. The default runner uses Lyra-2.

## What it is for

`lyra-1` is a world generation model.

Lyra comes in two generations: Lyra-1 for image-or-video-to-world-video and Lyra-2 for action-conditioned world video (paper on OpenReview; project page at NVIDIA Research). Running either needs local Lyra checkpoints, text-encoder assets, DA3 (Depth Anything 3) assets, and CUDA dependencies.

Tasks: open generative 3D and 4D world models. Aliases: `Project Lyra`, `Lyra 1.0`, and `Lyra 2.0`. Other variants: `lyra-2`.

Suggested benchmarks: [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Standard scoring for explorable generated worlds), [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Evaluates camera/viewpoint control quality during exploration).

## Runtime contract

Inputs `image` and `prompt` (bundled samples are used when omitted); options `mode`, `trajectory`, `camera-rotation`, `movement-distance`, `multi-trajectory`, `total-movement-distance-factor`, and 17 more; artifacts `generated_world`, `generated_3d_asset`, and `lyra-1.mp4`.

CLI task profiles: `official-static-sdg` and `official-zoomgs`. WorldFoundry binds `LyraPipeline`.

Start with `lyra-1`. The family has 2 variants, selectable in the command builder above: `lyra-1` (`image-or-video-to-world-video`) — Runner parity pending; `lyra-2` (`action-conditioned-world-video`) — Runner parity pending. Family status: **Verified**.

Recorded `official-zoomgs` defaults: fps=16, seed=1.

Pick the variant by input: lyra-1 when you start from an image or video, lyra-2 when you drive the world with actions. The default runner resolves to Lyra-2. Stage all required assets before submitting Studio jobs.

## Running in WorldFoundry

Generate a world with `wf run lyra-1 --pipeline.task-profile official-static-sdg`. Switch tasks in the command builder above to change `--pipeline.task-profile`.

Weights: `depth-anything/DA3NESTED-GIANT-LARGE-1.1`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh lyra-1`. Add `--download` to fetch missing public checkpoints.
