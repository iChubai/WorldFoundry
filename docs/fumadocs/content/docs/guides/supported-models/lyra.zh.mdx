**发表机构:** 英伟达（NVIDIA） · 企业

Lyra 是英伟达面向探索的生成式世界模型家族：Lyra-1 从图像或视频、Lyra-2 从动作输入生成可探索的世界视频。本 catalog 中两个 variant 都经由内置运行时适配器支撑的树内 pipeline 运行，默认 runner 指向 Lyra-2，runner 状态为 verified。原生 World Explorer 将上游 CUDA/C++/ImGui 交互与渲染实现内置在模型无关的推理适配器之后。

## 架构

catalog 记录两代模型：Lyra-1 做图像/视频到世界视频，Lyra-2 做动作条件世界视频（论文见 OpenReview，项目页在 NVIDIA Research）。运行需要本地 Lyra checkpoint、文本编码器资产、DA3（Depth Anything 3）资产与 CUDA 依赖；除已记录结构外的内部细节仓库未存。

## 使用要点

按输入选 variant：从图像或视频出发用 lyra-1，用动作驱动世界用 lyra-2。默认 catalog runner 解析到 Lyra-2。提交 Studio 任务前请就位所有记录资产；每次运行的验证证据在 catalog 外跟踪。
