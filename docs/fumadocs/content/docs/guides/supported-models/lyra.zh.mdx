Lyra 是英伟达面向探索的生成式世界模型家族：Lyra-1 根据图像或视频生成可探索的世界视频，Lyra-2 则根据动作输入生成。已使用本地资产验证：Lyra-1 跑通官方静态单图 SDG demo，Lyra-2 跑通官方 ZoomGS 单图前向导航 demo。默认 runner 使用 Lyra-2。

## 用来做什么

`lyra-1` 是世界生成模型。

Lyra 有两代模型：Lyra-1 用于图像/视频到世界视频生成，Lyra-2 用于动作条件世界视频生成（论文见 OpenReview，项目页在 NVIDIA Research）。运行任一代都需要本地 Lyra checkpoint、文本编码器资产、DA3（Depth Anything 3）资产与 CUDA 依赖。该模型由英伟达（NVIDIA）发布。

任务：open generative 3D and 4D world models。别名：`Project Lyra`、`Lyra 1.0`、`Lyra 2.0`。同系列还有 `lyra-2`。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（可探索生成世界的标准评分）、[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（评估探索过程中的相机/视角控制质量）。

## 运行时契约

输入 `image`、`prompt`（不传时使用内置示例）；参数 `mode`、`trajectory`、`camera-rotation`、`movement-distance`、`multi-trajectory`、`total-movement-distance-factor` 等 23 项；产物 `generated_world`、`generated_3d_asset`、`lyra-1.mp4`。

CLI task profile：`official-static-sdg`、`official-zoomgs`。绑定的 pipeline 类是 `LyraPipeline`。

建议从 `lyra-1` 开始。该系列共有 2 个 variant，可在上方命令构建器中切换：`lyra-1`（`image-or-video-to-world-video`）：已验证、`lyra-2`（`action-conditioned-world-video`）：已验证。系列状态：**已验证**。

`official-zoomgs` 的默认值：fps=16，seed=1。

根据输入选择 variant：以图像或视频为输入时使用 lyra-1，以动作驱动世界时使用 lyra-2。默认 runner 解析到 Lyra-2。提交 Studio 任务前请准备好所有必需资产。

## 在 WorldFoundry 中运行

用 `wf run lyra-1 --pipeline.task-profile official-static-sdg` 生成世界。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：独立环境 `lyra`（Python 3.10，CUDA 12.4，torch==2.6.0）。

权重仓库：`depth-anything/DA3NESTED-GIANT-LARGE-1.1`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh lyra-1`；下载缺失的公开权重时加 `--download`。
