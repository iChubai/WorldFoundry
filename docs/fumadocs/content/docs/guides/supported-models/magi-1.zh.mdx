## 用来做什么

用 `magi-1` 以参考图为起点生成视频。

上游将 MAGI-1 描述为按块自回归生成、使用因果注意力的大型视频模型，支持流式续写。WorldFoundry 接收提示词与输入图像，输出 generated_video 产物。

任务：图生视频、视频生成。模态上，它接受图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（基础视频生成质量评测）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `magi-1.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `MAGI1Pipeline`。

系列状态：**Runner 一致性待确认**。

运行前先就位 `sand-ai/MAGI-1` 权重。

尚未用发布的 checkpoint 在 GPU 上验证生成结果。

## 在 WorldFoundry 中运行

用 `wf run magi-1 --pipeline.task-profile interactive-video` 把静态图生成为视频。

运行环境：独立环境 `magi-official-cu124`（Python 3.10.12，CUDA 12.4）。

权重仓库：`sand-ai/MAGI-1`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh magi-1`；下载缺失的公开权重时加 `--download`。
