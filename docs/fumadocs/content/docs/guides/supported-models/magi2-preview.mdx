## What it is for

Use `magi2-preview` to turn a text prompt into a short video.

Tasks: text-to-video. Aliases: `magi2`, `magi2_preview`, and `magi-2-preview`. Modalities: text in, video out.

## Runtime contract

Input `prompt` (bundled samples are used when omitted); options `steps`, `seed`, `short-edge`, `aspect-ratio`, `duration-seconds`, and `use-refiner`; artifact `magi2-preview.mp4`.

CLI task profile: `default`. WorldFoundry binds `NativeMagi2Pipeline`. Family status: **Runner parity pending**. Defaults for `default`: steps=100, seed=0.

The pipeline supports ten-second text-to-video clips. Preview output is 12.5 fps; optional refinement increases temporal resolution and exports at 25 fps while preserving Preview audio.

The Refiner packs video in 8×4×4 latent blocks and uses the released radius-two local-attention window. Exact range-union attention preserves allowed keys without a quadratic dense mask. Sampling uses zero-SNR renoising, five UniPC steps, shift 5, and guidance 2 by default.

## Running in WorldFoundry

Run `wf run magi2-preview --pipeline.task-profile default` to generate the video.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `sand-ai/MAGI-2-preview`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh magi2-preview`. Add `--download` to fetch missing public checkpoints.

License: Apache-2.0; minimum VRAM 80 GB.

Prepare the `sand-ai/MAGI-2-preview` checkpoint layout: `preview/`, `refiner/`, `turbo_vae/`, `stable-audio-open-1.0/`, and `text_encoder/`. Components load lazily; Preview layers use sequential GPU residency.

```python
pipeline = NativeMagi2Pipeline.from_pretrained("/weights/MAGI-2-preview", device="cuda")
pipeline(
    prompt="A cinematic camera move through a sunlit forest.",
    use_refiner=True,
    refiner_num_inference_steps=5,
    refiner_height=1088,
    refiner_width=1920,
    output_path="/outputs/magi2-refined.mp4",
    seed=42,
)
```

`use_refiner=False` retains Preview-only behavior. Refiner height and width must be positive multiples of 16. Refinement maps latent temporal size `T` to `2T−1`; output audio comes from the Preview stage.
