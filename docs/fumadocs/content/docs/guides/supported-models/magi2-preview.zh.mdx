## 用来做什么

用 `magi2-preview` 把一段文本提示词变成短视频。

任务：文生视频。别名：`magi2`、`magi2_preview`、`magi-2-preview`。模态上，它接受文本，输出视频。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `steps`、`seed`、`short-edge`、`aspect-ratio`、`duration-seconds`、`use-refiner`；产物 `magi2-preview.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `NativeMagi2Pipeline`。系列状态：**Runner 一致性待确认**。`default` 的默认值：steps=100, seed=0。

Refiner 按 8×4×4 潜变量块打包视频，使用发布配置中的半径二局部注意力窗口。精确范围并集注意力保留所有允许的 key，不创建二次大小的稠密 mask。采样默认使用零 SNR 重加噪、五步 UniPC、shift 5 与 guidance 2。

## 在 WorldFoundry 中运行

运行 `wf run magi2-preview --pipeline.task-profile default` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`sand-ai/MAGI-2-preview`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh magi2-preview`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0；最低显存 80 GB。

准备 `sand-ai/MAGI-2-preview` 的权重布局：`preview/`、`refiner/`、`turbo_vae/`、`stable-audio-open-1.0/` 与 `text_encoder/`。组件按需加载；Preview 层使用顺序 GPU 驻留。
