Matrix-Game 1.0 is the first generation of Skywork's interactive game world model: from an image and keyboard/mouse-style actions it generates playable game-world video. It has its own model id and runs the official Matrix-Game 1 runtime, not the Matrix-Game 2 one.

## What it is for

Use it to generate game-world video from an image, a prompt, and keyboard/mouse actions with the first-generation model. For Matrix-Game 2.0 or 3.x, use their own model ids.

Launch `wf run matrix-game-1`.

Score on [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) — action-conditioned game-world rollout quality.

## Runtime contract

Required: `image` and `prompt`; `actions`: keyboard, mouse, navigation_token; artifacts: `world.mp4`.

## Running in WorldFoundry

Unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `Skywork/Matrix-Game` locally, then run `wf run matrix-game-1`.
