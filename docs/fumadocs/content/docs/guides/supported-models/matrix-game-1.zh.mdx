Matrix-Game 1.0 是昆仑万维交互式游戏世界模型的第一代：从一张图与键鼠式动作生成可交互的游戏世界视频。它有独立的模型 id，运行官方 Matrix-Game 1 运行时，而不是 Matrix-Game 2 的运行时。

## 用来做什么

用第一代模型从图像、提示词与键盘/鼠标动作生成游戏世界视频。Matrix-Game 2.0 或 3.x 请使用各自的模型 id。

启动 `wf run matrix-game-1`。

评测入口：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件游戏世界滚动生成质量）。

## 运行时契约

必填 `image`、`prompt`；`actions`：keyboard、mouse、navigation_token；产物 `world.mp4`。

## 在 WorldFoundry 中运行

统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。先在本地准备好 `Skywork/Matrix-Game`，再在该环境执行 `wf run matrix-game-1`。
