Matrix-Game 2.0 is Skywork's real-time-oriented interactive world model generation: an auto-regressive diffusion design that follows keyboard/mouse actions across game scenes. WorldFoundry matches the official universal mode on a 15-latent-frame run at 12 fps and 352×640 with official bench actions; the full 150-latent-frame default has not been compared.

## What it is for

Start on `matrix-game-2-universal-action-validation` with official bench actions. Matrix-Game 1 and 3 are separate models.

Launch `wf run matrix-game-2-universal-action-validation` with `--pipeline.task-profile official-universal-image`.

Score on [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) — action-conditioned game-world rollout quality.

## Runtime contract

Required: `image` and `official_bench_actions`; optional: `prompt` and `video`. Artifacts: `matrix-game-2-universal-ref-image-seed42-15f.mp4`, or `matrix_game2_official_universal_seed42_15f.mp4` with a JSON sidecar.

The official default is 150 latent frames, 12 fps, 352×640, seed 42. A 15-latent-frame run decodes to 57 RGB frames.

The loader accepts opt-in `fuse_qkv` with `qkv_strategy="packed"`, `"split"` or `"auto"`, `quantization`, and the shared `compile` options after restoring the DiT checkpoint. Fusion preserves the causal attention and cache algorithm. `vae_channels_last` and `vae_channels_last_3d` convert matching Conv2d/Conv3d decoder weights before compilation; the decoder retains FP16 weights when the DiT uses BF16. Unsupported optimization requests fail before loading.

`overlap_vae_decode=True` optionally decodes on a pipeline-owned CUDA stream while the caller stream refreshes clean generator context. A caller-stream event join orders returned video, copies, and recurrent cache reuse without a host wait during normal generation. Each pipeline has one active session; its owner serializes start, step, reset, and close. Reset, replacement sessions, close, and failed overlapped blocks drain only the owned decoder stream. A failed overlapped session must be replaced; CPU use reports a synchronous fallback.

These switches are disabled by default. Their latency benefit on the full checkpoint has not been measured.

The realtime session's universal mode keeps the W/S/A/D movement and I/K/J/L camera keys and also declares mouse and right-stick camera axes, which the Studio `world` page drives from the captured mouse pointer and a gamepad's right stick; each frame's axis values add to the key camera step and are clamped to the official ±0.1. The mouse scale is an initial calibration: about 40 pixels of motion in one frame reach that limit. gta_drive uses W/S for forward/back and A/D for steering, and templerun uses W jump, S slide, A/D side steps and Z/C turns, with idle frames encoded as `nomove`.

## Running in WorldFoundry

Unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `Skywork/Matrix-Game-2.0` locally. Run `wf run matrix-game-2-universal-action-validation` with `--pipeline.task-profile official-universal-image`. License: MIT. Needs at least 24 GB of VRAM.
