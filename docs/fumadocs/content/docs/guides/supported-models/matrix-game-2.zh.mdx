Matrix-Game 2.0 是昆仑万维面向实时的交互式世界模型：自回归扩散设计，在游戏场景中跟随键鼠动作。本 catalog 中 runner 已按官方 inference_universal 默认值验证——150 帧、12 fps、352x640、官方 bench 动作——经树内运行时运行。

## 用来做什么

从 `matrix-game-2-universal-action-validation` 起步，用官方 bench actions。不是 Matrix-Game 1 或 3。

启动 `worldfoundry-eval run matrix-game-2-universal-action-validation --pipeline.task-profile official-universal-image`。

评测入口：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件游戏世界滚动生成质量）。

## 运行时契约

必填 `image`、`official_bench_actions`；可选 `prompt`、`video`；产物 `matrix-game-2-universal-ref-image-seed42-15f.mp4`、`matrix_game2_official_universal_seed42_15f.mp4`、`matrix_game2_official_universal_seed42_15f.json`。

默认旋钮：150 帧、12 fps、352×640、seed 42。

## 在 WorldFoundry 中运行

状态：**已验证**。统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。先把 `Skywork/Matrix-Game-2.0` 就位到本地，缺文件加载失败，运行时不下载。在该环境执行 `worldfoundry-eval run matrix-game-2-universal-action-validation --pipeline.task-profile official-universal-image`。许可证：MIT。记录最低显存 24 GB。
