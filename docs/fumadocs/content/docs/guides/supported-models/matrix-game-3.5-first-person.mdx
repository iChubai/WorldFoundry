Matrix-Game 3.5 First-Person Base is the first-person profile of the Matrix-Game 3.5 release: long-horizon interactive world video at 1280x704, generated block by block (84 new frames per block) under camera-NPZ control. This model id always loads the first-person.safetensors weights.

## What it is for

`matrix-game-3.5-first-person` generates camera-controlled video: a camera trajectory in, a clip that follows it out.

Builds on Wan2.2-TI2V-5B (apache-2.0) with the Matrix-Game-3.5-Base weights and a DA3NESTED-GIANT-LARGE-1.1 depth dependency (CC-BY-NC-4.0 — separate non-commercial terms). The released checkpoint is the 25-step bidirectional 5B base, not the announced few-step real-time distilled model. It is published by Riemann Dynamics.

Tasks: image-to-video, camera-controlled video, interactive world model, and long horizon generation. Aliases: `matrix-game-3.5-fp` and `matrix-game-35-first-person`. Modalities: image in, video out.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Long-horizon interactive world-rollout quality), [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-NPZ trajectory adherence).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `fps`, `steps`, `guidance-scale`, `seed`, `camera`, `num-blocks`, and 1 more; artifacts `generated_world_video` and `matrix-game-3.5-first-person.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `MatrixGame35FirstPersonPipeline`.

Family status: **Runner parity pending**.

Each block consumes 84 camera poses and generates 84 new frames (exports include the anchor frame), so a one-block run exports 85 frames. Locally staged checkpoints are used first; missing Hub files can be fetched.

Run it with an image plus a camera NPZ. The third-person profile is the separate `matrix-game-3.5-third-person` model.

A run outputs the generated rollout and the provenance needed to reproduce it.

## Running in WorldFoundry

Generate a camera-controlled clip with `wf run matrix-game-3.5-first-person --pipeline.task-profile interactive-video`.

It runs in the dedicated environment `matrix-game-3.5` (Python 3.11, CUDA 12.8).

Weights: `RiemannDynamics/Matrix-Game-3.5-Base`, `Wan-AI/Wan2.2-TI2V-5B`, and `depth-anything/DA3NESTED-GIANT-LARGE-1.1` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh matrix-game-3.5-first-person`. Add `--download` to fetch missing public checkpoints.
