Matrix-Game 3.5 First-Person Base 是 Matrix-Game 3.5 发布的第一人称档案：在 camera NPZ 控制下逐块（每块新增 84 帧）生成 1280x704 的长时程交互世界视频。该模型 id 固定加载 first-person.safetensors 权重。

## 用来做什么

`matrix-game-3.5-first-person` 生成相机可控视频：输入相机轨迹，输出沿轨迹运动的视频。

基于 Wan2.2-TI2V-5B（apache-2.0），加 Matrix-Game-3.5-Base 权重与 DA3NESTED-GIANT-LARGE-1.1 深度依赖（CC-BY-NC-4.0——独立的非商用条款）。当前发布的 checkpoint 是 25 步双向 5B 基座，而非官宣的少步实时蒸馏模型。该模型由Riemann Dynamics（黎曼动力）发布。

任务：图生视频、相机可控视频、交互式世界模型、long-horizon-generation。别名：`matrix-game-3.5-fp`、`matrix-game-35-first-person`。模态上，它接受图像，输出视频。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（长时程交互世界滚动生成质量）、[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（camera NPZ 轨迹贴合度）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `fps`、`steps`、`guidance-scale`、`seed`、`camera`、`num-blocks` 等 7 项；产物 `generated_world_video`、`matrix-game-3.5-first-person.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `MatrixGame35FirstPersonPipeline`。

系列状态：**Runner 一致性待确认**。

每块消费 84 个相机位姿、生成 84 帧新画面（导出含锚帧），因此单块运行导出 85 帧。优先使用本地就位的 checkpoint，也可补齐缺失的 Hub 文件。

用图像加 camera NPZ 运行。第三人称档案是独立的 `matrix-game-3.5-third-person` 模型。

运行输出生成的 rollout 以及复现推理所需的溯源信息。

## 在 WorldFoundry 中运行

用 `wf run matrix-game-3.5-first-person --pipeline.task-profile interactive-video` 生成相机可控视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `RiemannDynamics/Matrix-Game-3.5-Base`、`Wan-AI/Wan2.2-TI2V-5B`、`depth-anything/DA3NESTED-GIANT-LARGE-1.1` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh matrix-game-3.5-first-person`；下载缺失的公开权重时加 `--download`。
