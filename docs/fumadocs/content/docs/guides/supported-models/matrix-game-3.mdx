## Architecture

The runtime is vendored under synthesis/visual_generation/matrix_game/matrix_game_3_runtime including the infer-only video writer needed by the official process_video call and Dynamo alias compatibility; checkpoint_dir remains an external asset path.

## Usage notes

No external Matrix-Game checkout is required at runtime. The verified demo uses int8 plus a compiled light VAE for speed — switch these off if you need maximum fidelity and have GPU headroom.
