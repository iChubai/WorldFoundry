Matrix-Game 3.0 is the third Skywork generation, pushing interactive world video to higher resolution with few-step inference. Validated on the official cityscape image-conditioned demo: actions forward + camera_r, 12 iterations, 3 inference steps, 704x1280, with int8 quantization, a compiled VAE, and the mg_lightvae decoder.

## What it is for

Interactive world video from an image and keyboard/mouse actions with Matrix-Game 3.0. Other Matrix-Game generations have their own pages.

Launch `wf run matrix-game-3` with `--pipeline.task-profile official-cityscape-image`.

Score on [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) — action-conditioned game-world rollout quality.

## Runtime contract

Required: `prompt` and `image`; optional: `video`; `actions`: keyboard, mouse; artifacts: `matrix-game-3.mp4`.

Recorded `official-cityscape-image` defaults: num_inference_steps=3, fps=17.

## Running in WorldFoundry

Unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `Skywork/Matrix-Game-3.0` locally before running. Run `wf run matrix-game-3` with `--pipeline.task-profile official-cityscape-image`.
