## 架构

运行时内置于 synthesis/visual_generation/matrix_game/matrix_game_3_runtime，包含官方 process_video 调用所需的仅推理视频写出器与 Dynamo 别名兼容；checkpoint_dir 保持为外部资产路径。

## 使用要点

运行时不需要外部 Matrix-Game 检出。已验证 demo 为提速使用 int8 与编译的轻量 VAE——若追求最高保真且 GPU 余量充足，可关闭这些选项。
