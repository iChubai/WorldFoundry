Matrix-Game 3.0 是昆仑万维的第三代，以少步推理把交互式世界视频推到更高分辨率。已在官方 cityscape 图像条件 demo 上验证：「forward + camera_r」动作、12 次迭代、3 步推理、704x1280，使用 int8 量化、编译 VAE 与 mg_lightvae 解码器。

## 用来做什么

用 Matrix-Game 3.0 从图像与键盘/鼠标动作生成交互世界视频。其他 Matrix-Game 版本各有独立页面。

启动 `wf run matrix-game-3 --pipeline.task-profile official-cityscape-image`。

评测入口：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件游戏世界滚动生成质量）。

## 运行时契约

必填 `prompt`、`image`；可选 `video`；`actions`：keyboard, mouse；产物 `matrix-game-3.mp4`。

`official-cityscape-image` 的默认值：num_inference_steps=3，fps=17。

## 在 WorldFoundry 中运行

统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。运行前先把 `Skywork/Matrix-Game-3.0` 就位到本地。在该环境执行 `wf run matrix-game-3 --pipeline.task-profile official-cityscape-image`。
