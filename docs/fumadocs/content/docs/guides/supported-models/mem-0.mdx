Mem-0 ("Memory Matters") is a memory-augmented manipulation policy from the RoboTwin RMBench line: an episodic memory bank lets the policy execute multi-task sequences that depend on what happened earlier. The qiuly/Mem-0-m1mix-RMBench checkpoint targets the published M1 multi-task execution setting.

## What it is for

Use `mem-0` to predict robot actions from observations and a language instruction.

The in-tree runtime contains the episodic memory bank, a Qwen feature path, a task classifier, and a flow-matching action decoder. Output matches the official 14-value dual-arm joint adapter, excluding the two model-only padding channels.

Tasks: VLA, VLA policy rollout, robot policy, and memory policy. Aliases: `mem0` and `memorymatters`.

Suggested benchmarks: [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (Built on the RoboTwin platform's RMBench memory tasks).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `action_trace` and `mem-0_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `Mem0Pipeline`.

Family status: **Static load only**.

Mem-0 runs the M1 multi-task execution checkpoint and does not require the high-level planning server. The published checkpoint is byte-split; the runtime reads its contiguous parts directly without assembling another copy.

No license is declared for the checkpoint; check the upstream RMBench terms before redistribution.

The official execution checkpoint is published as nine byte-split parts. The runtime reads them as one seekable stream, so no second 15.3 GB merged file is written.

## Running in WorldFoundry

Run the policy with `wf run mem-0 --pipeline.task-profile default`.

It runs in the dedicated environment `worldfoundry-vla-mem-0` (Python 3.11, CUDA 12.4+, torch>=2.6).

Weights: `qiuly/Mem-0-m1mix-RMBench` and `Qwen/Qwen3-VL-2B-Instruct`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh mem-0`. Add `--download` to fetch missing public checkpoints.
