Mem-0 ("Memory Matters") is a memory-augmented manipulation policy from the RoboTwin RMBench line: an episodic memory bank lets the policy execute multi-task sequences that depend on what happened earlier. The confirmed qiuly/Mem-0-m1mix-RMBench checkpoint targets the published M1 multi-task execution setting; the full runtime is in-tree and statically verified.
