Mem-0（“Memory Matters”）是 RoboTwin RMBench 线的记忆增强操作策略：情节记忆库使策略能执行依赖既往事件的多任务序列。已确认的 qiuly/Mem-0-m1mix-RMBench checkpoint 面向已发表的 M1 多任务执行设定；完整运行时内置树内并通过静态验证。

## 架构

树内运行时包含情节记忆库、Qwen 特征路径、任务分类器与 flow-matching 动作解码器。输出匹配官方 14 值双臂关节适配器，排除两个仅模型内部的填充通道。

## 使用要点

本条目面向 M1 多任务执行 checkpoint，无需高层规划服务。发布的 checkpoint 为字节分片——运行时直接读取其连续分片，无需另行拼装副本。
