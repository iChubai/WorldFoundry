Mem-0（“Memory Matters”）是 RoboTwin RMBench 线的记忆增强操作策略：情节记忆库使策略能执行依赖既往事件的多任务序列。qiuly/Mem-0-m1mix-RMBench checkpoint 面向已发表的 M1 多任务执行设定。

## 用来做什么

用 `mem-0` 根据观测和语言指令预测机器人动作。

树内运行时包含情节记忆库、Qwen 特征路径、任务分类器与 flow-matching 动作解码器。输出匹配官方 14 值双臂关节适配器，排除两个仅模型内部的填充通道。

任务：视觉-语言-动作（VLA）、VLA 策略执行、机器人策略、memory_policy。别名：`mem0`、`memorymatters`。

推荐评测：[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（构建于 RoboTwin 平台的 RMBench 记忆任务）。

Mem-0 记忆策略 rollout，不是视频生成器。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`mem-0_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `Mem0Pipeline`。

系列状态：**仅静态加载**。

Mem-0 运行 M1 多任务执行 checkpoint，无需高层规划服务。发布的 checkpoint 为字节分片，运行时直接读取其连续分片，无需另行拼装副本。

官方执行 checkpoint 以九个字节分片发布。运行时将其作为单一可寻址数据流读取，不会另写一份 15.3 GB 的合并文件。

## 在 WorldFoundry 中运行

用 `wf run mem-0 --pipeline.task-profile default` 运行策略。

运行环境是独立 profile `worldfoundry-vla-mem-0`（Python 3.11，CUDA 12.4+，torch>=2.6）。

权重仓库：`qiuly/Mem-0-m1mix-RMBench`、`Qwen/Qwen3-VL-2B-Instruct`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh mem-0`；下载缺失的公开权重时加 `--download`。
