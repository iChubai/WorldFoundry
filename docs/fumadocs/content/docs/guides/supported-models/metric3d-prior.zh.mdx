Metric3D 通过把图像归一化到规范相机空间，从单张图像恢复米制尺度深度，使单一模型能够跨相机泛化。WorldFoundry 将其用作米制深度先验，它也是 ViPE SLAM 配置中的默认米制深度模型。

## 用来做什么

用 `metric3d-prior` 从输入图像预测深度图。

按上游论文（ICCV 2023），规范相机变换消解了单图深度的米制歧义。checkpoint 为 JUGGHM/Metric3D，许可 bsd-2-clause。该模型由大疆创新 / 浙江大学发布。

任务：单目深度估计、米制深度估计、几何先验。别名：`metric3d`、`yvanyin-metric3d`。模态上，它接受图像，输出深度。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `model`、`version`、`focal-length`、`execute`、`max-points`；产物 `metric3d-prior.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `Metric3DPriorPipeline`。

系列状态：**已验证**。

通过 input_path 传入一张图像，已知焦距时同时传入 focal_length；运行后深度预测写入 metric3d-prior.npz。

## 在 WorldFoundry 中运行

用 `wf run metric3d-prior --pipeline.task-profile default` 估计深度。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`JUGGHM/Metric3D`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh metric3d-prior`；下载缺失的公开权重时加 `--download`。
