MineWorld 是微软面向 Minecraft 的实时开源交互世界模型：自回归 Transformer，从图像/视频上下文与动作向前推演 Minecraft 场景（arXiv 2504.08388，MIT 许可）。运行需要官方依赖环境、checkpoint 与验证/demo 数据。

## 用来做什么

`mineworld` 以动作为条件生成未来帧。

按论文：视觉 tokenizer 加在「状态-动作」交错 token 上的自回归 Transformer，配并行解码实现实时速度。该模型由微软（Microsoft）发布。

任务：交互式世界模型、Minecraft 世界模型、动作条件视频。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件游戏世界滚动生成质量）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `interactions`、`frames`、`fps`、`seed`；产物 `mineworld.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `MineWorldPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-video` 的默认值：frames=16, fps=16, seed=42。

请先就位官方 checkpoint 与验证数据；缺少时 pipeline 返回 blocked 运行时诊断，而不生成视频。

## 在 WorldFoundry 中运行

运行 `wf run mineworld --pipeline.task-profile interactive-video` 推演世界模型。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型没有登记公开 checkpoint；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh mineworld`；下载缺失的公开权重时加 `--download`。
