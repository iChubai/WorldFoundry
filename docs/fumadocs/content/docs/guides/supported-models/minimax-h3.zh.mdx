MiniMax H3 是来自 MiniMaxAI 的视频生成模型。Catalog 将它记录为文生视频、图生视频、参考图生成视频任务。它还有别名 minimax_h3、minimax-h3-t2va、minimax-h3-fl2va。

## 用来做什么

`minimax-h3` 是记录的文本/图像到视频线。需要同一张卡片上同时有 prompt 与静帧条件时用它。

catalog 记录的任务包括 文生视频、图生视频、参考图生成视频。别名包括 `minimax_h3`、`minimax-h3-t2va`、`minimax-h3-fl2va`、`minimax-h3-ref2va`。模态上，它接受文本、图像，输出视频。

计划中的 MiniMax H3 文生 / 图生 / 参考生视频。不是托管的 Hailuo 2.3 API 卡。

## 运行时契约

必填 `prompt`、`image`、`video`、`audio`；可选 `actions` (seed, task, flow_shift, audio_flow_shift)；产物 `minimax-h3.mp4`。

记录的任务 profile：`text-to-video`、`image-to-video`、`reference-to-video`。绑定的 pipeline 类是 `NativeMiniMaxH3Pipeline`。

系列状态：**计划中**。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run minimax-h3 --pipeline.task-profile text-to-video`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `MiniMaxAI/MiniMax-H3`、`MiniMaxAI/MiniMax-H3`。就位权重用 `bash scripts/inference/prepare_model_infer.sh minimax-h3`。

记录 license 为 apache-2.0；catalog 显存 80 GB；状态：**计划中**。
