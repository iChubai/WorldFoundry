MiniMax H3 是来自 MiniMaxAI 的视频生成模型，支持文生视频、图生视频、参考图生成视频。

## 用来做什么

用 `minimax-h3` 把一段文本提示词变成短视频。

任务：文生视频、图生视频、参考图生成视频。别名：`minimax_h3`、`minimax-h3-t2va`、`minimax-h3-fl2va`、`minimax-h3-ref2va`。模态上，它接受文本、图像，输出视频。

MiniMax H3 支持文生视频、图生视频与参考图生成视频，与托管的 Hailuo 2.3 API（`hailuo-2p3`）不是同一个模型。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；产物 `minimax-h3.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `NativeMiniMaxH3Pipeline`。

系列状态：**Runner 一致性待确认**。

## 在 WorldFoundry 中运行

运行 `wf run minimax-h3 --pipeline.task-profile default` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`MiniMaxAI/MiniMax-H3`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh minimax-h3`；下载缺失的公开权重时加 `--download`。

许可证为 Apache-2.0；最低显存 80 GB。
