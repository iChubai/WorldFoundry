## What it is for

`minwm-hy-action2v` conditions video generation on camera poses.

The inference-only camera transformer keeps the upstream PRoPE and autoregressive caches and uses the HunyuanVideo-1.5 VAE and encoders. It is published by Shengshu Technology.

Tasks: interactive world model, action-conditioned video, and camera-controlled video. Aliases: `minwm` and `minwm-hy-action2v`. Modalities: action and camera pose in, video out.

Suggested benchmarks: [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera/motion-trajectory adherence).

The official source is Apache-2.0. Only the HY15/Action2V/dmd subset of the 384.97 GB upstream minWM repository is required; you do not need the full research archive.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `frames`, `fps`, `height`, `width`, `steps`, `seed`, and 1 more; artifact `minwm-hy-action2v.mp4`.

CLI task profile: `default`. WorldFoundry binds `MinWMHYAction2VPipeline`. Family status: **Runner parity pending**. Defaults for `default`: frames=77, fps=16, height=480, width=832, steps=4, seed=0.

Stage HY15/Action2V/dmd plus the HunyuanVideo-1.5 encoders and VAE; only this subset of the minWM repository is needed. The public pipeline uses camera-conditioned four-step autoregressive inference and spatially tiled VAE decoding. Validated on a single H100: 77 frames at 832×480 with four DMD steps and a camera trajectory.

Only camera-conditioned generation is supported; non-camera modes are not available in this runtime. HY15-derived files retain Tencent Hunyuan license terms; see the included licenses and provenance.

Inputs are prompt, image, and trajectory (native motion tokens). Stage the HY15 Action2V DMD subset before running. For the Wan-based variant use `minwm-wan-action2v`.

## Running in WorldFoundry

Run `wf run minwm-hy-action2v --pipeline.task-profile default` to follow the camera path.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `MIN-Lab/minWM` and `tencent/HunyuanVideo-1.5`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh minwm-hy-action2v`. Add `--download` to fetch missing public checkpoints.
