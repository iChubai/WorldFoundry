## 用来做什么

用 `minwm-hy-action2v` 做相机条件视频推理。配方绑定了已记录的相机控制 profile。

官方源码以固定 revision 内置（apache-2.0）。仅需上游 384.97 GB minWM 仓库中的 HY15/Action2V/dmd 子集——该条目有意避免拉取完整研究归档。该模型由生数科技（Shengshu AI）发布。

catalog 记录的任务包括 交互式世界模型、动作条件视频、相机可控视频。别名包括 `minwm`、`minwm-hy-action2v`。

记录的评测入口包括[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机/运动轨迹贴合度）。
