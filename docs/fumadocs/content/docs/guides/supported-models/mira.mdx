MIRA is a multiplayer interactive world model: several players act in one shared, action-conditioned generated world (paper arXiv 2607.05352). WorldFoundry runs inference only; it needs a compatible local checkpoint and a local Rocket Science dataset split containing index.json.

Project page: [mira-wm.com](https://mira-wm.com). Code: [mira-wm/mira](https://github.com/mira-wm/mira).

The paper is [Multiplayer Interactive World Models with Representation Autoencoders](https://arxiv.org/abs/2607.05352).

## What it is for

`local-checkpoint` is a world generation model.

Per the paper, MIRA builds multiplayer interactive world models on representation autoencoders; the code is released under apache-2.0. The local-checkpoint variant runs the Rocket Science rollout task.

Tasks: action-conditioned world model and multiplayer game world model. Aliases: `mira-wm` and `multiplayer-interactive-world-model`.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Multiplayer world-rollout quality).

## Runtime contract

Inputs `load.checkpoint-path` and `load.dataset-path` (bundled samples are used when omitted); options `plan-only` and `timeout-seconds`; artifacts `generated_video` and `mira.mp4`.

CLI task profiles: `rocket-science-rollout`. WorldFoundry binds `MIRAPipeline`. The worker runs as `worldfoundry.synthesis.visual_generation.mira_wm.infer` and uses the canonical in-tree DINOv3 backbone. The frozen backbone is restored from the codec checkpoint; standalone pretrained weights can be supplied through `RS_DINO_WEIGHTS_DIR`.

Family status: **Runner parity pending**.

`rocket-science-rollout` defaults: seed=42.

The public Rocket Science dataset is about 29.24 TB and is never downloaded automatically; stage the split you need locally. Video decoding falls back to PyAV when TorchCodec is ABI-incompatible.

## Running in WorldFoundry

Run `wf run local-checkpoint --pipeline.task-profile rocket-science-rollout` to generate the world.

It runs in the dedicated environment `mira` (Python 3.12, CUDA 12.8, torch==2.8.0+cu128).

Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh local-checkpoint`. Add `--download` to fetch missing public checkpoints.
