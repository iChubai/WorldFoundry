MIRA 是多人交互世界模型：多名玩家在同一个动作条件生成世界中行动（论文 arXiv 2607.05352）。WorldFoundry 仅支持推理，需要兼容的本地 checkpoint 与包含 index.json 的本地 Rocket Science 数据集切分。

论文：[Multiplayer Interactive World Models with Representation Autoencoders](https://arxiv.org/abs/2607.05352)（2026）。

项目页：[mira-wm.com](https://mira-wm.com)。代码：[mira-wm/mira](https://github.com/mira-wm/mira)。

## 用来做什么

`local-checkpoint` 是世界生成模型。

按论文，MIRA 基于表征自编码器构建多人交互世界模型；代码以 apache-2.0 发布。local-checkpoint variant 运行 Rocket Science 滚动生成任务。

任务：action-conditioned-world-model、multiplayer-game-world-model。别名：`mira-wm`、`multiplayer-interactive-world-model`。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（多人世界滚动生成质量）。

## 运行时契约

输入 `load.checkpoint-path`、`load.dataset-path`（不传时使用内置示例）；参数 `plan-only`、`timeout-seconds`；产物 `generated_video`、`mira.mp4`。

CLI task profile：`rocket-science-rollout`。绑定的 pipeline 类是 `MIRAPipeline`。

系列状态：**Runner 一致性待确认**。

`rocket-science-rollout` 默认值：seed=42。

公开的 Rocket Science 数据集约 29.24 TB，不会自动下载；请在本地就位所需切分。TorchCodec ABI 不兼容时视频解码回退到 PyAV。

## 在 WorldFoundry 中运行

运行 `wf run local-checkpoint --pipeline.task-profile rocket-science-rollout` 生成世界。

运行环境：独立环境 `mira`（Python 3.12，CUDA 12.8，torch==2.8.0+cu128）。

准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh local-checkpoint`；下载缺失的公开权重时加 `--download`。
