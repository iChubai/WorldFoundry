MMAudio 为无声视频生成配音：给定一段视频（可附文本提示词），它合成与画面语义和时间对齐的音频。可用它为视频模型生成的片段补配音；产物类型是 generated_audio，而非视频。

## 用来做什么

用 `mmaudio` 生成音频。

MMAudio 是多模态联合训练的流匹配（flow-matching）模型，以视频帧与文本为条件生成音频（见其论文）。该模型由索尼 AI / 伊利诺伊大学厄巴纳-香槟分校发布。

任务：文生音频、视频生音频、audio-generation。别名：`hkchengrex/MMAudio`。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `steps`、`duration`、`variant`；产物 `mmaudio.wav`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `MMAudioPipeline`。

系列状态：**Runner 一致性待确认**。

典型工作流：先用任一文生/图生视频模型出片，再把视频交给 MMAudio 生成配音。

## 在 WorldFoundry 中运行

用 `wf run mmaudio --pipeline.task-profile interactive-video` 生成音频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`hkchengrex/MMAudio`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh mmaudio`；下载缺失的公开权重时加 `--download`。
