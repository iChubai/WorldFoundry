MME-VLA is the policy-learning line of the RoboMME project, centered on perceptual frame sampling for memory-heavy manipulation. It ships four Apache-2.0 checkpoint repos: the best perceptual-framesamp module, the mme_vla_suite collection, a pi05 baseline, and a VLM subgoal predictor.

## What it is for

`perceptual-framesamp-modul` is a vision-language-action policy: an instruction and observations in, actions out.

Combines a perceptual frame-sampling module with policy learning and an optional VLM subgoal predictor. WorldFoundry runs the policy in process without an external source checkout.

Tasks: VLA, VLA action prediction, VLA policy rollout, and embodied benchmark. Aliases: `mme_vla`, `robomme-policy-learning`, and `perceptual-framesamp-modul`.

Suggested benchmarks: [RoboMME](/docs/evaluation/benchmark-hub/robomme) (Native benchmark of the RoboMME project).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `checkpoint-ref` and `official-policy-observation`; artifacts `action_trace` and `mme-vla_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `MMEVLAPipeline`.

Family status: **Static load only**.

Stage the perceptual frame-sampling module checkpoint (`Yinpei/perceptual-framesamp-modul`) first.

## Running in WorldFoundry

Run `wf run perceptual-framesamp-modul --pipeline.task-profile default` to predict actions.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch==2.7.1).

Weights: `Yinpei/perceptual-framesamp-modul`, `Yinpei/mme_vla_suite`, and `Yinpei/pi05_baseline` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh perceptual-framesamp-modul`. Add `--download` to fetch missing public checkpoints.
