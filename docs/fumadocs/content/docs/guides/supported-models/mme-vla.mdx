MME-VLA is the policy-learning line of the RoboMME project, centered on perceptual frame sampling for memory-heavy manipulation. Four Apache-2.0 checkpoint repos are confirmed from the README — the best perceptual-framesamp module, the mme_vla_suite collection, a pi05 baseline, and a VLM subgoal predictor. WorldFoundry calls create_trained_policy(...).infer in-process from a vendored subset.
