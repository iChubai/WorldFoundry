## 用来做什么

`perceptual-framesamp-modul` 是视觉-语言-动作（VLA）策略：输入指令和观测，输出动作。

将感知帧采样模块与策略学习及可选的 VLM 子目标预测器结合。WorldFoundry 在进程内运行策略，无需外部源码检出。

任务：视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行、具身评测。别名：`mme_vla`、`robomme-policy-learning`、`perceptual-framesamp-modul`。

推荐评测：[RoboMME](/zh/docs/evaluation/benchmark-hub/robomme)（RoboMME 项目的原生基准）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `checkpoint-ref`、`official-policy-observation`；产物 `action_trace`、`mme-vla_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `MMEVLAPipeline`。

系列状态：**仅静态加载**。

请先就位感知帧采样模块 checkpoint（`Yinpei/perceptual-framesamp-modul`）。

## 在 WorldFoundry 中运行

运行 `wf run perceptual-framesamp-modul --pipeline.task-profile default` 预测动作。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch==2.7.1）。

权重仓库：`Yinpei/perceptual-framesamp-modul`、`Yinpei/mme_vla_suite`、`Yinpei/pi05_baseline` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh perceptual-framesamp-modul`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
