## What it is for

Use `mochi-1-preview-t2v` to turn a text prompt into a short video.

Upstream describes Mochi-1 as a 10B-parameter Asymmetric Diffusion Transformer (AsymmDiT) with a dedicated video VAE.

Tasks: text-to-video. Modalities: text in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Standard T2V quality suite).

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `frames`, `fps`, `height`, `width`, `steps`, `guidance-scale`, and 1 more; artifacts `mochi-1-preview-t2v.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `Mochi1PreviewT2VPipeline`.

Family status: **Runner parity pending**.

Defaults for `interactive-video`: frames=84, fps=30, height=480, width=848, seed=12345.

Stage the preview checkpoint (genmo/mochi-1-preview) before running. The GitHub organization is genmoai, while Hugging Face uses genmo.

## Running in WorldFoundry

Generate a clip with `wf run mochi-1-preview-t2v --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `genmo/mochi-1-preview`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh mochi-1-preview-t2v`. Add `--download` to fetch missing public checkpoints.
