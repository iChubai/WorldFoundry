## 用来做什么

`mochi-1-preview-t2v` 是记录的 prompt 到视频路由——不是图像编辑，也不是策略。只要任务是文生视频，从这里起步。

上游将 Mochi-1 描述为 100 亿参数的非对称扩散 Transformer（AsymmDiT），配专用视频 VAE。本仓库记录 runner 接线与标准 prompt/image/video/actions 输入 schema；更多内部细节仓库未记录。

catalog 记录的任务包括 文生视频。模态上，它接受文本，输出视频。

记录的评测入口包括[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（标准文生视频质量评测）。
