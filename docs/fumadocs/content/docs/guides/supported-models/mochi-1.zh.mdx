## 用来做什么

用 `mochi-1-preview-t2v` 把一段文本提示词变成短视频。

上游将 Mochi-1 描述为 100 亿参数的非对称扩散 Transformer（AsymmDiT），配专用视频 VAE。

任务：文生视频。模态上，它接受文本，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（标准文生视频质量评测）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`guidance-scale` 等 7 项；产物 `mochi-1-preview-t2v.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `Mochi1PreviewT2VPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-video` 的默认值：frames=84, fps=30, height=480, width=848, seed=12345。

运行前需准备 preview checkpoint（genmo/mochi-1-preview）。GitHub 组织名为 genmoai，Hugging Face 为 genmo。

## 在 WorldFoundry 中运行

用 `wf run mochi-1-preview-t2v --pipeline.task-profile interactive-video` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`genmo/mochi-1-preview`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh mochi-1-preview-t2v`；下载缺失的公开权重时加 `--download`。
