ModelScopeT2V is Alibaba DAMO Academy's original open text-to-video diffusion model — the 1.7B model that kicked off much of the open T2V ecosystem (ZeroScope is a fine-tune of it). It serves mainly as a historical baseline.

<ModelPaperFigures modelId="modelscope-t2v" locale="en" />

Paper: [arXiv 2308.06571](https://arxiv.org/abs/2308.06571).

Project page: [modelscope.cn](https://modelscope.cn/). Code: [modelscope/modelscope](https://github.com/modelscope/modelscope).

Architecturally it is a **latent video U-Net**: temporal attention is inserted into a text-to-image diffusion backbone so a prompt becomes a short, low-resolution clip. That is why later DiT families (Wan, CogVideoX, HunyuanVideo) superseded it on quality and temporal consistency. The Hugging Face checkpoint is `ali-vilab/modelscope-damo-text-to-video-synthesis`; stage that repo, not the similarly named `model-scope/text-to-video-synthesis`. The license is **CC-BY-NC-4.0** (non-commercial); do not treat it as unrestricted open source.

## What it is for

Use `modelscope-t2v` to turn a text prompt into a short video.

A U-Net latent video diffusion model with temporal attention layers inserted into a text-to-image backbone (per the upstream publication). It takes a text prompt only and writes a short video. It is published by Alibaba (DAMO Academy / ModelScope).

Tasks: text-to-video. Modalities: text in, video out.

Suggested benchmarks: [FETV](/docs/evaluation/benchmark-hub/fetv) (Fine-grained T2V evaluation suited to legacy baselines).

Reproduce a 2023-era open T2V baseline: required `prompt` in, `modelscope-t2v.mp4` out through `ModelScopeT2VPipeline`. The wired controls are text prompt, **fps**, and **seed**. Use it to compare against later entries or to explain ZeroScope's parent. For research-quality or production T2V, use the DiT models. [FETV](/docs/evaluation/benchmark-hub/fetv) is the fine-grained suite this generation of models is usually discussed on.

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `fps` and `seed`; artifacts `modelscope-t2v.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `ModelScopeT2VPipeline`.

Family status: **Runner parity pending**.

Use it for research comparisons only; for production-quality T2V use the DiT-based models.

## Running in WorldFoundry

Generate a clip with `wf run modelscope-t2v --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `ali-vilab/modelscope-damo-text-to-video-synthesis` and `ali-vilab/modelscope-damo-text-to-video-synthesis`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh modelscope-t2v`. Add `--download` to fetch missing public checkpoints.
