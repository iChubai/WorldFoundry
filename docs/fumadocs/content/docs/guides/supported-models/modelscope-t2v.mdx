ModelScopeT2V is Alibaba DAMO Academy's original open text-to-video diffusion model — the 1.7B model that kicked off much of the open T2V ecosystem (ZeroScope in this catalog is a fine-tune of it). The WorldFoundry route is complete and reports missing checkpoints at runtime. It is kept mainly as a historical baseline.

## Architecture

A U-Net latent video diffusion model with temporal attention layers inserted into a text-to-image backbone (per the upstream publication). This repository records the prompt-only input contract and generated_video artifact.

## Usage notes

The recorded license is non-commercial per HF cardData — the manifest says explicitly not to treat it as unrestricted open source. Use it for research comparisons only; for production-quality T2V use the DiT-based entries.
