ModelScopeT2V 是阿里达摩院最早开源的文生视频扩散模型，也是带动开源 T2V 生态发展的 1.7B 模型（ZeroScope 就是它的微调版）。它主要作为历史基线使用。

<ModelPaperFigures modelId="modelscope-t2v" locale="zh" />

论文：[arXiv 2308.06571](https://arxiv.org/abs/2308.06571)。

项目页：[modelscope.cn](https://modelscope.cn/)。代码：[modelscope/modelscope](https://github.com/modelscope/modelscope)。

结构上它是**潜空间视频 U-Net**：在文生图扩散骨干中插入时间注意力，根据一句 prompt 生成一段短小的低分辨率视频片段。这也是后来的 DiT 系列（Wan、CogVideoX、HunyuanVideo）在画质和时序上取代它的原因。Hugging Face checkpoint 是 `ali-vilab/modelscope-damo-text-to-video-synthesis`；请准备好这个仓库，不要使用名称相近的 `model-scope/text-to-video-synthesis`。许可是 **CC-BY-NC-4.0**（非商用），不应将其视为无限制开源。

## 用来做什么

用 `modelscope-t2v` 根据文本提示词生成短视频。

该模型采用 U-Net 潜空间视频扩散架构，在文生图基座中插入时序注意力层（见上游论文）。输入仅为文本提示词，输出一段短视频。该模型由阿里巴巴（达摩院 / ModelScope）发布。

任务：文生视频。模态上，它接受文本，输出视频。

推荐评测：[FETV](/zh/docs/evaluation/benchmark-hub/fetv)（细粒度文生视频评测，适合老基线）。

复现 2023 年左右的开源文生视频基线时，必须输入 `prompt`，经 `ModelScopeT2VPipeline` 生成 `modelscope-t2v.mp4`。已接入的控制参数是文本提示、**fps** 和 **seed**。可用于与后续模型对照，或说明 ZeroScope 的父模型。研究级或生产级文生视频请用 DiT 模型。这一代模型常用的细粒度套件是 [FETV](/zh/docs/evaluation/benchmark-hub/fetv)。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `fps`、`seed`；产物 `modelscope-t2v.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `ModelScopeT2VPipeline`。

系列状态：**Runner 一致性待确认**。

仅建议用于研究对比；生产级文生视频请用基于 DiT 的模型。

## 在 WorldFoundry 中运行

用 `wf run modelscope-t2v --pipeline.task-profile interactive-video` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`ali-vilab/modelscope-damo-text-to-video-synthesis`、`ali-vilab/modelscope-damo-text-to-video-synthesis`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh modelscope-t2v`；下载缺失的公开权重时加 `--download`。
