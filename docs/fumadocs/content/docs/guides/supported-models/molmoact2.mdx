MolmoAct2 is AI2's second-generation action reasoning model with a broad Apache-2.0 checkpoint zoo: base, Think (depth-reasoning), DROID (Franka), Bimanual YAM, SO100/101, and LIBERO checkpoints. WorldFoundry runs the official DROID/YAM predict_action contracts as an action_trace pipeline; no external source checkout is needed.

## What it is for

Use `molmoact2-droid` to predict robot actions from observations and a language instruction.

MolmoAct2 builds on the Molmo open VLM line with action-reasoning heads; the Think variant adds depth-based reasoning before acting. The DROID, YAM, SO100, LIBERO, and Think-LIBERO variants each run their own checkpoint and return an action trace. It is published by Allen Institute for AI (AI2).

Tasks: VLA, VLA action prediction, VLA policy rollout, and robot policy. Aliases: `molmo-act2`, `molmoact`, `molmoact2-droid`, and `molmoact2-yam`. Other variants: `molmoact2-bimanual-yam`, `molmoact2-so100-101`, `molmoact2-libero`.

Suggested benchmarks: [LIBERO](/docs/evaluation/benchmark-hub/libero) (Dedicated LIBERO and Think-LIBERO checkpoints).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); artifacts `action_trace` and `molmoact2_action_trace.json`.

CLI task profiles: `interactive-video`. WorldFoundry binds `MolmoAct2Pipeline`.

Start on `molmoact2-droid`. The family has 5 variants, all for `vla.policy_rollout`: `molmoact2-droid`, `molmoact2-bimanual-yam`, `molmoact2-so100-101`, `molmoact2-libero`, and `molmoact2-think-libero`.

Pick the checkpoint per embodiment: DROID for Franka arms, BimanualYAM for dual-arm YAM, SO100_101 for SO-ARM, LIBERO/Think-LIBERO for simulation. Camera and state inputs differ by variant: DROID uses external_cam, external_cam_2, and wrist_cam with an 8-D state; YAM uses top_cam, left_cam, and right_cam with a 14-D state; SO100/SO101 uses top_cam and side_cam with a 6-D state; LIBERO and Think-LIBERO use agentview and wrist RGB.

GPU policy rollouts are not yet validated; validation covers checkpoint loading for all five variants.

## Running in WorldFoundry

Run the policy with `wf run molmoact2-droid --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `allenai/MolmoAct2-DROID`, `allenai/MolmoAct2-BimanualYAM`, and `allenai/MolmoAct2-SO100_101` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh molmoact2-droid`. Add `--download` to fetch missing public checkpoints.
