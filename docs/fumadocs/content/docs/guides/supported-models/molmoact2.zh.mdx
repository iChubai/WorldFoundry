MolmoAct2 是 AI2 的第二代动作推理模型，Apache-2.0 checkpoint 阵容齐全：base、Think（深度推理）、DROID（Franka）、双臂 YAM、SO100/101 与 LIBERO。WorldFoundry 将官方 DROID/YAM predict_action 契约作为 action_trace pipeline 运行，无需外部源码检出。

## 用来做什么

用 `molmoact2-droid` 根据观测和语言指令预测机器人动作。

MolmoAct2 基于 Molmo 开放 VLM 线并加动作推理头；Think 变体在行动前增加基于深度的推理。DROID、YAM、SO100、LIBERO 与 Think-LIBERO 变体各自加载对应 checkpoint 并返回动作轨迹。该模型由艾伦人工智能研究所（AI2）发布。

任务：视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行、机器人策略。别名：`molmo-act2`、`molmoact`、`molmoact2-droid`、`molmoact2-yam`。同系列还有 `molmoact2-bimanual-yam`、`molmoact2-so100-101`、`molmoact2-libero`。

推荐评测：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（有专门的 LIBERO 与 Think-LIBERO checkpoint）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`molmoact2_action_trace.json`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `MolmoAct2Pipeline`。

建议从 `molmoact2-droid` 开始。该系列共有 5 个 variant，可在上方命令构建器中切换：`molmoact2-droid`（`vla.policy_rollout`）：Runner 一致性待确认、`molmoact2-bimanual-yam`（`vla.policy_rollout`）：Runner 一致性待确认、`molmoact2-so100-101`（`vla.policy_rollout`）：Runner 一致性待确认、`molmoact2-libero`（`vla.policy_rollout`）：Runner 一致性待确认、`molmoact2-think-libero`（`vla.policy_rollout`）：Runner 一致性待确认。系列状态：**已验证**。

按本体选择 checkpoint：Franka 机械臂用 DROID，双臂 YAM 用 BimanualYAM，SO-ARM 用 SO100_101，仿真用 LIBERO/Think-LIBERO。各变体的相机与状态输入不同：DROID 使用 external_cam、external_cam_2、wrist_cam 与 8 维状态；YAM 使用 top_cam、left_cam、right_cam 与 14 维状态；SO100/SO101 使用 top_cam、side_cam 与 6 维状态；LIBERO 与 Think-LIBERO 使用 agentview 与腕部 RGB。

尚未验证 GPU 策略 rollout；已验证的是全部五个变体的 checkpoint 加载。

## 在 WorldFoundry 中运行

用 `wf run molmoact2-droid --pipeline.task-profile interactive-video` 运行策略。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`allenai/MolmoAct2-DROID`、`allenai/MolmoAct2-BimanualYAM`、`allenai/MolmoAct2-SO100_101` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh molmoact2-droid`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
