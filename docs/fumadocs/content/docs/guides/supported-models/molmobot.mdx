## What it is for

Pick `molmobot-droid` when you want the catalog VLA policy: instruction and observation in, an action trace out. Use it to roll the recorded policy, not to train a new one.

Two inference contracts are recorded: an OLMo-based MolmoBot path and a MolmoBot-Pi0 path. Resolver, runtime import, and compileall checks pass without an external checkout; further internals are not recorded in this repository. It is published by Allen Institute for AI (AI2).

Catalog tasks include vla, vla action prediction, vla policy rollout, and robot policy. Catalog aliases include `molmob0t`, `molmobot-droid`, and `molmobot-pi0`. Also recorded: `molmobot-pi0-droid`.

## Runtime contract

Required `image`, `prompt`, and `state`; optional `model_id` (molmobot), `camera_keys` (exo_camera_1, wrist_camera), `state_keys` (qpos.arm, qpos.gripper), `policy_family`, and `action_representation`; artifacts `action_trace` and `molmobot_action_trace.json`.

Recorded task profiles: `vla`, `vla.action_prediction`, `vla.policy_rollout`, and `robot_policy`. WorldFoundry binds `MolmoBotPipeline`.

Start on `molmobot-droid`. The family registers 2 catalog variants (cards above): `molmobot-droid` (`vla.policy_rollout`) — Planned; `molmobot-pi0-droid` (`vla.policy_rollout`) — Planned. Family status: **Planned**.

Checkpoint-backed action-chunk validation remains required before demo parity is claimed. Choose MolmoBot-DROID for Franka, RBY1Multitask for the RBY1 humanoid platform.

WorldFoundry records MolmoBot OLMo/MolmoBot-Pi0 action inference contracts with an independent synthesis entrypoint.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run molmobot-droid --pipeline.task-profile vla.policy_rollout`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch>=2.3.1).

Recorded weight repositories include `allenai/MolmoBot-DROID`, `allenai/MolmoBot-Pi0-DROID`, and `allenai/MolmoBot-Img-DROID` among others. Stage assets with `bash scripts/inference/prepare_model_infer.sh molmobot-droid`.

Recorded licenses include apache-2.0; status: **Planned**.
