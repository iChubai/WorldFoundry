MolmoBot 是 AI2 围绕 Molmo VLM 的机器人策略家族。Franka DROID、图像条件 DROID 和 RBY1 多任务 checkpoint 采用 Apache-2.0；基于 Pi0 的 DROID checkpoint 标注为 Gemma 许可。WorldFoundry 支持两条动作推理路径。

## 用来做什么

`molmobot-droid` 是视觉-语言-动作（VLA）策略：输入指令和观测，输出动作。

基于 OLMo 的路径输出机器人专用动作块；独立的 Pi0-DROID 路径加载发布的 OpenPI 权重并解码关节位置手臂/夹爪动作。该模型由艾伦人工智能研究所（AI2）发布。

任务：视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行、机器人策略。别名：`molmob0t`、`molmobot-droid`、`molmobot-pi0`。同系列还有 `molmobot-pi0-droid`。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `official-policy-observation`；产物 `molmobot_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `MolmoBotPipeline`。

建议从 `molmobot-droid` 开始。该系列共有 2 个 variant，可在上方命令构建器中切换：`molmobot-droid`（`vla.policy_rollout`）：Runner 一致性待确认、`molmobot-pi0-droid`（`vla.policy_rollout`）：Runner 一致性待确认。系列状态：**已验证**。

MolmoBot-DROID、MolmoBot-Img-DROID 和 MolmoBot-Pi0-DROID 已在真实 DROID 观测上通过离线推理验证。Pi0 需要固定版本的 OpenPI 依赖与 PaliGemma tokenizer；RBY1Multitask 尚未验证。

尚未测量闭环机器人任务成功率或动作语义质量。Pi0 测试对仿真训练的策略使用了分布外的真实观测。

输入任务提示、`exo_camera_1` 与 `wrist_camera` 图像，以及对应的机器人状态。Pi0-DROID 已验证的状态包含 7 个手臂关节位置和 2 个夹爪值；输出动作包含手臂 `(7,)` 与夹爪 `(1,)`。使用发布的 `allenai/MolmoBot-Pi0-DROID` 权重，并通过 `MolmoBotPipeline.from_pretrained(..., variant="pi0_droid")` 选择 Pi0 路径。它需要固定版本的独立 OpenPI 依赖及 PaliGemma tokenizer；仓内公开适配器不会加载 MolmoSpaces 仿真器。

## 在 WorldFoundry 中运行

运行 `wf run molmobot-droid --pipeline.task-profile default` 预测动作。

运行环境：独立环境 `worldfoundry-molmobot-pi0-cu128`（Python 3.11，CUDA 12.8，torch==2.7.1）。

权重仓库：`allenai/MolmoBot-DROID`、`allenai/MolmoBot-Pi0-DROID`、`allenai/MolmoBot-Img-DROID` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh molmobot-droid`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0、Gemma 使用条款。
