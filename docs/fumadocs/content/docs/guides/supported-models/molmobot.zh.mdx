MolmoBot 是 AI2 围绕 Molmo VLM 的机器人策略家族，Apache-2.0 checkpoint 覆盖 Franka DROID、图像条件 DROID、RBY1 多任务与基于 Pi0 的 DROID 变体。WorldFoundry 记录 OLMo/MolmoBot-Pi0 动作推理契约，并调用扁平化树内推理封装。

## 用来做什么

需要 catalog 上的 VLA 策略时选 `molmobot-droid`：指令与观测进、动作轨迹出。用来滚动已记录策略，不是用来训练新策略。

仓库记录两个推理契约：基于 OLMo 的 MolmoBot 路径与 MolmoBot-Pi0 路径。解析器、运行时导入与 compileall 检查无需外部 checkout 即通过；更多内部细节仓库未记录。该模型由艾伦人工智能研究所（AI2）发布。

catalog 记录的任务包括 视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行、机器人策略。别名包括 `molmob0t`、`molmobot-droid`、`molmobot-pi0`。同系列还有 `molmobot-pi0-droid`。

MolmoBot VLA rollout。不是 MolmoAct2。

## 运行时契约

必填 `image`、`prompt`、`state`；可选 `model_id` (molmobot)、`camera_keys` (exo_camera_1, wrist_camera)、`state_keys` (qpos.arm, qpos.gripper)、`policy_family`、`action_representation`；产物 `action_trace`、`molmobot_action_trace.json`。

记录的任务 profile：`vla`、`vla.action_prediction`、`vla.policy_rollout`、`robot_policy`。绑定的 pipeline 类是 `MolmoBotPipeline`。

起步 variant 是 `molmobot-droid`。catalog 登记了 2 个 variant（上方卡片）：`molmobot-droid`（`vla.policy_rollout`）：计划中、`molmobot-pi0-droid`（`vla.policy_rollout`）：计划中。系列状态：**计划中**。

在声称 demo parity 前仍需 checkpoint 驱动的动作块验证。 Franka 用 MolmoBot-DROID，RBY1 人形平台用 RBY1Multitask。

导入验证进行中；尚未声称 demo parity。

## 在 WorldFoundry 中运行

catalog 启动命令是 `worldfoundry-eval run molmobot-droid --pipeline.task-profile vla.policy_rollout`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch>=2.3.1）。

记录的权重仓库包括 `allenai/MolmoBot-DROID`、`allenai/MolmoBot-Pi0-DROID`、`allenai/MolmoBot-Img-DROID` 等。就位权重用 `bash scripts/inference/prepare_model_infer.sh molmobot-droid`。

记录 license 为 apache-2.0；状态：**计划中**。
