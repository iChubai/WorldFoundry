MonST3R 把 DUSt3R 的点图方法扩展到动态场景：直接从视频逐时刻估计几何，在不假设静态场景的前提下同时恢复形状与运动。已通过 Studio 在 CUDA 上验证：pipeline 产出含 51 个几何体、点数据有限的合法 GLB 场景。

## 用来做什么

`monst3r` 从图像恢复 3D 几何：输入多视图，输出重建结果、相机轨迹或点云。

按上游论文，MonST3R 在动态数据上微调 DUSt3R 的点图回归器，使点图按时刻估计；下游优化将其对齐为 4D 场景。WorldFoundry 将结果输出为 GLB 场景。该模型由Google DeepMind / 加州大学伯克利分校发布。

任务：geometry estimation in the presence of motion。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `weights`、`seq-name`、`niter`、`flow-loss-weight`、`skip-pair-dynamic-mask`、`silent` 等 7 项；产物 `generated_4d_scene`、`monst3r.glb`。

CLI task profile：`default`。绑定的 pipeline 类是 `MonST3RPipeline`。

系列状态：**已验证**。

Studio 默认关闭可选的光流损失，因此 RAFT2/SAM2 资产缺失不会阻塞预览输出。若要完整对齐官方动态掩码效果，请在运行时环境中配置 MonST3R、RAFT 与 SAM2 资产。

## 在 WorldFoundry 中运行

用 `wf run monst3r --pipeline.task-profile default` 重建场景。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型没有登记公开 checkpoint；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh monst3r`；下载缺失的公开权重时加 `--download`。
