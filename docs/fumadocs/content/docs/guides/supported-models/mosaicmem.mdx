MosaicMem is a memory-augmented world-model component: it ingests keyframe patches, retrieves target views, summarizes coverage, and composes latent canvases — producing a memory index rather than video. It is exposed through worldfoundry.core.memory.

## What it is for

Use `mosaicmem` to generate an explorable world.

The upstream source is MIT-licensed. The output artifact type is memory_index.

Tasks: world model, memory augmented generation, and video generation. Output modalities: video.

Suggested benchmarks: [MemoBench](/docs/evaluation/benchmark-hub/memobench) (Long-horizon memory consistency evaluation).

## Runtime contract

Artifacts `memory_index` and `mosaicmem_runtime_plan.json`.

CLI task profiles: `default`. WorldFoundry binds `MosaicMemPipeline`.

Family status: **Runner parity pending**.

Until the required checkpoints and assets are staged, generation returns a runtime plan that lists the missing assets. Use it as the memory side of a world-model stack, not as a standalone generator.

Produces memory indexes, not video artifacts.

## Running in WorldFoundry

Run `wf run mosaicmem --pipeline.task-profile default` to generate the world.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

No public checkpoint is listed for this model; stage the weights as described in the usage notes. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh mosaicmem`. Add `--download` to fetch missing public checkpoints.
