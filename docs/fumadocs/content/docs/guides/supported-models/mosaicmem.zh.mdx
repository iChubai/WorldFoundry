MosaicMem 是记忆增强的世界模型组件：摄取关键帧 patch、检索目标视图、汇总覆盖度并组合潜空间画布——产物是记忆索引而非视频。本 catalog 中其源码路径按记忆计划产物注册，并通过 worldfoundry.core.memory 暴露；生成器资产保持运行时限制。
