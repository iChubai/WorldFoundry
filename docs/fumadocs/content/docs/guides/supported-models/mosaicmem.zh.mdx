MosaicMem 是记忆增强的世界模型组件：摄取关键帧 patch、检索目标视图、汇总覆盖度并组合潜空间画布——产物是记忆索引而非视频。它通过 worldfoundry.synthesis.visual_generation.memory.mosaic 暴露。

## 用来做什么

用 `mosaicmem` 生成可探索的世界。

上游源码为 MIT 许可。产物类型为 memory_index。

任务：世界模型、memory-augmented-generation、视频生成。输出模态为视频。

推荐评测：[MemoBench](/zh/docs/evaluation/benchmark-hub/memobench)（长时程记忆一致性评测）。

## 运行时契约

产物 `memory_index`、`mosaicmem_runtime_plan.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `MosaicMemPipeline`。

系列状态：**Runner 一致性待确认**。

在所需 checkpoint 与资产就位前，生成会返回列出缺失资产的运行时计划。请把它当作世界模型栈的记忆侧组件使用，而非独立生成器。

产物是记忆索引，不是视频。

## 在 WorldFoundry 中运行

运行 `wf run mosaicmem --pipeline.task-profile default` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型没有登记公开 checkpoint；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh mosaicmem`；下载缺失的公开权重时加 `--download`。
