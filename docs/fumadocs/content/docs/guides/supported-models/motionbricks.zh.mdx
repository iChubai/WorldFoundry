MotionBricks 属于英伟达 GR00T-WholeBodyControl 栈：用于生成人形机器人全身运动，属于具身世界建模的动作侧，产物是动作轨迹而非视频（论文 arXiv 2604.24833）。

<ModelPaperFigures modelId="motionbricks" locale="zh" />

论文：[MotionBricks: Scalable Real-Time Motions with Modular Latent Generative Model and Smart Primitives](https://arxiv.org/abs/2604.24833)（SIGGRAPH 2026, 2026）。

项目页：[nvlabs.github.io/motionbricks](https://nvlabs.github.io/motionbricks/)。代码：[NVlabs/GR00T-WholeBodyControl](https://github.com/NVlabs/GR00T-WholeBodyControl)。

## 用来做什么

用 `motionbricks` 以动作推进世界并渲染出相应画面。

WorldFoundry 以固定 commit 运行 GR00T-WholeBodyControl 仓库中 Apache-2.0 许可的官方 MotionBricks 源码，产物为 action_trace。该模型由英伟达（NVIDIA）发布。

任务：human-action-generation、motion-generation、世界模型。

## 运行时契约

产物 `action_trace`、`motionbricks_runtime_plan.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `MotionBricksPipeline`。

系列状态：**Runner 一致性待确认**。

将官方源码放在 $\{WORLDFOUNDRY_MODEL_SOURCE_DIR\}/GR00T-WholeBodyControl/motionbricks，并准备 MotionBricks checkpoint 与机器人资产。资产准备好之前，运行只会写出列出缺失资产的运行时计划（motionbricks_runtime_plan.json），不会生成运动。

产物是动作轨迹，不是视频。

必填 `prompt`、`video`；可选 `image`；`actions`：whole_body_motion, control_sequence；产物 `action_trace`、`motionbricks_runtime_plan.json`。

## 在 WorldFoundry 中运行

用 `wf run motionbricks --pipeline.task-profile default` 推进世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型未登记公开的 checkpoint；请按使用说明准备权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh motionbricks`；下载缺失的公开权重时加 `--download`。
