MotionCtrl 是统一、灵活的视频生成运动控制器：在单一模型中独立控制相机运动与物体运动（SIGGRAPH 2024）。已使用发布的 MotionCtrl 权重验证：相机运动 demo 可使用内置相机位姿示例完整运行。

## 用来做什么

用 `motionctrl` 生成可探索的世界。

按论文，相机运动控制模块以相机位姿序列为条件、物体运动控制模块以轨迹为条件，挂接在 LVDM 系视频基座上。WorldFoundry 在进程内运行模型栈、控制模块与采样器，无需检出上游仓库。该模型由腾讯（ARC Lab）发布。

任务：interactive-video。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机运动控制贴合度）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `height`、`width`、`seed`、`camera-pose-path`、`condtype`、`unconditional-guidance-scale` 等 7 项；产物 `motionctrl.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `MotionCtrlPipeline`。

系列状态：**已验证**。

`interactive-video` 的默认值：height=256, width=256, seed=42。

从内置的默认相机/物体运动条件与推理配置开始；需提供本地 MotionCtrl checkpoint。

## 在 WorldFoundry 中运行

运行 `wf run motionctrl --pipeline.task-profile interactive-video` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`TencentARC/MotionCtrl`、`TencentARC/MotionCtrl_SVD`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh motionctrl`；下载缺失的公开权重时加 `--download`。
