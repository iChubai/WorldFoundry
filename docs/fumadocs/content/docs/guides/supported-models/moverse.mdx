MoVerse turns one image into a navigable world: it builds a panoramic Gaussian scaffold from the input and generates camera-controlled video as you move through it. Validated on an H100: the pipeline runs the complete 161-frame path. It needs staged checkpoints, gated FLUX access, compatible CUDA kernels, and at least 24 GB VRAM.

## What it is for

Use `moverse` when the viewpoint must follow a given camera path.

Assembles GeoCalib AutoLevel, Depth Anything 3, SHARP panorama, Wan (Wan2.1-T2V-1.3B video base), and TAEHV components, plus FLUX.1-Fill-dev as the panorama base and MoVerse's own component weights.

Tasks: image-to-navigable-world, camera-controlled video, and panoramic gaussian scaffold. Aliases: `mo-verse` and `Orange-3DV-Team/MoVerse`. Modalities: image in, world state out.

Suggested benchmarks: [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Navigable generated-world quality), [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-control adherence during navigation).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `frames` and `fps`; artifacts `generated_world`, `gaussian_scaffold`, and `generated_video`.

CLI task profiles: `default`. WorldFoundry binds `MoVersePipeline`.

Family status: **Runner parity pending**.

Execution is offline and needs four pre-staged Hugging Face snapshots (`Orange-3DV-Team/MoVerse`, `black-forest-labs/FLUX.1-Fill-dev`, `depth-anything/DA3NESTED-GIANT-LARGE-1.1`, `Wan-AI/Wan2.1-T2V-1.3B`) plus ffmpeg, gsplat, and compatible CUDA kernels.

## Running in WorldFoundry

Run `wf run moverse --pipeline.task-profile default` to follow the camera path.

Weights: `Orange-3DV-Team/MoVerse`, `black-forest-labs/FLUX.1-Fill-dev`, and `depth-anything/DA3NESTED-GIANT-LARGE-1.1` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh moverse`. Add `--download` to fetch missing public checkpoints.
