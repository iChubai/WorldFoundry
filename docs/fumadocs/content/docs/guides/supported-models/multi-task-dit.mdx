## What it is for

Pick `multi-task-dit` when you want the catalog VLA policy: instruction and observation in, an action trace out. Use it to roll the recorded policy, not to train a new one.

A DiT (diffusion transformer) policy head conditioned on multi-task context, following the LeRobot reference implementation. Further internals are not recorded in this repository. It is published by Hugging Face (LeRobot reference).

Catalog tasks include imitation learning, diffusion transformer policy, and robot policy. Catalog aliases include `multi_task_dit` and `multitask-dit-policy`.
