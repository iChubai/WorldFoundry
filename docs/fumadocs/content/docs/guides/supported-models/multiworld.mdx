## What it is for

`multiworld` is an action-conditioned world model: actions and a starting frame in, a rollout out.

MultiWorld builds on Wan2.2-TI2V-5B (base model and VAE) with an action encoder and VGGT-1B as the environment encoder; the ItTakesTwo weights are Haoyuwu/MultiWorldCheckpoint.

Tasks: video generation, multi agent world model, interactive video generation, and game video. Aliases: `multiword` and `multiworld-ittakestwo`. Output modalities: video.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Multi-agent world-rollout quality).

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `frames`, `fps`, `steps`, `action-path`, `save-name`, `inference-seed`, and 1 more; artifacts `multiworld.mp4`.

CLI task profiles: `default`. WorldFoundry binds `MultiWorldItTakesTwoPipeline`.

Family status: **Verified**.

Defaults for `default`: frames=81, fps=60.

Supply an initial image and two-player discrete and continuous action tensors (or an action CSV). Validated with the released toydata checkpoint: the pipeline generates 81 frames at 480x480 with 35 steps.

## Running in WorldFoundry

Run `wf run multiworld --pipeline.task-profile default` to roll out the world model.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Haoyuwu/MultiWorldCheckpoint`, `Wan-AI/Wan2.2-TI2V-5B`, and `facebook/VGGT-1B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh multiworld`. Add `--download` to fetch missing public checkpoints.
