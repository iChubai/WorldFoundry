## 用来做什么

需要动作条件世界步进时选 `multiworld`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

除已记录任务外的架构内部细节仓库未存。上游许可为自定义条款，已标记需人工审查。

catalog 记录的任务包括 video_generation、multi-agent-world-model、交互式视频生成、game-video。别名包括 `multiword`、`multiworld-ittakestwo`。输出模态为视频。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（多智能体世界滚动生成质量）。
