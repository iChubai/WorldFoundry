## 用来做什么

`mvdiffusion` 从图像恢复 3D 几何：输入多视图，输出重建结果、相机轨迹或点云。

按 NeurIPS 2023 论文（arXiv 2307.01097），多个并行扩散分支借助「对应感知注意力」同时生成所有视图并保持全局一致。该模型由西蒙菲莎大学（Simon Fraser University）发布。

任务：correspondence-aware multiview image generation and scene texturing。别名：`MVDiffusion: Enabling Holistic Multi-view Image Generation`。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `steps`、`gen-video`、`python-executable`；产物 `generated_image`、`mvdiffusion.png`。

CLI task profile：`default`。绑定的 pipeline 类是 `MVDiffusionPipeline`。

系列状态：**Runner 一致性待确认**。

图像扩展路线需要一张输入图像，默认产物为全景 PNG。

各视角生成的墙面和物体可能明显偏离输入场景。

## 在 WorldFoundry 中运行

用 `wf run mvdiffusion --pipeline.task-profile default` 重建场景。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型没有登记公开 checkpoint；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh mvdiffusion`；下载缺失的公开权重时加 `--download`。
