## What it is for

Use `neoverse` to generate an explorable world.

Per the upstream release (arXiv 2601.00393), NeoVerse layers 4D reconstruction and control roles over a Wan video backbone. It is published by CreateAI (formerly TuSimple).

Tasks: 4D world modeling from in the wild monocular videos. Aliases: `NeoVerse: Enhancing 4D World Model`.

Suggested benchmarks: [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Scores navigable generated worlds), [4DWorldBench](/docs/evaluation/benchmark-hub/4dworldbench) (Matches NeoVerse's 4D world-model focus).

## Runtime contract

Inputs `video` and `prompt` (bundled samples are used when omitted); options `predefined-trajectory`, `num-frames`, `num-inference-steps`, `cfg-scale`, `seed`, `trajectory-mode`, and 7 more; artifacts `generated_world`, `generated_4d_scene`, and `neoverse.mp4`.

CLI task profiles: `official-tilt-up-video`. WorldFoundry binds `NeoVersePipeline`.

Family status: **Verified**.

Defaults for `official-tilt-up-video`: seed=42.

Running requires NeoVerse, Wan, reconstructor, LoRA, and CUDA assets. For video input, follow the official path with static_scene=false.

## Running in WorldFoundry

Run `wf run neoverse --pipeline.task-profile official-tilt-up-video` to generate the world.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Yuppie1204/NeoVerse`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh neoverse`. Add `--download` to fetch missing public checkpoints.
