## 用来做什么

用 `neoverse` 生成可探索的世界。

按上游发布（arXiv 2601.00393），NeoVerse 在 Wan 视频基座上叠加 4D 重建与控制角色。该模型由 CreateAI（原图森未来）发布。

任务：4D world modeling from in-the-wild monocular videos。别名：`NeoVerse: Enhancing 4D World Model`。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（评估可游走的生成世界）、[4DWorldBench](/zh/docs/evaluation/benchmark-hub/4dworldbench)（契合 NeoVerse 的 4D 世界模型定位）。

## 运行时契约

输入 `video`、`prompt`（不传时使用内置示例）；参数 `predefined-trajectory`、`num-frames`、`num-inference-steps`、`cfg-scale`、`seed`、`trajectory-mode` 等 13 项；产物 `generated_world`、`generated_4d_scene`、`neoverse.mp4`。

CLI task profile：`official-tilt-up-video`。绑定的 pipeline 类是 `NeoVersePipeline`。

系列状态：**已验证**。

`official-tilt-up-video` 的默认值：seed=42。

运行需要 NeoVerse、Wan、重建器、LoRA 与 CUDA 资产。视频输入请按官方路径使用 static_scene=false。

## 在 WorldFoundry 中运行

运行 `wf run neoverse --pipeline.task-profile official-tilt-up-video` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`Yuppie1204/NeoVerse`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh neoverse`；下载缺失的公开权重时加 `--download`。
