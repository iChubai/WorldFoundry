Navigation World Models (NWM) is Meta's navigation world model (CVPR 2025 highlight): a conditional diffusion transformer that predicts egocentric future video from past frames and navigation actions, and can plan trajectories by imagining them. Variants cover the RECON and SCAND dataset checkpoints. Runs need the checkpoints and evaluation datasets staged locally.

## What it is for

`nwm-recon` generates future frames conditioned on actions.

Per the upstream release, a Conditional Diffusion Transformer (CDiT) scales to 1B parameters and conditions on action and time embeddings for egocentric prediction (checkpoints at facebook/nwm, CC-BY-NC-4.0). It is published by Meta AI (FAIR).

Tasks: navigation world model, action-conditioned video, and egocentric video generation. Aliases: `navigation-world-models`, `nwm-recon`, and `nwm-scand`. Output modalities: video. Other variants: `nwm-scand`.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Navigation world-rollout quality).

NWM predicts egocentric future video from past frames plus navigation actions. Pick `nwm-recon` for RECON weights, or `nwm-scand` for SCAND.

## Runtime contract

Artifacts `nwm.mp4`.

CLI task profiles: `default`. WorldFoundry binds `NWMPipeline`.

Start with `nwm-recon`. The family has 2 variants, selectable in the command builder above: `nwm-recon` (`navigation-world-model`) — Planned; `nwm-scand` (`navigation-world-model`) — Planned. Family status: **Runner parity pending**.

The pipeline calls the official NWM inference entrypoint and reports which checkpoints and evaluation datasets are missing until they are staged. Use it for non-driving navigation video evaluation.

CC-BY-NC-4.0: non-commercial license.

## Running in WorldFoundry

Step the world with `wf run nwm-recon --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `facebook/nwm`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh nwm-recon`. Add `--download` to fetch missing public checkpoints.
