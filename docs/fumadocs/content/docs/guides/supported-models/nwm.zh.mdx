Navigation World Models（NWM）是 Meta 的导航世界模型（CVPR 2025 highlight）：条件扩散 Transformer，从历史帧与导航动作预测第一视角未来视频，并能通过「想象」来规划轨迹。variant 覆盖 RECON 与 SCAND 数据集 checkpoint。运行前需在本地就位 checkpoint 与评估数据集。

## 用来做什么

`nwm-recon` 以动作为条件生成未来帧。

按上游发布，条件扩散 Transformer（CDiT）参数量达 1B，以动作与时间嵌入为条件做第一视角预测（checkpoint 位于 facebook/nwm，CC-BY-NC-4.0）。该模型由Meta AI（FAIR）发布。

任务：navigation-world-model、动作条件视频、egocentric-video-generation。别名：`navigation-world-models`、`nwm-recon`、`nwm-scand`。输出模态为视频。同系列还有 `nwm-scand`。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（导航世界滚动生成质量）。

## 运行时契约

产物 `nwm.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `NWMPipeline`。

建议从 `nwm-recon` 开始。该系列共有 2 个 variant，可在上方命令构建器中切换：`nwm-recon`（`navigation-world-model`）：计划中、`nwm-scand`（`navigation-world-model`）：计划中。系列状态：**Runner 一致性待确认**。

pipeline 调用官方 NWM 推理入口，在 checkpoint 与评估数据集就位前报告缺失项。适用于非驾驶类导航视频评估。
