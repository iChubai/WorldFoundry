## What it is for

Pick `oasis-500m` when you need an action-conditioned world stepper: recorded actions and a frame in, a rollout out. Use it for interactive world inference, not a text-to-video prompt dump.

Per the upstream release, a ViT VAE compresses frames and a 500M diffusion transformer generates the next frame conditioned on past frames and actions (MIT license). Internals beyond this are not recorded here. It is published by Etched / Decart.

Catalog tasks include interactive-world-model, minecraft-world-model, and action-conditioned-video. Catalog aliases include `open-oasis` and `oasis`.

Recorded evaluation entry points include [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Action-conditioned game-world rollout quality).
