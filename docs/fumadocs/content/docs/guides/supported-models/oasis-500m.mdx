Oasis 500M (open-oasis) is the open release of the famous playable-Minecraft world model: an action-conditioned diffusion transformer that renders the next game frame from context frames and keyboard/mouse actions. In this catalog the source is vendored in-tree; execution waits on the Etched/oasis-500m checkpoint plus prompt image/video and action tensors.

## Architecture

Per the upstream release, a ViT VAE compresses frames and a 500M diffusion transformer generates the next frame conditioned on past frames and actions (MIT license). Internals beyond this are not recorded here.

## Usage notes

The pipeline resolves the official generate entrypoint and returns blocked diagnostics until checkpoints and action assets are staged. Supply action tensors in the official format.
