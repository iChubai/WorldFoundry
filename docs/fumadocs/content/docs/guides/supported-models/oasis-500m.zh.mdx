Oasis 500M（open-oasis）是「可游玩 Minecraft」世界模型的开源版本：动作条件扩散 Transformer，从上下文帧与键鼠动作渲染下一游戏帧。已通过真实权重 GPU 推理验证。运行前需就位 Etched/oasis-500m 权重、提示图像或视频以及动作张量。

## 用来做什么

`oasis-500m` 是动作条件世界模型：输入动作和起始帧，输出推演结果。

按上游发布，ViT VAE 压缩帧，500M 扩散 Transformer 以历史帧与动作为条件生成下一帧（MIT 许可）。该模型由 Etched / Decart 发布。

任务：交互式世界模型、Minecraft 世界模型、动作条件视频。别名：`open-oasis`、`oasis`。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件游戏世界滚动生成质量）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`plan-only`、`timeout-seconds`、`ddim-steps`；产物 `oasis-500m.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `Oasis500MPipeline`。

系列状态：**已验证**。

`interactive-video` 的默认值：frames=32, fps=20。

按官方 Open-Oasis 格式提供 25 列动作张量。上游转换器把 MineRL camera[0] 映射为 cameraX、camera[1] 映射为 cameraY，再分别按 (raw-40)/40 归一化。MineRL 定义 camera[0] 为垂直俯仰、camera[1] 为水平偏航，因此 cameraX 虽名为 X，实际是俯仰。依据：https://github.com/etched-ai/open-oasis/blob/f59deef2c019c212bd0c5a3a5b986a51f3701847/utils.py 和 https://github.com/minerllabs/minerl/blob/cdeae668c2f334e3c9117adf651b5a94436b45f8/minerl/herobraine/hero/handlers/agent/actions/camera.py。使用本地权重时，WORLDFOUNDRY_CKPT_DIR 应指向包含 Etched--oasis-500m 的目录。

## 在 WorldFoundry 中运行

用 `wf run oasis-500m --pipeline.task-profile interactive-video` 推进世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`Etched/oasis-500m`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh oasis-500m`；下载缺失的公开权重时加 `--download`。
