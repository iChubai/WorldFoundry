## 用来做什么

需要动作条件世界步进时选 `oasis-500m`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

按上游发布，ViT VAE 压缩帧，500M 扩散 Transformer 以历史帧与动作为条件生成下一帧（MIT 许可）。除此之外的内部细节此处未记录。该模型由Etched / Decart发布。

catalog 记录的任务包括 交互式世界模型、Minecraft 世界模型、动作条件视频。别名包括 `open-oasis`、`oasis`。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件游戏世界滚动生成质量）。
