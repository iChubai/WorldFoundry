Octo is Berkeley RAIL’s transformer generalist robot policy with a diffusion action head, implemented in JAX / Flax. The official paper is [Octo: An Open-Source Generalist Robot Policy](https://arxiv.org/abs/2405.12213) (arXiv 2405.12213). The project page is [octo-models.github.io](https://octo-models.github.io/). The GitHub tree is [octo-models/octo](https://github.com/octo-models/octo).

<ModelPaperFigures modelId="octo" locale="en" />

WorldFoundry runs Octo with its own inference code; no upstream checkout is needed. Two variants share that code: `octo-base-1.5` and `octo-small-1.5`. Validated on an A100 with the official **octo-small-1.5** checkpoint: the Orbax tree restores (**136,670,604** parameters) and `sample_actions` returns a finite **(1, 4, 7)** action chunk. `octo-base-1.5` sampling is not validated.

## What it is for

Start on `octo-small-1.5` for the GPU-validated path. Required inputs are `image`, `instruction`, `prompt`, and `video`. `OctoPipeline` writes `octo_action_trace.json`. Default runtime config pins `variant=small`, `dataset_key=bridge_dataset`, `image_key=image_primary`.

`octo-base-1.5` uses the same modeling code with its own Hugging Face checkpoint. A common evaluation venue for Open-X generalist policies is [SimplerEnv](/docs/evaluation/benchmark-hub/simpler-env). Real rollout still needs a benchmark-specific action-space binding.

## Runtime contract

Images are resized to **256×256**. The verified small-policy chunk is **batch 1 × action horizon 4 × action dim 7**. Text assets declared next to the policy: CLIP processor at `${WORLDFOUNDRY_HFD_ROOT}/openai--clip-vit-base-patch32` and a local multilingual sentence encoder under `${WORLDFOUNDRY_CKPT_DIR}/octo/universal-sentence-encoder-multilingual-3`.

## Running in WorldFoundry

Dedicated environment `worldfoundry-octo-jax` (Python 3.10, CUDA 11.8, JAX 0.4.20, cuDNN 8.9). This is not the PyTorch unified stack. Launch the GPU-validated variant with:

```
wf run octo-small-1.5
```

The command builder's default launch uses `octo-base-1.5`; switch to `octo-small-1.5` for the validated path. The license is not stated — confirm upstream terms before production use.
