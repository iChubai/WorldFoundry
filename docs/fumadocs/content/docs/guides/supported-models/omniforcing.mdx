## What it is for

`omniforcing` generates a 3D-consistent world rather than a single clip.

Tasks: audio visual world model, real time generation, and distillation.

## Runtime contract

Artifacts `generated_video` and `omniforcing_runtime_plan.json`.

CLI task profiles: `default`. WorldFoundry binds `OmniForcingPipeline`.

Family status: **Runner parity pending**.

Stage the required checkpoints and runtime assets first. Until they are in place, a run writes a runtime plan (`omniforcing_runtime_plan.json`) that lists the missing assets instead of generating video.

The upstream repository has no root license: legal review is required before use.

## Running in WorldFoundry

Run `wf run omniforcing --pipeline.task-profile default` to generate the world.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

No public checkpoint is listed for this model; stage the weights as described in the usage notes. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh omniforcing`. Add `--download` to fetch missing public checkpoints.
