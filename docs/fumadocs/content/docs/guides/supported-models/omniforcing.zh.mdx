## 用来做什么

`omniforcing` 生成 3D 一致的世界，而不只是一段视频。

任务：audio-visual-world-model、实时生成、蒸馏。

## 运行时契约

产物 `generated_video`、`omniforcing_runtime_plan.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `OmniForcingPipeline`。

系列状态：**Runner 一致性待确认**。

先就位所需 checkpoint 与运行时资产。资产就位前，运行只写出列出缺失资产的运行时计划（`omniforcing_runtime_plan.json`），不会生成视频。

上游仓库缺少根许可文件：使用前需要法律审查。

## 在 WorldFoundry 中运行

运行 `wf run omniforcing --pipeline.task-profile default` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型没有登记公开 checkpoint；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh omniforcing`；下载缺失的公开权重时加 `--download`。
