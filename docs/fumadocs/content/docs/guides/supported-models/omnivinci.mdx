## What it is for

`omnivinci` is a multimodal reasoning model.

OmniVinci combines a Qwen2 causal decoder, a Dynamic-S2 SigLIP vision tower and a Qwen2Audio encoder with temporal pooling and rotary embeddings. WorldFoundry packages the Apache-2.0 inference glue from nvidia/omnivinci revision 7b3777b and loads its backbones from local checkpoint data.

Tasks: multimodal reasoning, audio reasoning, image question answering, and video question answering. Aliases: `nvidia/omnivinci`.

## Runtime contract

Inputs `prompt`, `image`, and `video`; artifacts `omnivinci.json`.

CLI task profiles: `multimodal-reasoning`, `audio-reasoning`, `image-question-answering`, `video-question-answering`, and `video_generation`. WorldFoundry binds `OmniVinciPipeline`.

Family status: **Runner parity pending**.

Use it to ask questions about images and videos, rather than to generate content. Video requests default to 8 frames (max_video_frames accepts 1–128); load_audio_in_video is false by default. The local checkpoint must include its llm, vision_tower, sound_tower and both projector directories, tokenizer data and qwen2.jinja.

Checkpoint-backed GPU artifacts have not been verified; runner parity remains pending.

## Running in WorldFoundry

Run the model with `wf run omnivinci --pipeline.task-profile multimodal-reasoning`. Switch tasks in the command builder above to change `--pipeline.task-profile`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `nvidia/omnivinci`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh omnivinci`. Add `--download` to fetch missing public checkpoints.
