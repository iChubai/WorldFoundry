## 用来做什么

走记录的多模态推理路由时选 `omnivinci`：记录输入进、推理产物出。本卡是推理器而不是生成器时用它。

OmniVinci 结合 Qwen2 自回归解码器、Dynamic-S2 SigLIP 视觉编码器与 Qwen2Audio 音频编码器，并使用时间池化和旋转位置编码。WorldFoundry 将 nvidia/omnivinci 的 7b3777b 版本 Apache-2.0 推理组件纳入包内，从本地 checkpoint 数据加载原生 Transformers 骨干。该模型由英伟达（NVIDIA）发布。

catalog 记录的任务包括 多模态推理、音频推理、图像问答、视频问答。别名包括 `nvidia/omnivinci`。

## 运行时契约

可选 `prompt`、`image`、`video`、`seed`、`frames`；产物 `omnivinci.json`。

CLI task profile：`multimodal-reasoning`、`audio-reasoning`、`image-question-answering`、`video-question-answering`、`video_generation`。绑定的 pipeline 类是 `OmniVinciPipeline`。

系列状态：**Runner 一致性待确认**。

用于图像与视频问答，而非内容生成。 视频请求默认采样 8 帧（max_video_frames 接受 1–128）；load_audio_in_video 默认为 false。 本地 checkpoint 需包含 llm、vision_tower、sound_tower、两个投影器目录、tokenizer 数据和 qwen2.jinja。

Checkpoint 是受 NVIDIA OneWay Noncommercial 条款约束的外部资产；缺失权重会在运行时报告。

## 在 WorldFoundry 中运行

启动 `wf run omnivinci --pipeline.task-profile multimodal-reasoning` 跑推理路由。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `wf run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `nvidia/omnivinci`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh omnivinci`；下载缺失的公开权重时加 `--download`。
