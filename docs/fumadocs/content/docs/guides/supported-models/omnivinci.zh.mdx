OmniVinci 是英伟达的全模态理解大模型：单一模型同时对图像、视频与音频进行推理。它用于回答问题而非生成内容：任务为多模态推理、音频推理与图像/视频问答，产物是 model_response。

## 用来做什么

`omnivinci` 是多模态推理模型。

英伟达将 OmniVinci 描述为具备视觉-音频联合对齐的全模态 LLM（公开发布于 nvidia/omnivinci）。输入为 prompt 加图像或视频。该模型由英伟达（NVIDIA）发布。

任务：多模态推理、音频推理、图像问答、视频问答。别名：`nvidia/omnivinci`。

## 运行时契约

输入 `prompt`、`image`、`video`；产物 `omnivinci.json`。

CLI task profile：`multimodal-reasoning`、`audio-reasoning`、`image-question-answering`、`video-question-answering`、`video_generation`。绑定的 pipeline 类是 `OmniVinciPipeline`。

系列状态：**Runner 一致性待确认**。

适合用来审视生成模型产出的视频，例如就物理合理性或事件顺序提问。

## 在 WorldFoundry 中运行

用 `wf run omnivinci --pipeline.task-profile multimodal-reasoning` 运行模型。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`nvidia/omnivinci`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh omnivinci`；下载缺失的公开权重时加 `--download`。
