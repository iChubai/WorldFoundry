Open Dreamer is an open reimplementation of the Dreamer 4 interactive world model (paper arXiv 2509.24527): a diffusion world model that plays Minecraft-style scenes forward from a context clip and VPT-format actions. In this catalog the JAX source is never vendored — upstream publishes an all-rights-reserved notice — so WorldFoundry drives a user-staged checkout as a subprocess.

## Architecture

The WorldFoundry adapter is authored glue only: it resolves the staged checkout, gates on staging requirements, and builds the official inference.py command. WorldFoundry interaction tokens are rendered into Minecraft/VPT action JSONL so the shared world-model call surface drives the Dreamer 4 action space.

## Usage notes

Stage the official checkout (at WORLDFOUNDRY_MODEL_SOURCE_DIR/open-dreamer-inference or $WORLDFOUNDRY_OPEN_DREAMER_SOURCE) with its own CUDA-12 JAX environment. Upstream has not released weights — train the Orbax checkpoint yourself or pass checkpoint_path. Context clips must be RGB 368x640 (or 360x640, zero-padded).
