Open Dreamer is an open reimplementation of the Dreamer 4 interactive world model (paper arXiv 2509.24527): a diffusion world model that plays Minecraft-style scenes forward from a context clip and VPT-format actions. Upstream publishes an all-rights-reserved notice, so WorldFoundry does not bundle the JAX source; it runs your own checkout of the official code as a subprocess.

## What it is for

`open-dreamer` is an action-conditioned world model: actions and a starting frame in, a rollout out.

The WorldFoundry adapter resolves the staged checkout, checks staging requirements, and builds the official inference.py command. WorldFoundry interaction tokens are rendered into Minecraft/VPT action JSONL so the shared world-model call surface drives the Dreamer 4 action space.

Tasks: interactive world model, minecraft world model, action-conditioned video, and diffusion world model. Aliases: `open_dreamer`, `opendreamer`, `dreamer-4`, and `dreamer4`.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Action-conditioned world-rollout quality).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `steps`, `seed`, `plan-only`, `timeout-seconds`, `context-frames`, `horizon`, and 3 more; artifacts `generated_world`, `generated_video`, and `open-dreamer.mp4`.

CLI task profiles: `default`. WorldFoundry binds `OpenDreamerPipeline`.

Family status: **Runner parity pending**.

Defaults for `default`: seed=0.

Stage the official checkout (at WORLDFOUNDRY_MODEL_SOURCE_DIR/open-dreamer-inference or $WORLDFOUNDRY_OPEN_DREAMER_SOURCE) with its own CUDA-12 JAX environment. Upstream has not released weights — train the Orbax checkpoint yourself or pass checkpoint_path. Context clips must be RGB 368x640 (or 360x640, zero-padded).

## Running in WorldFoundry

Run `wf run open-dreamer --pipeline.task-profile default` to roll out the world model.

No public checkpoint is listed for this model; stage the weights as described in the usage notes. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh open-dreamer`. Add `--download` to fetch missing public checkpoints.
