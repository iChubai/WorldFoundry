Open-MAGVIT2 is Tencent ARC's open reproduction of the MAGVIT-v2 lookup-free visual tokenizer, plus autoregressive generation on top of it. WorldFoundry runs its class-conditional ImageNet image generation route: 256-token generation produces a 256x256 PNG image, not video. Validated with the released checkpoint: generating ImageNet class 207 yields a semantically correct image.

## What it is for

Use `open-magvit2` for text-to-image generation.

Two parts: the lookup-free quantization (LFQ) tokenizer with a very large codebook, and an autoregressive transformer that predicts visual tokens for a requested ImageNet class. The class_id input selects the category. It is published by Tencent (ARC Lab).

Tasks: video tokenization, class conditional image generation, and autoregressive generation. Aliases: `open_magvit2` and `openmagvit2`.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `steps`, `class-id`, and `batch-size`; artifacts `open_magvit2.png`.

CLI task profiles: `interactive-video`. WorldFoundry binds `OpenMAGVIT2Pipeline`.

Family status: **Verified**.

Stage the TencentARC/Open-MAGVIT2 weights (apache-2.0) and set class_id to choose the ImageNet category. This route is class-conditional image generation, not prompt-to-video; video tokenization is an upstream tokenizer capability.

The runnable route generates class-conditional images only — no free-form prompts, no video output.

Configuration `class_path` and `target` entries from the released `src.Open_MAGVIT2` namespace resolve to the installed in-tree classes at model load time. Checkpoint paths and sampling parameters keep their configured values.

## Running in WorldFoundry

Run `wf run open-magvit2 --pipeline.task-profile interactive-video` to write the image.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 11.3).

Weights: `TencentARC/Open-MAGVIT2`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh open-magvit2`. Add `--download` to fetch missing public checkpoints.
