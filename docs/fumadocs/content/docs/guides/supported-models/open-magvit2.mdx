**Publisher:** Tencent (ARC Lab) · Company

Open-MAGVIT2 is Tencent ARC's open reproduction of the MAGVIT-v2 lookup-free visual tokenizer, plus autoregressive generation on top of it. In this catalog the runnable route is class-conditional ImageNet image generation — full 256-token generation passed checkpoint-backed GPU and semantic visual QA (verified at 256x256, ImageNet class 207). The artifact is a generated PNG image, not video.

## Architecture

Two parts recorded in-tree: the lookup-free quantization (LFQ) tokenizer with a very large codebook, and an autoregressive transformer that predicts visual tokens for a requested ImageNet class. The class_id input selects the category; generation runs the vendored CUDA wrapper.

## Usage notes

Runner status is checkpoint_backed_verified — this route actually ran on GPU with the TencentARC/Open-MAGVIT2 weights (apache-2.0). Keep expectations scoped: it is class-conditional image generation, not prompt-to-video; video tokenization is what the tokenizer supports upstream.
