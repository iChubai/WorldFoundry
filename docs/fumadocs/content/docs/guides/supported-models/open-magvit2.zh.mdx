Open-MAGVIT2 是腾讯 ARC 对 MAGVIT-v2 免查表（lookup-free）视觉分词器的开源复现，并在其上构建自回归生成。WorldFoundry 运行其 ImageNet 类条件图像生成路径：256 token 生成产出 256x256 的 PNG 图像，而非视频。已用发布的 checkpoint 验证：生成 ImageNet 类别 207 得到语义正确的图像。

## 用来做什么

用 `open-magvit2` 做文生图。

包含两部分：带超大码本的免查表量化（LFQ）分词器，以及为指定 ImageNet 类别预测视觉 token 的自回归 Transformer。class_id 输入选择类别。该模型由腾讯（ARC Lab）发布。

任务：视频分词、class-conditional-image-generation、autoregressive-generation。别名：`open_magvit2`、`openmagvit2`。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `steps`、`class-id`、`batch-size`；产物 `open_magvit2.png`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `OpenMAGVIT2Pipeline`。

系列状态：**已验证**。

请就位 TencentARC/Open-MAGVIT2 权重（apache-2.0），并用 class_id 选择 ImageNet 类别。该路径是类条件图像生成，不是提示词生成视频；视频分词是其分词器在上游支持的能力。

可运行路径仅支持类条件图像生成——没有自由提示词，也没有视频输出。

加载模型时，已发布配置中 `src.Open_MAGVIT2` 命名空间下的 `class_path` 和 `target` 会解析到已安装的树内类。权重路径与采样参数保持配置值。

## 在 WorldFoundry 中运行

运行 `wf run open-magvit2 --pipeline.task-profile interactive-video` 写出图像。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 11.3）。

权重仓库：`TencentARC/Open-MAGVIT2`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh open-magvit2`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
