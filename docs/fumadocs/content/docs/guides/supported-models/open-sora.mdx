Open-Sora is HPC-AI Tech's open text-to-video stack. WorldFoundry runs the **v1.2 STDiT-v3** inference route through the official CLI — prompt in, `open-sora.mp4` out. It is not [Open-Sora-Plan](/docs/guides/supported-models/open-sora-plan).

<ModelPaperFigures modelId="open-sora" locale="en" />

The linked paper, [Open-Sora 2.0: Training a Commercial-Level Video Generation Model in $200k](https://arxiv.org/abs/2503.09642), is a later report. The checkpoints WorldFoundry runs are **Open-Sora v1.2**: `hpcai-tech/OpenSora-STDiT-v3` plus `hpcai-tech/OpenSora-VAE-v1.2`. Project page: [hpcaitech.github.io/Open-Sora](https://hpcaitech.github.io/Open-Sora/). Code: [hpcaitech/Open-Sora](https://github.com/hpcaitech/Open-Sora).

## What it is for

Text-to-video only. `OpenSoraPipeline` takes a required `prompt` and writes `open-sora.mp4`. There is **no local I2V or V2V** (upstream 1.3 / 2.0 lines advertise those; WorldFoundry does not run them). Forgetting the video VAE is the usual failure. Compare clip quality on [VBench](/docs/evaluation/benchmark-hub/vbench), the suite Open-Sora releases usually cite.

## Inference

The official-CLI wrapper overrides the vendored `sample.py` onto the Hugging Face demo quality preset:

| Knob | WorldFoundry launch | Vendored `sample.py` before override |
| --- | --- | --- |
| Resolution | **480p** | 240p |
| Aspect | **9:16** | 9:16 |
| Frames | **51** (~2 s) | 51 |
| FPS / save FPS | **24** | 24 |
| Sampler | **rectified flow** (`rflow`, timestep transform on) | same |
| Steps | **30** | 30 |
| Guidance | **7.0** (`--cfg-scale`) | 7.0 |
| Aesthetic | **6.5** (`--aes`); no forced motion score | 6.5, `flow=None` |
| Seed | **1024** | 42 |

Flash-attn and layernorm kernels are forced **off** on the launch command. No VRAM requirement is recorded. An older `hpcai-tech/OpenSora-STDiT-v1-HQ-16x512x512` repo is also listed; the default path is STDiT-v3.

## Running in WorldFoundry

`wf run open-sora` in `worldfoundry-unified-cu121` (Python 3.11, CUDA 12.1). Stage three Apache-2.0 public repos before launch:

- `hpcai-tech/OpenSora-STDiT-v3` (`config.json` + `model.safetensors`)
- `hpcai-tech/OpenSora-VAE-v1.2` (same pair)
- `DeepFloyd/t5-v1_1-xxl` (index + two `.bin` shards + `spiece.model`)
