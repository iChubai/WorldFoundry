## Architecture

Open-Sora uses a spatial-temporal diffusion transformer (its STDiT design) over a video VAE latent space, per the upstream project. This repository records the prompt-only input contract and the two-repo (model + VAE) checkpoint layout; version-specific internals are not recorded here.

## Usage notes

No runner-parity record exists yet. Stage both the model and VAE repositories before running — forgetting the VAE is the most common failure. Best used as a reproducible research baseline rather than a production generator.
