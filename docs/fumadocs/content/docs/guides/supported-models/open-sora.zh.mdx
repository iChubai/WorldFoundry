Open-Sora 是潞晨科技（HPC-AI Tech）的开源文生视频栈。WorldFoundry 通过官方 CLI 运行 **v1.2 STDiT-v3** 推理路径：输入 prompt，写出 `open-sora.mp4`。它不是 [Open-Sora-Plan](/zh/docs/guides/supported-models/open-sora-plan)。

<ModelPaperFigures modelId="open-sora" locale="zh" />

链接的论文 [Open-Sora 2.0: Training a Commercial-Level Video Generation Model in $200k](https://arxiv.org/abs/2503.09642) 是后续报告。WorldFoundry 运行的 checkpoint 是 **Open-Sora v1.2**：`hpcai-tech/OpenSora-STDiT-v3` 加 `hpcai-tech/OpenSora-VAE-v1.2`。项目页：[hpcaitech.github.io/Open-Sora](https://hpcaitech.github.io/Open-Sora/)。代码：[hpcaitech/Open-Sora](https://github.com/hpcaitech/Open-Sora)。

## 用来做什么

仅支持文生视频。`OpenSoraPipeline` 必填 `prompt`，写出 `open-sora.mp4`。**没有本地图生视频或视频到视频**（上游 1.3 / 2.0 系列曾宣传这些能力，WorldFoundry 不运行它们）。缺少视频 VAE 是最常见的失败原因。画质可使用 [VBench](/zh/docs/evaluation/benchmark-hub/vbench) 进行对比，这是 Open-Sora 发布时通常引用的评测套件。

## 推理

官方 CLI 封装会把 vendored 的 `sample.py` 覆盖成 Hugging Face demo 的质量预设：

| 参数 | WorldFoundry 启动 | 覆盖前的 `sample.py` |
| --- | --- | --- |
| 分辨率 | **480p** | 240p |
| 宽高比 | **9:16** | 9:16 |
| 帧数 | **51**（约 2 秒） | 51 |
| FPS / 保存 FPS | **24** | 24 |
| 采样器 | **rectified flow**（`rflow`，开启 timestep transform） | 相同 |
| 步数 | **30** | 30 |
| Guidance | **7.0**（`--cfg-scale`） | 7.0 |
| 美学分 | **6.5**（`--aes`）；不强制 motion score | 6.5，`flow=None` |
| Seed | **1024** | 42 |

启动命令会强制关闭 flash-attn 与 layernorm kernel。未记录显存需求。另列有较旧的 `hpcai-tech/OpenSora-STDiT-v1-HQ-16x512x512`；默认路径是 STDiT-v3。

## 在 WorldFoundry 中运行

在 `worldfoundry-unified-cu121`（Python 3.11，CUDA 12.1）中运行 `wf run open-sora`。启动前准备好三个公开的 Apache-2.0 仓库：

- `hpcai-tech/OpenSora-STDiT-v3`（`config.json` + `model.safetensors`）
- `hpcai-tech/OpenSora-VAE-v1.2`（同样一对文件）
- `DeepFloyd/t5-v1_1-xxl`（index + 两个 `.bin` 分片 + `spiece.model`）

许可证：Apache-2.0。
