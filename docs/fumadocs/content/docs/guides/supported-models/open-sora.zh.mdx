## 架构

Open-Sora 采用视频 VAE 潜空间上的时空扩散 Transformer（其 STDiT 设计），见上游项目。本仓库记录仅 prompt 的输入契约与「模型 + VAE」双仓库 checkpoint 布局；具体版本的内部细节仓库未记录。

## 使用要点

尚无 runner parity 记录。运行前请同时就位模型与 VAE 两个仓库——漏掉 VAE 是最常见的失败原因。它更适合作为可复现研究基线，而非生产级生成器。
