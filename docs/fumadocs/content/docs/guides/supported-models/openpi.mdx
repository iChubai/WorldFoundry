OpenPI is Physical Intelligence's official open-source release of the pi-series robot policies (Apache-2.0). Validated with the released checkpoint: pi05_libero policy inference runs end to end and emits the configured action schema.

## What it is for

OpenPI is the shared runtime for variants `pi0-base`, `pi05-libero`, `pi0-fast-base`, `pi0-fast-droid`. Use the π0 / π0-FAST / π0.5 models for a specific algorithm. Checkpoint-backed `pi05_libero` on [LIBERO](/docs/evaluation/benchmark-hub/libero) is the validated path.

## Runtime contract

Required `image`, `instruction`, and `prompt`. `actions`: `robot_action`, `proprio`, `action_space`. Artifact: `openpi_action_trace.json`.

## Running in WorldFoundry

Dedicated `worldfoundry-openpi-cu12` (Python 3.11, CUDA 12.4 or newer). Stage `gs://openpi-assets` with gsutil. License Apache-2.0. Launch `wf run pi0-base` for the family default.
