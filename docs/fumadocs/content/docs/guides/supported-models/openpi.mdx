**Publisher:** Physical Intelligence · Company

OpenPI is Physical Intelligence's official open-source release of the pi-series robot policies (Apache-2.0). WorldFoundry flattens the inference runtime in-tree and validates it end to end: py_compile, import/from_pretrained, plan-only predict, and checkpoint-backed pi05_libero policy inference all passed, emitting the configured action schema.

## Architecture

The runtime is the shared infrastructure for the pi0 / pi0-FAST / pi0.5 family: PaliGemma-based VLA backbones with flow-matching or FAST-token action decoding. The local pi05_libero route uses backend worldfoundry.openpi.in_tree_runtime.create_trained_policy_infer.

## Usage notes

Checkpoints come from GCS (gs://openpi-assets), not Hugging Face — use gsutil or gcloud to stage. For specific model generations use the dedicated pi0, pi0-fast, and pi05 catalog entries.
