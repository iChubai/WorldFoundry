OpenPI 是 Physical Intelligence 官方开源的 pi 系列机器人策略（Apache-2.0）。已用发布的 checkpoint 验证：pi05_libero 策略推理可端到端运行，并输出配置的动作 schema。

## 用来做什么

OpenPI 是共享运行时，variant 包括 `pi0-base`、`pi05-libero`、`pi0-fast-base`、`pi0-fast-droid`。具体算法请使用 π0 / π0-FAST / π0.5 模型。已验证路径是 [LIBERO](/zh/docs/evaluation/benchmark-hub/libero) 上带 checkpoint 的 `pi05_libero`。

## 运行时契约

必填 `image`、`instruction`、`prompt`。`actions`：`robot_action`、`proprio`、`action_space`。产物：`openpi_action_trace.json`。

## 在 WorldFoundry 中运行

独立环境 `worldfoundry-openpi-cu12`（Python 3.11，CUDA 12.4 或更新）。用 gsutil 就位 `gs://openpi-assets`。License Apache-2.0。家族默认启动 `wf run pi0-base`。
