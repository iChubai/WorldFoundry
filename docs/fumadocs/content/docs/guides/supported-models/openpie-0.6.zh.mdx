## 用来做什么

需要 catalog 上的 VLA 策略时选 `openpie-0.6`：指令与观测进、动作轨迹出。用来滚动已记录策略，不是用来训练新策略。

运行时契约为 exla-ai/fla 仓库的 FLA 策略工厂（锁定 head 1ac45102）。架构内部细节仓库未记录。

catalog 记录的任务包括 视觉-语言-动作（VLA）、机器人策略、策略执行。别名包括 `pi-0.6`、`openpie0.6`。

## 运行时契约

必填 `image`、`prompt`、`state`；可选 `model_id` (openpie-0.6)、`policy_family`、`action_representation`；产物 `action_trace`、`openpie-0.6_action_trace.json`。

记录的任务 profile：`vla`、`robot_policy`、`policy_rollout`。绑定的 pipeline 类是 `OpenPIE06Pipeline`。

系列状态：**Runner 一致性待确认**。

checkpoint 缺失由运行时 missing_assets 报告，不视为 catalog 阻塞；权重就位前运行输出运行时计划。

仅开放权重——可用性状态为 open_weights 而非完整开源。
