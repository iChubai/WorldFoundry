OpenVLA-OFT applies optimized fine-tuning to OpenVLA (parallel decoding, continuous action heads, and action chunking) and is released as five LIBERO checkpoints under the MIT license. Validated on an A100: all five checkpoints produce deterministic 8x7 action chunks, with 14.47 GiB peak VRAM.

<ModelPaperFigures modelId="openvla-oft" locale="en" />

The paper is [arXiv 2502.19645](https://arxiv.org/abs/2502.19645). Project page: [openvla-oft.github.io](https://openvla-oft.github.io). Code: [moojink/openvla-oft](https://github.com/moojink/openvla-oft).

Aliases include `openvla_oft` and `openvla-oft-libero`.

## What it is for

Use the OFT LIBERO specialists when you want parallel-decoded 8×7 action chunks on the OpenVLA 7B backbone; for the base model, use [OpenVLA](/docs/guides/supported-models/openvla).

Launch `wf run openvla-oft-libero-spatial`. Required: `image`, `prompt`, `state`. Artifacts: `action_trace` and `openvla-oft_action_trace.json`. Swap in `openvla-oft-libero-object`, `-goal`, `-10`, or the combined `openvla-oft-libero-spatial-object-goal-10` for the other splits.

Related suite: [LIBERO](/docs/evaluation/benchmark-hub/libero).

## Runtime contract

Required: `image`, `prompt`, `state`. Cameras: `full_image` and `wrist_image`. Proprio is 8-D; action chunk is **8×7**. Official demo observation: `experiments/robot/libero/sample_libero_spatial_observation.pkl`. All five LIBERO checkpoints are validated on an A100. Upstream memory hint is about **16 GB** for LIBERO.

## Running in WorldFoundry

Dedicated environment `worldfoundry-vla-openvla-compat-cu121` (Python 3.10, CUDA 12.1). Stage the matching `moojink/openvla-7b-oft-finetuned-libero-*` snapshot. Launch `wf run openvla-oft-libero-spatial`. License: MIT.
