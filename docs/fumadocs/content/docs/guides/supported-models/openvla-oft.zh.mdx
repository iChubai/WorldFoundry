OpenVLA-OFT 对 OpenVLA 施加优化微调——并行解码、连续动作头与动作分块——并在本 catalog 中完成 GPU 验证：A100 恢复全部 75.4 亿参数，对多组输入产出确定性的有限 8x7 动作块，峰值显存 14.47 GiB，五个声明的 LIBERO checkpoint 全部完成真实推理（MIT 许可）。

## 架构

OFT 配方在 7B OpenVLA 骨干上以并行解码替换自回归 token 解码，加 L1 连续动作头与 8 步分块，本体感知与噪声动作投影器内置树内。注意力按硬件解析：Ampere/Ada/Hopper 用 FlashAttention 2，其他架构（含 Blackwell）回退 PyTorch SDPA。

## 使用要点

按评测子集选择 LIBERO checkpoint（spatial、object、goal 等）；直接支持官方 LIBERO 观测输入。训练、RLDS 处理、TensorFlow 工具与 LIBERO 基准循环被排除。
