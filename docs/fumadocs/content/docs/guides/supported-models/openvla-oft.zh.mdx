OpenVLA-OFT 通过优化微调改进 OpenVLA（并行解码、连续动作头与动作分块），以五个 LIBERO checkpoint 发布，MIT 许可。已在 A100 上验证：五个 checkpoint 均输出确定性的 8x7 动作块，峰值显存 14.47 GiB。

论文是 [arXiv 2502.19645](https://arxiv.org/abs/2502.19645)。项目页：[openvla-oft.github.io](https://openvla-oft.github.io)。代码：[moojink/openvla-oft](https://github.com/moojink/openvla-oft)。

别名：`openvla_oft`、`openvla-oft-libero`。

## 用来做什么

需要在 OpenVLA 7B 骨干上通过并行解码生成 8×7 动作块时，使用 OFT 的 LIBERO 专家模型；基座模型请用 [OpenVLA](/zh/docs/guides/supported-models/openvla)。

启动 `wf run openvla-oft-libero-spatial`。必填：`image`、`prompt`、`state`。产物：`action_trace`、`openvla-oft_action_trace.json`。其他 split 换成 `openvla-oft-libero-object`、`-goal`、`-10` 或组合版 `openvla-oft-libero-spatial-object-goal-10`。

相关套件：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)。

## 运行时契约

必填：`image`、`prompt`、`state`。相机：`full_image`、`wrist_image`。本体感觉 8 维；动作块 **8×7**。官方 demo 观测：`experiments/robot/libero/sample_libero_spatial_observation.pkl`。五个 LIBERO checkpoint 均已在 A100 上验证。上游 LIBERO 显存提示约 **16 GB**。

## 在 WorldFoundry 中运行

独立环境 `worldfoundry-vla-openvla-compat-cu121`（Python 3.10，CUDA 12.1）。准备对应的 `moojink/openvla-7b-oft-finetuned-libero-*` 权重。启动 `wf run openvla-oft-libero-spatial`。许可：MIT。
