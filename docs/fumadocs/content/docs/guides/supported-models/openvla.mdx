OpenVLA is a 7B vision-language-action policy: a Prismatic VLM that turns one RGB frame and a language instruction into discretized action tokens, then de-tokenizes them into continuous **7-DoF** controls. The official paper is [OpenVLA: An Open-Source Vision-Language-Action Model](https://arxiv.org/abs/2406.09246) (arXiv 2406.09246). The project page is [openvla.github.io](https://openvla.github.io/). The GitHub tree is [openvla/openvla](https://github.com/openvla/openvla). Weights are **MIT**.

<ModelPaperFigures modelId="openvla" locale="en" />

WorldFoundry ships the Hugging Face Prismatic model code (`configuration_prismatic.py`, `modeling_prismatic.py`, `processing_prismatic.py`) in-tree, so inference does not depend on remote code. Two variants: `openvla-7b` and `openvla-libero-10`. The base route is **validated** on `openvla-7b` with `unnorm_key=bridge_orig`. The LIBERO-10 fine-tune runs on the same pipeline but has not been validated separately.

## What it is for

Start on `openvla-7b`. Required inputs are `image`, `instruction`, and `prompt`. `OpenVLAPipeline` writes `openvla_action_trace.json` (also `actions` / `rollout_metrics`). Default unnorm key is `bridge_orig` — that is the verified Bridge-style route. The matching evaluation page is [BridgeData V2](/docs/evaluation/benchmark-hub/bridgedata-v2).

Switch to `openvla-libero-10` and `unnorm_key=libero_10` only when the target suite is [LIBERO](/docs/evaluation/benchmark-hub/libero). For the faster continuous / chunked OpenVLA line, use [OpenVLA-OFT](/docs/guides/supported-models/openvla-oft).

## Runtime contract

Default vision backbone is **SigLIP 224px** fused with DINOv2; language side is Llama-2 7B. Action tokens use **256 bins** on \([-1, 1]\), then dataset-specific de-normalization into 7-DoF. Inference runs in **fp16**. `video` is optional and unused.

## Running in WorldFoundry

Unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage both Hugging Face trees locally, then:

```
wf run openvla-7b
```

`unnorm_key` must match the checkpoint’s data contract. Both checkpoints are **MIT**-licensed.
