OpenVLA is the widely used open 7B vision-language-action model (MIT license): a Prismatic-based VLM fine-tuned on Open X-Embodiment robot demonstrations to predict discretized actions. Both openvla-7b and the LIBERO-10 fine-tune are confirmed with pinned revisions, and the in-tree WorldFoundry runner is verified on the base route with unnorm_key=bridge_orig.

## Architecture

A 7B Prismatic VLM (fused SigLIP/DINOv2 vision, Llama-2 language) that emits action tokens de-tokenized into continuous 7-DoF actions using dataset-specific normalization keys.

## Usage notes

Set unnorm_key to match your data distribution (bridge_orig is the verified default). Use the LIBERO-10 fine-tune for LIBERO evaluation, and openvla-oft for the faster fine-tuned line.
