**Publisher:** Physical Intelligence · Company

pi0-FAST is the autoregressive variant of pi0: instead of flow matching it uses the FAST action tokenizer to decode actions as discrete tokens, trading some smoothness for faster, simpler decoding. WorldFoundry reuses the in-tree OpenPI runtime with the pi0_fast_droid configuration and pi0-FAST checkpoint resolution.

## Architecture

The same PaliGemma backbone as pi0 but with FAST (frequency-space action sequence tokenization) discrete action decoding. FAST decoding is integrated as algorithm-specific runtime behavior, not as a LeRobot policy-zoo variant.

## Usage notes

The default configuration targets DROID (pi0_fast_droid). Stage GCS checkpoints with gsutil/gcloud; runs emit a runtime plan until assets are staged.
