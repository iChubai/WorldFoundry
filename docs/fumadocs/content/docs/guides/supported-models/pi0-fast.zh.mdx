**发表机构:** Physical Intelligence（PI） · 企业

pi0-FAST 是 pi0 的自回归变体：不用 flow matching，而以 FAST 动作 tokenizer 将动作解码为离散 token，以少量平滑性换取更快更简单的解码。WorldFoundry 复用树内 OpenPI 运行时，采用 pi0_fast_droid 配置与 pi0-FAST checkpoint 解析。

## 架构

与 pi0 相同的 PaliGemma 骨干，但采用 FAST（频域动作序列 token 化）离散动作解码。 FAST 解码作为算法专属运行时行为集成，而非 LeRobot 策略库变体。

## 使用要点

默认配置面向 DROID（pi0_fast_droid）。用 gsutil/gcloud 就位 GCS checkpoint；资产就位前运行输出运行时计划。
