pi0 is Physical Intelligence's flagship flow-matching VLA: a PaliGemma-based backbone with an action expert that decodes continuous action chunks via flow matching. This catalog entry is the concrete pi0 algorithm route, reusing the flattened in-tree OpenPI runtime with pi0-specific configuration.

## Architecture

A PaliGemma VLM backbone plus a flow-matching action expert producing action chunks; the model graph, transforms, local checkpoint loader, and action sampler are in-tree. Checkpoints are GCS-hosted (gs://openpi-assets).

## Usage notes

Stage GCS checkpoints with gsutil/gcloud (not Hugging Face). Numerical parity remains gated only by staged checkpoint assets; the shared runtime infrastructure is validated under the openpi entry.
