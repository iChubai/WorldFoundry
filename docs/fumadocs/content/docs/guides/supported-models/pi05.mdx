pi0.5 is Physical Intelligence's open-world generalization upgrade of pi0: same flow-matching VLA at run time (PaliGemma plus an action expert), with `pi05_libero` as the in-tree validated `get_action` path. This catalog entry is the concrete pi0.5 algorithm route, reusing the in-tree OpenPI runtime with pi05-specific configuration and checkpoint selection.

## What it is for

Start on `pi05` for flow-matching decode on the open-world checkpoint. Launch `worldfoundry-eval run pi05 --pipeline.task-profile vla`. The validated in-tree reference is `pi05_libero` on [LIBERO](/docs/evaluation/benchmark-hub/libero). Do not route this through LeRobot policy-zoo.

## Runtime contract

Required `image`, `instruction`, and `prompt`. `actions`: `robot_action`, `proprio`, `action_space`. Artifact: `pi05_action_trace.json`. Keep the official OpenPI runtime with the pi05-specific config.

## Running in WorldFoundry

Dedicated `worldfoundry-openpi-cu12` (Python 3.11, CUDA 12.4 or newer). Stage `gs://openpi-assets` with gsutil. License is on the [OpenPI](/docs/guides/supported-models/openpi) card (Apache-2.0). Status: **Verified** on the `pi05_libero` path.

`pi05_libero` is the validated `get_action` reference. Import official LIBERO results with `worldfoundry-eval zoo benchmark-run --benchmark-id libero --mode official-validation` and read `success_rate`. Suite import is normalizer-only — not a leaderboard. Full cell: [Model → benchmark recipes](/docs/evaluation/model-benchmark-recipes).
