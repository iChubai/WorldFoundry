pi0.5 is Physical Intelligence's open-world generalization upgrade of pi0: a PaliGemma-based VLA with a flow-matching action expert. WorldFoundry runs it through the official OpenPI runtime with the official `pi05_libero` checkpoint.

## What it is for

Launch `wf run pi05` with a staged `pi05_libero` checkpoint. Validated on a GPU: the pipeline produces 10×7 action chunks from synthetic dual-camera images and the checkpoint-mean state; success on [LIBERO](/docs/evaluation/benchmark-hub/libero) tasks is not measured. Run it through the official OpenPI runtime, not the LeRobot policy zoo.

## Runtime contract

Required `image`, `instruction`, and `prompt`. `actions`: `robot_action`, `proprio`, `action_space`. Artifact: `pi05_action_trace.json`. Keep the official OpenPI runtime with the pi05-specific config.

## Running in WorldFoundry

Use an OpenPI environment with JAX GPU support and the package dependencies in `requirements/worldfoundry-unified.txt`. Stage `gs://openpi-assets` with gsutil or pass an explicit checkpoint path. The license follows [OpenPI](/docs/guides/supported-models/openpi) (Apache-2.0). Task performance and the `pi05_base`/`pi05_droid` checkpoints are not validated.

Import official LIBERO results with `wf zoo benchmark-run --benchmark-id libero --mode official-validation` and read `success_rate`; the import only normalizes published results and is not a leaderboard.
