pi0.5 是 Physical Intelligence 为提升 pi0 的开放世界泛化能力而推出的升级版本：基于 PaliGemma 的 VLA 与 flow-matching 动作专家。WorldFoundry 通过官方 OpenPI 运行时，使用官方 `pi05_libero` 权重运行它。

## 用来做什么

准备好 `pi05_libero` 权重后运行 `wf run pi05`。已在 GPU 上验证：pipeline 使用合成双相机图像及权重均值状态生成 10×7 动作块；[LIBERO](/zh/docs/evaluation/benchmark-hub/libero) 任务成功率尚未测量。请通过官方 OpenPI 运行时运行，不要使用 LeRobot policy-zoo。

## 运行时契约

必填 `image`、`instruction`、`prompt`。`actions`：`robot_action`、`proprio`、`action_space`。产物：`pi05_action_trace.json`。使用官方 OpenPI 运行时与 pi05 专用配置。

## 在 WorldFoundry 中运行

使用支持 JAX GPU 和 `requirements/worldfoundry-unified.txt` 所列依赖的 OpenPI 环境。使用 gsutil 准备 `gs://openpi-assets`，或显式传入权重路径。许可证随 [OpenPI](/zh/docs/guides/supported-models/openpi)（Apache-2.0）。任务表现及 `pi05_base`/`pi05_droid` 权重尚未验证。

用 `wf zoo benchmark-run --benchmark-id libero --mode official-validation` 导入官方 LIBERO 结果，读取 `success_rate`；导入仅对已发布结果进行归一化，并非 leaderboard。
