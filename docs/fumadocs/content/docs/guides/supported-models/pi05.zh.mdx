pi0.5 是 Physical Intelligence 对 pi0 的开放世界泛化升级：运行时仍是同一套 flow-matching VLA（PaliGemma 加动作专家），树内已验证的 `get_action` 路径是 `pi05_libero`。本 catalog 条目是具体的 pi0.5 算法路由，复用树内 OpenPI 运行时与 pi05 专用配置及 checkpoint 选择。

## 用来做什么

从 `pi05` 开始，用开放世界 checkpoint 跑 flow-matching 解码。启动 `worldfoundry-eval run pi05 --pipeline.task-profile vla`。树内已验证参考是 [LIBERO](/zh/docs/evaluation/benchmark-hub/libero) 上的 `pi05_libero`。不要走 LeRobot policy-zoo。

## 运行时契约

必填 `image`、`instruction`、`prompt`。`actions`：`robot_action`、`proprio`、`action_space`。产物：`pi05_action_trace.json`。使用官方 OpenPI 运行时与 pi05 专用配置。

## 在 WorldFoundry 中运行

独立环境 `worldfoundry-openpi-cu12`（Python 3.11，CUDA 12.4 或更新）。用 gsutil 就位 `gs://openpi-assets`。许可证见 [OpenPI](/zh/docs/guides/supported-models/openpi)（Apache-2.0）。状态：`pi05_libero` 路径 **已验证**。

`pi05_libero` 是已验证的 `get_action` 参照。用 `worldfoundry-eval zoo benchmark-run --benchmark-id libero --mode official-validation` 导入官方结果，读 `success_rate`。套件导入仅 normalizer——不是 leaderboard。完整单元格：[模型 → 评测配方](/zh/docs/evaluation/model-benchmark-recipes)。
