Pi3 (π³) is a feed-forward visual-geometry model that reconstructs 3D scenes, camera trajectories, and point clouds without relying on a fixed reference view — its permutation-equivariant design treats all input views symmetrically. WorldFoundry runs an in-tree point-cloud navigation pipeline for reconstruction and trajectory rendering.

## What it is for

Use `pi3` for feed-forward 3D reconstruction from the input views.

Per the paper (arXiv 2507.13347), Pi3 predicts affine-invariant camera poses and scale-invariant local pointmaps with a permutation-equivariant transformer, removing the need for a reference-view heuristic. Weights are apache-2.0.

Tasks: 3D reconstruction, trajectory, and point cloud. Output modalities: point cloud.
