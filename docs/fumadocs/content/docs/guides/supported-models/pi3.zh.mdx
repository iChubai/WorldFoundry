Pi3（π³）是前馈式视觉几何模型，重建 3D 场景、相机轨迹与点云，且不依赖固定参考视图——其置换等变设计对所有输入视图一视同仁。WorldFoundry 在树内运行点云导航 pipeline，用于重建与轨迹渲染。

## 用来做什么

用 `pi3` 从输入视图做前馈 3D 重建。

按论文（arXiv 2507.13347），Pi3 用置换等变 Transformer 预测仿射不变的相机位姿与尺度不变的局部点图，摆脱了参考视图启发式。权重为 apache-2.0。

任务：3D 重建、轨迹、点云。输出模态为点云。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `interval`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `Pi3Pipeline`。

系列状态：**Runner 一致性待确认**。

运行重建前请先就位上游 Pi3 权重（`yyfz233/Pi3X`）。
