## What it is for

`pika-h3-flex` covers text-to-video and image-to-video: a prompt and an optional still image in, a clip out. It is published by Pika Labs.

Tasks: text-to-video, image-to-video, reference-to-video, and audio video generation. Aliases: `pika-h3`, `pika-h3-flex-fl2va`, and `pika-h3-flex-ref2va`. Modalities: text and image in, video and audio out.

## Runtime contract

Input `prompt` (bundled samples are used when omitted); options `num-frames`, `short-edge`, `aspect-ratio`, and `seed`; artifact `pika-h3-flex.mp4`.

CLI task profiles: `t2va`, `i2va`, `l2va`, `fl2va`, and `ref2va`. WorldFoundry binds `PikaH3FlexPipeline`. Family status: **Runner parity pending**. Defaults for `t2va`, `i2va`, and `l2va`: num-frames=124, seed=0.

Stage the Pika H3 Flex fl2va or ref2va adapter together with the pinned MiniMax-H3 base snapshot. Use adapter_task=ref2va for reference generation.

Native output is 24 fps with 32 kHz stereo audio and six generator evaluations. Reference generation accepts image references only; video and standalone-audio references are not supported. Multi-GPU execution, the full 480p/768p bucket set, and checkpoint-backed outputs are not validated.

Use the `fl2va` adapter for text and endpoint-frame generation, and the `ref2va` adapter for image references. Outputs use 24 FPS video with synchronized 32 kHz stereo audio.

## Running in WorldFoundry

Run `wf run pika-h3-flex --pipeline.task-profile t2va` to generate the video. Switch tasks in the command builder above to change `--pipeline.task-profile`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Pika-Labs/Pika-H3-Flex` and `MiniMaxAI/MiniMax-H3`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh pika-h3-flex`. Add `--download` to fetch missing public checkpoints.
