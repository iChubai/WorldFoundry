Pika H3 Flex is a six-step MiniMax-H3 adapter for joint video and stereo audio generation. The WorldFoundry route reuses the canonical MiniMax-H3 transformer, Qwen3-VL conditioner, geometry, codecs and media writer.

Code: [Pika-Labs/Pika-H3-Flex](https://github.com/Pika-Labs/Pika-H3-Flex).

## Runtime contract

Use the `fl2va` adapter for text and endpoint-frame generation, and the `ref2va` adapter for image references. Outputs use 24 FPS video with synchronized 32 kHz stereo audio.

The adapter is loaded with `adapter_task=fl2va` or `adapter_task=ref2va`:

```bash
wf run pika-h3-flex --pipeline.task-profile t2va --json
```

Prepare the pinned MiniMax-H3 base snapshot and the Pika adapter files before running. Model assets remain outside Git.

## Validation status

The in-tree loader, fused-QKV/SwiGLU LoRA conversion, six-knot re-noising schedule and public pipeline route are implemented. Full checkpoint-backed artifact parity, video/audio references, multi-GPU execution and the complete 480p/768p bucket matrix remain pending GPU validation.
