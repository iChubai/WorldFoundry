## What it is for

Use `pixelsplat` for catalog geometry inference. Choose it when the artifact is a reconstruction, not a generated video.

Per the publication, an epipolar transformer resolves scale ambiguity between the two views, and the network predicts a probabilistic distribution over Gaussian parameters. WorldFoundry vendors the source under base_models/three_dimensions/point_clouds/pixelsplat with a lazy wrapper around the official test entrypoint (MIT license; checkpoint mirror dylanebert/pixelSplat). It is published by Massachusetts Institute of Technology (MIT).

Catalog tasks include 3d-reconstruction, gaussian-splatting, and novel-view-synthesis. Catalog aliases include `pixel-splat` and `pixel_splat`.
