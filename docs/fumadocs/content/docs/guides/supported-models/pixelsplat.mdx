## What it is for

`pixelsplat` estimates scene geometry from the input views.

Per the publication, an epipolar transformer resolves scale ambiguity between the two views, and the network predicts a probabilistic distribution over Gaussian parameters. WorldFoundry wraps the official test entrypoint; the code and the dylanebert/pixelSplat checkpoint mirror are MIT-licensed. It is published by Massachusetts Institute of Technology (MIT).

Tasks: 3D reconstruction, gaussian splatting, and novel view synthesis. Aliases: `pixel-splat` and `pixel_splat`.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); artifacts `pixelsplat.ply`.

CLI task profiles: `interactive-video`. WorldFoundry binds `PixelSplatPipeline`.

Family status: **Verified**.

Provide model_path pointing to re10k.ckpt or acid.ckpt, the matching experiment, and posed dataset_roots/index_path. Install the declared runtime dependencies and local Gaussian rasterizer. Bare image lists use a synthetic baseline. PLY output exports normalized geometry and DC color with standard opacity logits.

Supports the original convolutional checkpoints; newer camera-ready architectures are not interchangeable.

## Running in WorldFoundry

Reconstruct the scene with `wf run pixelsplat --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 11.3).

Weights: `dylanebert/pixelSplat`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh pixelsplat`. Add `--download` to fetch missing public checkpoints.
