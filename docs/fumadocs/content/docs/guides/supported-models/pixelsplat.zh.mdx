## 用来做什么

`pixelsplat` 根据输入视图估计场景几何。

按论文，极线 Transformer 消解两视图间的尺度歧义，网络预测高斯参数的概率分布。WorldFoundry 封装官方测试入口；代码与 checkpoint 镜像 dylanebert/pixelSplat 均为 MIT 许可。该模型由麻省理工学院（MIT）发布。

任务：3D 重建、高斯泼溅、新视角合成。别名：`pixel-splat`、`pixel_splat`。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；产物 `pixelsplat.ply`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `PixelSplatPipeline`。

系列状态：**已验证**。

model_path 指向 re10k.ckpt 或 acid.ckpt，同时指定匹配的 experiment 与标定数据 dataset_roots/index_path。需安装已声明的运行依赖和本地高斯光栅化扩展。仅传图像列表时使用合成基线。PLY 导出归一化几何、DC 颜色和标准透明度 logit。

支持原始卷积版本权重，不能直接替换为更新的 camera-ready 网络权重。

## 在 WorldFoundry 中运行

用 `wf run pixelsplat --pipeline.task-profile interactive-video` 重建场景。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 11.3）。

权重仓库：`dylanebert/pixelSplat`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh pixelsplat`；下载缺失的公开权重时加 `--download`。
