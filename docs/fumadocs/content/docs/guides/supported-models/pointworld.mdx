PointWorld is NVIDIA's point-cloud world model for robotics: instead of predicting pixels it predicts future 3D point-cloud states under actions, giving geometry-native world modeling.

## What it is for

`pointworld` estimates scene geometry from the input views.

Predicted point-cloud states are written as a generated_3d_asset artifact. The code is Apache-2.0; checkpoints are at nvidia/PointWorld_models.

Tasks: point cloud world model, robot world model, and 3D world model. Output modalities: point cloud.

Suggested benchmarks: [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) (Embodied world-model prediction quality).

## Runtime contract

Artifacts `generated_3d_asset` and `pointworld_runtime_plan.json`.

CLI task profiles: `default`. WorldFoundry binds `PointWorldPipeline`.

Family status: **Runner parity pending**.

Stage the nvidia/PointWorld_models checkpoints and the point-cloud assets before running; until they are staged, a run returns a plan that lists the missing assets instead of generating. Inputs include point clouds alongside the usual prompt/image/video/actions.

Point-cloud outputs need downstream rendering for visual inspection.

## Running in WorldFoundry

Reconstruct the scene with `wf run pointworld --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `nvidia/PointWorld_models`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh pointworld`. Add `--download` to fetch missing public checkpoints.
