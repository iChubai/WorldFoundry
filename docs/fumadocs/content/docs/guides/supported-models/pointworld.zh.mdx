PointWorld 是英伟达面向机器人的点云世界模型：不预测像素，而是在动作条件下预测未来 3D 点云状态，实现几何原生的世界建模。

代码：[NVlabs/PointWorld](https://github.com/NVlabs/PointWorld)。

## 用来做什么

`pointworld` 根据输入视图估计场景几何。

预测的点云状态以 generated_3d_asset 产物输出。代码采用 apache-2.0 许可；checkpoint 位于 nvidia/PointWorld_models。该模型由英伟达（NVIDIA）发布。

任务：点云世界模型、机器人世界模型、3D 世界模型。输出模态为点云。

推荐评测：[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（具身世界模型预测质量）。

## 运行时契约

产物 `generated_3d_asset`、`pointworld_runtime_plan.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `PointWorldPipeline`。

系列状态：**Runner 一致性待确认**。

运行前需准备 nvidia/PointWorld_models checkpoint 与点云资产；在它们就位前，运行只会返回列出缺失资产的计划，而不会生成结果。输入除常规的提示词/图像/视频/动作外还包括点云。

点云输出需要下游渲染才能可视化检查。

## 在 WorldFoundry 中运行

用 `wf run pointworld --pipeline.task-profile default` 重建场景。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`nvidia/PointWorld_models`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh pointworld`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
