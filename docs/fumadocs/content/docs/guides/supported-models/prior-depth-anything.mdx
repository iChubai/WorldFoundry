Prior Depth Anything is a depth-completion prior: it takes any coarse or sparse metric-depth prior plus an image and refines them into a dense, sharper metric depth map. Validated with the official checkpoint: it refines a real Depth Anything 3 metric-depth condition.

## What it is for

`prior-depth-anything` is a depth estimation model.

A prompt-conditioned depth-completion design: the model consumes prompt metric depth alongside the image (checkpoint `Rain729/Prior-Depth-Anything`, apache-2.0).

Tasks: depth completion, metric depth estimation, and geometry prior. Aliases: `priorda` and `prior-depth-anything-prior`. Modalities: image in, depth out.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `execute` and `max-points`; artifacts `prior-depth-anything.npz`.

CLI task profiles: `default`. WorldFoundry binds `PriorDepthAnythingPipeline`.

Family status: **Verified**.

It runs as an independent geometry prior through the shared geometry-prior pipeline/operator contract, so higher-level pipelines such as ViPE can use it. Pair it with a metric source (e.g. depth-anything-v3-prior) whose output it refines.

Needs a metric-depth condition as input — it refines priors rather than estimating from scratch.
