Prior Depth Anything is a depth-completion prior: it takes any coarse or sparse metric-depth prior plus an image and refines them into a dense, sharper metric depth map. ## Architecture

The catalog records a prompt-conditioned depth-completion design: the model consumes prompt metric depth alongside the image (checkpoint Rain729/Prior-Depth-Anything, apache-2.0). It is registered at base_models/three_dimensions/depth/priorda and shared by higher-level geometry pipelines without being nested under them.

## Usage notes

It is integrated as an independent geometry prior under worldfoundry/base_models and exposed through the shared geometry-prior pipeline/operator contract. Higher-level pipelines (e.g. ViPE) import it from this canonical owner instead of keeping private copies. Pair it with a metric source (e.g. depth-anything-v3-prior) whose output it refines.
