Prior Depth Anything 是深度补全先验：接受任意粗糙或稀疏的米制深度先验加一张图像，将其细化为致密且更锐利的米制深度图。已用官方 checkpoint 验证：可对真实的 Depth Anything 3 米制深度条件完成细化。

## 用来做什么

`prior-depth-anything` 是深度估计模型。

提示条件的深度补全设计：模型同时消费提示米制深度与图像（checkpoint 为 `Rain729/Prior-Depth-Anything`，apache-2.0）。

任务：depth-completion、米制深度估计、几何先验。别名：`priorda`、`prior-depth-anything-prior`。模态上，它接受图像，输出深度。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `execute`、`max-points`；产物 `prior-depth-anything.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `PriorDepthAnythingPipeline`。

系列状态：**已验证**。

它作为独立几何先验，通过共享的 geometry-prior pipeline/operator 契约运行，上层管线（如 ViPE）可直接使用。请与米制深度源（如 depth-anything-v3-prior）配对使用，由它细化该源的输出。

需要米制深度条件作为输入——它细化先验而非从零估计。

## 在 WorldFoundry 中运行

运行 `wf run prior-depth-anything --pipeline.task-profile default` 写出深度图。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`Rain729/Prior-Depth-Anything`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh prior-depth-anything`；下载缺失的公开权重时加 `--download`。
