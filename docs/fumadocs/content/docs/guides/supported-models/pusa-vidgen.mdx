Pusa VidGen (Pusa V1) demonstrates vectorized timestep adaptation: instead of one shared diffusion timestep for the whole video, each frame gets its own, which unlocks image-to-video, text-to-video, and video extension from one cheap LoRA training run on Wan2.2. WorldFoundry assembles it entirely from canonical Wan2.2 components — no external runtime checkout is needed at inference time.

## What it is for

Use `pusa-vidgen` for both text-to-video and image-to-video generation.

Pusa V1 = Wan2.2 base (canonical denoisers, conditioner, VAE, loaders, shared staged runner) + the official Pusa V1 LoRA checkpoint (RaphaelLiu/Pusa-Wan2.2-V1). The vectorized-timestep behavior comes from the LoRA; no alternate diffusion backend is involved. It is published by City University of Hong Kong.

Tasks: image-to-video, text-to-video, and video extension. Aliases: `pusa-v1` and `pusa-wan2.2-v1`. Modalities: image and text in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (General T2V/I2V quality suite).

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `frames`, `height`, `width`, `steps`, `guidance-scale`, `seed`, and 5 more; artifacts `generated_video` and `pusa_vidgen_public_runner.mp4`.

CLI task profiles: `default`. WorldFoundry binds `PusaVidGenPipeline`.

Family status: **Runner parity pending**.

Defaults for `default`: frames=81, height=720, width=1280, seed=0.

Call the pipeline with execute=True to write the generated_video artifact. Stage the Wan2.2 base weights plus the Pusa LoRA before running.

The supported `runner_version` is `v1`, backed by the Pusa high- and low-noise LoRAs and Wan2.2. Requests for `v0` raise an error; both V1 LoRA files must be staged before execution.

## Running in WorldFoundry

Run `wf run pusa-vidgen --pipeline.task-profile default` to generate the video.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `RaphaelLiu/Pusa-Wan2.2-V1`, `Wan-AI/Wan2.2-T2V-A14B`, and `lightx2v/Wan2.2-Lightning`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh pusa-vidgen`. Add `--download` to fetch missing public checkpoints.
