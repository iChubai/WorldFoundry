Pusa VidGen（Pusa V1）展示了向量化时间步适配：不再让整段视频共享一个扩散时间步，而是每帧独立时间步，从而用一次低成本的 Wan2.2 LoRA 训练同时解锁图生视频、文生视频与视频延展。WorldFoundry 完全用规范化 Wan2.2 组件装配它——推理时不需要外部运行时检出。

## 用来做什么

用 `pusa-vidgen` 同时完成文生视频和图生视频。

Pusa V1 = Wan2.2 基座（规范化去噪器、条件器、VAE、加载器与共享分段 runner）+ 官方 Pusa V1 LoRA checkpoint（RaphaelLiu/Pusa-Wan2.2-V1）。向量化时间步行为来自 LoRA；不涉及其它扩散后端。该模型由香港城市大学发布。

任务：图生视频、文生视频、视频延展。别名：`pusa-v1`、`pusa-wan2.2-v1`。模态上，它接受图像、文本，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（通用文生/图生视频质量评测）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `frames`、`height`、`width`、`steps`、`guidance-scale`、`seed` 等 11 项；产物 `generated_video`、`pusa_vidgen_public_runner.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `PusaVidGenPipeline`。

系列状态：**Runner 一致性待确认**。

`default` 的默认值：frames=81, height=720, width=1280, seed=0。

以 execute=True 调用 pipeline 即可写出 generated_video 产物。运行前请同时就位 Wan2.2 基座权重与 Pusa LoRA。

支持的 `runner_version` 为 `v1`，使用 Pusa 高噪声、低噪声 LoRA 与 Wan2.2。请求 `v0` 会报错；执行前必须就位 V1 的两个 LoRA 文件。

## 在 WorldFoundry 中运行

运行 `wf run pusa-vidgen --pipeline.task-profile default` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`RaphaelLiu/Pusa-Wan2.2-V1`、`Wan-AI/Wan2.2-T2V-A14B`、`lightx2v/Wan2.2-Lightning`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh pusa-vidgen`；下载缺失的公开权重时加 `--download`。
