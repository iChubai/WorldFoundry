Qwen2.5-Omni is Alibaba's end-to-end omni-modal model: it perceives text, images, audio, and video. WorldFoundry uses it for understanding and reasoning — multimodal reasoning, audio reasoning, and image/video QA — with model_response artifacts. The supported weight is the 7B release (Qwen/Qwen2.5-Omni-7B).

Paper: [arXiv 2503.20215](https://arxiv.org/abs/2503.20215).

Code: [Qwen/Qwen2.5-Omni-7B](https://huggingface.co/Qwen/Qwen2.5-Omni-7B).

The paper describes a **Thinker-Talker** stack with **TMRoPE** (time-aligned multimodal RoPE) so audio and video share a clock. Officially the model perceives **text, images, audio, and video** and can stream **text and speech** together. Audio frames in TMRoPE are aligned at **40 ms** per temporal id. WorldFoundry only wires the **text-response** path: required `prompt`, optional `image` / `video`, artifact `qwen2.5-omni.json`. The recorded weight is the **7B** release. The Hugging Face card lists the license as `other`; review it before production use.

## What it is for

Use `qwen2.5-omni` for multimodal reasoning.

Alibaba describes Qwen2.5-Omni with a Thinker-Talker design: a reasoning core plus a speech-generation head, with TMRoPE alignment for audio-video time synchronization. WorldFoundry uses only the text-response path: prompt, image, or video in, model response out. It is published by Alibaba (Qwen).

Tasks: multimodal reasoning, audio reasoning, image question answering, and video question answering. Aliases: `qwen2p5-omni`, `qwen2p5_omni`, and `Qwen/Qwen2.5-Omni-7B`. Modalities: audio, image, and video in, text out.

Caption, interrogate, or QA stills and clips produced by other models. Recorded task profiles are `multimodal-reasoning` (default), `audio-reasoning`, `image-question-answering`, and `video-question-answering`. All four share the same input contract and write `qwen2.5-omni.json` through `Qwen25OmniPipeline`.

## Runtime contract

Inputs `prompt`, `image`, and `video`; artifact `qwen2.5-omni.json`.

CLI task profiles: `multimodal-reasoning`, `audio-reasoning`, `image-question-answering`, `video-question-answering`, and `video_generation`. WorldFoundry binds `Qwen25OmniPipeline`. Family status: **Runner parity pending**.

Use it to caption, interrogate, or QA videos generated by other models. The 7B scale runs on a single modern GPU.

Only the text-response path is supported: there is no `audio` input and no Talker / streaming-speech output. Responses have not yet been validated on GPU with the released checkpoint.

Backend is the official Hugging Face Transformers runtime. Loading is `from_pretrained`. Talker / streaming-speech decode is not supported.

## Running in WorldFoundry

Run the model with `wf run qwen2.5-omni --pipeline.task-profile multimodal-reasoning`. Switch tasks in the command builder above to change `--pipeline.task-profile`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Qwen/Qwen2.5-Omni-7B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh qwen2.5-omni`. Add `--download` to fetch missing public checkpoints.
