Qwen2.5-Omni 是阿里通义千问的端到端全模态模型。官方论文是 [Qwen2.5-Omni Technical Report](https://arxiv.org/abs/2503.20215)（arXiv 2503.20215）。代码与模型卡见 [QwenLM/Qwen2.5-Omni](https://github.com/QwenLM/Qwen2.5-Omni) 与 [Qwen/Qwen2.5-Omni-7B](https://huggingface.co/Qwen/Qwen2.5-Omni-7B)。WorldFoundry 把它用作**理解 / 推理**模型——不是视频生成器——产物为 `model_response`。别名 `qwen2p5-omni`、`qwen2p5_omni`、`Qwen/Qwen2.5-Omni-7B` 解析到本页。

<ModelPaperFigures modelId="qwen2.5-omni" locale="zh" />

该模型采用论文描述的 **Thinker-Talker** 栈，并用 **TMRoPE**（时间对齐的多模态 RoPE）让音频与视频共用同一时钟。官方能力是感知**文本、图像、音频、视频**，并可同时流式输出**文本与语音**。在 TMRoPE 中，音频帧按每 **40 ms** 一个 temporal id 对齐。WorldFoundry 仅接入**文本响应**路径：必填 `prompt`，可选 `image` / `video`，产物 `qwen2.5-omni.json`。记录的权重是 **7B** 版本。Hugging Face 卡片的许可证为 `other`，生产使用前请自行核对。

## 用来做什么

用于其他模型生成的静帧或片段的描述、后续问答与质量检查。记录的任务 profile 是 `multimodal-reasoning`（默认）、`audio-reasoning`、`image-question-answering`、`video-question-answering`。四个 profile 共用同一输入契约，经 `Qwen25OmniPipeline` 写出 `qwen2.5-omni.json`。

先准备好 `Qwen/Qwen2.5-Omni-7B`。7B 版本按单张现代 GPU 设计。

`audio-reasoning` profile 不接受 `audio` 输入；这条路径不是语音输入 / 语音输出配置。

## 运行时契约
后端是官方 Hugging Face Transformers 运行时。加载方式为 `from_pretrained`。不支持 Talker / 流式语音解码。

## 在 WorldFoundry 中运行

在统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）里运行 `wf run qwen2.5-omni --pipeline.task-profile multimodal-reasoning`。准备和检查模型时，可使用 `bash scripts/inference/prepare_model_infer.sh qwen2.5-omni` 与 `wf zoo model-show --model-id qwen2.5-omni`。
