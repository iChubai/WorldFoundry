Real-Time Chunking (RTC) is not a model but an inference-time algorithm from Physical Intelligence: it lets flow-based VLA policies re-plan action chunks asynchronously so control stays smooth under real-time constraints. WorldFoundry routes RTC through an in-tree action runtime adapter — no checkpoint is required for chunk-context processing.

## What it is for

Use `real-time-chunking` for vision-language-action inference on this card. The recipe exists so you can launch the recorded policy profile.

RTC treats chunk switching as an inpainting problem: the start of the next chunk is constrained to agree with actions already executing, removing pauses and discontinuities at chunk boundaries. The reference implementation targets the Kinetix environment suite.

Catalog tasks include action chunking, real time control, and vla inference runtime. Catalog aliases include `rtc` and `action-chunking-rtc`.

Recorded evaluation entry points include [Kinetix](/docs/evaluation/benchmark-hub/kinetix) (The official reference implementation targets Kinetix).
