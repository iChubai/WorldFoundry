## 用来做什么

`recammaster` 以相机位姿为条件生成视频。

按论文（arXiv 2503.11647），ReCamMaster 通过帧维度条件化把源视频注入预训练文生视频模型（开源版基于 Wan 系），从而在生成时更换相机轨迹。该模型由快手（可灵团队）发布。

任务：camera-controlled video rerendering。别名：`Camera-Controlled Generative Rendering from A Single Video`。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（直接评估相机轨迹控制质量）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`steps`、`guidance-scale`、`camera-trajectory`；产物 `generated_video`、`generated_4d_scene`、`recammaster.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `ReCamMasterPipeline`。

系列状态：**已验证**。

`default` 的默认值：frames=81, fps=8。

提交任务前请就位 Wan2.1（Wan-AI/Wan2.1-T2V-1.3B）与 ReCamMaster checkpoint（KlingTeam/ReCamMaster-Wan2.1）；运行时还需要 torchvision 与 CUDA GPU。

## 在 WorldFoundry 中运行

用 `wf run recammaster --pipeline.task-profile default` 生成相机可控视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`KlingTeam/ReCamMaster-Wan2.1`、`Wan-AI/Wan2.1-T2V-1.3B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh recammaster`；下载缺失的公开权重时加 `--download`。
