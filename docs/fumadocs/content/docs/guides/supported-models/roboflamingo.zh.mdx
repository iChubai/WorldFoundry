RoboFlamingo 把 OpenFlamingo 变成语言条件机器人策略：VLM 编码相机帧和任务指令，循环头输出连续控制（通常是 **7 自由度** 位姿加夹爪）。官方论文是 [Vision-Language Foundation Models as Effective Robot Imitators](https://arxiv.org/abs/2311.01378)（arXiv 2311.01378）。项目页：[roboflamingo.github.io](https://roboflamingo.github.io/)。代码在 [RoboFlamingo/RoboFlamingo](https://github.com/RoboFlamingo/RoboFlamingo)。

已在 GPU 上验证：就位三套栈（发布的 CALVIN 策略、OpenFlamingo VLM、MPT 语言骨干）后，公开 pipeline 可产出 CUDA `action_trace`。请用具身动作基准评测它，不要用视频生成 scorecard。别名 `robo-flamingo` 指向同一模型。

## 用来做什么

面向 [CALVIN](/zh/docs/evaluation/benchmark-hub/calvin) 风格长时程套件上的语言条件操作。必填 `image`、`instruction`、`prompt`、`video`。`RoboFlamingoPipeline` 写出 `roboflamingo_action_trace.json`。

需要 GPU 就绪、且骨干就位路径明确的 OpenFlamingo 策略时使用它。它的动作头是循环结构，不是分块或扩散动作头。

## 运行时契约

架构默认值：

- 视觉：**ViT-L-14**（OpenCLIP），语言：**MPT-1B**（配置里的 `mpt_dolly_3b`）
- **`window_size` 12**，**`n_obs_steps` 2**，融合 `post`
- 策略头：**LSTM**（`decoder_type` / `head_type` 都是 `lstm`）
- 开夹爪相机，关本体感知（`use_state=false`），**fp32**

三套 checkpoint 目录都必须已在 `${WORLDFOUNDRY_HFD_ROOT}` 下：

- `robovlms/RoboFlamingo` → `robovlms--RoboFlamingo`（发布的 CALVIN 策略）
- `openflamingo/OpenFlamingo-3B-vitl-mpt1b-langinstruct` → `openflamingo--OpenFlamingo-3B-vitl-mpt1b-langinstruct`
- `anas-awadalla/mpt-1b-redpajama-200b-dolly` → `anas-awadalla--mpt-1b-redpajama-200b-dolly`

视觉编码器文件应位于 `${WORLDFOUNDRY_CKPT_DIR}/open_clip/ViT-L-14.pt`。完整的官方 CALVIN 评测还需要 CALVIN 资产。

## 在 WorldFoundry 中运行

环境 profile 是 `worldfoundry-unified-cu128`；其环境 YAML 固定 **Python 3.8**，以匹配 RoboFlamingo 上游要求。三套 checkpoint 就位后：

```
wf run roboflamingo
```

该模型未列出许可证。生产使用前请确认 RoboFlamingo / OpenFlamingo / MPT 条款。
