## Architecture

The in-tree inference-only runner reuses the existing forcing pipeline, causal Wan variant, attention sink/KV cache, core scheduler, attention dispatch, distributed helpers, and video I/O; execution never imports an external RollingForcing repository. The static integration follows the official five-step, three-latent-frame block configuration.

## Usage notes

The released route is text-to-video only — unverified I2V behavior is not advertised. BF16 and memory capacity are hardware requirements; the official 126 latent frames decode to a long 16 fps video, and smaller multiples of three are valid smoke runs. Upstream terms allow academic use only.
