RollingForcing streams minutes-long video autoregressively: rolling-window denoising with an attention sink lets it generate long text-to-video without the drift that kills naive streaming (paper arXiv 2509.25161). Validated with the released checkpoint on A100: 126 latent frames decode to a 31.31-second H.264 video (501 frames at 832x480, 16 fps).

## What it is for

`rolling-forcing` generates a video clip from a text prompt.

WorldFoundry runs it on a causal Wan backbone with an attention sink and KV cache, following the official five-step, three-latent-frame block configuration. It is published by Tencent (ARC Lab) / Nanyang Technological University.

Tasks: text-to-video, long video generation, and autoregressive video generation. Aliases: `RollingForcing`, `rolling_forcing`, and `rollingforcing`. Modalities: text in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Video quality for long text-to-video output), [ChronoMagic-Bench](/docs/evaluation/benchmark-hub/chronomagic-bench) (Long-horizon temporal coherence).

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `frames`, `seed`, `num-samples`, `use-ema`, `save-with-index`, and `report-timing`; artifacts `generated_video` and `rolling-forcing.mp4`.

CLI task profiles: `text-to-long-video`. WorldFoundry binds `RollingForcingPipeline`.

Family status: **Verified**.

Defaults for `text-to-long-video`: frames=126, seed=0.

The released route is text-to-video only. BF16 support and enough GPU memory are required; the official 126 latent frames decode to a long 16 fps video, and smaller multiples of three give shorter test runs. Upstream terms allow academic use only.

## Running in WorldFoundry

Generate a clip with `wf run rolling-forcing --pipeline.task-profile text-to-long-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch>=2.4).

Weights: `TencentARC/RollingForcing`, `TencentARC/RollingForcing`, and `Wan-AI/Wan2.1-T2V-1.3B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh rolling-forcing`. Add `--download` to fetch missing public checkpoints.
