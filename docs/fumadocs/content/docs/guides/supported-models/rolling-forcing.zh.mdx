RollingForcing 自回归地流式生成数分钟长的视频：滚动窗口去噪加 attention sink，避免了朴素流式生成的漂移崩坏（论文 arXiv 2509.25161）。已在 A100 上用发布的 checkpoint 验证：126 个潜帧解码为 31.31 秒的 H.264 视频（501 帧，832x480，16 fps）。

## 用来做什么

`rolling-forcing` 根据文本提示词生成视频。

WorldFoundry 在带 attention sink 与 KV 缓存的因果 Wan 骨干上运行，遵循官方五步、三潜帧块配置。该模型由腾讯（ARC Lab）/ 南洋理工大学发布。

任务：文生视频、长视频生成、autoregressive-video-generation。别名：`RollingForcing`、`rolling_forcing`、`rollingforcing`。模态上，它接受文本，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（长文生视频输出的质量评测）、[ChronoMagic-Bench](/zh/docs/evaluation/benchmark-hub/chronomagic-bench)（长时程时间连贯性评测）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `frames`、`seed`、`num-samples`、`use-ema`、`save-with-index`、`report-timing`；产物 `generated_video`、`rolling-forcing.mp4`。

CLI task profile：`text-to-long-video`。绑定的 pipeline 类是 `RollingForcingPipeline`。

系列状态：**已验证**。

`text-to-long-video` 的默认值：frames=126, seed=0。

发布路径仅支持文生视频。需要支持 BF16 且显存充足的 GPU；官方 126 潜帧解码为 16 fps 长视频，更小的三的倍数可用于较短的测试运行。上游条款仅允许学术使用。

## 在 WorldFoundry 中运行

用 `wf run rolling-forcing --pipeline.task-profile text-to-long-video` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch>=2.4）。

权重仓库：`TencentARC/RollingForcing`、`Wan-AI/Wan2.1-T2V-1.3B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh rolling-forcing`；下载缺失的公开权重时加 `--download`。

许可证：仅限学术用途（Rolling Forcing 许可）。
