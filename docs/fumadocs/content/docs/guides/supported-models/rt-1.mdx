## What it is for

`rt-1` is a vision-language-action policy: an instruction and observations in, actions out.

An EfficientNet-B3 image tokenizer with FiLM language conditioning, TokenLearner compression, and a decoder-only transformer emitting discretized action tokens — served as a TensorFlow SavedModel. It is published by Google Research.

Tasks: VLA, VLA policy rollout, robot policy, and robotics transformer. Aliases: `rt1` and `robotics-transformer`.

## Runtime contract

Required `input-path` and `language-embedding`; inputs `prompt` (bundled samples are used when omitted); options `plan-only`; artifacts `rt1_action_trace.json`.

CLI task profiles: `vla`. WorldFoundry binds `RT1Pipeline`.

Family status: **Runner parity pending**.

Supply a 512-D language_embedding from an encoder compatible with the checkpoint along with the image and prompt. The released SavedModel does not turn prompt text into that embedding; WorldFoundry rejects text-only inference instead of silently using zeros. GPU inference needs a TensorFlow/CuDNN-compatible environment.

Text-only inference requires a separately staged, checkpoint-compatible language encoder; offline action structure validation does not prove task success.
