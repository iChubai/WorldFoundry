RT-1（Robotics Transformer 1）是谷歌研究院开创性的大规模机器人 transformer，在 13 万条真实机器人示范上训练，从图像与指令输出离散化动作。已用官方权重在 GPU 上离线验证：传入合成 512 维向量时，SavedModel 适配器输出结构正确的动作。

## 用来做什么

`rt-1` 是视觉-语言-动作（VLA）策略：输入指令和观测，输出动作。

EfficientNet-B3 图像 token 化配 FiLM 语言条件、TokenLearner 压缩与 decoder-only transformer，输出离散化动作 token——以 TensorFlow SavedModel 提供。该模型由谷歌研究院（Google Research）发布。

任务：视觉-语言-动作（VLA）、VLA 策略执行、机器人策略、robotics_transformer。别名：`rt1`、`robotics-transformer`。

## 运行时契约

必填 `input-path`、`language-embedding`；输入 `prompt`（不传时使用内置示例）；参数 `plan-only`；产物 `rt1_action_trace.json`。

CLI task profile：`vla`。绑定的 pipeline 类是 `RT1Pipeline`。

系列状态：**Runner 一致性待确认**。

传入图像、指令以及由兼容编码器生成的 512 维 language_embedding。发布的 SavedModel 不会自行把指令文本编码成该向量；WorldFoundry 对只有文本的推理明确报错，不会默默使用零向量。GPU 推理需要兼容的 TensorFlow/CuDNN 环境。

仅输入文本还需要另行准备与 checkpoint 兼容的语言编码器；离线动作结构验证不代表任务成功。

## 在 WorldFoundry 中运行

用 `wf run rt-1 --pipeline.task-profile vla --pipeline.input-path VALUE --pipeline.language-embedding VALUE` 运行策略。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CPU）。

该模型未登记公开的 checkpoint；请按使用说明准备权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh rt-1`；下载缺失的公开权重时加 `--download`。
