## 用来做什么

需要 catalog 上的 VLA 策略时选 `rt-1`：指令与观测进、动作轨迹出。用来滚动已记录策略，不是用来训练新策略。

EfficientNet-B3 图像 token 化配 FiLM 语言条件、TokenLearner 压缩与 decoder-only transformer，输出离散化动作 token——以 TensorFlow SavedModel 提供。该模型由谷歌研究院（Google Research）发布。

catalog 记录的任务包括 视觉-语言-动作（VLA）、VLA 策略执行、机器人策略、robotics_transformer。别名包括 `rt1`、`robotics-transformer`。

记录的任务 profile：`vla`、`vla.policy_rollout`、`robot_policy`、`robotics_transformer`。绑定的 pipeline 类是 `RT1Pipeline`。
