## 用来做什么

`runway-gen4p5` 通过提供商的托管 API 运行，无需本地 checkpoint。

Runway 未公开其架构、参数规模或训练细节。WorldFoundry 通过 Studio pipeline 向服务方端点提交请求并回收生成的视频。

任务：图生视频、托管 API。别名：`gen_3_i2v`、`gen-3-i2v`。模态上，它接受图像，输出视频。
