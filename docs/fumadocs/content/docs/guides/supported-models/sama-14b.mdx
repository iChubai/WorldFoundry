## What it is for

`sama-14b` is a video-to-video model for editing and transforming clips.

A 14B-parameter editing model with a prompt/image/video input contract. See the upstream GitHub (Cynthiazxy123/SAMA) for architecture details.

Tasks: video editing.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `fps`, `height`, `width`, `seed`, `max-frames`, `tiled`, and 1 more; artifacts `sama-14b.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `SAMA14BPipeline`.

Family status: **Runner parity pending**.

Defaults for `interactive-video`: fps=16, height=480, width=832, seed=1.

Supply a source video and an edit instruction. A 17-frame edit with the released checkpoint was checked against the official implementation.

## Running in WorldFoundry

Edit a clip with `wf run sama-14b --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `syxbb/SAMA-14B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh sama-14b`. Add `--download` to fetch missing public checkpoints.
