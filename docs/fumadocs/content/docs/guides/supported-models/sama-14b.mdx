## What it is for

Use `sama-14b` for catalog video-to-video inference. Start here when the input is already a video.

The catalog records a 14B-parameter editing model with a prompt/image/video input contract; the publishing institution and architecture internals are not recorded in this repository — consult the upstream GitHub (Cynthiazxy123/SAMA) for details.

Catalog tasks include video-editing, reference-guided-video, and mask-conditioned-video.

## Runtime contract

## Running in WorldFoundry

Launch `worldfoundry-eval run sama-14b --pipeline.task-profile video-editing` to edit the clip. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `syxbb/SAMA-14B`. Stage assets with `bash scripts/inference/prepare_model_infer.sh sama-14b`.

Recorded licenses include apache-2.0; status: **Runner parity pending**.
