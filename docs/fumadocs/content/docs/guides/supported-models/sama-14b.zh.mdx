## 用来做什么

`sama-14b` 是视频到视频模型，用于编辑和变换视频。

14B 参数的视频编辑模型，输入契约为 prompt/image/video。架构细节请查阅上游 GitHub（Cynthiazxy123/SAMA）。

任务：视频编辑。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `fps`、`height`、`width`、`seed`、`max-frames`、`tiled` 等 7 项；产物 `sama-14b.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `SAMA14BPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-video` 的默认值：fps=16, height=480, width=832, seed=1。

提供源视频和编辑指令。使用官方权重的 17 帧编辑已与官方实现对照。

## 在 WorldFoundry 中运行

用 `wf run sama-14b --pipeline.task-profile interactive-video` 编辑视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`syxbb/SAMA-14B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh sama-14b`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
