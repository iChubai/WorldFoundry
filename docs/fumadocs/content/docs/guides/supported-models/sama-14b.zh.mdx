## 用来做什么

用 `sama-14b` 做 catalog 视频到视频推理。输入已经是视频时从这里起步。

catalog 记录这是一个 14B 参数的编辑模型，输入契约为 prompt/image/video；发表机构与架构内部细节仓库未记录——详情请查阅上游 GitHub（Cynthiazxy123/SAMA）。

catalog 记录的任务包括 视频编辑、reference-guided-video、mask-conditioned-video。

## 运行时契约

必填 `prompt`；可选 `image`、`video`；产物 `sama-14b.mp4`。

记录的任务 profile：`video-editing`、`reference-guided-video`、`mask-conditioned-video`。绑定的 pipeline 类是 `SAMA14BPipeline`。

系列状态：**Runner 一致性待确认**。

在完成一次 checkpoint 加载运行前，runner parity 保持 pending。 启动前请准备源视频、掩码与参考资产；路径会明确报告缺失资产。

Checkpoint 属于外部资产——权重缺失时会在运行时报告，而不会自动下载。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run sama-14b --pipeline.task-profile video-editing` 改视频。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

记录的权重仓库包括 `syxbb/SAMA-14B`。就位权重用 `bash scripts/inference/prepare_model_infer.sh sama-14b`。

记录 license 为 apache-2.0；状态：**Runner 一致性待确认**。
