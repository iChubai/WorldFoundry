Sana is NVIDIA's efficient generation family with twenty variants spanning text-to-image (600M–4.8B, up to 4K), ControlNet-conditioned image generation, Sana-Video 2B text-to-video at 480p/720p, LongSANA long video, and SANA-Streaming video-to-video (long and bidirectional).

Project page: [nvlabs.github.io/Sana](https://nvlabs.github.io/Sana/). Code: [NVlabs/Sana](https://github.com/NVlabs/Sana).

## What it is for

`sana-600m-512px` turns a text prompt into a still image.

Sana's efficiency comes from a deep-compression autoencoder (32x) plus linear-attention DiT blocks and a small LLM text encoder, per the publication (arXiv 2410.10629). The SANA-Streaming routes use the official BF16 CLI with hybrid DiT blocks, fused GDN kernels, and a causal LTX-2 VAE.

Tasks: text-to-image, text-to-video, video-to-video, and image-conditioned generation. Aliases: `sana-video`, `longsana-video`, `sana-streaming`, and `sana-streaming-bidirectional`. Modalities: text and video in, image and video out. Other variants: `sana-600m-1024px`, `sana-1600m-512px`, `sana-1600m-512px-multiling`.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Quality suite for the Sana-Video T2V routes), [SANA-WM 80-Scene Benchmark](/docs/evaluation/benchmark-hub/sana-wm-bench) (Sana-specific world-model benchmark).

SANA-WM has its own page: [SANA-WM](/docs/guides/supported-models/sana-wm).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `height`, `width`, `steps`, `guidance-scale`, and `seed`; artifacts `sana.png`.

CLI task profiles: `interactive-video` and `video-to-video`. WorldFoundry binds `SanaPipeline`.

Start with `sana-600m-512px`. The family has 20 variants, selectable in the command builder above: `sana-600m-512px` (`text-to-image`) — Runner parity pending; `sana-600m-1024px` (`text-to-image`) — Runner parity pending; `sana-1600m-512px` (`text-to-image`) — Runner parity pending; `sana-1600m-512px-multiling` (`text-to-image`) — Runner parity pending; `sana-1600m-1024px` (`text-to-image`) — Runner parity pending among others. Family status: **Runner parity pending**.

Validated with the long-streaming checkpoint: an A100 run decodes 81 frames at 1280x704, 16 FPS. SANA-Streaming accepts a source video path or hf:// URI. Quality parity with the official full 50-step, longer-frame configuration is not verified.

## Running in WorldFoundry

Run `wf run sana-600m-512px --pipeline.task-profile interactive-video` to write the image. Switch tasks in the command builder above to change `--pipeline.task-profile`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Efficient-Large-Model/Sana_600M_512px`, `Efficient-Large-Model/Sana_600M_1024px`, and `Efficient-Large-Model/Sana_1600M_512px` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh sana-600m-512px`. Add `--download` to fetch missing public checkpoints.
