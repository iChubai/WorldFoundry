Sana 是英伟达的高效生成系列，共二十个 variant，覆盖文生图（600M–4.8B，最高 4K）、ControlNet 条件图像生成、Sana-Video 2B 的 480p/720p 文生视频、LongSANA 长视频，以及 SANA-Streaming 的视频到视频（长时与双向）。

论文：[SANA: Efficient High-Resolution Image Synthesis with Linear Diffusion Transformers](https://arxiv.org/abs/2410.10629)（2024）。

项目页：[nvlabs.github.io/Sana](https://nvlabs.github.io/Sana/)。代码：[NVlabs/Sana](https://github.com/NVlabs/Sana)。

## 用来做什么

`sana-600m-512px` 把文本提示词变成一张静态图。

Sana 的高效来自深压缩自编码器（32x）、线性注意力 DiT 块与小型 LLM 文本编码器，见论文（arXiv 2410.10629）。SANA-Streaming 路径使用官方 BF16 CLI，包含混合 DiT 块、融合 GDN 核与因果 LTX-2 VAE。该模型由英伟达（NVIDIA）发布。

任务：文生图、文生视频、视频到视频、image-conditioned-generation。别名：`sana-video`、`longsana-video`、`sana-streaming`、`sana-streaming-bidirectional`。模态上，它接受文本、视频，输出图像、视频。同系列还有 `sana-600m-1024px`、`sana-1600m-512px`、`sana-1600m-512px-multiling`。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（Sana-Video 文生视频路径的质量评测）、[SANA-WM 80-Scene Benchmark](/zh/docs/evaluation/benchmark-hub/sana-wm-bench)（针对 Sana 的世界模型评测）。

SANA-WM 另有独立页面：[SANA-WM](/zh/docs/guides/supported-models/sana-wm)。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `height`、`width`、`steps`、`guidance-scale`、`seed`；产物 `sana.png`。

CLI task profile：`interactive-video`、`video-to-video`。绑定的 pipeline 类是 `SanaPipeline`。

建议从 `sana-600m-512px` 开始。该系列共有 20 个 variant，可在上方命令构建器中切换：`sana-600m-512px`（`text-to-image`）：Runner 一致性待确认、`sana-600m-1024px`（`text-to-image`）：Runner 一致性待确认、`sana-1600m-512px`（`text-to-image`）：Runner 一致性待确认、`sana-1600m-512px-multiling`（`text-to-image`）：Runner 一致性待确认、`sana-1600m-1024px`（`text-to-image`）：Runner 一致性待确认等。系列状态：**Runner 一致性待确认**。

已用 long-streaming checkpoint 验证：在 A100 上的运行解码出 81 帧 1280x704、16 FPS 视频。SANA-Streaming 接受源视频路径或 hf:// URI。

与官方完整 50 步、更长帧数配置的质量一致性尚未验证。

已用 long-streaming checkpoint 验证：在 A100 上的运行解码出 81 帧 1280x704、16 FPS 视频。

## 在 WorldFoundry 中运行

运行 `wf run sana-600m-512px --pipeline.task-profile interactive-video` 写出图像。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`Efficient-Large-Model/Sana_600M_512px`、`Efficient-Large-Model/Sana_600M_1024px`、`Efficient-Large-Model/Sana_1600M_512px` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh sana-600m-512px`；下载缺失的公开权重时加 `--download`。
