## Architecture

SCOPE-specific action conditioning is integrated as a canonical Wan network variant, assembled with shared Wan encoders, VAE, loaders, and staged execution (apache-2.0). Only the checkpoint-shaped action-conditioned network remains model-specific.

## Usage notes

SCOPEPipeline fails fast unless execute=True is supplied, then invokes the in-tree native assembly. Weights stay external HF assets injected through model_dir/checkpoint_root or SCOPE_MODEL_DIR.
