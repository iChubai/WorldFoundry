SCOPE is an interactive game world model over a Wan backbone: image plus per-step actions in, game-world video out (paper arXiv 2605.23345). Validated with the zizhaotong/SCOPE weights: the image-action-to-video demo runs end to end from the example image and an action parquet.

<ModelPaperFigures modelId="scope" locale="en" />

The paper is [SCOPE: Simulating Cross-game Operations in Playable Environments for FPS World Models](https://arxiv.org/abs/2605.23345). Project page: [z2tong.github.io/SCOPE](https://z2tong.github.io/SCOPE). Code: [z2tong/SCOPE](https://github.com/z2tong/SCOPE).

Aliases: `scope-world-model` and `zizhaotong/SCOPE`.

<ModelCommandBuilder modelId="scope" locale="en" />

## What it is for

Drive SCOPE as an action-conditioned world route. Launch `wf run scope` — required `image` and `prompt`; out `generated_video` and `scope.mp4`.

Score on [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench).

## Runtime contract

Required: `image` and `prompt`. Optional: `video`. Actions: action_parquet. Artifacts: `generated_video` and `scope.mp4`. Pass `execute=True` to `SCOPEPipeline` to run generation; without it the pipeline stops immediately. Point `model_dir`/`checkpoint_root` or `SCOPE_MODEL_DIR` at the staged weights.

Execution uses the installed `worldfoundry.synthesis.visual_generation.scope.scope_runtime.inference` module in the selected Python environment.

## Running in WorldFoundry

Run in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `zizhaotong/SCOPE` locally, then launch `wf run scope`.
