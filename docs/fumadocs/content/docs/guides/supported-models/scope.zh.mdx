## 架构

SCOPE 专属的动作条件被集成为规范 Wan 网络 variant，与共享 Wan 编码器、VAE、加载器与分级执行组装（apache-2.0）。只有按 checkpoint 形状实现的动作条件网络保持模型专属。

## 使用要点

SCOPEPipeline 在未提供 execute=True 时快速失败，提供后调用树内原生组装。权重保持为外部 HF 资产，通过 model_dir/checkpoint_root 或 SCOPE_MODEL_DIR 注入。
