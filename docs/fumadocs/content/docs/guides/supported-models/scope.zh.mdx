SCOPE 是基于 Wan 基座的交互式游戏世界模型：输入图像与逐步动作，输出游戏世界视频（论文 arXiv 2605.23345）。已用 zizhaotong/SCOPE 权重验证：图像+动作到视频的 demo 可基于示例图与动作 parquet 端到端运行。

<ModelPaperFigures modelId="scope" locale="zh" />

论文是 [SCOPE: Simulating Cross-game Operations in Playable Environments for FPS World Models](https://arxiv.org/abs/2605.23345)。项目页：[z2tong.github.io/SCOPE](https://z2tong.github.io/SCOPE)。代码：[z2tong/SCOPE](https://github.com/z2tong/SCOPE)。

别名：`scope-world-model`、`zizhaotong/SCOPE`。

<ModelCommandBuilder modelId="scope" locale="zh" />

## 用来做什么

把 SCOPE 当动作条件世界路径来跑。启动 `wf run scope`——必填 `image`、`prompt`；产物 `generated_video`、`scope.mp4`。

评测看 [WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)。

## 运行时契约

必填：`image`、`prompt`。可选：`video`。动作字段：action_parquet。产物：`generated_video`、`scope.mp4`。向 `SCOPEPipeline` 传入 `execute=True` 才会执行生成；未传入时 pipeline 会立即停止。通过 `model_dir`/`checkpoint_root` 或 `SCOPE_MODEL_DIR` 指向本地权重。

## 在 WorldFoundry 中运行

跑在统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。先把 `zizhaotong/SCOPE` 放到本地，再启动 `wf run scope`。
