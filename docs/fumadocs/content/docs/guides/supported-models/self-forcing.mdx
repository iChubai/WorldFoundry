## Architecture

Per the paper, a Wan2.1-based causal student is trained with holistic distribution matching over self-generated rollouts, plus KV caching for streaming. The runner owns prompt/i2v data materialization, Wan weight symlinks, command construction, and output loading in-tree (checkpoint: gdhe17/Self-Forcing).
