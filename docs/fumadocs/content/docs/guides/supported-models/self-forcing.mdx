Self-Forcing bridges the train-test gap in autoregressive video diffusion: by simulating the inference process during training — conditioning each frame on its own previously generated frames — it enables real-time streaming text-to-video on a single GPU (arXiv 2506.08009). In this catalog the official infer-only runtime is vendored in-tree; parity waits on the Self-Forcing DMD checkpoint plus Wan2.1 weights.
