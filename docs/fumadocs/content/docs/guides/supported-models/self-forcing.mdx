Self-Forcing bridges the train-test gap in autoregressive video diffusion: by simulating the inference process during training — conditioning each frame on its own previously generated frames — it enables real-time streaming text-to-video on a single GPU (arXiv 2506.08009). WorldFoundry serves it as a native diffusion recipe, offline and as a realtime stream, bitwise equal to the official inference script.

## What it is for

Pick `self-forcing` when you want this family's text-to-video line in WorldFoundry: a prompt in, a generated clip out. Use it as the catalog T2V start rather than an editor or a world-model stepper.

The causal Wan2.1 T2V 1.3B generator (gdhe17/Self-Forcing, self_forcing_dmd.pt) denoises three-latent-frame blocks in four distilled x0 steps at timesteps 1000, 750, 500 and 250 on the shift-5 flow calendar, then commits each clean block to a 21-latent-frame KV cache at timestep 0. It is published by Adobe Research / The University of Texas at Austin.

Catalog tasks include text-to-video and autoregressive-video-generation. Catalog aliases include `Self-Forcing`, `selfforcing`, and `self_forcing`. Documented modalities: text in, video out.

Recorded evaluation entry points include [VBench](/docs/evaluation/benchmark-hub/vbench) (Video quality for streaming text-to-video).

## Runtime contract

Optional `prompt`, `frames`, `fps`, `height`, and `width`; artifacts `self-forcing.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `NativeSelfForcingPipeline`.

Family status: **Verified**.

Recorded `interactive-video` defaults: frames=81, fps=16, height=480, width=832, seed=0.

Defaults follow the official CLI: 480x832, 81 frames (21 latent frames), four steps, guidance 1.0, 16 fps; num_frames must give a multiple of three latent frames up to 21. The realtime session emits 9 frames for the first block and 12 for each later block, 7 chunks for 81 frames. Loading with kv_window="sink5-window7-rerope" selects the approximate long-rollout cache for longer videos and unbounded streams.

## Running in WorldFoundry

The catalog launch is `wf run self-forcing --pipeline.task-profile interactive-video`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `wf run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `gdhe17/Self-Forcing` and `Wan-AI/Wan2.1-T2V-1.3B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh self-forcing`. Add `--download` to fetch missing public checkpoints.
