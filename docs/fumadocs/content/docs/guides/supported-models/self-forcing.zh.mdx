Self-Forcing 弥合了自回归视频扩散的训练-推理差距：在训练时模拟推理过程——让每帧以自己先前生成的帧为条件——从而在单卡上实现实时流式文生视频（arXiv 2506.08009）。WorldFoundry 运行官方仅推理运行时，需要 Self-Forcing DMD checkpoint 与 Wan2.1 权重。

## 用来做什么

`self-forcing` 根据文本提示词生成视频，也可以额外用一张静态图做条件。

按论文，基于 Wan2.1 的因果学生在自生成滚动上做整体分布匹配训练，并用 KV 缓存实现流式（checkpoint：gdhe17/Self-Forcing）。该模型由Adobe 研究院 / 得克萨斯大学奥斯汀分校发布。

任务：文生视频、图生视频、autoregressive-video-generation。别名：`Self-Forcing`、`selfforcing`、`self_forcing`。模态上，它接受文本、图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（流式文生视频的质量评测）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `seed`、`num-output-frames`、`num-samples`、`use-ema`、`save-with-index`；产物 `self-forcing.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `SelfForcingPipeline`。

系列状态：**Runner 一致性待确认**。

`default` 的默认值：seed=0。

默认 checkpoint 路径遵循 $\{WORLDFOUNDRY_CKPT_DIR\}/Self-Forcing 的官方 HF 布局——另行存放时请覆盖 checkpoint_path。Wan2.1 权重需按 wan_models 兼容布局准备；benchmark 提示词列表需自行准备，并通过本地输入配置提供。

## 在 WorldFoundry 中运行

运行 `wf run self-forcing --pipeline.task-profile default` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`gdhe17/Self-Forcing`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh self-forcing`；下载缺失的公开权重时加 `--download`。
