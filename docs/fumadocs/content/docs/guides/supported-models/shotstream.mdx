## What it is for

`shotstream` generates a 3D-consistent world rather than a single clip.

A 4-step causal video generator built on the Wan2.1-T2V-1.3B base model; weights are published at KlingTeam/ShotStream. It is published by Kuaishou (Kling Team).

Tasks: interactive video generation, real time video generation, and streaming video. Aliases: `interactive-video-generation`. Output modalities: video.

## Runtime contract

Inputs `prompt`, `load.checkpoint-dir`, and `load.wan-model-dir` (bundled samples are used when omitted); options `seed`, `fps`, `plan-only`, and `timeout-seconds`; artifacts `generated_video` and `shotstream.mp4`.

CLI task profiles: `causal-video`. WorldFoundry binds `ShotStreamPipeline`.

Family status: **Runner parity pending**.

Defaults for `causal-video`: seed=42, fps=16.

Stage the official ShotStream source checkout at the pinned revision under $\{WORLDFOUNDRY_MODEL_SOURCE_DIR\}/ShotStream, plus the KlingTeam/ShotStream checkpoint and Wan2.1-T2V-1.3B weights; until they are staged, a generation request returns a runtime plan listing the missing assets. A plain prompt becomes the official one-shot input; pass a full multi-shot CSV with data_path/input_csv.

## Running in WorldFoundry

Generate a world with `wf run shotstream --pipeline.task-profile causal-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `KlingTeam/ShotStream` and `Wan-AI/Wan2.1-T2V-1.3B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh shotstream`. Add `--download` to fetch missing public checkpoints.
