ShotStream 是快手可灵研究团队的实时交互流式视频生成器：目标是连续、可交互操控的视频流，而非固定片段。WorldFoundry 从用户准备的固定 commit 官方源码运行其 4 步因果生成器。

## 用来做什么

`shotstream` 生成 3D 一致的世界，而不只是一段视频。

基于 Wan2.1-T2V-1.3B 基座的 4 步因果视频生成器；权重发布于 KlingTeam/ShotStream。该模型由快手（可灵团队）发布。

任务：交互式视频生成、real-time-video-generation、streaming-video。别名：`interactive-video-generation`。输出模态为视频。

## 运行时契约

输入 `prompt`、`load.checkpoint-dir`、`load.wan-model-dir`（不传时使用内置示例）；参数 `seed`、`fps`、`plan-only`、`timeout-seconds`；产物 `generated_video`、`shotstream.mp4`。

CLI task profile：`causal-video`。绑定的 pipeline 类是 `ShotStreamPipeline`。

系列状态：**Runner 一致性待确认**。

`causal-video` 的默认值：seed=42, fps=16。

需在 $\{WORLDFOUNDRY_MODEL_SOURCE_DIR\}/ShotStream 准备固定 revision 的 ShotStream 官方源码，以及 KlingTeam/ShotStream checkpoint 与 Wan2.1-T2V-1.3B 权重；资产就位前，生成请求会返回列出缺失资产的运行时计划。普通 prompt 会转换为官方单镜头输入；完整多镜头 CSV 通过 data_path/input_csv 传入。

## 在 WorldFoundry 中运行

用 `wf run shotstream --pipeline.task-profile causal-video` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`KlingTeam/ShotStream`、`Wan-AI/Wan2.1-T2V-1.3B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh shotstream`；下载缺失的公开权重时加 `--download`。
