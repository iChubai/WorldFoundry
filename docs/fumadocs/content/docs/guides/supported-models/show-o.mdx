Show-o (Xie et al., Show Lab at NUS with ByteDance, arXiv 2408.12528) is a single 1.3B transformer that unifies multimodal understanding and generation. It is initialized from Phi-1.5 and, unlike systems that attach a separate diffusion expert to an MLLM, uses one set of weights for both.

## What it is for

`show-o` turns a text prompt into a still image.

Image I/O uses the MAGVIT-v2 VQ tokenizer (showlab/magvitv2). The paper also studies continuous MAGVIT or CLIP-ViT features for understanding (Show-o† / Show-o‡); the released default weights use discrete tokens for both understanding and generation. WorldFoundry takes mode, prompt, and image inputs and loads microsoft/phi-1_5 with showlab/show-o. It is published by National University of Singapore (Show Lab).

Tasks: multimodal generation and text-to-image. Aliases: `show_o` and `showo`. Modalities: text and image in, image and text out.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `guidance-scale`, `mode`, `generation-timesteps`, and `resolution`; artifacts `show_o.png`.

CLI task profiles: `default`. WorldFoundry binds `ShowOPipeline`.

Family status: **Verified**.

WorldFoundry runs T2I only — set mode accordingly and expect a generated_image artifact. Paper-default resolution is 256; the wrapper uses classifier-free guidance (default 3.0) and 18 discrete-diffusion steps. Weights are MIT at showlab/show-o, with showlab/magvitv2 (MAGVIT-v2) and microsoft/phi-1_5 as companion weights.

Only text-to-image is available; understanding (MMU), inpainting, and extrapolation are not.

## Running in WorldFoundry

Run `wf run show-o --pipeline.task-profile default` to write the image.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 11.3).

Weights: `showlab/show-o`, `showlab/magvitv2`, and `microsoft/phi-1_5`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh show-o`. Add `--download` to fetch missing public checkpoints.
