Show-o（Xie 等，新加坡国立大学 Show Lab 与 ByteDance，arXiv 2408.12528）是一个 1.3B 的单一 Transformer，把多模态理解与生成放在同一套权重里。它从 Phi-1.5 初始化，而不是把独立扩散专家接到 MLLM 上。

文本是离散 token，用自回归 next-token prediction；图像经 MAGVIT-v2 无查找量化，256×256 变成 16×16、码本 8,192，再用 MaskGIT 式离散扩散（mask-token prediction）和全注意力生成。Omni-attention 对文本因果、对图像 token 双向。文本条件由 LLM 自己编码，没有额外的 T5/CLIP 文本编码器。

论文中同一套权重可做 VQA/配文、文生图，以及无需额外微调的文本引导补全与外推，也支持混合模态序列。默认生成数字是 1.3B 参数、约 3500 万图文对（MSCOCO FID-30K 9.24），接近只做理解的 LLaVA-v1.5-Phi-1.5 基线。本 catalog 只接通 T2I；MMU、补全与外推仍是后续工作。

## 架构

Transformer 是带逐层 QK-Norm 的 Phi-1.5，词表额外增加 8,192 个可学习图像 token。统一 prompt 用 [MMU]/[T2I] 标明任务，用 [SOT]/[EOT]、[SOI]/[EOI] 框住文本与图像。训练同时做 mask-token prediction 与 next-token prediction（L_MTP + α L_NTP）。生成从全 [MASK] 开始、按 T 步逐步揭开，步数大约是自回归解码图像的 1/20；树内运行时默认 256 像素、CFG 3.0、18 步。

图像编解码用 MAGVIT-v2 VQ（showlab/magvitv2）。论文还试过把 MAGVIT 或 CLIP-ViT 连续特征用于理解（Show-o† / Show-o‡）；发布的默认权重和本 catalog 对理解与生成都用离散 token。WorldFoundry 运行时在 synthesis/visual_generation/show_o，契约为 mode/prompt/image，权重为 microsoft/phi-1_5 与 showlab/show-o。

## 使用要点

已验证的 WorldFoundry 路径仅 T2I——请相应设置 mode，预期产物为 generated_image。论文默认分辨率 256；封装使用 classifier-free guidance（默认 3.0）和 18 步离散扩散。权重为 MIT，位于 showlab/show-o，并记录 MAGVIT-v2 与 Phi-1.5。论文中的图像理解与编辑模式此处尚未接线。
