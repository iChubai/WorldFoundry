## What it is for

`simworld` is a world generation model.

A simulation platform interface, not a neural network.

Tasks: simulator control, multi agent simulation, and embodied policy rollout. Aliases: `simworld-ai` and `SimWorld-AI/SimWorld`.

## Runtime contract

Artifacts `world_state` and `simworld_runtime_plan.json`.

CLI task profiles: `default`. WorldFoundry binds `SimWorldPipeline`.

Family status: **Runner parity pending**.

A running simulator server is the key prerequisite. Until the required assets are staged, a run returns a runtime plan that lists what is missing.

Needs an external simulator server; no standalone generation.

## Running in WorldFoundry

Run `wf run simworld --pipeline.task-profile default` to generate the world.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

No public checkpoint is listed for this model; stage the weights as described in the usage notes. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh simworld`. Add `--download` to fetch missing public checkpoints.
