SimWorld 是模拟器控制模型而非视频生成器：通过模拟器服务器驱动多智能体具身仿真（策略滚动、世界状态），产出 world_state 产物。

## 用来做什么

`simworld` 是世界生成模型。

仿真平台接口，不是神经网络。

任务：simulator-control、multi-agent-simulation、embodied.policy_rollout。别名：`simworld-ai`、`SimWorld-AI/SimWorld`。

## 运行时契约

产物 `world_state`、`simworld_runtime_plan.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `SimWorldPipeline`。

系列状态：**Runner 一致性待确认**。

关键前置条件是一个运行中的模拟器服务器。在所需资产就位前，运行只返回列出缺失项的运行时计划。

需要外部模拟器服务器；无法独立生成。

## 在 WorldFoundry 中运行

运行 `wf run simworld --pipeline.task-profile default` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型未登记公开的 checkpoint；请按使用说明准备权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh simworld`；下载缺失的公开权重时加 `--download`。
