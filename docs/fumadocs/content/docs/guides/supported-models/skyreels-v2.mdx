SkyReels-V2 is Skywork AI's open film-generation model family built on the Wan architecture, covering text-to-video and image-to-video. WorldFoundry runs the 1.3B models on its shared native Wan graph, conditioner, VAE, scheduler, and loader.

## What it is for

`skyreels-v2` generates video from a text prompt, optionally conditioned on a still image.

SkyReels-V2's diffusion-forcing design conditions on frame rate to enable long-form generation. WorldFoundry runs it as a native Wan graph with prompt and image inputs and a generated video as output. It is published by Skywork AI (Kunlun).

Tasks: text-to-video and image-to-video. Modalities: text and image in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Standard T2V quality suite).

For the newer release, see [SkyReels V3](/docs/guides/supported-models/skyreels-v3).

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `frames`, `fps`, `steps`, `guidance-scale`, `seed`, and `shift`; artifacts `skyreels-v2.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `SkyReelsV2Pipeline`.

Family status: **Runner parity pending**.

Use the 1.3B checkpoints (Skywork/SkyReels-V2-DF-1.3B-540P for text-to-video, Skywork/SkyReels-V2-I2V-1.3B-540P for image-to-video). Larger upstream checkpoints (5B/14B) are not supported.

## Running in WorldFoundry

Run `wf run skyreels-v2 --pipeline.task-profile interactive-video` to generate the video.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Skywork/SkyReels-V2-DF-1.3B-540P`, `Skywork/SkyReels-V2-T2V-14B-720P`, and `Skywork/SkyReels-V2-I2V-1.3B-540P` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh skyreels-v2`. Add `--download` to fetch missing public checkpoints.
