SkyReels-V2 是昆仑万维 Skywork AI 基于 Wan 架构的开源影视生成模型系列，覆盖文生视频与图生视频。WorldFoundry 用共享的原生 Wan 图、条件器、VAE、调度器与加载器运行其 1.3B 模型。

## 用来做什么

`skyreels-v2` 根据文本提示词生成视频，也可以额外用一张静态图做条件。

SkyReels-V2 的 diffusion-forcing 设计以帧率为条件支撑长视频生成。WorldFoundry 将其作为原生 Wan 图运行，输入 prompt/image，输出生成视频。该模型由昆仑万维（Skywork AI）发布。

任务：文生视频、图生视频。模态上，它接受文本、图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（标准文生视频质量评测）。

更新的版本见 [SkyReels V3](/zh/docs/guides/supported-models/skyreels-v3)。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `frames`、`fps`、`steps`、`guidance-scale`、`seed`、`shift`；产物 `skyreels-v2.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `SkyReelsV2Pipeline`。

系列状态：**Runner 一致性待确认**。

请使用 1.3B checkpoint（文生视频用 Skywork/SkyReels-V2-DF-1.3B-540P，图生视频用 Skywork/SkyReels-V2-I2V-1.3B-540P）。不支持上游更大的 checkpoint（5B/14B）。

## 在 WorldFoundry 中运行

运行 `wf run skyreels-v2 --pipeline.task-profile interactive-video` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`Skywork/SkyReels-V2-DF-1.3B-540P`、`Skywork/SkyReels-V2-T2V-14B-720P`、`Skywork/SkyReels-V2-I2V-1.3B-540P` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh skyreels-v2`；下载缺失的公开权重时加 `--download`。

许可证：自定义许可（见模型卡）。
