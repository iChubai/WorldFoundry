## Architecture

Transformer, UMT5 text encoder, and VAE checkpoint schemas map exactly onto the native Wan graphs (recorded as verified). Reference conditioning concatenates reference-image latents; guidance runs dual text/image channels through the UniPC scheduler and dual-condition runner.

## Usage notes

Runner status is partial: checkpoint schema mapping is exact, and a prior official-runtime visual artifact is documented, but native visual parity still needs a GPU inference run. No Diffusers or model-owned subprocess runtime is involved.
