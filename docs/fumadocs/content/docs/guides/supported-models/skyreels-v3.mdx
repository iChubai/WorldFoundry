SkyReels V3 is Skywork's newer generation, covering reference-to-video, audio-guided video, and video-to-video. WorldFoundry runs the SkyReels-V3-R2V-14B checkpoint on the shared native Wan graph with reference-image latent concatenation and dual text/image guidance.

## What it is for

Use `skyreels-v3` to generate a video that starts from a reference image.

The transformer, UMT5 text encoder, and VAE checkpoints map exactly onto the native Wan graphs. Reference conditioning concatenates reference-image latents; guidance runs dual text/image channels through the UniPC scheduler and dual-condition runner. It is published by Skywork AI (Kunlun).

Tasks: reference-to-video, audio-guided video, video-to-video, and video generation. Modalities: image and video in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Baseline quality suite).

Not [SkyReels V2](/docs/guides/supported-models/skyreels-v2). Score on [VBench](/docs/evaluation/benchmark-hub/vbench).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `seed`, `task-type`, `duration`, and `resolution`; artifacts `skyreels-v3.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `SkyReelsV3Pipeline`.

Family status: **Runner parity pending**.

At 14B scale, plan for datacenter-class GPU memory.

WorldFoundry loads the SkyReels V3 checkpoint into the shared native Wan graph and framework-owned diffusion runner.

## Running in WorldFoundry

Animate a still image with `wf run skyreels-v3 --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Skywork/SkyReels-V3-R2V-14B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh skyreels-v3`. Add `--download` to fetch missing public checkpoints.
