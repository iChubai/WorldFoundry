SkyReels V3 是 Skywork 的新一代模型，覆盖参考图生视频、音频引导视频与视频到视频。WorldFoundry 在共享原生 Wan 图上运行 SkyReels-V3-R2V-14B checkpoint，采用参考图潜变量拼接与文本/图像双引导。

## 用来做什么

用 `skyreels-v3` 以参考图为起点生成视频。

Transformer、UMT5 文本编码器和 VAE 的 checkpoint 均与原生 Wan 图精确对应。参考条件通过拼接参考图潜变量实现；文本/图像双通道引导通过 UniPC 调度器和双条件 runner 执行。该模型由昆仑万维（Skywork AI）发布。

任务：参考图生成视频、音频引导视频、视频到视频、视频生成。模态上，它接受图像、视频，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（基础质量评测）。

不是 [SkyReels V2](/zh/docs/guides/supported-models/skyreels-v2)。评测看 [VBench](/zh/docs/evaluation/benchmark-hub/vbench)。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `seed`、`task-type`、`duration`、`resolution`；产物 `skyreels-v3.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `SkyReelsV3Pipeline`。

系列状态：**Runner 一致性待确认**。

14B 规模，需按数据中心级显存规划。

WorldFoundry 把 SkyReels V3 checkpoint 加载进共享原生 Wan 图，由框架的扩散 runner 执行。

## 在 WorldFoundry 中运行

用 `wf run skyreels-v3 --pipeline.task-profile interactive-video` 根据静态图生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`Skywork/SkyReels-V3-R2V-14B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh skyreels-v3`；下载缺失的公开权重时加 `--download`。
