## 架构

Transformer、UMT5 文本编码器与 VAE 的 checkpoint schema 与原生 Wan 图精确对应（已记录验证）。参考条件通过拼接参考图潜变量实现；引导以文本/图像双通道经 UniPC 调度器与双条件 runner 执行。

## 使用要点

runner 状态为 partial：checkpoint schema 映射精确、此前官方运行时的视觉产物有存档，但原生视觉一致性仍需一次 GPU 推理运行。不涉及 Diffusers 或模型自有的子进程运行时。
