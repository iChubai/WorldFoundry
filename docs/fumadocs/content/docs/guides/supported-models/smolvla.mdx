SmolVLA is Hugging Face / LeRobot's compact community VLA: a **SmolVLM2-500M** vision-language backbone plus a flow-matching action expert, sized for consumer hardware. The paper is [LeRobot: An Open-Source Library for End-to-End Robot Learning](https://arxiv.org/abs/2602.22818) (arXiv 2602.22818), the LeRobot library paper. Code lives in [huggingface/lerobot](https://github.com/huggingface/lerobot). Aliases `smolvla-libero`, `HuggingFaceVLA/smolvla_libero`, `smolvla-base`, and `lerobot/smolvla_base` resolve here.

There are two variants. **`smolvla-libero`** (`HuggingFaceVLA/smolvla_libero`) is the rollout default, with matching **8-D state** and **7-D action** statistics. **`smolvla-base`** (`lerobot/smolvla_base`) is a multi-robot foundation asset without a complete state-normalization contract — fine-tuning only, not a rollout path.

## What it is for

Roll out the LIBERO specialist: required `image`, `prompt`, and `state` in; `action_trace` / `smolvla_action_trace.json` out through `SmolVLAPipeline`. Two official cameras (`observation.images.image`, `observation.images.image2`). The action contract is a continuous chunk of shape **50×7**. Default launch is `wf run smolvla-libero`.

Score the LIBERO specialist on [LIBERO](/docs/evaluation/benchmark-hub/libero). Do not send `smolvla-base` through the same rollout.

Validated on GPU with the LIBERO checkpoint: with a flat 8-D state and both camera keys, **10** denoising steps return a finite **1×50×7** chunk. `smolvla-base` has not been validated.

## Runtime contract

Loading is local-only with no external source checkout. The pinned backbone is `HuggingFaceTB/SmolVLM2-500M-Video-Instruct` (the checkpoint's `SmolVLM2-500M-Instruct` id resolves to that published repo). Auto dtype is **bf16** on Ampere / Ada / Hopper / Blackwell and **fp16** on older CUDA. Masked attention goes through the shared SDPA selector.

## Running in WorldFoundry

Use the dedicated environment `worldfoundry-vla-smolvla` (Python 3.11, CUDA 12.8, `torch>=2.8`). Stage `HuggingFaceVLA/smolvla_libero` before you expect a `get_action` artifact.
