## What it is for

`solaris` is an action-conditioned world model: actions and a starting frame in, a rollout out.

The runtime is JAX-based and loads the official Orbax checkpoint. It is published by New York University (VisionX).

Tasks: video generation, multi agent world model, and interactive video generation. Aliases: `solaris-wm`. Output modalities: video.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Multi-agent world-rollout quality).

## Runtime contract

Options `eval-types`; artifacts `solaris.mp4`.

CLI task profiles: `default`. WorldFoundry binds `SolarisPipeline`.

Family status: **Verified**.

Inference launches one sample per visible GPU — eval_num_samples must be a multiple of the visible GPU count. Official weights and eval datasets resolve from HF or a same-layout local mirror.

Review the upstream license before use.

## Running in WorldFoundry

Run `wf run solaris --pipeline.task-profile default` to roll out the world model.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `nyu-visionx/solaris`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh solaris`. Add `--download` to fetch missing public checkpoints.
