## 用来做什么

`solaris` 是动作条件世界模型：输入动作和起始帧，输出推演结果。

运行时基于 JAX，加载官方 Orbax checkpoint。该模型由纽约大学（VisionX 实验室）发布。

任务：video_generation、multi-agent-world-model、交互式视频生成。别名：`solaris-wm`。输出模态为视频。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（多智能体世界滚动生成质量）。

## 运行时契约

参数 `eval-types`；产物 `solaris.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `SolarisPipeline`。

系列状态：**已验证**。

推理由已安装的 Solaris 包模块执行。runtime_root 是相对资产路径与工作目录的基准。推理按每张可见 GPU 启动一个样本——eval_num_samples 必须是可见 GPU 数的整数倍。官方权重与评估数据集从 HF 或同布局本地镜像解析。

使用前请审查上游许可。

## 在 WorldFoundry 中运行

运行 `wf run solaris --pipeline.task-profile default` 推演世界模型。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`nyu-visionx/solaris`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh solaris`；下载缺失的公开权重时加 `--download`。
