## What it is for

`solarwm-wan2.2-5b` is a world generation model.

A single WorldFoundry launcher runs the released solarwm infer route for the selected variant in its dedicated backend environment. Backbones, training code, and data pipelines come from the upstream source tree passed as source_root. It is published by Junchao-cs.

Tasks: camera-controlled video and interactive world model. Aliases: `solar-wm`, `solarwm-wan2.2-5b`, `solarwm-wan22-5b`, and `solarwm-wan2.2-14b` among others. Other variants: `solarwm-wan2.2-14b`, `solarwm-ltx-22b`, `solarwm-h3-33b`.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Long-horizon camera-controlled world consistency).

## Running in WorldFoundry

Run `wf run solarwm-wan2.2-5b --pipeline.task-profile indexed-inference` to generate the world.

It runs in the dedicated environment `worldfoundry-solarwm-wan22-cu124` (Python 3.10, CUDA 12.4, torch==2.5.1+cu124).

Weights: `junchaoh-cs/SolarWM` and `junchaoh-cs/SolarWM-H3-33B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh solarwm-wan2.2-5b`. Add `--download` to fetch missing public checkpoints.

Gated weights: `junchaoh-cs/SolarWM-H3-33B` (accept the upstream terms before downloading).
