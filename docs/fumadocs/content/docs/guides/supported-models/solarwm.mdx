SolarWM is an open data and scalable training foundation for camera-controlled, long-horizon video world models. It supports Wan2.2 5B/14B, LTX-2.5 22B, and MiniMax-H3 33B backbones; the 5B line releases the full bidirectional FM, TF-AnyFlow, and SGF progression.

## Architecture

The complete 5B route adapts Wan2.2 through Stage0.5 bidirectional flow matching, Stage1 teacher-forced AnyFlow, and Stage2 distribution matching via self-gradient forcing. The final causal model performs four-step autoregressive camera-conditioned rollout from short training clips.

## Usage notes

Stage the pinned SolarWM checkout, accept the gated Hugging Face repositories, download the Wan2.2-5B bundle and SolarWM-Data, then set source/base/checkpoint/data paths if they differ from WorldFoundry defaults. Inference consumes SolarWM dataset rows and camera trajectories; it is not a prompt-only T2V route.
