## 用来做什么

`solarwm-wan2.2-5b` 是世界生成模型。

WorldFoundry 用统一启动器为所选 variant 在对应独立环境中运行树内 solarwm infer 路线。推理代码来自 Junchao-cs/SolarWM 的 2fe1ea9a 版本，通过模型专用变体复用规范 Wan、LTX 与 MiniMax-H3 组件。该模型由 Junchao-cs 发布。

任务：相机可控视频、交互式世界模型。别名：`solar-wm`、`solarwm-wan2.2-5b`、`solarwm-wan22-5b`、`solarwm-wan2.2-14b` 等。同系列还有 `solarwm-wan2.2-14b`、`solarwm-ltx-22b`、`solarwm-h3-33b`。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（长时程相机控制下的世界一致性）。

## 运行时契约

必填 `load.base-path`、`load.data-root`；输入 `load.checkpoint-dir`（不传时使用内置示例）；参数 `execute`、`timeout-seconds`；产物 `generated_world`、`solarwm.mp4`。

CLI task profile：`indexed-inference`。绑定的 pipeline 类是 `SolarWMPipeline`。

建议从 `solarwm-wan2.2-5b` 开始。该系列共有 4 个 variant，可在上方命令构建器中切换：`solarwm-wan2.2-5b`（`camera-conditioned-video`）：Runner 一致性待确认、`solarwm-wan2.2-14b`（`camera-conditioned-video`）：Runner 一致性待确认、`solarwm-ltx-22b`（`camera-conditioned-video`）：Runner 一致性待确认、`solarwm-h3-33b`（`camera-conditioned-video`）：Runner 一致性待确认。系列状态：**Runner 一致性待确认**。

默认 variant=wan-5b-dmd，需提供 checkpoint_dir、base_path 和 data_root。提示词、图像和相机轨迹来自索引样本。Wan、LTX、H3 使用独立解释器，进程数遵循官方推理配置。

仅提供 infer 操作，不包含训练、预编码与数据引擎命令。

## 在 WorldFoundry 中运行

运行 `wf run solarwm-wan2.2-5b --pipeline.task-profile indexed-inference --pipeline.load.base-path VALUE --pipeline.load.data-root VALUE` 生成世界。

运行环境：独立环境 `worldfoundry-solarwm-wan22-cu124`（Python 3.10，CUDA 12.4，torch==2.5.1+cu124）。

权重仓库：`junchaoh-cs/SolarWM`、`junchaoh-cs/SolarWM-H3-33B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh solarwm-wan2.2-5b`；下载缺失的公开权重时加 `--download`。

gated 权重：`junchaoh-cs/SolarWM-H3-33B`（下载前需在上游接受条款）。
