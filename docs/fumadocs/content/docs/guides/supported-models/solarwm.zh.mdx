SolarWM 是面向相机控制、长时程视频世界模型的开放数据与可扩展训练基础设施，覆盖 Wan2.2 5B/14B、LTX-2.5 22B 与 MiniMax-H3 33B；其中 5B 路线完整发布了双向 FM、TF-AnyFlow 与 SGF 三阶段流程。

## 用来做什么

用 `solarwm-wan2.2-5b` 做 catalog 世界模型推理。需要动作条件未来帧、而不是独立片段生成器时选它。

完整 5B 路线以 Wan2.2 为基座，依次进行 Stage0.5 双向流匹配、Stage1 teacher-forced AnyFlow，以及 Stage2 基于 self-gradient forcing 的分布匹配；最终因果模型以四步自回归方式执行相机条件滚动生成。该模型由SolarWM 作者团队发布。

catalog 记录的任务包括 camera-conditioned-world-model、long-horizon-video-generation、交互式视频生成、camera-conditioned-long-horizon-video。别名包括 `solar-wm`、`solarwm-wan2.2-5b`、`solarwm-wan22-5b`。输出模态为视频。同系列还有 `solarwm-wan2.2-14b`、`solarwm-ltx-22b`、`solarwm-h3-33b`。

记录的评测入口包括[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（长时程相机控制下的世界一致性）。
