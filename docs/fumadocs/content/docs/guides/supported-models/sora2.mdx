Sora2 runs OpenAI's Sora 2 hosted video model for text-to-video and image-to-video. Prompts are submitted to OpenAI's API and the generated clips are stored as standard WorldFoundry artifacts, so Sora 2 output can be evaluated with the same tooling as local models. Sora cannot run locally; only the hosted API is supported.

## What it is for

Use `sora2` to call the hosted model through WorldFoundry.

OpenAI has publicly described the original Sora as a diffusion transformer operating on spacetime patches of video latents; beyond that public statement, no architecture, scale, or training details for Sora 2 are disclosed.

Tasks: text-to-video, image-to-video, and hosted api. Modalities: text and image in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Standard multi-dimension quality suite for comparing hosted text/image-to-video outputs), [Physics-IQ Original](/docs/evaluation/benchmark-hub/physics-iq) (Probes whether provider-side video models respect basic physical plausibility).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted).

CLI task profiles: `default`. WorldFoundry binds `Sora2Pipeline`.

The hosted-API Studio pipeline needs your own provider account and API key: pass api_key or set SORA2_API_KEY, SORA_API_KEY, or OPENAI_API_KEY. No weights are downloaded and no GPU environment is provisioned locally — generation happens on the provider side, so cost, quota, and content policy follow your provider account. Access requires an OpenAI account with Sora API availability in your region and tier.

Requires a paid provider account and API key; WorldFoundry does not ship credentials.

The provider controls model versioning, so outputs can change over time without any change in WorldFoundry.

## Running in WorldFoundry

Run `wf run sora2 --pipeline.task-profile default` to call the provider API.

No runtime environment is recorded for this model.

Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh sora2`. Add `--download` to fetch missing public checkpoints.
