Sora2 是 OpenAI Sora 2 托管视频模型在本 catalog 中的条目，记录了文生视频与图生视频任务。提示词提交给 OpenAI 的 API，生成的视频以标准 WorldFoundry 产物保存，使 Sora 2 的输出能够用与仓库内本地模型相同的工具链来评测。WorldFoundry 不会（也无法）在本地运行 Sora——该条目仅记录托管集成。

## 架构

OpenAI 曾公开将初代 Sora 描述为在视频潜空间时空 patch 上运行的扩散 Transformer；除这一公开表述外，Sora 2 的架构、规模与训练细节均未披露，本仓库亦未记录。

## 使用要点

Catalog 将该条目标记为 integrated：托管 API 的 Studio pipeline 已可用，但你必须自备服务方的 API key 与账号。本地不会下载任何权重、也不会创建 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。使用前需确认你的 OpenAI 账号在所在地区与订阅层级下拥有 Sora API 权限。
