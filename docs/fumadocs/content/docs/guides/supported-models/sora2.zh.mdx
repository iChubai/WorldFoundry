Sora2 调用 OpenAI 的 Sora 2 托管视频模型，支持文生视频与图生视频。提示词提交给 OpenAI 的 API，生成的视频以标准 WorldFoundry 产物保存，因此 Sora 2 的输出可以用与本地模型相同的工具链评测。Sora 无法在本地运行，仅支持托管 API。

## 用来做什么

用 `sora2` 在 WorldFoundry 中调用托管模型。

OpenAI 曾公开将初代 Sora 描述为在视频潜空间时空 patch 上运行的扩散 Transformer；除这一公开表述外，Sora 2 的架构、规模与训练细节均未披露。

任务：文生视频、图生视频、托管 API。模态上，它接受文本、图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（对比托管文/图生视频输出的标准多维质量评测）、[Physics-IQ Original](/zh/docs/evaluation/benchmark-hub/physics-iq)（检验服务方视频模型是否遵循基本物理合理性）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）。

CLI task profile：`default`。绑定的 pipeline 类是 `Sora2Pipeline`。

系列状态：**Runner 一致性待确认**。

托管 API 的 Studio pipeline 需要你自备服务方账号与 API key：传入 api_key，或设置 SORA2_API_KEY、SORA_API_KEY 或 OPENAI_API_KEY。本地不会下载任何权重、也不会创建 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。使用前需确认你的 OpenAI 账号在所在地区与订阅层级下拥有 Sora API 权限。

需要付费的服务方账号与 API key；WorldFoundry 不提供任何凭据。

## 在 WorldFoundry 中运行

运行 `wf run sora2 --pipeline.task-profile default` 调用提供商 API。

该模型未记录运行环境。

准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh sora2`；下载缺失的公开权重时加 `--download`。
