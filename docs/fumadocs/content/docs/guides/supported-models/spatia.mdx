Spatia is a camera-controlled video-to-video world model: given source video and a target camera trajectory it re-renders the scene along the new viewpoint path. WorldFoundry ships the official source and loads the Jinjing713/Spatia checkpoint, released under Apache-2.0.

## What it is for

`spatia` generates camera-controlled video: a camera trajectory in, a clip that follows it out.

Spatia builds on Wan2.2-TI2V-5B and uses MapAnything to reconstruct the source scene. A dense world-to-camera (W2C) trajectory supplies per-frame camera extrinsics that drive the re-rendering.

Tasks: camera-controlled video, video-to-video, and world model. Modalities: video in, video out.

Suggested benchmarks: [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-trajectory adherence for controlled re-rendering).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `frames`, `fps`, `height`, `width`, `steps`, `seed`, and 2 more; artifacts `spatia.mp4`.

CLI task profiles: `default`. WorldFoundry binds `SpatiaPipeline`.

Family status: **Verified**.

Defaults for `default`: frames=121, fps=24, height=704, width=1248, seed=20917.

Provide a source image or video, camera intrinsics, and a dense per-frame W2C camera trajectory. Optional mask_path passes one foreground mask matching the original source-frame size to reconstruction; set force_rebuild_intermediate when changing cached inputs. Validated with the released checkpoint: an image-input run generates 17 frames at 832x480 with 40 steps.

Spatia inference, MapAnything reconstruction and point rendering launch installed WorldFoundry package modules. Relative assets resolve from the fixed package working directory; model weights and input paths remain configurable. Cached reconstruction/render outputs and `force_rebuild_intermediate` retain the same behavior, without source-path injection.

## Running in WorldFoundry

Generate a camera-controlled clip with `wf run spatia --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Jinjing713/Spatia`, `Wan-AI/Wan2.2-TI2V-5B`, and `facebook/map-anything`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh spatia`. Add `--download` to fetch missing public checkpoints.
