Spatia 是相机控制的 video-to-video 世界模型：给定源视频与目标相机轨迹，沿新视角路径重新渲染场景。WorldFoundry 自带官方源码，加载以 Apache-2.0 许可发布的 Jinjing713/Spatia checkpoint。

## 用来做什么

`spatia` 生成相机可控视频：输入相机轨迹，输出沿轨迹运动的视频。

Spatia 基于 Wan2.2-TI2V-5B，并用 MapAnything 重建源场景。稠密 world-to-camera（W2C）轨迹提供逐帧相机外参，驱动重渲染。

任务：相机可控视频、视频到视频、世界模型。模态上，它接受视频，输出视频。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机轨迹跟随与受控重渲染质量）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`seed` 等 8 项；产物 `spatia.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `SpatiaPipeline`。

系列状态：**已验证**。

`default` 的默认值：frames=121, fps=24, height=704, width=1248, seed=20917。

提供源图像或视频、相机内参及逐帧稠密 W2C 相机轨迹。可选 mask_path 将一张与原始源帧尺寸一致的前景掩码传入重建阶段；改变缓存输入时设置 force_rebuild_intermediate。已用发布的 checkpoint 验证：图像输入运行以 40 步生成 832x480 的 17 帧视频。

Spatia 推理、MapAnything 重建与点渲染均启动已安装的 WorldFoundry 包模块。相对资源从固定包工作目录解析，模型权重与输入路径仍可配置。缓存的重建/渲染产物及 `force_rebuild_intermediate` 保持原有行为，且不依赖源码路径注入。

## 在 WorldFoundry 中运行

用 `wf run spatia --pipeline.task-profile default` 生成相机可控视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`Jinjing713/Spatia`、`Wan-AI/Wan2.2-TI2V-5B`、`facebook/map-anything`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh spatia`；下载缺失的公开权重时加 `--download`。
