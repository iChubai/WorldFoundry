Spatia 是相机控制的 video-to-video 世界模型：给定源视频与目标相机轨迹，沿新视角路径重新渲染场景。WorldFoundry 已将官方源码内置树内（revision f75b10c9），通过共享 pipeline runner 暴露， checkpoint 引用为 Jinjing713/Spatia，以 Apache-2.0 许可发布。

## 架构

树内路由接入 Spatia 推理与稠密 world-to-camera（W2C）轨迹输入：逐帧相机外参驱动重渲染。除内置源码外的架构内部细节仓库未记录。

## 使用要点

需提供源视频与逐帧稠密 W2C 相机轨迹；树内路由在执行前会校验二者。runner parity 仍为 pending，在记录 parity 运行前请将输出视为未验证。
