Spatial-Forcing aligns VLA internal representations with 3D geometry (via VGGT-style supervision) to boost manipulation precision on OpenVLA backbones. All four released OpenVLA-LIBERO checkpoints (spatial, object, goal, long; Apache-2.0) passed strict restoration and real A100 inference with finite 8x7 actions — the catalog status is all_released_checkpoints_gpu_validated.

## Architecture

Fine-tuned OpenVLA 7B checkpoints where spatial alignment was enforced during training; at inference the models run as standard OpenVLA-style policies. The inference-only runtime disables checkpoint-hosted remote code; VGGT, alignment projectors, and LoRA adapter copies are excluded.

## Usage notes

Pick the LIBERO split checkpoint you need (spatial/object/goal/long) from the official collection; only locally staged snapshots are accepted.
