Spatial-Forcing aligns VLA internal representations with 3D geometry (via VGGT-style supervision) to boost manipulation precision on OpenVLA backbones. All four released OpenVLA-LIBERO checkpoints (spatial, object, goal, long; Apache-2.0) are validated: each restores strictly and returns finite 8x7 action chunks in A100 inference.

## What it is for

`spatial-forcing-libero-spatial` is a vision-language-action policy: an instruction and observations in, actions out.

Fine-tuned OpenVLA 7B checkpoints where spatial alignment was enforced during training; at inference the models run as standard OpenVLA-style policies. The inference-only runtime disables checkpoint-hosted remote code; VGGT, alignment projectors, and LoRA adapter copies are excluded.

Tasks: VLA, VLA action prediction, and VLA policy rollout. Aliases: `spatial_forcing` and `spatial-forcing-openvla`. Other variants: `spatial-forcing-libero-object`, `spatial-forcing-libero-goal`, `spatial-forcing-libero-10`.

Suggested benchmarks: [LIBERO](/docs/evaluation/benchmark-hub/libero) (The four released checkpoints are fine-tuned for the LIBERO spatial, object, goal, and long suites).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `wrist-image`, `state`, `task-suite-name`, `unnorm-key`, `torch-dtype`, `attn-implementation`, and 1 more; artifacts `action_trace` and `spatial-forcing_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `SpatialForcingPipeline`.

Start with `spatial-forcing-libero-spatial`. The family has 4 variants, selectable in the command builder above: `spatial-forcing-libero-spatial` (`vla.policy_rollout`) — Verified; `spatial-forcing-libero-object` (`vla.policy_rollout`) — Verified; `spatial-forcing-libero-goal` (`vla.policy_rollout`) — Verified; `spatial-forcing-libero-10` (`vla.policy_rollout`) — Verified. Family status: **Verified**.

Pick the LIBERO split checkpoint you need (spatial/object/goal/long) from the official collection; only locally staged snapshots are accepted.

Released checkpoints are LIBERO fine-tunes; other embodiments need retraining.

## Running in WorldFoundry

Run `wf run spatial-forcing-libero-spatial --pipeline.task-profile default` to predict actions.

It runs in the dedicated environment `worldfoundry-vla-spatial-forcing-cu121` (Python 3.10, CUDA 12.1, torch==2.2.0).

Weights: `haofuly/spatial-forcing-7b-finetuned-libero-spatial`, `haofuly/spatial-forcing-7b-finetuned-libero-object`, and `haofuly/spatial-forcing-7b-finetuned-libero-goal` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh spatial-forcing-libero-spatial`. Add `--download` to fetch missing public checkpoints.
