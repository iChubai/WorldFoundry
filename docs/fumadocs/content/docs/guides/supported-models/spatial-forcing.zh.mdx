Spatial-Forcing 将 VLA 内部表征与 3D 几何对齐（借助 VGGT 式监督），提升 OpenVLA 骨干的操作精度。四个已发布 OpenVLA-LIBERO checkpoint（spatial、object、goal、long；Apache-2.0）均已验证：严格恢复后在 A100 推理中输出有限的 8x7 动作块。

## 用来做什么

`spatial-forcing-libero-spatial` 是视觉-语言-动作（VLA）策略：输入指令和观测，输出动作。

训练期施加空间对齐的 OpenVLA 7B 微调 checkpoint；推理时按标准 OpenVLA 式策略运行。推理专用运行时禁用 checkpoint 携带的远程代码；VGGT、对齐投影器与 LoRA 适配器副本被排除。

任务：视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行。别名：`spatial_forcing`、`spatial-forcing-openvla`。同系列还有 `spatial-forcing-libero-object`、`spatial-forcing-libero-goal`、`spatial-forcing-libero-10`。

推荐评测：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（四个发布的 checkpoint 分别针对 LIBERO 的 spatial、object、goal、long 套件微调）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `wrist-image`、`state`、`task-suite-name`、`unnorm-key`、`torch-dtype`、`attn-implementation` 等 7 项；产物 `action_trace`、`spatial-forcing_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `SpatialForcingPipeline`。

建议从 `spatial-forcing-libero-spatial` 开始。该系列共有 4 个 variant，可在上方命令构建器中切换：`spatial-forcing-libero-spatial`（`vla.policy_rollout`）：已验证、`spatial-forcing-libero-object`（`vla.policy_rollout`）：已验证、`spatial-forcing-libero-goal`（`vla.policy_rollout`）：已验证、`spatial-forcing-libero-10`（`vla.policy_rollout`）：已验证。系列状态：**已验证**。

从官方 collection 中按需选择 LIBERO 子集 checkpoint（spatial/object/goal/long）；仅接受本地就位的快照。

发布的 checkpoint 为 LIBERO 微调版；其他本体需重新训练。

## 在 WorldFoundry 中运行

运行 `wf run spatial-forcing-libero-spatial --pipeline.task-profile default` 预测动作。

运行环境：独立环境 `worldfoundry-vla-spatial-forcing-cu121`（Python 3.10，CUDA 12.1，torch==2.2.0）。

权重仓库：`haofuly/spatial-forcing-7b-finetuned-libero-spatial`、`haofuly/spatial-forcing-7b-finetuned-libero-object`、`haofuly/spatial-forcing-7b-finetuned-libero-goal` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh spatial-forcing-libero-spatial`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
