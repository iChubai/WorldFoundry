## 用来做什么

`spatial-ladder` 回答关于多模态输入的问题。

3B 参数的视觉-语言模型；其渐进式空间推理训练设计见上游说明。

任务：多模态推理、空间推理、图像问答、视频问答。别名：`spatial_ladder`、`hongxingli/SpatialLadder-3B`。

## 运行时契约

输入 `prompt`、`image`、`video`；产物 `spatial-ladder.json`。

CLI task profile：`multimodal-reasoning`、`spatial-reasoning`、`image-question-answering`、`video-question-answering`、`video_generation`。绑定的 pipeline 类是 `SpatialLadderPipeline`。

系列状态：**Runner 一致性待确认**。

可作为生成场景的轻量空间问答评审；3B 规模在一般 GPU 上即可运行。

## 在 WorldFoundry 中运行

运行 `wf run spatial-ladder --pipeline.task-profile multimodal-reasoning` 得到推理结果。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`hongxingli/SpatialLadder-3B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh spatial-ladder`；下载缺失的公开权重时加 `--download`。
