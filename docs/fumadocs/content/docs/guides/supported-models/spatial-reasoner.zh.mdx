SpatialReasoner 是约翰斯·霍普金斯大学 CCVL 组的视觉-语言模型，专注对图像与视频进行显式、分步的空间推理。它支持空间与多模态推理以及图像/视频问答，返回 model_response 产物。

## 用来做什么

`spatial-reasoner` 回答关于多模态输入的问题。

带显式 3D 感知空间推理阶段的视觉-语言模型（见上游 ccvl/SpatialReasoner 发布）。输入为 prompt 加图像或视频。该模型由约翰斯·霍普金斯大学（CCVL 实验室）发布。

任务：多模态推理、空间推理、图像问答、视频问答。别名：`spatial_reasoner`、`ccvl/SpatialReasoner`。

## 运行时契约

输入 `prompt`、`image`、`video`；产物 `spatial-reasoner.json`。

CLI task profile：`multimodal-reasoning`、`spatial-reasoning`、`image-question-answering`、`video-question-answering`、`video_generation`。绑定的 pipeline 类是 `SpatialReasonerPipeline`。

系列状态：**Runner 一致性待确认**。

可与生成模型配合，审查生成世界的空间一致性——例如物体位置与相对深度。

## 在 WorldFoundry 中运行

用 `wf run spatial-reasoner --pipeline.task-profile multimodal-reasoning` 运行模型。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`ccvl/SpatialReasoner`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh spatial-reasoner`；下载缺失的公开权重时加 `--download`。
