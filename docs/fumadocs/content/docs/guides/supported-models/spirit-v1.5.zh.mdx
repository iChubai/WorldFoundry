## 用来做什么

`spirit-v1.5` 是视觉-语言-动作（VLA）策略：输入指令和观测，输出动作。

Qwen3-VL 视觉-语言骨干配 Spirit 的动作预测头。

任务：VLA 动作预测、VLA 策略执行。别名：`spirit-vla`、`spirit-v1p5`、`spirit_v1p5`。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`spirit-v1.5_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `SpiritV15Pipeline`。

系列状态：**Runner 一致性待确认**。

运行前需在本地就位 21.6 GB 的 Spirit-v1.5 checkpoint 与 Qwen/Qwen3-VL-4B-Instruct 骨干。

许可证条款未注明，使用前请查看上游发布。
