## What it is for

Use `splatt3r` for feed-forward 3D reconstruction from the input views.

Per the paper (arXiv 2408.13912), Splatt3R builds on MASt3R's two-view geometry backbone and adds a Gaussian-parameter head. The WorldFoundry runtime is inference-only. It is published by University of Oxford (Active Vision Lab).

Tasks: 3D reconstruction and gaussian splatting. Aliases: `splattr` and `splatt3r-official`.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); artifacts `splatt3r.ply`.

CLI task profiles: `default`. WorldFoundry binds `Splatt3RPipeline`.

Family status: **Verified**.

Input is an uncalibrated image pair; output is a PLY Gaussian-splat file. Stage the brandonsmart/splatt3r_v1.0 checkpoint before running.

Two-view input: large scenes need multiple pairs and external merging.

## Running in WorldFoundry

Run `wf run splatt3r --pipeline.task-profile default` to write the geometry.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 11.3).

Weights: `brandonsmart/splatt3r_v1.0`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh splatt3r`. Add `--download` to fetch missing public checkpoints.
