Splatt3R 直接从未标定的图像对预测 3D 高斯泼溅场景——零样本、无需相机参数、无需逐场景优化。已用发布权重验证：在内置示例视图上的 GPU 推理生成含 344,064 个高斯的 PLY。

## 用来做什么

用 `splatt3r` 从输入视图做前馈 3D 重建。

按论文（arXiv 2408.13912），Splatt3R 在 MASt3R 的双视图几何主干上增加高斯参数头。WorldFoundry 中的运行时仅含推理。该模型由牛津大学（Active Vision Lab）发布。

任务：3D 重建、高斯泼溅。别名：`splattr`、`splatt3r-official`。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；产物 `splatt3r.ply`。

CLI task profile：`default`。绑定的 pipeline 类是 `Splatt3RPipeline`。

系列状态：**已验证**。

输入为未标定的图像对，输出为 PLY 高斯泼溅文件。运行前请先就位 brandonsmart/splatt3r_v1.0 checkpoint。

双视图输入：大场景需要多对图像并在外部合并。

## 在 WorldFoundry 中运行

运行 `wf run splatt3r --pipeline.task-profile default` 写出几何结果。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 11.3）。

权重仓库：`brandonsmart/splatt3r_v1.0`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh splatt3r`；下载缺失的公开权重时加 `--download`。
