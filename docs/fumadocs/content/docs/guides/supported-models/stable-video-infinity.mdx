Stable Video Infinity 2.0 (SVI) generates arbitrarily long videos by chaining clips with five-frame continuation and per-clip seed changes, driven by prompt streams. Validated with the default settings on an A100: two linked 81-frame clips at 832x544 form a 157-frame H.264 video that matches the official runtime at 31.03 dB PSNR under identical settings.

## What it is for

Use `stable-video-infinity` to generate a video that starts from a reference image.

SVI 2.0 is a LoRA on top of Wan2.1-I2V-14B-480P that keeps five-frame continuation, reference-frame padding, and prompt-stream repetition. Loading fails unless every LoRA pair in the released checkpoint merges into the Wan DiT. It is published by EPFL (VITA lab).

Tasks: image-to-video, long video generation, and prompt stream video generation. Aliases: `SVI`, `SVI-2.0`, `stable_video_infinity`, and `stable-video-infinity-2.0`. Modalities: image in, video out.

Suggested benchmarks: [ChronoMagic-Bench](/docs/evaluation/benchmark-hub/chronomagic-bench) (Long-horizon suite matching SVI's infinite-video goal), [VBench](/docs/evaluation/benchmark-hub/vbench) (Per-clip quality yardstick).

## Runtime contract

Inputs `prompt` and `image` (bundled samples are used when omitted); options `num-clips`, `num-frames`, `num-motion-frames`, `num-inference-steps`, `cfg-scale-text`, `seed`, and 4 more; artifacts `generated_video` and `stable-video-infinity.mp4`.

CLI task profiles: `prompt-stream-i2v`. WorldFoundry binds `StableVideoInfinityPipeline`.

Family status: **Verified**.

Defaults for `prompt-stream-i2v`: seed=0, fps=24.

Defaults follow the official recipe: five-motion-frame continuation, full reference padding, each clip a distinct seed, prompts repeated twice before advancing. The official 999-clip cap is bounded to two clips per prompt unless use_first_prompt_only is enabled. Stage both the SVI LoRA (vita-video-gen/svi-model, MIT) and the Wan2.1 base.

## Running in WorldFoundry

Animate a still image with `wf run stable-video-infinity --pipeline.task-profile prompt-stream-i2v`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch>=2.5).

Weights: `vita-video-gen/svi-model`, `Wan-AI/Wan2.1-I2V-14B-480P`, and `epfl-vita/svi-model`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh stable-video-infinity`. Add `--download` to fetch missing public checkpoints.
