## Architecture

SVI 2.0 is a LoRA on top of Wan2.1-I2V-14B-480P: the adapter reuses WorldFoundry's canonical Wan components and staged runner, preserving five-frame continuation, reference-frame padding, and prompt-stream repetition. Released training-pipeline LoRA keys are normalized to bare Wan DiT module names, and loading fails unless every discovered LoRA pair merges.

## Usage notes

Defaults follow the official recipe: five-motion-frame continuation, full reference padding, each clip a distinct seed, prompts repeated twice before advancing. The official 999-clip cap is bounded to two clips per prompt unless use_first_prompt_only is enabled. Stage both the SVI LoRA (vita-video-gen/svi-model, MIT) and the Wan2.1 base.
