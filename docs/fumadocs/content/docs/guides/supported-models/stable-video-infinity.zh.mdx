Stable Video Infinity 2.0（SVI）通过五帧续接与逐段换种子来串联视频段，由提示词流驱动，可生成任意长度的视频。已在 A100 上以默认设置验证：两段相接的 81 帧 832x544 视频组成 157 帧 H.264 视频，与官方运行时在相同设置下对比达到 31.03 dB PSNR。

## 用来做什么

用 `stable-video-infinity` 以参考图为起点生成视频。

SVI 2.0 是叠加在 Wan2.1-I2V-14B-480P 上的 LoRA，保留五帧续接、参考帧填充与提示词流重复机制。发布 checkpoint 中任一 LoRA 对未能合并到 Wan DiT 时，加载即失败。该模型由洛桑联邦理工学院（EPFL VITA 实验室）发布。

任务：图生视频、长视频生成、prompt-stream-video-generation。别名：`SVI`、`SVI-2.0`、`stable_video_infinity`、`stable-video-infinity-2.0`。模态上，它接受图像，输出视频。

推荐评测：[ChronoMagic-Bench](/zh/docs/evaluation/benchmark-hub/chronomagic-bench)（长时程评测，契合 SVI 的无限长视频目标）、[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（单段质量标尺）。

## 运行时契约

输入 `prompt`、`image`（不传时使用内置示例）；参数 `num-clips`、`num-frames`、`num-motion-frames`、`num-inference-steps`、`cfg-scale-text`、`seed` 等 10 项；产物 `generated_video`、`stable-video-infinity.mp4`。

CLI task profile：`prompt-stream-i2v`。绑定的 pipeline 类是 `StableVideoInfinityPipeline`。

系列状态：**已验证**。

`prompt-stream-i2v` 的默认值：seed=0, fps=24。

默认值遵循官方配方：五运动帧续接、完整参考帧填充、每段独立种子、每条提示词重复两次后推进。除非启用 use_first_prompt_only，官方 999 段上限被限定为每条提示词两段。需同时就位 SVI LoRA（vita-video-gen/svi-model，MIT）与 Wan2.1 基座。

## 在 WorldFoundry 中运行

用 `wf run stable-video-infinity --pipeline.task-profile prompt-stream-i2v` 把静态图转化为视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch>=2.5）。

权重仓库：`vita-video-gen/svi-model`、`Wan-AI/Wan2.1-I2V-14B-480P`、`epfl-vita/svi-model`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh stable-video-infinity`；下载缺失的公开权重时加 `--download`。
