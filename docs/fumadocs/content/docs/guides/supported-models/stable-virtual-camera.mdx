## What it is for

`stable-virtual-camera` estimates scene geometry from the input views.

Per the paper (arXiv 2503.14489), a multi-view diffusion model generates target views at sampled camera poses in a two-pass procedural manner, trading generality across trajectories for consistency.

Tasks: generative novel view synthesis with camera control. Aliases: `SEVA`.

Suggested benchmarks: [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Evaluates camera-path control quality of generated views).
