## What it is for

Use `stable-virtual-camera` for catalog geometry inference. Choose it when the artifact is a reconstruction, not a generated video.

Per the paper (arXiv 2503.14489), a multi-view diffusion model generates target views at sampled camera poses in a two-pass procedural manner, trading generality across trajectories for consistency. Details beyond the recorded tasks are not stored in this repository.

Catalog tasks include generative novel view synthesis with camera control. Catalog aliases include `SEVA`.

Recorded evaluation entry points include [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Evaluates camera-path control quality of generated views).
