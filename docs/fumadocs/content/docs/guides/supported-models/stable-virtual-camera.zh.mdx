## 用来做什么

`stable-virtual-camera` 根据输入视图估计场景几何。

按论文（arXiv 2503.14489），多视角扩散模型以两阶段程序化方式在采样相机位姿处生成目标视图，在轨迹通用性与一致性之间取得平衡。

任务：generative novel view synthesis with camera control。别名：`SEVA`。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（评估生成视图的相机路径控制质量）。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `steps`、`seed`、`version`、`task`、`pretrained-model-name-or-path`、`weight-name` 等 10 项；产物 `generated_video`、`stable_virtual_camera.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `StableVirtualCameraPipeline`。

系列状态：**Runner 一致性待确认**。

`default` 的默认值：seed=23。

运行前请在 Hugging Face 接受 gated checkpoint 条款并设置 HF_TOKEN。适配器驱动上游 demo.py 的 Fire 入口。

## 在 WorldFoundry 中运行

运行 `wf run stable-virtual-camera --pipeline.task-profile default` 写出几何结果。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`stabilityai/stable-virtual-camera`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh stable-virtual-camera`；下载缺失的公开权重时加 `--download`。

gated 权重：`stabilityai/stable-virtual-camera`（下载前需在上游接受条款）。
