StarVLA is a Lego-like modular VLA framework. Validated with the Qwen3-VL-OFT-LIBERO-4in1 checkpoint and the Qwen3-VL-4B base VLM: the official QwenOFT predict_action runs on an 80GB GPU. A Wan2.2-based WM4A world-action checkpoint is also available.

## What it is for

`starvla-qwen3-vl-oft-libero-4in1` is a vision-language-action policy: an instruction and observations in, actions out.

The validated path is QwenOFT: a Qwen3-VL-4B backbone with OFT-style parallel action decoding, fine-tuned on four LIBERO suites in one checkpoint (4in1). The WM4A variant couples the policy with a Wan2.2 world model.

Tasks: VLA, WAM, VLA policy rollout, and WAM world action modeling. Aliases: `Qwen3-VL-OFT-LIBERO-4in1` and `WM4A-Wan2d2-OFT-LIBERO-4in1`. Other variants: `starvla-wm4a-wan2d2-oft-libero-4in1`.

Suggested benchmarks: [LIBERO](/docs/evaluation/benchmark-hub/libero) (The 4in1 checkpoint covers four LIBERO suites).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `checkpoint-dir`, `base-vlm`, `source-repo-dir`, `enable-official-runtime`, and `attn-implementation`; artifacts `action_trace` and `starvla_action_trace.json`.

CLI task profiles: `interactive-video`. WorldFoundry binds `StarVLAPipeline`.

Start with `starvla-qwen3-vl-oft-libero-4in1`. The family has 2 variants, selectable in the command builder above: `starvla-qwen3-vl-oft-libero-4in1` (`vla.policy_rollout`) — Runner parity pending; `starvla-wm4a-wan2d2-oft-libero-4in1` (`wam.world_action_modeling`) — Runner parity pending. Family status: **Verified**.

Use the QwenOFT 4in1 checkpoint for LIBERO evaluation, and stage the Qwen3-VL-4B-Instruct base alongside the policy checkpoint.

Only the QwenOFT route is validated on GPU; the WM4A world-action route has load checks only.

## Running in WorldFoundry

Run `wf run starvla-qwen3-vl-oft-libero-4in1 --pipeline.task-profile interactive-video` to predict actions.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `StarVLA/Qwen3-VL-OFT-LIBERO-4in1`, `StarVLA/WM4A-Wan2d2-OFT-LIBERO-4in1`, and `Qwen/Qwen3-VL-4B-Instruct` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh starvla-qwen3-vl-oft-libero-4in1`. Add `--download` to fetch missing public checkpoints.
