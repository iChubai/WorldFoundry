## 用来做什么

`starvla-qwen3-vl-oft-libero-4in1` 是视觉-语言-动作（VLA）策略：输入指令和观测，输出动作。

已验证路径为 QwenOFT：Qwen3-VL-4B 骨干配 OFT 式并行动作解码，单 checkpoint 微调四个 LIBERO 套件（4in1）。WM4A 变体将策略与 Wan2.2 世界模型耦合。

任务：视觉-语言-动作（VLA）、wam、VLA 策略执行、wam.world_action_modeling。别名：`Qwen3-VL-OFT-LIBERO-4in1`、`WM4A-Wan2d2-OFT-LIBERO-4in1`。同系列还有 `starvla-wm4a-wan2d2-oft-libero-4in1`。

推荐评测：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（4in1 checkpoint 覆盖四个 LIBERO 套件）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `checkpoint-dir`、`base-vlm`、`source-repo-dir`、`enable-official-runtime`、`attn-implementation`；产物 `action_trace`、`starvla_action_trace.json`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `StarVLAPipeline`。

建议从 `starvla-qwen3-vl-oft-libero-4in1` 开始。该系列共有 2 个 variant，可在上方命令构建器中切换：`starvla-qwen3-vl-oft-libero-4in1`（`vla.policy_rollout`）：Runner 一致性待确认、`starvla-wm4a-wan2d2-oft-libero-4in1`（`wam.world_action_modeling`）：Runner 一致性待确认。系列状态：**已验证**。

LIBERO 评测用 QwenOFT 4in1 checkpoint，并与 Qwen3-VL-4B-Instruct 基座一同就位。

仅 QwenOFT 路径通过 GPU 验证；WM4A 世界-动作路径只做过加载检查。

## 在 WorldFoundry 中运行

运行 `wf run starvla-qwen3-vl-oft-libero-4in1 --pipeline.task-profile interactive-video` 预测动作。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`StarVLA/Qwen3-VL-OFT-LIBERO-4in1`、`StarVLA/WM4A-Wan2d2-OFT-LIBERO-4in1`、`Qwen/Qwen3-VL-4B-Instruct` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh starvla-qwen3-vl-oft-libero-4in1`；下载缺失的公开权重时加 `--download`。
