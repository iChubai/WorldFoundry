StarVLA 是乐高式模块化 VLA 框架；本 catalog 条目已 GPU 验证：官方 QwenOFT predict_action 在 80GB CUDA GPU 上以本地 Qwen3-VL-OFT-LIBERO-4in1 checkpoint 与 Qwen3-VL-4B 基座 VLM 运行。另有基于 Wan2.2 的 WM4A 世界-动作 checkpoint 已就位并通过张量/导入探针，但未被策略运行提升状态。

## 架构

已验证路径为 QwenOFT：Qwen3-VL-4B 骨干配 OFT 式并行动作解码，单 checkpoint 微调四个 LIBERO 套件（4in1）。WM4A 变体将策略与 Wan2.2 世界模型耦合，目前仅探针级验证。

## 使用要点

LIBERO 评测用 QwenOFT 4in1 checkpoint；WM4A 视为已就位但未验证。策略 checkpoint 需与 Qwen3-VL-4B-Instruct 基座一同就位。
