StarWM 是面向星际争霸类环境的多智能体世界模型：在大量交互单位下预测动作条件的游戏视频。WorldFoundry 内置官方离线推理客户端；作业通过 OpenAI 兼容的 StarWM 端点交互，使用官方 prompt fixture 格式。checkpoint 为 Hugging Face 上的 yxzhang2024/StarWM。

## 用来做什么

用 `starwm` 以动作推进世界并渲染出相应画面。

运行时为端点-客户端设计：路由构建官方 run_inference_client.py 命令，执行前校验 input_file、mode 与 served_model_id/api_model_id。

任务：multi-agent-world-model、starcraft-world-model、动作条件视频。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件游戏世界滚动生成质量）。

## 运行时契约

输入 `load.input-file`、`load.served-model-id`（不传时使用内置示例）；参数 `plan-only`、`timeout-seconds`；产物 `generated_world`、`starwm_predictions.jsonl`。

CLI task profile：`starcraft-offline-client`。绑定的 pipeline 类是 `StarWMPipeline`。

系列状态：**Runner 一致性待确认**。

真实生成需要一个运行中的 OpenAI 兼容 StarWM 端点；WorldFoundry 路由只负责构建并校验客户端命令。

依赖外部部署的 StarWM 端点；无法独立运行。

## 在 WorldFoundry 中运行

用 `wf run starwm --pipeline.task-profile starcraft-offline-client` 推进世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`yxzhang2024/StarWM`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh starwm`；下载缺失的公开权重时加 `--download`。
