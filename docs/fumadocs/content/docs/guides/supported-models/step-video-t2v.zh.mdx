text → video

Step-Video-T2V 是阶跃星辰的大规模开源文生视频模型（上游 300 亿参数，MIT 权重位于 stepfun-ai/stepvideo-t2v）。在 WorldFoundry 中，公开 pipeline 由原生角色化组件与共享扩散 runner 装配—— DiT、Step-LLM 文本编码器、CLIP、调度器、潜变量初始化与 VAE 解码全部进程内执行。

## 架构

上游：30B DiT，配深压缩 Video-VAE（空间 16x16、时间 8x）与双语文本编码器。本仓库中值得注意的工程事实是原生重装配：原 xFuser 与 caption/VAE HTTP 服务运行时不再是后端——runner 状态记录原生 checkpoint 布局已验证。

## 使用要点

原生 checkpoint 布局已验证；完整 GPU 产物一致性尚未记录。请使用 id step-video-t2v。30B 规模需要充足显存或多卡配置。
