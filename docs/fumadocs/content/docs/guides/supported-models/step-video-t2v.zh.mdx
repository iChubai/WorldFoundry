## 用来做什么

`step-video-t2v` 根据文本提示词生成视频。

上游：30B DiT，配深压缩 Video-VAE（空间 16x16、时间 8x）与双语文本编码器。

任务：文生视频、视频生成。别名：`step-video`、`stepvideo-t2v`、`step_video_t2v`。模态上，它接受文本，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（标准开源文生视频质量评测）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`guidance-scale` 等 7 项；产物 `generated_video`、`step_video_t2v.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `StepVideoT2VPipeline`。

系列状态：**已验证**。

`interactive-video` 的默认值：frames=204, fps=25, height=544, width=992。

已用发布的 checkpoint 验证：一个提示词在 GPU 上以 50 步生成 992x544、204 帧的视频。请使用 id step-video-t2v。30B 规模需要充足显存或多卡配置。

## 在 WorldFoundry 中运行

运行 `wf run step-video-t2v --pipeline.task-profile interactive-video` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`stepfun-ai/stepvideo-t2v`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh step-video-t2v`；下载缺失的公开权重时加 `--download`。
