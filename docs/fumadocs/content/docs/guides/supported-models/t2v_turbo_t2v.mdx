T2V-Turbo is a fast text-to-video model distilled from VideoCrafter2 with consistency distillation plus reward feedback, generating watchable clips in 4-8 steps.

## What it is for

`t2v_turbo_t2v` generates a video clip from a text prompt.

It is published by University of California, Santa Barbara.

Tasks: text-to-video. Aliases: `t2v-turbo-t2v` and `t2v-turbo`. Modalities: text in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (T2V-Turbo was tuned for exactly this suite's dimensions).

## Runtime contract

Optional `prompt`, `frames`, `fps`, `height`, and `width`.

CLI task profiles: `interactive-video`. WorldFoundry binds `T2VTurboT2VPipeline`.

Family status: **Static load only**.

Stage both the VideoCrafter2 base (VideoCrafter/VideoCrafter2) and the T2V-Turbo VC2 LoRA (jiachenli-ucsb/T2V-Turbo-VC2). Use it when you need many quick T2V drafts rather than maximum quality.

## Running in WorldFoundry

Generate a clip with `wf run t2v_turbo_t2v --pipeline.task-profile interactive-video`.

No runtime environment is recorded for this model.

Weights: `jiachenli-ucsb/T2V-Turbo-VC2` and `VideoCrafter/VideoCrafter2`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh t2v_turbo_t2v`. Add `--download` to fetch missing public checkpoints.
