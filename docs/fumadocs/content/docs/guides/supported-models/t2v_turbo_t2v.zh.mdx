T2V-Turbo 是从 VideoCrafter2 蒸馏出的快速文生视频模型，结合一致性蒸馏与奖励反馈，4-8 步即可生成可看的视频。

## 用来做什么

`t2v_turbo_t2v` 根据文本提示词生成视频。

基座：VideoCrafter2 的 U-Net 潜空间视频扩散。之上：以混合奖励反馈训练的一致性蒸馏 LoRA（见论文 arXiv 2405.18750）。该模型由加州大学圣塔芭芭拉分校（UCSB）发布。

任务：文生视频。别名：`t2v-turbo-t2v`、`t2v-turbo`。模态上，它接受文本，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（T2V-Turbo 的优化目标正是该评测的各维度）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`guidance-scale` 等 8 项。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `T2VTurboT2VPipeline`。

系列状态：**仅静态加载**。

`interactive-video` 的默认值：frames=16, fps=8, height=320, width=512, seed=0。

需同时就位 VideoCrafter2 基座（VideoCrafter/VideoCrafter2）与 T2V-Turbo VC2 LoRA（jiachenli-ucsb/T2V-Turbo-VC2）。适合需要大量快速文生视频草稿、而非极致质量的场景。

## 在 WorldFoundry 中运行

用 `wf run t2v_turbo_t2v --pipeline.task-profile interactive-video` 生成视频。

该模型未记录运行环境。

权重仓库：`jiachenli-ucsb/T2V-Turbo-VC2`、`VideoCrafter/VideoCrafter2`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh t2v_turbo_t2v`；下载缺失的公开权重时加 `--download`。
