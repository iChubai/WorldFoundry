TD-MPC (Temporal Difference Model Predictive Control) is a classic model-based RL algorithm: it learns a latent dynamics model and plans actions by combining short-horizon MPC with a learned terminal value function. The catalog sources the concrete official repository — not the generic LeRobot policy zoo — and routes it through an in-tree action runtime adapter.

## What it is for

Use `tdmpc` for vision-language-action inference on this card. The recipe exists so you can launch the recorded policy profile.

A task-oriented latent dynamics model (TOLD) plus value/policy heads; planning combines the cross-entropy method over the latent model with TD-learned values. Further internals are not recorded in this repository.

Catalog tasks include model predictive control, robot policy, and policy rollout. Catalog aliases include `td-mpc` and `temporal-difference-mpc`.
