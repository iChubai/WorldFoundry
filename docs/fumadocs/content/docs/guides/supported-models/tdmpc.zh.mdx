TD-MPC（时序差分模型预测控制）是经典的基于模型强化学习算法：学习隐式动力学模型，将短程 MPC 与学习到的终端价值函数结合来规划动作。catalog 采用具体官方仓库为源——而非通用 LeRobot 策略库——并经树内动作运行时适配器路由。

## 用来做什么

用 `tdmpc` 做本卡的视觉-语言-动作推理。这条配方用来启动已记录的策略 profile。

任务导向隐式动力学模型（TOLD）加价值/策略头；规划将隐式模型上的交叉熵方法与 TD 学习的价值结合。更多内部细节仓库未记录。

catalog 记录的任务包括 model_predictive_control、机器人策略、策略执行。别名包括 `td-mpc`、`temporal-difference-mpc`。

## 运行时契约

必填 `image`、`state`；可选 `model_id` (tdmpc)、`prompt`、`policy_family`、`action_representation`；产物 `action_trace`、`tdmpc_action_trace.json`。

记录的任务 profile：`model_predictive_control`、`robot_policy`、`policy_rollout`。绑定的 pipeline 类是 `TDMPCPipeline`。

## 在 WorldFoundry 中运行

启动 `worldfoundry-eval run tdmpc --pipeline.task-profile model_predictive_control` 执行策略。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `worldfoundry-eval run`。

运行环境是统一 profile `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。
