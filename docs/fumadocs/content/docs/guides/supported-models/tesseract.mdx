TesserAct is an embodied 4D world model for robotics: it predicts action-conditioned video of manipulation scenes with temporally consistent geometry. It is one of the WorldArena open-source world models; weights are published as anyeZHY/tesseract on Hugging Face.

## What it is for

`tesseract` generates future frames conditioned on actions.

The pipeline runs the official RGB-depth-normal SFT transformer (anyeZHY/tesseract) on a local CogVideoX-5b-I2V base model through the official inference entrypoint. It is published by University of Massachusetts Amherst (Embodied AGI Lab).

Tasks: embodied world model, robotics world model, and action-conditioned video. Aliases: `tesser-act`.

Suggested benchmarks: [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) (Embodied manipulation world-model quality), [WorldArena](/docs/evaluation/benchmark-hub/worldarena) (Listed among WorldArena open-source world models).

## Runtime contract

Inputs `input-path`, `prompt`, `load.checkpoint-dir`, and `load.base-model-dir` (bundled samples are used when omitted); options `geometry-mode`, `height`, `width`, `num-frames`, `num-inference-steps`, `guidance-scale`, and 8 more; artifacts `tesseract.mp4`.

CLI task profiles: `robot-action-video`. WorldFoundry binds `TesserActPipeline`.

Family status: **Runner parity pending**.

Defaults for `robot-action-video`: height=256, width=320, fps=8, seed=23.

Stage anyeZHY/tesseract, THUDM/CogVideoX-5b-I2V, and the embodied task assets locally; until they are staged, the pipeline returns diagnostics that list what is missing.

## Running in WorldFoundry

Step the world with `wf run tesseract --pipeline.task-profile robot-action-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `anyeZHY/tesseract` and `THUDM/CogVideoX-5b-I2V`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh tesseract`. Add `--download` to fetch missing public checkpoints.
