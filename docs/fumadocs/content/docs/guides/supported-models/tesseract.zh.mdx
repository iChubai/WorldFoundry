TesserAct 是面向机器人的具身 4D 世界模型：预测操作场景的动作条件视频，并保持时序一致的几何。它是 WorldArena 收录的开源世界模型之一；权重发布在 Hugging Face 的 anyeZHY/tesseract。

## 用来做什么

`tesseract` 以动作为条件生成未来帧。

pipeline 通过官方推理入口，在本地 CogVideoX-5b-I2V 基座上运行官方 RGB-深度-法线 SFT transformer（anyeZHY/tesseract）。该模型由马萨诸塞大学阿默斯特分校（Embodied AGI 实验室）发布。

任务：具身世界模型、机器人世界模型、动作条件视频。别名：`tesser-act`。

推荐评测：[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（具身操作世界模型质量）、[WorldArena](/zh/docs/evaluation/benchmark-hub/worldarena)（WorldArena 开源世界模型榜单收录）。

## 运行时契约

输入 `input-path`、`prompt`、`load.checkpoint-dir`、`load.base-model-dir`（不传时使用内置示例）；参数 `geometry-mode`、`height`、`width`、`num-frames`、`num-inference-steps`、`guidance-scale` 等 14 项；产物 `tesseract.mp4`。

CLI task profile：`robot-action-video`。绑定的 pipeline 类是 `TesserActPipeline`。

系列状态：**Runner 一致性待确认**。

`robot-action-video` 的默认值：height=256, width=320, fps=8, seed=23。

先在本地准备 anyeZHY/tesseract、THUDM/CogVideoX-5b-I2V 与具身任务资产；在它们就位前，pipeline 只返回列出缺失项的诊断信息。

## 在 WorldFoundry 中运行

用 `wf run tesseract --pipeline.task-profile robot-action-video` 推进世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`anyeZHY/tesseract`、`THUDM/CogVideoX-5b-I2V`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh tesseract`；下载缺失的公开权重时加 `--download`。
