**发表机构:** 马萨诸塞大学阿默斯特分校（Embodied AGI 实验室） · 高校

TesserAct 是面向机器人的具身 4D 世界模型：预测操作场景的动作条件视频，并保持时序一致的几何。官方 WorldArena 收录源码已内置树内，WorldFoundry 为其注册了运行时 manifest pipeline，并引用 Hugging Face 上已确认的 anyeZHY/tesseract checkpoint。

## 使用要点

在 checkpoint 与具身任务资产本地就位前，pipeline 返回 blocked 运行时诊断。请先就位 anyeZHY/tesseract 与任务资产，再重新运行。
