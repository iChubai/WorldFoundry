## 用来做什么

需要 catalog 音频生成时选 `thinksound`：记录输入进、音频出。用它而不是纯视频兄弟条目。

上游描述为「推理阶段（面向音频的思维链）+ 流/扩散音频生成器」。本仓库仅记录 prompt/video 契约与 generated_audio 产物——内部细节仓库未记录。该模型由阿里巴巴（通义 FunAudioLLM）发布。

catalog 记录的任务包括 视频生音频、audio-generation。别名包括 `FunAudioLLM/ThinkSound`。模态上，它接受视频，输出音频。
