TinyVLA targets fast, data-efficient VLA at sub-billion scale: LLaVA-Pythia backbones (400M / 700M / 1.3B released on the Hub) with ACT or conditional 1D-diffusion action heads. The published Hub models are VLM backbones for policy training — not task-trained robot checkpoints — so the in-tree runtime is checkpoint-gated until you stage a trained task policy.

## What it is for

`tinyvla` is the recorded instruction-to-action line. Start here when you need a WorldFoundry VLA rollout rather than a video generator.

LLaVA-Pythia multimodal backbones with CLIP/SigLIP vision fusion and swappable action heads (ACT or conditional 1D diffusion), executed fully in process. Both merged weights and local LoRA plus non-LoRA action tensors are supported.

Catalog tasks include vla, vla action prediction, and embodied policy. Catalog aliases include `tiny-vla` and `llava-pythia-vla`.

## Runtime contract

Required `prompt` and `image`; optional `model_id` (tinyvla), `state`, `preferred_cameras` (cam_left_wrist, cam_right_wrist, cam_head), `image_size` (480, 640), and `configured_action_horizon`; artifacts `action_trace` and `tinyvla_action_trace.json`.

Recorded task profiles: `vla`, `vla.action_prediction`, and `embodied_policy`. WorldFoundry binds `TinyVLAPipeline`.

Family status: **Runner parity pending**.

Runtime construction fails early until a compatible task checkpoint, its config.json (action dimensions and head type), and dataset statistics are staged locally.

LLaVA-Pythia, CLIP/SigLIP vision fusion, ACT, and conditional 1D diffusion action heads execute in process.

## Running in WorldFoundry

The catalog launch is `worldfoundry-eval run tinyvla --pipeline.task-profile vla`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch>=2.5).

Recorded weight repositories include `lesjie/Llava-Pythia-400M`. Stage assets with `bash scripts/inference/prepare_model_infer.sh tinyvla`.

Status: **Runner parity pending**.
