TinyVLA 追求亚十亿级的快速、数据高效 VLA：LLaVA-Pythia 骨干（Hub 上发布 400M / 700M / 1.3B）配 ACT 或条件 1D 扩散动作头。Hub 上发布的模型是用于策略训练的 VLM 骨干——并非任务训练好的机器人 checkpoint——因此运行前需自行准备训练好的任务策略。

## 用来做什么

用 `tinyvla` 根据观测和语言指令预测机器人动作。

LLaVA-Pythia 多模态骨干配 CLIP/SigLIP 视觉融合与可换动作头（ACT 或条件 1D 扩散），全部进程内执行。支持合并权重与本地 LoRA 加非 LoRA 动作张量两种形式。

任务：视觉-语言-动作（VLA）、VLA 动作预测、具身策略。别名：`tiny-vla`、`llava-pythia-vla`。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `action_trace`、`tinyvla_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `TinyVLAPipeline`。

系列状态：**Runner 一致性待确认**。

需在本地准备兼容的任务 checkpoint、含动作维度与头类型的 config.json 及数据集统计；缺少它们时运行时无法启动。

无公开任务训练动作 checkpoint；Hub 发布仅为骨干。

## 在 WorldFoundry 中运行

运行 `wf run tinyvla --pipeline.task-profile default` 预测动作。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch>=2.5）。

权重仓库：`lesjie/Llava-Pythia-400M`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh tinyvla`；下载缺失的公开权重时加 `--download`。
