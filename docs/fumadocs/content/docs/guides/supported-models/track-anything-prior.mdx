Segment and Track Anything (SAM-Track) combines SAM segmentation with AOT/DeAOT tracking so objects can be segmented once and tracked across a whole video, with GroundingDINO enabling text-prompted selection. WorldFoundry exposes it as a tracking prior through the shared geometry-prior pipeline.

## What it is for

`track-anything-prior` estimates scene geometry from the input views.

Three subcomponents work together: SAM produces masks, GroundingDINO grounds text prompts, and AOT/DeAOT propagates masks through the video. It is published by Zhejiang University (ReLER Lab).

Tasks: video object segmentation, object tracking, and geometry prior. Aliases: `segment-and-track-anything`, `track-anything`, and `aot-deaot-l`.
