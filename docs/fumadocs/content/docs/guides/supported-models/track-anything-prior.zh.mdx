Segment and Track Anything（SAM-Track）把 SAM 分割与 AOT/DeAOT 跟踪结合起来：对象只需分割一次即可在整段视频中被跟踪，GroundingDINO 支持文本提示选择。WorldFoundry 通过共享的 geometry-prior pipeline 将其作为跟踪先验提供。

## 用来做什么

`track-anything-prior` 根据输入视图估计场景几何。

三个子组件协同工作：SAM 生成掩码，GroundingDINO 做文本定位，AOT/DeAOT 在视频中传播掩码。该模型由浙江大学（ReLER 实验室）发布。

任务：video-object-segmentation、object-tracking、几何先验。别名：`segment-and-track-anything`、`track-anything`、`aot-deaot-l`。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `max-frames`、`execute`、`max-points`；产物 `track-anything-mask.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `TrackAnythingPriorPipeline`。

系列状态：**Runner 一致性待确认**。

运行先验推理前，先就位 SAM、GroundingDINO 与 AOT/DeAOT checkpoint。

## 在 WorldFoundry 中运行

运行 `wf run track-anything-prior --pipeline.task-profile default` 写出几何结果。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`ShilongLiu/GroundingDINO`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh track-anything-prior`；下载缺失的公开权重时加 `--download`。
