## What it is for

`unianimate-dit` is an image-to-video model: a still image in, a video clip out.

Built on the Wan2.1 image-to-video diffusion transformer with pose-sequence conditioning for human animation (checkpoint: ZheWang123/UniAnimate-DiT). It is published by Alibaba (Tongyi Lab).

Tasks: human image animation, image-to-video, and video generation. Modalities: image in, video out.

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `height`, `width`, `steps`, `seed`, and `max-frames`; artifacts `unianimate-dit.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `UniAnimateDiTPipeline`.

Family status: **Runner parity pending**.

Defaults for `interactive-video`: height=832, width=480, seed=0.

Prepare a clean subject photo and a driving pose sequence for best results.

## Running in WorldFoundry

Run `wf run unianimate-dit --pipeline.task-profile interactive-video` to generate the video.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `ZheWang123/UniAnimate-DiT`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh unianimate-dit`. Add `--download` to fetch missing public checkpoints.
