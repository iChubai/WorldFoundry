UniDepth V2 is a universal monocular metric-depth model: from a single image of any camera it predicts a metric 3D point cloud directly, without external intrinsics. Validated with the released checkpoint: inference and official point-cloud export run through the geometry-prior pipeline.

## What it is for

`unidepth-v2-prior` is a depth estimation model.

Per the upstream publication, a camera self-prompting module predicts a dense camera representation that conditions depth decoding, enabling cross-camera generalization. The default checkpoint is lpiccinelli/unidepth-v2-vitl14; set model_path to use a local copy. It is published by ETH Zurich.

Tasks: monocular depth estimation, metric depth estimation, and geometry prior. Aliases: `unidepth-v2`, `unidepth-v2-vitl14`, and `unidepth_v2_vitl14`. Modalities: image in, depth out.
