## 用来做什么

`unidepth-v2-prior` 是深度估计模型。

按上游论文，相机自提示模块预测稠密相机表示并条件化深度解码，实现跨相机泛化。默认 checkpoint 为 lpiccinelli/unidepth-v2-vitl14；可用 model_path 指定本地副本。该模型由苏黎世联邦理工学院（ETH Zurich）发布。

任务：单目深度估计、米制深度估计、几何先验。别名：`unidepth-v2`、`unidepth-v2-vitl14`、`unidepth_v2_vitl14`。模态上，它接受图像，输出深度。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `type`、`focal-length`、`execute`、`max-points`；产物 `unidepth-v2-prior.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `UniDepthV2PriorPipeline`。

系列状态：**已验证**。

UniDepth V2 可作为独立几何先验运行，也可由 ViPE 等上层管线调用以获得米制深度。
