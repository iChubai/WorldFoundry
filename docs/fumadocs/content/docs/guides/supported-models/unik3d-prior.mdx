UniK3D generalizes metric 3D estimation to any camera — pinhole, fisheye, even full panoramas — with one model. WorldFoundry uses it as a universal-camera geometry prior. Validated with the released checkpoint through the shared geometry-prior pipeline with automatic camera estimation; pinhole and panorama camera overrides are set explicitly.

## What it is for

`unik3d-prior` estimates depth: images in, depth maps out.

Per the upstream publication, UniK3D represents the camera with a learned spherical-basis model, decoupling ray directions from radial depth so that no distortion-specific tuning is needed. The default checkpoint resolves from lpiccinelli/unik3d-vitl, or from an explicit local model_path. It is published by ETH Zurich.

Tasks: panoramic depth estimation, metric 3D estimation, monocular depth estimation, and geometry prior. Aliases: `unik3d` and `unik3d-vitl`. Modalities: image in, depth out.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `type`, `camera-model`, `execute`, and `max-points`; artifacts `unik3d-prior.npz`.

CLI task profiles: `default`. WorldFoundry binds `UniK3DPriorPipeline`.

Family status: **Verified**.

Use it through the shared geometry-prior pipeline/operator contract; pipelines such as ViPE also use it as their geometry prior. Prefer it over pinhole-only priors when inputs include fisheye or panoramic imagery.

## Running in WorldFoundry

Run `wf run unik3d-prior --pipeline.task-profile default` to write the depth maps.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `lpiccinelli/unik3d-vitl`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh unik3d-prior`. Add `--download` to fetch missing public checkpoints.
