UniK3D 把米制 3D 估计推广到任意相机——针孔、鱼眼、乃至完整全景——只用一个模型。WorldFoundry 将其用作通用相机几何先验。已用发布的 checkpoint 通过共享几何先验 pipeline 验证，支持自动相机估计；针孔与全景相机覆盖需显式设置。

## 用来做什么

`unik3d-prior` 估计深度：输入图像，输出深度图。

按上游论文，UniK3D 用学习到的球谐基相机模型表示相机，把射线方向与径向深度解耦，无需针对畸变单独调参。默认 checkpoint 从 lpiccinelli/unik3d-vitl 解析，也可通过 model_path 显式指定本地路径。该模型由苏黎世联邦理工学院（ETH Zurich）发布。

任务：panoramic-depth-estimation、metric-3d-estimation、单目深度估计、几何先验。别名：`unik3d`、`unik3d-vitl`。模态上，它接受图像，输出深度。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `type`、`camera-model`、`execute`、`max-points`；产物 `unik3d-prior.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `UniK3DPriorPipeline`。

系列状态：**已验证**。

通过共享的 geometry-prior pipeline/operator 契约调用；ViPE 等 pipeline 也以它作为几何先验。当输入包含鱼眼或全景图像时，优先选它而非仅支持针孔的先验。

## 在 WorldFoundry 中运行

运行 `wf run unik3d-prior --pipeline.task-profile default` 写出深度图。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`lpiccinelli/unik3d-vitl`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh unik3d-prior`；下载缺失的公开权重时加 `--download`。
