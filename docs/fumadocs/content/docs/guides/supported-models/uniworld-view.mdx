## Architecture

UniView uses a Diffusers WanVACEPipeline backend with geometry estimation and rendered camera controls. Its in-tree inference runtime follows UniWorld-View at 660212c4 and reuses canonical SAM2, MoGe-2, DINOv2 and STream3R components. A MoGe variant preserves the upstream token-grid truncation and eager attention fallback.

## Runtime contract

Use the separate upstream environment and the official local weights. The upstream CLI uses BLIP2 captions rather than a user text prompt.

The inference code is vendored from revision `660212c48bff7c91a2ea5c7d5f3785af581100e2`. Download the weights in the upstream `checkpoints/` layout (including STream3R for dynamic view) to `UniWorld-View` under the WorldFoundry checkpoint root, or pass `checkpoint_root`. The route needs the **Diffusers-format** Wan2.1-VACE-14B base; the native `.pth` release is not interchangeable. Use the upstream Python 3.10 / Torch 2.4.0 CUDA 12.4 environment with its declared dependencies. Set `UNIWORLD_VIEW_PYTHON` when the Python executable is outside the default conda path.

The Python adapter is `UniWorldViewPipeline.from_pretrained(device="cuda:0")`. Pass `images` for single-image outpainting or `video` with `mode="dynamic_view"` for monocular video; the latter needs at least 13 generated frames because the second stage consumes 10 reference frames. The default `hybrid` renderer requires PyTorch3D; `render_method="warp"` selects the BiSplat route. Use `plan_only=True` to inspect the subprocess command without loading weights.

## Limitations

- The upstream authors recommend at least 60 GB of GPU memory.
- Validated with the released weights on the official samples and settings only; camera-angle accuracy and other scenes are not measured.
- With aspect-ratio preservation enabled, actual output dimensions can differ from the requested height and width.
- The in-tree runtime initializes STream3R for dynamic-view inference and honors the requested FPS and seed in the single-view path. Repeated runs with the same seed were checked frame by frame.
