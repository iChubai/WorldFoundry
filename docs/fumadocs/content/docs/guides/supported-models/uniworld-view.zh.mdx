## 架构

UniView 使用 Diffusers WanVACEPipeline 后端，结合几何估计和渲染后的相机控制。包内推理实现基于 UniWorld-View 的 660212c4 版本，复用 canonical SAM2、MoGe-2、DINOv2 和 STream3R；MoGe variant 保留上游 token 网格的截断规则和显式 attention 回退路径。

## 运行时契约

使用独立的官方环境和本地权重。上游 CLI 使用 BLIP2 自动描述，不读取用户文本提示。

推理代码 vendor 自源码版本 `660212c48bff7c91a2ea5c7d5f3785af581100e2`。按上游 `checkpoints/` 目录结构下载权重（动态视角还需 STream3R），放到 WorldFoundry checkpoint 根目录下的 `UniWorld-View`，或传入 `checkpoint_root`。此路线需要 **Diffusers 格式**的 Wan2.1-VACE-14B 基座，原生 `.pth` 版本不能替代。请使用上游 Python 3.10 / Torch 2.4.0 CUDA 12.4 环境及其依赖。如果 Python 不在默认 conda 路径下，设置 `UNIWORLD_VIEW_PYTHON`。

Python 适配器为 `UniWorldViewPipeline.from_pretrained(device="cuda:0")`。单图路线传入 `images`；单目视频路线传入 `video` 和 `mode="dynamic_view"`。后者至少需要生成 13 帧，因为第二阶段会读取 10 帧参考画面。默认 `hybrid` 渲染器依赖 PyTorch3D；`render_method="warp"` 选择 BiSplat 路线。`plan_only=True` 可在不加载权重的情况下查看子进程命令。

## 限制

- 上游建议显存至少 60 GB。
- 仅在官方样例的指定配置上用真实权重验证；其他场景及相机角度精度未经量化。
- 默认保持输入宽高比时，实际输出尺寸可能与请求的高度和宽度不同。
- 树内运行时初始化动态视角路线的 STream3R，并将请求的 FPS 与随机种子用于单视角路线。相同种子的重复运行已逐帧核对。
