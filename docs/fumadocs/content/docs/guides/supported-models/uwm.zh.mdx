## 用来做什么

`uwm` 是动作条件世界模型：输入动作和起始帧，输出推演结果。

UWM 是视频-动作扩散设计：单个扩散过程联合建模未来观测与机器人动作，同一网络兼任预测与策略角色。该模型由华盛顿大学（WEIRD 实验室）发布。

任务：机器人世界模型、动作条件视频、video-action-diffusion。别名：`uwm-libero90`、`uwm-droid`。

推荐评测：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（uwm-libero90 变体面向 LIBERO 任务）、[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（机器人世界模型滚动生成质量）。

## 运行时契约

产物 `generated_video`、`uwm_runtime_plan.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `UWMPipeline`。

系列状态：**Runner 一致性待确认**。

请按评测套件选择 LIBERO-90 或 DROID 变体。所需 checkpoint 与资产就位前，运行只会输出列出缺失资产的运行时计划，而不会生成结果。

checkpoint 与数据集不随附，运行前需自行就位。

## 在 WorldFoundry 中运行

运行 `wf run uwm --pipeline.task-profile default` 推演世界模型。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型没有登记公开 checkpoint；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh uwm`；下载缺失的公开权重时加 `--download`。
