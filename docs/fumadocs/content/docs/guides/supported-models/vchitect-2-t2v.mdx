## What it is for

Use `vchitect-2-t2v` to turn a text prompt into a short video.

A parallel diffusion transformer paired with an SD3-family VAE decoder. It is published by Shanghai AI Laboratory (Vchitect).

Tasks: text-to-video and video generation. Aliases: `vchitect`, `vchitect-2`, `vchitect2-t2v`, and `vchitect_2_t2v`. Modalities: text in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Standard T2V quality suite).

## Runtime contract

Inputs `prompt` (bundled samples are used when omitted); options `frames`, `fps`, `height`, `width`, `steps`, `guidance-scale`, and 1 more; artifacts `generated_video` and `vchitect_2_t2v_public_runner.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `Vchitect2T2VPipeline`.

Family status: **Static load only**.

Defaults for `interactive-video`: frames=40, fps=8, height=432, width=768, seed=0.

Weights are apache-2.0 at Vchitect/Vchitect-2.0-2B. Use id vchitect-2-t2v.

## Running in WorldFoundry

Generate a clip with `wf run vchitect-2-t2v --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `Vchitect/Vchitect-2.0-2B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh vchitect-2-t2v`. Add `--download` to fetch missing public checkpoints.
