## 用来做什么

用 `vchitect-2-t2v` 把一段文本提示词变成短视频。

并行扩散 Transformer 配 SD3 系 VAE 解码器。该模型由上海人工智能实验室（Vchitect 团队）发布。

任务：文生视频、视频生成。别名：`vchitect`、`vchitect-2`、`vchitect2-t2v`、`vchitect_2_t2v`。模态上，它接受文本，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（标准文生视频质量评测）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`guidance-scale` 等 7 项；产物 `generated_video`、`vchitect_2_t2v_public_runner.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `Vchitect2T2VPipeline`。

系列状态：**仅静态加载**。

`interactive-video` 的默认值：frames=40, fps=8, height=432, width=768, seed=0。

权重为 apache-2.0，位于 Vchitect/Vchitect-2.0-2B。请使用 id vchitect-2-t2v。

## 在 WorldFoundry 中运行

用 `wf run vchitect-2-t2v --pipeline.task-profile interactive-video` 生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`Vchitect/Vchitect-2.0-2B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh vchitect-2-t2v`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
