## What it is for

`veo3` runs on the provider's hosted API; no local checkpoint is needed.

Tasks: text-to-video, image-to-video, and hosted api. Modalities: text and image in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Standard multi-dimension quality suite for comparing hosted text/image-to-video outputs), [Physics-IQ Original](/docs/evaluation/benchmark-hub/physics-iq) (Probes whether provider-side video models respect basic physical plausibility).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted).

CLI task profiles: `default`. WorldFoundry binds `Veo3Pipeline`.

Supply your own provider API key and account. No weights are downloaded and no GPU environment is provisioned locally — generation happens on the provider side, so cost, quota, and content policy follow your provider account. Veo access is provisioned through Google's AI developer offerings (e.g. the Gemini API); regional availability applies.

Requires a paid provider account and API key; WorldFoundry does not ship credentials.

The provider controls model versioning, so outputs can change over time without any change on the WorldFoundry side.

## Running in WorldFoundry

Run `wf run veo3 --pipeline.task-profile default` to call the provider API.

No runtime environment is recorded for this model.

Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh veo3`. Add `--download` to fetch missing public checkpoints.
