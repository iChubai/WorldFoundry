Veo3 是 Google DeepMind 的 Veo 3 托管视频模型在本 catalog 中的条目，记录文生视频与图生视频任务。 WorldFoundry 通过 Google 的 API 提交生成请求并把渲染结果收为产物，使 Veo 3 的结果可以与开源模型在同一套评测框架下对比。模型本体始终运行在 Google 的基础设施上。

## 架构

这是由服务方托管运行的模型：厂商未公开其架构、参数规模或训练细节，本仓库也未记录这些信息。WorldFoundry 记录的只是集成层——一条向服务方端点提交请求并回收生成视频产物的 Studio pipeline。

## 使用要点

Catalog 将该条目标记为 integrated：托管 API 的 Studio pipeline 已可用，但你必须自备服务方的 API key 与账号。本地不会下载任何权重、也不会创建 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。Veo 的访问通过 Google 的 AI 开发者产品（如 Gemini API）开通，并受地区可用性限制。
