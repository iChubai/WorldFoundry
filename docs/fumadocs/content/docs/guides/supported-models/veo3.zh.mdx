## 用来做什么

`veo3` 通过提供商的托管 API 运行，无需本地 checkpoint。

这是由服务方托管运行的模型：厂商未公开其架构、参数规模或训练细节。WorldFoundry 提供一条 Studio pipeline，向服务方端点提交请求并回收生成的视频产物。

任务：文生视频、图生视频、托管 API。模态上，它接受文本、图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（对比托管文/图生视频输出的标准多维质量评测）、[Physics-IQ Original](/zh/docs/evaluation/benchmark-hub/physics-iq)（检验服务方视频模型是否遵循基本物理合理性）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）。

CLI task profile：`default`。绑定的 pipeline 类是 `Veo3Pipeline`。

系列状态：**Runner 一致性待确认**。

你需要自备服务方的 API key 与账号。本地不会下载任何权重、也不会创建 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。Veo 的访问通过 Google 的 AI 开发者产品（如 Gemini API）开通，并受地区可用性限制。

需要付费的服务方账号与 API key；WorldFoundry 不提供任何凭据。

## 在 WorldFoundry 中运行

运行 `wf run veo3 --pipeline.task-profile default` 调用提供商 API。

该模型未记录运行环境。
