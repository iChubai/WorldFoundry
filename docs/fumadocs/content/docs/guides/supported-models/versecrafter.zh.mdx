腾讯 ARC 的 VerseCrafter 是基于 4D 控制的相机可控图生视频世界模型：几何感知渲染阶段产出 4D 控制信号，引导扩散阶段沿指定相机路径生成。运行需要 TencentARC/VerseCrafter checkpoint，以及 Wan-AI/Wan2.1-T2V-14B 与 Ruicheng/moge-2-vitl-normal。

## 用来做什么

`versecrafter` 以相机位姿为条件生成视频。

两个阶段：仅相机的 4D 控制渲染，随后是扩散阶段，其扩散骨干来自 VideoX-Fun。该模型由腾讯 ARC 实验室发布。

任务：相机可控视频、图生视频、世界模型。模态上，它接受图像，输出视频。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（4D 控制生成的相机路径跟随）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`guidance-scale` 等 7 项；产物 `versecrafter.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `VerseCrafterPipeline`。

系列状态：**已验证**。

`default` 的默认值：frames=81, fps=16, height=480, width=832, seed=2025。

已用发布权重验证：可端到端生成相机可控短视频，后段帧有可见伪影。

## 在 WorldFoundry 中运行

用 `wf run versecrafter --pipeline.task-profile default` 生成相机可控视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`TencentARC/VerseCrafter`、`Wan-AI/Wan2.1-T2V-14B`、`Ruicheng/moge-2-vitl-normal`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh versecrafter`；下载缺失的公开权重时加 `--download`。
