VGGT-Omega is the extended VGGT release published under facebook/VGGT-Omega, covering 3D reconstruction, Gaussian splatting, and novel view synthesis. Validated on GPU: single-image outputs match the pinned upstream commit exactly, and the official scene-export route runs end to end.

## What it is for

Use `vggt-omega` for feed-forward 3D reconstruction from the input views.

It runs the official VGGT-Omega architecture and writes predictions.npz plus GLB scene artifacts through the WorldFoundry VGGT result interface. Weights are staged under assets/checkpoints. It is published by Meta AI.

Tasks: 3D reconstruction, gaussian splatting, and novel view synthesis. Aliases: `vggt_omega` and `facebook/VGGT-Omega`.

VGGT-Omega is a different model from [VGGT](/docs/guides/supported-models/vggt) and [VGGT-World](/docs/guides/supported-models/vggt-world).

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `task-type`, `image-resolution`, `preprocess-mode`, `video-sample-fps`, and `max-points-k`; artifacts `scene_conf20.0_blackFalse_whiteFalse_camTrue_skyFalse_max200k.glb`.

CLI task profiles: `interactive-video`. WorldFoundry binds `VGGTOmegaPipeline`.

Family status: **Verified**.

Use vggt-omega for the official scene-export route with predictions.npz and GLB outputs. It is a different model from vggt (base) and vggt-world — pick by route, not by name.

## Running in WorldFoundry

Reconstruct the scene with `wf run vggt-omega --pipeline.task-profile interactive-video`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `facebook/VGGT-Omega`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh vggt-omega`. Add `--download` to fetch missing public checkpoints.
