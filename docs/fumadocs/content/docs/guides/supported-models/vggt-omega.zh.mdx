VGGT-Omega 是以 facebook/VGGT-Omega 发布的 VGGT 扩展版本，覆盖 3D 重建、高斯泼溅与新视角合成。已在 GPU 上验证：单图输出与固定的上游 commit 完全一致，官方场景导出路径可端到端运行。

## 用来做什么

用 `vggt-omega` 从输入视图做前馈 3D 重建。

它运行官方 VGGT-Omega 架构，通过 WorldFoundry 的 VGGT 结果接口写出 predictions.npz 与 GLB 场景产物。权重就位于 assets/checkpoints。该模型由 Meta AI 发布。

任务：3D 重建、高斯泼溅、新视角合成。别名：`vggt_omega`、`facebook/VGGT-Omega`。

VGGT-Omega 与 [VGGT](/zh/docs/guides/supported-models/vggt)、[VGGT-World](/zh/docs/guides/supported-models/vggt-world) 是不同的模型。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `task-type`、`image-resolution`、`preprocess-mode`、`video-sample-fps`、`max-points-k`；产物 `scene_conf20.0_blackFalse_whiteFalse_camTrue_skyFalse_max200k.glb`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `VGGTOmegaPipeline`。

系列状态：**已验证**。

需要官方场景导出路径以及 predictions.npz 与 GLB 产物时使用 vggt-omega。它与 vggt（基础版）及 vggt-world 是不同的模型，请按路径而非名称选择。

## 在 WorldFoundry 中运行

用 `wf run vggt-omega --pipeline.task-profile interactive-video` 重建场景。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`facebook/VGGT-Omega`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh vggt-omega`；下载缺失的公开权重时加 `--download`。
