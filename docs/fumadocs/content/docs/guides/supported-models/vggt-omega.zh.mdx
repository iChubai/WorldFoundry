VGGT-Omega 是以 facebook/VGGT-Omega 发布的 VGGT 扩展版本，覆盖 3D 重建、高斯泼溅与新视角合成。本 catalog 中它以异常严格的证据验证：与固定上游 commit 的单图 GPU 一致性对比在可比输出上达到 max_abs_diff=0.0，树内 runner 支持官方场景导出路径。

## 架构

它使用官方架构的表示 runner 加上现有的 WorldFoundry VGGTResult/save 接口，输出 predictions.npz 与 GLB 场景产物。权重存放于 assets/checkpoints、绝不提交进源码；checkpoint 许可为 CC-BY-NC-4.0。
