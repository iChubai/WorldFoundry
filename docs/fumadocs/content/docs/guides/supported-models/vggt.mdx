VGGT (Visual Geometry Grounded Transformer, CVPR 2025) is a feed-forward network that infers cameras, depth maps, point maps, and 3D point tracks from one to hundreds of views in a single pass — no per-scene optimization. WorldFoundry runs an in-tree two-stage 3DGS pipeline on VGGT geometry; vggt-omega and vggt-world are separate models.

## What it is for

`vggt` estimates scene geometry from the input views.

Per the CVPR 2025 paper, a large transformer alternates frame-wise and global attention over image tokens, with task-specific heads for cameras, depth, pointmaps, and tracking. Weights are apache-2.0 (facebookresearch/vggt); the WorldFoundry route builds 3DGS from VGGT geometry in two stages. It is published by Meta AI (FAIR) / University of Oxford (VGG).

Tasks: 3D reconstruction, 3dgs, and point cloud. Output modalities: point cloud.

Related VGGT-based models: [VGGT-World](/docs/guides/supported-models/vggt-world) and [Infinite VGGT](/docs/guides/supported-models/infinite-vggt).

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `fps`, `height`, `width`, `point-conf-threshold`, `resolution`, and `preprocess-mode`.

CLI task profiles: `interactive-video`. WorldFoundry binds `VGGTPipeline`.

Family status: **Runner parity pending**.

For the verified scene-export route use vggt-omega; use vggt when you want the two-stage 3DGS pipeline over base VGGT geometry.

## Running in WorldFoundry

Reconstruct the scene with `wf run vggt --pipeline.task-profile interactive-video`.

No runtime environment is recorded for this model.

Weights: `facebook/VGGT-1B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh vggt`. Add `--download` to fetch missing public checkpoints.
