VGGT（Visual Geometry Grounded Transformer，CVPR 2025）是前馈网络：单次前向即可从一到数百个视图推断相机、深度图、点图与 3D 点轨迹——无需逐场景优化。WorldFoundry 在树内运行基于 VGGT 几何的两段式 3DGS pipeline；vggt-omega 与 vggt-world 是独立模型。

## 用来做什么

`vggt` 根据输入视图估计场景几何。

按 CVPR 2025 论文，大型 Transformer 在图像 token 上交替执行帧内与全局注意力，任务头分别输出相机、深度、点图与跟踪。权重采用 apache-2.0 许可（facebookresearch/vggt）；WorldFoundry 路径分两段从 VGGT 几何构建 3DGS。该模型由 Meta AI（FAIR）/ 牛津大学 VGG 组发布。

任务：3D 重建、3dgs、点云。输出模态为点云。

相关的 VGGT 系模型：[VGGT-World](/zh/docs/guides/supported-models/vggt-world)、[Infinite VGGT](/zh/docs/guides/supported-models/infinite-vggt)。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `fps`、`height`、`width`、`point-conf-threshold`、`resolution`、`preprocess-mode`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `VGGTPipeline`。

系列状态：**Runner 一致性待确认**。

需要已验证的场景导出路径时，请使用 vggt-omega；需要基于基础 VGGT 几何的两段式 3DGS pipeline 时，请使用 vggt。

## 在 WorldFoundry 中运行

用 `wf run vggt --pipeline.task-profile interactive-video` 重建场景。

该模型未记录运行环境。

权重仓库：`facebook/VGGT-1B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh vggt`；下载缺失的公开权重时加 `--download`。
