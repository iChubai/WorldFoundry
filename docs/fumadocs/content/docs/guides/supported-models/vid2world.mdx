## What it is for

Use `vid2world` to step a world forward with actions and render the resulting frames.

The core idea is video-diffusion adaptation: converting a full-sequence diffusion model into a causal, action-conditioned rollout. Official code: thuml/Vid2World. It is published by Tsinghua University (THUML).

Tasks: interactive world model, video diffusion adaptation, and action-conditioned video.

Suggested benchmarks: [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Action-conditioned interactive rollout quality).
