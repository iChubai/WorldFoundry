## 用来做什么

用 `vid2world` 以动作推进世界并渲染出相应画面。

核心思想是视频扩散适配：把全序列扩散模型改造成因果、动作条件的滚动生成。官方代码：thuml/Vid2World。该模型由清华大学（THUML 机器学习组）发布。

任务：交互式世界模型、video-diffusion-adaptation、动作条件视频。

推荐评测：[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件交互滚动生成质量）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `interactions`、`frames`、`fps`、`seed`；产物 `generated_video`、`vid2world_runtime_plan.json`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `Vid2WorldPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-video` 的默认值：frames=16, fps=16, seed=42。

在所需 checkpoint 与配置资产就位前，生成会返回列出缺失资产的运行时计划。

## 在 WorldFoundry 中运行

运行 `wf run vid2world --pipeline.task-profile interactive-video` 推演世界模型。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型未登记公开的 checkpoint；请按使用说明准备权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh vid2world`；下载缺失的公开权重时加 `--download`。
