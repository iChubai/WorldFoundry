Video Depth Anything brings temporal consistency to the Depth Anything family: it estimates depth over arbitrarily long videos without the flicker of frame-by-frame estimation. WorldFoundry exposes it as a standalone temporal depth prior that ViPE pipeline profiles can also select through shared runtime config.

## What it is for

`video-depth-anything-prior` estimates depth: images in, depth maps out.

Per the upstream release, a spatiotemporal head with a temporal-gradient consistency objective extends Depth Anything V2 to video, plus a keyframe strategy for long sequences. The checkpoint is depth-anything/Video-Depth-Anything-Large (apache-2.0). It is published by ByteDance.

Tasks: video depth estimation, temporal depth estimation, and geometry prior. Aliases: `video-depth-anything` and `vda-prior`. Modalities: image in, depth out.

## Runtime contract

Inputs `input-path` (bundled samples are used when omitted); options `model`, `input-size`, `max-frames`, `execute`, and `max-points`; artifacts `video-depth-anything-prior.npz`.

CLI task profiles: `default`. WorldFoundry binds `VideoDepthAnythingPriorPipeline`.

Family status: **Runner parity pending**.

Run it on its own as a geometry prior, or select it from a ViPE pipeline profile. Stage the depth-anything/Video-Depth-Anything-Large weights before running.

Relative depth focus — pair with a metric prior when metric scale is required.

## Running in WorldFoundry

Run `wf run video-depth-anything-prior --pipeline.task-profile default` to write the depth maps.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `depth-anything/Video-Depth-Anything-Large`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh video-depth-anything-prior`. Add `--download` to fetch missing public checkpoints.
