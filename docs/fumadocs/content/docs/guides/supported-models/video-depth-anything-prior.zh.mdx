Video Depth Anything 为 Depth Anything 家族带来时序一致性：在任意长度的视频上估计深度，避免逐帧估计的闪烁。WorldFoundry 将它作为独立的时序深度先验提供，ViPE pipeline 档案也可通过共享运行时配置选用它。

## 用来做什么

`video-depth-anything-prior` 估计深度：输入图像，输出深度图。

按上游发布，时空头加时间梯度一致性目标把 Depth Anything V2 扩展到视频，并用关键帧策略处理长序列。checkpoint 为 depth-anything/Video-Depth-Anything-Large（apache-2.0）。该模型由字节跳动发布。

任务：video-depth-estimation、temporal-depth-estimation、几何先验。别名：`video-depth-anything`、`vda-prior`。模态上，它接受图像，输出深度。

## 运行时契约

输入 `input-path`（不传时使用内置示例）；参数 `model`、`input-size`、`max-frames`、`execute`、`max-points`；产物 `video-depth-anything-prior.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `VideoDepthAnythingPriorPipeline`。

系列状态：**Runner 一致性待确认**。

可单独作为几何先验运行，也可在 ViPE pipeline 档案中选用。运行前请就位 depth-anything/Video-Depth-Anything-Large 权重。

以相对深度为主——需要米制尺度时请与米制先验配合。

## 在 WorldFoundry 中运行

运行 `wf run video-depth-anything-prior --pipeline.task-profile default` 写出深度图。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`depth-anything/Video-Depth-Anything-Large`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh video-depth-anything-prior`；下载缺失的公开权重时加 `--download`。
