VideoCrafter is Tencent AI Lab's U-Net latent video toolbox. The family groups three in-tree **infer-only** runtimes: [VideoCrafter2 T2V](/docs/guides/supported-models/videocrafter2-t2v) (the default launch), [VideoCrafter1 T2V](/docs/guides/supported-models/videocrafter1-t2v), and [VideoCrafter1 I2V](/docs/guides/supported-models/videocrafter1-i2v). Training, dataset, and download helpers are not included.

## What it is for

Start on VideoCrafter2 T2V (`VideoCrafter2T2VPipeline`): required `prompt`, artifact `videocrafter2-t2v.mp4`. It is the only route with a declared license (**Apache-2.0**) and the family default (`wf run videocrafter`).

Use [videocrafter1-t2v](/docs/guides/supported-models/videocrafter1-t2v) for the older 1024×576 text-to-video weights, and [videocrafter1-i2v](/docs/guides/supported-models/videocrafter1-i2v) to animate a still. There is **no V2V** route. Compare the companion suite [EvalCrafter](/docs/evaluation/benchmark-hub/evalcrafter) and general T2V quality on [VBench](/docs/evaluation/benchmark-hub/vbench).

## Inference

Sampler is **DDIM** (`ddim_steps=50`, `ddim_eta=1.0`, `unconditional_guidance_scale=12.0` unless you override). Height and width must be divisible by 16. Frame count defaults to the U-Net `temporal_length` of **16**.

| Route | Task | Size / frames / fps | Checkpoint |
| --- | --- | --- | --- |
| `videocrafter2-t2v` (default) | T2V | **512×320**, 16f, **28** fps | `VideoCrafter/VideoCrafter2` |
| `videocrafter1-t2v` | T2V | **1024×576**, 16f, **8** fps | `VideoCrafter/Text2Video-1024` |
| `videocrafter1-i2v` | I2V | **512×320**, 16f, **8** fps | `VideoCrafter/Image2Video-512` |

Image-to-video runs through the `videocrafter1-i2v` pipeline and writes `videocrafter1-i2v.mp4`.

## Running in WorldFoundry

Unified env `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage the matching `model.ckpt` under `$WORLDFOUNDRY_HFD_ROOT` (`VideoCrafter--VideoCrafter2`, `VideoCrafter--Text2Video-1024`, or `VideoCrafter--Image2Video-512`). The older Text2Video / Image2Video Hugging Face cards declare **no license**; do not assume Apache-2.0 for them.
