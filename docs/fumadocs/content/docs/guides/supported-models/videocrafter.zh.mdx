VideoCrafter 是腾讯 AI Lab 的 U-Net 潜空间视频工具箱。该系列包含三条树内**仅推理**运行路径：[VideoCrafter2 T2V](/zh/docs/guides/supported-models/videocrafter2-t2v)（默认启动）、[VideoCrafter1 T2V](/zh/docs/guides/supported-models/videocrafter1-t2v)、[VideoCrafter1 I2V](/zh/docs/guides/supported-models/videocrafter1-i2v)。不包含训练、数据集与下载辅助脚本。

## 用来做什么

从 VideoCrafter2 文生视频入手（`VideoCrafter2T2VPipeline`）：必填 `prompt`，产物 `videocrafter2-t2v.mp4`。这是唯一声明了许可的路径（**Apache-2.0**），也是系列默认（`wf run videocrafter`）。

旧版 1024×576 文生视频使用 [videocrafter1-t2v](/zh/docs/guides/supported-models/videocrafter1-t2v)，为静帧添加运动则使用 [videocrafter1-i2v](/zh/docs/guides/supported-models/videocrafter1-i2v)。**没有 V2V**。配套评测看 [EvalCrafter](/zh/docs/evaluation/benchmark-hub/evalcrafter)，通用文生视频质量看 [VBench](/zh/docs/evaluation/benchmark-hub/vbench)。

## 推理

采样器是 **DDIM**（除非覆盖，否则 `ddim_steps=50`、`ddim_eta=1.0`、`unconditional_guidance_scale=12.0`）。高宽须能被 16 整除。帧数默认取 U-Net 的 `temporal_length`，即 **16**。

| 路径 | 任务 | 分辨率 / 帧数 / fps | Checkpoint |
| --- | --- | --- | --- |
| `videocrafter2-t2v`（默认） | 文生视频 | **512×320**，16 帧，**28** fps | `VideoCrafter/VideoCrafter2` |
| `videocrafter1-t2v` | 文生视频 | **1024×576**，16 帧，**8** fps | `VideoCrafter/Text2Video-1024` |
| `videocrafter1-i2v` | 图生视频 | **512×320**，16 帧，**8** fps | `VideoCrafter/Image2Video-512` |

图生视频走 `videocrafter1-i2v` pipeline，产物为 `videocrafter1-i2v.mp4`。

## 在 WorldFoundry 中运行

统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。在 `$WORLDFOUNDRY_HFD_ROOT` 下准备好对应的 `model.ckpt`（`VideoCrafter--VideoCrafter2`、`VideoCrafter--Text2Video-1024` 或 `VideoCrafter--Image2Video-512`）。较早的 Text2Video/Image2Video Hugging Face 卡片**未声明许可**；不要默认它们是 Apache-2.0。
