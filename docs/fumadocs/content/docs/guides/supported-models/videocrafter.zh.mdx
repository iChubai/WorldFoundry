## 架构

U-Net 潜空间视频扩散模型：VideoCrafter1 提供 T2V（最高 1024x576）与 I2V；VideoCrafter2 通过解耦外观学习（低质量视频 + 高质量图像数据）改进 T2V。训练、数据集与下载辅助脚本被有意排除在树内包外。
