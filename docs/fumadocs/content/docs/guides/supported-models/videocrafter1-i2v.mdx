VideoCrafter1 I2V is the image-to-video member of Tencent AI Lab's VideoCrafter1 release: it animates a still image while preserving its content, style, and structure. The in-tree infer-only runtime wraps the official path with local checkpoint, fps, frame count, and seed controls.

## What it is for

Use `videocrafter1-i2v` to generate a video that starts from a reference image.

A U-Net latent video diffusion model conditioned on the input image embedding (per the upstream release). Training and download scripts are not included.

Tasks: image-to-video and video generation. Aliases: `videocrafter1_i2v`. Modalities: image in, video out.

Suggested benchmarks: [EvalCrafter](/docs/evaluation/benchmark-hub/evalcrafter) (Companion benchmark of the VideoCrafter effort).

For text-only generation use [VideoCrafter1 T2V](/docs/guides/supported-models/videocrafter1-t2v); the [VideoCrafter](/docs/guides/supported-models/videocrafter) family page compares all routes. Score on [EvalCrafter](/docs/evaluation/benchmark-hub/evalcrafter).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `frames`, `fps`, `height`, `width`, `steps`, `seed`, and 2 more; artifacts `generated_video` and `videocrafter1-i2v.mp4`.

CLI task profiles: `interactive-video`. WorldFoundry binds `VideoCrafter1I2VPipeline`.

Family status: **Runner parity pending**.

Expect 2023-era quality: short clips, modest motion. For higher fidelity image animation use DynamiCrafter or the DiT-based I2V models.

## Running in WorldFoundry

The catalog launch is `wf run videocrafter1-i2v --pipeline.task-profile interactive-video`. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `wf run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `VideoCrafter/Image2Video-512` and `laion/CLIP-ViT-H-14-laion2B-s32B-b79K`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh videocrafter1-i2v`. Add `--download` to fetch missing public checkpoints.
