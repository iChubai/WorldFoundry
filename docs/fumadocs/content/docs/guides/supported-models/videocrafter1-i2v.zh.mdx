VideoCrafter1 I2V 是腾讯 AI Lab VideoCrafter1 发布中的图生视频成员：在保持内容、风格与结构的前提下让静态图动起来。树内仅推理运行时封装官方路径，提供本地 checkpoint、fps、帧数与 seed 控制。

## 用来做什么

用 `videocrafter1-i2v` 以参考图为起点生成视频。

以输入图像嵌入为条件的 U-Net 潜空间视频扩散模型（见上游发布）。不包含训练与下载脚本。

任务：图生视频、视频生成。别名：`videocrafter1_i2v`。模态上，它接受图像，输出视频。

推荐评测：[EvalCrafter](/zh/docs/evaluation/benchmark-hub/evalcrafter)（VideoCrafter 项目的配套评测）。

纯文本生成请用 [VideoCrafter1 T2V](/zh/docs/guides/supported-models/videocrafter1-t2v)；[VideoCrafter](/zh/docs/guides/supported-models/videocrafter) 系列页对比了各条路径。评测看 [EvalCrafter](/zh/docs/evaluation/benchmark-hub/evalcrafter)。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`seed` 等 8 项；产物 `generated_video`、`videocrafter1-i2v.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `VideoCrafter1I2VPipeline`。

系列状态：**Runner 一致性待确认**。

预期是 2023 年代的质量：短片、运动幅度有限。若要更高保真的图像动画，请用 DynamiCrafter 或 DiT 系图生视频模型。

## 在 WorldFoundry 中运行

catalog 启动命令是 `wf run videocrafter1-i2v --pipeline.task-profile interactive-video`。上方命令构建器按已记录任务切换 `--pipeline.task-profile`，发出的仍是 `wf run`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`VideoCrafter/Image2Video-512`、`laion/CLIP-ViT-H-14-laion2B-s32B-b79K`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh videocrafter1-i2v`；下载缺失的公开权重时加 `--download`。
