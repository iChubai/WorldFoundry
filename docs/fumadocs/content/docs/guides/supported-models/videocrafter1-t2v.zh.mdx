VideoCrafter1 T2V 是 VideoCrafter1 发布中的文生视频成员，按提示词生成最高 1024x576 的视频。WorldFoundry 以仅推理方式运行官方 1024 文生视频路径，提供本地 checkpoint、fps、帧数与 seed 控制。

## 用来做什么

`videocrafter1-t2v` 根据文本提示词生成视频。

U-Net 潜空间视频扩散，最高 1024x576（见上游发布）。该模型由腾讯 AI Lab 发布。

任务：文生视频、视频生成。别名：`videocrafter1_t2v`。模态上，它接受文本，输出视频。

推荐评测：[EvalCrafter](/zh/docs/evaluation/benchmark-hub/evalcrafter)（VideoCrafter 项目的配套评测）。

不是 [VideoCrafter](/zh/docs/guides/supported-models/videocrafter)，也不是 [VideoCrafter2 T2V](/zh/docs/guides/supported-models/videocrafter2-t2v)。评测看 [EvalCrafter](/zh/docs/evaluation/benchmark-hub/evalcrafter)。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`seed` 等 8 项；产物 `generated_video`、`videocrafter1-t2v.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `VideoCrafter1T2VPipeline`。

系列状态：**Runner 一致性待确认**。

要更好的画质，改用同系列的 VideoCrafter2 T2V 或当前一代的 DiT 模型。

## 在 WorldFoundry 中运行

启动 `wf run videocrafter1-t2v --pipeline.task-profile default` 采样视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`VideoCrafter/Text2Video-1024`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh videocrafter1-t2v`；下载缺失的公开权重时加 `--download`。
