VideoCrafter2 T2V 是 VideoCrafter 系列中改进版的文生视频模型，通过将低质量视频数据与高质量图像数据结合训练来突破数据瓶颈。它以 Apache-2.0 许可发布，是系列中许可最宽松的成员。WorldFoundry 仅支持推理，提供本地 checkpoint、fps、帧数与 seed 控制。

## 用来做什么

用 `videocrafter2-t2v` 把一段文本提示词变成短视频。

U-Net 潜空间视频扩散模型，训练时将运动（来自视频）与外观（来自图像）解耦学习，见上游论文。该模型由腾讯 AI Lab发布。

任务：文生视频、视频生成。别名：`videocrafter2_t2v`。模态上，它接受文本，输出视频。

推荐评测：[EvalCrafter](/zh/docs/evaluation/benchmark-hub/evalcrafter)（VideoCrafter 项目的配套评测）、[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（标准文生视频评测）。

相关页面：[VideoCrafter](/zh/docs/guides/supported-models/videocrafter)（系列）与 [VideoCrafter1 T2V](/zh/docs/guides/supported-models/videocrafter1-t2v)。评测看 [EvalCrafter](/zh/docs/evaluation/benchmark-hub/evalcrafter)、[VBench](/zh/docs/evaluation/benchmark-hub/vbench)。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`seed` 等 8 项；产物 `generated_video`、`videocrafter2-t2v.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `VideoCrafter2T2VPipeline`。

系列状态：**Runner 一致性待确认**。

这是推荐的 VideoCrafter variant：质量优于 V1，许可为干净的 Apache-2.0。

## 在 WorldFoundry 中运行

启动命令是 `wf run videocrafter2-t2v --pipeline.task-profile default`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`VideoCrafter/VideoCrafter2`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh videocrafter2-t2v`；下载缺失的公开权重时加 `--download`。
