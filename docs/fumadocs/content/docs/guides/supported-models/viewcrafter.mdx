ViewCrafter is a novel-view-synthesis world model: from one or a few input images it synthesizes high-fidelity videos along new camera trajectories, using point-cloud priors from DUSt3R to anchor geometry. Four official Apache-2.0 checkpoints are confirmed on Hugging Face (ViewCrafter_25, _25_sparse, _16, _25_512) plus an official demo Space; WorldFoundry registers the official source route in-tree.

## What it is for

`viewcrafter` is the recorded interactive world line. Start here when the job is stepping a world with actions.

The design couples a point-cloud reconstruction prior (DUSt3R) with a video diffusion renderer: reconstructed geometry is re-projected along the target trajectory and the diffusion model fills in photoreal detail. Checkpoint variants cover 25-frame, sparse-view, 16-frame, and 512-resolution configurations.

Catalog tasks include world model.

Recorded evaluation entry points include [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Novel-view trajectory adherence and view quality).

## Running in WorldFoundry

Launch `worldfoundry-eval run viewcrafter --pipeline.task-profile world_model` to step the world. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `Drexubery/ViewCrafter_25`, `Drexubery/ViewCrafter_25_sparse`, and `Drexubery/ViewCrafter_16` among others. Stage assets with `bash scripts/inference/prepare_model_infer.sh viewcrafter`.
