ViewCrafter 是新视角合成方向的世界模型：从单张或少量输入图像出发，沿新的相机轨迹合成高保真视频，并用 DUSt3R 点云先验锚定几何。Hugging Face 上确认了四个官方 Apache-2.0 checkpoint（ViewCrafter_25、_25_sparse、_16、_25_512）与官方演示 Space；WorldFoundry 树内注册了官方源码路由。

## 用来做什么

`viewcrafter` 是记录的交互世界线。要用动作推进世界时从这里起步。

设计将点云重建先验（DUSt3R）与视频扩散渲染器耦合：沿目标轨迹重投影重建几何，再由扩散模型补全照片级细节。checkpoint 变体覆盖 25 帧、稀疏视角、16 帧与 512 分辨率配置。

catalog 记录的任务包括 世界模型。

记录的评测入口包括[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（新视角轨迹跟随与视图质量）。

## 运行时契约

产物 `generated_video`、`viewcrafter_runtime_plan.json`。

记录的任务 profile：`world_model`。绑定的 pipeline 类是 `ViewCrafterPipeline`。

系列状态：**Runner 一致性待确认**。

按帧数与分辨率需求选择 checkpoint 变体；DUSt3R 与视角资产同 checkpoint 一样为运行时门控。 配置解析与 pipeline 导入预期可通过；在所需 checkpoint/资产就位前，真实生成会输出运行时计划。 缺失资产由计划报告，不视为 catalog 阻塞。

checkpoint 与 DUSt3R/视角资产为运行时门控；仓库未记录 GPU 验证。
