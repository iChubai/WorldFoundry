## What it is for

`vlanext-libero` maps camera observations and an instruction to an action trajectory.

Public checkpoints cover the LIBERO suites (VLANeXt_libero_spatial.pt, _object.pt and more). It is published by Nanyang Technological University (S-Lab).

Tasks: VLA, VLA action prediction, and VLA policy rollout. Aliases: `vlanext-libero` and `vla-next`.

Suggested benchmarks: [LIBERO](/docs/evaluation/benchmark-hub/libero) (Official LIBERO checkpoint collection), [LIBERO-Plus](/docs/evaluation/benchmark-hub/libero-plus) (Official LIBERO-plus checkpoints are available).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `checkpoint-ref` and `official-policy-observation`; artifacts `action_trace` and `vlanext_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `VLANeXtPipeline`.

Family status: **Static load only**.

Download the LIBERO checkpoint for your suite from the DravenALG/VLANeXt collection before running. The S-Lab-1.0 license restricts commercial use.

S-Lab-1.0 license: source-available with research-use restrictions.

## Running in WorldFoundry

Run the policy with `wf run vlanext-libero --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8, torch==2.4.0).

Weights: `DravenALG/VLANeXt`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh vlanext-libero`. Add `--download` to fetch missing public checkpoints.
