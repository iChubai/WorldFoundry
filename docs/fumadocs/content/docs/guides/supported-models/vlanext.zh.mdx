## 用来做什么

`vlanext-libero` 把相机观测和指令映射为动作轨迹。

公开 checkpoint 覆盖 LIBERO 各套件（VLANeXt_libero_spatial.pt、_object.pt 等）。该模型由南洋理工大学（S-Lab）发布。

任务：视觉-语言-动作（VLA）、VLA 动作预测、VLA 策略执行。别名：`vlanext-libero`、`vla-next`。

推荐评测：[LIBERO](/zh/docs/evaluation/benchmark-hub/libero)（官方 LIBERO checkpoint 集合）、[LIBERO-Plus](/zh/docs/evaluation/benchmark-hub/libero-plus)（提供官方 LIBERO-plus checkpoint）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `checkpoint-ref`、`official-policy-observation`；产物 `action_trace`、`vlanext_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `VLANeXtPipeline`。

系列状态：**仅静态加载**。

运行前从 DravenALG/VLANeXt 集合下载对应套件的 LIBERO checkpoint。S-Lab-1.0 许可限制商业使用。

S-Lab-1.0 许可：源码可得，但仅限研究用途。

## 在 WorldFoundry 中运行

用 `wf run vlanext-libero --pipeline.task-profile default` 运行策略。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8，torch==2.4.0）。

权重仓库：`DravenALG/VLANeXt`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh vlanext-libero`；下载缺失的公开权重时加 `--download`。

许可证：S-Lab License 1.0。
