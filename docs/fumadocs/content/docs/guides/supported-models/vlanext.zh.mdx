**发表机构:** 南洋理工大学（S-Lab） · 高校

VLANeXt 是以 S-Lab License 1.0（源码可得、面向研究）发布的新一代 VLA，官方 LIBERO 与 LIBERO-plus checkpoint 收录于 DravenALG/VLANeXt 集合。WorldFoundry 从内置推理子集在进程内调用官方 get_vla/get_processor/get_vla_action 契约。

## 架构

公开 checkpoint 覆盖 LIBERO 各套件（VLANeXt_libero_spatial.pt、_object.pt 等）。官方仓库指针之外的架构内部细节仓库未记录。

## 使用要点

解析器、运行时导入与 compileall 检查无需外部 checkout 即通过；声称 demo parity 前仍需 checkpoint 驱动的动作块验证。注意 S-Lab-1.0 许可限制商业使用。
