VMem 是带「面元索引视图记忆」的交互式视频场景生成模型：当你在场景中游走时，它记住哪些表面曾从哪些视角被看到，使新视角与历史保持一致。已用发布的 VMem 与 CUT3R checkpoint 验证：树内 pipeline 复现了官方导航 demo。

## 用来做什么

`vmem` 以动作为条件生成未来帧。

VMem 以面元（surfel）索引历史视图，检索相关视图作为下一视角生成的条件（见论文 arXiv 2506.18903）。它以 CUT3R 为几何主干。该模型由牛津大学发布。

任务：视频生成、memory、stream、交互式世界模型。输出模态为视频。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（评估可相机游走的生成场景）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `vmem.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `VMemPipeline`。

系列状态：**已验证**。

输入为提示词、起始图像与导航/交互动作；输出为生成视频。runtime_root（或 VMEM_RUNTIME_ROOT）仅选择配置/数据目录，先查找其中的 configs/inference/inference.yaml，再回退到包内默认配置；config_path 可直接指定配置文件。Python 代码始终来自已安装的包。

需要在本地准备 VMem 与 CUT3R checkpoint，以及 Stable Diffusion 2.1 VAE 和 CLIP ViT-H-14 图像条件编码器。

## 在 WorldFoundry 中运行

运行 `wf run vmem --pipeline.task-profile interactive-video` 推演世界模型。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`liguang0115/vmem`、`liguang0115/cut3r`、`SagiPolaczek/stable-diffusion-2-1-base` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh vmem`；下载缺失的公开权重时加 `--download`。
