VQ-BeT (Vector-Quantized Behavior Transformer) generates behavior by tokenizing continuous actions with a hierarchical VQ-VAE and predicting those tokens with a transformer — capturing multimodal demonstrations without diffusion sampling costs. The catalog sources the official repository and routes it through an in-tree action runtime adapter.

## What it is for

Pick `vqbet` when you want the catalog VLA policy: instruction and observation in, an action trace out. Use it to roll the recorded policy, not to train a new one.

A residual VQ-VAE action tokenizer plus a GPT-style transformer over behavior tokens, with offset heads recovering continuous actions. Further internals are not recorded in this repository.

Catalog tasks include behavior generation, imitation learning, robot policy, and policy rollout. Catalog aliases include `vq-bet` and `vector-quantized-behavior-transformer`.

## Runtime contract

Required `image`, `prompt`, and `state`; optional `model_id` (vqbet), `policy_family`, and `action_representation`; artifacts `action_trace` and `vqbet_action_trace.json`.

Recorded task profiles: `behavior_generation`, `imitation_learning`, `robot_policy`, and `policy_rollout`. WorldFoundry binds `VQBeTPipeline`.

## Running in WorldFoundry

Launch `worldfoundry-eval run vqbet --pipeline.task-profile behavior_generation` to execute the policy. The command builder above switches `--pipeline.task-profile` among recorded tasks and still emits `worldfoundry-eval run`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Recorded weight repositories include `lerobot/vqbet`. Stage assets with `bash scripts/inference/prepare_model_infer.sh vqbet`.
