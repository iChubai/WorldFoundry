VQ-BeT（向量量化行为 Transformer）用分层 VQ-VAE 将连续动作 token 化，再以 transformer 预测这些 token 来生成行为——无需扩散采样开销即可捕捉多模态示范。catalog 以官方仓库为源，经树内动作运行时适配器路由。

## 用来做什么

需要 catalog 上的 VLA 策略时选 `vqbet`：指令与观测进、动作轨迹出。用来滚动已记录策略，不是用来训练新策略。

残差 VQ-VAE 动作 tokenizer 加 GPT 式行为 token transformer，偏移头恢复连续动作。更多内部细节仓库未记录。

catalog 记录的任务包括 行为生成、模仿学习、机器人策略、策略执行。别名包括 `vq-bet`、`vector-quantized-behavior-transformer`。

## 运行时契约

必填 `image`、`prompt`、`state`；可选 `model_id` (vqbet)、`policy_family`、`action_representation`；产物 `action_trace`、`vqbet_action_trace.json`。

记录的任务 profile：`behavior_generation`、`imitation_learning`、`robot_policy`、`policy_rollout`。绑定的 pipeline 类是 `VQBeTPipeline`。
