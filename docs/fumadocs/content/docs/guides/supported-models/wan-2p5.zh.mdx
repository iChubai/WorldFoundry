Wan 2.5 API 是阿里巴巴通义万相 Wan 2.5 视频生成模型的 DashScope 托管接入点，记录文生视频与图生视频任务。与本 catalog 中可本地运行的开源 Wan 权重不同，本条目覆盖的是服务方托管的生成路径：请求发往阿里云 DashScope，成片以产物形式返回。别名 wan2.5、wan-2.5 同样解析到本条目。

## 架构

托管版 Wan 2.5 属于 Wan 系列（阿里通义实验室研发的扩散 Transformer 视频生成模型），但 API 所服务修订版的确切架构与规模并未公开，本仓库仅记录端点集成信息。

## 使用要点

Catalog 将该条目标记为 integrated：托管 API 的 Studio pipeline 已可用，但你必须自备服务方的 API key 与账号。本地不会下载任何权重、也不会创建 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。API key 通过阿里云 DashScope（dashscope.aliyun.com）开通。
