Wan 2.6 API is the DashScope-hosted image-to-video endpoint for Alibaba's Wan 2.6 model. You provide a start image and receive a rendered clip from Alibaba Cloud; WorldFoundry records the request and stores the result in its standard artifact layout. ## Architecture

Wan 2.6 continues the Wan diffusion-transformer video family from Tongyi Lab; the API-served revision's precise architecture and parameters are not published, and this repository records only the hosted integration.

## Usage notes

The catalog marks this entry as integrated: the hosted-API Studio pipeline is available, but you must supply your own provider API key and account. No weights are downloaded and no GPU environment is provisioned locally — generation happens on the provider side, so cost, quota, and content policy follow your provider account. Keys are issued via Alibaba Cloud DashScope (dashscope.aliyun.com).
