Wan 2.6 API is the DashScope-hosted image-to-video endpoint for Alibaba's Wan 2.6 model. You provide a start image and receive a rendered clip from Alibaba Cloud; WorldFoundry stores the request and the result in its standard artifact layout. Aliases: wan2.6 and wan-2.6. Choose it when you want the newer hosted Wan generation without local GPU setup.

## What it is for

`wan-2p6` is served by its provider's API rather than local weights.

Wan 2.6 continues the Wan diffusion-transformer video family from Tongyi Lab; the API-served revision's precise architecture and parameters are not published. It is published by Alibaba (Tongyi Lab).

Tasks: image-to-video and hosted api. Aliases: `wan2.6` and `wan-2.6`. Modalities: image in, video out.

Suggested benchmarks: [VBench](/docs/evaluation/benchmark-hub/vbench) (Standard multi-dimension quality suite for comparing hosted text/image-to-video outputs), [Physics-IQ Original](/docs/evaluation/benchmark-hub/physics-iq) (Probes whether provider-side video models respect basic physical plausibility).

Wan 2.6 API is DashScope **image-to-video** and does not use local Wan weights. For hosted text-to-video, see [Wan 2.5](/docs/guides/supported-models/wan-2p5).

Launch `wf run wan-2p6`. Send a start image; take the returned clip. Sibling: [Wan 2.7 API](/docs/guides/supported-models/wan-2p7).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted).

CLI task profiles: `default`. WorldFoundry binds `Wan2p6Pipeline`.

Family status: **Runner parity pending**.

The hosted-API Studio pipeline is available; supply your own provider API key and account. No weights are downloaded and no local GPU environment is needed — generation happens on the provider side, so cost, quota, and content policy follow your provider account. Keys are issued via Alibaba Cloud DashScope (dashscope.aliyun.com).

Requires a paid provider account and API key; WorldFoundry does not ship credentials.

## Running in WorldFoundry

Run `wf run wan-2p6 --pipeline.task-profile default` to call the provider API.

No runtime environment is recorded for this model.

Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh wan-2p6`. Add `--download` to fetch missing public checkpoints.
