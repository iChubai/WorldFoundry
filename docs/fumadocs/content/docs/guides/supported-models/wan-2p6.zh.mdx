Wan 2.6 API 是阿里 Wan 2.6 模型的 DashScope 托管图生视频接入点。你提供起始图，阿里云返回渲染好的视频；WorldFoundry 按标准产物布局保存请求与结果。别名：wan2.6、wan-2.6。想在无本地 GPU 的情况下使用较新的托管 Wan 版本时选择它。

## 用来做什么

`wan-2p6` 通过提供商的 API 提供服务，而非使用本地权重。

Wan 2.6 延续通义实验室 Wan 系列扩散 Transformer 视频模型的脉络；API 使用的模型修订版，其确切架构与参数未公开。该模型由阿里巴巴（通义实验室）发布。

任务：图生视频、托管 API。别名：`wan2.6`、`wan-2.6`。模态上，它接受图像，输出视频。

推荐评测：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)（对比托管文/图生视频输出的标准多维质量评测）、[Physics-IQ Original](/zh/docs/evaluation/benchmark-hub/physics-iq)（检验服务方视频模型是否遵循基本物理合理性）。

Wan 2.6 API 是 DashScope **图生视频**，不使用本地 Wan 权重。托管文生视频见 [Wan 2.5](/zh/docs/guides/supported-models/wan-2p5)。

启动 `wf run wan-2p6`。输入起始图后返回成片。相邻版本：[Wan 2.7 API](/zh/docs/guides/supported-models/wan-2p7)。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）。

CLI task profile：`default`。绑定的 pipeline 类是 `Wan2p6Pipeline`。

托管 API 的 Studio pipeline 已可用，需自备服务方的 API key 与账号。本地不下载权重，也不需要 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。API key 通过阿里云 DashScope（dashscope.aliyun.com）开通。

需要付费的服务方账号与 API key；WorldFoundry 不提供任何凭据。

模型版本由服务方控制，即使 WorldFoundry 未变化，输出也可能随时间改变。

## 在 WorldFoundry 中运行

运行 `wf run wan-2p6 --pipeline.task-profile default` 调用提供商 API。

该模型未记录运行环境。

准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh wan-2p6`；下载缺失的公开权重时加 `--download`。
