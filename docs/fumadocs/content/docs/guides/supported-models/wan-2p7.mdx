Wan 2.7 API is Alibaba's DashScope-hosted Wan 2.7 endpoint for image-to-video. As with the Wan 2.5/2.6 APIs, WorldFoundry submits the start image to Alibaba Cloud and archives the returned clip; the aliases wan2.7 and wan-2.7 resolve to it. Alibaba controls the exact served model revision.

## What it is for

Wan 2.7 API is DashScope **image-to-video** — send a start image, archive the returned clip. It is not local [Wan2.2](/docs/guides/supported-models/wan2.2) and not [Wan 2.6 API](/docs/guides/supported-models/wan-2p6).

Launch `wf run wan-2p7`. Aliases `wan2.7` and `wan-2.7` resolve here. For hosted text-to-video use [Wan 2.5](/docs/guides/supported-models/wan-2p5).

Related suites: [VBench](/docs/evaluation/benchmark-hub/vbench) and [Physics-IQ](/docs/evaluation/benchmark-hub/physics-iq).

## Runtime contract

Hosted I2V only. No local resolution, frame, or step table — those knobs live on the DashScope request. Bring your own provider key. Alibaba controls the served revision.

## Running in WorldFoundry

No GPU environment is provisioned. Issue a DashScope key at dashscope.aliyun.com, then launch `wf run wan-2p7`. Cost, quota, and content policy follow your Alibaba Cloud account.
