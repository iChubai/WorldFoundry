Wan 2.7 API 是本 catalog 中最新的 DashScope 托管 Wan 接入点，记录图生视频任务。集成方式与 Wan 2.5/2.6 条目一致——WorldFoundry 把起始图提交给阿里云并归档返回的视频——并带有 wan2.7、wan-2.7 两个别名。注意实际服务的模型修订版由阿里控制，而非本仓库。

## 架构

Wan 2.7 属于通义实验室的 Wan 视频生成系列；其 API 版本的架构与规模未公开，本仓库仅记录端点集成信息。

## 使用要点

Catalog 将该条目标记为 integrated：托管 API 的 Studio pipeline 已可用，但你必须自备服务方的 API key 与账号。本地不会下载任何权重、也不会创建 GPU 环境——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。API key 通过阿里云 DashScope（dashscope.aliyun.com）开通。
