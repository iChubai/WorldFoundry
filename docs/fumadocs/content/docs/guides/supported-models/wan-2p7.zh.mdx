Wan 2.7 API 是阿里云 DashScope 托管的 Wan 2.7 图生视频接入点。与 Wan 2.5/2.6 API 一样，WorldFoundry 把起始图提交给阿里云并归档返回的视频；别名 wan2.7、wan-2.7 同样指向它。实际服务的模型修订版由阿里控制。

## 用来做什么

Wan 2.7 API 是 DashScope **图生视频**——以起始图为输入，并归档生成的成片。它不是本地 [Wan2.2](/zh/docs/guides/supported-models/wan2.2)，也不是 [Wan 2.6 API](/zh/docs/guides/supported-models/wan-2p6)。

启动 `wf run wan-2p7`。别名 `wan2.7`、`wan-2.7` 解析到这里。托管文生视频走 [Wan 2.5](/zh/docs/guides/supported-models/wan-2p5)。

相关套件：[VBench](/zh/docs/evaluation/benchmark-hub/vbench)、[Physics-IQ](/zh/docs/evaluation/benchmark-hub/physics-iq)。

## 运行时契约

仅托管图生视频。没有本地分辨率、帧数或步数表——这些参数在 DashScope 请求中设置。自备服务方密钥。服务修订版由阿里控制。

## 在 WorldFoundry 中运行

不创建本地 GPU 环境。在 dashscope.aliyun.com 开通 DashScope key，然后启动 `wf run wan-2p7`。费用、配额与内容政策以阿里云账号为准。
