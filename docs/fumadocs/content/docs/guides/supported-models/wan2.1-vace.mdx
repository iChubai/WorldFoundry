Wan2.1 VACE is the all-in-one video creation and editing member of the Wan2.1 family: reference-image guidance, video-to-video editing, and mask/control-conditioned generation in one checkpoint. WorldFoundry assembles it from the standard Wan components and supports image references, source video/mask conditions, and precomputed VACE context tensors; no upstream VACE runtime is needed.

## What it is for

Start on `wan2.1-vace`. Launch `wf run wan2.1-vace`. Use it for reference-image create/edit, V2V, and mask/control — not as the plain Wan2.1 T2V backbone.

[VBench](/docs/evaluation/benchmark-hub/vbench) is the listed quality suite.

## Runtime contract

Required `prompt`; optional `image` / `video`. Native defaults: **1280×720, 81 frames, 50 steps, guidance 5.0**. Artifact: `wan2.1-vace.mp4`. Image references, source video/mask conditions, and precomputed VACE context tensors are supported; no upstream VACE runtime is needed.

## Running in WorldFoundry

Unified `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `Wan-AI/Wan2.1-VACE-14B` or `Wan-AI/Wan2.1-VACE-1.3B-diffusers`. Prepare masks and references before launch.
