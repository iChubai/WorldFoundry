Wan2.1 VACE 是 Wan2.1 系列中「创作与编辑一体」的成员：参考图引导、视频到视频编辑与掩码/控制条件生成集于一个 checkpoint。WorldFoundry 用规范化 Wan 角色装配它；图像参考、源视频/掩码条件与预计算的 VACE 上下文张量均受支持，无需官方运行时后端。

## 架构

VACE 在 Wan2.1 DiT 上增加了视频条件与编辑上下文分支。原生默认保留官方 VACE-14B 推理形状：1280x720、81 帧、50 步、guidance scale 5.0。同时记录 14B checkpoint 与 1.3B diffusers variant。

## 使用要点

runner 状态为 integrated：加载、放置、offload、采样与产物写盘由共享基础设施承担，完整的 checkpoint 视觉一致性仍是一项 GPU 验证任务。按所需编辑模式准备参考图或「源视频 + 掩码」组合。
