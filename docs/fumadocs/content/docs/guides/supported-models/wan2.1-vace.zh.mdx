Wan2.1 VACE 是 Wan2.1 系列中「创作与编辑一体」的成员：参考图引导、视频到视频编辑与掩码/控制条件生成集于一个 checkpoint。WorldFoundry 用标准 Wan 组件装配它，支持图像参考、源视频/掩码条件与预计算的 VACE 上下文张量，无需上游 VACE 运行时。

## 用来做什么

从 `wan2.1-vace` 开始。启动 `wf run wan2.1-vace`。参考图创建/编辑、V2V 与 mask/控制均使用此模型，不要将其当作普通 Wan2.1 文生视频骨干。

质量评测见 [VBench](/zh/docs/evaluation/benchmark-hub/vbench)。

## 运行时契约

必填 `prompt`；可选 `image` / `video`。原生默认：**1280×720、81 帧、50 步、guidance 5.0**。产物：`wan2.1-vace.mp4`。支持参考图、源视频/mask 条件以及预计算 VACE context tensor，无需上游 VACE 运行时。

## 在 WorldFoundry 中运行

统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。准备好 `Wan-AI/Wan2.1-VACE-14B` 或 `Wan-AI/Wan2.1-VACE-1.3B-diffusers`。启动前准备 mask 与参考图。
