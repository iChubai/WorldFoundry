Wan2.1 is Alibaba Tongyi Lab's open video generation family and the backbone of a large part of this catalog — many world-model and control entries build on it. Four variants are recorded here: T2V 1.3B, T2V 14B, and I2V 14B at 480p and 720p. Only official Wan-Video GitHub and Wan-AI Hugging Face repositories are listed as sources.

## Architecture

Wan2.1 is a diffusion transformer with a spatio-temporal Wan-VAE and UMT5 text encoding (per the upstream release). In this repository the 1.3B T2V has an independent canonical native diffusion recipe; the recorded contract exposes prompt/image/video/actions inputs and a generated_video artifact.

## Usage notes

Read the status carefully: the runner-parity field says verified for the registered pipeline target, but the manifest notes that family-level integration remains planned because T2V-14B and the I2V variants have not passed checkpoint, official-demo, and runner parity. The 1.3B route is the safest starting point; its public binding stays unchanged until CUDA artifact parity passes.
