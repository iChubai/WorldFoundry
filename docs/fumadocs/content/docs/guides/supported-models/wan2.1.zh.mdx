Wan2.1 是阿里通义实验室的开源视频生成系列，也是本 catalog 相当一部分条目的基座——许多世界模型与控制类条目都构建在它之上。此处记录四个 variant：T2V 1.3B、T2V 14B，以及 480p 与 720p 的 I2V 14B。来源只列官方 Wan-Video GitHub 与 Wan-AI Hugging Face 仓库。

## 架构

Wan2.1 是扩散 Transformer，配时空 Wan-VAE 与 UMT5 文本编码（见上游发布）。在本仓库中， 1.3B T2V 拥有独立的规范化原生扩散配方；记录契约为 prompt/image/video/actions 输入与 generated_video 产物。

## 使用要点

状态要仔细读：runner parity 字段对已注册 pipeline target 记为 verified，但 manifest 注明系列级集成仍为 planned——因为 T2V-14B 与 I2V variant 尚未通过 checkpoint、官方 demo 与 runner 三重一致性。1.3B 路径是最稳妥的起点；在 CUDA 产物一致性通过前，其公开 binding 保持不变。
