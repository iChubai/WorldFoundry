Wan2.2 is Alibaba Tongyi Lab's next Wan generation — tracked separately from [Wan2.1](/docs/guides/supported-models/wan2.1) because upstream versions the code and checkpoints on their own. The family has three Apache-2.0 Hugging Face checkpoints: **T2V A14B** (MoE text-to-video), **I2V A14B** (MoE image-to-video), and **TI2V 5B** (dense text+image-to-video). Only the 5B variant has been validated.

The official paper is still [Wan: Open and Advanced Large-Scale Video Generative Models](https://arxiv.org/abs/2503.20314). Code and weights live at [Wan-Video/Wan2.2](https://github.com/Wan-Video/Wan2.2) and [Wan-AI](https://huggingface.co/Wan-AI). The project site is [wan.video](https://wan.video). Aliases `wan-2p2` and `wan2p2` resolve here.

## What it is for

Start on `wan2.2-ti2v-5b` for a validated clip. Its defaults are **1280×704** (or **704×1280**), **121 frames**, **24 fps**, **50 UniPC steps**, guidance **5.0**, flow-shift **5.0**, writing `wan2.2-ti2v-5b-1280x704-121f.mp4`. Prompt is required; an image switches the same 5B weights from T2V to I2V. It needs at least **24 GB** of VRAM.

Use `wan2.2-t2v-a14b` for the dual-expert text-to-video card and `wan2.2-i2v-a14b` when a still is the conditioner. The A14B variants run, but their output has not been validated against the official implementation.

There is **no V2V** route. Upstream Speech-to-Video (`Wan2.2-S2V-14B`) and Animate (`Wan2.2-Animate-14B`) exist on GitHub and Hugging Face but are not supported. Compare general clip quality on [VBench](/docs/evaluation/benchmark-hub/vbench).

## Inference

Native sampling is **UniPC only**. The three WorldFoundry defaults:

| Variant | Task | Size / frames / fps | Steps · guidance · shift | VRAM | Validated |
| --- | --- | --- | --- | --- | --- |
| `wan2.2-ti2v-5b` | T2V or I2V on one 5B card | 1280×704, 121f, 24 fps | 50 · 5.0 · 5.0 | 24 GB | yes |
| `wan2.2-t2v-a14b` | T2V MoE | 832×480, 81f, 16 fps | 40 · high 4.0 / low 3.0 · 12.0 | 80 GB | no |
| `wan2.2-i2v-a14b` | I2V MoE | 832×480, 81f, 16 fps | 40 · 3.5 / 3.5 · 5.0 | 80 GB | no |

A14B inference swaps a high-noise expert and a low-noise expert across the schedule (boundaries **0.875** T2V, **0.900** I2V). Official A14B generate scripts also advertise 480p and 720p (`1280×720`) at ≥80 GB with `--offload_model`; those sizes are upstream options, not the validated WorldFoundry defaults. TI2V 5B uses the high-compression Wan2.2-VAE (**16×16×4**). Seed is passed in the `actions` field (`base_seed` default 42 in the command builder). Prompt extension is off by default.

## Running in WorldFoundry

Install the unified environment with `bash scripts/setup/unified_install.sh` (Python 3.11, CUDA 12.8) and stage weights locally — the runtime does not download them. Launch with `wf run wan2.2-ti2v-5b`. Pipelines are `Wan2p2Pipeline` (5B), `Wan2p2T2VA14BPipeline`, and `Wan2p2I2VA14BPipeline`.

Checkpoints: `Wan-AI/Wan2.2-TI2V-5B`, `Wan-AI/Wan2.2-T2V-A14B`, `Wan-AI/Wan2.2-I2V-A14B` (all `apache-2.0`, public, not gated). The A14B variants need **80 GB** of VRAM; the 5B variant needs 24 GB.
