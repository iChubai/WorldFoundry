Wan2.2 是阿里巴巴通义实验室的下一代 Wan，因上游代码与 checkpoint 独立版本化而与 [Wan2.1](/zh/docs/guides/supported-models/wan2.1) 分开跟踪。该家族有三个 Apache-2.0 的 Hugging Face checkpoint：**T2V A14B**（MoE 文生视频）、**I2V A14B**（MoE 图生视频）、**TI2V 5B**（稠密图文生视频）。只有 5B variant 已验证。

官方论文仍是 [Wan: Open and Advanced Large-Scale Video Generative Models](https://arxiv.org/abs/2503.20314)。代码与权重在 [Wan-Video/Wan2.2](https://github.com/Wan-Video/Wan2.2) 和 [Wan-AI](https://huggingface.co/Wan-AI)。项目站是 [wan.video](https://wan.video)。也可使用别名 `wan-2p2`、`wan2p2`。

## 用来做什么

需要已验证的片段时，从 `wan2.2-ti2v-5b` 入手。默认设置是 **1280×704**（或 **704×1280**）、**121 帧**、**24 fps**、**50 步 UniPC**、guidance **5.0**、flow-shift **5.0**，写出 `wan2.2-ti2v-5b-1280x704-121f.mp4`。必填 prompt；加上 image 时，同一套 5B 权重从文生视频切到图生视频。该 variant 至少需要 **24 GB** 显存。

要跑双专家文生视频用 `wan2.2-t2v-a14b`，以静帧为条件用 `wan2.2-i2v-a14b`。两条 A14B variant 可以运行，但输出尚未与官方实现对照验证。

**没有 V2V** 路径。上游的 Speech-to-Video（`Wan2.2-S2V-14B`）和 Animate（`Wan2.2-Animate-14B`）在 GitHub / Hugging Face 上存在，但不受支持。通用片段质量可对照 [VBench](/zh/docs/evaluation/benchmark-hub/vbench)。

## 推理

原生采样目前只支持 **UniPC**。三条 WorldFoundry 默认配置：

| Variant | 任务 | 分辨率 / 帧数 / fps | 步数 · guidance · shift | 显存 | 已验证 |
| --- | --- | --- | --- | --- | --- |
| `wan2.2-ti2v-5b` | 同一 5B 卡上文生或图生 | 1280×704，121 帧，24 fps | 50 · 5.0 · 5.0 | 24 GB | 是 |
| `wan2.2-t2v-a14b` | T2V MoE | 832×480，81 帧，16 fps | 40 · 高噪 4.0 / 低噪 3.0 · 12.0 | 80 GB | 否 |
| `wan2.2-i2v-a14b` | I2V MoE | 832×480，81 帧，16 fps | 40 · 3.5 / 3.5 · 5.0 | 80 GB | 否 |

A14B 推理在时间步上切换高噪专家与低噪专家（边界：T2V **0.875**，I2V **0.900**）。官方 A14B 脚本还宣传 480p / 720p（`1280×720`），单卡需 ≥80 GB 并配合 `--offload_model`；那些尺寸是上游选项，不是 WorldFoundry 已验证的默认设置。TI2V 5B 使用高压缩 Wan2.2-VAE（**16×16×4**）。seed 通过 `actions` 字段传入（命令构建器里 `base_seed` 默认 42）。prompt extension 默认关闭。

## 在 WorldFoundry 中运行

用 `bash scripts/setup/unified_install.sh` 安装统一环境（Python 3.11，CUDA 12.8），并在本地就位权重——运行时不会下载。启动命令是 `wf run wan2.2-ti2v-5b`。Pipeline 分别为 `Wan2p2Pipeline`（5B）、`Wan2p2T2VA14BPipeline`、`Wan2p2I2VA14BPipeline`。

Checkpoint：`Wan-AI/Wan2.2-TI2V-5B`、`Wan-AI/Wan2.2-T2V-A14B`、`Wan-AI/Wan2.2-I2V-A14B`（均为 `apache-2.0`，公开、非 gated）。A14B variant 需要 **80 GB** 显存；5B variant 需要 24 GB。
