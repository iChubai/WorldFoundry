Wan2.1-Fun V1.1 14B Control Camera is Alibaba PAI's largest Wan2.1-generation camera-control checkpoint in the VideoX-Fun family: image-to-video generation steered by explicit camera pose sequences. WorldFoundry bundles VideoX-Fun (revision 403f1f7b) and runs the alibaba-pai/Wan2.1-Fun-V1.1-14B-Control-Camera checkpoint, released under Apache-2.0.

## What it is for

Use `wan21-fun-14b-cam` when the viewpoint must follow a given camera path.

A 14B-parameter Wan2.1 diffusion transformer with the VideoX-Fun Control-Camera conditioning pathway: camera extrinsics are injected as control signals alongside the image condition. It is published by Alibaba PAI (VideoX-Fun).

Tasks: camera-controlled video and image-to-video. Modalities: image in, video out.

Suggested benchmarks: [CameraBench](/docs/evaluation/benchmark-hub/camerabench) (Camera-pose adherence for controlled i2v generation).

For the base model see [Wan2.1](/docs/guides/supported-models/wan2.1); for the smaller camera-control checkpoint see [Wan2.1 Fun 1.3B Cam](/docs/guides/supported-models/wan21-fun-1p3b-cam). Score on [CameraBench](/docs/evaluation/benchmark-hub/camerabench).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `frames`, `fps`, `height`, `width`, `steps`, `seed`, and 1 more; artifacts `wan21-fun-14b-cam.mp4`.

CLI task profiles: `default`. WorldFoundry binds `Wan21Fun14BCameraPipeline`.

Family status: **Runner parity pending**.

Camera pose sequences must be supplied explicitly. The sibling wan21-fun-1p3b-cam runs the same route at 1.3B scale and is GPU-validated; use it as a reference.

WorldFoundry bundles VideoX-Fun at revision `403f1f7b78dcafccc4f6606dda4ec28e16e667dc`.

## Running in WorldFoundry

Run `wf run wan21-fun-14b-cam --pipeline.task-profile default` to follow the camera path.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `alibaba-pai/Wan2.1-Fun-V1.1-14B-Control-Camera`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh wan21-fun-14b-cam`. Add `--download` to fetch missing public checkpoints.
