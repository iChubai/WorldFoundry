Wan2.1-Fun V1.1 1.3B Control Camera 是 VideoX-Fun 家族的 1.3B 相机控制模型：按显式相机位姿从图像生成视频。已使用发布的 checkpoint 完成验证：官方位姿条件路由经四步去噪生成 672x384 的九帧连贯 H.264 视频。

## 用来做什么

视角需要沿指定相机路径运动时，用 `wan21-fun-1p3b-cam`。

1.3B 参数的 Wan2.1 扩散 Transformer，叠加 VideoX-Fun Control+i2v 相机条件通路。该模型由阿里云 PAI（VideoX-Fun）发布。

任务：相机可控视频、图生视频。模态上，它接受图像，输出视频。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（受控图生视频的相机位姿跟随）。

相关页面：[Wan2.1](/zh/docs/guides/supported-models/wan2.1) 与更大的 [Wan2.1 Fun 14B Cam](/zh/docs/guides/supported-models/wan21-fun-14b-cam)。评测看 [CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`seed` 等 7 项；产物 `wan21-fun-1p3b-cam.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `Wan21Fun1P3BCameraPipeline`。

系列状态：**已验证**。

这是 VideoX-Fun 相机控制的推荐起点：资源占用最小，且是唯一已在 GPU 上验证的 VideoX-Fun 相机变体。需显式提供相机位姿序列；流程运行成功后再升级到 14B/Wan2.2 变体。

## 在 WorldFoundry 中运行

用 `wf run wan21-fun-1p3b-cam --pipeline.task-profile default` 生成相机可控视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`alibaba-pai/Wan2.1-Fun-V1.1-1.3B-Control-Camera`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh wan21-fun-1p3b-cam`；下载缺失的公开权重时加 `--download`。
