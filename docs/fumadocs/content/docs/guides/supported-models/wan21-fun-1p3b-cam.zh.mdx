## 架构

1.3B 参数的 Wan2.1 扩散 Transformer，叠加 VideoX-Fun Control+i2v 相机条件通路。 checkpoint 与树内 989 个 transformer 张量全部匹配、无回退、无跳过的相机权重，确认转换精确。

## 使用要点

这是 VideoX-Fun 相机控制的推荐起点：占用最小，且是唯一记录了真实 GPU 验证的变体。需显式提供相机位姿序列；流程跑通后再升级到 14B/Wan2.2 变体。
