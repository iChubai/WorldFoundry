Wan2.2-Fun 5B Control Camera 将 VideoX-Fun 相机控制通路带入 Wan2.2 世代的 5B 规模：由显式相机位姿操控的图生视频，上游原生规格为 121 帧、24 FPS。权重：alibaba-pai/Wan2.2-Fun-5B-Control-Camera（Apache-2.0）。

## 用来做什么

`wan22-fun-5b-cam` 以相机位姿为条件生成视频。

5B 参数的 Wan2.2 扩散 Transformer，叠加 VideoX-Fun Control-Camera 条件通路。该模型由阿里云 PAI（VideoX-Fun）发布。

任务：相机可控视频、图生视频。模态上，它接受图像，输出视频。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（受控图生视频的相机位姿跟随）、[WRBench](/zh/docs/evaluation/benchmark-hub/wrbench)（原生 121 帧/24FPS 规格适配 WRBench 式请求）。

需要基础 Wan2.2 生成或 A14B 相机控制模型时，改用 [Wan2.2](/zh/docs/guides/supported-models/wan2.2) 或 [Wan2.2 Fun A14B Cam](/zh/docs/guides/supported-models/wan22-fun-a14b-cam)。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`seed` 等 7 项；产物 `wan22-fun-5b-cam.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `Wan22Fun5BCameraPipeline`。

系列状态：**Runner 一致性待确认**。

上游原生规格为 121 帧、24 FPS；WRBench 请求会显式传值，请主动设置帧数与 FPS，而非依赖默认值。

## 在 WorldFoundry 中运行

用 `wf run wan22-fun-5b-cam --pipeline.task-profile default` 生成相机可控视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`alibaba-pai/Wan2.2-Fun-5B-Control-Camera`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh wan22-fun-5b-cam`；下载缺失的公开权重时加 `--download`。
