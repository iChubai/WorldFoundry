Wan2.2-Fun A14B Control Camera 是 VideoX-Fun 家族中 Wan2.2 世代最大的相机控制 checkpoint：采用 A14B（专家混合式）扩散骨干，可根据显式相机位姿序列控制图生视频。使用 alibaba-pai/Wan2.2-Fun-A14B-Control-Camera checkpoint（Apache-2.0 许可）。

## 用来做什么

`wan22-fun-a14b-cam` 生成相机可控视频：输入相机轨迹，输出沿轨迹运动的视频。

A14B 规模的 Wan2.2 扩散骨干，叠加 VideoX-Fun Control-Camera 条件通路。该模型由阿里云 PAI（VideoX-Fun）发布。

任务：相机可控视频、图生视频。模态上，它接受图像，输出视频。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（受控图生视频的相机位姿跟随）。

相关模型：[Wan2.2](/zh/docs/guides/supported-models/wan2.2)、[Wan2.2 Fun 5B Cam](/zh/docs/guides/supported-models/wan22-fun-5b-cam)。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `frames`、`fps`、`height`、`width`、`steps`、`seed` 等 7 项；产物 `wan22-fun-a14b-cam.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `Wan22FunA14BCameraPipeline`。

系列状态：**Runner 一致性待确认**。

建议先在已通过 GPU 验证的 1.3B 同系列版本上成功运行流程，再使用此变体追求最高质量的相机控制生成效果；A14B checkpoint 是家族中显存需求最大的。

## 在 WorldFoundry 中运行

运行 `wf run wan22-fun-a14b-cam --pipeline.task-profile default` 沿相机路径生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`alibaba-pai/Wan2.2-Fun-A14B-Control-Camera`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh wan22-fun-a14b-cam`；下载缺失的公开权重时加 `--download`。
