Warp-as-History（WAH）是相机可控的图生视频方法：沿请求的相机轨迹对输入图像做 warp，并把这些 warp 当作「历史帧」交给视频模型细化。集成与 runner 状态均为 verified——使用就位的 Helios-Distilled 与 LoRA checkpoint 通过 GPU 一致性验证，复现了官方 BMX/涂鸦 warp 视频 demo。

## 架构

WAH = 几何 warp + Helios-Distilled diffusers 运行时 + 任务 LoRA；Pi3 子模块代码被内置，用于相机位姿到 warp 的渲染。checkpoint 保持外部，通过 model_path/lora_path/pi3x_ckpt_path 或对应的 WAH_* 环境变量注入。

## 使用要点

该模型有意使用专用 conda 环境：官方栈固定 Python 3.10 与 torch 2.5.0+cu121——请勿在统一环境中运行。只有从相机位姿渲染 warp 时才需要 Pi3X。
