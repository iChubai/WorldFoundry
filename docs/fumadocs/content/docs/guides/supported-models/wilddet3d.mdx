## What it is for

`wilddet3d` generates a 3D-consistent world rather than a single clip.

The official model combines SAM3 image features and LingBot-Depth geometry; upstream source and submodules are loaded from a pinned external checkout. It is published by Allen Institute for AI (AI2).

Tasks: 3D detection, wild 3D perception, and world understanding.

## Runtime contract

Artifacts `generated_3d_asset` and `wilddet3d_predictions.npz`.

CLI task profiles: `default`. WorldFoundry binds `WildDet3DPipeline`.

Family status: **Verified**.

Provide image_path and comma-separated classes in the prompt; optionally provide intrinsics_path for a finite 3x3 .npy matrix. Stage the full allenai/WildDet3D checkpoint, robbyant/lingbot-depth-postrain-dc-vitl14/model.pt, and pinned official checkout with submodules. The upstream source uses the SAM License.

Perception-only: no video or world generation output.

## Running in WorldFoundry

Generate a world with `wf run wilddet3d --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `allenai/WildDet3D` and `robbyant/lingbot-depth-postrain-dc-vitl14`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh wilddet3d`. Add `--download` to fetch missing public checkpoints.
