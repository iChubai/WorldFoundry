## 用来做什么

`wilddet3d` 生成 3D 一致的世界，而不只是一段视频。

官方模型结合 SAM3 图像特征与 LingBot-Depth 几何信息；源码和子模块从仓库外的固定版本检出加载。

任务：3d-detection、wild-3d-perception、world-understanding。

## 运行时契约

产物 `generated_3d_asset`、`wilddet3d_predictions.npz`。

CLI task profile：`default`。绑定的 pipeline 类是 `WildDet3DPipeline`。

系列状态：**已验证**。

传入 image_path，并用英文逗号分隔 prompt 中的检测类别；可选传入 3x3 的 intrinsics_path（.npy）。需要完整的 allenai/WildDet3D checkpoint、robbyant/lingbot-depth-postrain-dc-vitl14/model.pt，以及含子模块的官方固定版本源码。上游源码使用 SAM License。

仅感知：不产出视频或世界生成结果。

## 在 WorldFoundry 中运行

用 `wf run wilddet3d --pipeline.task-profile default` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`allenai/WildDet3D`、`robbyant/lingbot-depth-postrain-dc-vitl14`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh wilddet3d`；下载缺失的公开权重时加 `--download`。
