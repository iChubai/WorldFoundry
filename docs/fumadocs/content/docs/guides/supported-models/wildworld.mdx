## What it is for

`wildworld` generates a 3D-consistent world rather than a single clip.

As an evaluation pipeline its output artifact is an evaluation_report.

Tasks: world model benchmark, dataset, and evaluation.

## Runtime contract

Artifacts `evaluation_report` and `wildworld_runtime_plan.json`.

CLI task profiles: `default`. WorldFoundry binds `WildWorldPipeline`.

Family status: **Runner parity pending**.

Until the required checkpoints and assets are staged, a run emits a runtime plan that lists the missing assets instead of evaluating.

Upstream source status is unconfirmed; verify provenance before relying on it.

## Running in WorldFoundry

Generate a world with `wf run wildworld --pipeline.task-profile default`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

No public checkpoint is listed for this model; stage the weights as described in the usage notes. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh wildworld`. Add `--download` to fetch missing public checkpoints.
