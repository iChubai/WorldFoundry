## 用来做什么

`wildworld` 生成 3D 一致的世界，而不只是一段视频。

作为评测 pipeline，其输出产物为 evaluation_report。

任务：world-model-benchmark、dataset、evaluation。

## 运行时契约

产物 `evaluation_report`、`wildworld_runtime_plan.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `WildWorldPipeline`。

系列状态：**Runner 一致性待确认**。

在所需 checkpoint 与资产就位前，运行会输出运行时计划并列出缺失资产，而不执行评测。

上游来源状态未确认；使用前请核实其溯源。

## 在 WorldFoundry 中运行

用 `wf run wildworld --pipeline.task-profile default` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

该模型未登记公开的 checkpoint；请按使用说明准备权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh wildworld`；下载缺失的公开权重时加 `--download`。
