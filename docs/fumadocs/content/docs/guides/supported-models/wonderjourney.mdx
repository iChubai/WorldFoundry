## Architecture

Per the paper (arXiv 2312.03884), an LLM proposes upcoming scene descriptions, a point-cloud-and-inpainting visual module renders each new scene from the previous one, and a VLM verifies results. Missing assets or runtime dependencies are reported at inference time.

## Usage notes

Pipeline imports and plan-only inference are wired; full artifact parity needs the upstream assets (depth, inpainting, LLM access) staged locally before real journeys can be generated.
