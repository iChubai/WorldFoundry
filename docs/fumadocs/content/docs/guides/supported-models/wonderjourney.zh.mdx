## 用来做什么

用 `wonderjourney` 生成可探索的世界。

按论文（arXiv 2312.03884），LLM 提议后续场景描述，点云加图像修复的视觉模块从上一场景渲染新场景，VLM 负责校验结果。该模型由斯坦福大学 / Google 发布。

任务：3D 世界生成、scene-expansion、image-to-3d-world。模态上，它接受图像，输出 3D 场景、世界状态。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（生成可游走场景序列的标准评分）。

## 运行时契约

输入 `prompt`（不传时使用内置示例）；参数 `config`、`python-executable`；产物 `generated_world`、`wonderjourney.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `WonderJourneyPipeline`。

系列状态：**Runner 一致性待确认**。

生成旅程前需在本地就位上游资产（深度、修复、LLM 访问）；缺少这些资产时，运行只产出计划。

场景到场景的生成在长旅程中会累积风格与几何漂移。

## 在 WorldFoundry 中运行

运行 `wf run wonderjourney --pipeline.task-profile default` 生成世界。

运行环境：独立环境 `wonderworld`（Python 3.10，CUDA 12.4）。

该模型没有登记公开 checkpoint；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh wonderjourney`；下载缺失的公开权重时加 `--download`。
