## What it is for

`wonderworld` is the recorded interactive world line. Start here when the job is stepping a world with actions.

Per the paper (arXiv 2406.09394), the key representation is FLAGS (Fast LAyered Gaussian Surfels), generated from a single view with a guided depth-diffusion scheme — under 10 seconds per scene on the reported hardware. Direct execution requires WonderWorld checkpoints plus local PyTorch3D-compatible extensions. It is published by Stanford University / MIT.

Catalog tasks include image-to-3d-world, 3d-scene-generation, interactive-3d-generation, and interactive 3D scene generation from a single image. Catalog aliases include `WonderWorld: Interactive 3D Scene Generation from a Single Image`. Documented modalities: image in, 3D scene and world state out.

Recorded evaluation entry points include [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Standard scoring for interactive generated 3D worlds).
