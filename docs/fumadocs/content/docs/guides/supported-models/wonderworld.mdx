## Architecture

Per the paper (arXiv 2406.09394), the key representation is FLAGS (Fast LAyered Gaussian Surfels), generated from a single view with a guided depth-diffusion scheme — under 10 seconds per scene on the reported hardware. Direct execution requires WonderWorld checkpoints plus local PyTorch3D-compatible extensions.

## Usage notes

Missing source, inpainting, segmentation, depth/normal, or 3DGS assets are reported at inference time. Stage the full asset set and compile the PyTorch3D-compatible extensions before expecting real scene output.
