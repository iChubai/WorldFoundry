## 用来做什么

`wonderworld` 是记录的交互世界线。要用动作推进世界时从这里起步。

按论文（arXiv 2406.09394），核心表示是 FLAGS（快速分层高斯面元），配合引导式深度扩散从单视图生成——在论文硬件上每场景不足 10 秒。直接运行需要 WonderWorld checkpoint 与本地兼容 PyTorch3D 的扩展。该模型由斯坦福大学 / 麻省理工学院发布。

catalog 记录的任务包括 image-to-3d-world、3d-scene-generation、interactive-3d-generation、interactive 3D scene generation from a single image。别名包括 `WonderWorld: Interactive 3D Scene Generation from a Single Image`。模态上，它接受图像，输出3D scene、世界状态。

记录的评测入口包括[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（交互式生成 3D 世界的标准评分）。
