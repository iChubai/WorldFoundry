World Observer is a KAIST AI research project on persistent world modeling through joint actor-observer generation.

Paper: [arXiv:2610.02162](https://arxiv.org/abs/2610.02162). Repository: [cvlab-kaist/world-observer](https://github.com/cvlab-kaist/world-observer). Project: [World Observer](https://cvlab-kaist.github.io/world-observer/).

Model ID: `world-observer` (aliases `WorldObserver` and `worldobserver`). It cannot be run until the official checkpoint and inference code are released.

## Release status

The official repository contains the introduction and release plan. The dataset, checkpoint, inference code, and training code are all listed as forthcoming.
