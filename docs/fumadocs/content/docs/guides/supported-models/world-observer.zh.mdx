## 用来做什么

`world-observer` 是世界生成模型。该模型由 KAIST AI（韩国科学技术院）发布。

任务：持久化世界模型、行动者与观测者联合生成。别名：`WorldObserver`、`worldobserver`。

## 运行时契约

必填 `prompt`。

CLI task profile：`persistent-world-model`、`joint-actor-observer-generation`。系列状态：**计划中**。

运行它需要官方 checkpoint 与推理代码，二者尚未发布。

上游尚未发布模型 checkpoint 或推理代码。

## 在 WorldFoundry 中运行

运行 `wf run world-observer --pipeline.task-profile persistent-world-model` 生成世界。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

该模型未记录运行环境。

该模型没有登记公开 checkpoint；按使用说明就位权重。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh world-observer`；下载缺失的公开权重时加 `--download`。
