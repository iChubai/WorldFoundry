## 用来做什么

用 `worldcam` 做相机条件视频推理。配方绑定了已记录的相机控制 profile。

树内 runner 遵循官方条件视频路径，使用本地 WorldCam/Wan 资产，表明其为基于 Wan 的扩散骨干加相机位姿条件。除此之外的架构内部细节仓库未记录。该模型由KAIST（韩国科学技术院）/ Adobe Research / MAUM AI发布。

catalog 记录的任务包括 世界模型、相机控制。

记录的评测入口包括[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机位姿控制的滚动生成跟随度）、[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（长时程交互世界质量）。
