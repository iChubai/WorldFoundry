## 用来做什么

`worldcam` 以相机位姿为条件生成视频。

runner 遵循官方条件视频路径，使用 WorldCam 与 Wan 资产，表明其为基于 Wan 的扩散骨干加相机位姿条件。该模型由 KAIST（韩国科学技术院）/ Adobe Research / MAUM AI 发布。

任务：世界模型、相机控制。

推荐评测：[CameraBench](/zh/docs/evaluation/benchmark-hub/camerabench)（相机位姿控制的滚动生成跟随度）、[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（长时程交互世界质量）。

## 运行时契约

必填 `input-path`；输入 `prompt`（不传时使用内置示例）；参数 `fps`、`height`、`width`、`steps`、`guidance-scale`、`seed` 等 13 项；产物 `worldcam.mp4`。

CLI task profile：`interactive-video`。绑定的 pipeline 类是 `WorldCamPipeline`。

系列状态：**已验证**。

`interactive-video` 的默认值：fps=30, height=480, width=832, seed=0。

该发布为 code-only，需自行在本地就位 WorldCam 与 Wan2.1-T2V-1.3B 资产；wrapper 的 load_model=False 模式可在无权重时检查规划。

## 在 WorldFoundry 中运行

运行 `wf run worldcam --pipeline.task-profile interactive-video` 沿相机路径生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`worldcam/worldcam`、`Wan-AI/Wan2.1-T2V-1.3B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh worldcam`；下载缺失的公开权重时加 `--download`。
