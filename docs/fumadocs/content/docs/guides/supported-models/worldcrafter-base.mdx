## What it is for

`worldcrafter-base` conditions video generation on camera poses.

Tasks: text-to-video, image-to-video, camera-controlled video, and world model. Modalities: text and image in, video out.

## Runtime contract

Inputs `prompt` and `image`; artifacts `worldcrafter.mp4`.

CLI task profiles: `text-to-video`, `image-to-video`, `camera-controlled-video`, and `world-model`. WorldFoundry binds `WorldCrafterPipeline`.

Family status: **Verified**.

Validated with the released weights: two-segment 640×384 image-to-video and text-to-video inference generates and decodes completely.

Long-horizon visual quality is not yet established.

## Running in WorldFoundry

Run `wf run worldcrafter-base --pipeline.task-profile text-to-video` to follow the camera path. Switch tasks in the command builder above to change `--pipeline.task-profile`.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `TencentARC/WorldCrafter-Base` and `TencentARC/WorldCrafter-Fast`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh worldcrafter-base`. Add `--download` to fetch missing public checkpoints.
