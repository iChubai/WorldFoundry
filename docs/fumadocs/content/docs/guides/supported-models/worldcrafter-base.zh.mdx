## 用来做什么

`worldcrafter-base` 以相机位姿为条件生成视频。

任务：文生视频、图生视频、相机可控视频、世界模型。模态上，它接受文本、图像，输出视频。

## 运行时契约

输入 `prompt`、`image`；产物 `worldcrafter.mp4`。

CLI task profile：`text-to-video`、`image-to-video`、`camera-controlled-video`、`world-model`。绑定的 pipeline 类是 `WorldCrafterPipeline`。

系列状态：**已验证**。

已用发布权重验证：640×384 的双片段图生视频与文生视频推理可完整生成并解码。

长时程画面质量尚未确立。

## 在 WorldFoundry 中运行

运行 `wf run worldcrafter-base --pipeline.task-profile text-to-video` 沿相机路径生成视频。在上方命令构建器中切换任务，即可改变 `--pipeline.task-profile`。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`TencentARC/WorldCrafter-Base`、`TencentARC/WorldCrafter-Fast`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh worldcrafter-base`；下载缺失的公开权重时加 `--download`。
