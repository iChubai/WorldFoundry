WorldCrafter 是来自 TencentARC 的世界模型，支持文生视频、图生视频、相机可控视频、世界模型。

省略 `images` 即为文生视频。`actions`、`actions_file`、`camera_path` 三选一。相机文件是 `[T,3,4]` 或 `[T,4,4]` 的全局 **camera-to-world** 矩阵，平移单位为米，坐标轴为右/下/前，帧数须为 33 的整数倍。可以通过 `num_chunks` 截取已有轨迹。

Base 使用 `model_id="worldcrafter-base"`，并需要 Fast 权重中的 RepEncoder、tokenizer、UMT5 和 Wan VAE。共享权重不在标准本地目录时可传 `shared_model_path`。两个模型都以 Helios Transformer 与 VGGT 层为基础；WorldCrafter 增加相机残差、记忆查询与渲染以及蒸馏分支路由。

Base 默认 50 步、CFG 5。Fast 按官方三阶段 2/2/2 时间表运行，CFG 固定为 1；文生视频首段为 12 步，后续为 6 步。Fast 不接受任意步数或断点续推。Base 可使用 `chunk_output_dir`、`state_output_dir`、`resume_from`、`stop_after_chunk`，续推时提示词、图像和相机轨迹必须与原运行一致。

Base 常规输出会按上游规则裁剪到 `33 × num_chunks - 1` 帧；Fast 保留 `33 × num_chunks` 帧。Base 断点续推拼接完整分段，因此也是 `33 × num_chunks` 帧。

运行需要 CUDA、PyTorch 2.10、支持 Helios 的 Diffusers、Transformers 5.3、Accelerate、PEFT、Einops 和 safetensors。编译默认关闭。已在 H100 上用 Base 与 Fast 发布权重验证：两段 I2V/T2V 运行可严格加载、完整解码视频并通过画面审核；Base 断点续推与连续运行的输出逐值一致。长程记忆与相机控制质量尚未验证。

## 用来做什么

`worldcrafter` 以相机位姿为条件生成视频。

任务：文生视频、图生视频、相机可控视频、世界模型。模态上，它接受文本、图像、相机位姿，输出视频。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；产物 `worldcrafter.mp4`。

CLI task profile：`default`。绑定的 pipeline 类是 `WorldCrafterPipeline`。系列状态：**已验证**。

## 在 WorldFoundry 中运行

运行 `wf run worldcrafter --pipeline.task-profile default` 沿相机路径生成视频。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`TencentARC/WorldCrafter-Base`、`TencentARC/WorldCrafter-Fast`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh worldcrafter`；下载缺失的公开权重时加 `--download`。

许可证：worldcrafter-academic-only。
