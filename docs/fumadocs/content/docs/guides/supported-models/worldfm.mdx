InSpatio-WorldFM is a 3D world foundation model for spatial intelligence and frame generation, released with code and weights (inspatio/WorldFM on Hugging Face, Apache-2.0). The WorldFoundry runner runs the official meta.json demo with local WorldFM assets in the unified environment and produces the official video and panorama artifacts.

## What it is for

Use `worldfm` to generate an explorable world.

Outputs cover both video and panorama artifacts, reflecting a world-generation design that renders beyond a single fixed viewport.

Tasks: world, video, and world model. Output modalities: video.

Suggested benchmarks: [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Unified world-generation quality for 3D world output).

## Runtime contract

Inputs `input-path`, `prompt`, and `meta-path` (bundled samples are used when omitted); options `fps`, `panorama-path`, and `save-mode`; artifacts `generated_world` and `worldfm.mp4`.

CLI task profiles: `official-meta-demo`. WorldFoundry binds `WorldFMPipeline`.

Family status: **Verified**.

Defaults for `official-meta-demo`: fps=30.

Drive runs through the official meta.json demo format with local WorldFM assets staged.

## Running in WorldFoundry

Run `wf run worldfm --pipeline.task-profile official-meta-demo` to generate the world.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `inspatio/WorldFM`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh worldfm`. Add `--download` to fetch missing public checkpoints.
