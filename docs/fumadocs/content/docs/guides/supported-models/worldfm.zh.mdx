InSpatio-WorldFM 是面向空间智能与帧生成的 3D 世界基础模型，代码与权重均已发布（Hugging Face 上的 inspatio/WorldFM，Apache-2.0）。WorldFoundry runner 在统一环境中以本地 WorldFM 资产运行官方 meta.json demo，输出官方的视频与全景图产物。

## 用来做什么

用 `worldfm` 生成可探索的世界。

输出同时覆盖视频与全景图产物，体现其超越单一固定视口的世界生成设计。

任务：世界模型、video。输出模态为视频。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（3D 世界输出的统一世界生成质量）。

## 运行时契约

输入 `input-path`、`prompt`、`meta-path`（不传时使用内置示例）；参数 `fps`、`panorama-path`、`save-mode`；产物 `generated_world`、`worldfm.mp4`。

CLI task profile：`official-meta-demo`。绑定的 pipeline 类是 `WorldFMPipeline`。

系列状态：**已验证**。

`official-meta-demo` 的默认值：fps=30。

通过官方 meta.json demo 格式驱动运行，并就位本地 WorldFM 资产。

## 在 WorldFoundry 中运行

运行 `wf run worldfm --pipeline.task-profile official-meta-demo` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`inspatio/WorldFM`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh worldfm`；下载缺失的公开权重时加 `--download`。
