This WorldGen is **ZiYang Xie's** open 3D-world generator ([github.com/ZiYang-xie/WorldGen](https://github.com/ZiYang-xie/WorldGen), project [worldgen.github.io](https://worldgen.github.io/)). At runtime it turns a **text prompt** and/or a **single image** into a **3D scene** — default **Gaussian splat** `worldgen.ply`, or a **mesh** `worldgen.glb` when `return_mesh` is set. It does **not** emit world video.

<ModelPaperFigures modelId="worldgen" locale="en" />

The paper link and title-page thumbnail point to Meta Reality Labs' [WorldGen: From Text to Traversable and Interactive 3D Worlds](https://arxiv.org/abs/2511.16825), a **different project** with the same name. WorldFoundry runs the **LeoXie/WorldGen** release, not Meta's. It is also **not** [Hunyuan World worldgen](/docs/guides/supported-models/hyworld-worldgen).

## What it is for

Build a walkable 3D asset, not a clip. Launch `wf run worldgen`. Recorded inputs: `prompt` and `image`. Optional `actions.camera_path`. Video is **not** a required input. The in-tree flow is text-to-scene (`t2s`) or image-to-scene (`i2s`): FLUX paints a panorama, then the adapter reconstructs splat or mesh. You can also pass a ready panorama and skip FLUX generation.

Default inference resolution is **1600**. Low-VRAM mode turns on automatically below 24 GB. Background inpaint cannot combine with `return_mesh`.

Score generated 3D worlds on [WorldScore](/docs/evaluation/benchmark-hub/worldscore).

## Running in WorldFoundry

`WorldGenPipeline` runs in `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `LeoXie/WorldGen` **and** accept the gated **FLUX.1-dev** (text-to-pano) and **FLUX.1-Fill-dev** (image-to-pano) terms.

Validated locally: a 512×256, 50-step text-to-scene run produces a Gaussian-splat scene with the requested furniture. Image-to-scene from a cropped perspective photo produces a valid PLY but does not preserve the input room, because the upstream image path maps a single input onto spherical panorama rays without a specified camera field of view. A full 2:1 panorama input is preserved (recovered RGB differs from the input by 1.44/255 on average) but leaves nothing to inpaint, so novel expansion from a perspective photo is not demonstrated.
