这里的 WorldGen 是 **ZiYang Xie** 的开源 3D 世界生成器（[github.com/ZiYang-xie/WorldGen](https://github.com/ZiYang-xie/WorldGen)，项目页 [worldgen.github.io](https://worldgen.github.io/)）。运行时把**文本提示**和 / 或**单张图**变成 **3D 场景**——默认高斯溅射 `worldgen.ply`，打开 `return_mesh` 则写网格 `worldgen.glb`。它**不**输出世界视频。

论文链接和标题旁封面指向 Meta Reality Labs 的 [WorldGen: From Text to Traversable and Interactive 3D Worlds](https://arxiv.org/abs/2511.16825)，那是**同名的另一个项目**。WorldFoundry 运行的是 **LeoXie/WorldGen** 发布，不是 Meta 的发布。也**不是** [Hunyuan World worldgen](/zh/docs/guides/supported-models/hyworld-worldgen)。

## 用来做什么

做可走的 3D 资产，不是短片。启动 `wf run worldgen`，任务 profile 为 `3d-world-generation`。记录输入：`prompt` 与 `image`。可选 `actions.camera_path`。视频**不是**必填。树内流程是文生场景（`t2s`）或图生场景（`i2s`）：FLUX 先画全景，适配器再重建 splat 或 mesh。也可以直接给现成全景，跳过 FLUX 生成。

默认推理分辨率是 **1600**。显存低于 24 GB 会自动开低显存模式。背景 inpaint 不能与 `return_mesh` 同时用。

生成 3D 世界的评测入口是 [WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)。

## 在 WorldFoundry 中运行

`WorldGenPipeline` 运行在 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。就位 `LeoXie/WorldGen`，并接受 gated 的 **FLUX.1-dev**（文生全景）与 **FLUX.1-Fill-dev**（图生全景）条款。

已在本地验证：512×256、50 步的文生场景运行可生成包含提示要求家具的高斯溅射场景。裁剪的透视房间照片用于图生场景时能生成有效 PLY，但不会保留原房间，因为上游图像路径在未指定相机视场角的情况下把单张输入映射到球面全景光线。完整的 2:1 全景输入可以保留（恢复的 RGB 与输入平均相差 1.44/255），但没有待扩展的区域，因此尚未证明能从透视照片扩展出新内容。
