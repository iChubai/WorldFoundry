WorldGrow generates worlds by expansion: starting from a seed scene it progressively grows coherent 3D world blocks, targeting interactive world generation and scene extension. The UranusITS/WorldGrow checkpoint is published on Hugging Face; WorldFoundry runs the official source and needs the checkpoint and TRELLIS assets staged locally.

## What it is for

`worldgrow` is an action-conditioned world model: actions and a starting frame in, a rollout out.

The dependency on TRELLIS assets indicates a structured-3D-latent generation backbone extended with block-wise scene growth. The official source is world-grow/WorldGrow, pinned at 1f2ac49c.

Tasks: world generation, interactive world model, and scene expansion.

Suggested benchmarks: [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Growable 3D world coherence and quality).

## Runtime contract

Artifacts `generated_world` and `worldgrow_runtime_plan.json`.

CLI task profiles: `default`. WorldFoundry binds `WorldGrowPipeline`.

Family status: **Runner parity pending**.

Stage both the WorldGrow checkpoint and the TRELLIS assets before running; until they are staged, a run returns a plan that lists the missing assets.

The upstream repository has no root license file; review licensing before use.

## Running in WorldFoundry

Run `wf run worldgrow --pipeline.task-profile default` to roll out the world model.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `UranusITS/WorldGrow`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh worldgrow`. Add `--download` to fetch missing public checkpoints.
