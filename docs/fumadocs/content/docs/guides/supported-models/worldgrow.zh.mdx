WorldGrow 以扩张方式生成世界：从种子场景出发逐步生长出连贯的 3D 世界块，面向交互式世界生成与场景扩展。UranusITS/WorldGrow checkpoint 发布在 Hugging Face 上；WorldFoundry 运行官方源码，需要在本地就位 checkpoint 与 TRELLIS 资产。

## 用来做什么

`worldgrow` 是动作条件世界模型：输入动作和起始帧，输出推演结果。

对 TRELLIS 资产的依赖表明其以结构化 3D 隐变量生成为骨干、叠加分块场景生长。官方源码为 world-grow/WorldGrow，固定在 1f2ac49c。

任务：世界生成、交互式世界模型、scene-expansion。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（可生长 3D 世界的连贯性与质量）。

## 运行时契约

产物 `generated_world`、`worldgrow_runtime_plan.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `WorldGrowPipeline`。

系列状态：**Runner 一致性待确认**。

运行前需同时就位 WorldGrow checkpoint 与 TRELLIS 资产；就位前运行只会返回一份列出缺失资产的计划。

## 在 WorldFoundry 中运行

运行 `wf run worldgrow --pipeline.task-profile default` 推演世界模型。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`UranusITS/WorldGrow`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh worldgrow`；下载缺失的公开权重时加 `--download`。
