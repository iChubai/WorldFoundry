## 用来做什么

需要动作条件世界步进时选 `worldgrow`：记录动作与帧进、滚动生成出。用来做交互世界推理，不是把 prompt 倒进文生视频。

对 TRELLIS 资产的运行时依赖表明其以结构化 3D 隐变量生成为骨干、叠加分块场景生长。官方仓库指针（world-grow/WorldGrow，锁定 head 1f2ac49c）之外的架构内部细节仓库未记录。

catalog 记录的任务包括 世界生成、交互式世界模型、scene-expansion。

记录的评测入口包括[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（可生长 3D 世界的连贯性与质量）。

## 运行时契约

必填 `image`、`prompt`、`video`；可选 `actions` (camera_navigation, scene_expansion)；产物 `generated_world`、`worldgrow_runtime_plan.json`。

记录的任务 profile：`world-generation`、`interactive-world-model`、`scene-expansion`。绑定的 pipeline 类是 `WorldGrowPipeline`。

系列状态：**Runner 一致性待确认**。

配置解析与 pipeline 导入预期可通过；在所需 checkpoint/资产就位前，真实生成会输出运行时计划。 缺失资产由计划报告，不视为 catalog 阻塞。 真实运行前需同时就位 WorldGrow checkpoint 与 TRELLIS 资产。

WorldFoundry tracks upstream source and checkpoint 计划中; no runnable pipeline is registered.
