World Labs Marble 1.1 is a commercial API for 3D world generation: it produces explorable 3D worlds from prompts, accessed through api.worldlabs.ai. WorldFoundry calls it through the WorldLabs API pipeline with the marble-1.1 model id; there are no local weights.

## What it is for

Use `worldlabs-marble-1.1` to generate an explorable world.

Closed API service; architecture details are not public. The official sources are the release notes and the API endpoint.

Tasks: world generation, 3D world generation, and api world model. Aliases: `marble-1.1` and `worldlab-marble-1.1`.

Suggested benchmarks: [WorldScore](/docs/evaluation/benchmark-hub/worldscore) (Explorable 3D world generation quality).

For the general World Labs API entry, see [World Labs](/docs/guides/supported-models/worldlabs).

## Runtime contract

Artifacts `worldlabs-marble-1.1.zip`.

CLI task profiles: `default`. WorldFoundry binds `WorldLabsMarble11Pipeline`.

Family status: **Runner parity pending**.

Requires World Labs API credentials; requests go through the WorldLabs API pipeline using model id marble-1.1.

API-only: closed weights, closed architecture, external service dependency.

## Running in WorldFoundry

Run `wf run worldlabs-marble-1.1 --pipeline.task-profile default` to generate the world.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh worldlabs-marble-1.1`. Add `--download` to fetch missing public checkpoints.

Status: **Runner parity pending**.
