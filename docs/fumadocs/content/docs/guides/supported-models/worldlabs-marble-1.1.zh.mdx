World Labs Marble 1.1 是 3D 世界生成的商业 API：从提示生成可探索的 3D 世界，经 api.worldlabs.ai 访问。WorldFoundry 通过 WorldLabs API pipeline 以 marble-1.1 模型 id 调用该服务，没有本地权重。

## 用来做什么

用 `worldlabs-marble-1.1` 生成可探索的世界。

闭源 API 服务，架构细节未公开。官方来源为发布说明与 API 端点。

任务：世界生成、3D 世界生成、api-world-model。别名：`marble-1.1`、`worldlab-marble-1.1`。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（可探索 3D 世界生成质量）。

通用的 World Labs API 见 [World Labs](/zh/docs/guides/supported-models/worldlabs)。

## 运行时契约

产物 `worldlabs-marble-1.1.zip`。

CLI task profile：`default`。绑定的 pipeline 类是 `WorldLabsMarble11Pipeline`。

系列状态：**Runner 一致性待确认**。

需要 World Labs API 凭证；请求经 WorldLabs API pipeline 发出，模型 id 为 marble-1.1。

仅提供 API：权重与架构均闭源，依赖外部服务。

## 在 WorldFoundry 中运行

运行 `wf run worldlabs-marble-1.1 --pipeline.task-profile default` 生成世界。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh worldlabs-marble-1.1`；下载缺失的公开权重时加 `--download`。

状态：**Runner 一致性待确认**。
