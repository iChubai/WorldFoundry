World Labs API 是 World Labs 生成式世界服务的托管入口，用于世界生成与资产输出，而非普通视频。服务在 World Labs 的基础设施上生成可探索的 3D 世界内容，WorldFoundry 将 API 返回的内容保存为产物。

## 用来做什么

用 `worldlabs` 在 WorldFoundry 中调用托管模型。

World Labs 未公开其世界生成服务背后的架构。

任务：世界生成、assets、托管 API。

推荐评测：[WorldScore](/zh/docs/evaluation/benchmark-hub/worldscore)（评估可探索生成世界的统一基准）。

World Labs 的 Marble 1.1 模型见 [Marble 1.1](/zh/docs/guides/supported-models/worldlabs-marble-1.1)。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）。

CLI task profile：`default`。绑定的 pipeline 类是 `WorldLabsPipeline`。

系列状态：**Runner 一致性待确认**。

需自备 World Labs 账号与 API key，通过 WORLDLABS_API_KEY（或 WLT_API_KEY）提供；访问权限通过 World Labs 平台（worldlabs.ai）开通。本地不会下载任何权重，也不需要 GPU——生成在服务方完成，费用、配额与内容政策均以你的服务方账号为准。

## 在 WorldFoundry 中运行

用 `wf run worldlabs --pipeline.task-profile default` 调用托管模型。

该模型未记录运行环境。

准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh worldlabs`；下载缺失的公开权重时加 `--download`。
