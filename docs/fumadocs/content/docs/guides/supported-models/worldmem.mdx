WorldMem targets the core weakness of interactive world models — forgetting: it equips a Minecraft-style interactive world model with an explicit memory so revisited places stay consistent over long horizons (paper: arXiv 2504.12369). ## What it is for

Use `worldmem` to step a world forward with actions and render the resulting frames.

The design theme is long-term consistency via memory: past observations are stored and retrieved to condition future rollouts.

Tasks: interactive world model, minecraft world model, and long term consistency.

Suggested benchmarks: [MemoBench](/docs/evaluation/benchmark-hub/memobench) (Long-term memory consistency of world rollouts), [WorldModelBench](/docs/evaluation/benchmark-hub/worldmodelbench) (Action-conditioned interactive rollout quality).

## Running in WorldFoundry

Run `wf run worldmem --pipeline.task-profile default` to roll out the world model.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

No public checkpoint is listed for this model; stage the weights as described in the usage notes. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh worldmem`. Add `--download` to fetch missing public checkpoints.
