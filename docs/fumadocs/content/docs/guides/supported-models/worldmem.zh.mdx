WorldMem 针对交互式世界模型的核心弱点——遗忘：为 Minecraft 式交互世界模型加装显式记忆，使重访地点在长时程下保持一致（论文：arXiv 2504.12369）。WorldFoundry 在树内运行该路径；生成前需就位上游推理模型与数据资产。

## 用来做什么

用 `worldmem` 以动作推进世界并渲染出相应画面。

设计主题是基于记忆的长期一致性：存储并检索历史观测以条件化后续滚动生成。

任务：交互式世界模型、Minecraft 世界模型、长期一致性。

推荐评测：[MemoBench](/zh/docs/evaluation/benchmark-hub/memobench)（世界滚动生成的长期记忆一致性）、[WorldModelBench](/zh/docs/evaluation/benchmark-hub/worldmodelbench)（动作条件交互滚动生成质量）。
