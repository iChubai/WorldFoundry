WoW is X-Humanoid's embodied world model family for action-conditioned image-to-video, with four checkpoint lines: Wan 1.3B-2M (MIT), Wan 14B-600k (official demo default), Wan 14B-2M (official recommendation), and a DiT 2B development line. Validated: the released Wan 1.3B-2M checkpoint loads into the native Wan model with an exact structural match.

## What it is for

Use `wow` to step a world forward with actions and render the resulting frames.

The Wan line uses VAE-only first-frame conditioning on Wan diffusion backbones. The DiT 2B line is a transformer override on the Cosmos Predict2 recipe, selected via runtime_backend=dit2b. Official demo defaults: Wan uses steps=50, seed=42, tiled, 41 frames at 15 fps; DiT 2B uses 720p, 16 fps, guidance=7. It is published by X-Humanoid (Beijing Humanoid Robot Innovation Center).

Tasks: world model, image-to-video, and action-conditioned video. Aliases: `wow-world-model` and `world-of-worlds`. Modalities: image in, video out.

Suggested benchmarks: [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) (Embodied action-conditioned world-model quality), [WorldArena](/docs/evaluation/benchmark-hub/worldarena) (Listed among WorldArena open-source world models).

## Runtime contract

Inputs `input-path` and `prompt` (bundled samples are used when omitted); options `steps`, `num-frames`, `seed`, `no-tiled`, `enable-vram-management`, and `persistent-param-gb`; artifacts `wow.mp4`.

CLI task profiles: `official-image-to-world`. WorldFoundry binds `WoWPipeline`.

Family status: **Runner parity pending**.

Defaults for `official-image-to-world`: seed=42.

Start with the Wan 1.3B-2M (MIT) checkpoint; the official recommendation is Wan 14B-2M.

## Running in WorldFoundry

Run `wf run wow --pipeline.task-profile official-image-to-world` to roll out the world model.

It runs in the unified environment `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8).

Weights: `X-Humanoid/WoW-1-Wan-1.3B-2M`, `X-Humanoid/WoW-1-Wan-14B-600k`, and `X-Humanoid/WoW-1-Wan-14B-2M` among others. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh wow`. Add `--download` to fetch missing public checkpoints.
