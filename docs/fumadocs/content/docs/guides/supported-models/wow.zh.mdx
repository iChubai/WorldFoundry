WoW 是 X-Humanoid 的具身世界模型家族，面向动作条件图生视频，包含四条 checkpoint 线：Wan 1.3B-2M（MIT）、Wan 14B-600k（官方 demo 默认）、Wan 14B-2M（官方推荐），以及 DiT 2B 开发线。已验证：发布的 Wan 1.3B-2M checkpoint 可加载到原生 Wan 模型，结构完全匹配。

## 用来做什么

用 `wow` 以动作推进世界并渲染出相应画面。

Wan 线在 Wan 扩散骨干上采用仅 VAE 的首帧条件。DiT 2B 线是 Cosmos Predict2 配方上的 transformer 覆盖，经 runtime_backend=dit2b 选择。官方 demo 默认值：Wan 为 steps=50、seed=42、tiled、41 帧、15 fps；DiT 2B 为 720p、16 fps、guidance=7。该模型由 X-Humanoid（北京人形机器人创新中心）发布。

任务：世界模型、图生视频、动作条件视频。别名：`wow-world-model`、`world-of-worlds`。模态上，它接受图像，输出视频。

推荐评测：[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（具身动作条件世界模型质量）、[WorldArena](/zh/docs/evaluation/benchmark-hub/worldarena)（WorldArena 开源世界模型榜单收录）。

## 运行时契约

输入 `input-path`、`prompt`（不传时使用内置示例）；参数 `steps`、`num-frames`、`seed`、`no-tiled`、`enable-vram-management`、`persistent-param-gb`；产物 `wow.mp4`。

CLI task profile：`official-image-to-world`。绑定的 pipeline 类是 `WoWPipeline`。

系列状态：**Runner 一致性待确认**。

`official-image-to-world` 的默认值：seed=42。

建议从 Wan 1.3B-2M（MIT）checkpoint 起步；官方推荐为 Wan 14B-2M。

## 在 WorldFoundry 中运行

运行 `wf run wow --pipeline.task-profile official-image-to-world` 推演世界模型。

运行环境：统一环境 `worldfoundry-unified-cu128`（Python 3.11，CUDA 12.8）。

权重仓库：`X-Humanoid/WoW-1-Wan-1.3B-2M`、`X-Humanoid/WoW-1-Wan-14B-600k`、`X-Humanoid/WoW-1-Wan-14B-2M` 等。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh wow`；下载缺失的公开权重时加 `--download`。
