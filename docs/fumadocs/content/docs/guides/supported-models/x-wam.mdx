X-WAM is a world-action model: one Wan 2.2 joint flow process predicts future RGB/depth, proprioception, and robot actions together (Apache-2.0). Validated on GPU with the released checkpoints: RoboCasa-SFT produces actions and future RGB frames, and RoboTwin-SFT closely matches the pinned official runner on a paired in-domain episode.

## What it is for

Use `x-wam-robocasa-sft` to predict actions together with how the world evolves.

Built on Wan2.2-TI2V-5B: a joint flow model over visual futures and action streams. The official deployed policy uses asynchronous early stopping after 10 action steps and returns a 32-step action chunk; optional full world decoding continues to 50 steps.

Tasks: WAM, world action model, WAM world action modeling, and robot policy. Aliases: `x_wam`, `xwam`, and `X-WAM`. Modalities: image in, depth out. Other variants: `x-wam-robotwin-sft`, `x-wam-pretrained`.

Suggested benchmarks: [RoboCasa](/docs/evaluation/benchmark-hub/robocasa) (The RoboCasa-SFT checkpoint targets RoboCasa; closed-loop scores have not been measured), [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (The RoboTwin-SFT checkpoint targets RoboTwin; closed-loop scores have not been measured), [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) (Joint world-action prediction quality).

## Runtime contract

Inputs `prompt` and `input-path` (bundled samples are used when omitted); options `guidance-scale`, `rgb-views`, `state`, `variant`, `torch-dtype`, `denoise-steps`, and 5 more; artifacts `action_trace`, `predicted_video`, and `x-wam_action_trace.json`.

CLI task profiles: `default`. WorldFoundry binds `XWAMPipeline`.

Start with `x-wam-robocasa-sft`. The family has 3 variants, selectable in the command builder above: `x-wam-robocasa-sft` (`wam.world_action_modeling`) — Verified; `x-wam-robotwin-sft` (`wam.world_action_modeling`) — Verified; `x-wam-pretrained` (`wam.post_training_base`) — Verified. Family status: **Verified**.

Stage the X-WAM checkpoint states plus the Wan2.2-TI2V-5B base. The runtime does not need an external X-WAM checkout; training, simulators, ZeroMQ services, Lightning, and DeepSpeed orchestration are not included.

Optional depth decoding remains unvalidated.

## Running in WorldFoundry

Run the model with `wf run x-wam-robocasa-sft --pipeline.task-profile default`.

It runs in the dedicated environment `worldfoundry-x-wam-cu129` (Python 3.10, CUDA 12.9, torch==2.8.0).

Weights: `sharinka0715/X-WAM-checkpoints` and `Wan-AI/Wan2.2-TI2V-5B`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh x-wam-robocasa-sft`. Add `--download` to fetch missing public checkpoints.
