X-WAM is a GPU-validated world-action model: one Wan 2.2 joint flow process predicts future RGB/depth, proprioception, and robot actions together. The 38.9 GB RoboCasa-SFT checkpoint restored strictly and passed both the official 10-step action/proprioception path and a full 50-step future-RGB decode on an A100 (Apache-2.0).

## What it is for

`x-wam-robocasa-sft` is the recorded instruction-to-action line. Start here when you need a WorldFoundry VLA rollout rather than a video generator.

Built on Wan2.2-TI2V-5B: a joint flow model over visual futures and action streams. The official deployed policy uses asynchronous early stopping after 10 action steps and returns a 32-step action chunk; optional full world decoding continues to 50 steps. Both Hub repos are revision-pinned.

Catalog tasks include wam, world action model, wam world action modeling, and robot policy. Catalog aliases include `x_wam`, `xwam`, and `X-WAM`. Documented modalities: image in, depth out. Also recorded: `x-wam-robotwin-sft`, `x-wam-pretrained`.

Recorded evaluation entry points include [RoboCasa](/docs/evaluation/benchmark-hub/robocasa) (The GPU-validated checkpoint is RoboCasa-SFT), [EWMBench](/docs/evaluation/benchmark-hub/ewmbench) (Joint world-action prediction quality), [RoboTwin 2.0](/docs/evaluation/benchmark-hub/robotwin) (Referenced in this model's manifest evidence notes).
