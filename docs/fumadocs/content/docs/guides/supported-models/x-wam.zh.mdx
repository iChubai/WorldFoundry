X-WAM 是 GPU 已验证的世界-动作模型：单个 Wan 2.2 联合 flow 过程同时预测未来 RGB/深度、本体感知与机器人动作。38.9 GB 的 RoboCasa-SFT checkpoint 严格恢复，并在 A100 上通过官方 10 步动作/本体感知路径与完整 50 步未来 RGB 解码（Apache-2.0）。

## 架构

构建于 Wan2.2-TI2V-5B：对视觉未来与动作流的联合 flow 模型。官方部署策略在 10 个动作步后异步提前停止并返回 32 步动作块；可选的完整世界解码持续到 50 步。两个 Hub 仓库均锁定 revision。

## 使用要点

需就位 X-WAM checkpoint 状态与 Wan2.2-TI2V-5B 基座。运行时树内自足，绝不导入外部 X-WAM checkout；训练、模拟器、ZeroMQ 服务、Lightning 与 DeepSpeed 编排均被排除。
