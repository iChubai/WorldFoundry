X-WAM 是世界-动作模型：单个 Wan 2.2 联合 flow 过程同时预测未来 RGB/深度、本体感知与机器人动作（Apache-2.0）。已使用发布权重在 GPU 上验证：RoboCasa-SFT 可输出动作与未来 RGB 帧，RoboTwin-SFT 在一条配对的域内样本上与固定版本官方 Runner 接近一致。

## 用来做什么

用 `x-wam-robocasa-sft` 同时预测动作和世界的演化。

构建于 Wan2.2-TI2V-5B：对视觉未来与动作流的联合 flow 模型。官方部署策略在 10 个动作步后异步提前停止并返回 32 步动作块；可选的完整世界解码持续到 50 步。

任务：wam、world_action_model、wam.world_action_modeling、机器人策略。别名：`x_wam`、`xwam`、`X-WAM`。模态上，它接受图像，输出深度。同系列还有 `x-wam-robotwin-sft`、`x-wam-pretrained`。

推荐评测：[RoboCasa](/zh/docs/evaluation/benchmark-hub/robocasa)（RoboCasa-SFT 权重面向 RoboCasa；尚未测量闭环分数）、[RoboTwin 2.0](/zh/docs/evaluation/benchmark-hub/robotwin)（RoboTwin-SFT 权重面向 RoboTwin；尚未测量闭环分数）、[EWMBench](/zh/docs/evaluation/benchmark-hub/ewmbench)（联合世界-动作预测质量）。

## 运行时契约

输入 `prompt`、`input-path`（不传时使用内置示例）；参数 `guidance-scale`、`rgb-views`、`state`、`variant`、`torch-dtype`、`denoise-steps` 等 11 项；产物 `action_trace`、`predicted_video`、`x-wam_action_trace.json`。

CLI task profile：`default`。绑定的 pipeline 类是 `XWAMPipeline`。

建议从 `x-wam-robocasa-sft` 开始。该系列共有 3 个 variant，可在上方命令构建器中切换：`x-wam-robocasa-sft`（`wam.world_action_modeling`）：已验证、`x-wam-robotwin-sft`（`wam.world_action_modeling`）：已验证、`x-wam-pretrained`（`wam.post_training_base`）：已验证。系列状态：**已验证**。

需准备 X-WAM checkpoint 状态与 Wan2.2-TI2V-5B 基座。运行无需外部 X-WAM 源码；不包含训练、模拟器、ZeroMQ 服务、Lightning 与 DeepSpeed 编排。

可选的深度解码尚未验证。

## 在 WorldFoundry 中运行

用 `wf run x-wam-robocasa-sft --pipeline.task-profile default` 运行模型。

运行环境：独立环境 `worldfoundry-x-wam-cu129`（Python 3.10，CUDA 12.9，torch==2.8.0）。

权重仓库：`sharinka0715/X-WAM-checkpoints`、`Wan-AI/Wan2.2-TI2V-5B`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh x-wam-robocasa-sft`；下载缺失的公开权重时加 `--download`。

许可证：Apache-2.0。
