[X-VLA: Soft-Prompted Transformer as Scalable Cross-Embodiment Vision-Language-Action Model](https://arxiv.org/abs/2510.10274) (2025)

X-VLA is a cross-embodiment VLA built on a Florence-2 backbone with soft-prompt domain conditioning (paper: arXiv 2510.10274, Apache-2.0). It is one of the most thoroughly validated entries in this catalog: all nine released checkpoints restored strictly and produced finite 30x20 actions through real A100 inference with explicit domain IDs, and the in-tree action head matches upstream within 5e-7.

## Architecture

A Florence-2 vision-language backbone, the X-VLA processor, and a soft-prompted transformer whose domain-specific soft prompts switch embodiments; the in-tree action head has exactly the same 300 state keys, tensor shapes, and parameter count as upstream.

## Usage notes

Always pass the explicit domain ID matching your embodiment/checkpoint. Runtime forces trust_remote_code=false and never imports a source checkout; training, FastAPI serving, simulator clients, and robot drivers are excluded.
