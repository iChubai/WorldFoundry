X-VLA 是跨本体 VLA，基于 Florence-2 骨干与软提示域条件（论文：arXiv 2510.10274，Apache-2.0）。已在 A100 上验证：九个已发布 checkpoint 均可严格加载，并在显式域 ID 下产出有限的 30x20 动作，动作头输出与上游一致。

## 用来做什么

运行跨本体 VLA 策略。全部九个已发布 checkpoint 均已在 A100 上验证：每个 checkpoint 都使用显式 `domain_id`，可写出数值有限的 30×20 动作。

启动 `wf run xvla`。必填：`image`、`prompt`、`state`、`domain_id`、`denoising_steps`。产物：`action_trace`、`xvla_action_trace.json`。

`domain_id` 必须和 checkpoint 对齐（WidowX、Google Robot、LIBERO、CALVIN、RoboTwin2 等）。基座 `2toINF/X-VLA-Pt` 同样需要提供此 ID。相关套件：[BridgeData V2](/zh/docs/evaluation/benchmark-hub/bridgedata-v2)。

## 运行时契约

必填：`image`、`prompt`、`state`、`domain_id`、`denoising_steps`。可选相机：`image0`、`image1`、`image2`。默认 float32 解码；bf16/fp16 是显式性能开关。产物：`xvla_action_trace.json`（以及 `action_trace`）。运行时强制 `trust_remote_code=false`，不会导入上游 checkout。

## 在 WorldFoundry 中运行

独立环境 `worldfoundry-vla-xvla`（Python 3.10，CUDA 12.1 或更新，torch>=2.2）。准备好对应快照，例如 `2toINF/X-VLA-WidowX`、`2toINF/X-VLA-Google-Robot` 或 `2toINF/X-VLA-Libero`，然后启动 `wf run xvla`。许可：Apache-2.0。
