ZeroScope is a community **text-to-video** fine-tune of [ModelScopeT2V](/docs/guides/supported-models/modelscope-t2v) by **cerspense**, aimed at watermark-free **16:9** clips. A prompt goes in; `zeroscope.mp4` comes out. The in-tree runtime is **prompt-only**: image or video inputs raise. There is no camera path, no navigation action, and no 3D asset.

<ModelPaperFigures modelId="zeroscope" locale="en" />

WorldFoundry runs the Hugging Face Diffusers U-Net in-tree. Validated: for the selected configuration, output **matches the official Diffusers route**. Aliases `zero-scope` and `zero_scope` resolve here.

Two checkpoints are available: `cerspense/zeroscope_v2_576w` (base **576×320**) and `cerspense/zeroscope_v2_XL` (upscaler). The Studio/API profile uses the **576w** checkpoint. Both licenses are **CC-BY-NC-4.0**.

## What it is for

Smoke-test a legacy T2V pipe, or compare against the ModelScopeT2V parent — not produce modern DiT footage. Launch `wf run zeroscope` with a required `prompt`. Runtime defaults: **8 frames**, **576×320**, **25 steps**, guidance **9.0**, **8 fps**. Artifact: `zeroscope.mp4`.

Use [FETV](/docs/evaluation/benchmark-hub/fetv) if you need a fine-grained suite from this U-Net era. For first-person world exploration use [YUME](/docs/guides/supported-models/yume). For a 3D splat use [WorldGen](/docs/guides/supported-models/worldgen).

## Running in WorldFoundry

`ZeroScopePipeline` runs in `worldfoundry-unified-cu128` (Python 3.11, CUDA 12.8). Stage `cerspense/zeroscope_v2_576w` under `WORLDFOUNDRY_HFD_ROOT`. Review CC-BY-NC-4.0 before commercial use or automated benchmarking.

## Evaluation

Score generated clips on [FETV](/docs/evaluation/benchmark-hub/fetv) with `--fetv-metrics clip_score` and read `clip_score` — that is the bounded official component. `fetv_average` appears only when every declared component is present.
