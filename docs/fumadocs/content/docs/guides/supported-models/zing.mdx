## What it is for

`zing` generates future frames conditioned on actions.

Native Wan2.2 TI2V-5B layers, UMT5, VAE38 and attention are reused. Only the keyboard convolution and prompt-switching causal cache are model-specific. It is published by seedleap.

Tasks: text-to-video, image-to-video, and interactive world model. Aliases: `zing-0.5` and `zing-world-model`. Modalities: text and image in, video out.

## Runtime contract

Inputs `prompt`, `input-path`, and `load.checkpoint-dir` (bundled samples are used when omitted); options `num-frames`, `height`, `width`, `fps`, and `seed`; artifacts `generated_world` and `zing.mp4`.

CLI task profiles: `interactive-world-model`. WorldFoundry binds `ZingPipeline`.

Family status: **Runner parity pending**.

Defaults for `interactive-world-model`: height=480, width=832, fps=24, seed=0.

Use ZingPipeline.from_pretrained(checkpoint_dir). num_frames includes the optional reference and must be 1+4*N; height/width are multiples of 32. Keyboard controls contain N-1 rows of eight values for a total N-frame result.

## Running in WorldFoundry

Weights: `seedleap/zing-0.5`. Prepare the environment and check local assets with `bash scripts/inference/prepare_model_infer.sh zing`. Add `--download` to fetch missing public checkpoints.
