## 架构

复用原生 Wan2.2 TI2V-5B 层、UMT5、VAE38 和注意力实现，新增键盘卷积和支持提示词切换的因果缓存。

## 运行时契约

通过 ZingPipeline.from_pretrained 加载。num_frames 包含可选参考帧，必须为 1+4*N；宽高为 32 的倍数。总长 N 帧时键盘控制为 N-1 行、每行八个值。
