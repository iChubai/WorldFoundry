## 用来做什么

`zing` 以动作为条件生成未来帧。

复用原生 Wan2.2 TI2V-5B 层、UMT5、VAE38 和注意力实现，新增键盘卷积和支持提示词切换的因果缓存。该模型由 seedleap 发布。

任务：文生视频、图生视频、交互式世界模型。别名：`zing-0.5`、`zing-world-model`。模态上，它接受文本、图像，输出视频。

## 运行时契约

输入 `prompt`、`input-path`、`load.checkpoint-dir`（不传时使用内置示例）；参数 `num-frames`、`height`、`width`、`fps`、`seed`；产物 `generated_world`、`zing.mp4`。

CLI task profile：`interactive-world-model`。绑定的 pipeline 类是 `ZingPipeline`。

系列状态：**Runner 一致性待确认**。

`interactive-world-model` 的默认值：height=480, width=832, fps=24, seed=0。

通过 ZingPipeline.from_pretrained(checkpoint_dir) 加载。num_frames 包含可选参考帧，必须为 1+4*N；宽高为 32 的倍数。总长 N 帧时键盘控制为 N-1 行、每行八个值。

## 在 WorldFoundry 中运行

用 `wf run zing --pipeline.task-profile interactive-world-model` 推进世界。

运行环境：独立环境 `zing`（Python 3.11，CUDA 12.8，torch>=2.6）。

权重仓库：`seedleap/zing-0.5`。准备环境并检查本地资产：`bash scripts/inference/prepare_model_infer.sh zing`；下载缺失的公开权重时加 `--download`。
