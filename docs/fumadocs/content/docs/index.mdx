WorldFoundry is open-source infrastructure for running and evaluating world models. It is not a new architecture. Discovery, runtime and asset preparation, inference, artifact inspection, and benchmark evidence share one workflow across video, 3D/4D, interactive worlds, and embodied systems.

Catalog inclusion is not a runnable runtime. A demo is not benchmark evidence. An ingested score is not official leaderboard parity. Those states stay separate, with provenance.

## A first run

For `matrix-game-2`, confirm the catalog entry and local checkpoint, then generate one small result:

```bash
bash scripts/inference/prepare_model_infer.sh matrix-game-2 --download
python -m worldfoundry.evaluation zoo model-download \
  --model-id matrix-game-2 --check-local --json

bash scripts/inference/test_nav_video_gen.sh matrix-game-2 \
  --output-dir tmp/matrix_game2_first_run
```

That run justifies one claim: this configuration produced an inspectable artifact. It does not mean a benchmark completed. Layers and contracts are in [Design](/docs/overview/design); the longer problem statement is in [Why WorldFoundry](/docs/overview/why-worldfoundry).
