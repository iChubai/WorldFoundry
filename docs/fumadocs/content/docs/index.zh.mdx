WorldFoundry 是一套运行与评测世界模型的开源基础设施，不是又一个模型架构。模型发现、runtime 与资产准备、推理、artifact 检查和 benchmark 证据走同一条工作流，覆盖视频、3D/4D、交互世界与具身系统。

被 catalog 收录，不等于 runtime 能跑；demo 效果好，不等于已有 benchmark 证据；分数导入成功，也不等于官方 leaderboard 水平。这些状态分开记录，并保留 provenance。

## 第一次运行

第一次跑 `matrix-game-2` 时，先确认 catalog 条目和本地 checkpoint，再生成一个小结果：

```bash
bash scripts/inference/prepare_model_infer.sh matrix-game-2 --download
python -m worldfoundry.evaluation zoo model-download \
  --model-id matrix-game-2 --check-local --json

bash scripts/inference/test_nav_video_gen.sh matrix-game-2 \
  --output-dir tmp/matrix_game2_first_run
```

这次运行只支撑一个结论：这套配置产出了可检查的 artifact，并不等于某个 benchmark 已经跑完。各层与契约见[设计](/zh/docs/overview/design)，更完整的问题陈述见[为什么使用 WorldFoundry](/zh/docs/overview/why-worldfoundry)。
