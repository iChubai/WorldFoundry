title: Vendored licenses
description: Upstream license terms for in-tree copies. Official texts live at the upstream URLs, not as colocated LICENSE or UPSTREAM files.
---

WorldFoundry keeps some upstream inference code under `worldfoundry/base_models` and a few synthesis runtimes. Standalone `LICENSE`, `COPYING`, `NOTICE`, and `UPSTREAM.md` files are **not** stored next to that code. Read the official text at the upstream URL before you use a tree, especially for non-commercial or research-only terms.

Source-file copyright headers and SPDX comments stay in the code. Package-level attribution also lives in the repository-root `THIRD-PARTY-NOTICES` file.

<Callout type="warn" title="Non-commercial trees">
  Several 3D reconstructions are CC BY-NC-SA 4.0, CC BY-NC 4.0, or an Inria / Stability / Tencent research license. Those copies are for academic and evaluation use. Commercial use needs a separate grant from the upstream licensor.
</Callout>

## Do not merge parallel copies

These trees look related but are not interchangeable:

- **MonST3R** embeds a forked DUSt3R. Five files differ from canonical `general_3d/dust3r` (`cloud_opt/base_opt.py`, `cloud_opt/optimizer.py`, `model.py`, `utils/misc.py`, `utils/vo_eval.py`). Replacing them breaks motion-aware optimization.
- **Stable Virtual Camera** embeds an older DUSt3R/CroCo API. It is a different release, not a reformatted duplicate of canonical `dust3r`.
- **MegaSaM** embeds its own DROID-SLAM, UniDepth, and Depth-Anything forks. Do not replace them with the canonical WorldFoundry trees.
- **HunyuanWorld-Mirror** and **hyworldmirror_2p0** are two versions. The 2.0 tree imports utilities from `hunyuan_mirror`.
- **YOLO-World** exists twice (canonical detector tree and OpenS2V-Nexus eval). Treat semantic fixes as applying to both until they are deduplicated.
- Bare `import dust3r` / `import croco` can resolve to the wrong copy if more than one tree is on `sys.path`.

## Maintainer rule

When you vendor or update an in-tree upstream copy, record the license name and upstream URL on this page. Do not add a colocated `LICENSE`, `COPYING`, `NOTICE`, or `UPSTREAM.md` file next to the source.
