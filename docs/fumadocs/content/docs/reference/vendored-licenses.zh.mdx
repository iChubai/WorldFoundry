## 不要合并平行副本

这些树看起来相关，但不能互换：

- **MonST3R** 内嵌修改过的 DUSt3R。和仓内正式 `general_3d/dust3r` 有 5 个文件不同（`cloud_opt/base_opt.py`、`cloud_opt/optimizer.py`、`model.py`、`utils/misc.py`、`utils/vo_eval.py`）。换掉会破坏 motion-aware optimization。
- **Stable Virtual Camera** 内嵌的是较旧的 DUSt3R/CroCo API，不是正式 `dust3r` 的格式化副本。
- **MegaSaM** 自带 DROID-SLAM、UniDepth、Depth-Anything 的 fork，不能用仓内正式树替换。
- **HunyuanWorld-Mirror** 和 **hyworldmirror_2p0** 是两个版本。2.0 树会从 `hunyuan_mirror` import 工具函数。
- **YOLO-World** 有两份（正式 detector 树和 OpenS2V-Nexus eval）。在去重之前，语义修复要两边一起做。
- 如果不止一棵树在 `sys.path` 上，裸 `import dust3r` / `import croco` 可能解析到错误副本。
