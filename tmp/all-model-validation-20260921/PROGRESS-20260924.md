# WorldFoundry 全模型验证进展（2026-09-24）

当前覆盖快照包含 440 个模型、公共绑定、运行配置及必要变体。`COVERAGE.md` 由 `inventory.json`、`additional-variants.json` 和 `observations.json` 渲染；接口导入检查不能替代真实推理。当前最新状态为：139 `verified_configuration`、119 `verified_inference_only`、47 `quality_concern`、33 `blocked_external`、11 `failed_integration`、91 `not_run`。这些数字是条目数，不是成功率。

本批真实权重 GPU 结果包括 WorldMirror 的深度、法线、相机、点云与 Gaussian 输出；ATI-Wan2.1-14B 的 81 帧 8 步及默认 40 步视频；X-VLA 七个 checkpoint 的有限动作张量；以及 StarWM 上游正式 SC2 样例的结构化未来观测。X-VLA 多数使用跨域输入，不能证明任务成功；StarWM 的矿物和工人数与标签不符，故只记推理通过。HunyuanVideo I2V 的 17/33/65 帧复测连续，旧 129 帧突变仍记画质疑点；HyDRA 的遮挡疑点也未消除。

外部阻塞已逐项实查。WorldGen 缺 FLUX.1-dev，AC3D 缺所需 ControlNet 权重；FastVideo 的两个本地 T5 分片不符合官方 SHA-256，故 I2V 路由修正后仍未作真实 GPU 成功声明；LTX-2.5 的两项大权重下载未完成；LongVie-1 缺首代控制权重。Voyager 公共加载路径缺运行时源码模块。MiniMax H3 权重分片可读，但当前公共加载器把约 134 GiB 组件放到一张 80 GiB H100；LTX-2/2.3 的 V2V 只有计划中的配置，没有公共运行绑定。SANA-WM Streaming 已加载真实权重并进入 refiner，发现所装 Diffusers 的顶层 transformer 不接受前缀遮罩参数；代码已修正，GPU 复测尚未完成，当前保持 `failed_integration`。

检查记录：`tests/core/attention/test_dispatch_truthfulness.py` 与 `test_kv_arena.py` 在本地私有测试目录执行为 49 passed；FastVideo CPU 契约测试 10 passed；变动的 91 个 YAML/JSON 文件解析通过，`git diff --check` 通过。`tests/` 仅本地保留，不在公开 Git 树中。权重、大型 MP4 和占位 GPU 进程不进入 Git。

后续重点是完成尚未运行的 91 项、修复 11 项集成失败并逐项复测，以及对 47 项画质疑点做具任务语义的评估。`verified_inference_only` 不能升级为任务质量通过。
