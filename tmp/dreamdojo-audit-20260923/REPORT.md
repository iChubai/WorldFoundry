# DreamDojo validation audit

DreamDojo, 2B GR-1, and distilled GR-1 were **not run** on GPU. The staged 2B GR-1 distributed checkpoint is structurally complete: its metadata contains 1,394 state keys, including 697 `net_ema.*` keys, and every one of 9,472 storage records fits within eight existing nonempty shard files ([checkpoint-integrity.json](checkpoint-integrity.json)). The empty `.distcp` files in this download are not referenced by checkpoint metadata. This is a checkpoint integrity check, not inference.

The public WorldFoundry runtime still needs the converted `model_ema_bf16.pt`, an official GR-1 evaluation dataset with LeRobot statistics and video/action sequences, and its dedicated CUDA 12.8 environment. None is present. The expected dataset path `datasets/PhysicalAI-Robotics-GR00T-Teleop-GR1/GR1_robot` is absent; the adjacent `../ckpts/nvidia--PhysicalAI-Robotics-GR00T-Teleop-GR1` staging directory is empty. The configured `../envs/dreamdojo` environment is absent. The wrapper calls `cosmos_predict2.action_conditioned`, but that module is not bundled within its runtime tree; the available unified environment also lacks `cosmos_predict2`, `cosmos_cuda`, `transformer_engine`, and `torchcodec`. Running checkpoint conversion alone would not produce a valid inference result.

The confirmed official `nvidia/DreamDojo` Hugging Face revision `89d029e10816d2995d700cb8ba06f171e0504203` has 8,246 listed files, all under pretrain/post-train directories and root metadata. None is named `student` or `distilled`; the local staged repository also has no distilled GR-1 checkpoint. Thus the distilled variant has an additional missing-weight block. [asset-audit.json](asset-audit.json) contains the individual checks. No generated video, GPU forward, or task score is claimed for these three entries.
