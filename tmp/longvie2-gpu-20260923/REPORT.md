# LongVie 2 short single-GPU validation

The WorldFoundry `LongVie2Pipeline` loaded local `Vchitect/LongVie2` control and DiT attention weights, Wan2.1-I2V-14B-480P, and the UMT5 tokenizer on physical GPU 3. With one process and VRAM management enabled, it generated [demo.mp4](demo.mp4): 9/9 decodable frames at 640×352, 16 FPS, using four denoising steps. [result.json](result.json) records the checkpoint-backed runtime result; [validation.json](validation.json) records the decode and pixel checks. [contact.jpg](contact.jpg) shows frames 0, 4, and 8: the cat and water remain recognizable, with visible scene change. Mean first-to-last pixel difference is 24.59/255.

The first frame is the local Wan example cat image. The nine dense controls are blurred grayscale versions of it, and the nine sparse controls are schematic colored point grids; [preflight.json](preflight.json) lists the local paths and parameters. This checks the single-GPU loading, control-input, diffusion, and export path. It does **not** measure depth or pointmap control accuracy, long-horizon continuity, or 81-frame/50-step quality. The existing catalog records a separate four-rank full-quality Studio run dated 2026-07-28; that historical claim is not inferred from this short artifact.
