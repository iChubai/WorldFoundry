# Matrix-Game 2 Universal official-action validation

Public MatrixGame2Pipeline Universal checkpoint, official snowy reference image, seed42, official_bench_actions=true, 15 requested latent frames yielding 57 RGB frames 640x352/12fps. Both official and WorldFoundry videos fully decoded. Three CPU action lengths matched official tensors exactly; after project RNG/seed repair, decoded RGB mean absolute difference improved from 54.890 to 4.762. Viewed all six paired contact positions from the actual decoded videos: the snowy hut, trees and mountain background remain coherent while the camera moves around the hut and returns; corresponding official and repaired WorldFoundry frames have nearly the same layout. Fine texture and color differ, so this is not bitwise parity. This validates the short configuration, not the 150-latent-frame default, benchmark score, closed-loop gameplay, or exact pixel equality.

The original integrated run sampled official benchmark actions before applying seed42 and skipped an upstream random draw for the constant segment length. The result was a different camera trajectory (decoded RGB MAE 54.890). The repaired operator consumes that draw; the public pipeline passes seed42 into action construction, and the demo sidecar records the same seeded sequence. Official and repaired control tensors are exactly equal for 17, 57 and 153 RGB-frame lengths.

The fixed WorldFoundry run and official source run used separate H100 GPUs with the same Universal checkpoint, official image and parameters. The 15 model-frame argument produces 57 decoded RGB frames; both output videos passed full decode. Six corresponding frames were viewed, and mean RGB absolute difference fell to 4.762. This is close visual parity, not exact pixels. The checkpoint's local SHA-256 equals the official LFS SHA-256 at revision f1729d99a80e0f07993a77d7dad4a3190e23c2c8. No long rollout or benchmark scoring was run.
