# Zing-0.5

Inference-only adaptation of https://github.com/seedleap/zing-world-model at `11212da06f63290f4d354cdc0324241ba6eac356`. License: Apache-2.0 (see LICENSE).

Wan layers, UMT5, VAE and attention dispatch are reused from WorldFoundry base_models/core. Only Zing action conditioning, prompt-switch KV caches, message schema and DMD rollout are adapted. No upstream training code is included.
