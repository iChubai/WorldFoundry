## Usage

Nothing in WorldFoundry loads it. It is only listed in the Studio visualization inventory (`worldfoundry/studio/visualization/capability_registry.py`, shown by `wf models visualizations`) and in `segmentation_stack`, which no benchmark declares. Stage the weights with `wf models assets --capability mobile_sam --execute-downloads`.
