# FETV BLIP

BLIP retrieval model from FETV's automatic evaluation.

## Used by

| Benchmark / consumer | Metric | Caller |
| --- | --- | --- |
| FETV | BLIP-based text–video alignment | `worldfoundry/evals/tasks/execution/runners/fetv/runtime/fetv_eval/auto_eval.py` |

## Usage

Capability `fetv_blip_retrieval_source`; `WORLDFOUNDRY_FETV_BLIP_TOKENIZER` overrides the tokenizer.
