# Astronex-World inference integration

Upstream: https://github.com/Astronex-Robotics/Astronex-World

Revision: `27584bf1a89da01ef35a03b48d83bc818d2adf2b`

Wan2.2 TI2V-5B with PRoPE camera conditioning, 64-dimensional actions and embodiment conditioning. The official sampler remains external; no Wan backbone is copied into this integration.

No training loops, losses, optimizers, datasets or training configuration files are vendored by this integration. GPU artifact validation is pending.
