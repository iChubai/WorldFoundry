# SolarWM inference integration

Upstream: https://github.com/Junchao-cs/SolarWM

Revision: `2fe1ea9aca072f787bbba07ee9380b0e1ea7563b`

A single WorldFoundry launcher selects the released solarwm infer route in its dedicated backend environment. Source backbones, training code and data pipelines are not vendored.

No training loops, losses, optimizers, datasets or training configuration files are vendored by this integration. GPU artifact validation is pending.
